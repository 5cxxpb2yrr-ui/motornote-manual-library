Inspection Mode 7

DTC Item Note
B157287 Immobilizer communication -

Diagnostic procedure:

  1. Check that the battery voltage is 12 V or more and fuel remains approx. half [20 - 40 L (5.3 - 10.6 US gal, 4.4 - 8.8 Imp gal)].
  2. Using the Subaru Select Monitor. Perform the clear memory of [P-HEV Hybrid Powertrain Control].

    Refer to COMMON (DIAG)>CLEAR MEMORY .

  3. Using Subaru Select Monitor. read the DTC of [P-HEV Hybrid Powertrain Control] to check that there is no DTC displayed. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
    NOTE: If the DTC is displayed on the screen, the trouble is still present. Perform the diagnosis for the displayed DTCs. After solving the DTC, repeat from step  1.
  4. Turn the ignition switch to OFF.
  5. Turn to READY ON.
  6. Using Subaru Select Monitor. read the DTC of [P-HEV Hybrid Powertrain Control] to check that there is no DTC displayed. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
    NOTE: If the DTC is displayed on the screen, the trouble is still present. Perform the diagnosis for the displayed DTCs. After solving the DTC, repeat from step  1.
