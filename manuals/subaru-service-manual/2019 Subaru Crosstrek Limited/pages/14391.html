Monitor Description

WARNING: This page is about a different variant/trim than selected.

The Charge control ECU built into the Electric vehicle charger assembly monitors the input alternating voltage using the VAC sensor. If it detects a VAC sensor malfunction, it illuminates the MIL and stores a DTC.
