Lane Departure Warning Off Indicator Light Does Not Illuminate/Lane Departure Warning Off Indicator Light Goes Off Automatically

  1. CHECK CONDITION OF OCCURRENCE. 

    Interview the customer to check if it occurs when the engine is started.

    Does it occur when starting the engine?

    Yes:  This is normal. (Light illumination for a while after the engine start is normal.)

    No:  Go to  2.

  2. CHECK LANE DEPARTURE WARNING OFF SWITCH. 

    Check the lane departure warning OFF switch. Refer to EYESIGHT (DIAGNOSTICS) (EXCEPT FOR HEV)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC B28B7 LDP OFF SWITCH .

    Is the check result OK?

    Yes:  Replace the stereo camera. Refer to EYESIGHT>STEREO CAMERA>REMOVAL .

    No:  Repair or replace the faulty portion according to the inspection result.
