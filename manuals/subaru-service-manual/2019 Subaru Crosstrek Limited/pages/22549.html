DTC P1F0C: Transfer Input Torque: Notes

1. - 

DTC detecting condition: 

Immediately at fault recognition

Trouble symptom: 

Driveability getting worse.

  1. CHECK DTC  .

    Read the DTC of [Engine] using the Subaru Select Monitor. Refer to ENGINE (DIAGNOSTICS) (H4DO (HEV))>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC P1622 displayed?

    Yes:  Perform the diagnosis according to DTC. Refer to ENGINE (DIAGNOSTICS) (H4DO (HEV))>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Go to  2.

  2. CHECK DTC  .

    Using the Subaru Select Monitor, read the DTCs of [P-HEV Hybrid Powertrain Control] and [Engine]. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) . Refer to ENGINE (DIAGNOSTICS) (H4DO (HEV))>DIAGNOSTIC TROUBLE CODE (DTC) .

    Besides DTC P1622, is any DTC displayed?

    Yes:  Perform the diagnosis according to DTC. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST . Refer to ENGINE (DIAGNOSTICS) (H4DO (HEV))>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Current condition is normal. Reproduce the failure, and then perform the diagnosis again.
