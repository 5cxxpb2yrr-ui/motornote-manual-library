Basic Diagnostic Procedure: Procedure

CAUTION:
  • Subaru Select Monitor kit is required for reading DTC, performing diagnosis and reading data monitor.
  • Before removal or installation, be sure to remove any foreign matter (dust, moisture, oil, etc.).
  • Registration of immobilizer may be needed after the replacement of control modules, etc. For detailed procedure, refer to the "REGISTRATION INSTRUCTIONS FOR IMMOBILIZER" provided as a separate volume.
NOTE: Using the Function Setting (Customize), check that the keyless access system is not in a cancelled state. Refer to SECURITY AND LOCKS>FUNCTION SETTING (CUSTOMIZE)>OPERATION .
  1. PERFORM CUSTOMER INTERVIEW. 

    Ask the customer when and how the trouble occurred using the interview check list. Refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS)>CHECK LIST FOR INTERVIEW .

    Did you interview the customer?

    Yes:  Go to  2.

    No:  Perform the interview, and Go to  2.

  2. BASIC INSPECTION. 

    Perform basic inspection. Refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS)>GENERAL DESCRIPTION>INSPECTION .

    Is the check result OK?

    Yes:  Go to  3.

    No:  Repair the faulty part found in basic inspection, and Go to  3.

  3. CHECK SUBARU SELECT MONITOR COMMUNICATION. 
    1. Turn the ignition switch to OFF.
    2. Connect the Subaru Select Monitor to data link connector. Refer to COMMON (DIAG)>DATA LINK CONNECTOR .
    3. Turn the ignition switch to ON and run the Subaru Select Monitor.
    4. Select keyless access with push button start.
      NOTE: For detailed operation procedures, refer to "Help" of application.

    Is communication possible?

    Yes:  Go to  4.

    No:  Check the communication circuit. Refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE FOR SUBARU SELECT MONITOR COMMUNICATION .

  4. CHECK DTC. 

    Read the DTC of [Keyless Access with Push Button Start] using the Subaru Select Monitor. Refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed? (Current malfunction)

    Yes:  Record the DTC, time stamp and freeze frame data, and Go to  5.

    No:  Go to  6.

  5. PERFORM DIAGNOSIS. 
    1. Perform the diagnosis according to the DTC.
    2. Repair or replace the cause of trouble.
    3. Using the Subaru Select Monitor. Perform the clear memory of [Keyless Access with Push Button Start]. Refer to COMMON (DIAG)>DATA MONITOR .
    4. Execute the inspection mode. Refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS)>INSPECTION MODE .
    5. Read DTCs of Keyless Access with Push Button Start using the Subaru Select Monitor. Refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed? (Current malfunction)

    Yes:  Repeat Go to  5. until DTC is not shown.

    No:  Finish the diagnosis.

  6. CHECK LIST OF DIAGNOSTICS WITH PHENOMENON. 

    Check "Diagnostics with Phenomenon". Refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS)>DIAGNOSTICS WITH PHENOMENON .

    Is there a symptom that corresponds in the phenomenon list?

    Yes:  Perform diagnosis according to the procedures in the phenomenon list.

    No:  Keyless access with push button start system is normal.
