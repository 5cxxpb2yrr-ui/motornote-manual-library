TECHNICAL SERVICE BULLETIN

Reference Number(s): 15-247-19R, Date of Issue:  May 02, 2023
SUBARU: All Models

APPLICABILITY

All Models Equipped with Harman Audio/Navigation Head Units

Issue has been resolved in Past Firmware updates, please see TSB 15-236-18R for Software Update Bulletin for procedure 

INTRODUCTION

This Service Information Bulletin announces availability of a map update which includes new software to address a route searching error. A "Route Calculation Unsuccessful" message may be displayed when the selected route crosses state borders (e.g. Route 53 which crosses between Alabama and Tennessee).

SERVICE PROCEDURE/INFORMATION

REMINDER:  Customer satisfaction and retention starts with performing quality repairs.

If there is a customer complaint received similar to the map/navi issue as described above, Retailers (as a courtesy and/or customers) can update the map data by accessing the web portal on Subaru.com. A copy of the instructions is supplied below for convenience.
