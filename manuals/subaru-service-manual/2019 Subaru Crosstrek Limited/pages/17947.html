Secondary Pressure Sensor: Inspection

  1. Start and warm up the engine.
  2. Depress the brake pedal, and shift the select lever to "D" range.
  3. Shift the select lever to "P" or "N" range.
  4. Depress the brake pedal and hold it.
  5. Check «secondary pressure sensor voltage» by using Subaru Select Monitor while the engine is idling. Refer to TRANSMISSION (DIAGNOSTICS)>DATA MONITOR>OPERATION .

    Standard 

    Approx. 0.8 V

  6. Check «secondary pressure sensor voltage» by using Subaru Select Monitor while the engine is stopped and the ignition switch is turned on. Refer to TRANSMISSION (DIAGNOSTICS)>DATA MONITOR>OPERATION .

    Specification: 

    Approx. 0.5 V
