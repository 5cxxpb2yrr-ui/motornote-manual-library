Clutch Start Switch

WARNING: This page is about a different variant/trim than selected.
  1. Install the clutch start switch.
  2. Fully depress the clutch pedal and hold it.
  3. Install so that the gap (A) between the clutch pedal plate and the clutch start switch becomes 7.3 mm (0.29 in), and tighten the lock nut.

    Tightening torque: 

    8 N.m (0.8 kgf-m, 5.9 ft-lb)

    Courtesy of SUBARU OF AMERICA, INC.
  4. Connect the connector to the clutch start switch.
  5. Check the clutch start system.
  6. Install the knee airbag module. Refer to AIRBAG SYSTEM>KNEE AIRBAG MODULE>INSTALLATION .
  7. Install the instrument panel lower cover. Refer to EXTERIOR/INTERIOR TRIM>INSTRUMENT PANEL LOWER COVER>INSTALLATION .
  8. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
