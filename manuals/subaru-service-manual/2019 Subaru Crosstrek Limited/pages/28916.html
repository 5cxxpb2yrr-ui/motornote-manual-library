Diagnostic procedure:

  1. Using the Subaru Select Monitor, perform the clear memory of [Air Conditioner]. Refer to COMMON (DIAG)>CLEAR MEMORY .
  2. Using the Subaru Select Monitor, read the DTC of [Air Conditioner] to check that there is no DTC displayed. Refer to AIR CONDITIONER (DIAGNOSTICS) (HEV)>DIAGNOSTIC TROUBLE CODE (DTC) .
    NOTE: If the DTC is displayed on the screen, the trouble is still present. Perform the diagnosis for the displayed DTCs. After solving the DTC, repeat from step  1.
  3. Turn to READY ON and leave unattended for 20 seconds or more.
  4. Using the Subaru Select Monitor, read the DTC of [Air Conditioner] to check that there is no DTC displayed. Refer to AIR CONDITIONER (DIAGNOSTICS) (HEV)>DIAGNOSTIC TROUBLE CODE (DTC) .
    NOTE: If the DTC is displayed on the screen, the trouble is still present. Perform the diagnosis for the displayed DTCs.
