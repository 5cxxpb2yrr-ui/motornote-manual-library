Keyless Access Control Module: Installation

CAUTION: When the control module related to immobilizer has been replaced, be sure to perform the registration of immobilizer system. For detailed operation procedure, refer to "Type D" (except for hybrid model) or "Type F" (hybrid model) described in "REGISTRATION MANUAL FOR IMMOBILIZER".
  1. Install the keyless access Control Module.
  2. Install the pocket assembly and the back panel - pocket.
  3. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
