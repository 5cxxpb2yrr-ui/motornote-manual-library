Remote Climate Control (RCC) Operating Condition

WARNING: This page is about a different variant/trim than selected.
Item Condition
Push button ignition switch status ACC OFF, IG OFF
Push button ignition switch is not pressed
2.5 or more seconds have elapsed after push button ignition switch operation
Security status Alarm system information is normal
Door open/close status All doors closed
Hood is closed
Door lock status When starting by using access key or smartphone: All doors are locked or lockable
When starting in conjunction with charging: All doors are locked
NOTE: When operating conditions become less satisfied during RCC operation, stop the system.
