CVTF Inlet Pipe And CVTF Outlet Pipe

Do you like it dark? Easier on the eyes.

WARNING: This page is about a different variant/trim than selected.
CAUTION: Always use specified ATF. ATF other than specified ATF will cause malfunction.
  1. Use union bolts and new gaskets and temporarily install the CVTF inlet pipe and CVTF outlet pipe.
  2. Temporarily install the bolts which fasten the CVTF inlet pipe and CVTF outlet pipe, and install the clips.
  3. Tighten the bolts and union bolts in the numerical order as shown in the figure.

    Tightening torque: 

    T1: 16 N.m (1.6 kgf-m, 11.8 ft-lb)

    T2: 40 N.m (4.1 kgf-m, 29.5 ft-lb)

    Fig 1: CVTF Inlet Pipe And CVTF Outlet Pipe Bolts Tightening Sequence
    Courtesy of SUBARU OF AMERICA, INC.
  4. Install a new CVTF CVT inlet hose and a new CVTF CVT outlet hose.
  5. Install the front exhaust pipe.

    Refer to EXHAUST (H4DO (EXCEPT FOR HEV))>FRONT EXHAUST PIPE>INSTALLATION .

  6. Connect the battery ground terminal.

    Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .

  7. Adjust the ATF level.

    Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TH2A)>AUTOMATIC TRANSMISSION FLUID>REPLACEMENT .
