DTC B1408: Meter Non-Volatile Memory

Diagnosis start condition: 

  • Battery voltage is 10 V or more.
  • The remote engine starter was not used to start the engine.

DTC detecting condition: 

Defective combination meter

Trouble symptom: 

  • Engine will not start.
  • The security indicator illuminates.
CAUTION: When the combination meter is replaced, registration of the immobilizer system is required. For details, refer to the "REGISTRATION INSTRUCTIONS FOR IMMOBILIZER" provided as a separate volume.
  1. CHECK COMBINATION METER REGISTRATION. 
    1. Using the Subaru Select Monitor, perform the clear memory of [Body Control] and [Combination Meter]. Refer to COMMON (DIAG)>CLEAR MEMORY .
      • Body Control
      • Combination Meter
    2. Perform registration of combination meter. Refer to the "REGISTRATION INSTRUCTIONS FOR IMMOBILIZER" provided as a separate volume.
    3. Read the DTC of [Body Control] using the Subaru Select Monitor. Refer to IMMOBILIZER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

      Is DTC B1408 displayed? (Current malfunction)

      Yes:  Replace the combination meter. Refer to INSTRUMENTATION/DRIVER INFO>COMBINATION METER .

      No:  Even if DTC is displayed, the circuit has returned to a normal condition at this time. Reproduce the failure, and then perform the diagnosis again.

      NOTE: In this case, temporary poor contact of connector, temporary open or short circuit of harness may be the cause.
