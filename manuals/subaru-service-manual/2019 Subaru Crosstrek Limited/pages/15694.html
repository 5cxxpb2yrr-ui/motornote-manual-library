Center Brake Pipe

  1. Install the brake pipe.
    1. Install the brake pipe to the pipe clip and the rear floor.
    2. Install each brake pipe using a flare nut wrench.

      Tightening torque: 

      Refer to "COMPONENT" of "General Description". Refer to BRAKE>GENERAL DESCRIPTION>COMPONENT>CENTER BRAKE PIPES AND HOSES .

  2. Install the support - sub frame.

    Tightening torque: 

    Refer to "COMPONENT" of "General Description". Refer to REAR SUSPENSION>GENERAL DESCRIPTION>COMPONENT>REAR SUSPENSION .

  3. Install the fuel tank.
    • Except for hybrid model: Refer to FUEL INJECTION (FUEL SYSTEMS) (H4DO (EXCEPT FOR HEV))>FUEL TANK>INSTALLATION .
    • Hybrid model: Refer to FUEL INJECTION (FUEL SYSTEMS) (H4DO (HEV))>FUEL TANK>INSTALLATION .
  4. Install the rear differential.
    • T-type: Refer to DIFFERENTIALS>REAR DIFFERENTIAL (T-TYPE)>INSTALLATION .
    • VA-type: Refer to DIFFERENTIALS>REAR DIFFERENTIAL (VA-TYPE)>INSTALLATION .
  5. Install the propeller shaft assembly. Refer to DRIVE SHAFT SYSTEM>PROPELLER SHAFT>INSTALLATION .
  6. Install the rear exhaust pipe. Refer to EXHAUST (H4DO (EXCEPT FOR HEV))>REAR EXHAUST PIPE>INSTALLATION .
  7. Install the floor under protector RH. Refer to EXTERIOR/INTERIOR TRIM>FLOOR UNDER PROTECTOR>INSTALLATION .
  8. Install the fuel tank protector.
    • Except for hybrid model: Refer to FUEL INJECTION (FUEL SYSTEMS) (H4DO (EXCEPT FOR HEV))>FUEL TANK PROTECTOR>INSTALLATION .
    • Hybrid model: Refer to FUEL INJECTION (FUEL SYSTEMS) (H4DO (HEV))>FUEL TANK PROTECTOR>INSTALLATION .
  9. Install the crossmember support - rear RH. Refer to FRONT SUSPENSION>CROSSMEMBER SUPPORT>INSTALLATION .
  10. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY>GROUND TERMINAL REMOVAL OR INSTALLATION .
  11. Bleed air from the brake line.
    • Except for hybrid model: Refer to BRAKE>AIR BLEEDING>PROCEDURE>BRAKE LINE (EXCEPT FOR HYBRID MODEL) .
    • Hybrid model: Refer to BRAKE>AIR BLEEDING>PROCEDURE>BRAKE LINE (HYBRID MODEL) .
  12. Install the rear wheels.

    Tightening torque: 

    120 N.m (12.2 kgf-m, 88.5 ft-lb)
