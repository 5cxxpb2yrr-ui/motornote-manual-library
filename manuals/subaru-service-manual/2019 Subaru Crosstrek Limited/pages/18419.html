DTC C2547: Eyesight Check Sum

DTC detecting condition: 

When check sum error of EyeSight transmission data is detected after the ignition switch is ON.

Trouble symptom: 

EyeSight steering support function does not operate.

CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to POWER STEERING (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK POOR CONTACT OF CONNECTOR. 

    Is there poor contact of the stereo camera connector?

    Yes:  Repair the poor contact of connector.

    No:  Go to  2.

  2. CHECK DTC. 

    Read the DTC of [EyeSight] using the Subaru Select Monitor. Refer to EYESIGHT (DIAGNOSTICS) (EXCEPT FOR HEV)>DIAGNOSTIC TROUBLE CODE (DTC) . Refer to EYESIGHT (DIAGNOSTICS) (HEV)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC of EyeSight system displayed?

    Perform the diagnosis according to the DTC. Refer to EYESIGHT (DIAGNOSTICS) (EXCEPT FOR HEV)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST . Refer to EYESIGHT (DIAGNOSTICS) (HEV)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Go to  3.

  3. CHECK LAN SYSTEM. 

    Perform the diagnosis for LAN system using the Subaru Select Monitor. Refer to LAN SYSTEM (DIAGNOSTICS) (EXCEPT FOR HEV)>BASIC DIAGNOSTIC PROCEDURE . Refer to LAN SYSTEM (DIAGNOSTICS) (HEV)>BASIC DIAGNOSTIC PROCEDURE .

    Is DTC of CAN communication displayed?

    Yes:  Perform the diagnosis according to DTC. Refer to LAN SYSTEM (DIAGNOSTICS) (EXCEPT FOR HEV)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST . Refer to LAN SYSTEM (DIAGNOSTICS) (HEV)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Go to  4.

  4. CHECK POWER STEERING CONTROL MODULE. 
    1. Connect all connectors.
    2. Execute the inspection mode. Refer to POWER STEERING (DIAGNOSTICS)>INSPECTION MODE .
    3. Read the DTC of [Power Steering System] using the Subaru Select Monitor. Refer to POWER STEERING (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC C2547 displayed in current malfunction?

    Yes:  Replace the steering gearbox. Refer to POWER ASSISTED SYSTEM (POWER STEERING)>ELECTRIC POWER STEERING GEARBOX .

    No:  It results from a temporary noise interference. Clear the memory to complete the diagnosis. Refer to COMMON (DIAG)>CLEAR MEMORY .
