Front Sealing Cover

Do you like it dark? Easier on the eyes.

  1. Install the front sealing cover.
    1. Install while aligning the reference holes located in the front and rear of the sealing cover with the reference projections (a) of the panel assembly - front door.
    2. Check that the installation hole (b) of the trim panel - front door is not blocked.
      Courtesy of SUBARU OF AMERICA, INC.
    3. When replacing the sealing cover, use the butyl tape.

      Preparation items: 

      Butyl tape: 3M Butyl Tape 8626 or equivalent

    4. Forcefully push the butyl tape portion to prevent any floating on surface.
  2. Install the trim panel - front door.
  3. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY>GROUND TERMINAL REMOVAL OR INSTALLATION .
