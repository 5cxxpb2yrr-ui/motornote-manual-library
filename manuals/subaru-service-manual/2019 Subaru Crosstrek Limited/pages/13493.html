DTC P0613: TCM Processor: Notes

1. - 

DTC detecting condition: 

Immediately at fault recognition

Trouble symptom: 

TCM processor error

CAUTION: After servicing or replacing faulty parts, perform the last step of the basic diagnostic procedure. Refer to TRANSMISSION (DIAGNOSTICS)>BASIC DIAGNOSTIC PROCEDURE .
  1. CHECK DTC  .
    1. Using the Subaru Select Monitor, perform the clear memory. Refer to COMMON (DIAG)>CLEAR MEMORY .
    2. Read the DTC using Subaru Select Monitor. Refer to TRANSMISSION (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC P0613 displayed?

    Yes:  Replace the TCM. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSMISSION CONTROL MODULE (TCM) .

    No:  Current condition is normal. Check for interference from noise, etc.
