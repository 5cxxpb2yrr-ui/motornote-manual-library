Diagnostic Method

Judge as NG when the following conditions are established.

JUDGMENT VALUE SPECIFICATION

Malfunction Criteria Threshold Value
Judgment 1: Write and read test  
Written value to RAM Not equal to the reading value
Judgment 2: Error Correcting
Code (ECC) check		  
Check error of error correction code Detected

Time needed for diagnosis:  2 time

Malfunction indicator light illumination:  Illuminates as soon as a malfunction occurs.
