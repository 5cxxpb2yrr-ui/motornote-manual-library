From time to time the circumstance may arise where the combination meter needs to be replaced on a vehicle. Before replacement, Technicians should take note on which type of meter the vehicle is equipped with and current mileage. Certain model lines have different procedures regarding odometer writing, variant work being performed, and applied model setting. Please refer to the following charts and articles regarding combination meter replacement. Always consult STIS or contact the Techline for assistance.

First, we will discuss odometer writing. The following chart identifies the 3 main types of combination meters and their odometer writing capabilities.

Type 1:  These meters can be found on earlier models. The mileage cannot be written or saved from this meter. A mileage sticker will need to be affixed in a safe and accessible location. Usually the driver side inner door jamb is a good place.

Type 2:  These meters have the capability for mileage to be preprogrammed, so a sticker is no longer needed. This is made possible by United Radio (UR). They need to be contacted through the ordering process found on Subarunet. Ask your parts department for assistance. UR will write the appropriate mileage to the combination meter BEFORE  a Technician programs it to the vehicle. The vehicle needs to remain parked for the period, between ordering of the new meter and installation to avoid mileage mismatch.

NOTE: Type 1 and some Type 2 meters need the keys re-registered to the vehicle after combination meter replacement. Consult the appropriate Immobilizer Registration Manual. (STIS> Online Reference> check "Other/Miscellaneous" and use "IMM" as the keyword.)

The ordering process can be found under Parts Operations > Combi Meter Order Request.

Type 3:  Finally, the latest model of meter allows Technicians to transfer/write the odometer mileage to the combination meter through the Subaru Select Monitor. This process should take place with new and old meters in hand as the SSM will prompt the Technician. The process can be found under work support for the combination meter and is part of the variant work process.

NOTE: If for some reason the mileage cannot be read, for ANY  style meter, a mileage sticker MUST be used. This includes performing Variant Work: Operation Procedure B.

07 VARIANT WORK PROCEDURES

Most current model vehicles require Variant Work to be performed when replacing the combination meter. Typically, the Technician will perform Operation Procedure A which saves the configuration from the original meter before replacement then uploads it to the new meter. If Operation Procedure A fails or communication to the meter cannot be established, the Technician must perform Operation Procedure B. Due to changes in SSM software, additional steps are needed to successfully input the Applied Model and Option codes.

To enter this information, the Technician must click the "Input" button, enter the code, click OK, and click OK again.
NOTE: If abnormal lights appear on the combo meter, or lost communication codes with modules, the Variant Work may not have been performed correctly. Inspect the vehicle to see if it is equipped with the options indicated by the lights or DTCs.

Example:  A Technician receives a customer concern of the SRH (Steering Responsive Headlights) warning light is illuminated on the dash. The Technician inspects the vehicle and finds lost communication codes with the SRH CM. The Technician proceeds to inspect the headlights and finds this vehicle is not equipped with this option. The Technician needs to perform the variant work with the Subaru Select Monitor to correct the condition.

The Variant Work is very important because it indicates to the other control modules as to which features the vehicle is equipped with.

Important Variant Work Procedure Notes: 

  • If Operation Procedure A failed (write operation has failed) or operation Procedure B failed, the combination meter must be replaced with a new one.
  • Only  Operation Procedure A can read the odometer value. However, if the SSM shuts down or is disconnected during the procedure you will not  be able to write it to the new meter.
  • Operation Procedure B cannot  write the odometer value.
  • The writing of the combination meter is a onetime only action. It cannot be modified.

Always refer to STIS & the applicable Service Manual when replacing components. 

Go to: STIS> Body & Electrical/Wiring System> Instrumentation/Driver Info> Combination meter System> Operation> 3. Variant Work.

VARIANT WORK: Operation Procedure A 

Step 1: Read Control module setting information.

This reads the current setting information for the Combination Meter and saves it to the SSM. Make sure it is saved to a location where it can be found again.

Step 2: Write Control module setting information and odometer.

This step should happen immediately after saving the Read Control module file. There will be no  prompt from the SSM. The Technician needs to select this from Work Support to continue. Once selected, follow the prompts. When finished, the SSM will advise to replace the combination meter with the new one without turning the power off. The new meter should be installed at this point and continue following the prompts until the saved files/mileage are written.

Step 3: Write Control module setting information

Finally, the Technician needs to write the saved control module setting. Select Write Control module setting information -> Write ECU setting saved data -> Select the file saved earlier and follow the SSM prompts.

This completes the Variant Work Procedure A process. Be sure to confirm all functions of the Combination Meter operate before releasing the vehicle.

VARIANT WORK: Operation Procedure B 

1 Step:  Write Control module setting information.

After installing the new combination meter, perform the writing information procedure.

Select Write Control module setting information - > Write ECU Setting 12 Columns of models.

Follow the prompts from SSM, including inputting of the option code/applied model. This information can be found on the identification plaque located at the base of the passenger side B-pillar door jamb.

Special Input Code: 

(Featured in December 2019 TechTIPS) 

When performing Variant Work Procedure B, Technicians have reported a prompt for a special "input code". This concern can occur if the applied model or option code is input incorrectly. Side effects could include malfunction indicator lamps and false DTCs as mentioned earlier. Be mindful not to confuse characters. All letters for the Applied Model/Option Code are capitalized. The number 1 may be confused with the letter I (as in Indigo) as well as the number 5 and S (as in Sierra). If encountering this condition, follow the instructions below to repair the vehicle.

08 JOURNEY TIME ALERT ON COMBINATION METER TELLTALE DISPLAY

(Featured in September 2015 TechTIPS) 

An added feature of the Combination Meter is an alert message (accompanied by a single "beep" sound) which will be displayed in the Telltale section above the odometer after 2 hours of driving have elapsed from ignition ON. The "beep" is the same sound heard when the low fuel lamp is first illuminated. This message is provided simply as a notification to make the driver aware they have been driving for 2 hours and it may be a good time to consider taking a break, checking fuel level, etc. Like other alerts shown on the Telltale display, it cannot be turned off or adjusted. This feature has been included on Subaru vehicles for several years, but unless the vehicle is driven for approximately 2 hours or more, many customers may have never experienced it.

Until the Owner's Manual is revised, information will be limited regarding this message.

08 COMBINATION METER SETTINGS: KILOMETERS TO MILES

(Featured in May 2020 TechTIPS) 

When presented with a customer concern of the odometer reading in Kilometers instead of Miles, it is always a good idea to consult the Owner's Manual. If the Manual is not found in the vehicle, it can be accessed through STIS. Below is an example of the information found in the Owner's Manual to correct this concern.

ECM to combo meter mileage inaccuracy: 

Odometer Collation. 

One newer model vehicles, Technicians have the ability to see ECM mileage with the SSM4. Sometimes the mileage displayed on the Combination Meter and ECM are different. There can be several factors that play a role in this discrepancy.

Original ECM: 

To determine the discrepancy between the odometer mileage and the mileage in the ECM, it is always a good idea to consult with the customer, or review the previous service history, to see if the ECM has ever been changed/replaced or modified in anyway.

The ECM has an original odometer PID which is calculated from engine rpm, vehicle speed and gear position (gear ratio). Basically, it would be the same or similar to the mileage displayed in the combination meter. However, if the customer removes the original ECM and drives with another ECM, the original ECM will show less mileage than the combination meter.

The combination meter calculates its value by using the vehicle speed.

Tire Wear: 

Tire wear is the largest factor in Combination Meter to ECM odometer discrepancy. As tires wear, their circumference becomes smaller causing them to rotate faster.

Because ODO is calculated based on the specified maximum diameter of tire, but actual diameter of the tire is smaller than specified maximum due to treadwear. Therefore, calculated vehicle speed and ODO value is larger than the actual value.

NOTE: There is a small allowable difference between the ECM odometer and the combination meter. The criteria is within less than 20%, in most cases it is within 10%.

Replacing the ECM or combination meter causes a reset of its odometer.

NOTE: The odometer in ECM will not be reset by memory clear, battery removal or reprogramming the ECM via Flashwrite.
