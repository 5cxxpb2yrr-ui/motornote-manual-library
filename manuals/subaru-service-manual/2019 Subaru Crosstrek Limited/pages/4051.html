Keyless Access Outdoor Antenna: Inspection

Check the keyless access exterior antenna using the Subaru Select Monitor.

  1. Check the setting by performing the keyless access with push button start system check. Refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS)>KEYLESS ACCESS WITH PUSH BUTTON START CHECK .
  2. While bringing the access key, operate the trunk opener button to check if the trunk is opened. (4 door model)
  3. While bringing the access key, operate the opener switch on the rear gate and the lock request switch to check if the door lock or lock operates. (5 door model)
