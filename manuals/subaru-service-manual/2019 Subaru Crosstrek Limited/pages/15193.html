Pressure Sensor: Inspection

  1. Perform a diagnosis code (DTC) check by connecting the Subaru Select Monitor. Refer to AIR CONDITIONER (DIAGNOSTICS) (EXCEPT FOR HEV)>DIAGNOSTIC TROUBLE CODE (DTC)>OPERATION .
    NOTE: For detailed operation procedures, refer to "Help" of application.
  2. If the following diagnosis code (DTC) is displayed, refer to "Diagnostic Procedure with Diagnostic Trouble Code (DTC)" in "AIR CONDITIONER (DIAGNOSTICS)" instructions.
    • DTC B14A3 (REFRIGERANT PRESSURE SENSOR CIRCUIT OPEN): Refer to AIR CONDITIONER (DIAGNOSTICS) (EXCEPT FOR HEV)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC B14A3 REFRIGERANT PRESSURE SENSOR CIRCUIT OPEN .
    • DTC B14A4 (REFRIGERANT PRESSURE SENSOR CIRCUIT SHORT-CIRCUIT): Refer to AIR CONDITIONER) (DIAGNOSTICS) (EXCEPT FOR HEV)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC B14A4 REFRIGERANT PRESSURE SENSOR CIRCUIT SHORT-CIRCUIT .
