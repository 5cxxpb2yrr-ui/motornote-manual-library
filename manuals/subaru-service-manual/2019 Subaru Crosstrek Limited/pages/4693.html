VDC Warning Light And VDC Indicator Light Do Not Go Off

Do you like it dark? Easier on the eyes.

Detecting condition: 

  • Defective combination meter
  • Defective engine
  • Defective CAN communication

Trouble symptom: 

VDC warning light and VDC indicator light do not go off when starting the engine.

CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to BRAKE CONTROL (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. READ DTC. 

    Read the DTC using Subaru Select Monitor. Refer to BRAKE CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC displayed?

    Yes:  Perform the diagnosis according to DTC. Refer to BRAKE CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Go to  2.

  2. CHECK VDC Contol Module. 

    Using Subaru Select Monitor, display [VDC Warning Lamp] of [Data monitor]. Refer to BRAKE CONTROL (DIAGNOSTICS)>DATA MONITOR .

    Is [VDC Warning Lamp] ON?

    Yes:  Go to  3.

    No:  Go to  5.

  3. CHECK WARNING LIGHT. 
    1. Save the freeze frame data. Refer to BRAKE CONTROL (DIAGNOSTICS)>FREEZE FRAME DATA .
    2. Using the Subaru Select Monitor, perform the clear memory. Refer to COMMON (DIAG)>CLEAR MEMORY .

    Does the VDC warning light & VDC operation indicator light go off?

    Yes:  Normal. Perform the inspection mode to check that the light does not turn ON again.

    No:  Go to  4.

  4. READ DTC. 

    After driving the vehicle at 40 km/h (25 MPH) or more, read DTCs using Subaru Select Monitor. Refer to BRAKE CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC displayed?

    Yes:  Perform the diagnosis according to DTC. Refer to BRAKE CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Go to  5.

  5. CHECK LAN SYSTEM. 

    Perform the diagnosis for LAN system using the Subaru Select Monitor. Refer to LAN SYSTEM (DIAGNOSTICS) (EXCEPT FOR HEV)>BASIC DIAGNOSTIC PROCEDURE .

    Is DTC of CAN communication displayed?

    Yes:  Replace the VDC Contol Module only. Refer to LAN SYSTEM (DIAGNOSTICS) (EXCEPT FOR HEV)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Go to  6.

  6. CHECK COMBINATION METER. 

    Check the combination meter. Refer to INSTRUMENTATION/DRIVER INFO>COMBINATION METER SYSTEM>OPERATION>SELF-DIAGNOSIS DISPLAY MODE .

    Is the check result OK?

    Yes:  Replace the VDC Contol Module & H/U. Refer to VEHICLE DYNAMICS CONTROL (VDC)>VDC CONTROL MODULE AND HYDRAULIC CONTROL UNIT (VDCCM & H/U) .

    No:  Replace the combination meter. Refer to INSTRUMENTATION/DRIVER INFO>COMBINATION METER .
