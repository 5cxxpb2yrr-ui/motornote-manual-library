How To Use General Scan Tool

Do you like it dark? Easier on the eyes.

WARNING: This page is about a different variant/trim than selected.
  1. Prepare a scan tool (general scan tool) required by SAE J1978.
  2. Connect the general scan tool to data link connector located in the lower portion of the instrument panel (on the driver's side). Refer to COMMON (DIAG)>DATA LINK CONNECTOR .
  3. Using the general scan tool, call up each data. General scan tool functions consist of:
    1. MODE $01: Current powertrain diagnostic data
    2. MODE $02: Freeze frame data
    3. MODE $03: Emission-related DTC
    4. MODE $04: Clear/Reset emission-related diagnostic information
    5. MODE $07: Request on-board monitoring test results for intermittently monitored systems
    6. MODE $09: Request vehicle information
    7. MODE $0A: Emission-related DTC (with Permanent Status)
  4. Read data according to the repairing procedure. (For detailed operation procedures, refer to the general scan tool operation manual.)
    NOTE: For details concerning DTC, refer to "Diagnostic Trouble Code (DTC)". Refer to P-HEV HIGH VOLTAGE BATTERY (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
