DTC P1CB0-38: Drive Motor "A" Position Sensor Ref Signal Frequency Incorrect: Notes

Do you like it dark? Easier on the eyes.

WARNING: This page is about a different variant/trim than selected.

Detecting condition: 

Motor resolver REF signal cycle malfunction

Excitation signal (REF signal) cycle malfunction for resolver angle detection (1 trip detection logic)

Trouble symptom: 

  • Greatly reduced output power
  • Driving in reverse not possible
  • A driving range is limited
  • Engine used while driving and engine speed becomes high
NOTE: For the diagnostic procedure, refer to DTC P1C651F. Refer to P-HEV DRIVE MOTOR (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC P1C651F GENERATOR CONTROL MODULE CIRCUIT INTERMITTENT .
