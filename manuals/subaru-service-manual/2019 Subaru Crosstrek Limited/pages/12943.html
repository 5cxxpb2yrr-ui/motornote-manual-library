Power Steering Assist Disabled

Detecting condition: 

  • Except for HEV model CAN communication error (engine rpm signal not received)
  • HEV model CAN communication error (READY signal not received)

Trouble symptom: 

  • Not assisted due to power supply voltage failure.
  • The STEERING warning light is normal but there is no power steering assist (steering feels heavy).
NOTE:
  • During driving, the assist system will not be activated when the ignition voltage drops.
  • Power steering assist is not started unless both of the ignition switch ON signal and the engine speed signal are input. (Except for HEV model)
  • Power steering assist is not started unless both the ignition switch ON signal and READY signal are input. (HEV model)
  • In any of the following cases, the power steering assist is limited and steering wheel operation may become heavy.

If the steering wheel is held to an end for a long time, or the steering wheel turning to right and left at slow speed is repeated during parking, the assist limitation (overheat protection control) may operate to prevent failures by overheat.

In this case, by stopping the engine for approx. 30 minutes for cooling, the assist will start operating. While assist limitation (overheat protection control) is in active, [Limited Assist] is displayed in [EPS Status] in the Subaru Select Monitor "Data Monitor".

  • History can be confirmed on [ECU Overheat Protection] or [IGN count from overheating protection (most recent)] of "Data Monitor".
  • The overheat protection control system is normal operation, therefore, the STEERING warning light will not come on and there will be no DTC displayed.
  • If the power steering system connector is disconnected while cooling under the overheat protection control, different DTC may be recorded. If there is no DTC and assist limitation is in active, stop the engine for approx. 10 minutes for cooling.
  1. CHECK BATTERY. 

    Check the battery. Refer to STARTING/CHARGING SYSTEMS (H4DO (EXCEPT FOR HEV))>BATTERY>INSPECTION . Refer to STARTING/CHARGING SYSTEMS (H4DO (HEV))>BATTERY>INSPECTION .

    Is the check result OK?

    Yes:  Go to  2.

    No:  Charge or replace the battery.

  2. CHECK BATTERY TERMINAL AND FUSE. 

    Check the battery terminals and the fuse.

    Is the check result OK?

    Yes:  Go to  3.

    No:  Repair or replace faulty parts.

  3. CHECK DTC. 

    Read the DTC of VDC system using the Subaru Select Monitor. Refer to BRAKE CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) . Refer to BRAKE CONTROL (DIAGNOSTICS) (HEV)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC related to VDC system or ignition power supply system displayed?

    Perform the diagnosis according to DTC. Refer to BRAKE CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST . Refer to BRAKE CONTROL (DIAGNOSTICS) (HEV)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Go to  4.

  4. CHECK DATA MONITOR. 
    1. Start the engine.
    2. Display the data monitor [Engine Speed] of the power steering control module using the Subaru Select Monitor. Refer to POWER STEERING (DIAGNOSTICS)>DATA MONITOR .

    Is [Engine Speed] the same as that in the combination meter?

    Yes:  Go to  5.

    No:  Check the CAN communication. Refer to LAN SYSTEM (DIAGNOSTICS) (EXCEPT FOR HEV)>BASIC DIAGNOSTIC PROCEDURE . Refer to LAN SYSTEM (DIAGNOSTICS) (HEV)>BASIC DIAGNOSTIC PROCEDURE .

  5. CHECK DATA MONITOR. 

    Display the data monitor [EPS Status] of the power steering control module using the Subaru Select Monitor. Refer to POWER STEERING (DIAGNOSTICS)>DATA MONITOR .

    Is [Assist limitation] displayed?

    Yes:  It is possible that temporary assist limitation has occurred due to overheat protection. Stop the engine for approx. 30 minutes, and check again.

    No:  Go to  6.

  6. CHECK DATA MONITOR. 
    1. Display the data monitor [Torque sensor main output] and [Torque sensor sub output] of the power steering control module using the Subaru Select Monitor. Refer to POWER STEERING (DIAGNOSTICS)>DATA MONITOR .
    2. Move the steering wheel to the left and right.

    Do the values of [Torque sensor main output] and [Torque sensor sub output] change along with the operation?

    Yes:  Go to  7.

    No:  Check for poor contact of the torque sensor connector.

  7. CHECK DATA MONITOR. 

    Display the data monitor [IG voltage] of the power steering control module using the Subaru Select Monitor. Refer to POWER STEERING (DIAGNOSTICS)>DATA MONITOR .

    Is [IG voltage] stable? (While wiggling the harness)

    Yes:  Go to  8.

    No:  Check the ignition switch and IG voltage harness, and repair the defective part.

  8. CHECK CONNECTOR. 
    1. Turn the ignition switch to OFF.
    2. Disconnect the connector (B204).

    Are there any damages to terminal or other parts either on the power steering control module side or on the connector side?

    Yes:  Repair the terminal.

    No:  Replace the steering gearbox. Refer to POWER ASSISTED SYSTEM (POWER STEERING)>ELECTRIC POWER STEERING GEARBOX .
