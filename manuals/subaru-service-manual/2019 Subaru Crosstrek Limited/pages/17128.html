Intake Manifold Assembly: Assembly

  1. Install the manifold absolute pressure sensor. Refer to FUEL INJECTION (FUEL SYSTEMS) (H4DO (EXCEPT FOR HEV))>MANIFOLD ABSOLUTE PRESSURE SENSOR>INSTALLATION .
  2. Install the EGR control valve. Refer to EMISSION CONTROL (AUX. EMISSION CONTROL DEVICES) (H4DO (EXCEPT FOR HEV))>EGR CONTROL VALVE>INSTALLATION .
  3. Install the EGR pipe. Refer to EMISSION CONTROL (AUX. EMISSION CONTROL DEVICES) (H4DO (EXCEPT FOR HEV))>EGR PIPE>INSTALLATION .
  4. Install the purge control solenoid valve. Refer to EMISSION CONTROL (AUX. EMISSION CONTROL DEVICES) (H4DO (EXCEPT FOR HEV))>PURGE CONTROL SOLENOID VALVE>INSTALLATION .
  5. Install the throttle body. Refer to FUEL INJECTION (FUEL SYSTEMS) (H4DO (EXCEPT FOR HEV))>THROTTLE BODY>INSTALLATION .
