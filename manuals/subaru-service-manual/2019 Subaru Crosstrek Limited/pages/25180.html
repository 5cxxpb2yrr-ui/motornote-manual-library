Diagnosis 1

WARNING: This page is about a different variant/trim than selected.

Detect the malfunction depending on the average value of time necessary for A to inverse the air fuel ratio from "Lean → Rich → Lean" to "Rich → Lean → Rich".

Courtesy of SUBARU OF AMERICA, INC.

Judge as NG when the following conditions are established.

JUDGMENT VALUE SPECIFICATION

Malfunction Criteria Threshold Value DTC
Average value of time necessary for λ to inverse the air fuel ratio to Lean → Rich → Lean
Average value when λ is lean		 More than 200 ms
More than 250 ms		 P015A
Average value of time necessary for λ to inverse the air fuel ratio to Rich → Lean → Rich
Average value when λ is rich		 More than 100 ms
More than 200 ms		 P015B

Time needed for diagnosis:  8 ms x3750time(s)

Malfunction indicator light illumination:  Illuminates when malfunction occurs in 2 continuous driving cycles.
