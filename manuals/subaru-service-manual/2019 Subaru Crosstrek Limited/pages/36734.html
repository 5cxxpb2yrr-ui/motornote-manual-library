SI-DRIVE Mode Display Icon In The Combination Meter Blinks Approx. 5 Seconds After Switching SI-DRIVE Modes

Do you like it dark? Easier on the eyes.

Diagnosis: 

SI-DRIVE mode does not switch.

CAUTION: Note that SI-DRIVE system operates the following controls when it switches the modes.
  1. When turning the engine OFF and then ON again, it switches to I (intelligent) mode regardless of the mode before turning off the engine.
  2. Switches to I (intelligent) when the malfunction indicator light illuminates while the engine is running. In this case, it will not be possible to change to the S (Sports) mode.
  1. CHECK DTC. 

    Are any DTCs displayed?

    Yes:  Check the appropriate DTC using the "Diagnostic Trouble Code (DTC)" concerning the respective units.

    No:  Go to  2.

  2. CHECK COMBINATION METER DISPLAY. 

    Check for abnormal indication other than "I" blinking.

    NOTE: Examples:
    • Malfunction indicator light illuminates.
    • Fuel economy display area is not ON.

    Is there any abnormal indication other than "I" blinking?

    Yes:  For the diagnostic procedure, refer to LAN instructions. Refer to LAN SYSTEM (DIAGNOSTICS) (HEV)>BASIC DIAGNOSTIC PROCEDURE .

    No:  Go to  3.

  3. CHECK ECM AND COMBINATION METER. 

    Is the part number of ECM and combination meter correct?

    Yes:  Replace the meter case assembly. Refer to INSTRUMENTATION/DRIVER INFO>COMBINATION METER .

    No:  Replace ECM or meter case assembly with the one with the correct part number. Refer to FUEL INJECTION (FUEL SYSTEMS) (H4DO (HEV))>ENGINE CONTROL MODULE (ECM) . Refer to INSTRUMENTATION/DRIVER INFO>COMBINATION METER .
