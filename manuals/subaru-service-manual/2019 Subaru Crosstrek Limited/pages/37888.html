Stopping Keyless Access System Function By Using Access Key

  1. Open the driver's door, and then push the door lock knob forward (LOCK direction).
  2. Press the lock button of access key and trunk/rear gate button simultaneously for five seconds or more.
  3. The buzzer sounds for two seconds, and the function stops.
    NOTE: Perform the same procedures to re-activate the keyless access system from the disabled condition.
