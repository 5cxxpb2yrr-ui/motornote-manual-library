DTC P0BE9-28: Drive Motor "A" Phase V Current Sensor Signal Bias Level Out Of Range/Zero Adjustment Failure: Notes

WARNING: This page is about a different variant/trim than selected.

Detecting condition: 

Motor inverter current sensor V-phase offset malfunction

When the absolute value of the current sensor output exceeds the specified value while no current originally flows such as inverter shutdown

(1 trip detection logic)

Trouble symptom: 

  • Greatly reduced output power
  • Driving in reverse not possible
  • A driving range is limited
  • Engine used while driving and engine speed becomes high
    NOTE: For the diagnostic procedure, refer to DTC P0BE528. Refer to P-HEV DRIVE MOTOR (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC P0BE528 DRIVE MOTOR "A" PHASE U CURRENT SENSOR SIGNAL BIAS LEVEL OUT OF RANGE/ZERO ADJUSTMENT FAILURE .
