Explanation Of Circuits

WARNING: This page is about a different variant/trim than selected.

Accelerator pedal sensor is installed in the accelerator pedal to detect the accelerator pedal opening angle. This sensor is a non-contact type sensor with a hall element. The sensor generates two types of outputs. One detects the accelerator pedal position, and the other detects malfunctions of the accelerator pedal position sensor. Voltage is output from Accelerator pedal sensor to the VPA and VPA2 terminals of Hybrid vehicle control ECU assembly. This voltage fluctuates between 0 - 5 V according to the accelerator pedal opening angle. VPA2 is used to detect fault of the sensor. Hybrid vehicle control ECU assembly judges the current angle of the accelerator pedal based on the input signals from the VPA and VPA2 terminals, and controls the hybrid system based on these signals.
