Active Test: List

Do you like it dark? Easier on the eyes.

WARNING: This page is about a different variant/trim than selected.
NOTE: If not equipped (based on area or condition), some items are not displayed.
Active test items Range Contents Execution condition
In-vehicle Air Temperature setting -72.47 - 193.82°C Set in-vehicle sensor readings. Adjusting the in-vehicle sensor value to use for A/C control is useful for reproduction test in faulty events. Ignition switch ON
NOTE: READY ON is recommended.
Ambient Air Temperature Setting -40 - 80°C Set ambient sensor readings. Adjusting the ambient sensor value to use for A/C control is useful for reproduction test in faulty events. Ignition switch ON
NOTE: READY ON is recommended.
Quantity of Sunload Setting 0 - 4448 W/m2 Set sunload sensor readings. Adjusting the sunload sensor value to use for A/C control is useful for reproduction test in faulty events. Ignition switch ON
NOTE: READY ON is recommended.
Heater Water Temperature Setting -40 - 214°C Set coolant temperature sensor readings. Adjusting the coolant temperature sensor value to use for A/C control is useful for reproduction test in faulty events. READY ON
AUTO switch mode setting ON Transmit ON signal of AUTO switch contact. By operating A/C with the signal, it is possible to judge whether the control is faulty or the switch (A/C control panel) is faulty. Ignition switch ON
NOTE: READY ON is recommended.
Air mix door actuator target open (driver's side) 0 - 100% Set the driver's seat air mix door actuator opening angle. Useful for reproduction test in faulty events. Ignition switch ON
NOTE: READY ON is recommended.
Fresh/Rec Air Dr Act Trgt Open Angle 0 - 100% Set the intake door actuator opening angle. Useful for reproduction test in faulty events. Ignition switch ON
NOTE: READY ON is recommended.
Mode Door Actuator Opening Angle Target 0 - 100% Set the mode door actuator opening angle. Useful for reproduction test in faulty events. Ignition switch ON
NOTE: READY ON is recommended.
Blower Fan Level Setting 0 - 100
NOTE: Input up to 255 is possible, but 100 - 255 is the same.
 Set the blower fan level. Useful for reproduction test in faulty events. Ignition switch ON
NOTE:
  • READY ON is recommended.
  • Compressor OFF is needed to set the level to 0.
A/C Change Setting ON/OFF Set the compressor operation request. Useful for reproduction test in faulty events.
NOTE: Active test error may occur for the protection control of the engine or compressor.
  • READY ON
  • Blower ON
Rear Defogger Setting ON/OFF Transmit the rear defogger switch contact signal. By operating A/C with the signal, it is possible to judge whether the control is faulty or the switch (A/C control panel) is faulty. Ignition switch ON
NOTE: READY ON is recommended.
PTC steps 0 - 3 Set PTC level. Useful for reproduction test in faulty events.
NOTE: The setting value may not be obtained due to power supply circuit protection.
  • READY ON
  • Blower ON
Heater core temperature setting -40 - 214°C Set the heater core sensor readings. Adjusting the heater core sensor value to use for A/C control is useful for reproduction test in faulty events. Ignition switch ON
NOTE: READY ON is recommended.
Expansion valve full open mode - A mode necessary for draining refrigerant or performing evacuation. Setting for fully opening the expansion valve is possible.
  • Ignition switch ON
  • Blower OFF
  • Compressor OFF
  • Ambient temperature: 0°C (32°F) or more
Electric expansion valve force initialization mode - A mode necessary for replacement of the electric expansion valve. Setting for resetting the electric expansion valve to the original point is possible.
  • Ignition switch ON
  • Blower OFF
  • Compressor OFF
Refrigerant filling mode - A mode used for the case where the specified amount of refrigerant cannot be obtained after refrigerant filling work. This allows refrigerant filling.
  • READY ON
  • Ambient temperature: 0°C (32°F) or more
High pressure electromagnetic valve ON/OFF High pressure solenoid valve is set. Useful for reproduction check in faulty events. Ignition switch ON
NOTE: READY ON is recommended.
Low pressure electromagnetic valve ON/OFF Low pressure solenoid valve is set. Useful for reproduction check in faulty events. Ignition switch ON
NOTE: READY ON is recommended.
Electric expansion valve for heating 5 - 100%
NOTE: Input 0% up to 100% is possible, but use the range of 5 to 100%.
 Electric expansion valve for heating is set. Useful for reproduction check in faulty events.
  • READY ON
  • EV condition (READY for engine stop)
  • A/C switch OFF
  • Fan dial: HI (MAX)
  • Setting temperature: MAX HOT
  • Ambient temperature: 10 to 25°C (50 to 77°F)
  • Engine coolant temperature: 40°C (104°F) or less
  • Drive cycle status: Heating Refer to AIR CONDITIONER (DIAGNOSTICS) (HEV)>DATA MONITOR .
Electric expansion valve for cooling 20 - 38%
NOTE: Input 0% up to 100% is possible, but use the range of 20 to 38%.
 Electric expansion valve for cooling is set. Useful for reproduction check in faulty events.
  • READY ON
  • Fan dial: HI (MAX)
  • MAX A/C switch: ON
  • Ambient temperature: -10°C (14°F) or more
  • Drive cycle status: Cooling Refer to AIR CONDITIONER (DIAGNOSTICS) (HEV)>DATA MONITOR .
Electric compressor target revolution speed 1000 - 8600 rpm
NOTE:
  • Input up to 32767 rpm is possible, but 8600 to 32767 rpm are regarded as equivalent.
  • Input less than 1000 rpm is possible, but 1 to 1000 rpm are regarded as equivalent.
 Electric compressor target revolution speed is set. Useful for reproduction check in faulty events.
  • READY ON
  • Blower ON
  • A/C switch ON
  • Ambient temperature: 0°C (32°F) or more
