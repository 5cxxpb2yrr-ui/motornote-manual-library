Real-Time Diagnosis: Operation

  1. On [Start] display, select [Diagnosis].
  2. On [Select Vehicle] display, input the target vehicle information and select [OK].
  3. On [Main Menu] display, select [Each System].
  4. On [Select System] display, select [Engine], and then select [Next].
  5. On [Select Function] display, select [Data Monitor].
  6. Make sure that normal display is shown when operated as follows:
    • Depress and release the brake pedal. (Stop light switch and brake switch are turned ON.)
    • Turn the "CRUISE" switch to ON.
    • Turn the "CANCEL" switch to ON.
    • Turn the "SET/-" switch to ON.
    • Turn the "RES/+" switch to ON.
    • Depress or release the clutch switch.
    • Place the shift lever in any position other than neutral.
    NOTE: For detailed operation procedures, refer to "Help" of application.
