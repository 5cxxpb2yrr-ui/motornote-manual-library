TPMS Reminder Reset - Procedure 01: Notes

NOTE: If refilling tires to their standard values, the TPMS Warning Light will go out after driving above 20 mph for a few minutes.
NOTE: If tires are rotated, tire pressure sensor or TPM control module is replaced, or when wheels are changed (i.e., when snow tires are installed), the tire pressure sensor IDs must be registered.
NOTE: If tires were rotated, the performance and function of TPM system is not affected. However, correct tire positions will not displayed in the Subaru Select Monitor.
NOTE: In the following procedures, the Subaru Select Monitor and Transmitter Registration Tool (TPM-00012 or Kent-Moore Part No. FJ45295) must be used.
