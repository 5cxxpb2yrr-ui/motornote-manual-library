Converter Case: Installation

  1. Install the oil pump. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>OIL PUMP>INSTALLATION .
  2. Install the oil pump chain cover. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>OIL PUMP CHAIN>INSTALLATION .
  3. Install the front differential assembly. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>FRONT DIFFERENTIAL ASSEMBLY>INSTALLATION .
  4. Install the drive pinion shaft assembly. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>DRIVE PINION SHAFT ASSEMBLY>INSTALLATION .
  5. Install the forward clutch assembly. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>FORWARD CLUTCH ASSEMBLY>INSTALLATION .
  6. Install the reverse brake assembly. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>REVERSE BRAKE ASSEMBLY>INSTALLATION .
  7. Install the primary pulley, secondary pulley and variator chain. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>PRIMARY PULLEY AND SECONDARY PULLEY>INSTALLATION .
  8. Install the reduction drive gear. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>REDUCTION DRIVE GEAR>INSTALLATION .
  9. Install the transmission case. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSMISSION CASE>INSTALLATION .
  10. Install the transmission control device. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSMISSION CONTROL DEVICE>INSTALLATION .
  11. Install the oil strainer and oil pan. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>OIL PAN AND STRAINER>INSTALLATION .
  12. Install the reduction driven gear assembly. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>REDUCTION DRIVEN GEAR>INSTALLATION .
  13. Install the parking pawl. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>PARKING PAWL>INSTALLATION .
  14. Install the transfer driven gear assembly. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSFER DRIVEN GEAR>INSTALLATION .
  15. Install the transfer clutch assembly. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSFER CLUTCH>INSTALLATION .
  16. Install the extension case. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>EXTENSION CASE>INSTALLATION .
  17. Install the inhibitor switch. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>INHIBITOR SWITCH>INSTALLATION .
  18. Install the secondary speed sensor. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>SECONDARY SPEED SENSOR>INSTALLATION .
  19. Install the primary speed sensor. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>PRIMARY SPEED SENSOR>INSTALLATION .
  20. Install the turbine speed sensor. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TURBINE SPEED SENSOR>INSTALLATION .
  21. Install the transmission harness. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSMISSION HARNESS>INSTALLATION .
  22. Install the control valve body. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>CONTROL VALVE BODY>INSTALLATION .
  23. Install the air breather hose. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>AIR BREATHER HOSE>INSTALLATION .
  24. Install the transmission assembly to the vehicle. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>AUTOMATIC TRANSMISSION ASSEMBLY>INSTALLATION .
