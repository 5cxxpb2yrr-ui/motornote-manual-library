Inspection Mode AQ

WARNING: This page is about a different variant/trim than selected.
DTC Item Condition Number of driving cycles on the detecting condition
P0451 EVAP SYSTEM PRESSURE SENSOR/SWITCH CIRCUIT RANGE/PERFORMANCE - 2
NOTE: Perform the inspection mode after warming up the engine except that the engine coolant temperature at engine start is specified.
  1. Make sure that the battery voltage is 12 V or more.
  2. Using the Subaru Select Monitor, clear the memory of [Engine Control System]. Refer to COMMON (DIAG)>CLEAR MEMORY .
  3. Turn to READY OFF.
  4. Press the refueling request switch and leave the vehicle for one minute.
  5. Close the fuel lid.
  6. Turn to READY ON.
  7. Read the temporary code using the Subaru Select Monitor or general scan tool. Refer to COMMON (DIAG)>DIAGNOSTIC TROUBLE CODE (DTC) .
  8. Turn to READY OFF.
  9. Repeat 4 to 7 until the current malfunction code appears.
