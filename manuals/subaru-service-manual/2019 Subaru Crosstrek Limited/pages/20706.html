Basic Diagnostic Procedure: Procedure

Do you like it dark? Easier on the eyes.

  1. PERFORM CUSTOMER INTERVIEW. 

    Ask the customer when and how the trouble occurred using the interview check list. Refer to POWER WINDOW (DIAGNOSTICS)>CHECK LIST FOR INTERVIEW .

    Did you interview the customer?

    Yes:  Go to  2.

    No:  Perform the interview.

  2. BASIC INSPECTION. 

    Perform basic inspection. Refer to POWER WINDOW (DIAGNOSTICS)>GENERAL DESCRIPTION>INSPECTION .

    Is the check result OK?

    Yes:  Go to  3.

    No:  Repair the faulty part found in basic inspection, and Go to  3.

  3. CHECK SUBARU SELECT MONITOR COMMUNICATION. 
    1. Turn the ignition switch to OFF.
    2. Connect the Subaru Select Monitor to data link connector. Refer to COMMON (DIAG)>DATA LINK CONNECTOR .
    3. Turn the ignition switch to ON and run the Subaru Select Monitor.
    4. Select [Power Window (Switch)], [Power Window (Driver)] and [Power Window (Passenger)].
      NOTE: For detailed operation procedures, refer to "Help" of application.

      Is communication possible?

      Yes:  Go to  4.

      No:  Check the communication circuit. Refer to POWER WINDOW (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE FOR SUBARU SELECT MONITOR COMMUNICATION .

  4. CHECK DTC. 

    Using the Subaru Select Monitor, read the DTCs in [Power Window (Switch)], [Power Window (Driver)] and [Power Window (Passenger)]. Refer to POWER WINDOW (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    • Power Window (Switch)
    • Power Window (Driver)
    • Power Window (Passenger)

    Are any DTCs displayed? (Current malfunction)

    Yes:  Record the DTC, time stamp and freeze frame data, and Go to  5.

    No:  Perform diagnosis according to the procedures in the diagnostics with phenomenon.

    Refer to POWER WINDOW (DIAGNOSTICS)>DIAGNOSTICS WITH PHENOMENON .

  5. PERFORM DIAGNOSIS. 
    1. Perform the diagnosis for the displayed DTCs. Refer to POWER WINDOW (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .
    2. Repair or replace the cause of trouble.
    3. Using the Subaru Select Monitor, perform the clear memory of [Power Window (Switch)], [Power Window (Driver)] and [Power Window (Passenger)]. Refer to COMMON (DIAG)>CLEAR MEMORY .
      • Power Window (Switch)
      • Power Window (Driver)
      • Power Window (Passenger)
    4. Execute the inspection mode. Refer to POWER WINDOW (DIAGNOSTICS)>INSPECTION MODE .
    5. Using the Subaru Select Monitor, read the DTCs in [Power Window (Switch)], [Power Window (Driver)] and [Power Window (Passenger)]. Refer to POWER WINDOW (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
      • Power Window (Switch)
      • Power Window (Driver)
      • Power Window (Passenger)

      Are any DTCs displayed? (Current malfunction)

      Yes:  Repeat step  5 until DTC is not shown.

      No:  Finish the diagnosis.
