DTC B1655: Front Buckle Switch RH Failure

Do you like it dark? Easier on the eyes.

Diagnosis start condition: 

When the ignition voltage is 10 - 16 V.

DTC detecting condition: 

Buckle switch RH failure (open, short, unit failure), seat harness malfunction (open, short), occupant detection system failure

CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to OCCUPANT DETECTION (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK DTC. 

    Read the DTC of [Airbag] using the Subaru Select Monitor. Refer to AIRBAG (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC for [Airbag ECU Malfunction] displayed? (Current malfunction)

    Yes:  Perform the diagnosis for [Airbag ECU Malfunction]. Refer to AIRBAG (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC B1000 AIRBAG ECU MALFUNCTION .

    No:  Go to  2.

  2. CHECK DTC. 

    Read the DTC of [Occupant Detection] using the Subaru Select Monitor. Refer to OCCUPANT DETECTION (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC B1650 displayed? (Current malfunction)

    Yes:  Perform the diagnosis of DTC B1650. Refer to OCCUPANT DETECTION (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC B1650 OCCUPANT DETECTION SYSTEM MALFUNCTION .

    No:  Go to  3.

  3. CHECK DTC. 

    Read the DTC of [Occupant Detection] using the Subaru Select Monitor. Refer to OCCUPANT DETECTION (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC B1771 displayed? (Current malfunction)

    Yes:  Perform the diagnosis of DTC B1771. Refer to OCCUPANT DETECTION (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC B1771 BUCKLE SWITCH .

    No:  Replace the airbag control module. Refer to AIRBAG SYSTEM>AIRBAG CONTROL MODULE .
