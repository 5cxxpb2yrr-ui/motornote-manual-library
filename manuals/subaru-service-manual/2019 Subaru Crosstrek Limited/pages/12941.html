Warning Light Illumination Pattern: Inspection

  • Except for HEV model
    • When the ignition switch is turned to ON (engine OFF), the STEERING warning light illuminates.
    • After starting the engine, the STEERING warning light goes out. If it does not go off, a malfunction occurs in electric power steering combination meter.
  • HEV model
    • When the ignition switch is turned to ON (EV system OFF), the STEERING warning light illuminates.
    • After EV system start (READY signal is received), the STEERING warning light goes out. If it does not go off, a malfunction occurs in electric power steering combination meter.
