Diagnostic Method 1

Detect the malfunction by checking "Cumulative value of time when A changes from lean → rich" in comparison to "Time during which diagnosis is in progress".

Courtesy of SUBARU OF AMERICA, INC.

Judge as NG when the following conditions are established.

JUDGMENT VALUE SPECIFICATION

Malfunction Criteria Threshold Value DTC
(Cumulative value of time when λ changes from lean → rich)/(Time during which diagnosis is in progress) and
Average value of time necessary for A to inverse the air fuel ratio to Lean → Rich → Lean		 Less than 0.3
Exceeds 5 ms		 P014C
