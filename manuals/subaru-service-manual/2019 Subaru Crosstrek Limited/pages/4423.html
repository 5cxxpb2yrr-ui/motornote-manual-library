Outer Mirror Assembly: Assembly

CAUTION:
  • Be careful not to catch the harness in between the parts.
  • When installing the mirror - repair, insert the connector and clip securely.
  1. Install the light assembly - side turn mirror. (Model with side turn signal light)
  2. Install the Blind Spot Detection/Rear Cross Traffic Alert system indicator. (Model with Blind Spot Detection/Rear Cross Traffic Alert system)
  3. Install the cover - cap outer mirror.
  4. Install the cover - cap outer mirror lower.
  5. Check that all the claws are securely engaged.
  6. Install the mirror - repair in the reverse order of disassembly.
  7. For models with Blind Spot Detection/Rear Cross Traffic Alert system, perform operation check of Blind Spot Detection/Rear Cross Traffic Alert system indicator.
