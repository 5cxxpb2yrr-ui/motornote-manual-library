Pre-Collision Brake Off Indicator Light Does Not Go Off/Pre-Collision Brake Off Indicator Light Illuminates Automatically

  1. CHECK CONDITION OF OCCURRENCE. 

    Interview the customer to check if it occurs when the engine is started.

    Does it occur when starting the engine?

    Yes:  This is normal. (Light illumination for a while after the engine start is normal.)

    No:  Go to  2.

  2. CHECK FOR PRESENCE OF TEMPORARY STOP CODES. 

    Check for the presence of the temporary stop codes. Refer to EYESIGHT (DIAGNOSTICS) (EXCEPT FOR HEV)>EYESIGHT HALT CODE .

    Is a temporary stop code displayed?

    Yes:  Check EyeSight temporary stop code. Refer to EYESIGHT (DIAGNOSTICS) (EXCEPT FOR HEV)>EYESIGHT HALT CODE .

    No:  Go to  3.

  3. INSPECTION OF PRE-COLLISION BRAKE OFF SWITCH. 

    Check the pre-collision brake OFF switch. Refer to EYESIGHT (DIAGNOSTICS) (EXCEPT FOR HEV)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC B28B6 PRE-COLLISION OFF SWITCH .

    Is the check result OK?

    Yes:  Replace the stereo camera. Refer to EYESIGHT>STEREO CAMERA>REMOVAL .

    No:  Repair or replace the faulty portion according to the inspection result.
