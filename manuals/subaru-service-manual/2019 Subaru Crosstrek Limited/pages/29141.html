Circuit Explanation

WARNING: This page is about a different variant/trim than selected.

The Charge control ECU installed inside the Electric vehicle charger assembly uses a VAC sensor to monitor the input AC Voltage. It outputs a DTC code when a VAC sensor error is detected. If this DTC was output, perform a charging check suing an AC power supply that was confirmed to operate normally. If the trouble occurred again, replace the Electric vehicle charger assembly. For an explanation of the circuit, refer to DTC P0D3812.
