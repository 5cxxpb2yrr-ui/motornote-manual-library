Body Control System (Diagnostics): Customize: Operation

  1. On [Start] display, select [Diagnosis].
  2. On [Vehicle selection] display, input the target vehicle information and select [OK].
  3. On [Main Menu] display, select [Each System].
  4. On [Select System] display, select [Body Control], and then select [Enter].
  5. On [Select Function] display, select [Customize].
  6. When the setting is complete, make sure that the alterations by [Data monitor] are consistent with the actual equipment on the vehicle.
    NOTE:
    • For detailed operation procedures, refer to "Help" of application.
    • If not equipped (depending on destination area or vehicle equipment condition), process will not go on.
