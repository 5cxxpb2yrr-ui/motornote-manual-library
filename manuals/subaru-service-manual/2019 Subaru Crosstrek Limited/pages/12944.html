Steering Warning Light Does Not Go Off

Do you like it dark? Easier on the eyes.

Detecting condition: 

  • Defective combination meter
  • Open circuit of harness

Trouble symptom: 

  • Except for HEV model

    After starting the engine, the STEERING warning light continues to illuminate.

  • HEV model

    After READY ON, the STEERING warning light continues to illuminate.

  1. CHECK DTC. 

    Read the DTC of the power steering control module using the Subaru Select Monitor. Refer to POWER STEERING (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed?

    Perform the diagnosis according to DTC. Refer to POWER STEERING (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    Yes:  Go to  2.

  2. CHECK LAN SYSTEM. 

    Perform the diagnosis for LAN system using the Subaru Select Monitor. Refer to LAN SYSTEM (DIAGNOSTICS) (EXCEPT FOR HEV)>BASIC DIAGNOSTIC PROCEDURE . Refer to LAN SYSTEM (DIAGNOSTICS) (HEV)>BASIC DIAGNOSTIC PROCEDURE .

    Is DTC of CAN communication displayed?

    Perform the diagnosis according to DTC. Refer to LAN SYSTEM (DIAGNOSTICS) (EXCEPT FOR HEV)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST . Refer to LAN SYSTEM (DIAGNOSTICS) (HEV)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Go to  3.

  3. CHECK COMBINATION METER. 

    Check the combination meter. Refer to INSTRUMENTATION/DRIVER INFO>COMBINATION METER SYSTEM>OPERATION>SELF-DIAGNOSIS DISPLAY MODE .

    Is the check result OK?

    Yes:  Replace the steering gearbox. Refer to POWER ASSISTED SYSTEM (POWER STEERING)>ELECTRIC POWER STEERING GEARBOX .

    No:  Replace the combination meter. Refer to INSTRUMENTATION/DRIVER INFO>COMBINATION METER .
