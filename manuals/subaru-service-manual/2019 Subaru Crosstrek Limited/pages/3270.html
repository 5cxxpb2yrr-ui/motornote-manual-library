The Device Cannot Be Registered To Wifi Hotspot

Probable cause: 

DCM malfunction, navigation unit malfunction, WiFi device malfunction

CAUTION:
  • After the DCM is replaced, registrations of CommCheck and immobilizer system are required. Refer to ENTERTAINMENT & MONITORING>TELEMATICS SYSTEM>OPERATION>REGISTRATION (COMM CHECK) .
  • Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to TELEMATICS SYSTEM (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK THE WIFI DEVICE. 

    Check that a properly operating WiFi device can be connected.

    Can the WiFi device be registered?

    Yes:  No abnormality on the vehicle. The WiFi device which could not be connected was faulty.

    No:  Go to  2.

  2. CHECK THE WIFI SETTING. 

    Check the WiFi HotSpot setting of DCM by operating the navigation.

    Is the WiFi HotSpot setting ON?

    Yes:  Go to  3.

    No:  Set the WiFi HotSpot setting to ON.

  3. CHECK THE WIFI DEVICE SETTING (SSID). 

    Check whether the WiFi device access point is the same access point name as SSID displayed on the navigation display.

    Is it the same access point name?

    Yes:  Go to  4.

    No:  No abnormality on the vehicle. The access point is not the same.

  4. CHECK THE WIFI DEVICE SETTING (PASSWORD). 

    Check the password that is input in the WiFi device.

    Is the password correct?

    Yes:  Go to  5.

    No:  Input the correct password in the WiFi device to re-register.

  5. CHECK THE WIFI DEVICE SETTING (FREQUENCY BAND). 

    Check the frequency band of the WiFi device and the vehicle side.

    Is the frequency band correct?

    Yes:  Go to  6.

    No:  Set the frequency band again.

  6. CHECK DTCS. 

    Read the following DTCs using Subaru Select Monitor.

    • Telematics Refer to TELEMATICS SYSTEM (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
    • Infotainment Refer to INFOTAINMENT (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed?

    Yes:  Perform the diagnosis for the displayed DTCs. Refer to TELEMATICS SYSTEM (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST . Refer to INFOTAINMENT (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Go to  7.

  7. CHECK CONNECTED DEVICES (DATA MONITOR). 

    Using the Subaru Select Monitor, check the following items in the [Data monitor] of [Telematics]. Refer to TELEMATICS SYSTEM (DIAGNOSTICS)>DATA MONITOR .

    • WiFi (Device1): Device Name
    • WiFi (Device2): Device Name
    • WiFi (Device3): Device Name
    • WiFi (Device4): Device Name
    • WiFi (Device5): Device Name
    • WiFi (Device6): Device Name
    • WiFi (Device7): Device Name
    • WiFi (Device8): Device Name

    Do all items display a connected device name?

    Yes:  No abnormality on the vehicle. Connection was not able to be established because eight devices were connected.

    No:  Replace the DCM. Refer to ENTERTAINMENT & MONITORING>DATA COMMUNICATION MODULE .
