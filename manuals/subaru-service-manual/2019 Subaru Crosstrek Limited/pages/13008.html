Stabilizer Bushing

  1. Before installation, inspect the following items and replace any faulty part with a new one. Check the stabilizer bushing for abnormal cracks, fatigue or damage.
  2. Install the bushing - stabilizer.
  3. Install the clamp - stabilizer bushing.

    Tightening torque: 

    25 N.m (2.5 kgf-m, 18.4 ft-lb)

  4. Install the front exhaust pipe.

    Refer to EXHAUST (H4DO (EXCEPT FOR HEV))>FRONT EXHAUST PIPE>INSTALLATION .

  5. Install the crossmember support - rear.

    Tightening torque: 

    70 N.m (7.1 kgf-m, 51.6 ft-lb)

  6. Install the under cover - front.

    Tightening torque: 

    18 N.m (1.8 kgf-m, 13.3 ft-lb)
