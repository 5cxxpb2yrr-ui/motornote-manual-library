Transmission Rear Crossmember And Rear Cushion Rubber

WARNING: This page is about a different variant/trim than selected.
  1. Install the rear cushion rubber.

    Tightening torque: 

    40 N.m (4.1 kgf-m, 29.5 ft-lb)

  2. Install the transmission rear crossmember.

    Tightening torque: 

    T1: 35 N.m (3.6 kgf-m, 25.8 ft-lb)

    T2: 70 N.m (7.1 kgf-m, 51.6 ft-lb)

    Courtesy of SUBARU OF AMERICA, INC.
  3. Install the clip which holds the inhibitor harness to the transmission rear crossmember.
    Courtesy of SUBARU OF AMERICA, INC.
  4. Remove the transmission jack.
  5. Install the center exhaust cover.

    Tightening torque: 

    18 N.m (1.8 kgf-m, 13.3 ft-lb)

  6. Install the front exhaust pipe.

    Refer to EXHAUST (H4DO (EXCEPT FOR HEV))>FRONT EXHAUST PIPE>INSTALLATION .

  7. Connect the battery ground terminal.

    Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
