Solenoid Unit

  1. Clean all the parts before assembly.
  2. Insert the solenoid unit terminals to the harness connector.
    Courtesy of SUBARU OF AMERICA, INC.
  3. Install the solenoid unit.
  4. Install the harness connector to the plate COMPL.
  5. Install the spacer plate and the gasket. Refer to CONTROL SYSTEMS>SELECT LEVER>ASSEMBLY .
  6. Install the select lever. Refer to CONTROL SYSTEMS>SELECT LEVER>INSTALLATION .
