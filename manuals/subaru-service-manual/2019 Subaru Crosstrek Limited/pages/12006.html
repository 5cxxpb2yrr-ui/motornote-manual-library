Maintenance Reminder Display Reset - Procedure 01

Do you like it dark? Easier on the eyes.

To reset the Maintenance Reminders in the multi-function display see the procedure below. The resettable maintenance items are:

  • Engine Oil
  • Oil Filter
  • Tires
  • Maintenance Schedule
  1. Turn the ignition switch to the ON position.
  2. Pull and hold the steering wheel SET switch toward you to show the SETTING screen. See Fig 1 and Fig 3 .
    NOTE: On models with multi-function display controls on the center console, pushing the ENTER button replaces references to the SET switch. See Fig 2.
  3. After the SETTING screen is displayed, operate the ARROW buttons to highlight the MAINTENANCE item. Then, pull the SET switch toward you.
  4. Operate the ARROW buttons to highlight the maintenance item you wish to reset. Then, pull the SET switch toward you.
  5. Operate the ARROW buttons to highlight either category: DATE or DISTANCE. Then, pull the SET switch toward you.
  6. Operate the ARROW buttons to enter a date or distance. Then, pull the SET switch toward you.
    NOTE: If you wish to set the other category, operate the ARROW buttons to highlight that category, pull the SET switch toward you, and proceed as before.
  7. Highlight "Set" by operating the ARROW buttons, and confirm the setting by pulling the SET switch toward you.
  8. The system will notify you that the setting is complete.
