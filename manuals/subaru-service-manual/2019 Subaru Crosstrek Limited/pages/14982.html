Pre-Delivery Inspection (PDI) Procedure: Accessory

Check that the following accessories are provided.

  • Owner's manual
  • Warranty booklet
  • Maintenance note
  • Spare key
  • Key No. plate
  • Jack
  • Jack handle
  • Tool set
  • Charge cable
  • Spare tire or puncture repair kit
  • Towing hook (eyebolt)
