Differential Case Assembly

  1. Install the differential bevel gear and differential bevel pinion together with washer, and install the pinion shaft.
    NOTE: Apply differential gear oil on the sliding portion of the differential bevel gear, thrust washer and pinion shaft.
    Courtesy of SUBARU OF AMERICA, INC.
  2. Measure the backlash, and select the washer.
    1. Install the SUBARU genuine axle shaft to differential case.

      Part No. 38415AA070 AXLE SHAFT 

    2. Using ST1 and ST2, insert the ST2 through the window of differential case. Measure the backlash of the gear.
      NOTE:
      • Measure the backlash by applying a differential bevel pinion tooth between two differential bevel gear teeth.
      • When measuring, fix the differential bevel pinion in place with a screwdriver covered with cloth, or a similar tool.

      Preparation tool: 

      ST1: MAGNET BASE (498247001)

      ST2: DIAL GAUGE (498247100)

      Specification: 

      0.13 - 0.18 mm (0.0051 - 0.0071 in)

      Courtesy of SUBARU OF AMERICA, INC.
    3. If the backlash is not within specification, select a washer from the table below and replace.
    Washer
    Part No. Thickness mm (in)
    803038021 0.95 (0.037)
    803038022 1.00 (0.039)
    803038023 1.05 (0.041)
  3. Align the pinion shaft and differential case holes, and install the spring pin to the holes from the hypoid driven gear side using the ST.
    NOTE: Use new spring pin.

    Preparation tool: 

    ST: STRAIGHT PIN REMOVER (899904100)

    Courtesy of SUBARU OF AMERICA, INC.
  4. Using the ST1 and ST2, install the left and right taper roller bearings.

    Preparation tool: 

    ST1: BUSHING 1-2 INSTALLER (499277100)

    ST2: SEAT (398497701)

    Courtesy of SUBARU OF AMERICA, INC.
