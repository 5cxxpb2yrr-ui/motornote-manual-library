Power Steering Assist Enabled

Do you like it dark? Easier on the eyes.

Detecting condition: 

  • Defective combination meter
  • Defective harness

Trouble symptom: 

  • Except for HEV model

    When the ignition switch is turned to ON (engine OFF), the STEERING warning light does not illuminate.

  • HEV model

When the ignition switch is turned to ON (EV system OFF), the STEERING warning light does not illuminate.

NOTE:
  • Except for HEV model It is operating normally if the warning light illuminates when the ignition switch is turned to ON (engine OFF), and turns off approximately two seconds after engine start.
  • HEV model It is operating normally if the warning light illuminates when the ignition switch is turned to ON (EV system OFF), and turns off approximately two seconds after READY ON.
  1. CHECK ILLUMINATION OF OTHER LIGHTS. 
    • Turn the ignition switch to ON. (Engine OFF) (except for HEV model)
    • Turn the ignition switch to ON. (EV system OFF) (HEV model)

    Do other warning lights illuminate?

    Yes:  Go to  2.

    No:  Check the combination meter. Refer to INSTRUMENTATION/DRIVER INFO>COMBINATION METER SYSTEM>INSPECTION .

  2. CHECK LAN SYSTEM. 

    Perform the diagnosis for LAN system using the Subaru Select Monitor. Refer to LAN SYSTEM (DIAGNOSTICS) (EXCEPT FOR HEV)>BASIC DIAGNOSTIC PROCEDURE . Refer to LAN SYSTEM (DIAGNOSTICS) (HEV)>BASIC DIAGNOSTIC PROCEDURE .

    Is DTC of CAN communication displayed?

    Perform the diagnosis according to DTC. Refer to LAN SYSTEM (DIAGNOSTICS) (EXCEPT FOR HEV)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST . Refer to LAN SYSTEM (DIAGNOSTICS) (HEV)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Go to  3.

  3. CHECK COMBINATION METER. 

    Check the combination meter. Refer to INSTRUMENTATION/DRIVER INFO>COMBINATION METER SYSTEM>OPERATION>SELF-DIAGNOSIS DISPLAY MODE .

    Is the check result OK?

    Yes:  Current condition is normal.

    No:  Replace the combination meter. Refer to INSTRUMENTATION/DRIVER INFO>COMBINATION METER .
