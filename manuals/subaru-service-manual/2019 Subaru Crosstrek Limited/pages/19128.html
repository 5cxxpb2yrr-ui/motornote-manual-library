Cooler Valve

Do you like it dark? Easier on the eyes.

WARNING: This page is about a different variant/trim than selected.
CAUTION: Check that the DTC B1453 (cooling expansion valve circuit) is not displayed.
  1. Visually check that there is no dirt or damage on the expansion valve - cooler assembly. Clean or replace as necessary.
  2. Attach the manifold gauge set. Refer to AIR CONDITIONER (HEV)>REFRIGERANT PRESSURE WITH MANIFOLD GAUGE SET>PROCEDURE .

    Preparation tool: 

    Manifold gauge set

  3. Using the Subaru Select Monitor, select [Cooling electric expansion valve] under [Air Conditioner] in the active test list. Refer to AIR CONDITIONER (DIAGNOSTICS) (HEV)>ACTIVE TEST .
  4. Set the vehicle to the following conditions.
    Item Condition
    READY ON
    MAX A/C switch ON
    Fan dial HI (MAX)
    Ambient temperature -10°C (14°F) or more
    Driving cycle status (Confirm on Data Monitor.) Cooling
  5. Manipulate the active test input value, and check whether the manifold gauge value changes.
    NOTE: Check with active test input values in the range of 20 - 38%.
  6. If the check results show that the value does not change, replace the expansion valve - cooler assembly.
