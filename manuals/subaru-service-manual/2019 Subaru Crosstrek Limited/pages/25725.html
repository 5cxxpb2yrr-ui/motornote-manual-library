Inspection Mode 31

WARNING: This page is about a different variant/trim than selected.
Code Note Number of driving cycles on the detecting condition
P0A9300 - 1

Diagnostic procedure:

  1. Using the Subaru Select Monitor, perform the clear memory of [P-HEV Hybrid Powertrain Control]. Refer to COMMON (DIAG)>CLEAR MEMORY .
  2. Turn to IG OFF, and wait for two minutes or more.
  3. Using the Subaru Select Monitor, read the DTC of [P-HEV Hybrid Powertrain Control] to check that there is no DTC displayed. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
    NOTE: If the DTC is displayed on the screen, the trouble is still present. Perform the diagnosis for the displayed DTCs. After solving the DTC, repeat from step  1.
  4. Turn to IG ON, and wait for five seconds or more.
  5. Turn to READY ON, and wait for 5 seconds or more.
  6. Drive the vehicle approximately 15 minutes while referring to [Vehicle Speed] of the freeze frame data.

    During driving, use the Subaru Select Monitor to display the following items in the [Data monitor] of [P-HEV Hybrid Powertrain Control], and pay attention to a temperature increase. Refer to PHEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DATA MONITOR .

    • Inverter Coolant Water Temperature
    • Motor Inverter Temperature
    • Generator Inverter Calculated Temperature
    • Boosting Converter Temperature (Upper)
    • Boosting Converter Temperature (Lower)
    NOTE: HV battery capacity may be decreased due to the evacuation drive after the malfunction occurrence. By turning to READY ON after repairing, the HV system charges HV battery automatically approximately five to 10 minutes; therefore, the battery will recover by itself.
  7. Read the [Readiness code] of [P-HEV Hybrid Powertrain Control] using Subaru Select Monitor and check that the concerned self-diagnosis is completed. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>ALL READINESS DIAGNOSTIC CODE(S) .
    NOTE: If the concerned DTC is displayed, the self-diagnosis of the DTC is not complete. Repeat from step  4.
  8. Using the Subaru Select Monitor, read the DTC of [P-HEV Hybrid Powertrain Control] to check that there is no DTC displayed. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
NOTE: If the DTC is displayed on the screen, the trouble is still present. Perform the diagnosis for the displayed DTCs.
