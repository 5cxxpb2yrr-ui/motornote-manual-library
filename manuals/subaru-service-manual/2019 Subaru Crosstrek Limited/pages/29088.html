Vehicle Control History Data (HV)

WARNING: This page is about a different variant/trim than selected.

When the vehicle control history is erased, all stored history items are deleted.

  1. On [Start] screen, select [Diagnosis].
  2. On [Vehicle selection] screen, enter vehicle information and select [OK].
  3. On [Main Menu] screen, select [Each System].
  4. On [Select System] screen, select [P-HEV Hybrid Powertrain Control].
  5. On [Select Function] screen, select [Work Support].
  6. On [Work Support] screen, select [Vehicle Ctl. Hist.].
  7. Select the vehicle control history item name, and display the freeze frame data from the time when control occurred.
  8. Check the output data. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>WORK SUPPORT .
