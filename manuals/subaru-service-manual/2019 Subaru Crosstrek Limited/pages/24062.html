Basic Diagnostic Procedure: Procedure

Do you like it dark? Easier on the eyes.

  1. PERFORM CUSTOMER INTERVIEW. 

    Ask the customer when and how the trouble occurred using the interview check list.

    Did you interview the customer?

    Yes:  Go to  2.

    No:  Perform the interview, and Go to  2.

  2. PERFORM BASIC INSPECTION. 

    Perform basic inspection. Ref. to PEDESTRIAN ALERT (DIAGNOSTICS)>GENERAL DESCRIPTION>INSPECTION .

    Is the check result OK?

    Yes:  Go to  3.

    No:  Repair the faulty part found in basic inspection, and Go to  3.

  3. CHECK SUBARU SELECT MONITOR COMMUNICATION. 
    1. Turn the ignition switch to OFF.
    2. Connect the Subaru Select Monitor to data link connector. Ref. to COMMON (DIAG)>DATA LINK CONNECTOR .
    3. Turn the ignition switch to ON and run the Subaru Select Monitor.
    4. Select [Pedestrian Alert].
      NOTE: For detailed operation procedures, refer to "Help" of application.

      Is communication possible?

      Yes:  Go to  4.

      No:  Check the communication circuit. Ref. to PEDESTRIAN ALERT (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE FOR SUBARU SELECT MONITOR COMMUNICATION .

  4. CHECK DTC. 

    Read the DTC of [Pedestrian Alert] using the Subaru Select Monitor. Ref. to PEDESTRIAN ALERT (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed? (Current malfunction)

    Yes:  Record the DTC, time stamp and freeze frame data, and go to next. Go to  5.

    No:  Perform diagnosis according to the procedures in the diagnostics with phenomenon. Ref. to PEDESTRIAN ALERT (DIAGNOSTICS)>DIAGNOSTICS WITH PHENOMENON .

  5. PERFORM DIAGNOSIS. 
    1. Perform the diagnosis for the displayed DTCs. Ref. to PEDESTRIAN ALERT (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .
    2. Repair or replace the cause of trouble.
    3. Using the Subaru Select Monitor, perform the clear memory of [Pedestrian Alert]. Ref. to COMMON (DIAG)>CLEAR MEMORY .
    4. Read the DTC of [Pedestrian Alert] using the Subaru Select Monitor. Ref. to PEDESTRIAN ALERT (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

      Are any DTCs displayed? (Current malfunction)

      Yes:  Repeat step  5 until DTC is not shown.

      No:  Finish the diagnosis.
