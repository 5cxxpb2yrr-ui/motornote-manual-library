Oil Pan Upper

  1. Install the clutch housing cover. (MT model and hybrid model)

    Tightening torque: 

    MT model 

    5 N.m (0.5 kgf-m, 3.7 ft-lb)

    Hybrid model 

    5.6 N.m (0.6 kgf-m, 4.1 ft-lb)

  2. Install the stud bolt.

    Tightening torque: 

    10 N.m (1.0 kgf-m, 7.4 ft-lb)

  3. Install the baffle plate.

    Tightening torque: 

    6.4 N.m (0.7 kgf-m, 4.7 ft-lb)
