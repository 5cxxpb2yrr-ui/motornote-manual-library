Telematics Sub Antenna

  1. Install the telematics sub antenna.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

    NOTE: Install the telematics sub antenna by using the sting left inside the parts to pull the part into the instrument panel.
  2. Install the GPS antenna assembly.
  3. Install the combination meter assembly.
  4. Install the cover assembly - instrument panel LWR driver.
  5. Install the audio assembly or navigation assembly.
  6. Install the grille assembly - CTR ventilation.
  7. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
