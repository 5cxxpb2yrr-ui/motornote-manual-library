Trunk Will Not Open With Keyless Access

Trouble causes: 

  • Malfunction of door lock control system
  • Malfunction of harness between the body integrated unit and trunk lid lock actuator
  • Trunk lid lock actuator malfunction
  • Body integrated unit malfunction
  • Access key malfunction
  • Malfunction of harness between trunk opener button and keyless access control module
  • Trunk opener button malfunction
  • Keyless access control module malfunction
  • Malfunction of harness between exterior rear antenna and keyless access control module
  • Exterior rear antenna malfunction
CAUTION:
  • Check that there are no other registered access keys inside the trunk.
  • Inspect LAN system according to the basic diagnostic procedure, and make sure that there is no fault.
  • Check that the keyless access function is not stopped.
  • When the access key or keyless access control module is replaced, registration of the immobilizer is required. For the relevant procedures, refer to the "REGISTRATION INSTRUCTIONS FOR IMMOBILIZER" provided as a separate volume.
  • Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK TRUNK OPENER BUTTON. 

    Check that the trunk opens with the driver's seat trunk opener button.

    Does it open normally?

    Yes:  Go to  2.

    No:  Check the door lock circuit. Refer to SECURITY AND LOCKS>Door Lock Control System>INSPECTION>SYMPTOM CHART .

  2. CHECK KEYLESS OPERATION. 

    Check that the trunk opens when the trunk opener button of the access key is operated.

    Does it open normally?

    Yes:  Go to  7.

    No:  Go to  3.

  3. CHECK TRUNK UNLOCK OPERATION. 
    1. Using the Subaru Select Monitor, check the following items of [Active Test] of [Body Control]. Refer to BODY CONTROL (DIAGNOSTICS)>ACTIVE TEST .
      • R gate/trunk UNLK output
    2. Check that the trunk opens when the R gate/trunk UNLK signal is output.

    Does it open normally?

    Yes:  Go to  7.

    No:  Go to  4.

  4. CHECK HARNESS (OPEN CIRCUIT). 
    1. Disconnect the body integrated unit connector and trunk lid lock actuator connector.
    2. Check the continuity between body integrated unit connector and trunk lid lock actuator connector.

      Connector & terminal 

      (i266) No. 7 - (R186) No. 1:

    Is there continuity?

    Yes:  Go to  5.

    No:  Repair or replace the open circuit of harness.

  5. CHECK WIRING HARNESS. 

    Check the continuity between the trunk lid lock actuator connector and chassis ground.

    Connector & terminal 

    (R186) No. 2 - Chassis ground:

    Is there continuity?

    Yes:  Go to  6.

    No:  Repair or replace the open circuit of harness.

  6. CHECK TRUNK LID LOCK ACTUATOR. 

    Check the trunk lid lock actuator. Refer to SECURITY AND LOCKS>TRUNK LID LATCH AND ACTUATOR ASSEMBLY .

    Is trunk lid actuator normal?

    Yes:  Replace the body integrated unit. Refer to SECURITY AND LOCKS>BODY INTEGRATED UNIT .

    No:  Replace the trunk lid latch & actuator assembly. Refer to SECURITY AND LOCKS>TRUNK LID LATCH AND ACTUATOR ASSEMBLY .

  7. CHECK ACCESS KEY. 

    Check the access key LED when the trunk opener button of the access key is operated.

    Does the access key LED illuminate?

    Yes:  Go to  8.

    No:  Replace the access key. Refer to SECURITY AND LOCKS>ACCESS KEY>REPLACEMENT .

  8. CHECK ACCESS KEY. 
    1. Prepare all access keys registered to the vehicle.
    2. Check that the trunk opens with each access key.

    Does it open normally?

    Yes:  Go to  9.

    No:  Replace the access key. Refer to SECURITY AND LOCKS>ACCESS KEY>REPLACEMENT .

  9. CHECK DATA MONITOR. 
    1. Using the Subaru Select Monitor, check the following items in the [Data Monitor] of [Keyless Access with Push Button Start]. Refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS)>DATA MONITOR .
      • Trunk Request SW
    2. Read the data when pressing the trunk opener button.

    Does the data display ON?

    Yes:  Go to  13.

    No:  Go to  10.

  10. CHECK HARNESS (OPEN CIRCUIT). 
    1. Disconnect the trunk opener button connector and the keyless access control module connector.
    2. Using a tester, check continuity between the trunk opener button connector and keyless access control module connector.

      Connector & terminal 

      (R294) No. 1 - (i75) No. 17:

    Is there continuity?

    Yes:  Go to  11.

    No:  Repair or replace the open circuit of harness.

  11. CHECK HARNESS (OPEN CIRCUIT). 
    1. Using a tester, check the continuity between the trunk opener button connector and chassis ground.

      Connector & terminal 

      (R294) No. 2 - Chassis ground:

    Is there continuity?

    Yes:  Go to  12.

    No:  Repair or replace the open circuit of harness.

  12. CHECK TRUNK OPENER BUTTON. 

    Using a tester, check the continuity between trunk opener button connector terminals.

    Terminal 

    No. 1 - No. 2:

    Is there continuity when pressing the switch?

    Yes:  Go to  13.

    No:  Replace the trunk opener button.

  13. CHECK HARNESS (OPEN CIRCUIT). 
    1. Disconnect the exterior rear antenna connector and the keyless access control module connector.
    2. Using a tester, check continuity between the exterior rear antenna connector and keyless access control module connector.

      Connector & terminal 

      (R299) No. 1 - (i241) No. 8:

      (R299) No. 2 - (i241) No. 7:

    Is there continuity?

    Yes:  Go to  14.

    No:  Repair or replace the open circuit of harness.

  14. CHECK OUTSIDE REAR ANTENNA. 

    Replace the outside rear antenna with new or properly working parts.

    Does it operate properly?

    Yes:  Replace the outside rear antenna. Refer to SECURITY AND LOCKS>KEYLESS ACCESS OUTDOOR ANTENNA>REMOVAL .

    No:  Go to  15.

  15. CHECK KEYLESS ACCESS SYSTEM CHECK. 
    1. Using the Subaru Select Monitor, check the following items in the [Keyless Access with Push Button Start Check] of [Keyless Access with Push Button Start]. Refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS)>KEYLESS ACCESS WITH PUSH BUTTON START CHECK .
      • Out of trunk transmitter + room tuner

    Does the outside buzzer sound?

    Yes:  The circuit has returned to a normal condition at this time. Reproduce the failure, and then perform the diagnosis again.

    NOTE: In this case, temporary poor contact of connector, temporary open or short circuit of harness may be the cause.

    No:  Replace the keyless access control module. Refer to SECURITY AND LOCKS>KEYLESS ACCESS control module .
