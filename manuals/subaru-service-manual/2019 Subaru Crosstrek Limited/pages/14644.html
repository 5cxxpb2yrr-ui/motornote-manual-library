Freeze Frame Data: Operation

  1. On [Start] display, select [Diagnosis].
  2. On [Vehicle selection] display, input the target vehicle information and select [OK].
  3. On [Main Menu] display, select [Each System].
  4. On [Select System] display, select the corresponding system and select [Next].
  5. On [Select Function] display, select [DTC].
  6. On [DTC] display, select [FFD].
    NOTE:
    • For detailed operation procedures, refer to "Help" of application.
    • Sub screen may appear in the system selection display. In that case, select appropriate items in accordance with the contents of the display.
    • Freeze frame data is cleared by clearing memory.
