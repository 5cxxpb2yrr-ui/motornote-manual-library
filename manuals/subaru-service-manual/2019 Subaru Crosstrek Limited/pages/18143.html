Front Exhaust Pipe: Assembly

  1. Install each exhaust cover.

    Tightening torque: 

    13 N.m (1.3 kgf-m, 9.6 ft-lb)

  2. Install the front oxygen (A/F) sensor and rear oxygen sensor.

    Except for hybrid model: 

    Front oxygen (A/F) sensor 

    Refer to FUEL INJECTION (FUEL SYSTEMS) (H4DO (EXCEPT FOR HEV))>FRONT OXYGEN (A/F) SENSOR>INSTALLATION .

    Rear oxygen sensor 

    Refer to FUEL INJECTION (FUEL SYSTEMS) (H4DO (EXCEPT FOR HEV))>REAR OXYGEN SENSOR>INSTALLATION .

    Hybrid model: 

    Front oxygen (A/F) sensor 

    Refer to FUEL INJECTION (FUEL SYSTEMS) (H4DO (HEV))>FRONT OXYGEN (A/F) SENSOR>INSTALLATION .

    Rear oxygen sensor 

    Refer to FUEL INJECTION (FUEL SYSTEMS) (H4DO (HEV))>REAR OXYGEN SENSOR>INSTALLATION .
