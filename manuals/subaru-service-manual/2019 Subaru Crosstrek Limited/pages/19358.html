Basic Diagnostic Procedure: Procedure

WARNING: This page is about a different variant/trim than selected.
  1. PERFORM CUSTOMER INTERVIEW  .

    Ask the customer when and how the trouble occurred using the interview check list. Refer PHEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>CHECK LIST FOR INTERVIEW>CHECK .

    Did you interview the customer?

    Yes:  Go to  2.

    No:  Perform the interview.

  2. CHECK SUBARU SELECT MONITOR COMMUNICATION  .
    1. Turn the ignition switch to OFF.
    2. Connect the Subaru Select Monitor to data link connector.
    3. Turn the ignition switch to ON and run the Subaru Select Monitor.
    4. Select [P-HEV Hybrid Powertrain Control].
    NOTE: For detailed operation procedures, refer to "Help" of application.

    Is communication possible?

    Yes:  Go to  3.

    No:  Check the communication circuit. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE FOR SUBARU SELECT MONITOR COMMUNICATION>INSPECTION .

  3. CHECK DTC  .

    Read the DTC of [P-HEV Hybrid Powertrain Control] using the Subaru Select Monitor. Refer to PHEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed?

    Yes:  Record the DTC, time stamp and freeze frame data, and Go to  4.

    No:  Perform appropriate inspection using Diagnostics with Phenomenon. Refer to PHEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DIAGNOSTICS WITH PHENOMENON>LIST .

  4. PERFORM DIAGNOSIS  .
    1. Perform the diagnosis for the displayed DTCs.
      NOTE: When a DTC indicating a malfunction in the CAN communication system is displayed, perform diagnosis for CAN communication first.
    2. Repair or replace the cause of trouble.
    3. Using the Subaru Select Monitor, perform the clear memory of [P-HEV Hybrid Powertrain Control]. Refer to COMMON (DIAG)>CLEAR MEMORY .
    4. Execute the inspection mode. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>INSPECTION MODE .
    5. Using the Subaru Select Monitor, display [Readiness code] of [P-HEV Hybrid Powertrain Control] and check that self-diagnosis of the DTC is completed. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>ALL READINESS DIAGNOSTIC CODE(S) .
    6. Read the DTC of [P-HEV Hybrid Powertrain Control] using the Subaru Select Monitor. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed?

    Yes:  Repeat step  4 until DTC is not shown.

    No:  Finish the diagnosis.
