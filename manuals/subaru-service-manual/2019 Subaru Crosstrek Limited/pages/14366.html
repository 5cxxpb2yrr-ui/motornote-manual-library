DTC P0D38-12: Hybrid/EV Battery Charger Input Current Sensor Circuit Short To Auxiliary Battery: Notes

WARNING: This page is about a different variant/trim than selected.

Outline of diagnosis: 

IAC sensor output voltage exceeded the threshold value.

(1 trip detection logic)

Trouble symptom: 

Plug-in charging suspended

NOTE: For the diagnostic procedure, refer to DTC P0D2A19. Refer to PLUG-IN BATTERY CHARGER (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC P0D2A19 HYBRID/EV BATTERY CHARGER INPUT CURRENT SENSOR CIRCUIT CURRENT ABOVE THRESHOLD .
