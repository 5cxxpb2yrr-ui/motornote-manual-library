Crank Pulley: Installation

Do you like it dark? Easier on the eyes.

  1. Clean the crankshaft thread using compressed air.
  2. Apply engine oil to the crank pulley bolt seat and thread.
  3. Install the crank pulley.
    1. Install new O-ring to the crank pulley boss.
    2. Set the crank pulley to the crank pulley boss.
      NOTE: Install the crank pulley by aligning the flat sides (A) of the crank pulley and the flat sides (B) of the crank pulley boss.
      Courtesy of SUBARU OF AMERICA, INC.
    3. Use the ST1 and ST2 to lock the crank pulley, and temporarily tighten the crank pulley bolt.
      NOTE: To prevent damaging ST1, attach the ST2 onto the ST1 as shown in the figure below.
      Courtesy of SUBARU OF AMERICA, INC.

      Preparation tool: 

      ST1: PULLEY WRENCH (18355AA000)

      ST2: PULLEY WRENCH PIN SET (18334AA000)

      Tightening torque: 

      Except for hybrid model

      80 N.m (8.2 kgf-m, 59.0 ft-lb)

      Hybrid model 

      95 N.m (9.7 kgf-m, 70.1 ft-lb)

      Courtesy of SUBARU OF AMERICA, INC.
    4. Draw reference lines (A) and (B) using a marker to set the socket to the crank pulley bolt as shown in the figure.
      Courtesy of SUBARU OF AMERICA, INC.
    5. Draw reference lines (A) and (B) on the crank pulley bolt using a marker as shown in the figure.
      Courtesy of SUBARU OF AMERICA, INC.
    6. Draw end line (C) on crank pulley using a marker at the same position as reference line (B) drawn on the crank pulley bolt in step (5).
      Courtesy of SUBARU OF AMERICA, INC.
    7. Use the ST1 and ST2 to lock the crank pulley, and tighten the crank pulley bolt until the reference line (A) and end line (C) are aligned.
      NOTE: It should be approx. 60° when reference line (A) and end line (C) are aligned.

      Preparation tool: 

      ST1: PULLEY WRENCH (18355AA000)

      ST2: PULLEY WRENCH PIN SET (18334AA000) 

      Tightening angle: 

      60°±5°

    Courtesy of SUBARU OF AMERICA, INC.
  4. Install the V-belts.

    Except for hybrid model: 

    Refer to MECHANICAL (H4DO (EXCEPT FOR HEV))>V-BELT>INSTALLATION>EXCEPT FOR HYBRID MODEL>V-BELT .

    Hybrid model: 

    Refer to MECHANICAL (H4DO (EXCEPT FOR HEV))>V-BELT>INSTALLATION>HYBRID MODEL>V-BELT .

  5. When working on the vehicle
    NOTE: When working on the vehicle, perform the following steps also.
    1. Install the bolts securing the lower side of the radiator upper frame.
      NOTE: This procedure is performed only when the component is removed for installation/removal of the crank pulley bolt.

      Tightening torque: 

      18 N.m (1.8 kgf-m, 13.3 ft-lb)

      Courtesy of SUBARU OF AMERICA, INC.
    2. Install the front under cover. (Except for hybrid model) Refer to EXTERIOR/INTERIOR TRIM>FRONT UNDER COVER>INSTALLATION .
      NOTE: This procedure is performed only when the component is removed for installation/removal of the crank pulley bolt.
    3. Install the A/C accumulator assembly. (Hybrid model) Refer to AIR CONDITIONER (HEV)>ACCUMULATOR>INSTALLATION .
    4. Install the air intake duct. Refer to INTAKE (INDUCTION) (H4DO (EXCEPT FOR HEV))>AIR INTAKE DUCT>INSTALLATION .
