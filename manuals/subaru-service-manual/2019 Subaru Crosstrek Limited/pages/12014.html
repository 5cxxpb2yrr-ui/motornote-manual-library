Transmitter ID Registration

NOTE: If the registration of the transmitter ID is not finished within 300 seconds, the registration will be cancelled.
  1. Adjust all tire pressures to the specified pressure.
  2. Turn the ignition switch to OFF.
  3. Connect the SSM3 to the DLC3.
  4. Turn the ignition and SSM3 to ON.
  5. Enter the following menus: EACH SYSTEM CHECK > TIRE PRESSURE MONITOR > WORK SUPPORT> TRANSMITTER ID REGIST.
  6. Perform the procedure displayed in the SSM3.
