DTC B1414: Immobilizer Control Module Non-Volatile Memory

Do you like it dark? Easier on the eyes.

Diagnosis start condition: 

  • Battery voltage is 10 V or more.
  • The remote engine starter was not used to start the engine.

DTC detecting condition: 

  • Defective immobilizer control module
  • Failed to access the ROM in immobilizer control module.

Trouble symptom: 

Engine will not start.

CAUTION: When the immobilizer control module is replaced, registration of the immobilizer system is required. For details, refer to the "REGISTRATION INSTRUCTIONS FOR IMMOBILIZER" provided as a separate volume.
  1. CHECK DTC. 
    1. Disconnect the ground terminal from battery.
    2. Wait for at least 10 seconds.
    3. Connect the ground cable to battery.
    4. Read the DTC of [Immobilizer] using the Subaru Select Monitor. Refer to IMMOBILIZER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

      Is DTC B1414 displayed? (Current malfunction)

      Yes:  Go to  2.

      No:  The system has returned to a normal condition at this time. Finish the diagnosis.

  2. CHECK DTC. 
    1. Using the Subaru Select Monitor, perform the clear memory of [Immobilizer]. Refer to COMMON (DIAG)>CLEAR MEMORY .
    2. Disconnect the ground terminal from battery.
    3. Wait for at least 10 seconds.
    4. Connect the ground cable to battery.
    5. Read the DTC of [Immobilizer] using the Subaru Select Monitor. Refer to IMMOBILIZER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

      Is DTC B1414 displayed? (Current malfunction)

      Yes:  Replace the immobilizer control module. Refer to SECURITY AND LOCKS>IMMOBILIZER CONTROL MODULE .

      No:  The system has returned to a normal condition at this time. Finish the diagnosis.
