EGR Control Valve: Installation

  1. Install the EGR pipe adapter to the intake manifold assembly.

    Tightening torque: 

    19 N.m (1.9 kgf-m, 14.0 ft-lb)

  2. Set a new gasket and install the EGR control valve to the EGR pipe adapter.

    Tightening torque: 

    19 N.m (1.9 kgf-m, 14.0 ft-lb)

  3. Set a new gasket, and install the stud bolts using TORX® E8.

    Tightening torque: 

    5 N.m (0.5 kgf-m, 3.7 ft-lb)

  4. Install the nuts securing the EGR cooler.

    Tightening torque: 

    19 N.m (1.9 kgf-m, 14.0 ft-lb)

  5. Connect the connector.
  6. Attach the PCV hose No. 1. Refer to EMISSION CONTROL (AUX. EMISSION CONTROL DEVICES) (H4DO (EXCEPT FOR HEV))>PCV Hose>INSTALLATION>PCV HOSE NO. 1 .
  7. Install the EGR pipe. Refer to EMISSION CONTROL (AUX. EMISSION CONTROL DEVICES) (H4DO (EXCEPT FOR HEV))>EGR PIPE>INSTALLATION .
  8. Tighten the bolts holding the EGR cooler to the cylinder head RH.

    Tightening torque: 

    6.4 N.m (0.7 kgf-m, 4.7 ft-lb)

  9. Install the air intake boot. Refer to INTAKE (INDUCTION) (H4DO (EXCEPT FOR HEV))>Air Intake Boot>INSTALLATION .
  10. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
