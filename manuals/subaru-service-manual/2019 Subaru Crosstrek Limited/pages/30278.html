Cooler Valve

WARNING: This page is about a different variant/trim than selected.
CAUTION: Replace the O-rings with new parts, and then apply compressor oil to install completely.
  1. Install expansion valve - cooler assembly.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  2. Install the pipe - evaporator cooling.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  3. Install the pipe - sensor.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  4. Install the air intake boot. Refer to INTAKE (INDUCTION) (H4DO (EXCEPT FOR HEV))>Air Intake Boot>INSTALLATION .
  5. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
  6. Charge refrigerant. Refer to AIR CONDITIONER (HEV)>REFRIGERANT CHARGING PROCEDURE>PROCEDURE .
  7. When the expansion valve - cooler assembly was replaced with a new part, follow the procedure below and perform initialization.
    1. Check that all connectors are locked securely.
    2. Make sure that the outdoor air temperature is equal to or higher than 0°C (32°F).
    3. Turn the ignition switch to ON.
    4. Turn the A/C switch OFF so that the electric compressor does not operate.
    5. Turn the fan dial OFF.
    6. Using the Subaru Select Monitor, perform electric expansion valve forced initialization mode.
      NOTE: For detailed operation procedures, refer to "Help" of application.
      1. Connect the Subaru Select Monitor.
      2. On [Start] screen, select [Diagnosis].
      3. On [Select Vehicle] screen, enter vehicle information and select [OK].
      4. On [Main Menu] screen, select [Each System].
      5. On [Select System] screen, select [Air Conditioner], and then select [Next].
      6. On [Select Function] screen, select [Work Support].
      7. From the list of work support items, select [Electric expansion valve forced initialization mode] and then follow the procedure to perform and check preparation work.
      8. When preparation work is completed, select [Execution].
      9. When [Electric expansion valve forced initialization mode] changes from [incomplete] → [Complete], select [OK].
    7. Exit the Subaru Select Monitor and then turn the ignition switch to OFF.
