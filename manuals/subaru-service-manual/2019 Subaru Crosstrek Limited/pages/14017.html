MT Gear Select Cable: Installation

CAUTION:
  • Always use new MT gear select cable if the cable is removed from selector lever COMPL of transmission side.
  • Do not bend the MT gear select cable sharply.
  • Do not twist the inner cable excessively.
  • Do not apply excessive load while holding the part (a).
Courtesy of SUBARU OF AMERICA, INC.
  1. Remove the MT gear select cable from the select bracket.
    CAUTION: Check for assembling position before removing the MT gear select cable from the select bracket.
    Courtesy of SUBARU OF AMERICA, INC.
  2. Set to the new MT gear select cable to the select bracket and secure it with the clamp.
    CAUTION: Be careful not to mistake the MT gear select cable installing direction.
    Courtesy of SUBARU OF AMERICA, INC.
  3. Install the MT gear select cable and select bracket as a single unit.

    Tightening torque:

    18 N.m (1.8 kgf-m, 13.3 ft-lb)

    Courtesy of SUBARU OF AMERICA, INC.
  4. Install the MT gear select cable to the select lever COMPL.
    Courtesy of SUBARU OF AMERICA, INC.
  5. Insert the MT gear select cable into cable cover assembly, and install the clamp.
    Courtesy of SUBARU OF AMERICA, INC.
  6. Measure the exposed length (a) of MT gear select cable. If the value is out of specification, adjust the MT gear select cable. Refer to CONTROL SYSTEMS>MT GEAR SELECT CABLE>ADJUSTMENT .

    Exposed length (a) of MT gear select cable:

    Specification: 11 mm (0.4 in)

    Courtesy of SUBARU OF AMERICA, INC.
  7. Connect the MT gear select cable.
    CAUTION: Do not apply excessive load while holding the part (a).
    Courtesy of SUBARU OF AMERICA, INC.
  8. Attach the cable cover plate.

    Tightening torque:

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

    Courtesy of SUBARU OF AMERICA, INC.
  9. Insert the MT gear select cable into cable clamp, and install to the transmission.

    Tightening torque:

    18 N.m (1.8 kgf-m, 13.3 ft-lb)

    Courtesy of SUBARU OF AMERICA, INC.
  10. Raise the transmission jack, install the front crossmember and rear crossmember.

    Tightening torque:

    T1: 75 N.m (7.6 kgf-m, 55.3 ft-lb)

    T2: 140 N.m (14.3 kgf-m, 103.3 ft-lb)

    Courtesy of SUBARU OF AMERICA, INC.
  11. Take out the transmission jack.
  12. Install the propeller shaft. Refer to DRIVE SHAFT SYSTEM>PROPELLER SHAFT>INSTALLATION .
  13. Install the center exhaust cover.

    Tightening torque:

    18 N.m (1.8 kgf-m, 13.3 ft-lb)

  14. Install the front exhaust pipe. Refer to EXHAUST (H4DO (EXCEPT FOR HEV))>FRONT EXHAUST PIPE>INSTALLATION .
  15. Lower the vehicle.
  16. Install the pitching stopper. Refer to MANUAL TRANSMISSION AND DIFFERENTIAL (6MT)>TRANSMISSION MOUNTING SYSTEM>INSTALLATION>PITCHING STOPPER .
  17. Install the transmission radio ground cord terminal.

    Tightening torque:

    32.3 N.m (3.3 kgf-m, 23.8 ft-lb)

    Courtesy of SUBARU OF AMERICA, INC.
  18. Install the air breather hose.
    Courtesy of SUBARU OF AMERICA, INC.
  19. Install the coupling harness.
    Courtesy of SUBARU OF AMERICA, INC.
  20. Install the air intake duct. Refer to INTAKE (INDUCTION) (H4DO (EXCEPT FOR HEV))>AIR INTAKE DUCT>INSTALLATION .
  21. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
  22. Make sure the gears can be shifted accurately into each gear.
