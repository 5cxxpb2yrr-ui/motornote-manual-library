Reduction Driven Gear: Assembly

  1. Using the ST, install the parking gear.

    Preparation tool: 

    ST: INSTALLER (499757002)

    Courtesy of SUBARU OF AMERICA, INC.
  2. Using the ST, install the transfer drive gear.

    Preparation tool: 

    ST: INSTALLER (499757002)

    Courtesy of SUBARU OF AMERICA, INC.
  3. Using the ST, install the ball bearing.
    NOTE: Use a new ball bearing.

    Preparation tool: 

    ST: BUSHING 1-2 INSTALLER (499277100)

    Courtesy of SUBARU OF AMERICA, INC.
  4. Using the ST1, ST2 and ST3, counter the rotation of the reduction driven gear assembly, and install the lock nut.
    NOTE: Use a new lock nut.

    Preparation tool: 

    ST1: PULLEY WRENCH (18355AA000)

    ST2: PULLEY WRENCH PIN SET (18334AA000)

    ST3: SOCKET WRENCH (35) (499987003)

    Tightening torque: 

    95 N.m (9.7 kgf-m, 70.1 ft-lb)

    Courtesy of SUBARU OF AMERICA, INC.
  5. Crimp the lock nut at four locations so that the dimension of A becomes 18.9 mm (0.74 in) or less.
    CAUTION: Do not allow the lock nut to be cracked during crimping operation.
    Courtesy of SUBARU OF AMERICA, INC.
