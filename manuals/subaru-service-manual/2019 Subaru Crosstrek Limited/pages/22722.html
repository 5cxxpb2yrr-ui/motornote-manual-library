Basic Diagnostic Procedure: Procedure

Do you like it dark? Easier on the eyes.

CAUTION: Remove foreign matter (dust, water, oil, etc.) from the TPMS & keyless entry control module connector or TPMS control module connector during removal and installation.
  1. PERFORM CUSTOMER INTERVIEW. 

    Ask the customer when and how the trouble occurred using the interview check list. Refer to TIRE PRESSURE MONITOR (DIAGNOSTICS)>CHECK LIST FOR INTERVIEW .

    Did you interview the customer?

    Yes:  Go to  2.

    No:  Perform the interview, and Go to  2.

  2. BASIC INSPECTION. 

    Perform basic inspection. Refer to TIRE PRESSURE MONITOR (DIAGNOSTICS)>GENERAL DESCRIPTION>INSPECTION .

    Is the check result OK?

    Yes:  Go to  3.

    No:  Repair the faulty part found in basic inspection, and Go to  3.

  3. CHECK SUBARU SELECT MONITOR COMMUNICATION. 
    1. Turn the ignition switch to OFF.
    2. Connect the Subaru Select Monitor to data link connector. Refer to COMMON (DIAG)>DATA LINK CONNECTOR .
    3. Turn the ignition switch to ON and run the Subaru Select Monitor.
    4. Select [Tire Pressure Monitor].
    NOTE: For detailed operation procedures, refer to "Help" of application.

    Is communication possible?

    Yes:  Go to  4.

    No:  Check the communication circuit. Refer to TIRE PRESSURE MONITOR (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE FOR SUBARU SELECT MONITOR COMMUNICATION .

  4. CHECK DTC. 

    Read the DTC of [Tire Pressure Monitor] using the Subaru Select Monitor. Refer to TIRE PRESSURE MONITOR (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed? (Current malfunction)

    Yes:  Record the DTC, and Go to  5.

    No:  The system has returned to a normal condition at this time. Reproduce the failure, and then perform the diagnosis again.

    NOTE: In this case, there may be temporary poor communication due to radio wave environment inside/outside the vehicle.
  5. PERFORM DIAGNOSIS. 
    1. Perform the diagnosis according to the displayed DTC. Refer to TIRE PRESSURE MONITOR (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .
    2. Repair or replace the cause of trouble.
    3. Using the Subaru Select Monitor, perform the clear memory of [Tire Pressure Monitor]. Refer to COMMON (DIAG)>CLEAR MEMORY .
    4. Execute the inspection mode. Refer to TIRE PRESSURE MONITOR (DIAGNOSTICS)>INSPECTION MODE .
    5. Read the DTC of [Tire Pressure Monitor] using the Subaru Select Monitor. Refer to TIRE PRESSURE MONITOR (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed? (Current malfunction)

    Yes:  Repeat step  5 until DTC is not shown.

    No:  Finish the diagnosis.
