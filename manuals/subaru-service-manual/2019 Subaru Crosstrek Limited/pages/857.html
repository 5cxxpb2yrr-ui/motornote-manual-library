Door Outer Handle: Installation: Rear

  1. Before installation, check the following items.
    • Lever is free from deformation.
    • Grease is applied sufficiently to lever joints.

      If grease is insufficient, add it as necessary before assembling the lever.

  2. Install the frame assembly - rear door outer.

    Preparation tool: 

    TORX® T30

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  3. Install the spacer - door handle outer A and B.
  4. Install the handle - rear door outer.
  5. Install the cover - handle rear outer.

    Preparation tool: 

    TORX® T30

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  6. Install the latch and actuator assembly - rear. Refer to SECURITY AND LOCKS>DOOR LATCH & DOOR LOCK ACTUATOR ASSEMBLY>INSTALLATION .
  7. Install the sealing cover - rear door.
  8. Install the trim panel - rear door.
  9. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
