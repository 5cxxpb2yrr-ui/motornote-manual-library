Front Strut: Installation

CAUTION: For parts which are not reusable, always use new parts.
  1. Install the strut mount - front at the upper side of the strut to the vehicle body.

    Tightening torque: 

    32 N.m (3.3 kgf-m, 23.6 ft-lb)

  2. Align alignment marks on the camber adjusting bolt and the strut, and install the strut to the front axle housing.
    NOTE: While holding the bolt head of adjusting bolt, tighten the nut.

    Tightening torque: 

    155 N.m (15.8 kgf-m, 114.3 ft-lb)

  3. Install the ABS wheel speed sensor and harness bracket.
    CAUTION: During the installation, make sure that the marking of ABS wheel speed sensor harness does not twist.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  4. Install the brake hose bracket.

    Tightening torque: 

    33 N.m (3.4 kgf-m, 24.3 ft-lb)

  5. Install the stabilizer link.

    Refer to FRONT SUSPENSION>STABILIZER>INSTALLATION>STABILIZER LINK .

  6. Lower the vehicle, and install the front wheels.

    Tightening torque: 

    120 N.m (12.2 kgf-m, 88.5 ft-lb)

  7. Inspect the wheel alignment and adjust if necessary.
    • Inspection:

      Refer to FRONT SUSPENSION>WHEEL ALIGNMENT>INSPECTION .

    • Adjustment:

      Refer to FRONT SUSPENSION>WHEEL ALIGNMENT>ADJUSTMENT .

      CAUTION: When the wheel alignment has been adjusted, perform the following adjustment.
      • Lane keep assist learning value clear (except for hybrid model) (model with EyeSight):

        Refer to EYESIGHT (DIAGNOSTICS) (EXCEPT FOR HEV)>CLEAR ACTIVE LANE KEEP SYSTEM LEARNING VALUE>OPERATION .

      • Lane keep assist learning value clear (hybrid model):

        Refer to EYESIGHT (DIAGNOSTICS) (HEV)>CLEAR ACTIVE LANE KEEP SYSTEM LEARNING VALUE>OPERATION .

      • VDC sensor midpoint setting mode:

        Refer to VEHICLE DYNAMICS CONTROL (VDC)>VDC CONTROL MODULE AND HYDRAULIC CONTROL UNIT (VDCCM & H/U)>ADJUSTMENT .

  8. Perform reinitialization of the auto headlight beam leveler system. (Model with auto headlight beam leveler)

    Refer to LIGHTING SYSTEM>AUTO HEADLIGHT BEAM LEVELER SYSTEM>PROCEDURE .
