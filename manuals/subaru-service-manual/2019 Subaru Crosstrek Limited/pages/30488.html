Fuel Level Sensor: Installation

WARNING: This page is about a different variant/trim than selected.
  1. Install the stay to the fuel pump assembly.
  2. Install the fuel level sensor to the stay.
    CAUTION: Be sure to install the fuel level sensor harness to the clip first, then install the connector cable. Otherwise, malfunction may occur.
    Courtesy of SUBARU OF AMERICA, INC.
  3. Install the fuel pump assembly. Refer to FUEL INJECTION (FUEL SYSTEMS) (H4DO (HEV))>FUEL PUMP>INSTALLATION .
