Reverse Automatic Braking: Note

Do you like it dark? Easier on the eyes.

For procedure of each component in the Reverse Automatic Braking, refer to the respective information.

  • Control module
    NOTE: System control of the Reverse Automatic Braking is performed by each module. For procedure, refer to the following information.
    • Engine control module (ECM)
      • Except for hybrid model: Ref. to FUEL INJECTION (FUEL SYSTEMS) (H4DO (EXCEPT FOR HEV))>ENGINE CONTROL MODULE (ECM) .
      • Hybrid model: Ref. to FUEL INJECTION (FUEL SYSTEMS) (H4DO (HEV))>ENGINE CONTROL MODULE (ECM) .
    • Transmission control module (TCM)
      • Except for hybrid model: Ref. to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSMISSION CONTROL MODULE (TCM) .
      • Hybrid model: Ref. to HYBRID ELECTRIC VEHICLE>HYBRID POWERTRAIN CONTROL MODULE .
    • VDC control module (VDC CM): Ref. to VEHICLE DYNAMICS CONTROL (VDC)>VDC CONTROL MODULE AND HYDRAULIC CONTROL UNIT (VDCCM & H/U) .
    • Body integrated unit: Ref. to SECURITY AND LOCKS>BODY INTEGRATED UNIT .
    • Reverse Automatic Braking Control Module: Ref. to REVERSE AUTOMATIC BRAKING>REVERSE AUTOMATIC BRAKING CONTROL MODULE .
  • Sonar sensor: Ref. to REVERSE AUTOMATIC BRAKING>SENSOR AND HARNESS .
  • Stereo camera: Ref. to EYESIGHT>STEREO CAMERA .
  • Combination meter: Ref. to INSTRUMENTATION/DRIVER INFO>COMBINATION METER .
  • Audio (navigation) unit: Ref. to ENTERTAINMENT & MONITORING>AUDIO .
