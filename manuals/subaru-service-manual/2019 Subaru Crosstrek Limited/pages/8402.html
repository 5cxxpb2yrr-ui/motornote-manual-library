General Scan Tool

NOTE: For detailed operation procedures, refer to the general scan tool operation instructions.
  1. Clear the memory. Refer to ENGINE (DIAGNOSTICS) (H4DO (EXCEPT FOR HEV))>GENERAL SCAN TOOL>OPERATION>MODE $04 (CLEAR/RESET EMISSION-RELATED DIAGNOSTIC INFORMATION) .
  2. Read the diagnostic trouble code (DTC) and check that no DTC is displayed. Refer to ENGINE (DIAGNOSTICS) (H4DO (EXCEPT FOR HEV))>GENERAL SCAN TOOL>OPERATION>MODE $07 (INITIAL EMISSION-RELATED POWERTRAIN DTC) .
    NOTE: If the DTC is displayed on the screen, the trouble is still present. Perform the diagnosis using "Diagnostic Procedure with Diagnostic Trouble Code (DTC)". Refer to ENGINE (DIAGNOSTICS) (H4DO (EXCEPT FOR HEV))>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC) . After solving the DTC, repeat from step  1.
  3. Start the engine, and run the engine at idle for 10 seconds or more.
  4. Read the diagnostic trouble code (DTC) and check the DTC. Refer to ENGINE (DIAGNOSTICS) (H4DO (EXCEPT FOR HEV))>GENERAL SCAN TOOL>OPERATION>MODE $07 (INITIAL EMISSION-RELATED POWERTRAIN DTC) .
    NOTE: If the DTC is displayed on the screen, the trouble is still present. Perform the diagnosis using "Diagnostic Procedure with Diagnostic Trouble Code (DTC)". Refer to ENGINE (DIAGNOSTICS) (H4DO (EXCEPT FOR HEV))>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC) . After solving the DTC, repeat from step  1.
