ABS Warning Light Does Not Go Off

WARNING: This page is about a different variant/trim than selected.

Detecting condition: 

  • Defective combination meter
  • Defective engine
  • Defective CAN communication

Trouble symptom: 

ABS warning light does not go off when starting the engine.

  1. READ DTC. 

    Read the DTC using Subaru Select Monitor. Refer to BRAKE CONTROL (DIAGNOSTICS) (HEV)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC displayed?

    Yes:  Perform the diagnosis according to DTC. Refer to BRAKE CONTROL (DIAGNOSTICS) (HEV)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Go to  2.

  2. CHECK VDCCM. 

    Connect the Subaru Select Monitor and display [ABS Warning Lamp] of [Data monitor]. Refer to BRAKE CONTROL (DIAGNOSTICS) (HEV)>DATA MONITOR .

    Is [ABS Warning Lamp] ON?

    Yes:  Go to  3.

    No:  Go to  5.

  3. CHECK WARNING LIGHT. 
    1. Save the freeze frame data. Refer to BRAKE CONTROL (DIAGNOSTICS) (HEV)>FREEZE FRAME DATA .
    2. Using the Subaru Select Monitor, perform the clear memory. Refer to COMMON (DIAG)>CLEAR MEMORY .

    Does the ABS warning light go off?

    Yes:  Normal. Perform the inspection mode to check that the light does not turn ON again.

    No:  Go to  4.

  4. READ DTC. 

    After driving the vehicle at 40 km/h (25 MPH) or more, read DTCs using Subaru Select Monitor. Refer to BRAKE CONTROL (DIAGNOSTICS) (HEV)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC displayed?

    Yes:  Perform the diagnosis according to DTC. Refer to BRAKE CONTROL (DIAGNOSTICS) (HEV)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Go to  5.

  5. CHECK LAN SYSTEM. 

    Check the LAN system. Refer to LAN SYSTEM (DIAGNOSTICS) (HEV)>BASIC DIAGNOSTIC PROCEDURE .

    Is the check result OK?

    Yes:  Go to  6.

    No:  Perform the diagnosis for LAN system.

  6. CHECK COMBINATION METER. 

    Check the combination meter. Refer to INSTRUMENTATION/DRIVER INFO>COMBINATION METER SYSTEM>OPERATION>SELF-DIAGNOSIS DISPLAY MODE .

    Is the check result OK?

    Yes:  Replace the VDCCM & H/U. Refer to VEHICLE DYNAMICS CONTROL (VDC)>VDC CONTROL MODULE AND HYDRAULIC CONTROL UNIT (VDCCM & H/U) .

    No:  Replace the combination meter. Refer to INSTRUMENTATION/DRIVER INFO>COMBINATION METER>REMOVAL .
