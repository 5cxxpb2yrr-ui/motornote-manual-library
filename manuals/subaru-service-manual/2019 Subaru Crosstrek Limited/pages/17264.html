Drain Filter: Installation

  1. Install the bolts which hold the drain filter bracket to install the drain filter.
    NOTE: Install the drain filter bracket to the fuel filler pipe by aligning the alignment mark (a).

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  2. Connect the drain tube (A). Refer to FUEL INJECTION (FUEL SYSTEMS) (H4DO (EXCEPT FOR HEV))>Fuel Delivery and Evaporation Lines>INSTALLATION>QUICK CONNECTOR CONNECTION (TYPE E) .
    Courtesy of SUBARU OF AMERICA, INC.
  3. Install the mud guard - rear RH. Refer to EXTERIOR/INTERIOR TRIM>MUD GUARD>INSTALLATION .
  4. Lower the vehicle.
  5. Install the rear wheel RH. Refer to WHEEL AND TIRE SYSTEM>TIRE AND WHEEL>INSTALLATION .
