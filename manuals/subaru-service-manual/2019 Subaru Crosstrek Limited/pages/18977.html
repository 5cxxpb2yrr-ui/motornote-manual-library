Monitor Description

WARNING: This page is about a different variant/trim than selected.

The Hybrid vehicle control ECU assembly monitors the inverter voltage and the battery charger output voltage. If one of them exceeds the threshold, the Hybrid vehicle control ECU assembly will illuminate the MIL and set a DTC.
