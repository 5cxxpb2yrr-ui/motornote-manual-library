Tire Pressure Warning Light Does Not Come Off

Detecting condition: 

  • Defective combination meter
  • Tires pressure drop
  • Transmitter ID not registered

Trouble symptom: 

Tire pressure warning light remains illuminating after engine starts.

CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to TIRE PRESSURE MONITOR (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK DTC. 

    Read the DTC of [Tire Pressure Monitor] using the Subaru Select Monitor. Refer to TIRE PRESSURE MONITOR (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed?

    Yes:  Perform the diagnosis for the displayed DTCs. Refer to TIRE PRESSURE MONITOR (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Go to  2.

  2. CHECK TRANSMITTER (ID). 

    Using the Subaru Select Monitor, check the following items in the [Data monitor] of [Tire Pressure Monitor]. Refer to TIRE PRESSURE MONITOR (DIAGNOSTICS)>DATA MONITOR .

    • FL Registered ID
    • FR Registered ID
    • RR Registered ID
    • RL Registered ID

    Is the transmitter ID registered?

    Yes:  Go to  3.

    No:  Register the transmitter ID. Refer to TIRE PRESSURE MONITOR (DIAGNOSTICS)>REGISTER TRANSMITTER (ID)>OPERATION .

  3. CHECK TRANSMITTER DATA OUTPUT. 
    1. Start the engine.
    2. Using the Subaru Select Monitor, check the following items in the [Data monitor] of [Tire Pressure Monitor]. Refer to TIRE PRESSURE MONITOR (DIAGNOSTICS)>DATA MONITOR .
    • INDICATOR LAMP
    • FR Registered ID
    • RR Registered ID
    • RL Registered ID
    • Is [ON] displayed?

    Yes:  Replace the TPMS & keyless entry control module or TPMS control module. Refer to WHEEL AND TIRE SYSTEM>TIRE PRESSURE MONITORING SYSTEM .

    No:  Replace the combination meter. Refer to INSTRUMENTATION/DRIVER INFO>COMBINATION METER>REMOVAL .
