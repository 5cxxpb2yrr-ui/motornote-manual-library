Occupant Detection System (Diagnostics): Rezero: List

Code Contents Causes Action to take
0020H Timeout due to unstable load Occupant detection control module judged the current situation as error because the over-specified load change occurred during rezeroing. Perform rezeroing again at a stable place where vehicle vibration hardly occurs.
0021H FL sensor upper limit error Rezeroing cannot be executed because the load value of FL sensor exceeds the upper limit of rezero adjustment range. Check that the seat is in proper position and fixed securely, and perform rezeroing again. If the same code appears again, replace the seat assembly. Refer to SEATS>FRONT SEAT .
0022H FL sensor lower limit error Rezeroing cannot be executed because the load value of FL sensor exceeds the lower limit of rezero adjustment range. Check that the seat is in proper position and fixed securely, and perform rezeroing again. If the same code appears again, replace the seat assembly. Refer to SEATS>FRONT SEAT .

Read the DTC of [Occupant Detection] Refer to OCCUPANT DETECTION (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) ., and perform the diagnosis for the displayed DTCs. Refer to OCCUPANT DETECTION (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .
