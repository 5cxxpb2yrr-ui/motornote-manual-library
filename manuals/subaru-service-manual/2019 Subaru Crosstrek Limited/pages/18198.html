Front Hood: Assembly

  1. Install the hinge COMPL - front hood.

    Tightening torque: 

    25 N.m (2.5 kgf-m, 18.4 ft-lb)

  2. Install the cover - fender UPR.
  3. Install the cowl panel - side.
  4. Install the insulator - front hood.
  5. Align the alignment marks (A), and install the striker - front hood to the hood COMPL - front.
    CAUTION: When installing the striker - front hood, make sure that the front and rear sides are positioned in a correct direction.
    NOTE: It is not necessary to adjust the striker - front hood because there is no span of adjustable range.

    Tightening torque: 

    33 N.m (3.4 kgf-m, 24 ft-lb)
