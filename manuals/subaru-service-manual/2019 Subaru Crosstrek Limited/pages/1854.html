Radar Sensor: Installation

  1. Install the radar bracket.

    Tightening torque:

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  2. Install the radar sensor.

    Tightening torque:

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  3. Install the bumper face - rear.
  4. Connect the battery ground terminal. Ref. to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
  5. Perform the adjustment of the radar sensor radar axis. Ref. to BLIND SPOT DETECTION/REAR CROSS TRAFFIC ALERT>RADAR SENSOR>ADJUSTMENT>RADAR AXIS ADJUSTMENT .
