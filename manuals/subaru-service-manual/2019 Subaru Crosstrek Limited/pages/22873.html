Exterior Lights (Diagnostics): Customize: Operation

  1. On [Start] display, select [Diagnosis].
  2. On [Vehicle selection] display, input the target vehicle information and select [OK].
  3. On [Main Menu] display, select [Each System].
  4. On [Select System] display, select [Headlight/Foglight], and then select [Enter].
  5. On [Select Function] display, select [Customize].
  6. On [Customize] display, select an item to be customized.
    NOTE:
    • For detailed operation procedures, refer to "Help" of application.
    • For details on customization, refer to the list. Refer to HEADLIGHT/FOGLIGHT (DIAGNOSTICS)>CUSTOMIZE>LIST .
    • If not equipped (depending on destination area or vehicle equipment condition), some items are not displayed.
