Electrical Specification

Do you like it dark? Easier on the eyes.

WARNING: This page is about a different variant/trim than selected.
  • Central gateway control module

    For I/O signals of the central gateway control module, refer to CENTRAL GATEWAY (DIAGNOSTICS). Refer to CENTRAL GATEWAY (DIAGNOSTICS)>CONTROL MODULE I/O SIGNAL .

  • Body integrated unit

    For I/O signals of the body integrated unit, refer to BODY CONTROL SYSTEM (DIAGNOSTICS). Refer to BODY CONTROL (DIAGNOSTICS)>CONTROL MODULE I/O SIGNAL>ELECTRICAL SPECIFICATION .

  • ECM

    For unit I/O signals of ECM, refer to ENGINE (DIAGNOSTICS). Refer to ENGINE (DIAGNOSTICS) (H4DO (HEV))>CONTROL MODULE I/O SIGNAL>ELECTRICAL SPECIFICATION .

  • VDC control module & H/U

    For unit I/O signals of VDC control module & H/U, refer to BRAKE CONTROL (DIAGNOSTICS). Refer to BRAKE CONTROL (DIAGNOSTICS)>CONTROL MODULE I/O SIGNAL .

  • Electric brake booster control module (EBB control module)

    For unit I/O signals of EBB control module, refer to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS). Refer to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>CONTROL MODULE I/O SIGNAL .

  • AWD control module

    For unit I/O signals of AWD control module, refer to AWD CONTROL (DIAGNOSTICS). Refer to AWD CONTROL (DIAGNOSTICS)>CONTROL MODULE I/O SIGNAL .

  • Power steering control module

    For unit I/O signals of power steering control module, refer to POWER STEERING (DIAGNOSTICS). Refer to POWER STEERING (DIAGNOSTICS)>CONTROL MODULE I/O SIGNAL .

  • A/C control panel

    For unit I/O signals of A/C control panel, refer to AIR CONDITIONER (DIAGNOSTICS). Refer to AIR CONDITIONER (DIAGNOSTICS) (HEV)>CONTROL MODULE I/O SIGNAL .

  • Combination meter

    For I/O signals of combination meter, refer to COMBINATION METER (DIAGNOSTICS). Refer to COMBINATION METER (DIAGNOSTICS)>CONTROL MODULE I/O SIGNAL .

  • MFD

    For I/O signals of MFD, refer to MFD (DIAGNOSTICS). Refer to MULTI-FUNCTION DISPLAY (DIAGNOSTICS)>CONTROL MODULE I/O SIGNAL .

  • Airbag control module

    For I/O signals of the airbag control module, refer to AIRBAG SYSTEM (DIAGNOSTICS). Refer to AIRBAG (DIAGNOSTICS)>CONTROL MODULE I/O SIGNAL .

  • Keyless access control module

    For I/O signals of keyless access control module, refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS). Refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS)>CONTROL MODULE I/O SIGNAL .

  • TPMS control module

    For I/O signals of TPMS control module, refer to TIRE PRESSURE MONITOR (DIAGNOSTICS). Refer to TIRE PRESSURE MONITOR (DIAGNOSTICS)>CONTROL MODULE I/O SIGNAL .

  • Auto headlight beam leveler control module

    For I/O signals of auto headlight beam leveler control module, refer to AUTO HEADLIGHT BEAM LEVELER SYSTEM (DIAGNOSTICS). Refer to HEADLIGHT/FOGLIGHT (DIAGNOSTICS)>CONTROL MODULE I/O SIGNAL>ELECTRICAL SPECIFICATION .

  • Radar sensor

    For I/O signals of the radar sensor, refer to BSD/RCTA (DIAGNOSTICS). Refer to BLIND SPOT DETECTION/REAR CROSS TRAFFIC ALERT (DIAGNOSTICS)>CONTROL MODULE I/O SIGNAL .

  • Audio or navigation unit

    For I/O signals of the audio or navigation, refer to INFOTAINMENT SYSTEM (DIAGNOSTICS). Refer to INFOTAINMENT (DIAGNOSTICS)>CONTROL MODULE I/O SIGNAL .

  • Data communication module (DCM)

    For I/O signals of DCM, refer to TELEMATICS (DIAGNOSTICS). Refer to TELEMATICS SYSTEM (DIAGNOSTICS)>CONTROL MODULE I/O SIGNAL .

  • RAB control module

    For I/O signals of the RAB control module, refer to Reverse Automatic Braking (DIAGNOSTICS). Refer to REVERSE AUTOMATIC BRAKING (DIAGNOSTICS)>CONTROL MODULE I/O SIGNAL .

  • Stereo camera

    For I/O signals of stereo camera, refer to EyeSight (DIAGNOSTICS). Refer to EYESIGHT (DIAGNOSTICS) (HEV)>CONTROL MODULE I/O SIGNAL .

  • Pedestrian alert control module

    For I/O signals of the pedestrian alert control module, refer to PEDESTRIAN ALERT SYSTEM (DIAGNOSTICS). Refer to PEDESTRIAN ALERT (DIAGNOSTICS)>CONTROL MODULE I/O SIGNAL .

  • Hybrid vehicle control ECU assembly

    For I/O signals of Hybrid vehicle control ECU assembly, refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS). Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>CONTROL MODULE I/O SIGNAL .

  • Inverter with converter assembly

    For I/O signals of Inverter with converter assembly, refer to P-HEV DRIVE MOTOR (DIAGNOSTICS). Refer to P-HEV DRIVE MOTOR (DIAGNOSTICS)>CONTROL MODULE I/O SIGNAL .

  • Electric vehicle charger assembly

    For I/O signals of Electric vehicle charger assembly, refer to PLUG-IN BATTERY CHARGER (DIAGNOSTICS). Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>CONTROL MODULE I/O SIGNAL .

  • Battery ECU assembly

    For I/O signals of Battery ECU assembly, refer to P-HEV HIGH VOLTAGE BATTERY (DIAGNOSTICS). Refer to P-HEV HIGH VOLTAGE BATTERY (DIAGNOSTICS)>CONTROL MODULE I/O SIGNAL .

  • Data link connector

    For I/O signals of data link connector, refer to COMMON (DIAGNOSTICS). Refer to COMMON (DIAG)>DATA LINK CONNECTOR .
