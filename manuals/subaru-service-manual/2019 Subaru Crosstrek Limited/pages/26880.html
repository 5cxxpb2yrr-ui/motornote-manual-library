DTC P060A-47: Hybrid/EV Powertrain Control Module Monitoring Processor Watchdog/Safety MCU Failure: Notes

WARNING: This page is about a different variant/trim than selected.

Outline of diagnosis: 

Internal malfunction of Hybrid vehicle control ECU assembly (sub CPU WDC malfunction)

(1 trip detection logic)

Trouble symptom: 

Hybrid system stopped

NOTE: This DTC is output when Hybrid vehicle control ECU assembly detects the operation malfunction in Hybrid vehicle control ECU assembly. Therefore, when this DTC is output, replace Hybrid vehicle control ECU assembly. Refer to HYBRID ELECTRIC VEHICLE>HYBRID POWERTRAIN CONTROL MODULE .
