Inspection Mode 3

DTC Item Note
B2329 REAR RADAR AXIS ALIGNMENT INCOMPLETE -
  1. Using the Subaru Select Monitor, perform the clear memory of [Blind Spot Detection/Rear Cross Traffic Alert (RH)] or [Blind Spot Detection/Rear Cross Traffic Alert (LH)]. Refer to COMMON (DIAG)>CLEAR MEMORY .
  2. Read the DTC of [Blind Spot Detection/Rear Cross Traffic Alert (RH)] or [Blind Spot Detection/Rear Cross Traffic Alert (LH)] using Subaru Select Monitor and check that the DTC is not displayed. Refer to BLIND SPOT DETECTION/REAR CROSS TRAFFIC ALERT (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
    NOTE: If the DTC is displayed on the screen, the trouble is still present. Perform the diagnosis for the displayed DTCs - After solving the DTC, repeat from step  1.
  3. Perform the adjustment of radar axis.
  4. Read the DTC of [Blind Spot Detection/Rear Cross Traffic Alert (RH)] or [Blind Spot Detection/Rear Cross Traffic Alert (LH)] using Subaru Select Monitor and check that the DTC is not displayed. Refer to BLIND SPOT DETECTION/REAR CROSS TRAFFIC ALERT (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
    NOTE: If the DTC is displayed on the screen, the trouble is still present. Perform the diagnosis for the displayed DTCs. Refer to BLIND SPOT DETECTION/REAR CROSS TRAFFIC ALERT (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .
