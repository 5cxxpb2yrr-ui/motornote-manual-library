Clearing Vehicle Control History

WARNING: This page is about a different variant/trim than selected.

If the vehicle control history is cleared, all the stored items will be cleared.

  1. On [Start] screen, select [Diagnosis].
  2. On [Vehicle selection] screen, enter vehicle information and select [OK].
  3. On [Main Menu] screen, select [Each System].
  4. On [Select System] screen, select [P-HEV High Voltage Battery].
  5. On [Select Function] screen, select [Work Support].
  6. On [Work Support] screen, select [Vehicle Control History].
  7. On [Vehicle Control History] screen, select [Hist. Clear].
