DTC P1606-00: Collision Detected Or Collision Sensor Connection (Open): Notes

WARNING: This page is about a different variant/trim than selected.

1. - 

Outline of diagnosis: 

Collision judgment detection

Shutdown signal from AIRBAG CONTROL MODULE is received

(1 trip detection logic)

Trouble symptom: 

Hybrid system stopped

CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
NOTE: With DTC P160600 and P160604 displayed, READY ON cannot be turned on unless the clear memory of DTC is performed using the Subaru Select Monitor.
  1. CHECK VEHICLE CONDITION  .

    Verify the damage condition of the vehicle.

    Is the vehicle damaged?

    Yes:  Go to  2.

    No:  Repair the vehicle.

  2. CHECK DTC  .

    Read the DTC of [P-HEV Hybrid Powertrain Control] using the Subaru Select Monitor. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    NOTE:

    DTC P160600 or P160604 may be output simultaneously due to the fault that DTC above describes  .

    When "Either DTC P160600 or P160604 is displayed" or "DTC other than above is displayed", go to  A.

    When DTCs related to [P-HEV Hybrid Powertrain Control], mentioned above, are simultaneously displayed, go to  B.

    Yes: 

    1. Go to  3.
    2. Perform the diagnosis for the simultaneously displayed DTCs.

    No:  -

  3. CHECK DTC  .

    Read the DTC of [P-HEV Hybrid Powertrain Control] using the Subaru Select Monitor. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC P160600 displayed?

    Yes:  Perform the diagnosis for Airbag System. Refer to AIRBAG (DIAGNOSTICS)>BASIC DIAGNOSTIC PROCEDURE .

    No:  Go to  4.

  4. CHECK DTC  .

    Read the following DTCs using Subaru Select Monitor. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) . Refer to P-HEV DRIVE MOTOR (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    • P-HEV Hybrid Powertrain Control
    • P-HEV Drive Motor
