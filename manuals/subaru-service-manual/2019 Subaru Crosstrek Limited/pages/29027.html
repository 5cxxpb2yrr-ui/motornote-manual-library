Inspection Mode AF

Do you like it dark? Easier on the eyes.

WARNING: This page is about a different variant/trim than selected.
DTC Item Condition Number of driving cycles on the detecting condition
P04B6 FUEL FILL DOOR STUCK CLOSED - 2
NOTE:
  • Perform the inspection mode after warming up the engine except that the engine coolant temperature at engine start is specified.
  • As there is a procedure where 20 L (5.3 US gal, 4.4 Imp gal) or more of fuel is refilled, adjust to the fuel level that allows refueling.
  1. Make sure that the battery voltage is 12 V or more.
  2. Using the Subaru Select Monitor, clear the memory of [Engine Control System]. Refer to COMMON (DIAG)>CLEAR MEMORY .
  3. Turn the ignition switch to ON.
  4. Turn the ignition switch to OFF.
  5. Refill 20 L (5.3 US gal, 4.4 Imp gal) or more of fuel.
  6. Turn to READY ON and wait for 10 seconds or more.
  7. Read the temporary code using the Subaru Select Monitor or general scan tool. Refer to COMMON (DIAG)>DIAGNOSTIC TROUBLE CODE (DTC) .
