Outline Of Diagnosis

WARNING: This page is about a different variant/trim than selected.

Judge as NG when the status enters into any one of the followings.

  • When ECM does not detect engine start though engine cranking is performed based on the engine start command from HV system.
  • When ECM detects that it takes a long time to start the engine though engine cranking is performed based on the engine start command from HV system.
