Sunload Sensor (Auto A/C Model): Installation

  1. Install the sunload sensor.
  2. Install the grille - front defroster.
  3. Install the multi-function display. Refer to INSTRUMENTATION/DRIVER INFO>MULTI-FUNCTION DISPLAY (MFD)>INSTALLATION .
  4. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
