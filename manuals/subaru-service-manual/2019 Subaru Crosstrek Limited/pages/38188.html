INTRODUCTION

This Service Bulletin is to inform you of the availability of the new auxiliary USB terminal and adapter cord designed to address cases of intermittent communication loss when using Apple CarPlay and/or Android Auto application connected via the auxiliary USB terminal port (2-port type) to Gen 3.1 Harman Head Unit. When using a USB cable to connect a smart phone to the auxiliary USB terminal, the data between the external device and the Head Unit can possibly be disturbed resulting in connection loss. If this occurs, the Head Unit software cannot reestablish the connection automatically. If this symptom is reported, follow the service procedure outlined below.

SERVICE PROCEDURE

The auxiliary USB terminal and adapter cord have been modified to secure stable connection for the USB port. The Head Unit software is optimized to reestablish the connection, even if it has been interrupted for any reason. If Apple CarPlay or Android Auto connection problem is reported, update the Head Unit with the latest software version per TSB 15-236-18R  and replace the auxiliary USB terminal with new part in conjunction with the adapter cord. The adapter cord MUST be replaced when a new auxiliary USB terminal is installed (Except for BRZ models).

IMPORTANT: BRZ models will ONLY require the reprogramming procedures outlined in TSB 15-236-18R  .

STEP 1:  Remove the auxiliary USB terminal as per the applicable Service Manual. Refer to STIS: Body & Electrical/WIRING SYSTEM > External Connection Terminal 

STEP 2:  Insert adapter cord (86259FL000) between the original body wiring harness (with 8-pin connector) and the new auxiliary USB terminal as the pin location on the new terminal is different from the original one. The original body wiring harness with 4-pin connector can be used without adapter cord.

STEP 3:  Install the new auxiliary USB terminal and adapter per the applicable Service Manual. Refer to STIS: Body & Electrical/WIRING SYSTEM > External Connection Terminal 

STEP 4:  Reprogram the Head Unit with the latest software version per TSB 15-236-18R  .

NOTE: The software update will enable automatic reconnection in case of accidental disconnection however the AUX connection is stabilized by the hardware replacement (for robustness improvement.)
