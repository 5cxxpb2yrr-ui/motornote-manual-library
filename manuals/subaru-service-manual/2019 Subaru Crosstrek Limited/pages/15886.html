Inspection Mode AJ

Do you like it dark? Easier on the eyes.

WARNING: This page is about a different variant/trim than selected.

WARNING: When performing inspection mode AJ on a public road, pay sufficient attention to the traffic condition and give the highest priority to safe driving.
NOTE:
  • Perform the inspection mode after warming up the engine except that the engine coolant temperature at engine start is specified.
  • Even if switched to the hybrid battery save mode under the following conditions, the engine may not start.
    • Power from HV battery is low and reduction in SOC is slight.
    • SOC is recovering due to regeneration, etc.
  1. Check that the battery voltage is 12 V or more and fuel remains approx. half [20 - 40 L (5.3 - 10.6 US gal, 4.4 - 8.8 Imp gal)].
  2. Using the Subaru Select Monitor, clear the memory of [Engine Control System]. Refer to COMMON (DIAG)>CLEAR MEMORY .
  3. Drive 4 times according to the drive pattern described below.
    Courtesy of SUBARU OF AMERICA, INC.
  4. Read the temporary code using the Subaru Select Monitor or general scan tool. Refer to COMMON (DIAG)>DIAGNOSTIC TROUBLE CODE (DTC) .
