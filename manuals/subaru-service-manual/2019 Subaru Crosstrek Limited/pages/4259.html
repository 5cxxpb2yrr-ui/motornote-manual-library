Rear Door (5 Door Model)

Do you like it dark? Easier on the eyes.

  1. Apply the rear door sash tape - medium from the front of the vehicle towards the rear.
    NOTE: Apply the end of the tape to the position shown in the figure.
    Courtesy of SUBARU OF AMERICA, INC.
  2. Install a new cover B pillar - rear and a new cover C pillar.
  3. Install the weather strip outer - rear door.
  4. Install the running channel - rear door.
  5. Install the glass assembly - rear door.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  6. Install the rear sealing cover.
  7. Install the trim panel - rear door.
  8. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY>GROUND TERMINAL REMOVAL OR INSTALLATION .
