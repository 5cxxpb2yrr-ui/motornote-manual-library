Brake Pedal

CVT MODEL 

CAUTION: Before handling the airbag system components, always refer to "CAUTION" of "General Description" in "AIRBAG SYSTEM". Refer to AIRBAG SYSTEM>GENERAL DESCRIPTION>CAUTION .
  1. Install the brake pedal assembly.
    CAUTION:
    • Apply grease to the snap pin to prevent the operating rod from wear.
    • Replace the clevis pin with a new part, and apply a thin coat of grease to the clevis pin.

    Preparation items: 

    • Impreza model

      Grease (clevis pin): Shell Gadus S2 V220 or equivalent

    • Except for Impreza model

      Grease (clevis pin): IDEMITSU APOLLOIL AUTOLEX A or equivalent

    Tightening torque: 

    Brake pedal: 18 N.m (1.8 kgf-m, 13.3 ft-lb)

  2. Install the hybrid powertrain control module. (Hybrid model) Refer to HYBRID ELECTRIC VEHICLE>HYBRID POWERTRAIN CONTROL MODULE>INSTALLATION .
  3. Install the duct - foot driver.
    • Except for hybrid model: Refer to AIR CONDITIONER (EXCEPT FOR HEV)>HEATER DUCT>INSTALLATION .
    • Hybrid model: Refer to AIR CONDITIONER (HEV)>HEATER DUCT>INSTALLATION .
  4. Install the column assembly - steering. Refer to POWER ASSISTED SYSTEM (POWER STEERING)>STEERING COLUMN>INSTALLATION .
  5. Install the universal joint assembly - steering. Refer to POWER ASSISTED SYSTEM (POWER STEERING)>UNIVERSAL JOINT>INSTALLATION .
    CAUTION:
    • Always install the universal joint assembly - steering after installing the steering column to avoid damage to the universal joint assembly - steering.
    • Be sure to follow the tightening order and tightening torque of the universal joint assembly - steering to avoid the steering effort from becoming heavy. After confirming that the steering column position is in the neutral position, tighten the universal joint assembly - steering.
    • Always place the tilt lever to the lock position after the steering column is adjusted.
  6. Install the knee airbag module.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  7. Install the cover assembly - instrument panel LWR driver.
  8. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY>GROUND TERMINAL REMOVAL OR INSTALLATION .
  9. Check that the brake light operate properly.
  10. Check the brake pedal after installation. Refer to BRAKE>BRAKE PEDAL>INSPECTION .
  11. Erase the backup memory. (Hybrid model) Refer to BRAKE>BRAKE SYSTEM>OPERATION>BACK-UP MEMORY CLEARING .
  12. Perform linear valve offset learning. (Hybrid model) Refer to BRAKE>BRAKE SYSTEM>OPERATION>LINEAR VALVE OFFSET LEARNING .

    MT model 

    NOTE: Brake pedal is integrated with the clutch pedal.

    For installation procedure of the brake pedal, refer to Clutch service information. Refer to CLUTCH SYSTEM>CLUTCH PEDAL>INSTALLATION .
