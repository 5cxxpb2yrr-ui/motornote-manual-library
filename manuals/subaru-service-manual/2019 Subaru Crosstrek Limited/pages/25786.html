Inspection Mode 16

WARNING: This page is about a different variant/trim than selected.
Code Note Number of driving cycles on the detecting condition
P1AFC00 - 1

Diagnostic procedure:

  1. Using the Subaru Select Monitor, perform the clear memory of [P-HEV High Voltage Battery]. Refer to COMMON (DIAG)>CLEAR MEMORY .
  2. Turn to IG OFF, and wait for two minutes or more.
  3. Turn to IG ON, and wait for 11 seconds or more.
  4. Turn to IG OFF, and wait for 30 seconds or more.
  5. Perform steps  3 and  4 41 times or more.
  6. Read the [Readiness code] of [P-HEV High Voltage Battery] using Subaru Select Monitor and check that the concerned self-diagnosis is completed. Refer to P-HEV HIGH VOLTAGE BATTERY (DIAGNOSTICS)>ALL READINESS DIAGNOSTIC CODE(S) .
    NOTE: If the concerned DTC is displayed, the self-diagnosis of the DTC is not complete. Repeat from step  3.
  7. Using the Subaru Select Monitor, read the DTC of [P-HEV High Voltage Battery] to check that there is no DTC displayed. Refer to P-HEV HIGH VOLTAGE BATTERY (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
    NOTE: If the DTC is displayed on the screen, the trouble is still present. Perform the diagnosis for the displayed DTCs.
