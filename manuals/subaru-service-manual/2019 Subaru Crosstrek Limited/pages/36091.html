Diagnostic Trouble Code (DTC): Operation

NOTE:
  • Refer to "COMMON (diag)". Refer to COMMON (diag)>DIAGNOSTIC TROUBLE CODE (DTC) .
  • For details on DTCs, refer to the list. Refer to POWER WINDOW (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .
  • Up to three DTCs are stored for past malfunction.
  • If the number of DTCs exceeds the number of allowed DTCs, new DTCs are not stored.
  • Any recorded DTCs for current malfunctions are displayed.
