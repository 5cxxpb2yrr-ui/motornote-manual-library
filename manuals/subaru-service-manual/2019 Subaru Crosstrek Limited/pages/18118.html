Engine Cooling System (Except For HEV): Radiator: Installation

  1. When assembled together with condenser
    1. Install the radiator lower cushion.
    2. Assemble the radiator fan & fan motor assembly. Refer to COOLING (H4DO (EXCEPT FOR HEV))>RADIATOR FAN AND FAN MOTOR ASSEMBLY>INSTALLATION .
    3. Assemble the condenser. Refer to AIR CONDITIONER (EXCEPT FOR HEV)>CONDENSER>INSTALLATION .
    4. Install the radiator, radiator fan & fan motor assembly, and the condenser as an assembly.
    5. Connect the hose - pressure discharge and the pipe - evaporator cooling. Refer to AIR CONDITIONER (EXCEPT FOR HEV)>CONDENSER>INSTALLATION .
  2. When condenser is not removed
    1. Install the radiator lower cushion.
    2. Install the radiator fan and fan motor assembly. Refer to COOLING (H4DO (EXCEPT FOR HEV))>RADIATOR FAN AND FAN MOTOR ASSEMBLY>INSTALLATION .
    3. Install the radiator and the radiator fan & fan motor assembly as an assembly.
    4. Install the condenser to the radiator.
    5. Install the pipe - evaporator cooling to the clip.
  3. Install the radiator upper cushion to the pin at the upper part of the radiator.
  4. Set the radiator upper frame, and install the upper side bolts securing the radiator upper frame.
    NOTE: Securely install the radiator upper cushion to the radiator upper frame.

    Tightening torque: 

    18 N.m (1.8 kgf-m, 13.3 ft-lb)

  5. Connect the radiator inlet hoses and over flow hose.
  6. Connect the horn connector and install the clip.
  7. Install the front hood lock assembly. Refer to SECURITY AND LOCKS>FRONT HOOD LOCK ASSEMBLY>INSTALLATION .
  8. Install the bracket - bumper UPR.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  9. Install the cover UPR - front.
  10. Install the front bumper. Refer to EXTERIOR/INTERIOR TRIM>FRONT BUMPER>INSTALLATION .
  11. Install the air intake duct. Refer to INTAKE (INDUCTION) (H4DO (EXCEPT FOR HEV))>AIR INTAKE DUCT>INSTALLATION .
  12. Install the reservoir tank. Refer to COOLING (H4DO (EXCEPT FOR HEV))>RESERVOIR TANK>INSTALLATION .
  13. Connect the radiator outlet hose.
  14. Connect the main fan motor connector and the sub fan motor connector.
  15. Install the lower side bolts securing the radiator upper frame.

    Tightening torque: 

    18 N.m (1.8 kgf-m, 13.3 ft-lb)

  16. Install the front exhaust pipe. Refer to EXHAUST (H4DO (EXCEPT FOR HEV))>FRONT EXHAUST PIPE>INSTALLATION .
  17. Install the V-belt cover.

    Tightening torque: 

    7 N.m (0.7 kgf-m, 5.2 ft-lb)

  18. Charge the A/C system with refrigerant. Refer to AIR CONDITIONER (EXCEPT FOR HEV)>REFRIGERANT CHARGING PROCEDURE .
    NOTE: This step is necessary only if the condenser has been removed.
  19. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
  20. Fill engine coolant. Refer to COOLING (H4DO (EXCEPT FOR HEV))>ENGINE COOLANT>REPLACEMENT>FILLING OF ENGINE COOLANT .
