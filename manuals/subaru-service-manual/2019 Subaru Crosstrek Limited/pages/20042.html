DTC B1828: Short In Side Airbag LH (TO +B)

Diagnosis start condition: 

When the ignition voltage is 10 - 16 V.

DTC detecting condition: 

  • Side airbag harness LH is shorted to power supply.
  • Side airbag module LH is faulty.
  • Airbag control module is faulty.

Wiring diagram: 

Airbag system Refer to WIRING SYSTEM (IMPREZA MODEL)>AIRBAG SYSTEM>WIRING DIAGRAM . Refer to WIRING SYSTEM (CROSSTREK MODEL (EXCEPT FOR HEV))>AIRBAG SYSTEM>WIRING DIAGRAM . Refer to WIRING SYSTEM (CROSSTREK MODEL (HEV))>AIRBAG SYSTEM>WIRING DIAGRAM .

CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to AIRBAG (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK POOR CONTACT OF CONNECTORS. 

    Check for poor contact of the connectors between the airbag control module, side airbag module LH and the side airbag sensor LH.

    Is there poor contact?

    Yes:  Replace the airbag rear harness along with body harness.

    No:  Go to  2.

  2. CHECK AIRBAG REAR HARNESS (SIDE AIRBAG MODULE HARNESS LH) (SHORTED TO POWER SUPPLY). 
    1. Turn the ignition switch to OFF, disconnect the battery ground terminal, and wait for 60 seconds or more. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
    2. Disconnect the connector (AB21) from seat belt pretensioner LH.
    3. Disconnect the connector (AB19) from side airbag module LH.
    4. Disconnect the connector (AB31) from curtain airbag module LH.
    5. Disconnect the connectors (AB6, AB17, AB18) from airbag control module.
    6. Measure the voltage between connector (AB19) of side airbag module LH and chassis ground.
      CAUTION: Connect the test harness AT terminal to the connector (AB19) terminal and contact a tester to the test harness AT.

      Connector & terminal 

      (AB19) No. 1 (+) - Chassis ground (-):

      (AB19) No. 2 (+) - Chassis ground (-):

    Is the voltage less than 1 V?

    Yes:  Go to  3.

    No:  Replace the airbag rear harness along with body harness.

  3. CHECK AIRBAG CONTROL MODULE. 
    1. Connect all connectors other than side airbag module LH connector (AB19).
    2. Connect the battery ground terminal and turn the ignition switch to ON. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
    3. Using the Subaru Select Monitor, perform the clear memory of [Airbag]. Refer to COMMON (DIAG)>CLEAR MEMORY .
    4. Execute the inspection mode. Refer to AIRBAG (DIAGNOSTICS)>INSPECTION MODE .
    5. Read the DTC of [Airbag] using the Subaru Select Monitor. Refer to AIRBAG (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC B1828 displayed? (Current malfunction)

    Yes:  Replace the airbag control module. Refer to AIRBAG SYSTEM>AIRBAG CONTROL MODULE .

    No:  Go to  4.

  4. CHECK SIDE AIRBAG MODULE. 
    1. Turn the ignition switch to OFF, disconnect the battery ground terminal, and wait for 60 seconds or more. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
    2. Connect all connectors.
    3. Connect the battery ground terminal and turn the ignition switch to ON. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
    4. Using the Subaru Select Monitor, perform the clear memory of [Airbag]. Refer to COMMON (DIAG)>CLEAR MEMORY .
    5. Execute the inspection mode. Refer to AIRBAG (DIAGNOSTICS)>INSPECTION MODE .
    6. Read the DTC of [Airbag] using the Subaru Select Monitor. Refer to AIRBAG (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC B1828 displayed? (Current malfunction)

    Yes:  Replace the side airbag module LH. Refer to AIRBAG SYSTEM>SIDE AIRBAG MODULE>REMOVAL .

    No:  Go to  5.

  5. CHECK FOR ANY OTHER DTC ON DISPLAY. 

    Read the DTC of [Airbag] using the Subaru Select Monitor. Refer to AIRBAG (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is any other DTC displayed? (Current malfunction)

    Yes:  Perform the diagnosis for other displayed DTCs. Refer to AIRBAG (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Finish the diagnosis.
