Vehicle Information Registration (CROSSTREK Model Only)

Perform when replacing stereo camera. (Do not perform when performing stereo camera re-adjustment and inspection) Register the vehicle information according to the procedure of "Selection of Parameter", and confirm the vehicle information content in "Confirm on parameter".

PARAMETER SELECTION 

NOTE:
  • To check the applied model, refer to the "Model number plate" attached to the vehicle. Ref. to IDENTIFICATION .
  • If you entered a wrong applied model, you can re-write it.
  1. Connect the Subaru Select Monitor.
    NOTE: For detailed operation procedures, refer to "Help" of application.
  2. On [Start] screen, select [Diagnosis].
  3. On [Vehicle selection] screen, enter vehicle information and select [Confirmed].
  4. On [Main Menu] screen, select [Each System].
  5. On [Select System] screen, select [EyeSight], and then select [Enter].
  6. On [Select Function] screen, select [Work Support].
  7. On the work support item list, select [Selection of Parameter].
  8. Check the applied model and option code indicated on the "Model number plate". Ref. to IDENTIFICATION .
  9. Enter the applied model (alphanumeric characters) and press the Enter key.
  10. When the option code input screen appears after entering the applied model, enter the option code (alphanumeric characters), and press the Enter key.
  11. When the confirmation screen indicating the vehicle information appears, check that the correct applied model and option code are displayed and click the [OK] button.
NOTE: When the displayed applied model and option code are different from those of the vehicle, click the [OK] button and then perform the registration operation again. Note that checking the digit corresponding to option code is not required if "*" or "_" is displayed for option code.

PARAMETER CHECK 

NOTE: The parameter data registered in the stereo camera is shown on the display.
  1. Connect the Subaru Select Monitor.
    NOTE: For detailed operation procedures, refer to "Help" of application.
  2. On [Start] screen, select [Diagnosis].
  3. On [Select Vehicle] screen, enter vehicle information and select [Set].
  4. On [Main Menu] screen, select [Each System].
  5. On [Select System] screen, select [EyeSight], and then select [Enter].
  6. On [Select Function] screen, select [Work Support].
  7. On the work support item list, select [Confirm on parameter].
  8. On the [Confirm on parameter] screen, check that the applied model and option code for the relevant vehicle are displayed, and click the [OK] button.
  9. If the applied model and option code for the relevant vehicle are not displayed on the [Confirm on parameter] screen, perform parameter selection and registration.
NOTE: Note that checking the digit corresponding to option code is not required if "*" or "_" is displayed for option code.
