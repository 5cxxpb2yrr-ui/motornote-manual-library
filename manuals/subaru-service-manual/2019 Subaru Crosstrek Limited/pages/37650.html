Keyless Access With Push Button Start Check: Operation

  1. On [Start] display, select [Diagnosis].
  2. On [Select Vehicle] display, input the target vehicle information and select [OK].
  3. On [Main Menu] display, select [Each System].
  4. On [Select System] display, select [Keyless Access with Push Button Start], and then select [Next].
  5. On [Select Function] display, select [Work Support].
  6. On [Work Support] display, select [Keyless Access with Push Button Start Check].
  7. Select a transmitter to be checked.
    NOTE:
    • For detailed operation procedures, refer to "Help" of application.
    • For details on items, refer to the list. Refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS)>KEYLESS ACCESS WITH PUSH BUTTON START CHECK>LIST .
