Cruise Control System DTCS

Code Reference
11 This code is displayed without operating the CRUISE switch. Refer to CRUISE CONTROL (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH CANCEL CODE>11 .
12 This code is displayed without depressing the brake pedal. Refer to CRUISE CONTROL (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH CANCEL CODE>12 .
13 This code is displayed without depressing the clutch pedal. Refer to CRUISE CONTROL (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH CANCEL CODE>13 .
14 This code is displayed without shifting to neutral position. Refer to CRUISE CONTROL (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH CANCEL CODE>14 .
15 This code is displayed without operating the cancel switch. Refer to CRUISE CONTROL (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH CANCEL CODE>15 .
16 This code is displayed without operating the ignition switch. Refer to CRUISE CONTROL (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH CANCEL CODE>16 .
21 This code is displayed when the ignition switch is turned to ON without operating the cruise control command switch. Refer to CRUISE CONTROL (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH CANCEL CODE>21 .
22 Refer to CRUISE CONTROL (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH CANCEL CODE>22 .
24 This code is displayed with normal operation. Refer to CRUISE CONTROL (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH CANCEL CODE>24 .
31 Cruise in 2nd shift position or more. Refer to CRUISE CONTROL (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH CANCEL CODE>31 .
32 This code is displayed, though the vehicle speed is increased to the speed available for cruise set and set operation was performed again. Refer to CRUISE CONTROL (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH CANCEL CODE>32 .
34 This code is displayed when driving for a long period of time at higher speed than appropriate cruise set vehicle speed by operating accelerator pedal. In this case, the cruise setting is deactivated. Refer to CRUISE CONTROL (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH CANCEL CODE>34 .
35 This code is displayed when driving condition is not suitable for cruise control. Eliminate the probable cause, and perform the cruise set operation again. Refer to CRUISE CONTROL (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH CANCEL CODE>35 .
41 This code is displayed when driving condition is not suitable for cruise control. Eliminate the probable cause, and perform the cruise set operation again. Refer to CRUISE CONTROL (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH CANCEL CODE>41 .
