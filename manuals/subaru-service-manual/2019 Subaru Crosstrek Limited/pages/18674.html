Parking Brake Harness

  1. Install the electronic parking brake harness.

    Tightening torque: 

    Harness clamp: 18 N.m (1.8 kgf-m, 13.3 ft-lb)

  2. Install the fuel tank protector. Refer to FUEL INJECTION (FUEL SYSTEMS) (H4DO (HEV))>FUEL TANK PROTECTOR>REMOVAL .
  3. Install the rear seat cushion assembly. Refer to SEATS>REAR SEAT>INSTALLATION .
  4. Install the console box assembly.

    Tightening torque: 

    Console box: 6.5 N.m (0.7 kgf-m, 4.8 ft-lb)

  5. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY>GROUND TERMINAL REMOVAL OR INSTALLATION .
  6. Install the rear wheels.

Tightening torque: 

120 N.m (12.2 kgf-m, 88.5 ft-lb)
