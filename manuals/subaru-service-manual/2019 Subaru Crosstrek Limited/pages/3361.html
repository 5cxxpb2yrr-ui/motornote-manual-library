Instrument Panel Assembly: Installation

CAUTION:
  • The clips "C62" and "C63" shown in the figure may have different engaging forces. Always use the specified parts when installing.
  • Before handling the airbag system components, refer to "CAUTION" of "General Description" in "AIRBAG SYSTEM". Refer to AIRBAG SYSTEM>GENERAL DESCRIPTION>CAUTION .
  • When installing the cover - instrument panel side (a), make sure that the body side weather strip - flange front does not come inside the panel COMPL - instrument (b).
    Courtesy of SUBARU OF AMERICA, INC.
  • When reusing the tether clip on the upper part of the trim panel - front pillar UPR, check that there is no damage to the tether clip. If the tether clip is damaged, always replace it with a new tether clip. If the tether clip is damaged, its holding force is reduced and the trim panel - front pillar UPR may come off.
  • Do not reuse the tether clip removed from the upper part of the trim panel - front pillar UPR. Always replace with a new part.
  • Do not reuse the upper clips of the trim panel - center pillar UPR. Once the clip is removed, its holding force is reduced. Be sure to replace it with a new clip.
  1. Attach each part until the panel COMPL - instrument is assembled.
    NOTE: Method of installing insulator
    • Adhesive

      Use polyurethane adhesive. When assembling the instrument panel assembly, wait until the adhesive has evaporated to prevent filling of the smell in the compartment.

    • Double-sided tape

      Use commercial double-sided tape. (Use strong double-sided adhesive tape.)

  2. Install the beam COMPL - steering.
    1. Place the beam COMPL - steering on the vehicle, and check that the pins on both sides are inserted securely and the harness is routed properly. Connect each connector.
    2. Secure the beam COMPL - steering to the heater and cooling unit assembly.

      Tightening torque: 

      7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

    3. Install the ground bolt and fuse box.

      Tightening torque: 

      Ground bolt: 13 N.m (1.3 kgf-m, 9.6 ft-lb)

      Fuse box, relay box: 7.5N.m (0.8 kgf-m, 5.5 ft-lb)

    4. Temporarily tighten the bolts of the beam COMPL - steering.
    5. Tighten the adjuster portion (a) of the adjuster - clip space.

      Preparation tool: 

      Hexagon wrench: 8 mm (0.31 in)

      NOTE: When the TORX® bolt is tightened after setting the adjuster portion (a) of the adjuster - clip space to the free position, the adjuster is secured at the position where there is no gap to the body, and then the TORX® bolt is tightened.

      Tightening torque: 

      Adjuster - clip space: 0.8 - 4 N.m (0.08 - 0.4 kgf-m, 0.6 - 3 ft-lb)

    6. Tighten the beam COMPL - steering in the order from (b) to (e) to the specified torque.

      Preparation tool: 

      TORX® T40

      Tightening torque: 

      Refer to "COMPONENT" of "General Description". Refer to EXTERIOR/INTERIOR TRIM>GENERAL DESCRIPTION>COMPONENT>INSTRUMENT PANEL .

    Courtesy of SUBARU OF AMERICA, INC.
  3. Install the heat pump Control Module. (Hybrid model) Refer to AIR CONDITIONER (HEV)>CONTROL UNIT>INSTALLATION .
  4. Install the duct - rear floor.
  5. Install the column assembly - steering.

    Tightening torque: 

    Column assembly - steering: Refer to POWER ASSISTED SYSTEM (POWER STEERING)>GENERAL DESCRIPTION>COMPONENT>STEERING WHEEL AND COLUMN .

  6. Install the universal joint assembly - steering. Refer to POWER ASSISTED SYSTEM (POWER STEERING)>UNIVERSAL JOINT>INSTALLATION .
  7. Install the panel COMPL - instrument.
    CAUTION: Be careful not to allow the harness to be caught.
    1. Align the matching pins on the body side (three locations - one in the center and the remaining two on both sides) with the panel COMPL - instrument.
    2. Route each connector of the sunload sensor and multi-function display harnesses in the specified position.
    3. Secure the clamps of the speaker assembly - tweeter, sunload sensor and multi-function display harnesses.
  8. Install the sunload sensor and the grille - front defroster.
  9. Install the passenger's airbag module, and connect the connector.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  10. Install the switch assembly - combination and the cover assembly - _______column.
  11. Install the panel - starter SW and the push button ignition switch. (Model with keyless access with push button start)
  12. Install the cover - starter SW. (Model without keyless access with push button start)
  13. Install the combination meter assembly, the cover assembly - visor LWR, and the visor assembly - combination meter.
  14. Install the steering wheel. Refer to POWER ASSISTED SYSTEM (POWER STEERING)>STEERING WHEEL>INSTALLATION .
  15. Install the driver's airbag module. Refer to AIRBAG SYSTEM>DRIVER'S AIRBAG MODULE>INSTALLATION .
  16. Install the knee airbag module. Refer to AIRBAG SYSTEM>KNEE AIRBAG MODULE>INSTALLATION .
  17. Install the cover assembly - instrument panel LWR driver.
  18. Install the glove box assembly.
  19. Install the trim panel - front pillar UPR on the left and right sides.
  20. Install the grille speaker side on the left and right sides.
  21. Install the tray - center UPR and the panel center LWR.
  22. Install the heater control assembly.
  23. Install the panel center LWR on the left and right sides.
  24. Install the console box assembly.

    Tightening torque: 

    6.5 N.m (0.7 kgf-m, 4.8 ft-lb)

  25. Install the cover assembly - front.
  26. Install the mat - center tray and the tray - center LWR.
  27. Install the boot - hand brake. (Except for hybrid model)
  28. Install the multi-function display assembly.
  29. Install the audio assembly or navigation assembly.
  30. Install the panel - center UPR.
  31. Install the center grille assembly.
  32. Install the body side weather strip - flange front.
  33. Install the cover side sill - front on the left and right sides.
  34. Install the cover side sill - front INN on the left and right sides.
  35. Install the cover - instrument panel side on the left and right sides.
  36. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
    NOTE: For CVT models, after connecting the battery ground terminal, place the select lever in the P position.
