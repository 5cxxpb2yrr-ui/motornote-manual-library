Clutch Pipe And Hose: Installation

WARNING: This page is about a different variant/trim than selected.
  1. Install the clutch pipe to the mass damper, clutch damper, master cylinder and pipe grommet.
    CAUTION: Be sure to tighten the clutch pipe (D) temporarily.

    Tightening torque: 

    T: 15 N.m (1.5 kgf-m, 11.1 ft-lb)

    Courtesy of SUBARU OF AMERICA, INC.
  2. Install the clutch pedal assembly. Refer to CLUTCH SYSTEM>CLUTCH PEDAL>INSTALLATION .
  3. Install the tank hose.
    CAUTION: Be sure to install so that the side with the triangle mark faces upward.
    Courtesy of SUBARU OF AMERICA, INC.
  4. Temporarily install the two-way connector and the clutch connector bracket, and engage the clutch pipe.
    Courtesy of SUBARU OF AMERICA, INC.
  5. Install the two-way connector and the clutch connector bracket.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

    Courtesy of SUBARU OF AMERICA, INC.
  6. Tighten the clutch pipe.

    Tightening torque: 

    15 N.m (1.5 kgf-m, 11.1 ft-lb)

    Courtesy of SUBARU OF AMERICA, INC.
  7. Install the steering column. Refer to POWER ASSISTED SYSTEM (POWER STEERING)>STEERING COLUMN>INSTALLATION .
  8. Replace the gasket with a new part, and install the clutch hose to the operating cylinder.
    CAUTION: Be sure to install with the marking side facing upward.

    Tightening torque: 

    18 N.m (1.8 kgf-m, 13.3 ft-lb)

  9. Connect the clutch hose, and install the clamp.
    CAUTION:
    • Be sure to install the clutch hose with the marking side facing upward.
    • Install the clutch hoses while making sure that there is no twisting.
    Courtesy of SUBARU OF AMERICA, INC.
  10. Install the clutch hose bracket.

    Tightening torque: 

    25 N.m (2.5 kgf-m kgf-m, 18.4 ft-lb)

  11. Install the clutch pipe.

    Tightening torque: 

    T: 15 N.m (1.5 kgf-m, 11.1 ft-lb)

    Courtesy of SUBARU OF AMERICA, INC.
  12. Install the vacuum pipe & hose assembly.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

    Courtesy of SUBARU OF AMERICA, INC.
  13. Add the recommended brake fluid. Refer to CLUTCH SYSTEM>CLUTCH FLUID .
  14. Bleed air from the clutch system, and ensure that no fluid leaks. Refer to CLUTCH SYSTEM>CLUTCH FLUID AIR BLEEDING>PROCEDURE .
  15. Adjust the clutch pedal. Refer to CLUTCH SYSTEM>CLUTCH PEDAL>ADJUSTMENT .
  16. Install the instrument panel lower cover. Refer to EXTERIOR/INTERIOR TRIM>INSTRUMENT PANEL LOWER COVER>INSTALLATION .
  17. Install the air intake boot. Refer to INTAKE (INDUCTION) (H4DO (EXCEPT FOR HEV))>Air Intake Boot>INSTALLATION .
  18. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
