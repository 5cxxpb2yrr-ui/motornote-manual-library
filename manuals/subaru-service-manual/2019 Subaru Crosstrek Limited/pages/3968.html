Door Latch & Door Lock Actuator Assembly: Installation: Front

  1. Before installation, check the following items.
    • Cable and rod are free from deformation.
    • Grease is applied sufficiently to cable and rod joints.

      If grease is insufficient, add it as necessary before assembling the cable and rod.

  2. Install the latch and actuator assembly - front.
    CAUTION:
    • Do not re-use the screws. Always replace with a new part.
    • Insert the rod of the latch & actuator assembly - front into the frame assembly - front door outer, and connect using the rod clamp.

    Preparation tool: 

    TORX® T30

    Tightening torque: 

    6.5 N.m (0.7 kgf-m, 5.2 ft-lb)

  3. Install the sash COMPL - lower.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  4. Install the plate - door UPR.
  5. Install the sealing cover - front door.
  6. Install the trim panel - front door.
  7. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
