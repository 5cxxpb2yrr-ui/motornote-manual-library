DTC P0400: EGR "A" Flow: Notes

WARNING: This page is about a different variant/trim than selected.

1. - 

DTC detecting condition: 

Detected when two consecutive driving cycles with fault occur.

Trouble symptom: 

  • Movement performance problem when engine is low speed
  • Improper idling
  • Movement performance problem
NOTE: After the faulty parts are repaired or replaced, perform the final check in Basic Diagnostic Procedure. Refer to ENGINE (DIAGNOSTICS) (H4DO (HEV))>BASIC DIAGNOSTIC PROCEDURE>PROCEDURE .
  1. CHECK DATA MONITOR  .
    1. Turn the ignition switch to ON.
    2. Navigate to Inspection Mode for measuring Exhaust Gas. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>Work Support>OPERATION>SERVICE MODE .
      NOTE: If it is necessary to run the engine for 10 minutes or more, fasten the driver's seat belt.
    3. Start the engine.
    4. Using the Subaru Select Monitor, read the value in [Mani. Absolute Pressure].
      NOTE: For detailed operation procedures, refer to "Data Monitor". Refer to COMMON (DIAG)>DATA MONITOR .

    Is the value of [Mani. Absolute Pressure] 53.3 kPa (400 mmHg, 15.74 inHg, 7.73 psi) or more?

    Yes:  Make sure that the EGR control valve, manifold absolute pressure sensor and throttle body are installed securely.

    No:  Go to  2.

  2. CHECK EGR CONTROL VALVE  .

    Remove the EGR control valve.

    Are there any holes, clogged lines or foreign matters in the EGR system?

    Yes:  Repair the EGR system.

    No:  Replace EGR control valve. Refer to EMISSION CONTROL (AUX. EMISSION CONTROL DEVICES) (H4DO (HEV))>EGR CONTROL VALVE .
