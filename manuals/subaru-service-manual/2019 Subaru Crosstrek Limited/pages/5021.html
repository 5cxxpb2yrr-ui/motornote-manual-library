DTC C1A3E: Right Front Wheel Speed Sensor Supply Voltage: Notes

1. - 

DTC detecting condition: 

Power supply failure signal (CAN value) of a wheel speed sensor is input when communication from VDC has been established.

Trouble symptom: 

  • Regenerative brake cannot be controlled.
  • Brake assist does not operate.
  • EyeSight functions (ACC/PCS) do not operate.

Wiring diagram: 

Electronic controlled brake system Ref. to WIRING SYSTEM (CROSSTREK MODEL (HEV))>ELECTRIC CONTROL BRAKE SYSTEM .

Courtesy of SUBARU OF AMERICA, INC.
  1. CHECK DATA MONITOR. 

    Display the following items in [Data monitor] using Subaru Select Monitor. Ref. to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>DATA MONITOR .

    • [Speed sensor FR abnormality flag]
    • [Speed sensor FL abnormality flag]
    • [Speed sensor RR abnormality flag]
    • [Speed sensor RL abnormality flag]

    Is the displayed data [Abnormal]?

    Yes:  Go to  4.

    No:  Go to  2.

  2. CHECK DTC OF EBB Control Module. 

    Read the DTC of [Electric Brake Booster] using the Subaru Select Monitor. Ref. to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are the same DTCs (C1A3E/C1A4E/C1A5E/C1A6E) displayed?

    Yes:  Go to  3.

    No:  Currently, it is normal. There may have been a temporary poor contact in the harness and connector or a temporary noise interference.

  3. CHECK CONNECTOR. 

    Check the connecting condition of the intermediate connectors (AD81, B652) and VDC CM.

    Is there looseness, deformation, or corrosion at the connectors?

    Yes:  Repair or replace the connector.

    No:  Go to  4.

  4. CHECK DTC OF VDC CM. 

    Read the DTC of [Brake Control] using the Subaru Select Monitor. Ref. to BRAKE CONTROL (DIAGNOSTICS) (HEV)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed?

    Yes:  Perform the diagnosis according to DTC. Ref. to BRAKE CONTROL (DIAGNOSTICS) (HEV)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Go to  5.

  5. CHECK DTC OF EBB Control Module. 
    1. Connect all connectors.
    2. Using the Subaru Select Monitor, perform the clear memory. Ref. to COMMON (DIAG)>CLEAR MEMORY .
    3. Read the DTC of [Electric Brake Booster] using the Subaru Select Monitor. Ref. to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are the same DTCs (C1A3E/C1A4E/C1A5E/C1A6E) displayed as current malfunction?

    Yes:  Replace the brake booster assembly (with the master cylinder). Ref. to BRAKE>BRAKE BOOSTER .

    No:  Go to  6.

  6. CHECK DETECTION OF OTHER DTCS FOR EBB Control Module. 

    Read the DTC using Subaru Select Monitor. Ref. to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is any other DTC displayed?

    Yes:  Perform the diagnosis according to DTC. Ref. to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Currently, it is normal. There may have been a temporary poor contact in the harness and connector or a temporary noise interference.
