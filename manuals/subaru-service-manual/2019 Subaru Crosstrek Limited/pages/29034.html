Inspection Mode AM

WARNING: This page is about a different variant/trim than selected.
DTC Item Condition Number of driving cycles on the detecting condition
P0071 AMBIENT AIR TEMPERATURE SENSOR CIRCUIT "A" RANGE/PERFORMANCE 6 hours or more have elapsed since ignition switch is OFF under a completely warmed up condition. 2
P0111 INTAKE AIR TEMPERATURE SENSOR 1 CIRCUIT RANGE/PERFORMANCE BANK 1 2
P0116 ENGINE COOLANT TEMPERATURE SENSOR 1 CIRCUIT RANGE/PERFORMANCE 2
P0196 ENGINE OIL TEMPERATURE SENSOR "A" RANGE/PERFORMANCE 2
P040B EGR TEMPERATURE SENSOR "A" CIRCUIT RANGE/PERFORMANCE 2
P050A COLD START IDLE CONTROL SYSTEM PERFORMANCE - 2
P050B COLD START IGNITION TIMING PERFORMANCE - 2
P24B9 EVAP SYSTEM LEAK DETECTION PUMP PRESSURE SENSOR CIRCUIT RANGE/PERFORMANCE 60 seconds or more have elapsed since ignition switch is OFF. 2
  1. Check that the battery voltage is 12 V or more and fuel remains approx. half [20 - 40 L (5.3 - 10.6 US gal, 4.4 - 8.8 Imp gal)].
  2. Using the Subaru Select Monitor, clear the memory of [Engine Control System]. Refer to COMMON (DIAG)>CLEAR MEMORY .
  3. With the ignition switch ON (engine stopped), read the values in [Engine Coolant Temperature] and [Intake Air Temperature] using the Subaru Select Monitor. Refer to ENGINE (DIAGNOSTICS) (H4DO (HEV))>DATA MONITOR .
  4. If the values from step 3) satisfy the following conditions, navigate to Inspection Mode for measuring Exhaust Gas. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>Work Support>OPERATION>SERVICE MODE .

    Condition: 

    | Engine coolant temperature - Intake air temperature | 5°C (9°F) or more

    NOTE:
    • If the conditions are not satisfied, turn the ignition switch to OFF and wait until the parameters are satisfied.
    • Hold the select lever in "P" range or "N" range during engine start.
    • If it is necessary to run the engine for 10 minutes or more, fasten the driver's seat belt.
  5. Start the engine and wait for 30 seconds.
  6. Read the temporary code using the Subaru Select Monitor or general scan tool. Refer to COMMON (DIAG)>DIAGNOSTIC TROUBLE CODE (DTC) .
