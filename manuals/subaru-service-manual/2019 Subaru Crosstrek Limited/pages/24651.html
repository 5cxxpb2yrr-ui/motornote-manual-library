Diagnostic Method

WARNING: This page is about a different variant/trim than selected.

Diagnosis 1 

If the duration of time while the following conditions are met is longer than the time indicated, judge as NG.

JUDGMENT VALUE SPECIFICATION

Malfunction Criteria Threshold Value
Number of camshaft position sensor signals during cranking 0

Diagnosis 2 

Judge as NG if there is no input signal from the camshaft position sensor for 4 ((10time(s)+2)/3) engine revs.

JUDGMENT VALUE SPECIFICATION

Malfunction Criteria Threshold Value
Amount of camshaft position sensor signals during 0.5 revs of crankshaft 0

Time needed for diagnosis: 

Diagnosis 1 

3000 ms

Diagnosis 2 

Engine speed: 4 engine revs.

Malfunction indicator light illumination:  Illuminates as soon as a malfunction occurs.
