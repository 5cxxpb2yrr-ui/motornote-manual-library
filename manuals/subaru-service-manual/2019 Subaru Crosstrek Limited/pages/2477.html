Engine Will Not Start

Probable cause: 

The vehicle is in the Stolen Vehicle Recovery + state.

CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to TELEMATICS SYSTEM (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK STOLEN VEHICLE RECOVERY +. 

    Using Subaru Select Monitor, check the following items with [Data monitor] of [Body Control] for models without Keyless Access with Push Button Start, and with [Data monitor] of [Keyless Access with Push Button Start] for models with Keyless Access with Push Button Start. Refer to BODY CONTROL (DIAGNOSTICS)>DATA MONITOR . Refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS)>DATA MONITOR .

    • Body Control
      • Immobilizer Set Memory
    • Keyless Access with Push Button Start
      • Immobilizer Set Memory

    Is [Set] displayed?

    Yes:  Have the customer contact the call center to release the lock.

    No:  Perform inspection according to the diagnosis of engine. Refer to ENGINE (DIAGNOSTICS) (H4DO (EXCEPT FOR HEV))>BASIC DIAGNOSTIC PROCEDURE>PROCEDURE .
