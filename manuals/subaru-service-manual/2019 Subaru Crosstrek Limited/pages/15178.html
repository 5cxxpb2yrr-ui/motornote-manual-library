HVAC System (Heater, Ventilator And A/C) (Except For HEV): Evaporator: Installation

CAUTION:
  • Since the auto A/C model uses the variable displacement compressor, be careful of the following items.
    • Do not start the engine before charging refrigerant.
    • If the engine is started with no refrigerant charge, replace the compressor assembly.
  • If the evaporator has been replaced, add an appropriate amount of compressor oil to the compressor. Refer to AIR CONDITIONER (EXCEPT FOR HEV)>COMPRESSOR OIL>ADJUSTMENT .
  • Replace the O-rings with new parts, and then apply compressor oil to install completely.
  • Before handling the airbag system components, refer to "CAUTION" of "General Description" in "AIRBAG SYSTEM". Refer to AIRBAG SYSTEM>GENERAL DESCRIPTION>CAUTION .
  1. Install the evaporator sensor to the specified location. Refer to AIR CONDITIONER (EXCEPT FOR HEV)>EVAPORATOR SENSOR>INSTALLATION .
  2. Install the evaporator assembly - cooling.
  3. Install the case assembly - heater unit.
  4. Install the cover - evaporator.
  5. Install the bracket - cable. (Manual A/C model)
  6. Install the motor - actuator mix LH and RH. (Auto A/C model) Refer to AIR CONDITIONER (EXCEPT FOR HEV)>AIR MIX DOOR ACTUATOR>INSTALLATION .
  7. Attach the heater core. Refer to AIR CONDITIONER (EXCEPT FOR HEV)>HEATER CORE>INSTALLATION .
  8. Install the heater and cooling unit assembly. Refer to AIR CONDITIONER (EXCEPT FOR HEV)>HEATER AND COOLING UNIT>INSTALLATION .
  9. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
  10. Charge refrigerant. Refer to AIR CONDITIONER (EXCEPT FOR HEV)>REFRIGERANT CHARGING PROCEDURE>PROCEDURE .
  11. Fill engine coolant. Refer to COOLING (H4DO (EXCEPT FOR HEV))>ENGINE COOLANT>REPLACEMENT>FILLING OF ENGINE COOLANT .
