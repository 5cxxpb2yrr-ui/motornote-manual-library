Hybrid Model

NOTE: The electric brake booster control module (EBB Control Module) is integrated with the master cylinder.
  1. Check and adjust the operating rod of the electric brake booster control module (EBB Control Module).
    1. Measure the length between the electric brake booster control module (EBB Control Module) mounting service and clevis pin hole.
    2. If it is not the standard value, loosen the lock nut and adjust by rotating the electric brake booster control module (EBBCM) operating rod.

      Specification L: 

      134.7 mm (5.3 in)

    Courtesy of SUBARU OF AMERICA, INC.
  2. Install the electric brake booster control module (EBB Control Module).

    Tightening torque: 

    18 N.m (1.8 kgf-m, 13.3 ft-lb)

    CAUTION:
    • Apply grease to the snap pin to prevent the operating rod from wear.
    • Replace the clevis pin with a new part, and apply a thin coat of grease to the clevis pin.

    Preparation items: 

    Grease (clevis pin): IDEMITSU APOLLOIL AUTOLEX A or equivalent 

  3. Install the hybrid powertrain control module. Refer to HYBRID ELECTRIC VEHICLE>HYBRID POWERTRAIN CONTROL MODULE>INSTALLATION .
  4. Install the duct - foot driver. Refer to AIR CONDITIONER (EXCEPT FOR HEV)>HEATER DUCT>INSTALLATION>FOOT>LH SIDE .
  5. Install the column assembly - steering. Refer to POWER ASSISTED SYSTEM (POWER STEERING)>STEERING COLUMN>INSTALLATION .
  6. Install the universal joint assembly - steering. Refer to POWER ASSISTED SYSTEM (POWER STEERING)>UNIVERSAL JOINT>INSTALLATION .
    CAUTION:
    • Always install the universal joint assembly - steering after installing the steering column to avoid damage to the universal joint assembly - steering.
    • Be sure to follow the tightening order and tightening torque of the universal joint assembly - steering to avoid the steering effort from becoming heavy. After confirming that the steering column position is in the neutral position, tighten the universal joint assembly - steering.
    • Always place the tilt lever to the lock position after the steering column is adjusted.
  7. Install the knee airbag module.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  8. Install the cover assembly - instrument panel LWR driver.
  9. Install the brake pipe assembly and reservoir joint pipe.

    Tightening torque: 

    Refer to "COMPONENT" of "General Description" for the tightening torque. Refer to BRAKE>GENERAL DESCRIPTION>COMPONENT .

  10. Install the bracket - adapter cord.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  11. Install the connectors and clips of the adapter cord.
  12. Install the engine control module (ECM). Refer to FUEL INJECTION (FUEL SYSTEMS) (H4DO (HEV))>ENGINE CONTROL MODULE (ECM)>INSTALLATION .
  13. Disconnect the reservoir joint pipe from the brake accumulator assembly.
    Courtesy of SUBARU OF AMERICA, INC.
  14. Install the reservoir joint pipe to the brake accumulator assembly.
    1. Remove the nuts securing the reservoir joint pipe.
      Courtesy of SUBARU OF AMERICA, INC.
    2. Raise the reservoir joint hose B so that the hose end becomes higher than the reservoir tank.
      Courtesy of SUBARU OF AMERICA, INC.
    3. Remove the cap - reservoir tank, and add the brake fluid.
    4. Confirm that the brake fluid flows out, and install the reservoir joint hose B to the brake accumulator assembly.
    5. Install the nuts securing the reservoir joint pipe.

      Tightening torque: 

      7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  15. Bleed air from the reservoir joint pipe. Refer to BRAKE>AIR BLEEDING>PROCEDURE>RESERVOIR JOINT PIPE (HYBRID MODEL) .
  16. Install the air intake boot. Refer to INTAKE (INDUCTION) (H4DO (EXCEPT FOR HEV))>Air Intake Boot>INSTALLATION .
  17. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
  18. Bleed air from the brake system. Refer to BRAKE>AIR BLEEDING>PROCEDURE>BRAKE SYSTEM (HYBRID MODEL) .
  19. Bleed air from the brake line. Refer to BRAKE>AIR BLEEDING>PROCEDURE>BRAKE LINE (HYBRID MODEL) .
  20. Install the front and rear wheels.

    Tightening torque: 

    120 N.m (12.2 kgf-m, 88.5 ft-lb)

  21. Erase the backup memory. Refer to BRAKE>BRAKE SYSTEM>OPERATION>BACK-UP MEMORY CLEARING .
  22. Perform linear valve offset learning. Refer to BRAKE>BRAKE SYSTEM>OPERATION>LINEAR VALVE OFFSET LEARNING .
  23. Perform a road test to make sure the brakes do not drag.
