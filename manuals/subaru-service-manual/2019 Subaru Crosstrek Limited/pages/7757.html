Oil Level Switch: Installation

  1. Use a new O-ring to install the oil level switch, and install the clip to the oil pan upper.
    NOTE: Apply engine oil to O-ring.

    Tightening torque: 

    6.4 N.m (0.7 kgf-m, 4.7 ft-lb)

  2. Connect the connector and install the clip.
  3. Install the engine mounting LH.

    Tightening torque: 

    35 N.m (3.6 kgf-m, 25.8 ft-lb)

  4. Lower the engine and remove the lifting device and wire ropes.
  5. Remove the ST. (Except for hybrid model)
  6. Install the electric power steering gearbox. Refer to POWER ASSISTED SYSTEM (POWER STEERING)>ELECTRIC POWER STEERING GEARBOX>INSTALLATION .
  7. Install the nuts which hold the engine mounting to the front crossmember. (CVT model)
    CAUTION: Use new nuts.
    NOTE: Make sure that locators (a) of the engine mounting are securely inserted.

    Tightening torque: 

    90 N.m (9.2 kgf-m, 66.4 ft-lb)

    Courtesy of SUBARU OF AMERICA, INC.
  8. Install the nuts which hold the engine mounting to the front crossmember. (MT model)
    CAUTION: Use new nuts.

    Tightening torque: 

    90 N.m (9.2 kgf-m, 66.4 ft-lb)

  9. Install the front exhaust pipe. Refer to EXHAUST (H4DO (EXCEPT FOR HEV))>FRONT EXHAUST PIPE>INSTALLATION .
  10. Install the A/C accumulator assembly. (Hybrid model) Refer to AIR CONDITIONER (HEV)>ACCUMULATOR>INSTALLATION .
  11. Install the transmission harness in original position. (Except for hybrid model (CVT model))

    Tightening torque: 

    7 N.m (0.7 kgf-m, 5.2 ft-lb)

  12. Install the TCM. (Except for hybrid model (CVT model)) Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSMISSION CONTROL MODULE (TCM)>INSTALLATION .
  13. Install the transmission bracket. (Hybrid model)

    Tightening torque: 

    8 N.m (0.8 kgf-m, 5.9 ft-lb)

  14. Install the pitching stopper. (MT model and hybrid model)

    5MT model: 

    Refer to MANUAL TRANSMISSION AND DIFFERENTIAL (5MT)>TRANSMISSION MOUNTING SYSTEM>INSTALLATION>PITCHING STOPPER .

    6MT model: 

    Refer to MANUAL TRANSMISSION AND DIFFERENTIAL (6MT)>TRANSMISSION MOUNTING SYSTEM>INSTALLATION>PITCHING STOPPER .

    Hybrid model: 

    Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TH2A)>TRANSMISSION MOUNTING SYSTEM>INSTALLATION>PITCHING STOPPER .

  15. Install the air intake boot. Refer to INTAKE (INDUCTION) (H4DO (EXCEPT FOR HEV))>Air Intake Boot>INSTALLATION .
  16. Install the air intake duct.
  17. Install the V-belt cover. (Except for hybrid model)

    Tightening torque: 

    7 N.m (0.7 kgf-m, 5.2 ft-lb)

  18. Install the collector cover. (Hybrid model) Refer to INTAKE (INDUCTION) (H4DO (EXCEPT FOR HEV))>COLLECTOR COVER>INSTALLATION .
  19. Fill engine oil. Refer to LUBRICATION (H4DO (EXCEPT FOR HEV))>ENGINE OIL>REPLACEMENT .
  20. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
  21. Charge refrigerant. (Hybrid model) Refer to AIR CONDITIONER (HEV)>REFRIGERANT CHARGING PROCEDURE>PROCEDURE .
  22. Set the front hood to the normal position. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>FRONT HOOD STAY .
  23. Install the striker - front hood. Refer to EXTERIOR BODY PANELS>FRONT HOOD>ASSEMBLY .
