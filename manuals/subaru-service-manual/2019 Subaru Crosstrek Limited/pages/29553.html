Diagnostic Procedure for Subaru Select Monitor Communication: Inspection

WARNING: This page is about a different variant/trim than selected.

Communication error with stereo camera

Detecting condition: 

  • Defective connector
  • Power supply circuit malfunction
  • Defective stereo camera
  • Defective CAN system
  • Defective Subaru Select Monitor

Trouble symptom: 

  • EyeSight warning light blinks.

Wiring diagram: 

CAN communication system Refer to WIRING SYSTEM (CROSSTREK MODEL (HEV))>CAN COMMUNICATION SYSTEM>WIRING DIAGRAM .

EyeSight system Refer to WIRING SYSTEM (CROSSTREK MODEL (HEV))>EYESIGHT SYSTEM>WIRING DIAGRAM .

Courtesy of SUBARU OF AMERICA, INC.
CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to EYESIGHT (DIAGNOSTICS) (HEV)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK SUBARU SELECT MONITOR. 
    1. Connect the Subaru Select Monitor to another vehicle.
    2. Check communication condition between Subaru Select Monitor and vehicle.

    Is communication performed normally?

    Yes:  Go to  2.

    No:  Subaru Select Monitor unit or diagnosis cable is faulty.

  2. CHECK COMMUNICATION FOR INITIALIZING ERROR. 

    Perform the communication for initializing with each module by connecting the Subaru Select Monitor. (For systems whose module can communicate with diagnostic devices)

    NOTE: By performing [CAN bus check], confirmation of minimal connection modules is possible. Refer to LAN SYSTEM (DIAGNOSTICS) (HEV)>CAN BUS CHECK .

    Is the communication possible with all modules?

    Yes:  The circuit has returned to a normal condition at this time.

    NOTE: In this case, temporary poor contact of connector, temporary open or short circuit of harness may be the cause.

    No:  When the communication fails with all modules, Go to  3.

    When the communication fails with particular module only, perform the inspection using the check sheet of communication for initializing. Refer to LAN SYSTEM (DIAGNOSTICS) (HEV)>DIAGNOSTIC PROCEDURE FOR SUBARU SELECT MONITOR COMMUNICATION>INSPECTION>CHECK USING THE CHECK SHEET OF COMMUNICATION FOR INITIALIZING

  3. CHECK DATA LINK CONNECTOR (OPEN CIRCUIT). 

    Use a tester to check for continuity in the ground circuit.

    Connector & terminal 

    (i288) No. 4 - Chassis ground:

    (i288) No. 5 - (B134) No. 50:

    Is there continuity?

    Yes:  Go to  4.

    No:  Repair or replace the open circuit.

  4. CHECK SUBARU SELECT MONITOR COMMUNICATION. 
    1. Turn the ignition switch to ON.
    2. Using a tester, check the power supply of data link connector.

      Connector & terminal 

      (i288) No. 8 (+) - Chassis ground (-):

      (i288) No. 16 (+) - Chassis ground (-):

    Is the voltage 10 V or more?

    Yes:  The circuit has returned to a normal condition at this time. Reproduce the failure, and then perform the diagnosis again.

    NOTE: In this case, temporary poor contact of connector, temporary open or short circuit of harness may be the cause.

    No:  Check the power supply circuits to the data link connector. (Including the fuses)
