DTC B281E: RAB Control Module

Detected when error occurs in sonar or RAB Control Module.

DTC detecting condition: 

  • Defective RAB Control Module.
  • Defective unit that is cooperatively controlled with stereo camera.

Trouble symptom: 

  • The Reverse Automatic Braking function does not operate.
  • RAB warning light illuminates.
  • All functions of EyeSight system do not operate. (Functions terminated due to a cooperative control unit failure)
  • EyeSight warning light illuminates. (Functions terminated due to a cooperative control unit failure)
CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to EYESIGHT (DIAGNOSTICS) (EXCEPT FOR HEV)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK DTCS (DETERMINING A FAILURE OF COOPERATIVE CONTROL UNIT). 

    Read the DTC of [EyeSight] using the Subaru Select Monitor. Refer to EYESIGHT (DIAGNOSTICS) (EXCEPT FOR HEV)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC other than DTC B281E displayed?

    Yes:  Perform the diagnosis for DTC other than DTC B281E.

    No:  Go to  2.

  2. CHECK DTC. 

    Read the DTC of [Reverse Automatic Braking] using the Subaru Select Monitor. Refer to REVERSE AUTOMATIC BRAKING (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed?

    Yes:  Perform the diagnosis for the displayed DTCs. Refer to REVERSE AUTOMATIC BRAKING (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    No:  Finish the diagnosis.
