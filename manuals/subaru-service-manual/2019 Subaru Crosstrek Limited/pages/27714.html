Monitor Description

WARNING: This page is about a different variant/trim than selected.

The Motor generator control ECU performs diagnostic tests to verify proper operation of internal unit systems. In one of those tests, the Motor generator control ECU checks for an R/D (Resolver/Digital converter) malfunction involving the motor resolver. If the Motor generator control ECU motor generator control module detects an R/D converter error, it will conclude that there is an internal malfunction involving the motor resolver. The Motor generator control ECU will illuminate the MIL and set a DTC.
