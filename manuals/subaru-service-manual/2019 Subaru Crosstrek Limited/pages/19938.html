Event Record Data: Operation

  1. On [Start] display, select [Diagnosis].
  2. On [Vehicle selection] display, input the target vehicle information and select [OK].
  3. On [Main Menu] display, select [Each System].
  4. On [Select System] display, select [Airbag], and then select [Enter].
  5. On [Airbag] display, select [Work Support].
  6. On [[Work Support item]] display, select [Event Record Data]. After it is selected, [IMPORTANT NOTICE] screen is displayed.
  7. After checking the content of [IMPORTANT NOTICE], click the checkbox for "Yes".
  8. If the applicable law is not violated, click the [Yes] button to display the EDR data.
    Courtesy of SUBARU OF AMERICA, INC.
  9. Select the items to be checked from each event record data.
  10. Select the record data to be checked from each record data.
  11. The selected record data is displayed. When no EDR data is recorded, [Event Record Data is not recorded] will be displayed.
  12. Select [Exit] to return to each event record data screen.
