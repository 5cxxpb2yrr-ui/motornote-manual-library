Active Test: Operation

Do you like it dark? Easier on the eyes.

  1. On [Start] screen, select [Diagnosis].
  2. On [Vehicle selection] screen, input the target vehicle information and select [OK].
  3. On [Main Menu] screen, select [Each System].
  4. On [Select System] screen, select [Pedestrian Alert], and then select [Enter].
  5. On [Select Function] screen, select [Active Test].
    NOTE: For detailed operation procedures, refer to "Help" of application.
