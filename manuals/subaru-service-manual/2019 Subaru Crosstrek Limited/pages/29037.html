WARNING: When performing inspection mode AP a public road, pay sufficient attention to the traffic condition and give the highest priority to safe driving.
CAUTION: Performing inspection mode needs a driver along with a checker who should check AP the data.
NOTE: Even if switched to the hybrid battery save mode under the following conditions, the engine may not start.
  • Power from HV battery is low and reduction in SOC is slight.
  • SOC is recovering due to regeneration, etc.
  1. Check that the battery voltage is 12 V or more and fuel remains approx. half [20 - 40 L (5.3 - 10.6 US gal, 4.4 - 8.8 Imp gal)].
  2. Warm up the engine until [Engine Coolant Temperature] reaches 70°C (158°F) or more.
  3. Using the Subaru Select Monitor, clear the memory of [Engine Control System]. Refer to COMMON (DIAG)>CLEAR MEMORY .
  4. Drive according to the drive pattern described below.

    *: For details concerning learning and diagnostic values, refer to MODE $06 (Request on-board monitoring test results for intermittently monitored systems). Refer to ENGINE (DIAGNOSTICS) (H4DO (HEV))>GENERAL SCAN TOOL>OPERATION>MODE $06 (REQUEST ON-BOARD MONITORING TEST RESULTS FOR INTERMITTENTLY MONITORED SYSTEMS) .

    NOTE:
    • In pattern (D), it is acceptable to stop the vehicle depending on the traffic conditions. Drive the vehicle with the accelerator opening angle of 0% ←→ 15% (10 seconds) for an accumulated duration of 20 minutes or more.
    • The condition of acceleration or constant driving can be changed according to different traffic conditions.
    • Always keep on checking the data while reading out the diagnostic value because the diagnostic value is repeatedly updated.
    • If diagnostic values have not been input after driving, repeat the cycle from diagnosis 4 without stopping the engine.
  5. Read the temporary code using the Subaru Select Monitor or general scan tool. Refer to COMMON (DIAG)>DIAGNOSTIC TROUBLE CODE (DTC) .
