Trunk Lid Latch and Actuator Assembly: Installation

  1. Install the lock assembly - trunk lid.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  2. Install the cable assembly - trunk lid.
  3. Install the trim panel - trunk lid.
  4. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
