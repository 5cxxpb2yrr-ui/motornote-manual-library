DTC P0D3D-17: Hybrid/EV Battery Charger Input Voltage Sensor For Control Circuit Voltage Above Threshold: Notes

WARNING: This page is about a different variant/trim than selected.

Outline of diagnosis: 

VAC sensor output voltage exceeded the threshold value.

(1 trip detection logic)

Trouble symptom: 

Plug-in charging suspended

NOTE: For the diagnostic procedure, refer to DTC P0D3D16. Refer to PLUG-IN BATTERY CHARGER (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC P0D3D16 HYBRID/EV BATTERY CHARGER INPUT VOLTAGE SENSOR FOR CONTROL CIRCUIT VOLTAGE BELOW THRESHOLD .
