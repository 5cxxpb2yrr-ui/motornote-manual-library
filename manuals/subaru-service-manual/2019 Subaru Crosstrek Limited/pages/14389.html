DTC P0D3D-16: Hybrid/EV Battery Charger Input Voltage Sensor For Control Circuit Voltage Below Threshold: Notes

WARNING: This page is about a different variant/trim than selected.

Outline of diagnosis: 

VAC sensor output voltage was smaller than the threshold value.

(1 trip detection logic)

Trouble symptom: 

Plug-in charging suspended

NOTE: For the diagnostic procedure, refer to DTC P0D2A19. Refer to PLUG-IN BATTERY CHARGER (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC P0D2A19 HYBRID/EV BATTERY CHARGER INPUT CURRENT SENSOR CIRCUIT CIRCUIT CURRENT ABOVE THRESHOLD .
