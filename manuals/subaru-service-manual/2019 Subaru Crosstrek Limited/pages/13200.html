DTC C2821: Wheel Position Sensing Abnormal

Do you like it dark? Easier on the eyes.

DTC detecting condition  :

When the position detection does not finish and fails 10 times in a row.

Trouble symptom: 

Pressure monitor display of the combination meter indicates "-".

CAUTION:
  • When driving vehicle to perform driving test, there should be always 2 persons (driver and checker) to check.
  • Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to TIRE PRESSURE MONITOR (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK DRIVING HISTORY. 

    Ask the customer about the following items.

    • Did the customer drive in a traffic congestion?
    • Did the customer drive on rough road (such as unpaved road)?

    Did the customer drive in a traffic congestion or on rough road?

    Yes:  When the vehicle is driven in a traffic congestion or on rough road, this DTC may be recorded.

    No:  Go to  2.

  2. REPRODUCTION OF FAILURE. 
    1. Perform the drive test.

      Drive the vehicle at 40 km/h (25 MPH) or faster for at least 10 minutes.

    2. Read the DTC of [Tire Pressure Monitor] using the Subaru Select Monitor. Refer to TIRE PRESSURE MONITOR (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC displayed as current malfunction?

    Yes:  Go to  3.

    No:  When DTC is displayed as "Past faults", the system has returned to a normal condition at this time. Reproduce the failure, and then perform the diagnosis again.

    NOTE: In this case, there may be temporary poor communication due to radio wave environment inside/outside the vehicle.
  3. CHECK DTC. 

    Read the DTC of [Tire Pressure Monitor] using the Subaru Select Monitor. Refer to TIRE PRESSURE MONITOR (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is any DTC other than DTC C2821 displayed as current malfunction?

    Yes:  Perform the diagnosis for DTCs other than the displayed DTC C2821. Refer to TIRE PRESSURE MONITOR (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Go to  4.

  4. CHECK VDC. 

    Read the DTC of [Brake Control] using the Subaru Select Monitor. Refer to BRAKE CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC displayed as current malfunction?

    Yes:  Perform the diagnosis for the displayed DTCs. Refer to BRAKE CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Go to  5.

  5. CHECK TCM. 

    Read the DTC of [Transmission] using the Subaru Select Monitor. Refer to TRANSMISSION (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed? (Current malfunction)

    Yes:  Perform the diagnosis for the displayed DTCs. Refer to TRANSMISSION (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Go to  6.

  6. CHECK CONNECTOR. 

    Check each connector.

    Is there poor contact or any other faults?

    Yes:  Repair the connector.

    No:  Replace the TPMS & keyless entry control module or TPMS control module. Refer to WHEEL AND TIRE SYSTEM>TIRE PRESSURE MONITORING SYSTEM .
