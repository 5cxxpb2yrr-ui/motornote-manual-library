IMPREZA Model

CAUTION:
  • For parts which are not reusable, always use new parts.
  • Do not apply grease to the tapered portion of ball stud.
  • Make sure that there is no gap between the front axle housing and the collar.
  • If the collar comes off from the front axle housing, replace the front axle housing with a new part.
  1. Install the ball joint to the front axle housing.

    Tightening torque: 

    51 N.m (5.2 kgf-m, 37.6 ft-lb)

  2. Insert the washer, and secure the flange nut.
  3. Insert a new snap pin.
  4. Install the drive shaft.

    Refer to DRIVE SHAFT SYSTEM>FRONT DRIVE SHAFT>INSTALLATION .

  5. Install the flange nut on the bottom of the ball joint.

    Tightening torque: 

    100 N.m (10.2 kgf-m, 73.8 ft-lb)

  6. Install the stabilizer link (bottom part).

    Tightening torque: 

    60 N.m (6.1 kgf-m, 44.3 ft-lb)

  7. Install the tie-rod end.
    NOTE:
    • Do not forget to install the washer.
    • When tightening the castle nut, tighten the castle nut to the specified torque first, then tighten it further but within 60° until the hole in the ball stud is aligned with a slot in castle nut.

    Tightening torque: 

    27 N.m (2.7 kgf-m, 19.9 ft-lb)

  8. Insert a new cotter pin and secure the castle nut.
  9. Install the crossmember support - rear.

    Tightening torque: 

    70 N.m (7.1 kgf-m, 51.6 ft-lb)

  10. Install the under cover - front.

    Tightening torque: 

    18 N.m (1.8 kgf-m, 13.3 ft-lb)

  11. Lower the vehicle, and install the front wheels.

    Tightening torque: 

    120 N.m (12.2 kgf-m, 88.5 ft-lb)

  12. Confirm that the wheels are in full contact with the ground, and tighten the nuts of the strut mount CTR.
    CAUTION: Be sure to use a new self-locking nut.

    Tightening torque: 

    55 N.m (5.6 kgf-m, 40.6 ft-lb)
