DTC U0423: Invalid Data Received From Instrument Panel Cluster Control Module

DTC detecting condition: 

CAN data from combination meter is abnormal.

Trouble symptom: 

  • Displayed units are incorrect. (Temperature, fuel economy, distance, speed)
  • The display order of date (year, month, day) is incorrect.
  • Ambient air temperature reading in the regularly displayed bar is not correct. (Bar display)
  • EyeSight screen is not displayed.
  • EyeSight status is not displayed correctly in the electrical parts operation status screen.
  • RAB status is not displayed correctly in the electrical parts operation status screen.
  • Favorite screen Average speed does not change.
  • Favorite screen Instantaneous fuel economy does not change.
  • Favorite screen Orientation is not displayed.
  • Favorite screen Weather does not change.
  • Favorite screen Speed limit does not change.
  • Fuel economy screen Instantaneous fuel economy does not change.
  • Fuel economy screen Average fuel economy is not displayed.
  • Fuel economy screen Remaining fuel cruising distance value is not displayed.
  • Illumination brightness is not changed by the bright switch.
  • "Welcome" display is not displayed.
  • The language shown is different from the language displayed in the combination meter.
  • A screen cannot be switched to the setting screen.
  • When the setting screen is on, the switches are disabled.
  • Switch that recalls the timer charging setting cannot be operated. (Hybrid model)
  • Orientation screen is not displayed.
  • Turn by turn screen is not displayed.
  • Weather screen is not displayed.
  • Audio screen is not displayed.
  • Time is not shared with audio.
  • Preventive safety screen X-MODE is not displayed.
  • Unable to switch TRIP display.
NOTE: For the diagnostic procedure, refer to DTC U0074. Refer to MULTI-FUNCTION DISPLAY (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC U0074 CONTROL MODULE COMMUNICATION BUS "BODY-CAN" OFF .
