DTC P0441: EVAP System (CPC) Incorrect Purge Flow: Notes

1. - 

DTC detecting condition: 

Detected when two consecutive driving cycles with fault occur.

Trouble symptom: 

Improper idling

NOTE: After the faulty parts are repaired or replaced, perform the final check in Basic Diagnostic Procedure. Refer to ENGINE (DIAGNOSTICS) (H4DO (EXCEPT FOR HEV))>BASIC DIAGNOSTIC PROCEDURE>PROCEDURE .
  1. CHECK DTC  .

    Using the Subaru Select Monitor or a general scan tool, read the DTC of [Engine]. Refer to ENGINE (DIAGNOSTICS) (H4DO (EXCEPT FOR HEV))>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC other than P0441 displayed? (Current malfunction)

    Yes: 

    Check the appropriate DTC using the "Diagnostic Trouble Code (DTC)". Refer to ENGINE (DIAGNOSTICS) (H4DO (EXCEPT FOR HEV))>DIAGNOSTIC TROUBLE CODE (DTC) .

    No: 

    Go to  2.

  2. CHECK PURGE CONTROL SOLENOID VALVE  .

    Operate the purge control solenoid valve using the Subaru Select Monitor.

    NOTE: For detailed operation procedures, refer to the "Active Test". Refer to ENGINE (DIAGNOSTICS) (H4DO (EXCEPT FOR HEV))>ACTIVE TEST .

    Does the purge control solenoid valve operate?

    Yes: 

    Go to  3.

    No: 

    Replace the purge control solenoid valve. Refer to EMISSION CONTROL (AUX. EMISSION CONTROL DEVICES) (H4DO (EXCEPT FOR HEV))>PURGE CONTROL SOLENOID VALVE .

  3. CHECK EVAPORATIVE EMISSION CONTROL SYSTEM LINE  .

    Check the evaporative emission control system line.

    Are there holes, cracks, clogging, or disconnection, misconnection of hoses or pipes in evaporative emission control system?

    Yes: 

    Repair or replace the hoses or pipes.

    No: 

    Repair the poor contact of ECM connector.
