Diagnostic Method

If the duration of time while the following conditions are met is longer than the time indicated, judge as NG.

  • Judgment 1: Diagnosis for open circuit Judgment value 
    JUDGMENT VALUE SPECIFICATION

    Malfunction Criteria Threshold Value
    Operating current 0.2 A or less
  • Judgment 2: Diagnosis for overcurrent Judgment value 
    JUDGMENT VALUE SPECIFICATION

    Malfunction Criteria Threshold Value
    Operating current 32.4 A or more
  • Judgment 3: Diagnosis for ground short Judgment value 
    JUDGMENT VALUE SPECIFICATION

    Malfunction Criteria Threshold Value
    Terminal voltage 1 V or less
  • Judgment 4: Diagnosis for power supply short Judgment value 
    JUDGMENT VALUE SPECIFICATION

    Malfunction Criteria Threshold Value
    Terminal voltage 5 V or more
  • Judgment 5: Diagnosis for short circuit to ground (between ECM and injector driver) Judgment value 
    JUDGMENT VALUE SPECIFICATION

    Malfunction Criteria Threshold Value
    Injector control voltage Less than 3.92 V
  • Judgment 6: Diagnosis for short circuit to power supply (between ECM and injector driver) Judgment value 
    JUDGMENT VALUE SPECIFICATION

    Malfunction Criteria Threshold Value
    Injector control voltage 3.92 V or more

Time needed for diagnosis: 

Judgment 1, 2, 5: Map1

Judgment 3, 4, 6: Map2

ENGINE SPEED DESCRIPTION - MAP 1

Engine speed (rpm) 500 2000 4000
Time when calculation was performed 10 times (sec) 2.40 0.60 0.30
ENGINE SPEED DESCRIPTION - MAP 2

Engine speed (rpm) 0 500 2000 4000
Time when calculation was performed 10 times (sec) 0.04 2.40 0.60 0.30

Malfunction indicator light illumination:  Illuminates as soon as a malfunction occurs.
