Front Brake Pipe

  1. Install the brake pipe.
    1. Install the brake pipe to the pipe clip.
    2. Install each brake pipe using a flare nut wrench.

      Tightening torque: 

      Refer to "COMPONENT" of "General Description". Refer to BRAKE>GENERAL DESCRIPTION>COMPONENT>FRONT BRAKE PIPES AND HOSES .

  2. Install the brake accumulator assembly. (Crosstrek hybrid model) Refer to BRAKE>BRAKE ACCUMULATOR ASSY>INSTALLATION .
  3. Install the vacuum booster assembly. Refer to BRAKE>BRAKE BOOSTER>INSTALLATION .
  4. Install the crossmember support - rear RH. Refer to FRONT SUSPENSION>CROSSMEMBER SUPPORT>INSTALLATION .
  5. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY>GROUND TERMINAL REMOVAL OR INSTALLATION .
  6. Bleed air from the brake line.
    • Except for hybrid model: Refer to BRAKE>AIR BLEEDING>PROCEDURE>BRAKE LINE (EXCEPT FOR HYBRID MODEL) .
    • Hybrid model: Refer to BRAKE>AIR BLEEDING>PROCEDURE>BRAKE LINE (HYBRID MODEL) .
  7. Install the front wheels.

    Tightening torque: 

    120 N.m (12.2 kgf-m, 88.5 ft-lb)
