Fuel Level Sensor: Installation

  1. Install the fuel level sensor to the fuel pump assembly.
    CAUTION: Be sure to install the fuel level sensor harness to the clip first, then install the connector cable. Otherwise, malfunction may occur.
    Courtesy of SUBARU OF AMERICA, INC.
  2. Install the fuel pump assembly. Refer to FUEL INJECTION (FUEL SYSTEMS) (H4DO (EXCEPT FOR HEV))>FUEL PUMP>INSTALLATION .
