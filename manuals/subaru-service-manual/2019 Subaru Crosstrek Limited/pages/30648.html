Before Registration

Do you like it dark? Easier on the eyes.

Transmitter ID is written on the tire pressure sensor. It is impossible to read the transmitter ID after tire is installed to the wheel. Because of this, be sure to record the transmitter ID before tire installation.

  • When replacing the transmitter, record the 7 digit number (transmitter ID) on the transmitter.
  • When replacing the tire pressure warning ECM/receiver, check the registered ID of transmitter that is recorded in the former ECM using SSM3, and record it. If the recorded transmitter ID is not read out because of a transmitter part failure, remove the tire from wheel and record the ID on the transmitter.
