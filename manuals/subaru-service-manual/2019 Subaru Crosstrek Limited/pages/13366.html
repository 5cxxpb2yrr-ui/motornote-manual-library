Reduction Driven Gear: Installation

  1. Install the reduction driven gear assembly and spacer oil.

    Tightening torque: 

    17 N.m (1.7 kgf-m, 12.5 ft-lb)

    Courtesy of SUBARU OF AMERICA, INC.
  2. Select the transfer drive gear shim. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>REDUCTION DRIVE GEAR>ADJUSTMENT .
  3. Install the parking pawl. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>PARKING PAWL>INSTALLATION .
  4. Attach the selected transfer drive gear shim to extension case with vaseline.
  5. Install the transfer driven gear assembly. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSFER DRIVEN GEAR>INSTALLATION .
  6. Install the transfer clutch assembly. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSFER CLUTCH>INSTALLATION .
  7. Install the extension case. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>EXTENSION CASE>INSTALLATION .
  8. Install the transmission assembly to the vehicle. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>AUTOMATIC TRANSMISSION ASSEMBLY>INSTALLATION .
