TPMS Reminder Reset - Procedure 03

NOTE: Perform the transmitter registration procedure if the tire sensor, TPMS & keyless entry control module, or the TPMS control module is replaced.
NOTE: If registration of the transmitter ID is not possible after two attempts, replace the TPMS & keyless entry control module or TPMS control module.
NOTE: If tires were rotated, the performance and function of TPM system is not affected. However, correct tire positions will not displayed in the Subaru Select Monitor.
NOTE: In the following procedures, the Subaru Select Monitor (SSM3) and Transmitter Registration Tool (TPM-00012 or Kent-Moore Part No. FJ45295) must be used.
  1. Adjust all tire pressures to specification.
  2. Connect the Subaru Select Monitor, and select DIAGNOSIS on the START display.
  3. On VEHICLE SELECTION display, input the target vehicle information and select CONFIRMED.
  4. On MAIN MENU display, select EACH SYSTEM.
  5. On SELECT SYSTEM display, select TIRE PRESSURE MONITOR and then select ENTER.
  6. On SELECT FUNCTION display, select WORK SUPPORT.
  7. On WORK SUPPORT display, select TRANSMITTER ID REGIST.
  8. ID REGISTRATION MODE WHEN EXECUTE REGISTERED ID IS DELETED CONTINUE? is displayed, select OK.
  9. Press the transmitter registration tool to the tire side wall area near the air valve on the Front Left tire, and press the switch. The transmitter ID is sent to the TPMS & keyless entry control module or TPMS control module (At this time, the tire pressure warning light blinks to confirm that the registration has started).
    NOTE: When registration of each tire is completed, ID REGISTRATION COMPLETED is displayed on the Select Monitor screen.
    NOTE: If the registration procedure stops before completion (turning ignition switch to OFF, wrong registration order, etc), proceed again from step  5.
  10. When ID registration is completed, the tire pressure warning light remains lit for approximately 2 seconds. Switch to the screen displaying the transmitter ID on the Subaru Select Monitor display.
  11. Check the transmitter ID that was registered, then perform driving test.
