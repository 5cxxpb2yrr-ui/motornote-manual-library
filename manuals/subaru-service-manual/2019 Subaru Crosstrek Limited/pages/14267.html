Switches And Harness: Installation: Switch

WARNING: This page is about a different variant/trim than selected.
  • TIMER CHARGING SETTING SWITCH 
    1. Install the timer charging setting switch.
    2. Install the cover assembly - instrument panel LWR driver OUT.
    3. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY>GROUND TERMINAL REMOVAL OR INSTALLATION .
  • HYBRID MODE SWITCH 
  1. Install the hybrid mode switch.
  2. Install the cover assembly - front.
  3. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY>GROUND TERMINAL REMOVAL OR INSTALLATION .
