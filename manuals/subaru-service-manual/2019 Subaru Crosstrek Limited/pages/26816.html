Malfunction Description

WARNING: This page is about a different variant/trim than selected.

Hybrid vehicle control ECU assembly and AIRBAG CONTROL MODULE detect occurrence of collision and turn off the system main relay.

The following cases are assumed to be malfunction causes:

  • If collision is detected
  • Detection sensor system fault
    • Airbag system malfunction
    • Malfunction of Hybrid vehicle control ECU assembly
    • Communication error between AIRBAG CONTROL MODULE - Hybrid vehicle control ECU assembly
    • Communication error of Hybrid vehicle control ECU assembly
