Rear Seat: Assembly

CAUTION:
  • Do not reuse the hog ring and hang wire.
  • Secure the hog ring using hog ring pliers.
  • Install the hog rings to the specified points securely and make sure that there is no wrinkle or twisting on the cover COMPL - rear backrest.
  1. Assemble the cover COMPL - rear backrest and the cover - rear cushion in the same manner as for the front seat. Refer to SEATS>FRONT SEAT>ASSEMBLY .
  2. Install the hog rings on the back side of the rear seat cushion assembly.
  3. Install the hog rings and wire clip, then install the cover COMPL - rear backrest.
    NOTE:
    • Do not contaminate or damage the cover COMPL - rear backrest and the cover - rear cushion.
    • While installing the hog rings, prevent the cover COMPL - rear backrest and the cover - rear cushion from getting wrinkled.
  4. Install the frame assembly - rear backrest.
  5. For the backrest LH side, install the hog ring, wire clamp and J-fastener, etc. (Crosstrek model with armrest)
    Courtesy of SUBARU OF AMERICA, INC.
  6. For the backrest LH, install the hog ring and wire clamp. (Impreza model with armrest)
    Courtesy of SUBARU OF AMERICA, INC.
  7. Install the bushing - headrest and the bushing - lock assembly.
    CAUTION: Pay attention to the orientation of the bushing - headrest.
    Courtesy of SUBARU OF AMERICA, INC.
  8. Install the lock assembly - rear backrest rear.

    Tightening torque: 

    Refer to "COMPONENT" of "General Description". Refer to SEATS>GENERAL DESCRIPTION>COMPONENT>REAR SEAT .

  9. Install the plastic hooks on the back side of the backrest assembly.
  10. Install the clips on the backside of the cover COMPL - rear backrest.
  11. Install the knob - backrest. (Screw-in type)
  12. Install the tether anchor cover. (5 door model, Crosstrek model)
  13. Install the armrest. (Models with armrest)

    Tightening torque: 

    Refer to "COMPONENT" of "General Description". Refer to SEATS>GENERAL DESCRIPTION>COMPONENT>REAR SEAT .

  14. Install the headrest assembly - rear backrest.
  15. Before installation, check the following items.
    • No tear and fray on the cover COMPL - rear backrest and the cover - rear cushion.
  16. Install the rear seat. Refer to SEATS>REAR SEAT>INSTALLATION .
