At Rapid Start Prevention Control Does Not Operate/At Rapid Start Prevention Control Is Released Automatically

WARNING: This page is about a different variant/trim than selected.
  1. CHECK PRE-COLLISION BRAKE OFF INDICATOR LIGHT. 

    Check the pre-collision brake OFF indicator light.

    Is the pre-collision brake OFF indicator light off?

    Yes:  Go to  2.

    No:  This is normal. Operate the brake OFF switch to deactivate. When the indicator remains on after the deactivation, perform the diagnosis described in "Pre-collision brake OFF indicator light does not go off".

  2. CHECK USING CHECK LIST. 

    Using CHECK LIST (AT RAPID START PREVENTION CONTROL), check the following and respond to it.

    • Does it apply to the condition that the AT rapid start prevention control may not operate?
    • Does it apply to the condition that the pre-collision brake OFF indicator light illuminates?

    Is there a relevant item in the check list?

    Yes:  When there is a relevant item, it can be the cause of malfunction. Eliminate the cause, and check that the malfunction has been improved.

    No:  Replace the stereo camera. Refer to EYESIGHT>STEREO CAMERA>REMOVAL .
