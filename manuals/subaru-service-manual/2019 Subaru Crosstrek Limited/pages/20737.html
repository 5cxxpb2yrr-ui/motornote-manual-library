System Initialization

Sometimes top dead position or bottom dead position becomes misaligned even if it is initialized by operating the power window switches.

With this procedure, the following data can be initialized.

  • Top dead position
  • Bottom dead position
  • Sliding resistance value
  • DTC/FFD
  • Data monitor history items
  1. On [Start] display, select [Diagnosis].
  2. On [Vehicle selection] display, input the target vehicle information and select [OK].
  3. On [Main Menu] display, select [Each System].
  4. On [Select System] display, select [Power Window (Driver)] or [Power Window (Passenger)], and then select [Enter].
  5. On [Select Function] display, select [Work Support].
  6. On [Work Support] display, select [Initialization Mode].
  7. On [Initialization Mode] display, select [System Initialization].
  8. Perform operation following directions in the Subaru Select Monitor.
