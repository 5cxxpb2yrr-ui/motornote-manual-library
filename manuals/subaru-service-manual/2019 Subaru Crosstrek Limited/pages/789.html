DTC B1401: Meter Collation

Do you like it dark? Easier on the eyes.

Diagnosis start condition: 

  • Battery voltage is 10 V or more.
  • The remote engine starter was not used to start the engine.

DTC detecting condition: 

Reference code incompatibility between combination meter and body integrated unit

Trouble symptom: 

  • Engine will not start.
  • The security indicator illuminates.
CAUTION: When the combination meter is replaced, registration of the immobilizer system is required. For details, refer to the "REGISTRATION INSTRUCTIONS FOR IMMOBILIZER" provided as a separate volume.
  1. CHECK COMBINATION METER REGISTRATION. 

    Perform registration of combination meter. Refer to the "REGISTRATION INSTRUCTIONS FOR IMMOBILIZER" provided as a separate volume.

    Is registration complete?

    Yes:  Currently, it is normal. (Combination meter registration is not complete.)

    No:  Refer to "Correspondence table when registration is not possible" in the "REGISTRATION INSTRUCTIONS FOR IMMOBILIZER" provided as a separate volume. If the registration still does not work properly, replace the combination meter. Refer to INSTRUMENTATION/DRIVER INFO>COMBINATION METER .
