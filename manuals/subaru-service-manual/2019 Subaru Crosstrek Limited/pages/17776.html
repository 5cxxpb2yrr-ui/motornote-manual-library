DTC P2746: Intermediate Shaft Speed Sensor "B" Circuit Range/Performance: Notes

Do you like it dark? Easier on the eyes.

1. - 

DTC detecting condition: 

Immediately at fault recognition

Trouble symptom: 

  • Standing start problems
  • Shock occurs when engaging the lockup clutch.
  • Shock occurs when selecting shift position.
CAUTION: After servicing or replacing faulty parts, perform the last step of the basic diagnostic procedure. Refer to TRANSMISSION (DIAGNOSTICS)>BASIC DIAGNOSTIC PROCEDURE .
  1. CHECK DTC  .

    Read the DTC using Subaru Select Monitor. Refer to TRANSMISSION (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Besides DTC P2746, is DTC P2747 or P2751 displayed?

    Yes:  Perform the diagnosis according to DTCs other than P2746. Refer to TRANSMISSION (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Perform the diagnosis according to DTC P2747. Refer to TRANSMISSION (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC P2747 INTERMEDIATE SHAFT SPEED SENSOR "B" CIRCUIT NO SIGNAL .
