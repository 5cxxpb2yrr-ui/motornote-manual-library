IMPREZA Model

  1. Install the seal to the cylinder body assembly.
  2. Install the reservoir tank.
    CAUTION: Be careful not to tighten a vise excessively.
    1. Place the master cylinder assembly between aluminum plates and fix it on a vise.
    2. Tighten the pin using a driver to install the reservoir tank.

      Tightening torque: 

      5.5 N.m (0.6 kgf-m, 4.1 ft-lb)
