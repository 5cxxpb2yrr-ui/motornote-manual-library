DTC P0D5E-00: Hybrid/EV Battery Charger Hybrid/EV System Discharge Time Too Long: Notes

Do you like it dark? Easier on the eyes.

WARNING: This page is about a different variant/trim than selected.

1. - 

Outline of diagnosis: 

After charging was completed, VCHG voltage did not decrease even though sufficient time had elapsed

(1 trip detection logic)

Trouble symptom: 

Plug-in charging suspended

CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK DTC  .

    Read the following DTCs using Subaru Select Monitor. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) . Refer to P-HEV HIGH VOLTAGE BATTERY (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) . Refer to PLUG-IN BATTERY CHARGER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
