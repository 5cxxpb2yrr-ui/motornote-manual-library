DTC U1447: Invalid Data Received From Gateway "A" BODY-CAN

DTC detecting condition: 

Data from central gateway control module is abnormal.

Trouble symptom: 

  • The energy flow screen is not displayed correctly.
  • The electrical parts operation screen is not displayed correctly.
  • The left side of the preventive safety screen (powertrain display) is not displayed correctly.
  • Favorite screen Water temperature does not change.
  • Favorite screen Oil temperature does not change.
  • Favorite screen Accelerator opening angle does not change.
  • Setting screen Cannot set timer charging.
  • Setting screen Cannot set cable lock mode.
  • Setting screen Cannot set maximum AC charging current.
  • Switch that recalls the timer charging setting cannot be operated.
  • The next timer charging schedule display is not displayed properly.
NOTE: For the diagnostic procedure, refer to DTC U0074. Refer to MULTI-FUNCTION DISPLAY (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC U0074 CONTROL MODULE COMMUNICATION BUS "BODY-CAN" OFF .
