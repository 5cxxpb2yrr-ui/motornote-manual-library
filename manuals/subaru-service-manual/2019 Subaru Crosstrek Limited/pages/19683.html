DTC P1CD8-00: Hybrid/EV Powertrain Control Module Processor Or Monitoring Processor Charging Permission Signal Internal Failure: Notes

WARNING: This page is about a different variant/trim than selected.

1. - 

Outline of diagnosis: 

The charger gate permission signal from Hybrid vehicle control ECU assembly is faulty

(1 trip detection logic)

Trouble symptom: 

Plug-in charging suspended

CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK DTC  .

    Read the following DTCs using Subaru Select Monitor. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) . Refer to PLUG-IN BATTERY CHARGER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    • P-HEV Hybrid Powertrain Control
    • Plug-in Battery Charger
