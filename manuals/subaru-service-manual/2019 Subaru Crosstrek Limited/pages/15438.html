5 Door Model

CAUTION: Make sure the bolt is tightened securely because improper roof spoiler installation may cause water leakage.
  1. Install the light assembly - high-mounted.

    Tightening torque: 

    4.5 N.m (0.5 kgf-m, 3.3 ft-lb)

  2. Install the roof spoiler. Refer to EXTERIOR/INTERIOR TRIM>ROOF SPOILER>INSTALLATION .
  3. Install the trim panel - rear gate.
  4. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
