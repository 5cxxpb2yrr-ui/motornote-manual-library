Diagnostic Method

Compare the diagnostic value with the threshold value, and if a condition meeting the malfunction criteria continues for 10s x 3time(s) or more, judge that there is a fault in the fuel system.

JUDGMENT VALUE SPECIFICATION

Malfunction Criteria Threshold Value
Offset amount of main feedback Value of Map or more

Map 

Amount of air (g/s (oz/s)) 0 (0) 3.2 (0.11)
Threshold Value 1.35 1.35

Time needed for diagnosis:  10s x 3time(s)

Malfunction indicator light illumination:  Illuminates when malfunction occurs in 2 continuous driving cycles.
