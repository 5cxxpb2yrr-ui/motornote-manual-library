Front Fog Light Assembly: Installation

CAUTION: Install the mud guard - front so that the front end of the mud guard (b), except for the clip fixing point, comes inside the bumper face (a).
Courtesy of SUBARU OF AMERICA, INC.
  1. Install the fog light assembly - front.
    CAUTION: After connecting the connector, make sure that the bulb is locked securely.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  2. Install the mud guard - front.
  3. Install the under cover - front.

    Tightening torque: 

    18 N.m (1.8 kgf-m, 13.3 ft-lb)

  4. Lower the vehicle.
  5. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
  6. Adjust the fog light beam. Refer to LIGHTING SYSTEM>FRONT FOG LIGHT ASSEMBLY>ADJUSTMENT>FOG LIGHT AIMING .
