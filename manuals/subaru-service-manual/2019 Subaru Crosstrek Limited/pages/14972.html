Fuse Installation

Do you like it dark? Easier on the eyes.

  • Backup fuse (30 A) remains removed to prevent the battery consumption when vehicles are delivered. Install the backup fuse by following the illustration. Besides, removing the backup fuse from the fuse holder deactivates the control during shipping (delivery mode).
    NOTE: For models with LED headlight, park the vehicle on a horizontal ground when performing this procedure.
    Courtesy of SUBARU OF AMERICA, INC.
  • When the vehicle is delivered, the backup fuse is normally placed in the position (1) as shown in the figure. However, if placed in the position (2), it may indicate that the headlight beam is deviated. In this case, perform the following procedures. (Model with LED headlight)
  1. Park the vehicle on a level ground.
  2. Install the backup fuse in the position (1) and then turn the ignition switch to ON.
  3. Turn the ignition switch to OFF, install the backup fuse in the position (2), and start the engine.
