Initialization Of High Pressure Fuse Load Log

Do you like it dark? Easier on the eyes.

WARNING: This page is about a different variant/trim than selected.
NOTE: When DTC P0A9563 (HIGH VOLTAGE FUSE ACCUMULATED LOAD HISTORY) is output and Hybrid battery terminal block is replaced, perform [High Voltage Fuse Accumulated Load History Reset] and clear memory of the DTC.
If [High Voltage Fuse Accumulated Load History Reset] has not been performed, DTC P0A9563 (HIGH VOLTAGE FUSE ACCUMULATED LOAD HISTORY) is output again because the high pressure fuse load log stored in Battery ECU assembly, otherwise, can be initialized.
  1. Connect the Subaru Select Monitor.
  2. Turn to IG ON.
  3. On [Start] screen, select [Diagnosis].
  4. On [Vehicle selection] screen, enter vehicle information and select [OK].
  5. On [Main Menu] screen, select [Each System].
  6. On [Select System] screen, select [P-HEV High Voltage Battery].
  7. On [Select Function] screen, select [Work Support].
  8. On [Work Support] screen, select [High Voltage Fuse Accumulated Load History Reset].
  9. Check that the [Executed High Voltage Fuse Accumulated LoadHistory Reset] is displayed.
    NOTE:
    • High Voltage Fuse Accumulated LoadHistory Reset takes about 10 seconds to 25 minutes.
    • Check [Executed High Voltage Fuse Accumulated LoadHistory Reset] on the Subaru Select Monitor and then end the procedure.
    • If the message [Failed to High Voltage Fuse Accumulated Load History Reset] is displayed, perform it from the beginning.
  10. Turn the ignition to OFF.
