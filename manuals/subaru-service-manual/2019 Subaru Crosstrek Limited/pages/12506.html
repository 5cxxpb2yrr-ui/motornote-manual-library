DTC B11F0: Disposal Process Complete

Diagnosis start condition: 

When the ignition voltage is 10 V - 16 V.

DTC detecting condition: 

Airbag disposal is completed with ISO collective disposal tool.

CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to AIRBAG (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK DTC. 

    Read the DTC of [Airbag] using the Subaru Select Monitor. Refer to AIRBAG (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC B11F0 displayed? (Current malfunction)

    Yes:  Replace the airbag control module.

    No:  Using the Subaru Select Monitor, perform the clear memory of [Airbag]. Refer to COMMON (DIAG)>CLEAR MEMORY .
