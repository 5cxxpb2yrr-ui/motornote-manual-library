Transmission Case Side

  1. Install the air breather cap.
  2. Install the air breather hose.
    Courtesy of SUBARU OF AMERICA, INC.
  3. Install the transmission case cover.

    Tightening torque: 

    Cover (small): 7 N.m (0.7 kgf-m, 5.2 ft-lb)

    Cover (large): 8 N.m (0.8 kgf-m, 5.9 ft-lb)

    NOTE: First install the transmission case cover (large), then insert the transmission case cover (small) between the transmission case cover (large) and the transmission to install.
    Courtesy of SUBARU OF AMERICA, INC.
  4. Install the transmission assembly. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>AUTOMATIC TRANSMISSION ASSEMBLY>INSTALLATION .
  5. Install the air breather hose to the bracket.
    NOTE: Assemble the hose with the marked position facing in the direction shown in the figure.
    Courtesy of SUBARU OF AMERICA, INC.
