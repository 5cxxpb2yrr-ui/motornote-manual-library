Fender Panel

Do you like it dark? Easier on the eyes.

CAUTION: Install the mud guard - front so that the front end of the mud guard (b), except for the clip fixing point, comes inside the bumper face (a).
Courtesy of SUBARU OF AMERICA, INC.
  1. Install the fender - front.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

    NOTE: When installing the fender - front, make sure that a uniform clearance is created around it.
    • Fender - front to Hood COMPL - front: Refer to EXTERIOR BODY PANELS>FRONT HOOD>ADJUSTMENT .
    • Fender - front to Panel assembly - front door: Refer to EXTERIOR BODY PANELS>FRONT DOOR>ADJUSTMENT .
  2. Install the cover - A pillar assembly.
  3. Install the spoiler assembly - side.
  4. Install the mud guard - front.
  5. Install the insulator - fender rear. (Equipped model only)
    1. Push the insulator - fender rear (a) so that the front side comes back of the reinforce - front panel side (b) end.
      Courtesy of SUBARU OF AMERICA, INC.
  6. Install the cover - fender UPR.
  7. Install the cowl panel - side.
  8. Install the light assembly - head.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  9. Install the bumper face - front. Refer to EXTERIOR/INTERIOR TRIM>FRONT BUMPER>INSTALLATION .
  10. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY>GROUND TERMINAL REMOVAL OR INSTALLATION .
  11. Adjust the headlight beam and fog light beam.
    • Adjust the headlight beam. Refer to LIGHTING SYSTEM>HEADLIGHT ASSEMBLY>ADJUSTMENT>HEADLIGHT BEAM ADJUSTMENT .
    • Adjust the fog light beam. (Model with fog light) Refer to LIGHTING SYSTEM>FRONT FOG LIGHT ASSEMBLY>ADJUSTMENT>FOG LIGHT AIMING .
