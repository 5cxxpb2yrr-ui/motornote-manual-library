Inspection Mode 8

Code Description & trouble part Note
B2B20 Passenger's Door Power Window Auto Switch Stuck -

Diagnostic procedure:

  1. Using the Subaru Select Monitor, perform the clear memory of [Power Window (Passenger)]. Refer to COMMON (DIAG)>CLEAR MEMORY .
  2. Using the Subaru Select Monitor, read the DTC of [Power Window (Passenger)] to check that there is no DTC displayed. Refer to POWER WINDOW (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
    NOTE: If the DTC is displayed on the screen, the trouble is still present. Perform the diagnosis for the displayed DTCs. After solving the DTC, repeat from step  1.
  3. Using the passenger's side power window switch, operate the automatic up/down feature and check that the window rolls up and down.
  4. Using the Subaru Select Monitor, read the DTC of [Power Window (Passenger)] to check that there is no DTC displayed. Refer to POWER WINDOW (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
    NOTE: If the DTC is displayed on the screen, the trouble is still present. Perform the diagnosis for the displayed DTCs.
