How To Use General Scan Tool

  1. Prepare a scan tool (general scan tool) required by SAE J1978.
  2. Connect the general scan tool to data link connector located in the lower portion of the instrument panel (on the driver's side). Refer to COMMON (DIAG)>DATA LINK CONNECTOR .
  3. Using the general scan tool, call up each data. General scan tool functions consist of:
    1. MODE $01: Current powertrain diagnostic data
    2. MODE $02: Powertrain freeze frame data
    3. MODE $03: Emission-related powertrain DTC
    4. MODE $04: Clear/Reset emission-related diagnostic information
    5. MODE $07: Initial emission-related powertrain DTC
    6. MODE $09: Request vehicle information
    7. MODE $0A: Emission-related DTC
  4. Read out the data according to repair procedures. (For detailed operation procedures, refer to the general scan tool operation instructions.)
NOTE: For details concerning DTC, refer to "Diagnostic Trouble Code (DTC)". Refer to TRANSMISSION (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .
