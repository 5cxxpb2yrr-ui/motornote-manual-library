Circuit Explanation

WARNING: This page is about a different variant/trim than selected.

The Charge control ECU installed inside the Electric vehicle charger assembly uses sensors to monitor the high voltage circuit in the Electric vehicle charger assembly and performs plug-in charging control and error detection.

Courtesy of SUBARU OF AMERICA, INC.
Sensor name Detection contents Sensor name Detection contents
VIN AC input voltage (before rectification) VAC AC input voltage (after rectification)
IAC Input AC current VH Voltage in boost circuit
IVH DC section current VCHG DC section voltage
VHT Temperature in boost circuit PFCT Temperature in transformer circuit

The Charge control ECU built into the Electric vehicle charger assembly monitors the input alternating current using the IAC sensor. If it detects an IAC sensor malfunction, it stores a DTC. If this DTC is output, check the plug-in charge state using a known good external power source. If a malfunction occurs again, replace the Electric vehicle charger assembly.
