Rear Gate Panel

CAUTION: The panel - rear gate is heavy. When removing and installing it, always work in a team of two or more persons.
  1. Install the hinge - rear gate to the vehicle body.
  2. Temporarily install the panel - rear gate to the hinge - rear gate.
    NOTE: When installing, make sure that a uniform clearance is created around the panel rear gate.
  3. Adjust the clearance around the panel - rear gate. Refer to EXTERIOR BODY PANELS>REAR GATE>ADJUSTMENT .
  4. Tighten the bolts of the hinge - rear gate.

    Tightening torque: 

    25 N.m (2.5 kgf-m, 18.4 ft-lb)

  5. Install the stay assembly - rear gate.
    CAUTION: Before installing, degrease the bracket surface of stay assembly - rear gate.

    Tightening torque: 

    Refer to "COMPONENT" of "General Description". Refer to EXTERIOR BODY PANELS>GENERAL DESCRIPTION>COMPONENT>REAR GATE .

  6. Install the rear gate glass. Refer to GLASS/WINDOWS/MIRRORS>REAR GATE GLASS>INSTALLATION .
  7. Install the harness clip and the harness.
  8. Install the light assembly - rear finisher.

    Tightening torque: 

    4.5 N.m (0.5 kgf-m, 3.3 ft-lb)

  9. Install the license plate light. Refer to LIGHTING SYSTEM>LICENSE PLATE LIGHT>INSTALLATION .
  10. Install the rearview camera assembly. Refer to ENTERTAINMENT & MONITORING>CAMERA>INSTALLATION>REAR .
  11. Install the nozzle and hose assembly - rear washer. Refer to WIPER AND WASHER SYSTEMS>REAR WASHER>INSTALLATION .
  12. Connect the hose assembly - rear washer.
  13. Install the garnish assembly - rear gate.

    Tightening torque: 

    4.5 N.m (0.5 kgf-m, 3.3 ft-lb)

  14. Install the roof spoiler. Refer to EXTERIOR/INTERIOR TRIM>ROOF SPOILER>INSTALLATION .
  15. Install the drip - rear gate.
  16. Install the arm assembly - rear wiper and the motor assembly - rear wiper. Refer to WIPER AND WASHER SYSTEMS>REAR WIPER MOTOR>INSTALLATION .
  17. Attach the buffer - rear gate and the stopper - rear gate.

    Tightening torque: 

    Refer to "COMPONENT" of "General Description". Refer to EXTERIOR BODY PANELS>GENERAL DESCRIPTION>COMPONENT>REAR GATE .

  18. Install the latch and actuator - rear gate. Refer to SECURITY AND LOCKS>REAR GATE LATCH AND ACTUATOR ASSEMBLY>INSTALLATION .
