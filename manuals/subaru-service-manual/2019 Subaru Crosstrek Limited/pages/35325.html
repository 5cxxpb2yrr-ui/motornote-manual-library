Basic Diagnostic Procedure: Procedure

  1. PERFORM CUSTOMER INTERVIEW. 

    Ask the customer when and how the trouble occurred using the interview check list. Ref. to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>CHECK LIST FOR INTERVIEW .

    Did you interview the customer?

    Yes:  Go to  2.

    No:  Perform the interview, and Go to  2.

  2. BASIC INSPECTION. 

    Perform basic inspection. Ref. to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>GENERAL DESCRIPTION>INSPECTION .

    Is the check result OK?

    Yes:  Go to  3.

    No:  Repair the faulty part found in basic inspection, and Go to  3.

  3. CHECK WARNING LIGHT. 

    Check the lighting condition of brake warning light in the combination meter.

    Does the brake warning light illuminate?

    Yes:  Go to  4.

    No:  Currently, it is normal.

  4. CHECK SUBARU SELECT MONITOR COMMUNICATION. 
    1. Turn the ignition switch to OFF.
    2. Connect the Subaru Select Monitor to data link connector. Ref. to COMMON (DIAG)>DATA LINK CONNECTOR .
    3. Turn the ignition switch to ON and run the Subaru Select Monitor.
    4. Select [Electric Brake Booster].
    NOTE: For detailed operation procedures, refer to "Help" of application.

    Is communication possible?

    Yes:  Go to  5.

    No:  Check the communication circuit. Ref. to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE FOR SUBARU SELECT MONITOR COMMUNICATION .

  5. CHECK DTC. 

    Read the DTC using Subaru Select Monitor. Ref. to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are DTC, time stamp and freeze frame data displayed?

    Yes:  Record the DTC, time stamp and freeze frame data. Go to  6.

    No:  Currently, it is normal.

  6. PERFORM DIAGNOSIS. 
    1. Perform the diagnosis for the displayed DTCs. Ref. to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .
    2. Repair or replace the faulty parts.
    3. Using the Subaru Select Monitor, perform the clear memory. Ref. to COMMON (DIAG)>CLEAR MEMORY .
    4. Read the DTC using Subaru Select Monitor. Ref. to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed?

    Yes:  Repeat step  6 until DTC is not shown.

    No:  Finish the diagnosis.
