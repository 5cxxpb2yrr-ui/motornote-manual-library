Floor Mat: Installation

CAUTION:
  • If the passenger's seat is removed, be sure to perform [Rezeroing] for the occupant detection system after installing the seat to the vehicle.
  • Make sure that the knobs of the hook - seat cushion rear are securely installed.
Courtesy of SUBARU OF AMERICA, INC.
  1. Bring the floor mat into the vehicle, and secure with the clips.
  2. Install the hook - seat cushion rear.
  3. Install the pull handle cover.
  4. Install the lower inner trim.
  5. Install the console box assembly, the cover - shift lever and the panel center LWR.
  6. Install the power amplifier assembly and the extension duct. (Model with power amplifier) Refer to ENTERTAINMENT & MONITORING>POWER AMPLIFIER>INSTALLATION .
  7. Install the holder assembly jack and extension duct. (Hybrid model)
  8. Install the rear seat cushion assembly.
  9. Install the front seat.

    Tightening torque: 

    53 N.m (5.4 kgf-m, 39.1 ft-lb)

  10. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
    NOTE: For CVT models, after connecting the battery ground terminal, place the select lever in the P position.
  11. Perform [Rezeroing] for the occupant detection system. Refer to OCCUPANT DETECTION (DIAGNOSTICS)>REZERO .
