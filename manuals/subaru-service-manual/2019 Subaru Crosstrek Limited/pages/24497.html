Outline Of Diagnosis

WARNING: This page is about a different variant/trim than selected.

DTC P1622 is recorded if detection conditions for DTC P1620 or P1621 are met while fuel level is less than the specified value (with the fuel level warning light illuminated).

NOTE: For the detection standard, refer to DTC P1620 and P1621.
  • Refer to ENGINE (DIAGNOSTICS) (H4DO (HEV))>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC P1620 NO ENGINE TORQUE .
  • Refer to ENGINE (DIAGNOSTICS) (H4DO (HEV))>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC P1621 ENGINE DOES NOT START .
