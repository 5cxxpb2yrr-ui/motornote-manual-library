Check Abnormality Of Subaru Starlink

Do you like it dark? Easier on the eyes.

Symptoms Counter-measure
SUBARU STARLINK app was terminated. Perform the procedures described on "Check connection between smartphone and unit". Refer to INFOTAINMENT (DIAGNOSTICS)>DIAGNOSTICS WITH PHENOMENON>INSPECTION>CHECK CONNECTION BETWEEN SMARTPHONE AND UNIT .
Smartphone was powered off while connecting via the SUBARU STARLINK.
Bluetooth connection stops while connecting via the SUBARU STARLINK.
Communication gets out of service while connecting via the SUBARU STARLINK.
Radio wave reception becomes worse while connecting via the SUBARU STARLINK.
NOTE: Possible error messages with relation to the above symptoms. When the message below is displayed, perform inspection according to "Inspection when an error message is displayed (SUBARU STARLINK)". Refer to INFOTAINMENT (DIAGNOSTICS)>DIAGNOSTICS WITH PHENOMENON>LIST>INSPECTION WHEN AN ERROR MESSAGE IS DISPLAYED (SUBARU STARLINK) .
Details of message
Please disconnect mobile device and install the STARLINK application on your mobile device and try again.
Bluetooth disconnected, please reconnect and try again.
Smartphone data connection is poor, please try to connect again.
