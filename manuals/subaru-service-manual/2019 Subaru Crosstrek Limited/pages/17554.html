Basic Diagnostic Procedure: Procedure

Do you like it dark? Easier on the eyes.

  1. CHECK PRE-INSPECTION  .
    1. Ask the customer when and how the trouble occurred using the interview check list. Refer to TRANSMISSION (DIAGNOSTICS)>CHECK LIST FOR INTERVIEW .
    2. Before performing diagnostics, check the following items which might affect CVT problems.
    • General inspection Refer to TRANSMISSION (DIAGNOSTICS)>GENERAL DESCRIPTION>INSPECTION .
    • Disconnection of harness connector
    • Visual check for harness damage
    • Oil leakage
    • Stall speed test Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>STALL TEST .
    • Secondary pressure test Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>SECONDARY PRESSURE (LINE PRESSURE) TEST .
    • Transfer clutch pressure test Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSFER CLUTCH PRESSURE TEST .
    • Time lag test Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TIME LAG TEST .
    • ROAD TEST Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>ROAD TEST .
    • Inhibitor switch Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>INHIBITOR SWITCH .

    Is the check result OK?

    Yes:  Go to  2.

    No:  Repair the items which may be affecting the CVT trouble.

  2. CHECK AT OIL TEMP LIGHT  .

    Turn the ignition switch to ON and wait for at least 2 seconds.

    Does the AT OIL TEMP light illuminate?

    Yes:  Go to  3.

    No:  Check the AT OIL TEMP light.

  3. CHECK AT OIL TEMP LIGHT  .

    Start the engine and wait for 2 seconds or more.

    Does the AT OIL TEMP light blink?

    Yes:  Go to  4.

    No:  Go to  5.

  4. CHECK DTC  .

    Read the DTC using Subaru Select Monitor. Refer to TRANSMISSION (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    DTC Check 

    NOTE: If the communication function of Subaru Select Monitor cannot be executed normally, check the communication circuit. Refer to TRANSMISSION (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE FOR SUBARU SELECT MONITOR COMMUNICATION>COMMUNICATION FOR INITIALIZING IMPOSSIBLE .

    Are any DTCs displayed?

    Yes:  Record the DTC, time stamp and freeze frame data. Go to  6.

    No:  Go to  5.

  5. PERFORM GENERAL DIAGNOSTICS  .
    1. Inspect using "Diagnostic Procedure without Diagnostic Trouble Code (DTC)". Refer to TRANSMISSION (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITHOUT DIAGNOSTIC TROUBLE CODE (DTC) .
    2. Inspect using "Diagnostics with Phenomenon". Refer to TRANSMISSION (DIAGNOSTICS)>DIAGNOSTICS WITH PHENOMENON .
    3. Perform the road test. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>ROAD TEST .
    4. Read the DTC using Subaru Select Monitor. Refer to TRANSMISSION (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed?

    Yes:  Go to  6.

    No:  Finish the diagnosis.

  6. PERFORM DIAGNOSIS  .
    1. Inspect by referring to "Diagnostic Procedure with Diagnostic Trouble Code (DTC)". Refer to TRANSMISSION (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC) .
      NOTE: For the DTC table, refer to "Diagnostic Trouble Code (DTC)". Refer to TRANSMISSION (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .
    2. Repair the trouble cause.
    3. Using the Subaru Select Monitor, perform the clear memory. Refer to COMMON (DIAG)>CLEAR MEMORY .
    4. Execute the inspection mode. Refer to TRANSMISSION (DIAGNOSTICS)>INSPECTION MODE .
    5. Check the readiness code using Subaru Select Monitor and confirm that the diagnosis is completed. Refer to TRANSMISSION (DIAGNOSTICS)>ALL READINESS DIAGNOSTIC CODE(S) .

      Readliness Code 

    6. Read the DTC using Subaru Select Monitor. Refer to TRANSMISSION (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed?

    Yes:  Inspect by referring to "Diagnostic Procedure with Diagnostic Trouble Code (DTC)". Refer to TRANSMISSION (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC) .

    No:  Finish the diagnosis.
