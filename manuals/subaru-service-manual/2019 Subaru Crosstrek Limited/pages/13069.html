Sub Frame: Installation

CAUTION:
  • For parts which are not reusable, always use new parts.
  • Always tighten the bushing in the state where the vehicle is at curb weight and the wheels are in full contact with the ground.
  • During the installation, make sure that the marking of ABS wheel speed sensor harness does not twist.
NOTE: This procedure is only for non-hybrid models. For hybrid models, perform the procedure by referring to the procedure for non-hybrid models.
  1. Check the removed parts for wear, damage and crack, and repair or replace them if faulty.
  2. Install the rear upper arm assembly to the sub frame assembly.

    Tightening torque: 

    90 N.m (9.2 kgf-m, 66.4 ft-lb)

  3. Install the sub frame assembly.
    1. Lift the sub frame assembly using a transmission jack.
    2. Install the support - sub frames on the left and right sides, and install the sub frame assembly.
      CAUTION:
      • The sub frame assembly is heavy. Make sure that it is firmly supported so that it is level.
      • While checking there is no dragging of harness and wire, raise it slowly with a transmission jack.
      Courtesy of SUBARU OF AMERICA, INC.

      Tightening torque: 

      Refer to "COMPONENT" of "General Description" for the tightening torque.

      Refer to REAR SUSPENSION>GENERAL DESCRIPTION>COMPONENT .

  4. Install the rear differential.

    Refer to DIFFERENTIALS>REAR DIFFERENTIAL (T-TYPE)>INSTALLATION .

  5. Install the rear axle housing.

    Tightening torque: 

    Refer to "COMPONENT" of "General Description" for the tightening torque.

    Refer to REAR SUSPENSION>GENERAL DESCRIPTION>COMPONENT .

  6. Install the drive shaft.

    Refer to DRIVE SHAFT SYSTEM>REAR DRIVE SHAFT>INSTALLATION .

  7. Install the cable assembly - parking brake.

    Tightening torque: 

    18 N.m (1.8 kgf-m, 13.3 ft-lb)

  8. Install the cable assembly - parking brake to the parking brake shoe.

    Refer to PARKING BRAKE>PARKING BRAKE ASSEMBLY (REAR DISC BRAKE)>INSTALLATION .

  9. Install the brake hose bracket and the disc brake assembly - rear.

    Tightening torque: 

    Brake hose bracket: 33 N.m (3.4 kgf-m, 24.3 ft-lb)

    Disc brake assembly - rear: Refer to "COMPONENT" of "General Description" for the tightening torque.

    Refer to BRAKE>GENERAL DESCRIPTION>COMPONENT>REAR DISC BRAKE .

  10. Install the rear ABS wheel speed sensor.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  11. Install the stabilizer link (bottom part). (Model with stabilizer)

    Refer to REAR SUSPENSION>STABILIZER>INSTALLATION>STABILIZER LINK .

  12. Install the rear lateral link (rear).

    Refer to REAR SUSPENSION>REAR LATERAL LINK (REAR)>INSTALLATION .

  13. Install the rear lateral link (front).

    Refer to REAR SUSPENSION>REAR LATERAL LINK (FRONT)>INSTALLATION .

  14. Install the trailing link.

    Refer to REAR SUSPENSION>TRAILING LINK>INSTALLATION .

  15. Install the sensor assembly - headlight beam leveler. (Model with auto headlight beam leveler)
    CAUTION: Do not apply impact to the sensor assembly - headlight beam leveler or forcibly move the arm. Doing so may cause sensor damage and malfunction.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  16. Install the clamp of the sub rear harness.
  17. Install the propeller shaft assembly.

    Refer to DRIVE SHAFT SYSTEM>PROPELLER SHAFT>INSTALLATION .

  18. Install the rear exhaust pipe.

    Refer to EXHAUST (H4DO (EXCEPT FOR HEV))>REAR EXHAUST PIPE>INSTALLATION .

  19. Install the fuel tank protector.

    Refer to FUEL INJECTION (FUEL SYSTEMS) (H4DO (EXCEPT FOR HEV))>FUEL TANK PROTECTOR>INSTALLATION .

  20. Install the rear wheels and lower the vehicle.

    Tightening torque: 

    120 N.m (12.2 kgf-m, 88.5 ft-lb)

  21. Connect the battery ground terminal.

    Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY>GROUND TERMINAL REMOVAL OR INSTALLATION .

  22. Inspect the wheel alignment and adjust if necessary.
    • Inspection:

      Refer to FRONT SUSPENSION>WHEEL ALIGNMENT>INSPECTION .

    • Adjustment:

      Refer to FRONT SUSPENSION>WHEEL ALIGNMENT>ADJUSTMENT .

      CAUTION: When the wheel alignment has been adjusted, perform the following adjustment.
      • Lane keep assist learning value clear (except for hybrid model) (model with EyeSight):

        Refer to EYESIGHT (DIAGNOSTICS) (EXCEPT FOR HEV)>CLEAR ACTIVE LANE KEEP SYSTEM LEARNING VALUE>OPERATION .

      • Lane keep assist learning value clear (hybrid model):

        Refer to EYESIGHT (DIAGNOSTICS) (HEV)>CLEAR ACTIVE LANE KEEP SYSTEM LEARNING VALUE>OPERATION .

      • VDC sensor midpoint setting mode:

        Refer to VEHICLE DYNAMICS CONTROL (VDC)>VDC CONTROL MODULE AND HYDRAULIC CONTROL UNIT (VDCCM & H/U)>ADJUSTMENT .

  23. Perform reinitialization of the auto headlight beam leveler system. (Model with auto headlight beam leveler)

    Refer to LIGHTING SYSTEM>AUTO HEADLIGHT BEAM LEVELER SYSTEM>PROCEDURE .
