Roof Rail: Installation

CAUTION:
  • When removing or installing the roof rail, be careful not to scratch the body panel with the stud bolt of roof rail.
  • Do not reuse the following parts. If a gasket is reused, water leakage may occur.
    • Gasket
    • Self-locking nut
    • Protector
    • Seal washer

Install each part in the reverse order of removal.

  1. Install the gasket. (Except for hybrid model)
  2. Install the protector and seal washer. (Hybrid model)
  3. Install the roof rail.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  4. Install the curtain airbag module. Refer to AIRBAG SYSTEM>CURTAIN AIRBAG MODULE>INSTALLATION .
  5. Install the trim panel - roof. Refer to EXTERIOR/INTERIOR TRIM>ROOF TRIM>INSTALLATION .
  6. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
