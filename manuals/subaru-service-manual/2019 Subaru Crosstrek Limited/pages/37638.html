Warning Light Illumination Pattern: Inspection

  • Security indicator light

    Blinks slowly once with the push button ignition switch not pressed.

    Goes off when the push button ignition switch is pressed while carrying the regular access key.

    The indicator light continues to blink and the engine (except for hybrid model) or hybrid system (hybrid model) is not allowed to start when the push button ignition switch is pressed while carrying a key other than the regular access key.
