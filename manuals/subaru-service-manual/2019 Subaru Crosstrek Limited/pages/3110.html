Backup Battery

Do you like it dark? Easier on the eyes.

  1. Install the backup battery.
  2. Install the battery cover.

    Tightening torque: 

    0.3 N.m (0.03 kgf-m, 0.2 ft-lb)

  3. Install the data communication module. Refer to ENTERTAINMENT & MONITORING>DATA COMMUNICATION MODULE>INSTALLATION>DATA COMMUNICATION MODULE .
  4. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
