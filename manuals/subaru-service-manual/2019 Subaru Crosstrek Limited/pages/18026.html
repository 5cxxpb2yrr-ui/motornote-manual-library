Reduction Drive Gear: Installation

  1. Install the reduction drive gear to secondary pulley.
    Courtesy of SUBARU OF AMERICA, INC.
  2. Select the reduction drive gear shim. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>REDUCTION DRIVE GEAR>ADJUSTMENT .
  3. Install the selected reduction drive gear shim.
  4. Install the transmission case. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSMISSION CASE>INSTALLATION .
  5. Install the transmission control device. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSMISSION CONTROL DEVICE>INSTALLATION .
  6. Install the oil strainer and oil pan. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>OIL PAN AND STRAINER>INSTALLATION .
  7. Install the reduction driven gear assembly. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>REDUCTION DRIVEN GEAR>INSTALLATION .
  8. Install the parking pawl. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>PARKING PAWL>INSTALLATION .
  9. Install the transfer driven gear assembly. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSFER DRIVEN GEAR>INSTALLATION .
  10. Install the transfer clutch assembly. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSFER CLUTCH>INSTALLATION .
  11. Install the extension case. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>EXTENSION CASE>INSTALLATION .
  12. Install the inhibitor switch. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>INHIBITOR SWITCH>INSTALLATION .
  13. Install the secondary speed sensor. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>SECONDARY SPEED SENSOR>INSTALLATION .
  14. Install the primary speed sensor. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>PRIMARY SPEED SENSOR>INSTALLATION .
  15. Install the turbine speed sensor. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TURBINE SPEED SENSOR>INSTALLATION .
  16. Install the transmission harness. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSMISSION HARNESS>INSTALLATION .
  17. Install the control valve body. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>CONTROL VALVE BODY>INSTALLATION .
  18. Install the air breather hose. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>AIR BREATHER HOSE>INSTALLATION .
  19. Install the transmission assembly to the vehicle. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>AUTOMATIC TRANSMISSION ASSEMBLY>INSTALLATION .
