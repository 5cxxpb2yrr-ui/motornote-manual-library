DTC B1412: Immobilizer Control Module CAN Register Stuck

Diagnosis start condition: 

  • Battery voltage is 10 V or more.
  • The remote engine starter was not used to start the engine.

DTC detecting condition: 

  • Defective immobilizer control module
  • Failed to access the ROM of immobilizer control module

Trouble symptom: 

  • The security indicator does not blink after the ignition key is turned to OFF.
  • The security indicator remains off.
CAUTION: When the immobilizer control module is replaced, registration of the immobilizer system is required. For details, refer to the "REGISTRATION INSTRUCTIONS FOR IMMOBILIZER" provided as a separate volume.
  1. CHECK DTC. 
    1. Disconnect the ground terminal from battery.
    2. Wait for at least 10 seconds.
    3. Connect the ground cable to battery.
    4. Using the Subaru Select Monitor, perform the clear memory of [Immobilizer]. Refer to COMMON (DIAG)>CLEAR MEMORY .
    5. Read the DTC of [Immobilizer] using the Subaru Select Monitor. Refer to IMMOBILIZER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

      Is DTC B1412 displayed? (Current malfunction)

      Yes:  Go to  2.

      No:  Currently, it is normal.
