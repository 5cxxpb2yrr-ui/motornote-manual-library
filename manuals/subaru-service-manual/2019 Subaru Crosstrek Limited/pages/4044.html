Keyless Access Indoor Antenna: Inspection

Check the keyless access interior antenna using the Subaru Select Monitor.

  1. Check the setting by performing the keyless access with push button start system check. Refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS)>KEYLESS ACCESS WITH PUSH BUTTON START CHECK .
