DTC P060B-16: Hybrid/EV Battery Energy Control Module A/D Processing Circuit Voltage Below Threshold: Notes

Do you like it dark? Easier on the eyes.

WARNING: This page is about a different variant/trim than selected.

1. - 

Outline of diagnosis: 

Battery ECU assembly internal malfunction

(1 trip detection logic)

Trouble symptom: 

  • Reduced output power
  • Engine not stopped
CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to P-HEV HIGH VOLTAGE BATTERY (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK DTC. 

    Using the Subaru Select Monitor, read DTCs of the following system. Refer to P-HEV HIGH VOLTAGE BATTERY (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) . Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    • P-HEV High Voltage Battery
    • P-HEV Hybrid Powertrain Control
