Inspection Mode 1

DTC Item Note
B1401 COMBINATION METER COLLATION -
B1402 IMMOBILIZER KEY COLLATION -
B1407 COMBINATION METER COMMUNICATION -
B1408 COMBINATION METER NON-VOLATILE MEMORY -
B1410 TRANSPONDER COMMUNICATION -
B1411 IMMOBILIZER ANTENNA -
B1413 IMMOBILIZER CONTROL MODULE BATTERY POWER SUPPLY -

Diagnostic procedure:

  1. Using the Subaru Select Monitor, perform the clear memory of [Body Control] or [Immobilizer]. Refer to COMMON (DIAG)>CLEAR MEMORY .
  2. Read the DTC of [Body Control] or [Immobilizer] using Subaru Select Monitor and check that the DTC is not displayed. Refer to IMMOBILIZER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
    NOTE: If the DTC is displayed on the screen, the trouble is still present. Perform the diagnosis for the displayed DTCs. After solving the DTC, repeat from step  1.
  3. Remove the ignition key from the ignition switch, and insert again.
  4. Turn the ignition switch OFF → ON, and wait for 10 seconds or more.
  5. Read the DTC of [Body Control] or [Immobilizer] using Subaru Select Monitor and check that the DTC is not displayed. Refer to IMMOBILIZER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
    NOTE: If the DTC is displayed on the screen, the trouble is still present. Perform the diagnosis for the displayed DTCs.
