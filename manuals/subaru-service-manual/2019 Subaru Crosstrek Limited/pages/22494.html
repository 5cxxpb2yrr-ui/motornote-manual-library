Active Test: Operation

Do you like it dark? Easier on the eyes.

CAUTION:
  • Be sure to perform the active test when READY is OFF.
  • After executing the active test, perform the memory clear. Refer to COMMON (DIAG)>CLEAR MEMORY .
  1. On [Start] screen, select [Diagnosis].
  2. On [Vehicle selection] screen, enter vehicle information and select [OK].
  3. On [Main Menu] screen, select [Each System].
  4. On [Select System] screen, select [AWD Control].
  5. On [Select Function] screen, select [Active Test].
