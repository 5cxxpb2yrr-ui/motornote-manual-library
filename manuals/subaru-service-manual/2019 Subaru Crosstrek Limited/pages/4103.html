Active Test: List

NOTE: Each output check continues to run for five seconds before stopping automatically.
Active test items Range Contents Execution condition
Driver seat sensor power supply Output Stop Perform the output check for the driver's door touch sensor. -
Passenger seat sensor power supply Output Stop Perform the output check for the passenger's door touch sensor. -
STSW Output Stop Turn on the STSW.(2) -
ACC Output Stop Turn on the ACC. -
IGN1/2 Output Stop Turn on the IGN1/2. -
IGB Output Stop Turn on the IGB. -
IGBD Output Stop Turn on the IGBD. -
Start SW character illumination lighted Output Stop Perform ON output of the push button ignition switch backup light.(1) -
Start SW indicator lighted (green) Output Stop Perform ON output of the push button ignition switch backup light.(1) -
Start SW indicator lighted (orange) Output Stop Perform ON output of the push button ignition switch backup light.(1) -
Steering lock power supply Output Stop Output the power supply signal from keyless access control module to steering lock control module. -
(1) When lit by a condition other than for active test, it will not become unlit even when set to either OFF or no output.

(2) When performed with ignition switch ON, engine will start. Therefore, great care must be exercised.
