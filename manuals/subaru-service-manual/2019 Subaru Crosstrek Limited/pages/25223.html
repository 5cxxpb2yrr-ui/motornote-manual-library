TEMPORARY STOP OF EyeSight

WARNING: This page is about a different variant/trim than selected.
  1. CHECK FOR PRESENCE OF TEMPORARY STOP CODES. 

    Check for the presence of the temporary stop codes. Refer to EYESIGHT (DIAGNOSTICS) (HEV)>EYESIGHT HALT CODE .

    Is a temporary stop code displayed?

    Yes:  Check EyeSight temporary stop code. Refer to EYESIGHT (DIAGNOSTICS) (HEV)>EYESIGHT HALT CODE .

    No:  Temporary stop does not occur. Make sure to interview with the customer, and also confirm that no DTCs are recorded.
