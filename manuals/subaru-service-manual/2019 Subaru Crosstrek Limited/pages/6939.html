Light Auto Display Is Not Displayed In The Electrical Parts Operation Status Screen

Detecting condition: 

MFD initial setting, communication circuit or MFD is abnormal.

Wiring diagram: 

  • Except for hybrid model
    • Multi-function display (MFD) system Refer to WIRING SYSTEM (IMPREZA MODEL)>MULTI-FUNCTION DISPLAY (MFD) SYSTEM>WIRING DIAGRAM . Refer to WIRING SYSTEM (CROSSTREK MODEL (EXCEPT FOR HEV))>MULTI-FUNCTION DISPLAY (MFD) SYSTEM>WIRING DIAGRAM .
    • CAN communication system Refer to WIRING SYSTEM (IMPREZA MODEL)>CAN COMMUNICATION SYSTEM>WIRING DIAGRAM . Refer to WIRING SYSTEM (CROSSTREK MODEL (EXCEPT FOR HEV))>CAN COMMUNICATION SYSTEM>WIRING DIAGRAM .
      Courtesy of SUBARU OF AMERICA, INC.
  • Hybrid model
    • Multi-function display (MFD) system Refer to WIRING SYSTEM (CROSSTREK MODEL (HEV))>MULTI-FUNCTION DISPLAY (MFD) SYSTEM>WIRING DIAGRAM .
    • CAN communication system Refer to WIRING SYSTEM (CROSSTREK MODEL (HEV))>CAN COMMUNICATION SYSTEM>WIRING DIAGRAM .
      Courtesy of SUBARU OF AMERICA, INC.
    CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to MULTI-FUNCTION DISPLAY (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. INITIAL SETTING. 
    1. Switch the MFD display screen to the electrical parts operation status screen.
    2. Move the light switch to AUTO position.

    Is AUTO light displayed?

    Yes:  Initial setting has not been made.

    No:  Go to  2.

  2. CHECK THE HARNESS BETWEEN THE MFD AND BODY INTEGRATED UNIT (EXCEPT FOR HYBRID MODEL) OR CENTRAL GATEWAY (HYBRID MODEL). 
    1. Turn the ignition switch to OFF.
    2. Disconnect the MFD connector.
    3. Disconnect the body integrated unit connector (except for hybrid model) or central gateway control module connector (hybrid model).
    4. Measure the harness resistance between the MFD connector and body integrated unit connector (except for hybrid model) or central gateway control module connector (hybrid model).

      Connector & terminal 

      Except for hybrid model 

      (i122) No. 19 - (B281) No. 17:

      (i122) No. 20 - (B281) No. 19:

      Hybrid model 

      (i122) No. 19 - (i366) No. 15:

      (i122) No. 20 - (i366) No. 16:

    Is the resistance less than 10 Ω?

    Yes:  Go to  3.

    No:  Repair or replace the open circuit of harness.

  3. CHECK THE BODY INTEGRATED UNIT (EXCEPT FOR HYBRID MODEL) OR CENTRAL GATEWAY (HYBRID MODEL). 

    Using the Subaru Select Monitor, read the DTC of [Body Control] (except for hybrid model) or [Central Gateway] (hybrid model). Refer to BODY CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) . Refer to CENTRAL GATEWAY (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed? (Current malfunction)

    Yes:  Perform the diagnosis according to displayed DTC. Refer to BODY CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST . Refer to CENTRAL GATEWAY (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Replace the MFD. Refer to INSTRUMENTATION/DRIVER INFO>MULTI-FUNCTION DISPLAY (MFD) .
