Disable Button

Do you like it dark? Easier on the eyes.

Vehicles with the auto stop/start off button, press the button to switch the system OFF. The button may illuminate to indicate the system is OFF. Deactivation using the button lasts only one key cycle. Press the button again to restore auto stop/start function. See Fig 1.
