DTC U1198: Lost Communication With Telematics System

DTC detecting condition: 

CAN data from data communication module is faulty.

Trouble symptom: 

  • There is no effect on MFD operation/display. (Except for hybrid model)
  • Cannot set timer charging from the smartphone. (Hybrid model)
NOTE: For the diagnostic procedure, refer to DTC U0074. Refer to MULTI-FUNCTION DISPLAY (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC U0074 CONTROL MODULE COMMUNICATION BUS "BODY-CAN" OFF .
