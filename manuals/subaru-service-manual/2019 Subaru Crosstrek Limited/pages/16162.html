Intake Manifold Assembly: Assembly

Do you like it dark? Easier on the eyes.

WARNING: This page is about a different variant/trim than selected.
  1. Install the engine wiring harness stay (A) and collector cover bracket (B).

    Tightening torque: 

    6.4 N.m (0.7 kgf-m, 4.7 ft-lb)

    Courtesy of SUBARU OF AMERICA, INC.
  2. Install the manifold absolute pressure sensor. Refer to FUEL INJECTION (FUEL SYSTEMS) (H4DO (HEV))>MANIFOLD ABSOLUTE PRESSURE SENSOR>INSTALLATION .
  3. Install the EGR pipe. Refer to EMISSION CONTROL (AUX. EMISSION CONTROL DEVICES) (H4DO (HEV))>EGR PIPE>INSTALLATION .
  4. Install the purge control solenoid valve. Refer to EMISSION CONTROL (AUX. EMISSION CONTROL DEVICES) (H4DO (HEV))>PURGE CONTROL SOLENOID VALVE>INSTALLATION .
  5. When the engine coolant (engine side) is drained before removing the intake manifold assembly
    1. Install the throttle body. Refer to FUEL INJECTION (FUEL SYSTEMS) (H4DO (HEV))>THROTTLE BODY>INSTALLATION .
