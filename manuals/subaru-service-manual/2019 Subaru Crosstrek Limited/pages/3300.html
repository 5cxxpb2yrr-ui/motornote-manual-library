Mud Guard: Installation

CAUTION: Install the mud guard - front so that the front end of the mud guard (b), except for the clip fixing point, comes inside the bumper face (a).
Courtesy of SUBARU OF AMERICA, INC.
  1. Install the mud guard - front.
  2. Install the under cover - front. Refer to EXTERIOR/INTERIOR TRIM>FRONT UNDER COVER>INSTALLATION .
  3. Install the spoiler assembly - side sill.
  4. Install the wheel.

    Tightening torque: 

    Wheel nut: 120 N.m (12.2 kgf-m, 88.5 ft-lb)

  5. Lower the vehicle.
