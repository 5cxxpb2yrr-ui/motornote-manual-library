Basic Diagnostic Procedure: Procedure

  1. PERFORM CUSTOMER INTERVIEW  .

    Ask the customer when and how the trouble occurred using the interview check list. Refer to AWD CONTROL (DIAGNOSTICS)>CHECK LIST FOR INTERVIEW .

    Did you interview the customer?

    Yes:  Go to  2.

    No:  Perform the interview.

  2. CHECK WARNING LIGHT  .

    Check the lighting status of AWD warning light in the combination meter.

    Is the AWD warning illuminated or blinking?

    Yes:  Go to  3.

    No:  Currently, it is normal.

  3. CHECK SUBARU SELECT MONITOR COMMUNICATION  .
    1. Turn the ignition switch to OFF.
    2. Connect the Subaru Select Monitor to data link connector. Refer to COMMON (DIAG)>DATA LINK CONNECTOR .
    3. Turn the ignition switch to ON and run the Subaru Select Monitor.
    4. Select [AWD Control].
      NOTE: For detailed operation procedures, refer to "Help" of application.

    Is communication possible?

    Yes:  Go to  4.

    No:  Check the communication circuit. Refer to AWD CONTROL (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE FOR SUBARU SELECT MONITOR COMMUNICATION .

  4. CHECK DTC  .

    Read the DTC of [AWD Control] using the Subaru Select Monitor. Refer to AWD CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are DTC, time stamp and freeze frame data displayed?

    Yes:  Record the DTC, time stamp and freeze frame data. Go to  5.

    No:  Currently, it is normal.

  5. PERFORM DIAGNOSIS  .
    1. Perform the diagnosis for the displayed DTCs. Refer to AWD CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .
    2. Repair or replace the faulty parts.
    3. Using the Subaru Select Monitor, perform the clear memory. Refer to COMMON (DIAG)>CLEAR MEMORY .
    4. Execute the inspection mode. Refer to AWD CONTROL (DIAGNOSTICS)>INSPECTION MODE .
    5. Check the readiness code using Subaru Select Monitor and confirm that the diagnosis is completed. Refer to AWD CONTROL (DIAGNOSTICS)>ALL READINESS DIAGNOSTIC CODE(S) .
    6. Read the DTC using Subaru Select Monitor. Refer to AWD CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed?

    Yes:  Repeat step  5 until DTC is not shown.

    No:  Finish the diagnosis.
