Diagnostic Method

WARNING: This page is about a different variant/trim than selected.

If the duration of time while the following conditions are met is longer than the time indicated, judge as NG.

JUDGMENT VALUE SPECIFICATION (CHARGE INCOMPLETE MALFUNCTION)

Malfunction Criteria Threshold Value
Monitoring value of charge voltage inside direct injection drive IC 18 V or less
JUDGMENT VALUE SPECIFICATION (OVER-CHARGE MALFUNCTION)

Malfunction Criteria Threshold Value
Monitoring value of charge voltage inside direct injection drive IC 80 V or more

Time needed for diagnosis:  Value of Map

ENGINE SPEED DESCRIPTION - MAP

Engine speed (rpm) 0 500 2000 4000
Time when calculation was performed 10 times (sec) 0.04 2.4 0.6 0.3

Malfunction indicator light illumination:  Illuminates as soon as a malfunction occurs.
