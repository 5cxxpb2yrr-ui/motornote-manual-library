Expansion Valve: Installation

Do you like it dark? Easier on the eyes.

CAUTION:
  • Since the auto A/C model uses the variable displacement compressor, be careful of the following items.
    • Do not start the engine before charging refrigerant.
    • If the engine is started with no refrigerant charge, replace the compressor assembly.
  • Replace the O-rings with new parts, and then apply compressor oil to install completely.
  1. Install the expansion valve - cooling.

    Preparation tool: 

    Hexagon wrench: 4 mm (0.16 in)

    Tightening torque: 

    3.5 N.m (0.4 kgf-m, 2.6 ft-lb)

  2. Install the hose - pressure suction and the pipe - evaporator cooling.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  3. Install the air intake boot. Refer to INTAKE (INDUCTION) (H4DO (EXCEPT FOR HEV))>Air Intake Boot>INSTALLATION .
  4. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
  5. Charge refrigerant. Refer to AIR CONDITIONER (EXCEPT FOR HEV)>REFRIGERANT CHARGING PROCEDURE>PROCEDURE .
