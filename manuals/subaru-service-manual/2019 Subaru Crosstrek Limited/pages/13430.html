Oil Pump: Installation

  1. Install the O-rings.
    NOTE:
    • Use new O-rings.
    • Apply CVTF to the O-rings.
    Courtesy of SUBARU OF AMERICA, INC.
  2. Install the plate and the oil pump.
    NOTE: Apply CVTF to the bolt.

    Tightening torque: 

    8.5 N.m (0.9 kgf-m, 6.3 ft-lb)

    Courtesy of SUBARU OF AMERICA, INC.
  3. Install the oil pump chain cover. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>OIL PUMP CHAIN>INSTALLATION .
  4. Install the torque converter assembly. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TORQUE CONVERTER ASSEMBLY>INSTALLATION .
  5. Install the transmission assembly to the vehicle. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>AUTOMATIC TRANSMISSION ASSEMBLY>INSTALLATION .
