Pedestrian Alert Control Unit: Installation

  1. Install the pedestrian alert control unit.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  2. Install the hybrid powertrain control module. Refer to HYBRID ELECTRIC VEHICLE>HYBRID POWERTRAIN CONTROL MODULE>INSTALLATION .
  3. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
