Hybrid Model

NOTE:
  • Before installation, remove mud and foreign matter from the disc brake assembly.
  • Check that the battery ground terminal is disconnected.
  1. Install the pad - disc brake rear.
  2. Install the caliper body assembly.
    CAUTION: Securely install the electronic parking brake harness connector.

    Tightening torque: 

    Guide pin - rear brake: 25 N.m (2.5 kgf-m, 18.4 ft-lb)

    Brake hose bracket: 33 N.m (3.4 kgf-m, 24.3 ft-lb)

  3. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY>GROUND TERMINAL REMOVAL OR INSTALLATION .
  4. Using the Subaru Select Monitor, exit the brake maintenance mode according to the display screen. Refer to PARKING BRAKE>PARKING BRAKE SYSTEM>OPERATION>BRAKE MAINTENANCE MODE .
    NOTE: For detailed operation procedures, refer to "Help" of application.
  5. After the operation is completed, apply and release the parking brake five times and ensure that the brake operates normally.
  6. Install the rear wheels.

    Tightening torque: 

    120 N.m (12.2 kgf-m, 88.5 ft-lb)
