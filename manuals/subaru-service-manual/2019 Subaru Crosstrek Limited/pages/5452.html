Except For Hybrid Model

  1. Check and adjust the operating rod of the vacuum booster assembly.
    1. Measure the length between the vacuum booster assembly mounting surface and clevis pin hole.
    2. If it is not within the specification, loosen the lock nut, rotate the vacuum booster assembly operating rod to adjust the rod length.

      Specification L: 

      136.3 mm (5.37 in)

    Courtesy of SUBARU OF AMERICA, INC.
  2. Install the vacuum booster assembly.

    Tightening torque: 

    18 N.m (1.8 kgf-m, 13.3 ft-lb)

    CAUTION:
    • When installing a new vacuum booster assembly, be sure to apply a damping sheet. (Models with EyeSight)
    • Apply grease to the snap pin to prevent the operating rod from wear.
    • Replace the clevis pin with a new part, and apply a thin coat of grease to the clevis pin.

      Preparation items: 

      • Impreza model

        Grease (clevis pin): Shell Gadus S2 V220 or equivalent

      • Crosstrek model

        Grease (clevis pin): IDEMITSU APOLLOIL AUTOLEX A or equivalent

    • When installing the master cylinder assembly, replace the ring seal with a new part, and install it to the vacuum booster assembly. (Impreza model)
    • When installing the master cylinder assembly, replace the seal sub assembly with a new part, and install it to the vacuum booster assembly. (Crosstrek)
    Courtesy of SUBARU OF AMERICA, INC.
  3. Install the duct - foot driver. Refer to AIR CONDITIONER (EXCEPT FOR HEV)>HEATER DUCT>INSTALLATION>FOOT>LH SIDE .
  4. Install the column assembly - steering. Refer to POWER ASSISTED SYSTEM (POWER STEERING)>STEERING COLUMN>INSTALLATION .
  5. Install the universal joint assembly - steering. Refer to POWER ASSISTED SYSTEM (POWER STEERING)>UNIVERSAL JOINT>INSTALLATION .
    CAUTION:
    • Always install the universal joint assembly - steering after installing the steering column to avoid damage to the universal joint assembly - steering.
    • Be sure to follow the tightening order and tightening torque of the universal joint assembly - steering to avoid the steering effort from becoming heavy. After confirming that the steering column position is in the neutral position, tighten the universal joint assembly - steering.
    • Always place the tilt lever to the lock position after the steering column is adjusted.
  6. Install the knee airbag module.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  7. Install the cover assembly - instrument panel LWR driver.
  8. Install the brake pipe assembly to the pipe clip.
  9. Install the master cylinder assembly. Refer to BRAKE>MASTER CYLINDER>INSTALLATION .
  10. Install the engine control module (ECM). Refer to FUEL INJECTION (FUEL SYSTEMS) (H4DO (EXCEPT FOR HEV))>ENGINE CONTROL MODULE (ECM)>INSTALLATION .
  11. Install the clutch connector bracket. (MT model)

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  12. Install the vacuum hose. Refer to BRAKE>BRAKE VACUUM PUMP>INSTALLATION>BRAKE VACUUM HOSE & PIPE .
  13. Bleed air from the master cylinder. Refer to BRAKE>AIR BLEEDING>PROCEDURE>MASTER CYLINDER (EXCEPT FOR HYBRID MODEL) .
  14. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY>GROUND TERMINAL REMOVAL OR INSTALLATION .
  15. Install the front and rear wheels.

    Tightening torque: 

    120 N.m (12.2 kgf-m, 88.5 ft-lb)

  16. Perform a road test to make sure the brakes do not drag.
