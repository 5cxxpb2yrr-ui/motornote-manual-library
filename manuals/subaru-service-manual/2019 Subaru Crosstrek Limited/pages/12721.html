Seat Belt Outer - Rear RH And LH (5 Door Model)

  1. Before installation, perform a unit inspection of retractor. Refer to SEAT BELT SYSTEM>REAR SEAT BELT>INSPECTION .
  2. Install the seat belt outer - rear.
    CAUTION:
    • During installation, make sure that the seat belts are not twisted.
    • After installation, make sure that the seat belts are smoothly extended and wound.

    Tightening torque:

    Rear seat belt: Refer to SEAT BELT SYSTEM>GENERAL DESCRIPTION>COMPONENT>REAR SEAT BELT (5 DOOR MODEL) .

  3. Install the duct - battery cooling blower. (Hybrid model) Refer to HYBRID ELECTRIC VEHICLE>HIGH VOLTAGE BATTERY COOLING SYSTEM>INSTALLATION>FRONT DUCT .
  4. Install the trim panel - rear apron. (Hybrid model) Refer to EXTERIOR/INTERIOR TRIM>REAR QUARTER TRIM>INSTALLATION>5 DOOR MODEL (HYBRID) .
  5. Install the trim panel - rear apron. (Except for hybrid model) Refer to EXTERIOR/INTERIOR TRIM>REAR QUARTER TRIM>INSTALLATION>5 DOOR MODEL (EXCEPT FOR HYBRID) .
  6. Install the cover side sill - rear INN.
  7. Install the rear seat cushion assembly.
  8. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
  9. After installation, check the following points.
    • The seat belt is not twisted.
    • The seat belt can be pulled out and retracted smoothly.
