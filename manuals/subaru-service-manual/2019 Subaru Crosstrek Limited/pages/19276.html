Active Test: Operation

WARNING: This page is about a different variant/trim than selected.
  1. On [Start] screen, select [Diagnosis].
  2. On [Vehicle selection] screen, input the target vehicle information and select [OK].
  3. On [Main Menu] screen, select [Each System].
  4. On [Select System] screen, select [Air Conditioner], and then select [Enter].
  5. On [Select Function] screen, select [Active Test].
NOTE:
  • For detailed operation procedures, refer to "Help" of application.
  • For details on active tests, refer to the list. Refer to AIR CONDITIONER (DIAGNOSTICS) (HEV)>ACTIVE TEST>LIST .
