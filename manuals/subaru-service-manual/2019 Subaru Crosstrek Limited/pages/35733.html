DTC C1B5D: Motor Control Circuit

Do you like it dark? Easier on the eyes.

DTC detecting condition: 

The pump does not operate when the electrically controlled booster sends drive request to the pump motor (faulty relay inside electric booster).

Trouble symptom: 

EyeSight functions (ACC/PCS) do not operate.

  1. CHECK DTC. 

    Read the DTC using Subaru Select Monitor. Ref. to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is only DTC C1B5D displayed?

    Yes:  Replace the brake booster assembly (with the master cylinder). Ref. to BRAKE>BRAKE BOOSTER .

    No:  Perform the diagnosis according to DTC. Ref. to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .
