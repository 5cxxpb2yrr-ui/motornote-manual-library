Passenger's Airbag Module: Installation

CAUTION:
  • Before handling the airbag system components, refer to "CAUTION" of "General Description" in "AIRBAG SYSTEM". Refer to AIRBAG SYSTEM>GENERAL DESCRIPTION>CAUTION .
  • Do not allow harness and connectors to interfere or get tangled up with other parts.
  • When reusing the tether clip on the upper part of the trim panel - front pillar UPR, check that there is no damage to the tether clip. If the tether clip is damaged, always replace it with a new tether clip. If the tether clip is damaged, its holding force is reduced and the trim panel - front pillar UPR may come off.
  1. Before installation, inspect the following items and replace any faulty part with a new one.
    • Passenger's airbag lid (instrument panel surface) is cracked or deformed.
    • Airbag module is cracked or deformed.
    • Harness and/or connector is cracked, deformed or open.
    • Harness wire is exposed.
    • Mounting bracket is cracked or deformed.
  2. Install the panel COMPL - instrument. Refer to EXTERIOR/INTERIOR TRIM>INSTRUMENT PANEL ASSEMBLY>INSTALLATION .
  3. Install the switch assembly - combination and the cover assembly - column.
  4. Install the panel - starter SW and the push button ignition switch. (Model with keyless access with push button start)
  5. Install the cover - starter SW. (Model without the keyless access with push button start)
  6. Install the combination meter assembly, the cover assembly - visor LWR, and the visor assembly - combination meter.
  7. Install the steering wheel. Refer to POWER ASSISTED SYSTEM (POWER STEERING)>STEERING WHEEL>INSTALLATION .
  8. Install the driver's airbag module. Refer to AIRBAG SYSTEM>DRIVER'S AIRBAG MODULE>INSTALLATION .
  9. Install the knee airbag module. Refer to AIRBAG SYSTEM>KNEE AIRBAG MODULE>INSTALLATION .
  10. Install the cover assembly - instrument panel LWR driver.
  11. Install the glove box assembly.
  12. Install the trim panel - front pillar UPR on the left and right sides.
  13. Install the grille speaker side on the left and right sides.
  14. Install the tray - center UPR and the panel center LWR.
  15. Install the heater control assembly.
  16. Install the panel center LWR on the left and right sides.
  17. Install the console box assembly.

    Tightening torque:

    6.5 N.m (0.7 kgf-m, 4.8 ft-lb)

  18. Install the cover assembly - front.
  19. Install the mat - center tray, the tray - center LWR, and the boot - hand brake.
  20. Install the multi-function display assembly.
  21. Install the audio assembly or navigation assembly.
  22. Install the panel - center UPR.
  23. Install the center grille assembly.
  24. Install the cover - instrument panel side on the left and right sides.
  25. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
NOTE: After connecting the battery ground terminal, place the select lever in the "P" position.
