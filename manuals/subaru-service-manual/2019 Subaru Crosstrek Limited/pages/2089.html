Sonar Sensor

HEIGHT AND ANGLE INSPECTION 

CAUTION: Perform the inspection for each sonar sensor at curb weight.
  1. Before performing measurement, check the following items.
    1. The vehicle is parked on a level surface.
    2. The inflation pressure of tires is correct.
    3. The vehicle does not have load.
    4. Check the areas around the sensor and the bumper face - rear for any scratches or other type of deformation.
  2. Prepare the measure, plumb bob, leveling line, angle gauge and try square.
  3. Measure installation height of the sonar sensor.
    NOTE: The figure for Crosstrek model is only shown here. For Impreza model, perform the same procedure as Crosstrek model.
    1. Suspend the plumb bob with leveling line from the sensor, and mark the position where the plumb bob touches the ground. (Point A)
      NOTE: Stick the packing tape etc. on the floor, then make a marking on the tape.
    2. Measure the height from the sensor to the marked Point A.
      Courtesy of SUBARU OF AMERICA, INC.
    3. Confirm that sensor installation height is within the acceptable limit.

    Specification:

    Impreza model (4 door model): 555 - 605 mm (21.85 - 23.82 in)

    Impreza model (5 door model): 545 - 595 mm (21.46 - 23.43 in)

    Crosstrek model: 665 - 715 mm (26.18 - 28.15 in)

  4. Measure the installation angle of the sonar sensor.
    1. Using an angle gauge and try square, measure the installation angle as shown in the figure.
      Courtesy of SUBARU OF AMERICA, INC.
      NOTE: Use the measurement tools while placing them perpendicularly to the sonar sensor.
    2. Confirm that sensor installation angle is within the acceptable limit.

    Specification:

    • Impreza model (4 door model): 0.5° - 5.5°
    • Impreza model (5 door model): 2.5° - 7.5°
    • Crosstrek model
    • Inner: 3° - 9°
    • Corner: 4.5° - 9.5 °
  5. If the inspection result is not within the standard value, the bumper face - rear, bezel - sonar or sonar sensor may be improperly installed or deformed. Check the installation status of each part, and perform inspection again.
