For C5

Do you like it dark? Easier on the eyes.

Diagnosis start condition: 

  • Battery voltage is 10 V or more.
  • The remote engine starter was not used to start the engine.

DTC detecting condition: 

Use of unregistered key in immobilizer control module.

Trouble symptom: 

  • Engine will not start.
  • The security indicator illuminates, when the ignition key is inserted into the ignition switch or when the ignition switch is turned to ON.
CAUTION: When the immobilizer control module is replaced, registration of the immobilizer system is required. For details, refer to the "REGISTRATION INSTRUCTIONS FOR IMMOBILIZER" provided as a separate volume.
  1. CONFIRM NUMBER OF REGISTERED IGNITION KEY. 

    Using the Subaru Select Monitor, check the number of registered ignition keys. Refer to the "REGISTRATION INSTRUCTIONS FOR IMMOBILIZER" provided as a separate volume.

    Is one or more ignition key(s) registered?

    Yes:  Go to  2.

    No:  Register the immobilizer.

  2. CHECK IGNITION KEY. 
    1. Prepare all the pre-registered ignition keys.
    2. Insert the ignition key in the ignition switch.
    3. Turn the ignition switch to ON.
    4. Read the DTC of [Immobilizer] using the Subaru Select Monitor. Refer to IMMOBILIZER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
    5. Perform step  2 to  4 with another registered ignition key.

      Is DTC B1402 displayed for all ignition keys? (Current malfunction)

      Yes:  Refer to "REGISTRATION INSTRUCTIONS FOR IMMOBILIZER" provided as a separate volume, and perform the actions for the case that all keys are faulty/lost.

      No:  Go to  3.

  3. REGISTRATION OF IGNITION KEY. 

    Register the key. Refer to the "REGISTRATION INSTRUCTIONS FOR IMMOBILIZER" provided as a separate volume.

    Is the key registration completed normally?

    Yes:  Malfunction occurred in ignition key.

    No:  Replace the ignition key.
