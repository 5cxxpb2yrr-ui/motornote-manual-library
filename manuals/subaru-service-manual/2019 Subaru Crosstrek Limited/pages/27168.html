Inspection Mode 23

Do you like it dark? Easier on the eyes.

WARNING: This page is about a different variant/trim than selected.
Code Note Number of driving cycles on the detecting condition
P1C2E46 - 2

Diagnostic procedure:

  1. Using the Subaru Select Monitor, perform the clear memory of [P-HEV Drive Motor]. Refer to COMMON (DIAG)>CLEAR MEMORY .
  2. Turn to IG OFF, and wait for two minutes or more.
  3. Using the Subaru Select Monitor, read the DTC of [P-HEV Drive Motor] to check that there is no DTC displayed. Refer to P-HEV DRIVE MOTOR (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
    NOTE: If the DTC is displayed on the screen, the trouble is still present. Perform the diagnosis for the displayed DTCs. After solving the DTC, repeat from step  1.
  4. Turn to IG ON, and wait for five seconds or more.
  5. Turn to IG OFF, and wait for two minutes or more.
  6. Turn to IG ON, and wait for five seconds or more.
  7. Read the [Readiness code] of [P-HEV Drive Motor] using Subaru Select Monitor and check that the concerned self-diagnosis is completed. Refer to P-HEV DRIVE MOTOR (DIAGNOSTICS)>ALL READINESS DIAGNOSTIC CODE(S) .
    NOTE: If the concerned DTC is displayed, the self-diagnosis of the DTC is not complete. Repeat from step  4.
  8. Using the Subaru Select Monitor, read the DTC of [P-HEV Drive Motor] to check that there is no DTC displayed. Refer to P-HEV DRIVE MOTOR (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
    NOTE: If the DTC is displayed on the screen, the trouble is still present. Perform the diagnosis for the displayed DTCs.
