Monitor Description

WARNING: This page is about a different variant/trim than selected.

A malfunction is detected and the MIL is illuminated when one of the following conditions is met:

  1. Answer-back for battery charger start permission signal is ON while battery charger start permission signal from HV main CPU is ON and battery charger start permission signal from monitor CPU is OFF.
  2. Answer-back for battery charger start permission signal is ON while battery charger start permission signal from HV main CPU is OFF and battery charger start permission signal from monitor CPU is ON.
