FOTA Does Not Operate

Probable cause: 

No contract agreement, out of service area, server side malfunction, DCM malfunction, antenna malfunction, navigation unit malfunction

CAUTION:
  • After the DCM is replaced, registrations of CommCheck and immobilizer system are required. Refer to ENTERTAINMENT & MONITORING>TELEMATICS SYSTEM>OPERATION>REGISTRATION (COMM CHECK) .
  • Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to TELEMATICS SYSTEM (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK NAVIGATION UNIT. 
    1. Turn the ignition switch to ON.
    2. Check whether installation-in-progress remains displayed on the screen.

    Does it remain displayed?

    Yes:  Check the navigation unit. Refer to ENTERTAINMENT & MONITORING>NAVIGATION SYSTEM . If no fault is found, Go to  2.

    No:  Go to  2.

  2. CHECK THE TELEMATICS BUTTON (LED). 

    Check that the telematics button (LED) illuminates.

    Does the RED LED or the GREEN LED illuminate?

    Yes:  Go to  3.

    No:  Check the telematics button. Refer to ENTERTAINMENT & MONITORING>SWITCHES AND HARNESS . If no fault is found, Go to  3.

  3. CHECK DEFECTIVE DCM. 

    Connect the Subaru Select Monitor and select [Telematics].

    Is there any response?

    Yes:  Initialize the navigation unit memory, Refer to INFOTAINMENT (DIAGNOSTICS)>SERVICE DIAGNOSTICS MODE>OPERATION . Go to  4.

    No:  Replace the DCM. Refer to ENTERTAINMENT & MONITORING>DATA COMMUNICATION MODULE .

  4. CHECK THE SUBSCRIPTION STATUS. 

    Using the Subaru Select Monitor, check the following items in the [Data monitor] of [Telematics]. Refer to TELEMATICS SYSTEM (DIAGNOSTICS)>DATA MONITOR .

    • Over The Air Active

    Is the data [TRUE]?

    Yes:  Go to  5.

    No:  The user does not have a service subscription; therefore, it is not a failure.

  5. CHECK DTCS. 

    Read the following DTCs using Subaru Select Monitor.

    • Telematics Refer to TELEMATICS SYSTEM (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
    • Infotainment Refer to INFOTAINMENT (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed?

    Yes:  Initialize the navigation unit memory, Refer to INFOTAINMENT (DIAGNOSTICS)>SERVICE DIAGNOSTICS MODE>OPERATION . and perform the diagnosis for the displayed DTCs. Refer to TELEMATICS SYSTEM (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST . Refer to INFOTAINMENT (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Currently no failure is found.
