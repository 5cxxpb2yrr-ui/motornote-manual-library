Release Bearing And Lever: Installation

Do you like it dark? Easier on the eyes.

WARNING: This page is about a different variant/trim than selected.
  1. Apply grease of 0.5 - 0.8 g (0.02 - 0.03 oz) to the contact surface (dented portion) of the release lever and pivot.

    Grease 

    NICHIMOLY N-130 or equivalent

  2. Apply 0.2 g (0.01 oz) of grease to the contact surface (dented portion) of the release lever and operating cylinder.

    Grease 

    NICHIMOLY N-130 or equivalent

  3. Apply grease to the transmission main shaft spline, the contact surface of the release lever and release bearing, and the contact surface of the release bearing and transmission case.

    Grease 

    NICHIMOLY N-130 or equivalent

  4. While pushing the release lever to the pivot and twisting it to both sides, fit the lever spring onto the raised portion of the pivot.
    CAUTION: Observing from the main case hole, check that the lever spring is installed securely.
  5. Install the release bearing and fasten it with two clips.
  6. Install the dust cover.
    Courtesy of SUBARU OF AMERICA, INC.
  7. Operate the release lever and check if the release bearing moves smoothly.
  8. Install the manual transmission assembly.
