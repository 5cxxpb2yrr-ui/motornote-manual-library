Without Keyless Access With Push Button Start System

Do you like it dark? Easier on the eyes.

CAUTION: When the body integrated unit (except for C5 model) or the immobilizer control module (C5 model) is replaced, registration of the immobilizer system is required. For details, refer to the "REGISTRATION INSTRUCTIONS FOR IMMOBILIZER" provided as a separate volume.
  1. PERFORM CUSTOMER INTERVIEW. 

    Ask the customer when and how the trouble occurred using the interview check list. Refer to IMMOBILIZER (DIAGNOSTICS)>CHECK LIST FOR INTERVIEW .

    Did you interview the customer?

    Yes:  Go to  2.

    No:  Perform the interview, and Go to  2.

  2. CONFIRM NUMBER OF REGISTERED IMMOBILIZER KEY. 

    Confirm the number of registered immobilizer key. For details, refer to the "REGISTRATION INSTRUCTIONS FOR IMMOBILIZER" provided as a separate volume.

    Is the number of registration 0?

    Yes:  Register the immobilizer system.

    No:  Go to  3.

  3. CHECK SECURITY INDICATOR LIGHT. 
    1. Remove the ignition key from ignition switch.
    2. Wait at least 60 seconds.

      Does the security indicator light blink?

      Yes:  Go to  4.

      No:  Check the security indicator light circuit. Refer to IMMOBILIZER (DIAGNOSTICS)>WARNING LIGHT ILLUMINATION PATTERN .

  4. CHECK KEY SWITCH. 

    Insert the ignition key in the ignition switch. (OFF or ACC)

    Does the security indicator light remain blinking?

    Yes:  Check the key switch circuit. Refer to IMMOBILIZER (DIAGNOSTICS)>DIAGNOSTICS WITH PHENOMENON>INSPECTION>CHECK KEY SWITCH CIRCUIT .

    No:  Go to  5.

  5. CHECK SECURITY INDICATOR LIGHT. 

    Check the security indicator light status in the condition of step 4.

    Does the security indicator light go off?

    Yes:  Go to  8.

    No:  Go to  6.

  6. CHECK SECURITY INDICATOR LIGHT. 

    Turn the ignition switch to ON.

    Does the security indicator light go off?

    Yes:  Go to  8.

    No:  Go to  7.

  7. CHECK ENGINE START. 

    Turn the ignition switch to START.

    Does the starter operate?

    Yes:  Check the LAN system. Refer to LAN SYSTEM (DIAGNOSTICS) (EXCEPT FOR HEV)>BASIC DIAGNOSTIC PROCEDURE .

    No:  Go to  9.

  8. CHECK ENGINE START. 

    Turn the ignition switch to START.

    Does the engine start?

    Yes:  Immobilizer system is normal.

    No:  Go to  10.

  9. CHECK DTC. 

    Read the following DTCs using Subaru Select Monitor. Refer to IMMOBILIZER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    • Body Control (except for C5 model)
    • Immobilizer (for C5 model)
    NOTE: Check the Subaru Select Monitor communication if the communication is disabled. Refer to IMMOBILIZER (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE FOR SUBARU SELECT MONITOR COMMUNICATION .

    Are any DTCs displayed?

    Yes:  Record the DTC, time stamp and freeze frame data, and Go to  11.

    No:  Replace the body integrated unit (except for C5 model) or the immobilizer control module (C5 model). Refer to SECURITY AND LOCKS>BODY INTEGRATED UNIT .

  10. CHECK DTC. 

    Read the DTC of [Engine Control System] using the Subaru Select Monitor. Refer to ENGINE (DIAGNOSTICS) (H4DO (EXCEPT FOR HEV))>DIAGNOSTIC TROUBLE CODE (DTC) .

    NOTE: Check the Subaru Select Monitor communication if the communication is disabled. Refer to IMMOBILIZER (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE FOR SUBARU SELECT MONITOR COMMUNICATION .

    Are any DTCs displayed? (Current malfunction)

    Yes:  Record the DTC, time stamp and freeze frame data, and Go to  11.

    No:  Perform the diagnosis for engine system. Refer to ENGINE (DIAGNOSTICS) (H4DO (EXCEPT FOR HEV))>BASIC DIAGNOSTIC PROCEDURE>PROCEDURE .

  11. CHECK FREEZE FRAME DATA. 

    Check the freeze frame data. Refer to IMMOBILIZER (DIAGNOSTICS)>FREEZE FRAME DATA .

    Are the data recorded?

    Yes:  Record the data. Go to  12.

    No:  Go to  12.

  12. CHECK DTC. 

    Check the displayed DTC.

    Are DTCs irrelevant to the immobilizer displayed? (Current malfunction)

    Yes:  Perform the diagnosis according to DTCs irrelevant to the immobilizer first.

    No:  Go to  13.

  13. PERFORM DIAGNOSIS. 
    1. Perform the diagnosis for the displayed DTCs. Refer to IMMOBILIZER (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC) .
    2. Repair or replace the cause of trouble.
    3. Using the Subaru Select Monitor, perform the clear memory. Refer to COMMON (DIAG)>CLEAR MEMORY .
      • Body Control (except for C5 model)
      • Immobilizer (for C5 model)
    4. Execute the inspection mode. Refer to IMMOBILIZER (DIAGNOSTICS)>INSPECTION MODE .
    5. Read the DTC using Subaru Select Monitor. Refer to IMMOBILIZER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
      • Body Control (except for C5 model)
      • Immobilizer (for C5 model)

      Are any DTCs displayed? (Current malfunction)

      Yes:  Repeat step  13 until DTC is not shown.

      No:  Finish the diagnosis.
