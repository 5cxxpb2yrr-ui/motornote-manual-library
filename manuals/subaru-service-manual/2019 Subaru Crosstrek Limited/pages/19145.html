A/C Pipe

Do you like it dark? Easier on the eyes.

WARNING: This page is about a different variant/trim than selected.
CAUTION: Replace the O-rings with new parts, and then apply compressor oil to install completely.
  1. Install the pipe - sensor.
    1. Install the pipe - sensor.

      Tightening torque: 

      7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

    2. Connect the connector of the pressure sensor.
    3. Install the bracket - air conditioner wire.

      Tightening torque: 

      7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

    4. Connect the upper connector of the engine control module (ECM). Refer to FUEL INJECTION (FUEL SYSTEMS) (H4DO (HEV))>ENGINE CONTROL MODULE (ECM)>INSTALLATION .
    5. Connect the connector and harness of the main fuse box.
    6. Install the engine harness bracket.
    7. Install the battery cable assembly. Refer to STARTING/CHARGING SYSTEMS (H4DO (HEV))>BATTERY CABLE ASSEMBLY>INSTALLATION .
  2. Install the pipe - return assembly. Refer to AIR CONDITIONER (HEV)>HOSE AND PIPE>INSTALLATION>RETURN PIPE .
  3. Install the hose - pressure suction discharge. Refer to AIR CONDITIONER (HEV)>HOSE AND PIPE>INSTALLATION>HIGH-PRESSURE HOSE .
  4. Install the radiator assembly. Refer to COOLING (H4DO (HEV))>RADIATOR>INSTALLATION .
  5. Install the bumper face - front. Refer to EXTERIOR/INTERIOR TRIM>FRONT BUMPER>INSTALLATION .
  6. Install the battery and battery tray. Refer to STARTING/CHARGING SYSTEMS (H4DO (HEV))>BATTERY>INSTALLATION .
  7. Charge refrigerant. Refer to AIR CONDITIONER (HEV)>REFRIGERANT CHARGING PROCEDURE>PROCEDURE .
