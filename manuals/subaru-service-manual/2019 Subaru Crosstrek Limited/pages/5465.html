Brake System (Hybrid Model)

CAUTION: To avoid battery discharge, perform the operation under the following condition.
  • Perform the operation while the battery is being charged.
  • While bleeding air, close all doors and do not operate any electrical parts.
  1. Lift up the vehicle, and then remove the front and rear wheels.
  2. Remove cap - reservoir tank.
  3. Bleed air from the brake system.
    1. Add brake fluid to between the MIN and MAX marks on the reservoir tank.
    2. Using the Subaru Select Monitor, select [Brake System Air Bleeding] of [Brake Air Bleeding] on the [Work Support] display. Refer to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>WORK SUPPORT .
    3. Follow the instructions on the Subaru Select Monitor screen and bleed the air from the brake system.
      NOTE: For air bleeding of each brake caliper, refer to "Brake line (except for hybrid model)". Refer to BRAKE>AIR BLEEDING>PROCEDURE>BRAKE LINE (EXCEPT FOR HYBRID MODEL) .
    4. After bleeding air from the brake system, turn the ignition switch OFF and tighten each of the bleeder-screws to the specified torque.

      Tightening torque: 

      Front: 8 N.m (0.8 kgf-m, 5.9 ft-lb)

      Rear: 17 N.m (1.7 kgf-m, 12.5 ft-lb)

  4. Install cap - reservoir tank.
  5. Erase the diagnostic code. Refer to BRAKE CONTROL (DIAGNOSTICS) (HEV)>DIAGNOSTIC TROUBLE CODE (DTC) .
  6. Check that there are no brake fluid leaks in the entire brake system.
  7. If there is noise from the engine compartment which could be caused by an air bleeding failure, perform the following diagnosis.
    NOTE: Perform forced refresh of the actuator up to three times.
    1. CHECK DTC  .
      1. Using the Subaru Select Monitor, perform the clear memory. Refer to COMMON (DIAG)>CLEAR MEMORY .
      2. Read the DTC using Subaru Select Monitor. Refer to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

      Are any DTCs displayed?

      Yes:  Perform the diagnosis according to the DTC. Refer to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

      No:  Go to  2.

    2. AIR BLEEDING FROM BRAKE SYSTEM  .
      1. Using the Subaru Select Monitor, perform the clear memory. Refer to COMMON (DIAG)>CLEAR MEMORY .
      2. Using the Subaru Select Monitor, select [Brake System Air Bleeding] of [Brake Air Bleeding] on the [Work Support] display. Refer to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>WORK SUPPORT .
      3. Follow the instructions on the Subaru Select Monitor screen and bleed the air from the brake system.
      4. Depress the brake pedal and check for abnormal noise from the engine compartment.

      Is the check result OK?

      Yes:  Go to  3.

      No:  Go to  4.

    3. CHECK DTC  .
      1. Using the Subaru Select Monitor, perform the clear memory. Refer to COMMON (DIAG)>CLEAR MEMORY .
      2. Read the DTC using Subaru Select Monitor. Refer to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

      Are any DTCs displayed?

      Yes:  Perform the diagnosis according to the DTC. Refer to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

      No:  Finish the diagnosis.

    4. PERFORMING ACTUATOR FORCED REFRESH (1ST TIME)  .
      CAUTION: Because hydraulic pressure is generated while actuator forced refresh is performed, do not operate the brake pedal or perform work on the brake system.
      NOTE: While actuator forced refresh is in progress, the accumulator pressure may drop and the meter buzzer may sound.
      1. Check the following conditions.
        • Shift position indicator shows P when the shifter is in P.
        • Set the parking brake to ON.
        • Vehicle speed 0 km/h (0 MPH)
        • Do not operate the brake pedal while actuator forced refresh is in progress.
        • The READY indicator in the combination meter assembly illuminates. (Can be performed when ignition is ON or with power supply backup.)
      2. Using the Subaru Select Monitor, select [Forced refresh of Actuator.] of [Brake Air Bleeding] on the [Work Support] display. Refer to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>WORK SUPPORT .
      3. Follow the instructions on the Subaru Select Monitor screen and perform actuator forced refresh.
      4. Check time required for the actuator forced refresh.
      CAUTION: If the required time was less than 10 minutes 50 seconds, it is possible that actuator forced refresh was not completed successfully. Check the conditions and perform actuator forced refresh again.

      Is the check result OK?

      Yes:  Go to  5.

      No:  Perform actuator forced refresh again.

    5. CHECK FOR ABNORMAL NOISE  .
      1. Depress the brake pedal and check for abnormal noise from the engine compartment.

      Is the check result OK?

      Yes:  Go to  6.

      No:  Go to  7.

    6. CHECK DTC  .
      1. Using the Subaru Select Monitor, perform the clear memory. Refer to COMMON (DIAG)>CLEAR MEMORY .
        NOTE: Performing actuator forced refresh may cause DTC: C1B6E and DTC: C1B6F to be stored. After the actuator forced refresh, perform memory clear.
      2. Read the DTC using Subaru Select Monitor. Refer to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

      Are any DTCs displayed?

      Yes:  Perform the diagnosis according to the DTC. Refer to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

      No:  Finish the diagnosis.

      1. Depress the brake pedal and check for abnormal noise from the engine compartment.

      Is the check result OK?

      Is the check result OK?

      Yes:  -

      No:  Perform actuator forced refresh again.

  8. Install the front and rear wheels.

    Tightening torque: 

    120 N.m (12.2 kgf-m, 88.5 ft-lb)
