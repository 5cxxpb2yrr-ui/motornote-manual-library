EV Charger

WARNING: This page is about a different variant/trim than selected.
WARNING: The hybrid system includes a high voltage circuit. Mishandling could cause accidents such as electric shock or leak. Always check "WARNING (HYBRID SYSTEM)" and perform the proper operation. Refer to PRECAUTION/WARNING>WARNING (HYBRID SYSTEM) .
CAUTION: Airbag system satellite safing sensor is located under the front center of the rear seat cushion. Be careful not to apply strong impact to the sensor when working with the rear seat cushion removed.
  1. Install the EV charger assembly.
    WARNING:
    • Be sure to wear insulated gloves.
    • Be sure to use an insulating sheet at locations other than the work location.

    Tightening torque: 

    HV battery: Refer to HYBRID ELECTRIC VEHICLE>GENERAL DESCRIPTION>COMPONENT>HV BATTERY .

    NOTE: Use the ST and tighten the bolts shown in the figure below.

    Preparation tool: 

    ST: Special tool condenser (73099SG000)

    Calculation formula
    T = L/(100 mm (3.94 in) + L) x 7.5 N.m (0.8 kgf-m, 5.5 ft-lb)
    T: Tightening torque
    L: Effective length of torque wrench
    NOTE: If the effective length of the torque wrench used is unknown, consult the manufacturer of the torque wrench.
    Courtesy of SUBARU OF AMERICA, INC.
    Courtesy of SUBARU OF AMERICA, INC.
  2. Install the frame battery - upper COMPL.
    WARNING: Be sure to wear insulated gloves.

    Tightening torque: 

    HV battery: Refer to HYBRID ELECTRIC VEHICLE>GENERAL DESCRIPTION>COMPONENT>HV BATTERY .

  3. Install the cover - charger.
    WARNING: Be sure to wear insulated gloves.

    Tightening torque: 

    HV battery: Refer to HYBRID ELECTRIC VEHICLE>GENERAL DESCRIPTION>COMPONENT>HV BATTERY .

  4. Install the cover - battery front.
    WARNING: Be sure to wear insulated gloves.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  5. Install the bar - floor front COMPL.

    Tightening torque: 

    28 N.m (2.9 kgf-m, 20.7 ft-lb)

  6. Install the cover - sensor.
    WARNING: Be sure to wear insulated gloves.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  7. Connect the main battery cable assembly.
    WARNING: Be sure to wear insulated gloves.
    CAUTION: Make sure the main battery cable assembly connector is connected securely.
  8. Install the charger duct. Refer to HYBRID ELECTRIC VEHICLE>ELECTRIC VEHICLE CHARGER>INSTALLATION>CHARGER DUCT .
  9. Install the duct assembly - cooling out. Refer to HYBRID ELECTRIC VEHICLE>HIGH VOLTAGE BATTERY COOLING SYSTEM>INSTALLATION>REAR DUCT .
  10. Install the Reverse Automatic Braking control module. Refer to REVERSE AUTOMATIC BRAKING>REVERSE AUTOMATIC BRAKING CONTROL MODULE >INSTALLATION .
  11. Install the trim panel - rear apron. Refer to EXTERIOR/INTERIOR TRIM>REAR QUARTER TRIM>INSTALLATION .
  12. Install the backrest assembly LH and rear seat cushion assembly. Refer to SEATS>REAR SEAT>INSTALLATION .
  13. Install the service disconnect plug. Refer to HYBRID ELECTRIC VEHICLE>SERVICE PLUG>INSTALLATION .
  14. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
