Heater Duct: Installation: Rear

Do you like it dark? Easier on the eyes.

CAUTION: Before handling the airbag system components, refer to "CAUTION" of "General Description" in "AIRBAG SYSTEM". Refer to AIRBAG SYSTEM>GENERAL DESCRIPTION>CAUTION .
  1. Install the duct - rear heater rear.
    NOTE: For models with power amplifier, install the duct - extension.
  2. Install the floor mat. Refer to EXTERIOR/INTERIOR TRIM>FLOOR MAT>INSTALLATION .
  3. Install the front seat. Refer to SEATS>FRONT SEAT>INSTALLATION .
  4. Install the duct - rear heater front. Refer to AIR CONDITIONER (HEV)>HEATER DUCT>INSTALLATION>FRONT .
  5. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
