Diagnostic procedure: 

  1. Start the engine.
  2. Check the readiness code using Subaru Select Monitor and confirm that the diagnosis is not completed. Refer to TRANSMISSION (DIAGNOSTICS)>ALL READINESS DIAGNOSTIC CODE(S) .
  3. Accelerate slowly to a legal speed, and then decelerate slowly to a stop.
  4. Check the readiness code using Subaru Select Monitor, confirm that the diagnosis is completed, and end the procedure.
