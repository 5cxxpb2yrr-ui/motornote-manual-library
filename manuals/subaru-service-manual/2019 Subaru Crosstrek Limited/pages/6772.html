Combination Meter System: Inspection: Buzzer

  1. Using the Subaru Select Monitor, perform the active test for buzzer. Refer to COMBINATION METER (DIAGNOSTICS)>ACTIVE TEST .
  2. If no buzzer sounds, replace the combination meter assembly.
