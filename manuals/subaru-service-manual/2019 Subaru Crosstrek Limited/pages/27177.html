NOTE: The following "Examples of several DTCs output" must be used as reference of abnormal conditions. Therefore, do not use the examples when actually performing the check.

Examples of several DTCs output

  1. The power supply in microcomputer is reduced while driving.
    1. DTCs are detected and the vehicle behavior is as follows.

      Detected DTCs

      • DTC P060B1C (HYBRID/EV POWERTRAIN CONTROL MODULE A/D PROCESSING VOLTAGE OUT OF RANGE) Microcomputer malfunction*
      • DTC P0C5016 (DRIVE MOTOR "A" POSITION SENSOR CIRCUIT "A" CIRCUIT VOLTAGE BELOW THRESHOLD) Sensor and actuator circuit malfunction*
      • DTC P0A3F16 (DRIVE MOTOR "A" POSITION SENSOR CIRCUIT VOLTAGE BELOW THRESHOLD) Sensor and actuator circuit malfunction*
      • DTC P1CAD49 (DRIVE MOTOR "A" POSITION SENSOR INTERNAL ELECTRONIC FAILURE) Sensor and actuator circuit malfunction*
      • DTC P1CAC49 (GENERATOR POSITION SENSOR INTERNAL ELECTRONIC FAILURE) Sensor and actuator circuit malfunction*

        *: Check the priority level using "DTC priority" table described above.

      Vehicle behavior

      Hybrid system stopped

    2. The inspection priority is as follows: "Microcomputer system → Power supply system → Communication system → Sensor/actuator system → System". Therefore, check the repair procedure of DTC P060B1C.
    3. Replace the Hybrid vehicle control ECU assembly according to the repair procedure. Repair finished.

    This allows you to identify the defective area without performing unnecessary checks.
