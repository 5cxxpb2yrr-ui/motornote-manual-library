Water Pump Pulley

Do you like it dark? Easier on the eyes.

WARNING: This page is about a different variant/trim than selected.
  1. Using the ST1 and ST2, install the water pump pulley.

    Preparation tool: 

    ST1: PULLEY WRENCH (18355AA000)

    ST2: PULLEY WRENCH PIN SET (18334AA020)

    Tightening torque: 

    14 N.m (1.4 kgf-m, 10.3 ft-lb)

  2. Install the V-belts.

    Refer to MECHANICAL (H4DO (EXCEPT FOR HEV))>V-BELT>INSTALLATION>HYBRID MODEL>V-BELT .
