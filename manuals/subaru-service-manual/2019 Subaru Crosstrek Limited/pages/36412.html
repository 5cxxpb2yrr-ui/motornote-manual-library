IMPREZA Model

Do you like it dark? Easier on the eyes.

  1. Pinch the metal clip with pliers, and remove it from the assist grip BRKT.
  2. Install the metal clip to the assist grip side.
  3. Install the cap to the assist grip.
    NOTE: If the metal clip is not inserted to the end, the cap cannot be installed.
  4. Install the assist grip to the vehicle.
