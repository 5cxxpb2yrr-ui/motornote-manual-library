Diagnostic Method

Judge as NG when one of the following conditions is established.

JUDGMENT VALUE SPECIFICATION

Malfunction Criteria Threshold Value
  1. Main throttle opening angle - Main throttle opening angle at monitoring start
 1.6% or more
(2) Monitoring IC register writing value Not equal to the reading value
(3) Self test error Detect

Time needed for diagnosis: 

  1. 24 ms
  2. 200 ms
  3. 2 times

Malfunction indicator light illumination:  Illuminates as soon as a malfunction occurs.
