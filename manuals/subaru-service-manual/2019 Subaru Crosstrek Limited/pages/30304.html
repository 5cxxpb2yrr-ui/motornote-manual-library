Section 3 (HVAC System (Heater, Ventilator And A/C) (HEV)): Accumulator: Installation

WARNING: This page is about a different variant/trim than selected.
  1. Install the bracket - A/C accumulator.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  2. Install the cable - front hood and the cable - safety. Refer to SECURITY AND LOCKS>FRONT HOOD LOCK ASSEMBLY>INSTALLATION>LOCK ASSEMBLY .
  3. Install the A/C accumulator assembly.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  4. Install the hose - pressure suction and the hose - pressure suction COMPL.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  5. Install the bracket - hose - pressure suction COMPL.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  6. Install the inverter tank. Refer to COOLING (H4DO (HEV))>INVERTER TANK>INSTALLATION .
  7. Install the bracket - hood stay.

    Tightening torque: 

    18 N.m (1.8 kgf-m, 13.3 ft-lb)

  8. Install the cover UPR - front.
  9. Install the air intake duct. Refer to INTAKE (INDUCTION) (H4DO (EXCEPT FOR HEV))>AIR INTAKE DUCT>INSTALLATION .
  10. Install the under cover - front. Refer to EXTERIOR/INTERIOR TRIM>FRONT UNDER COVER>INSTALLATION .
  11. Install the collector cover. Refer to INTAKE (INDUCTION) (H4DO (EXCEPT FOR HEV))>COLLECTOR COVER>INSTALLATION .
  12. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
  13. Charge refrigerant. Refer to AIR CONDITIONER (HEV)>REFRIGERANT CHARGING PROCEDURE>PROCEDURE .
