Radiator Fan and Fan Motor Assembly: Assembly

Do you like it dark? Easier on the eyes.

  1. Install the main fan motor and the sub fan motor.

    Tightening torque: 

    4.41 N.m (0.45 kgf-m, 3.25 ft-lb)

  2. Install the radiator main fan and the radiator sub fan.
    CAUTION: Use new nuts (with locking agent).

    Tightening torque: 

    3.43 N.m (0.35 kgf-m, 2.53 ft-lb)

  3. Install the main fan motor harness and the sub fan motor harness.
  4. Install the over flow hose and the over flow pipe.
