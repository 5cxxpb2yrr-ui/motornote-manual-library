Charging Inlet Door

WARNING: This page is about a different variant/trim than selected.
  1. Install the push-lifter.
  2. Install the EV charger lid switch assembly.

    Tightening torque: 

    4.5 N.m (0.5 kgf-m, 3.3 ft-lb)

  3. Install a new charging inlet light.
    NOTE: The gasket is integrated with the charging inlet light.
  4. Install the push-lifter.
