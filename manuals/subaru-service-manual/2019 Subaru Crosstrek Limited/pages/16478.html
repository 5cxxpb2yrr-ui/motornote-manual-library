Accessory Power Supply Socket: Installation: Front

Do you like it dark? Easier on the eyes.

  1. Install the socket assembly.
    NOTE: Align the groove of the tray - center UPR with the claw of the socket assembly.
  2. Install the heater control assembly. Refer to AIR CONDITIONER (EXCEPT FOR HEV)>CONTROL PANEL>INSTALLATION .
  3. Install the audio assembly or navigation assembly.
  4. Install the grille assembly - CTR ventilation.
  5. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
