Inspection Mode 2

DTC Item Note
B1412 IMMOBILIZER CONTROL MODULE CAN REGISTER STUCK -
B1414 IMMOBILIZER CONTROL MODULE NONVOLATILE MEMORY -

Diagnostic procedure:

  1. Using the Subaru Select Monitor, perform the clear memory of [Immobilizer]. Refer to COMMON (DIAG)>CLEAR MEMORY .
  2. Using the Subaru Select Monitor, read the DTC of [Immobilizer] to check that there is no DTC displayed. Refer to IMMOBILIZER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
    NOTE: If the DTC is displayed on the screen, the trouble is still present. Perform the diagnosis for the displayed DTCs. After solving the DTC, repeat from step  1.
  3. Disconnect and reconnect the battery, and then wait for one minute or more.
  4. Turn the ignition switch to ON.
  5. Using the Subaru Select Monitor, read the DTC of [Immobilizer] to check that there is no DTC displayed. Refer to IMMOBILIZER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
    NOTE: If the DTC is displayed on the screen, the trouble is still present. Perform the diagnosis for the displayed DTCs.
