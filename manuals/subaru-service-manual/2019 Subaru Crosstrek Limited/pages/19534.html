DTC P0A1F-94: Hybrid/EV Battery Energy Control Module Unexpected Operation: Notes

WARNING: This page is about a different variant/trim than selected.

1. - 

Outline of diagnosis: 

Information of Battery ECU assembly was received at the main CPU of Hybrid vehicle control ECU assembly, and an unexpected value continued for a predetermined period of time

(1 trip detection logic)

Trouble symptom: 

  • Reduced output power
  • Engine not stopped
CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK DTC  .

Read the DTC of [P-HEV Hybrid Powertrain Control] using the Subaru Select Monitor. Refer to PHEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

Is DTC other than P0A1F94 displayed?

Yes:  Perform the diagnosis for DTC other than P0A1F94. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

No:  Replace Battery ECU assembly. Refer to HYBRID ELECTRIC VEHICLE>BATTERY CONTROL MODULE .
