Charging Time Is Long

WARNING: This page is about a different variant/trim than selected.
CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to PLUG-IN BATTERY CHARGER (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK DTC. 

    Using the Subaru Select Monitor, read all DTCs. Refer to COMMON (diag)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed?

    Yes:  Perform the diagnosis for the displayed DTCs.

    No:  Go to  2.

  2. CHECK DATA MONITOR. 
    1. Using the Subaru Select Monitor, display the following items in the [Work Support] of [Plug-in Battery Charger]. Refer to PLUG-IN BATTERY CHARGER (DIAGNOSTICS)>WORK SUPPORT .
      • Vehicle Ctl. Hist.
    2. Using the Subaru Select Monitor, display the following items in the [Work Support] of [P-HEV Hybrid Powertrain Control]. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>WORK SUPPORT .
      • Vehicle Ctl. Hist.
    3. Check the vehicle control history.

    Is the vehicle control history displayed?

    Yes:  Go to the vehicle control history.

    • Plug-in Battery Charger. Refer to PLUG-IN BATTERY CHARGER (DIAGNOSTICS)>WORK SUPPORT .
    • P-HEV Hybrid Powertrain Control. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>WORK SUPPORT .

    No:  Go to  3.

  3. CHECK CHARGING. (USE AN AC POWER SUPPLY WHICH WAS CONFIRMED TO OPERATE NORMALLY.). 
    CAUTION:
    • Perform charging with an AC power supply that was confirmed to operate normally.
    • Select an AC power supply (120 V or 240 V) that is the same as the power supply used by the customer.
    1. Using the Subaru Select Monitor, perform all memory clear. Refer to COMMON (DIAG)>CLEAR MEMORY .
    2. Using the Subaru Select Monitor, display the following items in the [Work Support] of [Plug-in Battery Charger]. Refer to PLUG-IN BATTERY CHARGER (DIAGNOSTICS)>WORK SUPPORT .
      • Vehicle Ctl. Hist.
    3. Using the Subaru Select Monitor, clear all memory of [Vehicle Control History]. Refer to COMMON (DIAG)>CLEAR MEMORY .
    4. Using the Subaru Select Monitor, display the following items in the [Work Support] of [P-HEV Hybrid Powertrain Control]. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>WORK SUPPORT .
      • Vehicle Ctl. Hist.
    5. Using the Subaru Select Monitor, clear all memory of [Vehicle Control History]. Refer to COMMON (DIAG)>CLEAR MEMORY .
    6. Using the Subaru Select Monitor, display the following items in the [Data Monitor] of [P-HEV Hybrid Powertrain Control]. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DATA MONITOR .
      • Hybrid Battery SOC
    7. Read the data monitor, and check that the HV battery SOC is less than 70%.
      NOTE: If the HV battery SOC is 70% or more, perform driving in EV mode or use other means to discharge the HV battery and reduce the SOC to less than 70%.
      Item name Item explanation Display range Standard
      Hybrid Battery SOC Indicates the battery capacity. 0.00 - 100.00% 0.00 - 100.00%: Always
    8. Turn ON "Charge Now".
      NOTE:
      • This is not necessary when there is nothing registered in the timer charging schedule.
      • How to set Charge Now
        • Press the Timer charging setting switch.
        • Display the MFD "Charge timer settings" screen and select Charge Now.
    9. Turn the ignition to OFF.
    10. Connect the Electric vehicle charger cable assembly and charge until charging is completed.
    11. Turn to IG ON.
    12. Using the Subaru Select Monitor, read all DTCs. Refer to COMMON (diag)>DIAGNOSTIC TROUBLE CODE (DTC) .
    13. Using the Subaru Select Monitor, display the following items in the [Work Support] of [Plug-in Battery Charger]. Refer to PLUG-IN BATTERY CHARGER (DIAGNOSTICS)>WORK SUPPORT .
      • Vehicle Ctl. Hist.
    14. Using the Subaru Select Monitor, display the following items in the [Work Support] of [P-HEV Hybrid Powertrain Control]. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>WORK SUPPORT .
      • Vehicle Ctl. Hist.

    If a DTC is displayed, go to  A.

    If a vehicle control history is displayed, go to  B.

    If no DTC or vehicle control history is displayed, and the charging time is long, go to  C.

    If no DTC or vehicle control history is displayed, and the charging time is not long, go to  D.

    Yes: 

    1. Perform the diagnosis for the displayed DTCs.
    2. Go to the vehicle control history.
      • Plug-in Battery Chargers Refer to PLUG-IN BATTERY CHARGER (DIAGNOSTICS)>WORK SUPPORT .
      • P-HEV Hybrid Powertrain Control. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>WORK SUPPORT .
    3. Analyze the cause (vehicle cause).

      Analyze the cause as shown below.

      • Battery (12V) deterioration
        • Check the Battery (12V). Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
      • Accuracy of remaining charging time display
        • Explain that the remaining charging time display is an approximate guide, and may deviate due to causes such as the temperature of the HV battery during charging.
      • Prioritizing full charge (when the timer setting is the set departure time)
        • Explain that when the air conditioner is started before the departure time that is set in the timer settings, charging may continue after the set departure time was reached.
    4. Analyze the cause (environment or user cause).

      Analyze the cause as shown below in order: environment → user.

    Environment

    • Low power level due to low AC voltage on charger side
      • Ask questions to customer and check charger.
      • Explain that the charging time will be longer when the AC voltage is low.
    • Low power level due to control on charger side
      • Ask questions to customer and check charger.
      • Explain that power restrictions on the charger side may cause charging times to become longer. (Check using the charger instructions.)
    • Paused due to power outage during charging.
      • Explain that charging stops when there is a power outage and that it resumes when power is restored.
    • Reduced charging control power or changes in predicted charging time resulting from outdoor air temperature and temperature of the HV battery
      • Explain that when the temperature of the HV battery changes, the charging time may become longer.
      • In particular when the outdoor air temperature is low, the HV battery heater operates in order to ensure EV traveling distance and this can result in a longer charging time.
    • Abnormal heating of the power plug was detected.
      • Explain that when abnormal heating at the outlet and power plug connector occurs during charging, the charging current may be restricted based on detection of the temperature inside the power plug, resulting in a longer charging time.
      • Check that there is no deterioration of the power outlet and no looseness in the connection.
    • A 120 V Electric vehicle charger cable assembly was used.
      • Explain that 120 V charging requires more time than 240 V charging.

    User

    • Switching of charging current
      • Explain that when the charging current is set to 8 A in the MFD charging settings, the charging time will be longer.
    • Large power consumption resulting from failure to turn off headlights or use of other accessories
      • Explain that power consumption by accessories may cause charging times to become longer.
