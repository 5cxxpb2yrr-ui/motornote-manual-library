DTC B2B09: Driver's Door Power Window Control Module EEPROM

DTC detecting condition: 

When one of the following data cannot be read from the non-volatile memory as the CPU is reset.

  • Window position
  • Sliding learn value
  • Initialization completed state
  • Full open stop position

Trouble symptom: 

  • When the power window main switch is operated, driver's side window does not work.
  • When the power window main switch is operated, driver's side window rolls down only in manual down operation, or inches up. (Inch up: Operating the switch rolls up the window about 10 mm only)
CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to POWER WINDOW (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. INITIALIZATION BY POWER WINDOW SWITCH (DRIVER'S SIDE). 
    1. Perform initialization using the power window switch. Refer to POWER WINDOW (DIAGNOSTICS)>WORK SUPPORT>NOTE .
    2. Read the DTC of [Power Window (Driver)] using the Subaru Select Monitor. Refer to POWER WINDOW (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

      Is DTC B2B09 displayed? (Current malfunction)

      Yes:  Go to  2.

      No:  Even if DTC is displayed. The circuit has returned to a normal condition at this time.

      Reproduce the failure, and then perform the diagnosis again.

      NOTE: In this case, temporary poor contact of connector, temporary open or short circuit of harness may be the cause.
  2. SYSTEM INITIALIZATION. 
    1. Using the Subaru Select Monitor, perform [System Initialization] of [Power Window (Driver)].

      Refer to POWER WINDOW (DIAGNOSTICS)>WORK SUPPORT>OPERATION>SYSTEM INITIALIZATION .

      NOTE: Record the DTCs and FFD because they will be erased when the initialization is performed.
    2. Read the DTC of [Power Window (Driver)] using the Subaru Select Monitor. Refer to POWER WINDOW (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

      Is DTC B2B09 displayed? (Current malfunction)

      Yes:  Replace the front regulator & motor assembly (driver's side). Refer to GLASS/WINDOWS/MIRRORS>FRONT REGULATOR AND MOTOR ASSEMBLY .

      No:  Even if DTC is displayed. The circuit has returned to a normal condition at this time.

      Reproduce the failure, and then perform the diagnosis again.

      NOTE: In this case, temporary poor contact of connector, temporary open or short circuit of harness may be the cause.
