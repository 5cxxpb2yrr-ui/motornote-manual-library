DTC C2543: Error Passive

Do you like it dark? Easier on the eyes.

DTC detecting condition: 

When send/receive failure of CAN communication is detected after the ignition switch is ON.

Trouble symptom: 

The steering wheel operation feels heavy.

Wiring diagram: 

Electric power steering system Refer to WIRING SYSTEM (IMPREZA MODEL)>ELECTRIC POWER STEERING SYSTEM . Refer to WIRING SYSTEM (CROSSTREK MODEL (EXCEPT FOR HEV))>ELECTRIC POWER STEERING SYSTEM . Refer to WIRING SYSTEM (CROSSTREK MODEL (HEV))>ELECTRIC POWER STEERING SYSTEM .

Courtesy of SUBARU OF AMERICA, INC.
CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to POWER STEERING (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK PERIPHERALS. 

    Check the data link connector.

    Is any other electrical part connected to the data link connector or harness?

    Yes:  Disconnect the connection of electrical parts and perform inspection again.

    No:  Go to  2.

  2. CHECK LAN SYSTEM. 

    Perform the diagnosis for LAN system using the Subaru Select Monitor. Refer to LAN SYSTEM (DIAGNOSTICS) (EXCEPT FOR HEV)>BASIC DIAGNOSTIC PROCEDURE . Refer to LAN SYSTEM (DIAGNOSTICS) (HEV)>BASIC DIAGNOSTIC PROCEDURE .

    Is DTC of CAN communication displayed?

    Yes:  Perform the diagnosis according to the DTC. Refer to LAN SYSTEM (DIAGNOSTICS) (EXCEPT FOR HEV)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Go to  3.

  3. CHECK DTC. 

    Read the DTC of [Power Steering System] using the Subaru Select Monitor. Refer to POWER STEERING (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC C2543 displayed in current malfunction?

    Yes:  Go to  4.

    No:  System is normal. Temporary interference from noise is a possible cause. Clear the memory to complete the diagnosis. Refer to COMMON (DIAG)>CLEAR MEMORY .

  4. CHECK CONNECTOR. 

    Check the connecting condition of connector.

    Is the connector firmly installed?

    Yes:  Go to  5.

    No:  Install the connector, and check again.

  5. CHECK CONNECTOR. 
    1. Turn the ignition switch to OFF.
    2. Disconnect the connector (B204).

    Is there crimped or spread portion in connector terminal on vehicle harness side and power steering control module side?

    Yes:  Repair or replace faulty parts.

    No:  Go to  6.

  6. CHECK HARNESS. 

    Check the harness related to CAN communication system.

    Is there any fault in the harness?

    Yes:  Repair or replace the harness.

    No:  Replace the steering gearbox. Refer to POWER ASSISTED SYSTEM (POWER STEERING)>ELECTRIC POWER STEERING GEARBOX .
