Hybrid Model

• CHECK ACCELERATOR PEDAL SENSOR AREA (METHOD WITH CIRCUIT TESTER) 

  1. Turn to IG ON.
  2. Measure the voltage between terminals of the hybrid vehicle control computer connector.
    NOTE:
    • For location, refer to "Electrical Component Location" for "P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)" service information. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>ELECTRICAL COMPONENT LOCATION>LOCATION .
    • For details concerning the hybrid vehicle control computer connector, refer to "Control Module I/O Signal" of "P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)" service information. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>CONTROL MODULE I/O SIGNAL>ELECTRICAL SPECIFICATION .
    Courtesy of SUBARU OF AMERICA, INC.
    Accelerator pedal position sensor Accelerator pedal Terminal No. Standard
    Main Not depressed (full closed) 28 (+) - 18 (-) 0.4 - 1.4 V
    Depressed (full opened) 2.6 - 4.5 V
    Sub Not depressed (full closed) 20 (+) - 29 (-) 1.0 - 2.2 V
    Depressed (full opened) 3.4 - 5.3 V
  3. After inspection, restore the vehicle to its original state.

• CHECK ACCELERATOR PEDAL SENSOR AREA (METHOD WITH SUBARU SELECT MONITOR) 

  1. Connect the Subaru Select Monitor.
  2. Turn to IG ON.
  3. Read the accelerator opening angle and the accelerator sensor voltage using Subaru Select Monitor. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DATA MONITOR .
    Accelerator pedal position sensor Accelerator pedal opening angle Standard
    I/O signal name Data monitor name
    Main No. 1 0%-100% The opening angle should change gently.
    Sub No. 2

• OTHER INSPECTIONS 

  1. Check that there is no deformation, cracks or other damages.
  2. Check for smooth operation when the accelerator pedal is depressed.
  3. Check if the accelerator pedal returns to its original position smoothly when the pedal is released.
