Grommet Installation

Use the following procedures to install the grommet.

  • Install the grommet stored in the glove box to the tie-down hole. (Impreza model)
  • Install the grommet provided on the rear seat to the tie-down hole. (Crosstrek model)
CAUTION: Make sure that the tie-down hole is firmly plugged with the grommet. Otherwise, dust, smell, etc. may come into the passenger compartment indirectly from the rear quarter, via the side sill from the tie-down hole.
