DTC P0E31-1C: Boosting Converter Voltage Sensor "A" Voltage Out Of Range: Notes

WARNING: This page is about a different variant/trim than selected.

1. - 

Outline of diagnosis: 

Property abnormality of the boosting converter voltage (VL) sensor

With boosting not performed, difference between voltage before boosting (VL) and battery voltage (VB) is large, and, at the same time, difference between voltage before boosting (VL) and voltage after boosting (VH) is large 

(1 trip detection logic)

Trouble symptom: 

Normal driving

CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK DTC  .

    Read the following DTCs using Subaru Select Monitor. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) . Refer to P-HEV DRIVE MOTOR (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) . Refer to P-HEV HIGH VOLTAGE BATTERY (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
