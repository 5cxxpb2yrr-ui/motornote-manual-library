Steering Lock System

Symptoms Note
The steering lock cannot be released (Cannot start the engine (except for hybrid model) or READY ON is not possible (hybrid model)) Refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS)>DIAGNOSTICS WITH PHENOMENON>INSPECTION>THE STEERING LOCK IS NOT RELEASED .
The steering lock does not operate. Refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS)>DIAGNOSTICS WITH PHENOMENON>INSPECTION>THE STEERING LOCK DOES NOT OPERATE .
