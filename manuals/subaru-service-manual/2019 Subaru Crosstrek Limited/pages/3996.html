Front Hood Opener

  1. Install the bracket - opener handle.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  2. Before installation, check the following items.
    • Cable is free from deformation such as fray.
  3. Install the cable - front hood.
    NOTE: Pull the string attached to the body into the vehicle, and install the cable clip and cable - front hood.
  4. Install the mud guard - front LH. Refer to EXTERIOR/INTERIOR TRIM>MUD GUARD>INSTALLATION .
  5. Install the cover assembly - instrument panel LWR driver OUT.
  6. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
