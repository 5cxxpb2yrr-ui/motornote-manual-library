DTC U0424-81: HVAC Control Module To Hybrid Powertrain Control Module Invalid Serial Data Received: Notes

Do you like it dark? Easier on the eyes.

WARNING: This page is about a different variant/trim than selected.

1. - 

Outline of diagnosis: 

A/C control module failure

Hybrid vehicle control ECU assembly receives communication malfunction from A/C control module

(1 trip detection logic)

Trouble symptom: 

-

CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK DTC  .

    Read the DTC of [Air Conditioner] using the Subaru Select Monitor. Refer to AIR CONDITIONER (DIAGNOSTICS) (HEV)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed?

    Yes:  Perform the diagnosis for the displayed DTCs. Refer to AIR CONDITIONER (DIAGNOSTICS) (HEV)>DIAGNOSTIC TROUBLE CODE (DTC) .

    No:  Replace A/C control module. Refer to AIR CONDITIONER (HEV)>CONTROL PANEL .
