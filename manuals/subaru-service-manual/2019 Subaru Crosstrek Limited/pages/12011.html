Display Transmitter ID Operation

NOTE: In the following procedure, the Subaru Select Monitor must be used.
  1. Connect Subaru Select Monitor.
  2. On "MAIN MENU" display screen, select "EACH SYSTEM CHECK" and press YES/OK key.
  3. On "SYSTEM SELECTION MENU" display screen, select "TIRE PRESSURE MONITORING" and press YES/OK key.
  4. Press YES/OK key after "TIRE PRESSURE MONITORING" is displayed.
  5. On "TIRE PRESSURE MONITOR DIAGNOSIS" display screen, select "TRANSMITTER ID REGIST CONFIRM" and press YES/OK key.
  6. Select "TRANSMITTER ID DATA MONITOR", and press YES/OK key to display transmitter ID.
