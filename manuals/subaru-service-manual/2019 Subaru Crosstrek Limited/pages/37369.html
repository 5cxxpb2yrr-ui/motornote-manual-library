Hybrid Model

Wiring diagram: 

Reverse Automatic Braking Refer to WIRING SYSTEM (CROSSTREK MODEL (HEV))>REVERSE AUTOMATIC BRAKING>WIRING DIAGRAM .

Courtesy of SUBARU OF AMERICA, INC.
  1. CHECK WARNING LIGHT. 

    Is the RAB warning light blinking and an EyeSight failure displayed?

    Yes:  Repair the open circuit in the harness between the stereo camera and combination meter.

    No:  Go to  2.

  2. CHECK LAN SYSTEM. 

    Perform the diagnosis for LAN system. Refer to LAN SYSTEM (DIAGNOSTICS) (HEV)>BASIC DIAGNOSTIC PROCEDURE>PROCEDURE .

    Is the check result OK?

    Yes:  Go to  3.

    No:  Perform the inspection according to the diagnosis for LAN system.

  3. READ DTC. 

    Read the DTC of [Reverse Automatic Braking] using the Subaru Select Monitor. Refer to REVERSE AUTOMATIC BRAKING (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is a DTC related to the EyeSight system displayed? (Current malfunction)

    Yes:  Go to  4.

    No:  Go to  5.

  4. READ DTC. 

    Read the DTC of [EyeSight] using the Subaru Select Monitor. Refer to EYESIGHT (DIAGNOSTICS) (HEV)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is a DTC related to the central gateway displayed? (Current malfunction)

    Yes:  Go to  5.

    No:  Perform the diagnosis for the EyeSight system. Refer to EYESIGHT (DIAGNOSTICS) (HEV)>BASIC DIAGNOSTIC PROCEDURE>PROCEDURE .

  5. READ DTC. 

    Read the DTC of [Central Gateway] using the Subaru Select Monitor. Refer to CENTRAL GATEWAY (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is a DTC related to the combination meter displayed? (Current malfunction)

    Yes:  Go to  6.

    No:  Perform the diagnosis for the central gateway. Refer to CENTRAL GATEWAY (DIAGNOSTICS)>BASIC DIAGNOSTIC PROCEDURE>PROCEDURE .

  6. CHECK COMBINATION METER. 

    Check the combination meter. Refer to INSTRUMENTATION/DRIVER INFO>COMBINATION METER SYSTEM>OPERATION>SELF-DIAGNOSIS DISPLAY MODE .

    Is the check result OK?

    Yes:  Replace the RAB control module. Refer to REVERSE AUTOMATIC BRAKING>REVERSE AUTOMATIC BRAKING control module .

    No:  Replace the combination meter. Refer to INSTRUMENTATION/DRIVER INFO>COMBINATION METER SYSTEM .
