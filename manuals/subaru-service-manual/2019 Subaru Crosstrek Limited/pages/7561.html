Exhaust System: Muffler: Installation

  1. Install the rear exhaust cover.

    Tightening torque: 

    10 N.m (1.0 kgf-m, 7.4 ft-lb)

  2. Apply a coat of spray type lubricant to the mating area of cushion rubber.
  3. Install the muffler.
    NOTE: After installation, degrease the cushion rubber.
  4. Set a new gasket, and connect the rear exhaust pipe and muffler.
    CAUTION: Be sure to use a new self-locking nut.

    Tightening torque: 

    48 N.m (4.9 kgf-m, 35.4 ft-lb)
