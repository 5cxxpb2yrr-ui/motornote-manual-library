Front Bumper: Assembly

  1. Install the bumper guard front. (Hybrid model)
  2. Install the cover intake - front.
  3. Install the energy absorber LWR - front.
  4. Remove the clips, and install the sealing bumper - front and the plate UPR - front.
  5. Install the cover - fog light.
  6. Install the fog light assembly - front or the light assembly - daytime running.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  7. Install the front grille assembly.
