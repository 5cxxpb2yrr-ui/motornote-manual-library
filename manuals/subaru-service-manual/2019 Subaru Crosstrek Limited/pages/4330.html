Rear Gate Garnish: Installation

CAUTION:
  • Make sure that there is a gasket attached on the clip of the spoiler assembly or garnish assembly and bolt. If a gasket is not attached, water leakage may occur.
  • Make sure that the harness grommet is securely installed. If not properly installed, this may cause leaks or noises.
  1. Install each part.
    • Switch - opener rear gate: Refer to SECURITY AND LOCKS>REAR GATE OPENER BUTTON>INSTALLATION .
  2. Install the garnish assembly - rear gate.

    Tightening torque: 

    Garnish assembly - rear gate: 4.5 N.m (0.5 kgf-m, 3.3 ft-lb)

  3. Install the rear gate trim.
  4. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
