Active Test: Operation

WARNING: This page is about a different variant/trim than selected.
  1. On [Start] screen, select [Diagnosis].
  2. On [Vehicle selection] screen, enter vehicle information and select [OK].
  3. On [Main Menu] screen, select [Each System].
  4. On [Select System] screen, select [Plug-in Battery Charger].
  5. On [Select Function] screen, select [Active Test].
  6. On [Active Test] screen, select an item to be checked.
    NOTE:
    • For detailed operation procedures, refer to "Help" of application.
    • If the connector with the Subaru Select Monitor becomes disconnected or a communication error occurs during the active test, use sufficient caution because driving may not be possible (READY OFF).
    • After the active test is finished, turn IG OFF and then resume work.
