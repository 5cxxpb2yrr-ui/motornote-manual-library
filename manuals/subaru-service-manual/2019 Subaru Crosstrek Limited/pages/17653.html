Outline Of Diagnosis

  • Detect the abnormality in transmission gear ratio control function.
  • Judge as NG if a discrepancy between the transmission target gear ratio (as internal data) and the actual gear ratio becomes the specified value or more. (Compare the value of "Gear Ratio Target x Secondary pulley speed ≈ Target primary speed equivalent value" with the value of primary pulley speed sensor.)
