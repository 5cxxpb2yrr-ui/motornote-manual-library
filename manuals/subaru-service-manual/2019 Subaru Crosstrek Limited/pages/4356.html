Console Box: Installation

CAUTION: The clips "C62" and "C63" shown in the figure may have different engaging forces. Always use the specified parts when installing.
  1. Assemble the cover assembly - front and the console box assembly.
  2. Install the console box assembly.

    Tightening torque: 

    6.5 N.m (0.7 kgf-m, 4.8 ft-lb)

  3. Install the cover assembly - front.
  4. Install the mat - center tray and the tray - center LWR.
  5. Install the shift knob or selector knob.
  6. Install the boot - hand brake. (Except for hybrid model)
  7. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
    NOTE: For CVT models, after connecting the battery ground terminal, place the select lever in the P position.
