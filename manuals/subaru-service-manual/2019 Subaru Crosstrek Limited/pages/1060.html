Immobilizer System

Do you like it dark? Easier on the eyes.

Symptoms Note
Engine does not start (except for hybrid model) or READY ON does not occur (hybrid model) Refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS)>DIAGNOSTICS WITH PHENOMENON>INSPECTION>ENGINE DOES NOT START .
Refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC B2784 ANTENNA CIRCUIT (PUSH ENGINE SWITCH) .
Refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC B278A PUSH ENGINE SWITCH POWER SUPPLY CIRCUIT .
Refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC B2785 LIN COMMUNICATION .
Refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC B2789 ID CODE BOX COMMUNICATION .
Refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC B2790 ID CODE BOX CIRCUIT .
Check the brake switch. Refer to BRAKE>STOP LIGHT SWITCH>INSPECTION .
Check the parking switch signal. Refer to CONTROL SYSTEMS>AT SHIFT LOCK SOLENOID AND "P" RANGE SWITCH>INSPECTION .
Check DTC of ECM. Refer to ENGINE (DIAGNOSTICS) (H4DO (EXCEPT FOR HEV))>DIAGNOSTIC TROUBLE CODE (DTC) .
Cannot register the immobilizer. Refer to the "REGISTRATION INSTRUCTIONS FOR IMMOBILIZER".
Engine does not start with the remote engine starter. Refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC B2779 REMOTE CONTROL ENGINE STARTER COLLATION .
