Tire Pressure Sensor Registration

NOTE: If the ignition switch and power supply of Subaru Select Monitor are turned off or the registration procedure is not performed within 5 minutes, registration mode is cancelled.
NOTE: If registration procedure is not successful after 2 attempts, replace TPM control module.
  1. Set the tire pressure of all wheels to specification.
  2. Connect Subaru Select Monitor.
  3. On "MAIN MENU" display screen, select "EACH SYSTEM CHECK" and press YES/OK key.
  4. On "SYSTEM SELECTION MENU" display screen, select "TIRE PRESSURE MONITORING" and press YES/OK key.
  5. Press YES/OK key after "TIRE PRESSURE MONITORING" is displayed.
  6. On display screen, select "TRANSMITTER ID REGIST CONFIRM" and press YES/OK key.
  7. When "ID REGISTRATION MODE EXECUTE, REGISTERED ID IS DELETED PROCEED?" is displayed, press YES/OK key.
  8. Using Transmitter Registration Tool (TPM-00012 or Kent-Moore Part No. FJ45295), contact sidewall near air valve of front left tire and press the switch to send transmitter ID to TPM control module (at this time, tire pressure warning light blinks to start registration procedure). Register tire pressure sensors, while noting the following:
    • Register transmitters in the following order: Left Front, Right Front, Right Rear, Left Rear.
    • Transmitter registration tool should be in contact with sidewall, near transmitter.
    • After registration for each tire completes, hazard light will blink and "ID REGISTRATION COMPLETED" will be displayed in the Select Monitor display screen.
    • If registration procedure stops before completion (turning ignition switch to OFF position, wrong registration order, etc.), repeat procedure from step  6.
  9. After ID registration is completed, tire pressure warning light will turn on for 2 seconds to indicate registration procedure is completed. Display screen will show transmitter IDs.
  10. Check the registered transmitter ID. See Display Transmitter ID Operation . After all IDs are confirmed, drive vehicle at 25 mph (40 km/h) for 10 minutes.
