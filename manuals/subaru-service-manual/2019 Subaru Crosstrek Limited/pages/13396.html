Reverse Brake Assembly: Installation

Do you like it dark? Easier on the eyes.

  1. Select a washer. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>FORWARD CLUTCH ASSEMBLY>ADJUSTMENT .
  2. Install the selected washer to the reverse brake housing.
    Courtesy of SUBARU OF AMERICA, INC.
  3. Install the thrust bearing to the reverse brake housing.
    NOTE: Face the temper color surface to the reverse brake side.
    Courtesy of SUBARU OF AMERICA, INC.
  4. Remove the internal gear from the forward clutch assembly, and install it to the reverse brake housing.
    Courtesy of SUBARU OF AMERICA, INC.
  5. Install the O-rings.
    NOTE:
    • Install a new O-ring.
    • Apply CVTF to the O-rings.
    Courtesy of SUBARU OF AMERICA, INC.
  6. Install the reverse brake assembly and internal gear as a unit to the drive pinion retainer.
    NOTE: Slowly rotate the input shaft by hand to engage the internal gear and pinion gear of planetary carrier.

    Tightening torque: 

    37 N.m (3.8 kgf-m, 27.3 ft-lb)

    Courtesy of SUBARU OF AMERICA, INC.
  7. Install the O-ring to the lubrication pipe.
    NOTE:
    • Install a new O-ring.
    • Apply CVTF to the O-rings.
    Courtesy of SUBARU OF AMERICA, INC.
  8. Install the lubrication pipe and oil guide.

    Tightening torque: 

    16 N.m (1.6 kgf-m, 11.8 ft-lb)

    Courtesy of SUBARU OF AMERICA, INC.
  9. Install the manual valve assembly and separator plate.

    Tightening torque: 

    9 N.m (0.9 kgf-m, 6.6 ft-lb)

    Courtesy of SUBARU OF AMERICA, INC.
  10. Install the primary pulley, secondary pulley and variator chain. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>PRIMARY PULLEY AND SECONDARY PULLEY>INSTALLATION .
  11. Select shims for pulley alignment. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>PRIMARY PULLEY AND SECONDARY PULLEY>ADJUSTMENT .
  12. Install the reduction drive gear. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>REDUCTION DRIVE GEAR>INSTALLATION .
  13. Install the transmission case. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSMISSION CASE>INSTALLATION .
  14. Install the transmission control device. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSMISSION CONTROL DEVICE>INSTALLATION .
  15. Install the oil strainer and oil pan. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>OIL PAN AND STRAINER>INSTALLATION .
  16. Install the reduction driven gear assembly. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>REDUCTION DRIVEN GEAR>INSTALLATION .
  17. Install the parking pawl. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>PARKING PAWL>INSTALLATION .
  18. Install the transfer driven gear assembly. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSFER DRIVEN GEAR>INSTALLATION .
  19. Install the transfer clutch assembly. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSFER CLUTCH>INSTALLATION .
  20. Install the extension case. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>EXTENSION CASE>INSTALLATION .
  21. Install the inhibitor switch. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>INHIBITOR SWITCH>INSTALLATION .
  22. Install the secondary speed sensor. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>SECONDARY SPEED SENSOR>INSTALLATION .
  23. Install the primary speed sensor. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>PRIMARY SPEED SENSOR>INSTALLATION .
  24. Install the turbine speed sensor. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TURBINE SPEED SENSOR>INSTALLATION .
  25. Install the transmission harness. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSMISSION HARNESS>INSTALLATION .
  26. Install the control valve body. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>CONTROL VALVE BODY>INSTALLATION .
  27. Install the air breather hose. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>AIR BREATHER HOSE>INSTALLATION .
  28. Install the transmission assembly to the vehicle. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>AUTOMATIC TRANSMISSION ASSEMBLY>INSTALLATION .
