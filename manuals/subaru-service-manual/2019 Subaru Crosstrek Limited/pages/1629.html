Recovery Procedure When Can Connection Unit Is Incorrectly Connected

If a unit was connected which is different from the unit that will be connected to the vehicle, be sure to perform [Re-register LAN connection unit] and [Clear memory].

If a unit was connected which is different from the unit that will be connected to the vehicle, the wrong unit connection is registered in [CAN bus check] and a DTC detection error occurs. Therefore perform the following steps after disconnecting the wrong unit.

  1. Turn the ignition switch to ON.
  2. Perform [Re-register LAN connection unit] and check that it is completed successfully. Ref. to CENTRAL GATEWAY (DIAGNOSTICS)>WORK SUPPORT>OPERATION>RE-REGISTER LAN CONNECTION UNIT .
  3. Perform [Clear memory] and check that it is completed successfully. Ref. to COMMON (DIAG)>CLEAR MEMORY .
