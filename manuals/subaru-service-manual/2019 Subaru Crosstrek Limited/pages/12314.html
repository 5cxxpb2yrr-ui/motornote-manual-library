A/C Pipe

CAUTION:
  • Since the auto A/C model uses the variable displacement compressor, be careful of the following items.
    • Do not start the engine before charging refrigerant.
    • If the engine is started with no refrigerant charge, replace the compressor assembly.
  • If the hose and pipe has been replaced, add an appropriate amount of compressor oil to the compressor. Refer to AIR CONDITIONER (EXCEPT FOR HEV)>COMPRESSOR OIL>ADJUSTMENT .
  • Replace the O-rings with new parts, and then apply compressor oil to install completely.
  • When connecting pipes, do not apply an excessive force to them. After installation, check that the pipes are not damaged.
  1. Install the pipe - evaporator cooling.
    1. Install the pipe - evaporator cooling.

      Tightening torque: 

      7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

    2. Connect the connector of the pressure switch or pressure sensor.
    3. Connect the upper connector of the engine control module (ECM). Refer to FUEL INJECTION (FUEL SYSTEMS) (H4DO (EXCEPT FOR HEV))>ENGINE CONTROL MODULE (ECM)>INSTALLATION .
    4. Connect the connector and harness of the main fuse box.
    5. Install the engine harness bracket.
    6. Install the battery cable bracket.
    7. Install the vacuum hose.
  2. Install the hose - pressure suction. Refer to AIR CONDITIONER (EXCEPT FOR HEV)>HOSE AND PIPE>INSTALLATION>LOW-PRESSURE HOSE .
  3. Install the hose - pressure suction discharge. Refer to AIR CONDITIONER (EXCEPT FOR HEV)>HOSE AND PIPE>INSTALLATION>HIGH-PRESSURE HOSE .
  4. Install the air intake boot. Refer to INTAKE (INDUCTION) (H4DO (EXCEPT FOR HEV))>Air Intake Boot>INSTALLATION .
  5. Install the battery and battery tray. Refer to STARTING/CHARGING SYSTEMS (H4DO (EXCEPT FOR HEV))>BATTERY>INSTALLATION .
  6. Charge refrigerant. Refer to AIR CONDITIONER (EXCEPT FOR HEV)>REFRIGERANT CHARGING PROCEDURE>PROCEDURE .
