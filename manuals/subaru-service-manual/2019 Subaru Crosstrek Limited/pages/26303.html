DTC P0ABF-2A: Hybrid/EV Battery Current Sensor "A" Signal Stuck In Range: Notes

WARNING: This page is about a different variant/trim than selected.

1. - 

Outline of diagnosis: 

When BATTERY CURRENT SENSOR output is stuck

HV battery voltage changes but HV battery current does not change

(1 trip detection logic)

Trouble symptom: 

  • Reduced output power
  • Engine not stopped
CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to P-HEV HIGH VOLTAGE BATTERY (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK DTC. 

    Read the following DTCs using Subaru Select Monitor. Refer to P-HEV HIGH VOLTAGE BATTERY (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) . Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    • P-HEV High Voltage Battery
    • P-HEV Hybrid Powertrain Control
    NOTE:
    System Related DTC
    P-HEV High Voltage Battery P060A47 HYBRID/EV BATTERY ENERGY CONTROL MODULE MONITORING PROCESSOR WATCHDOG/SAFETY MCU FAILURE
    P060B49 HYBRID/EV BATTERY ENERGY CONTROL MODULE A/D PROCESSING INTERNAL ELECTRONIC FAILURE
    P060687 HYBRID/EV BATTERY ENERGY CONTROL MODULE PROCESSOR TO MONITORING PROCESSOR MISSING MESSAGE
    P0ABF11 HYBRID/EV BATTERY CURRENT SENSOR "A" CIRCUIT SHORT TO GROUND
    P0ABF15 HYBRID/EV BATTERY CURRENT SENSOR "A" CIRCUIT SHORT TO AUXILIARY BATTERY OR OPEN
    P1CBB12 HYBRID/EV BATTERY CURRENT SENSOR POWER SUPPLY CIRCUIT SHORT TO AUXILIARY BATTERY
    P1CBB14 HYBRID/EV BATTERY CURRENT SENSOR POWER SUPPLY CIRCUIT SHORT TO GROUND OR OPEN
    P-HEV Hybrid Powertrain Control P0A1F94 HYBRID/EV BATTERY ENERGY CONTROL MODULE UNEXPECTED OPERATION

    When "Only DTC P0ABF2A is displayed" or "DTC other than above is displayed", go to  A.

    When DTCs related to [P-HEV High Voltage Battery], mentioned above, are simultaneously displayed, go to  B.

    When DTCs related to [P-HEV Hybrid Powertrain Control], mentioned above, are simultaneously displayed, go to  C.

    Yes: 

    1. Go to  2.
    2. Perform the diagnosis for the simultaneously displayed DTCs.
      NOTE: If more than one DTC is simultaneously displayed, perform the diagnosis in the order described in the above.
    3. Perform the diagnosis for the simultaneously displayed DTCs.
    NOTE: If more than one DTC is simultaneously displayed, perform the diagnosis in the order described in the above.

    No:  -

  2. CHECK DTC. 

    Read the DTC of [P-HEV High Voltage Battery] using the Subaru Select Monitor. Refer to P-HEV HIGH VOLTAGE BATTERY (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC P1A001C, P1A051C, P1A0A1C, P1A101C or P301A1C displayed?

    Yes:  Perform the diagnosis for the displayed DTCs.

    No:  Go to  3.

  3. CHECK DATA MONITOR (Hybrid Battery Cell 1 Voltage - Hybrid Battery Cell 95 Voltage). 
    1. Using the Subaru Select Monitor, display the following items in the [Data monitor] of [P-HEV High Voltage Battery]. Refer to P-HEV HIGH VOLTAGE BATTERY (DIAGNOSTICS)>DATA MONITOR .
      • Hybrid Battery Cell 1 Voltage

        to

      • Hybrid Battery Cell 95 Voltage
      NOTE: Do not select the item other than from [Hybrid Battery Cell 1 Voltage] to [Hybrid Battery Cell 95 Voltage].
    2. Check each of all Hybrid battery cell voltage in the data monitor [Hybrid Battery Cell 1 Voltage] - [Hybrid Battery Cell 95 Voltage] during IG ON.
    Courtesy of SUBARU OF AMERICA, INC.

    Turn to IG ON and wait for 60 seconds. Does any of [Hybrid Battery Cell 1 Voltage] - [Hybrid Battery Cell 95 Voltage] change by 0.05 V or more? (The difference between the maximum and minimum voltage is 0.05 V or more)

    Yes:  Replace Battery ECU assembly. Refer to HYBRID ELECTRIC VEHICLE>BATTERY CONTROL MODULE .

    No:  Replace HV battery junction block. Refer to HYBRID ELECTRIC VEHICLE>RELAY AND FUSE .
