DTC B1407: MET Communication

Do you like it dark? Easier on the eyes.

Diagnosis start condition: 

  • Battery voltage is 10 V or more.
  • The remote engine starter was not used to start the engine.

DTC detecting condition: 

Communication failure between body integrated unit and combination meter

Trouble symptom: 

  • Engine will not start.
  • The security indicator illuminates.
CAUTION: When the combination meter is replaced, registration of the immobilizer system is required. For details, refer to the "REGISTRATION INSTRUCTIONS FOR IMMOBILIZER" provided as a separate volume.
  1. CHECK DTC. 

    Read the DTC of [Body Control] using the Subaru Select Monitor. Refer to IMMOBILIZER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is a DTC other than DTC B1407 displayed for [Body Control]? (Current malfunction)

    Yes:  Perform the diagnosis for DTC other than B1407.

    No:  Check the combination meter. Refer to COMBINATION METER (DIAGNOSTICS)>BASIC DIAGNOSTIC PROCEDURE>PROCEDURE .
