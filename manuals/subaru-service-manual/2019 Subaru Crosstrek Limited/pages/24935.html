Diagnostic Method

WARNING: This page is about a different variant/trim than selected.

Judge as NG when the absolute value of the difference between cam signal input position and learning value is out of specification.

JUDGMENT VALUE SPECIFICATION

Malfunction Criteria Threshold Value
<Diagnosis 1> 
|Crankshaft position when camshaft position sensor signal is input - Learning value|
<Diagnosis 2> 
Camshaft position sensor signal input position (Bank 1)
Camshaft position sensor signal input position (Bank 2)		 More than 10°CA
Less than 30.18 °CA
Or,
More than 89.13 °CA
Less than 29.65 °CA
Or,
More than 87.66 °CA

Time needed for diagnosis:  1000 ms

Illumination of malfunction indicator light:  Illuminates when two consecutive driving cycles with fault occur.

NOTE: Initial standard learning value is the value of crank angle initially input at the production plant. And then it will be updated every time normal judgment has been completed. Learning value will not be updated if NG judgment occurs because timing chain derails suddenly in process or because wrong assembly occurs during servicing.
