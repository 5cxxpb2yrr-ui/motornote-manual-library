Auto A/C Model

CAUTION:
  • After installing the compressor, do not start the engine until the A/C system is charged with refrigerant.
  • If the engine is started with no refrigerant charge, replace the compressor assembly.
  • Replace the O-rings with new parts, and then apply compressor oil to install completely.
  • After replacing the compressor assembly, adjust the amount of the compressor oil. Refer to AIR CONDITIONER (EXCEPT FOR HEV)>COMPRESSOR OIL>ADJUSTMENT .
  1. Install the bracket - air conditioner.

    Tightening torque: 

    36 N.m (3.7 kgf-m, 26.6 ft-lb)

    NOTE: Tighten the bracket - air conditioner in the numerical order as shown in the figure. Refer to AIR CONDITIONER (EXCEPT FOR HEV)>GENERAL DESCRIPTION>COMPONENT>COMPRESSOR .
  2. Install the compressor assembly.

    Tightening torque: 

    36 N.m (3.7 kgf-m, 26.6 ft-lb)

  3. Install the hose - pressure suction and the hose - pressure discharge.

    Tightening torque: 

    10 N.m (1 kgf-m, 704 ft-lb)

  4. Install the V-belts. Refer to MECHANICAL (H4DO (EXCEPT FOR HEV))>V-BELT>INSTALLATION .
  5. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
  6. Charge refrigerant. Refer to AIR CONDITIONER (EXCEPT FOR HEV)>REFRIGERANT CHARGING PROCEDURE>PROCEDURE .
  7. If replacing the compressor assembly with a new part, perform a break-in operation according to the following steps.
    NOTE: Do not increase the engine speed to and above 4, 000 r/min unless the break-in operation finishes.
    1. Check that all connectors are locked securely.
    2. Reset the heater control assembly. (Disconnect and then connect the connector)
    3. Attach a delivery (test) mode fuse to the main fuse box.
    4. Using the Subaru Select Monitor, perform the break-in operation.
      NOTE: For detailed operation procedures, refer to "Help" of application.
      1. Connect the Subaru Select Monitor.
      2. On [Start] screen, select [Diagnosis].
      3. On [Select Vehicle] screen, enter vehicle information and select [OK].
      4. On [Main Menu] screen, select [Each System].
      5. On [Select System] screen, select [Air Conditioner], and then select [Next].
      6. On [Select Function] screen, select [Work Support].
      7. Select [Variable compressor break-in drive] mode from the work support list, and display [Break-in variable compressor drive, finish status] by following the procedure.
      8. Start and idle the engine at or below 1, 800 r/min. (The compressor operation is automatically changed to the break-in drive mode.)
      9. When [Break-in variable compressor drive, finish status] changes from [incomplete] to [ON], stop the engine.
        CAUTION: If the engine may have been started with no refrigerant charge, check for any diagnosis code (DTC) using Subaru Select Monitor. If the code B14A8
        (REFRIGERANT NOT SEALED DRIVE ERROR) is output, replace the compressor assembly.
    5. Remove the delivery (test) mode fuse from the main fuse box.
    6. The break-in operation finishes.
  8. Check that the air conditioner system operates normally.
