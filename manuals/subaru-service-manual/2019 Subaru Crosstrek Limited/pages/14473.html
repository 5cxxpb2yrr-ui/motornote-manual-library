Circuit Explanation

WARNING: This page is about a different variant/trim than selected.

The Charge control ECU installed inside the Electric vehicle charger assembly uses a IVH sensor to monitor the DC section current. It outputs a DTC code when an IVH sensor error is detected. If this DTC was detected, replace the Electric vehicle charger assembly.
