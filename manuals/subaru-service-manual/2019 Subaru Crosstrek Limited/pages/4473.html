Rear Seat: Installation

Do you like it dark? Easier on the eyes.

  1. Install the following parts.
    • Plate - anchor LWR
    • Stay - rear floor
    • Striker - backrest rear
    NOTE: Use the following procedures to install the stay - rear floor.
    • Except for hybrid model
      Courtesy of SUBARU OF AMERICA, INC.
      1. Temporarily tighten the bolt (a).
      2. Tighten the bolts (b) and (c) to the specified torque.
      3. Tighten the bolts (a) and (d) and the nut (e) to the specified torque.
    • Hybrid model
    Courtesy of SUBARU OF AMERICA, INC.

    1. Temporarily tighten the bolt (a).
    2. Tighten the bolts (b) and (c) to the specified torque.
    3. Tighten the bolt (a) to the specified torque.

    Tightening torque: 

    Refer to "COMPONENT" of "General Description" for the tightening torque. Refer to SEATS>GENERAL DESCRIPTION>COMPONENT>REAR SEAT .

  2. Install the high voltage battery assembly. (Hybrid model) Refer to HYBRID ELECTRIC VEHICLE>HIGH VOLTAGE BATTERY>INSTALLATION .
    WARNING: The hybrid system includes a high voltage circuit. Mishandling could cause accidents such as electric shock or leak. Always check "WARNING (HYBRID - SYSTEM)" and perform the proper operation. Refer to PRECAUTION/WARNING>WARNING (HYBRID SYSTEM) .
  3. Install the cover side sill rear - INN, and install the trim panel - rear pillar LWR or the trim panel - rear apron.
    • 4 door model: Refer to EXTERIOR/INTERIOR TRIM>REAR QUARTER TRIM>INSTALLATION>4 DOOR MODEL .
    • 5 door model
      • Except for hybrid model: Refer to EXTERIOR/INTERIOR TRIM>REAR QUARTER TRIM>INSTALLATION>5 DOOR MODEL (EXCEPT FOR HYBRID) .
      • Hybrid model: Refer to EXTERIOR/INTERIOR TRIM>REAR QUARTER TRIM>INSTALLATION>5 DOOR MODEL (HYBRID) .
  4. Install the hinge assembly. (Hybrid model)

    Tightening torque: 

    Refer to "COMPONENT" of "General Description" for the tightening torque. Refer to SEATS>GENERAL DESCRIPTION>COMPONENT>REAR SEAT .

  5. Install the backrest assembly RH and LH.

    Tightening torque: 

    Refer to "COMPONENT" of "General Description" for the tightening torque. Refer to SEATS>GENERAL DESCRIPTION>COMPONENT>REAR SEAT .

    NOTE:
    • After installing the backrest assembly, make sure that each seat belt operates normally.
    • Make sure that they are properly secured on each hook on the vehicle side.
  6. Install the rear seat cushion assembly.
  7. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
