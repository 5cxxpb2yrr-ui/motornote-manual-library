Outline Of Diagnosis

The electric brake booster control module monitors the drive voltage and current of the linear solenoids. Based on the monitored information, if any of the following abnormal conditions are detected, the MIL is illuminated and a DTC is stored.

  • Based on the duty cycle, the monitored current value is considerably high.
  • A current leakage is detected.
  • When the monitored current value increases to a value that is not possible when normal.
