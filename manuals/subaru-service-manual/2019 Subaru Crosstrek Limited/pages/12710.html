Seat Belt Inner - Front

CAUTION:
  • Before installation, make sure that the correct part is used.
  • During installation, make sure that the seat belts are not twisted.
  • Check that there is no pinching of the seat belt harness. Wrong harness rooting may cause the harness short from pinch.
  • Do not forget the wave washer, when installing front seat inner belt assembly.
  • If the passenger's seat is removed, be sure to perform [Rezero] for the occupant detection system after installing the seat to the vehicle.
  1. Install the seat belt inner - front.
    1. Install the wave washer, seat belt inner - front and nut in order and then tighten the nut.

      Tightening torque:

      38 N.m (3.9 kgf-m, 28 ft-lb)

    2. Locate the seat belt harness and retain it with a harness clip.

  3. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
  4. If the passenger's seat is removed, make sure to perform [Rezero] in the occupant detection system. Refer to OCCUPANT DETECTION (DIAGNOSTICS)>REZERO .
