Inspection Mode 5

Code Description & trouble part Note
B2B10 Passenger's Door Power Window Driver's Door Auto Switch Stuck -

Diagnostic procedure:

  1. Using the Subaru Select Monitor, perform the clear memory of [Power Window (Driver)]. Refer to COMMON (DIAG)>CLEAR MEMORY .
  2. Using the Subaru Select Monitor, read the DTC of [Power Window (Driver)] to check that there is no DTC displayed. Refer to POWER WINDOW (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
    NOTE: If the DTC is displayed on the screen, the trouble is still present. Perform the diagnosis for the displayed DTCs. After solving the DTC, repeat from step  1.
  3. Using the automatic up and down feature of the driver's side main switch and check that the window operates automatically.
  4. Using the Subaru Select Monitor, read the DTC of [Power Window (Driver)] to check that there is no DTC displayed. Refer to POWER WINDOW (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
    NOTE: If the DTC is displayed on the screen, the trouble is still present. Perform the diagnosis for the displayed DTCs.
