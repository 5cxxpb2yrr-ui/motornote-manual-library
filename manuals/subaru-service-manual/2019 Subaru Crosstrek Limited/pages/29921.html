Door Indicator Is Not Displayed

WARNING: This page is about a different variant/trim than selected.

Trouble causes: 

  • CAN communication failure
  • Body integrated unit malfunction
  • Combination meter malfunction
  • Door switch circuit malfunction
CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to LAN SYSTEM (DIAGNOSTICS) (HEV)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK DTC. 

    Read the DTC of [Body Control] using the Subaru Select Monitor. Refer to BODY CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed? (Current malfunction)

    Yes:  Perform the diagnosis for the displayed DTCs.

    No:  Go to  2.

  2. CHECK DTC. 
    1. Start the engine.
    2. Using the Subaru Select Monitor, read all DTCs. Refer to LAN SYSTEM (DIAGNOSTICS) (HEV)>DIAGNOSTIC TROUBLE CODE (DTC)>OPERATION .

    Is DTC U**** displayed? (Current malfunction)

    Yes:  Perform the diagnosis according to the basic diagnostic procedure in LAN SYSTEM (DIAGNOSTICS). Refer to LAN SYSTEM (DIAGNOSTICS) (HEV)>BASIC DIAGNOSTIC PROCEDURE .

    No:  Go to  3.

  3. CHECK DOOR INDICATOR. 

    Using the Subaru Select Monitor, check the following items in the [Active Test] of [Combination Meter]. Refer to COMBINATION METER (DIAGNOSTICS)>ACTIVE TEST .

    • All seats door
    • Driver side door
    • Passenger side door
    • Rear side (right) door
    • Rear side (left) door

    Do the indication on Subaru Select Monitor and the door indicator indication match?

    Yes:  Go to  4.

    No:  Replace the combination meter. Refer to INSTRUMENTATION/DRIVER INFO>COMBINATION METER .

  4. CHECK DATA MONITOR FOR BODY INTEGRATED UNIT. 

    Using the Subaru Select Monitor, check the following items in the [Data Monitor] of [Body Control]. Refer to BODY CONTROL (DIAGNOSTICS)>DATA MONITOR .

    • Driver's door SW input
    • P-door SW input
    • Rear right door SW input
    • Rear left door SW input

    Do the door open/close and data indication match?

    Yes:  Replace the body integrated unit. Refer to SECURITY AND LOCKS>BODY INTEGRATED UNIT .

    No:  Inspect door switch circuit. Refer to SECURITY AND LOCKS>KEYLESS ENTRY SYSTEM>INSPECTION .
