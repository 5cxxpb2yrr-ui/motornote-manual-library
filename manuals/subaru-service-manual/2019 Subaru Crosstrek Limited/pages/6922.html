DTC U0463: Invalid Data Received From Navigation Display Module

DTC detecting condition: 

CAN data from AVN is abnormal.

Trouble symptom: 

  • Time is not shared with audio.
  • Orientation screen is not displayed.
  • Turn by turn screen is not displayed.
  • Weather screen is not displayed.
  • Audio screen is not displayed.
  • Favorite screen Orientation is not displayed.
  • Favorite screen Weather is not displayed.
  • Favorite screen Speed limit are not displayed.
  • Orientation is not displayed properly in the orientation screen.
  • Orientation shown in the orientation screen is different from one in the navigation system.
  • Names of streets and symbols shown in the orientation screen are different from those in the navigation system.
  • Speed limit and signs shown in the orientation screen are different from those in the navigation system.
  • Arrows shown in the turn by turn screen are different from those in the navigation system.
  • Remaining distance shown in the turn by turn screen is different from one in the navigation system.
  • Names of the next streets shown in the turn by turn screen are different from those in the navigation system.
  • Weather shown in the weather screen is different from one in the head unit.
  • The source display shown in the audio screen is different from one in the head unit.
  • Audio information shown in the audio screen is different from one in the head unit.
NOTE: For the diagnostic procedure, refer to DTC U0074. Refer to MULTI-FUNCTION DISPLAY (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC U0074 CONTROL MODULE COMMUNICATION BUS "BODY-CAN" OFF .
