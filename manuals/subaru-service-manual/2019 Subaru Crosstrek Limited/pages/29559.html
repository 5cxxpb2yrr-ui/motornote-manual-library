Clear Active Lane Keep System Learning Value: Operation

WARNING: This page is about a different variant/trim than selected.
  1. On [Start] display, select [Diagnosis].
  2. On [Vehicle selection] display, input the target vehicle information and select [OK].
  3. On [Main Menu] display, select [Each System].
  4. On [Select System] display, select [EyeSight], and then select [Enter].
  5. On [Select Function] display, select [Work Support].
  6. On [Work Support] display, select [Clear Active Lane Keep System Learning Value].
    NOTE:
    • When suspension parts are replaced or wheel alignment is adjusted, perform [Clear Active Lane Keep System Learning Value].
    • For detailed operation procedures, refer to "Help" of application.
