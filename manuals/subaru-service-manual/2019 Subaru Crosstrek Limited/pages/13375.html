Transmission Case: Installation

Do you like it dark? Easier on the eyes.

  1. Clean the mating surface of transmission case and converter case.
  2. Select the reduction gear shim. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>REDUCTION DRIVE GEAR>ADJUSTMENT .
  3. Remove the transmission case, and install the selected reduction gear shim to the reduction drive gear.
  4. Install the O-rings to the reverse clutch housing and drive pinion retainer.
    NOTE:
    • Use new O-rings.
    • Apply CVTF to the O-rings.
    Courtesy of SUBARU OF AMERICA, INC.
  5. Install the seal ring to the transmission case.
    NOTE:
    • Use new seal rings.
    • When installing the seal rings, do not expand the seal rings too much.
    • Apply CVTF to the seal rings.
    Courtesy of SUBARU OF AMERICA, INC.
  6. Cover the secondary pulley with the oil baffle, and temporarily install it with bolts.
    Courtesy of SUBARU OF AMERICA, INC.
  7. Apply liquid gasket seamlessly to the mating surface of transmission case.

    Liquid gasket: 

    THREE BOND 1215B or equivalent

    Courtesy of SUBARU OF AMERICA, INC.
  8. Install the transmission case.
    NOTE: The total number of transmission case mounting bolts is 15.

    Tightening torque: 

    22 N.m (2.2 kgf-m, 16.2 ft-lb)

  9. Install the oil cooler pipe.
    NOTE: Use new O-rings.

    Tightening torque: 

    25 N.m (2.5 kgf-m, 18.4 ft-lb)

    Courtesy of SUBARU OF AMERICA, INC.
  10. Install the oil baffle securing bolt.

    Tightening torque: 

    16 N.m (1.6 kgf-m, 11.8 ft-lb)

    Courtesy of SUBARU OF AMERICA, INC.
  11. Install the transmission control device. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSMISSION CONTROL DEVICE>INSTALLATION .
  12. Install the oil pan and oil strainer. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>OIL PAN AND STRAINER>INSTALLATION .
  13. Install the reduction driven gear assembly. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>REDUCTION DRIVEN GEAR>INSTALLATION .
  14. Install the parking pawl. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>PARKING PAWL>INSTALLATION .
  15. Install the transfer driven gear assembly. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSFER DRIVEN GEAR>INSTALLATION .
  16. Install the transfer clutch assembly. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSFER CLUTCH>INSTALLATION .
  17. Install the extension case. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>EXTENSION CASE>INSTALLATION .
  18. Install the inhibitor switch. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>INHIBITOR SWITCH>INSTALLATION .
  19. Install the secondary speed sensor. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>SECONDARY SPEED SENSOR>INSTALLATION .
  20. Install the primary speed sensor. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>PRIMARY SPEED SENSOR>INSTALLATION .
  21. Install the turbine speed sensor. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TURBINE SPEED SENSOR>INSTALLATION .
  22. Install the transmission harness. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSMISSION HARNESS>INSTALLATION .
  23. Install the control valve body. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>CONTROL VALVE BODY>INSTALLATION .
  24. Install the air breather hose. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>AIR BREATHER HOSE>INSTALLATION .
  25. Install the transmission assembly to the vehicle. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>AUTOMATIC TRANSMISSION ASSEMBLY>INSTALLATION .
