DTC B1732: Central Gateway Control Module Non-Volatile Memory

Outline of diagnosis: 

A data error was detected when reading was performed immediately after writing to non-volatile memory was completed.

Trouble symptom: 

Error in data written to non-volatile memory

NOTE: If this DTC was detected, replace the central gateway control module. Ref. to SECURITY AND LOCKS>GATEWAY CONTROL MODULE .
