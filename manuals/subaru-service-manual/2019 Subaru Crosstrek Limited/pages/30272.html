Heater and Cooling Unit: Installation

WARNING: This page is about a different variant/trim than selected.
CAUTION:
  • Replace the O-rings with new parts, and then apply compressor oil to install completely.
  • Before handling the airbag system components, refer to "CAUTION" of "General Description" in "AIRBAG SYSTEM". Refer to AIRBAG SYSTEM>GENERAL DESCRIPTION>CAUTION .
  1. Install the blower motor unit assembly.
  2. Install the heater and cooling unit assembly.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  3. Install the hose - drain.
  4. Install the duct - foot. Refer to AIR CONDITIONER (HEV)>HEATER DUCT>INSTALLATION>FOOT .
  5. Install the duct - rear heater front. Refer to AIR CONDITIONER (HEV)>HEATER DUCT>INSTALLATION>FRONT .
  6. Install the instrument panel assembly and the beam COMPL - steering. Refer to EXTERIOR/INTERIOR TRIM>INSTRUMENT PANEL ASSEMBLY>INSTALLATION .
  7. Install the hose - heater outlet and the hose - heater inlet.
  8. Install expansion valve - cooler assembly hose and pipe - return assembly.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  9. Install the hose - pressure discharge and the pipe - sensor.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  10. Install the air intake boot. Refer to INTAKE (INDUCTION) (H4DO (EXCEPT FOR HEV))>Air Intake Boot>INSTALLATION .
  11. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
  12. Charge refrigerant. Refer to AIR CONDITIONER (HEV)>REFRIGERANT CHARGING PROCEDURE>PROCEDURE .
  13. Fill engine coolant. (Engine side) Refer to COOLING (H4DO (HEV))>ENGINE COOLANT>REPLACEMENT>FILLING OF ENGINE COOLANT .
