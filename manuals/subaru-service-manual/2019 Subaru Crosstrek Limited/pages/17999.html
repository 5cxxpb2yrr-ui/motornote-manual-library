Transfer Driven Gear: Installation

Do you like it dark? Easier on the eyes.

  1. Install the transfer driven gear assembly.
    Courtesy of SUBARU OF AMERICA, INC.
  2. Install the transfer clutch assembly. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSFER CLUTCH>INSTALLATION .
  3. Select the transfer driven gear shim. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSFER CLUTCH>ADJUSTMENT .
  4. Install the extension case. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>EXTENSION CASE>INSTALLATION .
  5. Install the transmission assembly to the vehicle. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>AUTOMATIC TRANSMISSION ASSEMBLY>INSTALLATION .
