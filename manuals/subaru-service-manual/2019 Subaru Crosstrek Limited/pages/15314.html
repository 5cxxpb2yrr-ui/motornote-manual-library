Unable To Switch Vents

Do you like it dark? Easier on the eyes.

Trouble symptom: 

  • Unable to switch blow vents.
  • Outlet opening does not switch in the sequence of FACE → B/L → FOOT → F/D after operating the mode switch or mode dial.

Trouble causes: 

Mode actuator failure

CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to AIR CONDITIONER (DIAGNOSTICS) (EXCEPT FOR HEV)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK A/C CONTROL PANEL. 
    1. Turn the ignition switch to ON.
    2. Using the Subaru Select Monitor, check the following items in the [Data monitor] of [Air Conditioner]. Refer to AIR CONDITIONER (DIAGNOSTICS) (EXCEPT FOR HEV)>DATA MONITOR .
      • Mode Door Actuator Position Target
    3. Operate the mode change switch.

    Does the value of [Mode Door Actuator Position Target] change along with the operation?

    Yes:  Go to  2.

    No:  Replace the A/C control panel. Refer to AIR CONDITIONER (EXCEPT FOR HEV)>CONTROL PANEL .

  2. CHECK DTC. 
    1. Set the mode change switch to DEF, and wait for 16 seconds or more.
    2. Read the DTC of [Air Conditioner] using the Subaru Select Monitor. Refer to AIR CONDITIONER (DIAGNOSTICS) (EXCEPT FOR HEV)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC B1438 or B1439 displayed? (Current malfunction)

    Yes:  Perform the diagnosis for the displayed DTC B1438 or B1439. Refer to AIR CONDITIONER (DIAGNOSTICS) (EXCEPT FOR HEV)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC B1438 MODE DOOR ACTUATOR CIRCUIT OPEN . Refer to AIR CONDITIONER (DIAGNOSTICS) (EXCEPT FOR HEV)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC B1439 MODE DOOR ACTUATOR CIRCUIT SHORT-CIRCUIT .

    No:  Go to  3.

  3. CHECK DTC. 
    1. Set the mode change switch to VENT, and wait for 16 seconds or more.
    2. Read the DTC of [Air Conditioner] using the Subaru Select Monitor. Refer to AIR CONDITIONER (DIAGNOSTICS) (EXCEPT FOR HEV)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC B1438 or B1439 displayed? (Current malfunction)

    Yes:  Perform the diagnosis for the displayed DTC B1438 or B1439. Refer to AIR CONDITIONER (DIAGNOSTICS) (EXCEPT FOR HEV)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC B1438 MODE DOOR ACTUATOR CIRCUIT OPEN . Refer to AIR CONDITIONER (DIAGNOSTICS) (EXCEPT FOR HEV)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC B1439 MODE DOOR ACTUATOR CIRCUIT SHORT-CIRCUIT .

    No:  The circuit has returned to a normal condition at this time. Reproduce the failure, and then perform the diagnosis again.

    NOTE: In this case, temporary poor contact of connector, temporary open or short circuit of harness may be the cause.
