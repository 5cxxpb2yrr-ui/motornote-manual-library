HVAC System (Diagnostics) (Except For HEV): Customize: Operation

Do you like it dark? Easier on the eyes.

  1. On [Start] display, select [Diagnosis].
  2. On [Vehicle selection] display, input the target vehicle information and select [OK].
  3. On [Main Menu] display, select [Each System].
  4. On [Select System] display, select [Air Conditioner], and then select [Enter].
  5. On [Select Function] display, select [Customize].
    NOTE:
    • For detailed operation procedures, refer to "Help" of application.
    • For details on customization, refer to the list. Refer to AIR CONDITIONER (DIAGNOSTICS) (EXCEPT FOR HEV)>CUSTOMIZE>LIST .
