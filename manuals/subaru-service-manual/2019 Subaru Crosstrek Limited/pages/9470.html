Inspection Mode X

DTC Item Condition Number of driving cycles on the detecting condition
P2004 TGV CONTROL STUCK OPEN BANK 1 - 1
P2005 TGV CONTROL STUCK OPEN BANK 2 - 1
P2006 TGV CONTROL STUCK CLOSED BANK 1 - 1
P2007 TGV CONTROL STUCK CLOSED BANK 2 - 1

Diagnostic procedure: 

  1. Using the Subaru Select Monitor, clear the memory of [Engine Control System]. Refer to COMMON (DIAG)>CLEAR MEMORY .
  2. Idle the engine for 10 seconds or more after engine start.
  3. Shift the select lever to "P" range (CVT model), or the gear shift lever to the neutral position (MT model), and race the engine for 10 seconds or more.
    NOTE: Keep Engine speed at 3500 rpm or more.
  4. Read the temporary code using the Subaru Select Monitor or general scan tool. Refer to COMMON (DIAG)>DIAGNOSTIC TROUBLE CODE (DTC) .
