Cancel Code: Operation

  1. On [Start] display, select [Diagnosis].
  2. On [Vehicle selection] display, input the target vehicle information and select [OK].
  3. On [Main Menu] display, select [Each System].
  4. On [Select System] display, select [Blind Spot Detection/Rear Cross Traffic Alert (RH)] or [Blind Spot Detection/Rear Cross Traffic Alert (LH)], and then select [Enter].
  5. On [Select Function] display, select [Cancel Code].
    NOTE:
    • For detailed operation procedures, refer to "Help" of application.
    • For details concerning cancel codes, refer to the List of Cancel Codes. Refer to BLIND SPOT DETECTION/REAR CROSS TRAFFIC ALERT (DIAGNOSTICS)>CANCEL CODE>LIST .
