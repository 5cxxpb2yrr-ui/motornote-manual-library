Multi-function Display (MFD): Installation

CAUTION:
  • Make sure the electrical connector is connected securely.
  • Make sure that the multi-function display operates normally.
  1. Install the multi-function display.
  2. Install the cover - center UPR.
  3. Install the audio assembly or navigation assembly.
  4. Install the panel - center UPR.
  5. Install the grille assembly - CTR ventilation.
  6. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
