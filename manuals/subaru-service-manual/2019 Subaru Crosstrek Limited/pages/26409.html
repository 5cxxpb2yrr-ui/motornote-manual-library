Temporary Vehicle Start

Do you like it dark? Easier on the eyes.

WARNING: This page is about a different variant/trim than selected.
NOTE: Do not perform while the Hybrid Fail Lamp is on.
Only use this when "Hybrid system disabled Have vehicle inspected at retailer" is displayed on the combination meter and the vehicle cannot be started.
Even when the vehicle start is temporarily permitted by this function, the message "Hybrid system disabled Have vehicle inspected at retailer" displayed on the combination meter does not disappear.
  1. Connect the Subaru Select Monitor.
  2. Turn to IG ON.
  3. On [Start] screen, select [Diagnosis].
  4. On [Vehicle selection] screen, enter vehicle information and select [OK].
  5. On [Main Menu] screen, select [Each System].
  6. On [Select System] screen, select [P-HEV High Voltage Battery].
  7. On [Select Function] screen, select [Work Support].
  8. On [Work Support] screen, select [Temporary Vehicle Start Up].
    NOTE: [Temporary Vehicle Start Up] cannot be accepted if the brake pedal has been depressed once and READY ON is executed. Therefore turn to IG OFF to repeat the procedure.
  9. Confirm the items indicated on the screen, then press [Next].
  10. The screen changes to display [Please wait].
  11. The screen changes to display [Executed Temporary Vehicle Start Up].
    NOTE:
    • Once READY OFF is in effect, the vehicle cannot be started.
    • After READY ON, it is OK to remove the Subaru Select Monitor.
  12. Turn to READY ON.
  13. If it is out of the execution condition for temporary vehicle start, display the interruption content on the Subaru Select Monitor. In this case, confirm the interruption reason, perform troubleshooting according to the instruction of «Temporary vehicle start - Measure during interruption» below and perform [Temporary Vehicle Start Up] again.
