Glass Lid

Do you like it dark? Easier on the eyes.

  1. Using a new TORX® bolt, temporarily install the lid assembly - sunroof.

    Preparation tool: 

    TORX® T25

  2. Perform the open/close operation checks for the glass lid.
  3. Tighten the TORX® bolts to the specified torque while adjusting the height of the lid assembly - sunroof to the specified value.

    Specification: 

    Lid assembly - sunroof to Roof panel (H): 0.7±1 mm (0.03±0.04 in)

    Courtesy of SUBARU OF AMERICA, INC.

    Tightening torque: 

    4.5 N.m (0.5 kgf-m, 3.3 ft-lb)

  4. Install the cover - lid.
