Malfunction Description

WARNING: This page is about a different variant/trim than selected.

Hybrid vehicle control ECU assembly monitors HV battery voltage via the inverter voltage and charging voltage, and detects malfunctions.

The following cases are assumed to be malfunction causes:

Inverter function fault (boosting converter system)

  • VL sensor malfunction
  • VH sensor malfunction

HV battery system fault

  • Malfunction of Battery ECU assembly
  • Malfunction of HV battery

Fault of voltage sensor (VCHG) in Electric vehicle charger assembly

  • Voltage sensor (VCHG) malfunction
