Batch Save Of Event Record Data: Operation

  1. On [Start] display, select [Diagnosis].
  2. On [Vehicle selection] display, input the target vehicle information and select [OK].
  3. On [Main Menu] display, select [Each System].
  4. On [Select System] display, select [Airbag], and then select [Enter].
  5. On [Airbag] display, select [Work Support].
  6. On [[Work Support item]] display, select [Batch save of Event record data]. After it is selected, [IMPORTANT NOTICE] screen is displayed.
  7. After checking the content of [IMPORTANT NOTICE], click the checkbox for "Yes".
  8. If the applicable law is not violated, click the [Yes] button to display the EDR data.
    Courtesy of SUBARU OF AMERICA, INC.
  9. Specify the destination for the event record data to save the data there.
  10. After saving the file, click the [OK] button to return the menu screen.
