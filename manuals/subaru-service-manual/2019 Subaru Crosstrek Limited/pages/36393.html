Lower Inner Trim: Installation

Do you like it dark? Easier on the eyes.

  1. Install the cover - catcher.
  2. Install the trim panel - center pillar LWR.
    NOTE: Assemble the trim panel - center pillar LWR to the trim panel - center pillar UPR securely.
  3. Install the cover side sill - rear INN.
  4. Install the rear seat cushion assembly.
  5. Install the cover side sill - front.
  6. Install the cover side sill - front INN.
  7. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
