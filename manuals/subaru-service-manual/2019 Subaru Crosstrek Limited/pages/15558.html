High Beam Assist Indicator Does Not Illuminate

Trouble symptom: 

High beam assist indicator light does not illuminate though the operating conditions for the high beam assist are met.

CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to BODY CONTROL (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
NOTE: When there is faulty in the combination switch, combination meter, illumination sensor for the auto lighting or the operation of auto lighting, perform the diagnosis for each system in advance.
  1. CHECK BODY INTEGRATED UNIT SETTING. 

    Using the Subaru Select Monitor, check the following items in the [Data monitor] of [Body Control]. Refer to BODY CONTROL (DIAGNOSTICS)>DATA MONITOR .

    • High Beam Assist Function Setting (mirror/EyeSight)
    • High Beam Assist Current Setting

    Is [High Beam Assist Function Setting (mirror/EyeSight)] set to [EyeSight HBA], and [High Beam Assist Current Setting] set to [ON]?

    Yes:  Go to  2.

    No:  Set [High Beam Assist Function Setting (mirror/EyeSight)] to [EyeSight HBA], and set [High Beam Assist Current Setting] to [ON].

  2. CHECK DTC. 

    Using the Subaru Select Monitor, read all DTCs. Refer to COMMON (diag)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed? (Current malfunction)

    Yes:  Perform the diagnosis for the displayed DTCs. Refer to BODY CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Go to  3.

  3. CHECK "EyeSight TEMPORARY STOP INDICATOR". 
    1. Turn the ignition switch to OFF.
    2. Turn the ignition switch to ON.
    3. Check "EyeSight temporary stop indicator". Refer to EYESIGHT (DIAGNOSTICS) (EXCEPT FOR HEV)>EYESIGHT HALT CODE . Refer to EYESIGHT (DIAGNOSTICS) (HEV)>EYESIGHT HALT CODE .

    Is "EyeSight temporary stop indicator" displayed?

    Yes:  Perform inspection according to "EyeSight temporary stop code" in "ES (DIAGNOSTICS)".

    No:  Go to  4.

  4. CHECK HIGH BEAM ASSIST INDICATOR. 
    1. Turn the ignition switch to ON.
    2. Set the light SW position to Auto.
    3. Set the dimmer Hi SW to ON.
    4. Shade the illumination sensor for the auto lighting.

    Does the high beam assist indicator illuminate?

    Yes:  The circuit has returned to a normal condition at this time. Reproduce the failure, and then perform the diagnosis again.

    NOTE: In this case, temporary poor contact of connector, temporary open or short circuit of harness may be the cause.

    No:  Go to  5.

  5. CHECK HIGH BEAM ASSIST INDICATOR. 

    Using the Subaru Select Monitor, check the following items in the [Active Test] of [Combination Meter]. Refer to COMBINATION METER (DIAGNOSTICS)>ACTIVE TEST .

    • HBA indicator

    Does the high beam assist indicator illuminate?

    Yes:  Replace the combination meter. Refer to INSTRUMENTATION/DRIVER INFO>COMBINATION METER .

    No:  Replace the body integrated unit. Refer to SECURITY AND LOCKS>BODY INTEGRATED UNIT .
