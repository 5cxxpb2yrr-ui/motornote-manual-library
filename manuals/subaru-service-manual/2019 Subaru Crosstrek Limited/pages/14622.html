Timer Charging Does Not Start At The Set Time

WARNING: This page is about a different variant/trim than selected.
CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to PLUG-IN BATTERY CHARGER (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK DTC. 

    Using the Subaru Select Monitor, read all DTCs. Refer to COMMON (diag)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed?

    Yes:  Perform the diagnosis for the displayed DTCs.

    No:  Go to  2.

  2. CHECK DATA MONITOR. 
    1. Using the Subaru Select Monitor, display the following items in the [Work Support] of [Plug-in Battery Charger]. Refer to PLUG-IN BATTERY CHARGER (DIAGNOSTICS)>WORK SUPPORT .
      • Vehicle Ctl. Hist.
    2. Using the Subaru Select Monitor, display the following items in the [Work Support] of [P-HEV Hybrid Powertrain Control]. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>WORK SUPPORT .
      • Vehicle Ctl. Hist.
    3. Check the vehicle control history.

    Is the vehicle control history displayed?

    Yes:  Go to the vehicle control history.

    • Plug-in Battery Chargers Refer to PLUG-IN BATTERY CHARGER (DIAGNOSTICS)>WORK SUPPORT .
    • P-HEV Hybrid Powertrain Controls Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>WORK SUPPORT .

    No:  Go to  3.

  3. REPRODUCTION TEST (TIMERSETTING). 
    CAUTION:
    • Perform charging with an AC power supply that was confirmed to operate normally.
    • Select an AC power supply (120 V or 240 V) that is the same as the power supply used by the customer.
    NOTE: When setting the timer, set a charging start time that is at least 5 minutes ahead of the current time.
    When setting a departure time, set a time after considering the current HV battery SOC.
    Procedure for setting timer charging:
    Select the MFD "Settings screen" → "Charge settings" → "Charge timer settings" to display the change screen, then configure the timer charging settings.
    Timer charging activates according to the set date (year, month, day) and MFD time.
    1. Using the Subaru Select Monitor, perform all memory clear. Refer to COMMON (DIAG)>CLEAR MEMORY .
    2. Using the Subaru Select Monitor, display the following items in the [Work Support] of [Plug-in Battery Charger]. Refer to PLUG-IN BATTERY CHARGER (DIAGNOSTICS)>WORK SUPPORT .
      • Vehicle Ctl. Hist.
    3. Using the Subaru Select Monitor, clear all memory of [Vehicle Ctl. Hist.]. Refer to COMMON (DIAG)>CLEAR MEMORY .
    4. Using the Subaru Select Monitor, display the following items in the [Work Support] of [P-HEV Hybrid Powertrain Control]. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>WORK SUPPORT .
      • Vehicle Ctl. Hist.
    5. Using the Subaru Select Monitor, clear all memory of [Vehicle Ctl. Hist.]. Refer to COMMON (DIAG)>CLEAR MEMORY .
    6. Using the Subaru Select Monitor, display the following items in the [Data Monitor] of [P-HEV Hybrid Powertrain Control]. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DATA MONITOR .
      • Hybrid Battery SOC
    7. Read the data monitor, and check that the HV battery SOC is less than 70%.
      NOTE: If the HV battery SOC is 70% or more, perform driving in EV mode or use other means to discharge the HV battery and reduce the SOC to less than 70%.
      Item name Item explanation Display range Standard
      Hybrid Battery SOC Indicates the battery capacity. 0.00 - 100.00% 0.00 - 100.00%: Always
    8. Check whether the date and time displayed on the MFD are correct, and adjust them if necessary.
    9. Use the MFD to set a timer for a set start time.
    10. Turn the ignition to OFF.
    11. Connect the Electric vehicle charger cable assembly and perform timer charging with a set start time.
    12. Turn to IG ON.
    13. Using the Subaru Select Monitor, read all DTCs. Refer to COMMON (diag)>DIAGNOSTIC TROUBLE CODE (DTC) .
    14. Using the Subaru Select Monitor, display the following items in the [Work Support] of [Plug-in Battery Charger]. Refer to PLUG-IN BATTERY CHARGER (DIAGNOSTICS)>WORK SUPPORT .
      • Vehicle Ctl. Hist.
    15. Using the Subaru Select Monitor, display the following items in the [Work Support] of [P-HEV Hybrid Powertrain Control]. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>WORK SUPPORT .
      • Vehicle Ctl. Hist.

    If a DTC is displayed, go to  A.

    If a DTC is not displayed and a vehicle control history is displayed, go to  B.

    If no DTC or vehicle control history is displayed, and charging does not start at the set start time, go to  C.

    If no DTC or vehicle control history is displayed, and charging starts at the set start time, go to  D.

    Yes: 

    1. Perform the diagnosis for the displayed DTCs.
    2. Go to the vehicle control history.
      • Plug-in Battery Charger. Refer to PLUG-IN BATTERY CHARGER (DIAGNOSTICS)>WORK SUPPORT .
      • P-HEV Hybrid Powertrain Controls Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>WORK SUPPORT .
    3. Go to  4.
    4. Analyze the cause (environment or user cause).

      Analyze the cause as shown below in order: environment → user.

    Environment

    • Stop caused by power outage, breaker trip, etc.
      • Ask questions to customer and explain method of use.
      • Explain that charging does not start when a power outage or breaker trip occurs.
    • Plug-in charging suspended from the charger side or problem with compatibility
      • Ask questions to customer and explain method of use.
      • Explain that there is the possibility that charging will not start due to power restrictions or power ON/OFF function on the charger side, and that charging may not be possible due to problems with charger compatibility. (Check with the charger manufacturer.)
      • Explain that due to the charger specifications, charging may stop when the HV battery is cold.

    User

    • The vehicle time or date display is incorrect.
      • Adjust the vehicle time and date to the correct values.
    • The timer settings are incorrect.
      • Ask questions to customer and explain method of use.
      • Check with the instructions or other material.
    • Setting a timer and charging from a public charger or similar equipment
      • Ask questions to customer and explain method of use.
      • Explain that with some chargers, charging using the vehicle timer is not possible due to the charger specifications.
    • The Electric vehicle charger cable assembly was connected after the set start time.
      • Explain that the Electric vehicle charger cable assembly must be inserted before the set start time.
    • The Charging connector is not securely connected to the Charging inlet.
      • Ask questions to customer and explain method of use.
      • Explain that the Charging connector must be inserted all the way into the Charging inlet.
      • Explain that when a timer is set and the Charging connector is connected, the charging indicator blinks (normal).
    • Charging when fully charged
      • Explain that charging does not start when the battery is fully charged.
      • Explain that charging may not start because the system considers the battery fully charged until the remaining battery charge has dropped by a certain amount or more after driving.
      • Explain that if the Charging connector is connected to the vehicle when the battery is fully charged, charging does not start. In this case, the charging indicator illuminates for several seconds (Charge Now) or blinks for several seconds (timer charging) and then turns OFF.
    • Selection of wrong charging mode
      • Ask questions to customer and explain method of use.
      • Explain that when the charging mode is "Start time", charging starts at the set time. When the mode is "Departure time", charging is performed so that it is completed at the set time.

    No:  -

  4. CHECK CHARGING. (USE AN Electric vehicle charger cable assembly WHICH WAS CONFIRMED TO OPERATE NORMALLY.). 
    CAUTION:
    • Perform charging with an AC power supply that was confirmed to operate normally.
    • Use an Electric vehicle charger cable assembly which was confirmed to operate normally.
    • Select an AC power supply (120 V or 240 V) that is the same as the power supply used by the customer.
    1. Using the Subaru Select Monitor, perform all memory clear. Refer to COMMON (DIAG)>CLEAR MEMORY .
    2. Using the Subaru Select Monitor, display the following items in the [Work Support] of [Plug-in Battery Charger]. Refer to PLUG-IN BATTERY CHARGER (DIAGNOSTICS)>WORK SUPPORT .
      • Vehicle Ctl. Hist.
    3. Using the Subaru Select Monitor, clear all memory of [Vehicle Ctl. Hist.]. Refer to COMMON (DIAG)>CLEAR MEMORY .
    4. Using the Subaru Select Monitor, display the following items in the [Work Support] of [P-HEV Hybrid Powertrain Control]. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>WORK SUPPORT .
      • Vehicle Ctl. Hist.
    5. Using the Subaru Select Monitor, clear all memory of [Vehicle Ctl. Hist.]. Refer to COMMON (DIAG)>CLEAR MEMORY .
    6. Using the Subaru Select Monitor, display the following items in the [Data Monitor] of [P-HEV Hybrid Powertrain Control]. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DATA MONITOR .
      • Hybrid Battery SOC
    7. Read the data monitor, and check that the HV battery SOC is less than 70%.
      NOTE: If the HV battery SOC is 70% or more, perform driving in EV mode or use other means to discharge the HV battery and reduce the SOC to less than 70%.
      Item name Item explanation Display range Standard
      Hybrid Battery SOC Indicates the battery capacity. 0.00 - 100.00% 0.00 - 100.00%: Always
    8. Turn ON "Charge Now".
      NOTE:
      • This is not necessary when there is nothing registered in the timer charging schedule.
      • How to set Charge Now
        • Press the Timer charging setting switch.
        • Display the MFD "Charge timer settings" screen and select Charge Now.
    9. Connect an Electric vehicle charger cable assembly which was confirmed to operate normally and perform charging.
    10. Using the Subaru Select Monitor, read all DTCs. Refer to COMMON (diag)>DIAGNOSTIC TROUBLE CODE (DTC) .
    11. Using the Subaru Select Monitor, display the following items in the [Work Support] of [Plug-in Battery Charger]. Refer to PLUG-IN BATTERY CHARGER (DIAGNOSTICS)>WORK SUPPORT .
      • Vehicle Ctl. Hist.
    12. Using the Subaru Select Monitor, display the following items in the [Work Support] of [P-HEV Hybrid Powertrain Control]. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>WORK SUPPORT .
      • Vehicle Ctl. Hist.
    13. Remove the Electric vehicle charger cable assembly.

    If a DTC is displayed, go to  A.

    If a vehicle control history is displayed, go to  B.

    If no DTC or vehicle control history is displayed, go to  C.

    (If trouble occurred, use the Electric vehicle charger cable assembly that was provided with the vehicle.)

    If no DTC or vehicle control history is displayed, and charging did not start, go to  D.

    (If trouble occurred, use a charger or an Electric vehicle charger cable assembly other than the one that was provided with the vehicle.)

    If no DTC or vehicle control history is displayed, and charging started, go to  E.

    (If trouble occurred, use a charger or an Electric vehicle charger cable assembly other than the one that was provided with the vehicle.)

    Yes: 

    1. Perform the diagnosis for the displayed DTCs.
    2. Go to the vehicle control history.
      • Plug-in Battery Charger. Refer to PLUG-IN BATTERY CHARGER (DIAGNOSTICS)>WORK SUPPORT .
      • P-HEV Hybrid Powertrain Control. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>WORK SUPPORT .

    5. Analyze the cause (environment or user cause).

      Analyze the cause as shown below in order: environment → user.

    Environment

    • Stop caused by power outage, breaker trip, etc.
      • Ask questions to customer and explain method of use.
      • Explain that charging does not start when a power outage or breaker trip occurs.
    • Plug-in charging suspended from the charger side or problem with compatibility
      • Ask questions to customer and check charger.
      • Explain that there is the possibility that charging will not start due to power restrictions or power ON/OFF function on the charger side, and that charging may not be possible due to problems with charger compatibility. (Check with the charger manufacturer.)
      • Explain that due to the charger specifications, charging may stop when the HV battery is cold.

    User

    • The timer is set.
      • Ask questions to customer and explain method of use.
      • Explain that when a timer is set and the Charging connector is connected, the charging indicator may blink for several seconds and then turn OFF.
      • Explain that when a timer is set, charging will not begin immediately when the Electric vehicle charger cable assembly is connected. (Explain that in order to start charging immediately, the user should either cancel all set timers or to select "Charge Now", which temporarily enables immediate charging while the timer is set.)
      • Explain that in order to select Charge Now, the user should display the MFD "Charge timer settings" screen and select Charge Now.
    • Incorrect method of charger use
      • Check the method of charger use with the instructions or other material.
    • The Charging connector is not securely connected to the Charging inlet.
      • Ask questions to customer and explain method of use.
      • Explain that the Charging connector must be inserted all the way into the Charging inlet to connect it.
    • Charging when fully charged
      • Explain that if the Charging connector is connected to the vehicle when the battery is fully charged, charging does not start. In this case, the charging indicator illuminates for several seconds (Charge Now) or blinks for several seconds (timer charging) and then turns OFF.
