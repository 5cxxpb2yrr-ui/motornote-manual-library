EV Charger

Do you like it dark? Easier on the eyes.

WARNING: This page is about a different variant/trim than selected.
  1. Install the EV charger.
    1. Install the bracket - EV charger.
      CAUTION: Use a new bolt.

      Tightening torque: 

      5 N.m (0.5 kgf-m, 3.7 ft-lb)

    2. Install the EV charger to the frame - charger.

    Tightening torque: 

    HV battery: Refer to HYBRID ELECTRIC VEHICLE>GENERAL DESCRIPTION>COMPONENT>HV BATTERY .

  2. Install the bracket - harness.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  3. Install the charger harness.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  4. Install the HV battery charger wire No. 2.
    CAUTION: Make sure the connector is connected securely.
  5. Install the HV battery charger wire No. 1.
    CAUTION: Make sure the connector is connected securely.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  6. Install the plate - charger side.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  7. Install the plate - charger rear.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  8. Install the duct - outlet charger INN.
  9. Install the charger cooling blower. Refer to HYBRID ELECTRIC VEHICLE>ELECTRIC VEHICLE CHARGER>INSTALLATION>COOLING BLOWER .
