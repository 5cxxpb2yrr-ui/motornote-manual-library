Rear Antenna

• 4 DOOR MODEL 

  1. Install the rear antenna assembly - interior.
  2. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .

• 5 DOOR MODEL (EXCEPT FOR HYBRID) 

  1. Install the rear antenna assembly - interior.
  2. Install the spacer - rear floor CTR.
  3. Install the mat - rear floor, spacer - rear floor side RH, and spacer - rear floor side LH.
  4. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .

• 5 DOOR MODEL (HYBRID) 

  1. Install the rear antenna assembly - interior.
  2. Install the box - sub-trunk.
  3. Install the mat - rear floor.
  4. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
