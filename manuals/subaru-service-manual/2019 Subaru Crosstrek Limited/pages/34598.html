Chain Cover: Assembly

  1. Install the camshaft position sensor.

    Except for hybrid model: 

    Refer to FUEL INJECTION (FUEL SYSTEMS) (H4DO (EXCEPT FOR HEV))>CAMSHAFT POSITION SENSOR>INSTALLATION .

    Hybrid model: 

    Refer to FUEL INJECTION (FUEL SYSTEMS) (H4DO (HEV))>CAMSHAFT POSITION SENSOR>INSTALLATION .

  2. Install the oil control solenoid.

    Except for hybrid model: 

    Refer to FUEL INJECTION (FUEL SYSTEMS) (H4DO (EXCEPT FOR HEV))>OIL CONTROL SOLENOID>INSTALLATION .

    Hybrid model: 

    Refer to FUEL INJECTION (FUEL SYSTEMS) (H4DO (HEV))>OIL CONTROL SOLENOID>INSTALLATION .

  3. Install the engine oil temperature sensor.

    Except for hybrid model: 

    Refer to FUEL INJECTION (FUEL SYSTEMS) (H4DO (EXCEPT FOR HEV))>ENGINE OIL TEMPERATURE SENSOR>INSTALLATION .

    Hybrid model: 

    Refer to FUEL INJECTION (FUEL SYSTEMS) (H4DO (HEV))>ENGINE OIL TEMPERATURE SENSOR>INSTALLATION .

  4. Install the oil pressure switch. Refer to LUBRICATION (H4DO (EXCEPT FOR HEV))>OIL PRESSURE SWITCH>INSTALLATION .
  5. Install the engine oil filter and the oil pump union. Refer to LUBRICATION (H4DO (EXCEPT FOR HEV))>OIL FILTER>INSTALLATION .
  6. Install the oil filler cap.
