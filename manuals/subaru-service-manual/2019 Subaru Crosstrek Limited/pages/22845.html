DTC B1576: EGI Control Module EEPROM

Diagnosis start condition: 

  • Battery voltage is 10 V or more.
  • The remote engine starter was not used to start the engine.

DTC detecting condition: 

  • ECM malfunctioning
  • Failed to access ROM in ECM during key registration.

Trouble symptom: 

  • Engine will not start.
  • The security indicator illuminates.
CAUTION: When the ECM is replaced, registration of the immobilizer system is required. For details, refer to the "REGISTRATION INSTRUCTIONS FOR IMMOBILIZER" provided as a separate volume.
  1. PERFORM ECM REGISTRATION. 

    Perform ECM registration. Refer to the "REGISTRATION INSTRUCTIONS FOR IMMOBILIZER" provided as a separate volume.

    Is registration complete?

    Yes:  Finish the diagnosis.

    No:  Go to  2.

  2. PERFORM ECM REGISTRATION. 

    Perform ECM registration. Refer to the "REGISTRATION INSTRUCTIONS FOR IMMOBILIZER" provided as a separate volume.

    Is registration complete?

    Yes:  Finish the diagnosis.

    No:  Go to  3.

  3. PERFORM ECM REGISTRATION. 

    Perform ECM registration. Refer to the "REGISTRATION INSTRUCTIONS FOR IMMOBILIZER" provided as a separate volume.

    Is registration complete?

    Yes:  Finish the diagnosis.

    No:  Refer to "Correspondence table when registration is not possible" in the "REGISTRATION INSTRUCTIONS FOR IMMOBILIZER" provided as a separate volume. If the registration still does not work properly, replace the ECM. Refer to FUEL INJECTION (FUEL SYSTEMS) (H4DO (EXCEPT FOR HEV))>ENGINE CONTROL MODULE (ECM) .
