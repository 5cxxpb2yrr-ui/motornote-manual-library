Radiator Fan and Fan Motor Assembly: Installation

  1. Install the radiator fan and fan motor assembly.
  2. Install the radiator upper cushion to the pin at the upper part of the radiator.
  3. Set the radiator upper frame, and install the upper side bolts securing the radiator upper frame.
    NOTE: Securely install the radiator upper cushion to the radiator upper frame.

    Tightening torque: 

    18 N.m (1.8 kgf-m, 13.3 ft-lb)

  4. Connect the horn connector and install the clip.
  5. Install the front hood lock assembly. Refer to SECURITY AND LOCKS>FRONT HOOD LOCK ASSEMBLY>INSTALLATION .
  6. Install the bracket - bumper UPR.

    Tightening torque: 

    7.5 N.m (0.8 kfg-m, 5.5 ft-lb)

  7. Install the cover UPR - front.
  8. Install the front bumper. Refer to EXTERIOR/INTERIOR TRIM>FRONT BUMPER>INSTALLATION .
  9. Install the air intake duct. Refer to INTAKE (INDUCTION) (H4DO (EXCEPT FOR HEV))>AIR INTAKE DUCT>INSTALLATION .
  10. Install the reservoir tank. Refer to COOLING (H4DO (EXCEPT FOR HEV))>RESERVOIR TANK>INSTALLATION .
  11. Connect the over flow hose.
  12. Connect the main fan motor connector and the sub fan motor connector.
  13. Install the lower side bolts securing the radiator upper frame.

    Tightening torque: 

    18 N.m (1.8 kgf-m, 13.3 ft-lb)

  14. Install the under cover - front. Refer to EXTERIOR/INTERIOR TRIM>FRONT UNDER COVER>INSTALLATION .
  15. Install the V-belt cover.

    Tightening torque: 

    7 N.m (0.7 kgf-m, 5.2 ft-lb)

  16. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
