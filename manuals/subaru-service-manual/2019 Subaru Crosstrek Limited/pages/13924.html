DTC P1F09: Control Module Processor: Notes

1. - 

DTC detecting condition: 

Immediately at fault recognition

Trouble symptom: 

Driveability getting worse.

  1. CHECK DTC  .
    1. Using the Subaru Select Monitor, perform the clear memory. Refer to COMMON (DIAG)>CLEAR MEMORY .
    2. Read the DTC using Subaru Select Monitor. Refer to AWD CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC P1F09 displayed?

    Yes:  Replace the AWD control module. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TH2A)>AWD CONTROL MODULE .

    No:  Current condition is normal. Check for interference from noise, etc.
