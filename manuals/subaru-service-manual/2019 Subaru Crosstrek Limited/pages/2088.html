Sonar Sensor

CAUTION: When reusing the sensor, make sure to align the mark on the sensor and the bumper face - rear or others, and surely return each sensor to the original position before removed.
  1. Install the bezel - sonar.
  2. Install the sonar sensor.
  3. Install the cord assembly - sonar.
  4. Install the bumper face - rear.
  5. Connect the battery ground terminal. Ref. to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
  6. When the bumper face - rear and the sonar sensor are replaced, check the installation height and angle. Ref. to REVERSE AUTOMATIC BRAKING>SENSOR AND HARNESS>INSPECTION>SONAR SENSOR .
