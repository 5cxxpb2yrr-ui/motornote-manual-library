Inspection Mode 1

Do you like it dark? Easier on the eyes.

WARNING: This page is about a different variant/trim than selected.
Code Note Number of driving cycles on the detecting condition
P034000 - 1
P034031 - 1

Diagnostic procedure:

  1. Using the Subaru Select Monitor, perform the clear memory of [P-HEV Drive Motor]. Refer to COMMON (DIAG)>CLEAR MEMORY .
  2. Turn to IG OFF, and wait for two minutes or more.
  3. Using the Subaru Select Monitor, read the DTC of [P-HEV Drive Motor] to check that there is no DTC displayed. Refer to P-HEV DRIVE MOTOR (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
    NOTE: If the DTC is displayed on the screen, the trouble is still present. Perform the diagnosis for the displayed DTCs. After solving the DTC, repeat from step  1.
  4. Turn to READY ON.
  5. Move the shift to P position with the vehicle stopped.
  6. Press Hybrid mode switch, and switch to the battery save mode.
    NOTE: When the HV warning indicator is on due to DTC detection for [P-HEV Hybrid Powertrain Control], [P-HEV Drive Motor] or [P-HEV High Voltage Battery], switching to the battery save mode is not possible. Therefore, inspect the detected DTCs first.

    When switching to the battery save mode is not possible due to a reason other than above, check "Unable to switch to each mode" in Diagnostics with Phenomenon. When the condition is confirmed as normal as a result of checking, proceed the inspection in normal mode. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DIAGNOSTICS WITH PHENOMENON>LIST .

  7. Depress the accelerator pedal to start the engine.
  8. Keep depressing the accelerator pedal to maintain the engine speed to 1, 000 rpm or more for five seconds or more.
  9. Read the [Readiness code] of [P-HEV Drive Motor] using Subaru Select Monitor and check that the concerned self-diagnosis is completed. Refer to P-HEV DRIVE MOTOR (DIAGNOSTICS)>ALL READINESS DIAGNOSTIC CODE(S) .
    NOTE: If the concerned DTC is displayed, the self-diagnosis of the DTC is not complete. Repeat from step  4.
  10. Using the Subaru Select Monitor, read the DTC of [P-HEV Drive Motor] to check that there is no DTC displayed. Refer to P-HEV DRIVE MOTOR (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
    NOTE: If the DTC is displayed on the screen, the trouble is still present. Perform the diagnosis for the displayed DTCs.
