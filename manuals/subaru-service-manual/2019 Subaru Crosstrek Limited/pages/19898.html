DTC P1C2D-62: Hybrid/EV Battery "A" Voltage Sensor/Boosting Converter Voltage Sensor "A" Signal Compare Failure: Notes

WARNING: This page is about a different variant/trim than selected.

1. - 

Outline of diagnosis: 

Deviation abnormality of the battery voltage (VB) sensor/boosting converter voltage (VL) sensor With boosting in progress, difference between battery voltage (VB) and voltage before boosting (VL) is large

(1 trip detection logic)

Trouble symptom: 

Reduced output power

CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK DTC  .

    Read the following DTCs using Subaru Select Monitor. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) . Refer to P-HEV DRIVE MOTOR (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) . Refer to P-HEV HIGH VOLTAGE BATTERY (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

  2. CHECK DTC  .
    1. Using the Subaru Select Monitor, read and record DTC and the freeze frame data of [P-HEV Hybrid Powertrain Control]. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) . Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>FREEZE FRAME DATA .
    2. Using the Subaru Select Monitor, perform the clear memory of [P-HEV Hybrid Powertrain Control]. Refer to COMMON (DIAG)>CLEAR MEMORY .
    3. Set the wheel stoppers to the tires, and apply the parking brake.
    4. Turn to READY ON.
    5. Using the Subaru Select Monitor, display the following items in the [Data monitor] of [P-HEV Hybrid Powertrain Control]. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DATA MONITOR .
      • Hybrid Battery SOC
    6. When [Hybrid Battery SOC] is less than 55%, shift to D position, depress both the accelerator pedal and brake pedal, and charge the battery up to 55% or more.
    7. Shift to P position.
    8. Set the A/C switch to MAX COOL, and turn on the headlight.
    9. Using the Subaru Select Monitor, display the following items in the [Data monitor] of [P-HEV Hybrid Powertrain Control]. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DATA MONITOR .
      • Hybrid Battery Current
    10. Check that the [Hybrid Battery Voltage] exceeds 3 A.
    11. In Engine always stopped state with steps 7), 8), 9), 10) satisfied, wait for 15 seconds.
    12. Read the DTC of [P-HEV Hybrid Powertrain Control] using the Subaru Select Monitor. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
      NOTE: When an indication that HV battery voltage decreased is displayed, shift to P position, and start the engine to charge HV battery. After Engine always stopped, repeat from step  4.

    When no DTC is displayed, or DTC other than below is displayed, go to  A.

    When DTC P0E311C or P0CA300 is displayed, go to  B.

    When DTC P0B231C or P1C8349 is displayed, go to  C.

    When DTC P300000 is displayed, go to  D.

    Yes: 

    1. Go to  3.
    2. Replace Inverter with converter assembly. Refer to HYBRID ELECTRIC VEHICLE>INVERTER AND CONVERTER ASSEMBLY .
    3. Replace Battery ECU assembly. Refer to HYBRID ELECTRIC VEHICLE>BATTERY CONTROL MODULE .
    4. Leave the shift in P position, and after charging the battery while idling until idling-stop, perform step 2 again.

    No:  -

  3. CHECK DATA MONITOR  .
    1. Turn to IG ON.
    2. Using the Subaru Select Monitor, display the following items in the [Data monitor] of [P-HEV Hybrid Powertrain Control]. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DATA MONITOR .
      • Hybrid Battery SOC
    3. Using the Subaru Select Monitor, check [Data monitor] of [P-HEV Hybrid Powertrain Control] to see if [Hybrid Battery SOC] is less than 70%.
      NOTE: When the value of [Hybrid Battery SOC] is 70% or more, leave with READY ON, N position and so on to lower [Hybrid Battery SOC] to less than 70%.
    4. Turn to IG OFF, and wait for two minutes or more.
    5. Connect Electric vehicle charger cable assembly, and start charging.

    When the charging finished within 20 seconds: Go to  A.

    When the charging continued for 20 seconds or more: Go to  B.

    Yes: 

    1. Go to  4.
    2. Go to  5.

    No:  -

  4. CHECK DATA MONITOR  .
    1. Disconnect Electric vehicle charger cable assembly, and wait for 10 seconds or more.
    2. Turn to IG ON.
    3. Read the DTC of [P-HEV Hybrid Powertrain Control] using the Subaru Select Monitor. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    When only DTC P1C2D62 and P0D4C1C are displayed at the same time, go to  A.

    When DTC other than P1C2D62 and P0D4C1C is displayed, go to  B.

    Yes: 

    1. Replace Battery ECU assembly. Refer to HYBRID ELECTRIC VEHICLE>BATTERY CONTROL MODULE .
    2. Perform the diagnosis for the displayed DTCs.

    No:  -

  5. CHECK DATA MONITOR  .
    1. Turn to IG ON.
    2. Using the Subaru Select Monitor, display the following items in the [Data monitor] of [P-HEV Hybrid Powertrain Control]. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DATA MONITOR .
      • Hybrid Battery Voltage
      • Charging Voltage for Hybrid Battery

    When deviation between [Hybrid Battery Voltage] and [Charging Voltage for Hybrid Battery] is less than 33 V constantly, go to  A.

    When deviation between [Hybrid Battery Voltage] and [Charging Voltage for Hybrid Battery] is 33 V or more constantly, go to  B.

    Yes: 

    1. Replace Inverter with converter assembly. Refer to HYBRID ELECTRIC VEHICLE>INVERTER AND CONVERTER ASSEMBLY .
    2. Replace Battery ECU assembly. Refer to HYBRID ELECTRIC VEHICLE>BATTERY CONTROL MODULE .
