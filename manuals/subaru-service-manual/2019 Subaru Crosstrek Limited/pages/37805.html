Lock Assembly

  1. Before installation, check the following items.
    • Is the cable deformed?
    • Grease is applied sufficiently to cable joints.

      If grease is insufficient, add it as necessary before assembling the cable.

  2. Adjust and install the lock assembly - front hood.
    NOTE: Refer to "ADJUSTMENT" of the lock assembly - front hood. Refer to SECURITY AND LOCKS>FRONT HOOD LOCK ASSEMBLY>ADJUSTMENT .

    Tightening torque: 

    33 N.m (3.4 kgf-m, 24.3 ft-lb)

  3. Install the cable - front hood and the cable - safety.
  4. Install the connector - hood alarm.
  5. Install the cover UPR - front.
  6. Install the air intake duct.
  7. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
  8. Check the clearance and surface level gap between hood COMPL - front and bumper face front, and adjust if it is outside the standard value. Refer to EXTERIOR BODY PANELS>FRONT HOOD>ADJUSTMENT .
