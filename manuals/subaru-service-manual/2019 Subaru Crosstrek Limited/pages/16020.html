CVTF Cooler (Air Cooling): Installation

Do you like it dark? Easier on the eyes.

WARNING: This page is about a different variant/trim than selected.
  1. Install the nuts securing the CVTF cooler (air cool) in the numerical order shown in the figure.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

    Fig 1: CVTF Cooler (Air Cool) Nuts Tightening Sequence
    Courtesy of SUBARU OF AMERICA, INC.
  2. Install a new CVTF cooler (air cool) inlet hose and a new CVTF cooler (air cool) outlet hose.
  3. Install the bumper face - front.

    Refer to EXTERIOR/INTERIOR TRIM>FRONT BUMPER>INSTALLATION .

  4. Connect the battery ground terminal.

    Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
