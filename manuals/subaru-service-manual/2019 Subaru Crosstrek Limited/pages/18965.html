Explanation For Circuits

WARNING: This page is about a different variant/trim than selected.

Motor generator control ECU built in Inverter with converter assembly controls the motor by receiving commands via communication from Hybrid vehicle control ECU assembly.

Hybrid vehicle control ECU assembly monitors the communication data and detects errors.

Communication failure between Motor generator control ECU and Hybrid vehicle control ECU assembly.

NOTE: For the inverter circuit explanation, refer to DTC P0D2D16. Refer to P-HEV DRIVE MOTOR (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC P0D2D16 DRIVE MOTOR "A" INVERTER VOLTAGE SENSOR (VH) CIRCUIT VOLTAGE BELOW THRESHOLD .
