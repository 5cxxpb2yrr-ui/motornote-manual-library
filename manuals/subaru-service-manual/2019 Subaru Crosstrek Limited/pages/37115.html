Audio / Video System: Audio: Installation

CAUTION: Do not allow harness and cables to interfere with or get caught by other parts.
  1. Install the audio bracket.
  2. Install the audio assembly.
  3. Install the panel - center UPR.
  4. Install the grille assembly - CTR ventilation.
  5. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
