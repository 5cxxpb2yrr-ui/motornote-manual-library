DTC C1C60: Not Initializing: Notes

1. - 

DTC detecting condition: 

  • When [Motor Control Prohibition] in [Work Support] is performed by using the Subaru Select Monitor.
  • When the brake booster assembly (with the master cylinder) is replaced.

Trouble symptom: 

Regenerative brake cannot be controlled.

  1. AIR BLEEDING FROM BRAKE SYSTEM. 

    Using the Subaru Select Monitor, perform [Air Bleeding from Brake System] under [Brake System Bleeding] in [Work Support]. Ref. to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>WORK SUPPORT .

    Yes:  Go to  2.

    No:  -

  2. CHECK DTC. 
    1. Using the Subaru Select Monitor, perform the clear memory. Ref. to COMMON (DIAG)>CLEAR MEMORY .
    2. Read the DTC using Subaru Select Monitor. Ref. to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC C1C60 displayed?

    Yes:  Bleed air from brake system again.

    No:  Finish the diagnosis.
