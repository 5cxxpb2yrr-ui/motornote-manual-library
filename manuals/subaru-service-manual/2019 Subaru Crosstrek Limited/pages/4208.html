Work Support: Operation

  1. On [Start] display, select [Diagnosis].
  2. On [Vehicle selection] display, input the target vehicle information and select [OK].
  3. On [Main Menu] display, select [Each System].
  4. On [Select System] display, select [Keyless Entry].
  5. On [Select Function] display, select [Work Support].
  6. Select a process item.
    NOTE:
    • For detailed operation procedures, refer to "Help" of application.
    • For details on items, refer to the list. Ref. to KEYLESS ENTRY (DIAGNOSTICS)>FREEZE FRAME DATA>LIST .
