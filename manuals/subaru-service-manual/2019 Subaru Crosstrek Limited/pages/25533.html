Trunk Lid Opener

  1. Before installation, check the following items.
    • Cable is free from deformation such as fray.
  2. Install the cable assembly - trunk lid and the cable assembly - fuel.
  3. Install the lower inner trim. Refer to EXTERIOR/INTERIOR TRIM>LOWER INNER TRIM>INSTALLATION .
  4. Install the trim panel - trunk side RH and the trim panel - trunk lid. Refer to EXTERIOR/INTERIOR TRIM>TRUNK ROOM TRIM>INSTALLATION .
  5. Install the spacer - rear floor front.
  6. Install the trim panel - trunk mat and the spacer - CTR.
  7. Install the pull handle - opener.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  8. Install the cover - handle.
