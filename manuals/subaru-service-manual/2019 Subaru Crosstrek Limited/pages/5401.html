Linear Valve Offset Learning

NOTE: The brake warning light blinks while linear valve offset learning is in progress, and either turns OFF or illuminates (constant) when learning is completed.
  1. Check the following items in order to correctly complete linear valve offset learning.
    • Check that the voltage of the 12 volt auxiliary battery is correct when READY is ON.
    • Check whether the VDC control unit & hydraulic control module (VDC Control Module & H/U) or brake accumulator assembly is hot.
    CAUTION: If the VDC control unit & hydraulic control module (VDC Control Module & H/U) or brake accumulator assembly is hot, wait for the temperature to drop before performing linear valve offset learning.
  2. Release the parking brake.
    NOTE:
    • Linear valve offset learning, brake stroke sensor 0-point learning, and system information storage cannot be started when the parking brake is engaged.
    • If the parking brake was engaged while linear valve offset learning was in progress, learning is stopped. If learning was stopped, learning will be resumed when the parking brake is released.
  3. Using the Subaru Select Monitor, select [Learning Offset of Liner Solenoid Valve] on the [Work Support] display. Refer to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>WORK SUPPORT .
  4. Follow the instructions on the Subaru Select Monitor screen and perform linear valve offset learning.
  5. Keep the vehicle at rest and do not operate the brake pedal for approximately 2 minutes after changing to test mode.
    CAUTION: Do not drive or operate the brake pedal while linear valve offset learning is in progress.
  6. When executed (approximately 2 minutes), the brake warning light (red) will change from illuminated to blinking (0.25 second cycle), and then change to blinking on a 1 second cycle before turning OFF. At this point, linear valve offset learning is completed.
NOTE:
  • Learning is possible when the voltage of the 12 volt auxiliary battery is 10V or higher.
  • When the voltage of the 12 volt auxiliary battery is low, learning may become impossible before it is completed.
  • The time required until learning is completed varies depending on the 12 volt auxiliary battery voltage.
  • If linear valve offset learning stopped before it was completed, DTC: C1BFF (linear valve offset learning not performed) is stored. Turn the ignition switch OFF and perform learning again.
  • During learning, the brake warning light (red) changes as shown in the table below.
    Linear valve offset learning status Brake warning light (red) status
    During learning (before completion) Blinking at 1 sec cycle
    Learning completed OFF or ON
  • After linear valve offset learning is completed, the brake warning light (red) turns OFF.
  • If learning was not completed (such as when DTC: C1BFF is stored), or if learning was completed when a DTC was stored before learning start, the brake warning light (red) turns ON. In this case, repair or replace faulty parts according to the DTC diagnosis.
