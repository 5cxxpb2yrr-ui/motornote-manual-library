Primary Pulley And Secondary Pulley: Installation

  1. Select shims for pulley alignment. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>PRIMARY PULLEY AND SECONDARY PULLEY>ADJUSTMENT .
  2. Install the seal ring to the input shaft.
    NOTE:
    • Use new seal rings.
    • When installing the seal rings, do not expand the seal rings too much.
    • Apply CVTF to the seal rings.
    Courtesy of SUBARU OF AMERICA, INC.
  3. Install the seal ring to drive pinion retainer.
    NOTE:
    • Use new seal rings.
    • Apply CVTF to the seal rings.
    Courtesy of SUBARU OF AMERICA, INC.
  4. Install the selected shims to the primary pulley bearing catch surface.
  5. Install the secondary pulley to the drive pinion retainer.
    Courtesy of SUBARU OF AMERICA, INC.
  6. Install and tighten the secondary pulley securing bolts.
    1. Tighten the three bolts until the seating surfaces contact the bearing retainer.
      NOTE:
      • Be careful not to tilt the bearing retainer of the secondary pulley.
      • Apply CVTF to the bolt.
      Courtesy of SUBARU OF AMERICA, INC.
    2. Tighten the bolts in the order of (A) → (B) → (C) → (B).

      Tightening torque: 

      67.5 N.m (6.9 kgf-m, 49.8 ft-lb)

    Courtesy of SUBARU OF AMERICA, INC.
  7. Place the variator chain on the V groove of the secondary pulley, and set the ST.

    Preparation tool: 

    ST: EXPANDER PULLEY (18769AA010)

    Courtesy of SUBARU OF AMERICA, INC.
  8. Expand the V groove of the secondary pulley.
  9. Install the primary pulley to the reverse brake housing together with the variator chain.
    CAUTION: Cover the V grooves of primary pulley and secondary pulley with cloth to protect the both pulleys and variator chain from scratching.
    1. Intersect the V groove of primary pulley and the V groove of secondary pulley and install the secondary pulley while placing the variator chain on secondary pulley.
      Courtesy of SUBARU OF AMERICA, INC.
    2. Install the primary pulley to the reverse brake housing so that the bolt hole of primary bearing retainer and the bolt hole of reverse brake housing are aligned.
  10. Install the primary pulley bolt.

    Tightening torque: 

    21 N.m (2.1 kgf-m, 15.5 ft-lb)

    Courtesy of SUBARU OF AMERICA, INC.
  11. Install the chain guide.
    1. Install the chain guide to the variator chain, and move it to the primary pulley side.
      Courtesy of SUBARU OF AMERICA, INC.
    2. Place the support rod inside of the variator chain.
      CAUTION: Protect the both pulleys and variator chain from scratching.
    3. While holding the support rod, press the chain guide so that the support rod runs through between the protrusions of chain guide and install the chain guide to the support rod.
      Courtesy of SUBARU OF AMERICA, INC.
    4. Install the support rod.

      Tightening torque: 

      21 N.m (2.1 kgf-m, 15.5 ft-lb)

      Courtesy of SUBARU OF AMERICA, INC.
    5. Install the lubrication pipe.

      Tightening torque: 

      21 N.m (2.1 kgf-m, 15.5 ft-lb)

      Courtesy of SUBARU OF AMERICA, INC.
    6. Install the chain guide so that the lubrication pipe runs through between the protrusions of each chain guide. Then remove the ST (EXPANDER PULLEY).
    Courtesy of SUBARU OF AMERICA, INC.
  12. Install the reduction drive gear. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>REDUCTION DRIVE GEAR>INSTALLATION .
  13. Select the reduction drive gear shim. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>REDUCTION DRIVE GEAR>ADJUSTMENT .
  14. Install the transmission case. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSMISSION CASE>INSTALLATION .
  15. Install the transmission control device. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSMISSION CONTROL DEVICE>INSTALLATION .
  16. Install the oil strainer and oil pan. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>OIL PAN AND STRAINER>INSTALLATION .
  17. Install the reduction driven gear assembly. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>REDUCTION DRIVEN GEAR>INSTALLATION .
  18. Install the parking pawl. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>PARKING PAWL>INSTALLATION .
  19. Install the transfer driven gear assembly. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSFER DRIVEN GEAR>INSTALLATION .
  20. Install the transfer clutch assembly. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSFER CLUTCH>INSTALLATION .
  21. Install the extension case. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>EXTENSION CASE>INSTALLATION .
  22. Install the inhibitor switch. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>INHIBITOR SWITCH>INSTALLATION .
  23. Install the secondary speed sensor. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>SECONDARY SPEED SENSOR>INSTALLATION .
  24. Install the primary speed sensor. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>PRIMARY SPEED SENSOR>INSTALLATION .
  25. Install the turbine speed sensor. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TURBINE SPEED SENSOR>INSTALLATION .
  26. Install the transmission harness. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSMISSION HARNESS>INSTALLATION .
  27. Install the control valve body. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>CONTROL VALVE BODY>INSTALLATION .
  28. Install the air breather hose. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>AIR BREATHER HOSE>INSTALLATION .
  29. Install the transmission assembly to the vehicle. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>AUTOMATIC TRANSMISSION ASSEMBLY>INSTALLATION .
