Transfer Clutch: Installation

  1. Install the thrust bearing.
    NOTE: Make sure to install in the right direction.
    Courtesy of SUBARU OF AMERICA, INC.
  2. Install the transfer clutch assembly.
    Courtesy of SUBARU OF AMERICA, INC.
  3. Select the transfer driven gear shim. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSFER CLUTCH>ADJUSTMENT .
  4. Attach the selected transfer driven gear shim to extension case with vaseline.
  5. Remove the transfer clutch assembly.
  6. Install the seal ring to the transfer clutch assembly.
    NOTE:
    • Use new seal rings.
    • When installing the seal rings, do not expand the seal rings too much.
    • Apply CVTF to the seal rings.
    Courtesy of SUBARU OF AMERICA, INC.
  7. Install the seal ring to the transfer driven gear assembly.
    NOTE:
    • Use new seal rings.
    • When installing the seal rings, do not expand the seal rings too much.
    • Apply CVTF to the seal rings.
    Courtesy of SUBARU OF AMERICA, INC.
  8. Install the transfer clutch assembly.
  9. Install the extension case. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>EXTENSION CASE>INSTALLATION .
  10. Install the transmission assembly to the vehicle. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>AUTOMATIC TRANSMISSION ASSEMBLY>INSTALLATION .
