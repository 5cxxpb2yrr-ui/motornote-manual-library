DTC P0A95-63: High Voltage Fuse Accumulated Load History: Notes

WARNING: This page is about a different variant/trim than selected.

1. - 

Outline of diagnosis: 

If the accumulated value exceeds the threshold value by estimating the heat load of high pressure fuse

(1 trip detection logic)

Trouble symptom: 

Normal driving

CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to P-HEV HIGH VOLTAGE BATTERY (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. REPLACEMENT OF Hybrid battery terminal block. 
    CAUTION: Make sure to wear insulated gloves and protective goggles during the work.

    Replace Hybrid battery terminal block.

    Is Hybrid battery terminal block replaced?

    Yes:  Go to  2.

    No:  Replace Hybrid battery terminal block.

    And then, Go to  2.

  2. PERFORM High Voltage Fuse Accumulated Load History Reset. 
    CAUTION: Make sure to wear insulated gloves and protective goggles during the work.
    1. Restore the vehicle to its original state.
    2. Using the Subaru Select Monitor, perform [High Voltage Fuse Accumulated Load History Reset] on [Work Support] of [P-HEV High Voltage Battery]. Refer to P-HEV HIGH VOLTAGE BATTERY (DIAGNOSTICS)>WORK SUPPORT>OPERATION>INITIALIZATION OF HIGH PRESSURE FUSE LOAD LOG .

    Was [High Voltage Fuse Accumulated Load History Reset] performed?

    Yes:  Go to  3.

    No:  Perform [High Voltage Fuse Accumulated Load History Reset].

    And then, Go to  3.

  3. CLEAR MEMORY. 

    Using the Subaru Select Monitor, perform the clear memory of [P-HEV High Voltage Battery]. Refer to COMMON (DIAG)>CLEAR MEMORY .

    Is Clear Memory performed?

    Yes:  Finish the work.

    No:  Clear the memory and end the work.
