X MODE Switch: Installation

  1. Install X mode switch to the cover assembly - front.
  2. Install the cover assembly - front. Refer to EXTERIOR/INTERIOR TRIM>CONSOLE BOX>INSTALLATION .
  3. Connect the ground terminal to battery sensor. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
