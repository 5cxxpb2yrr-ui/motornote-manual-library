Re-Register LAN Connection Unit

  1. On [Start] screen, select [Diagnosis].
  2. On [Select Vehicle] screen, input the target vehicle information and select [OK].
  3. On [Main Menu] screen, select [Each System].
  4. On [Select System] screen, select [Central Gateway], and then select [Next].
  5. On [Select Function] screen, select [Work Support].
  6. Select [Re-register LAN connection unit] on the [Work Support] screen.
    NOTE: For detailed operation procedures, refer to "Help" of application.
