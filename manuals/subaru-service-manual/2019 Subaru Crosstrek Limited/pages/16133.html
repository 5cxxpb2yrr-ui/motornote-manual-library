Rear Exhaust Pipe: Installation

Do you like it dark? Easier on the eyes.

  1. Install the center exhaust cover.

    Tightening torque: 

    18 N.m (1.8 kgf-m, 13.3 ft-lb)

  2. Set new gasket to the rear exhaust pipe. (Front side)
  3. Apply a coat of spray type lubricant to the mating area of cushion rubber.
  4. Install the rear exhaust pipe.
    NOTE: After installation, degrease the cushion rubber.
  5. Set a new gasket, and connect the rear exhaust pipe and muffler.
    CAUTION: Be sure to use a new self-locking nut.

    Tightening torque: 

    48 N.m (4.9 kgf-m, 35.4 ft-lb)

  6. Connect the front exhaust pipe and rear exhaust pipe.

    Tightening torque: 

    18 N.m (1.8 kgf-m, 13.3 ft-lb)
