Front Suspension System And Wheel Alignment: Stabilizer: Installation: Stabilizer

  1. Install the clamp - stabilizer bushing.

    Tightening torque: 

    25 N.m (2.5 kgf-m, 18.4 ft-lb)

  2. Install the stabilizer link (bottom part).

    Tightening torque: 

    60 N.m (6.1 kgf-m, 44.3 ft-lb)

  3. Install the front exhaust pipe.

    Refer to EXHAUST (H4DO (EXCEPT FOR HEV))>FRONT EXHAUST PIPE>INSTALLATION .

  4. Install the crossmember support - rear.

    Tightening torque: 

    70 N.m (7.1 kgf-m, 51.6 ft-lb)

  5. Install the under cover - front.

    Tightening torque: 

    18 N.m (1.8 kgf-m, 13.3 ft-lb)
