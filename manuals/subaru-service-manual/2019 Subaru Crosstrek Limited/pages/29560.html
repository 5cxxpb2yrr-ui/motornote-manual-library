Diagnostic Trouble Code (DTC): Operation

WARNING: This page is about a different variant/trim than selected.
NOTE:
  • Refer to "COMMON (diag)". Refer to COMMON (diag)>DIAGNOSTIC TROUBLE CODE (DTC) .
  • For details on DTCs, refer to the list. Refer to EYESIGHT (DIAGNOSTICS) (HEV)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .
  • Up to ten codes can be stored. When more than ten codes are output, they will not be stored.
  • The same code is stored only once, and even when the same code occurs several times, information will not be updated.
