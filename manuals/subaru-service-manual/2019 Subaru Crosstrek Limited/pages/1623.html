Inspection Mode 2

DTC Item Note
B1730 CENTRAL GATEWAY CONTROL MODULE IGNITION/ACCESSORY POWER -
U0073 CONTROL MODULE COMMUNICATION BUS OFF -
U0074 CONTROL MODULE COMMUNICATION BUS "BODY-CAN" OFF -
U0075 CONTROL MODULE COMMUNICATION BUS "PU-CAN" OFF -
U0078 CONTROL MODULE COMMUNICATION BUS "C-CAN" OFF -

Diagnostic procedure:

  1. Using the Subaru Select Monitor, perform the clear memory of [Central Gateway]. Ref. to COMMON (DIAG)>CLEAR MEMORY .
  2. Using the Subaru Select Monitor, read the DTC of [Central Gateway] to check that there is no DTC displayed. Ref. to COMMON (diag)>DIAGNOSTIC TROUBLE CODE (DTC) .
    NOTE: If the DTC is displayed on the screen, the trouble is still present. Perform the diagnosis for the displayed DTCs. After solving the DTC, repeat from step  1.
  3. After the ignition switch is turned ON, wait for 45 seconds or more.
  4. Using the Subaru Select Monitor, read the DTC of [Central Gateway] to check that there is no DTC displayed.
    NOTE: If the DTC is displayed on the screen, the trouble is still present. Perform the diagnosis for the displayed DTCs.
