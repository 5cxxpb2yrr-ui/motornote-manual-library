Outline Of Diagnosis

WARNING: This page is about a different variant/trim than selected.

Judge as NG when the CPU operation is abnormal.

  1. - 1 and (1) - 2 instruction check
  2. Software flow check
  3. Software monitor check
  4. If the output IC operation is abnormal
  5. CAN register check
  6. self check
  7. Register monitoring
