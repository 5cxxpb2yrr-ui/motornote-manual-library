Starting System & Charging System (Except For HEV): Generator: Assembly

Do you like it dark? Easier on the eyes.

  1. Install a new ball bearing to the front cover using a press.
    CAUTION:
    • Press the outer race of bearing using an attachment, etc. suitable for the press.
    • Do not apply grease, etc. to the bearing.
    • If grease, etc. adheres to the bearing mounting section, remove it completely.
  2. Install the bearing retainer to the front cover.

    Tightening torque: 

    2.26 N.m (0.2 kgf-m, 1.7 ft-lb)

  3. Using a vise, secure the rotor assembly.
    CAUTION:
    • Place aluminum plates or wooden pieces between the contacting surfaces of the vise and rotor to prevent rotor damage.
    • Be sure to hold it with the wider surface of the pole core.
    • Do not tighten the vise more than necessary.
  4. Install the front cover to the rotor assembly.
  5. Install the pulley.

    Tightening torque: 

    80 N.m (8.2 kgf-m, 59.0 ft-lb)

  6. Install a new dust cover.
  7. Install a new bearing cover to the stator coil assembly.
  8. Install the stator coil assembly to the rotor assembly.
  9. Install the through bolt.

    Tightening torque: 

    5.6 N.m (0.6 kgf-m, 4.1 ft-lb)

  10. Install the brush assembly.
    NOTE: Install with the brush pressed using the lock pin, etc. Remove the lock pin after installation.

    Tightening torque: 

    1.76 N.m (0.2 kgf-m, 1.3 ft-lb)

  11. Install the bushing to the terminal B.
  12. Install the rear cover.

    Tightening torque: 

    4.55 N.m (0.5 kgf-m, 3.4 ft-lb)

  13. Manually turn the pulley to check that the rotor rotates smoothly.
