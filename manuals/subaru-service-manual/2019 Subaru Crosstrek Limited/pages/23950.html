Horn System: Horn: Installation

CAUTION: Install the mud guard - front so that the front end of the mud guard (b), except for the clip fixing point, comes inside the bumper face (a).
Courtesy of SUBARU OF AMERICA, INC.
  1. Install the horn assembly.

    Tightening torque: 

    18 N.m (1.8 kgf-m, 13.3 ft-lb)

  2. Install the mud guard - front. (Horn assembly - Lo)
  3. Install the under cover - front. (Horn assembly - Lo)

    Tightening torque: 

    18 N.m (1.8 kgf-m, 13.3 ft-lb)

  4. Lower the vehicle. (Horn assembly - Lo)
  5. Install the cover UPR - front. (Horn assembly - Hi)
  6. Install the duct - air intake. (Horn assembly - Hi)
  7. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
