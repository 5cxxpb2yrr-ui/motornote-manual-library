Front Bumper: Installation

CAUTION:
  • Before installing the bumper face, match the claws on the bracket - front bumper with the engaging position of flange section on the bumper face side. If the engaging position is not correct, the flange section may be broken or the clearance between fender panel and bumper face may not be uniform.
  • Install the mud guard - front so that the front end of the mud guard (b), except for the clip fixing point, comes inside the bumper face (a).
Courtesy of SUBARU OF AMERICA, INC.
  1. Install the fog light assembly - front. Refer to LIGHTING SYSTEM>FRONT FOG LIGHT ASSEMBLY>INSTALLATION .
  2. Install the bracket - front bumper side.
  3. Install the bracket - front bumper corner.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  4. Install the bracket - front center LWR.

    Tightening torque: 

    9.5 N.m (1 kgf-m, 7 ft-lb)

  5. Install the under cover - front.

    Tightening torque: 

    18 N.m (1.8 kgf-m, 13.3 ft-lb)

  6. Install the bumper beam COMPL - front.

    Tightening torque: 

    Impreza model 

    33 N.m (3.4 kgf-m, 24.3 ft-lb)

    Crosstrek model 

    32 N.m (3.3 kgf-m, 23.6 ft-lb)

  7. Install the air guide LWR. (Hybrid model)
  8. Install the shutter frame assembly - active grille shutter. (Model without active grille shutter)

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  9. Install the active grille shutter. (Model with active grille shutter)

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  10. Install the energy absorber.
  11. Install the bumper face - front.

    Tightening torque: 

    Plate UPR - front: 7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  12. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
  13. Adjust the headlight beam and fog light beam.
    • Adjust the headlight beam. Refer to LIGHTING SYSTEM>HEADLIGHT ASSEMBLY>ADJUSTMENT>HEADLIGHT BEAM ADJUSTMENT .
    • Adjust the fog light beam. (Model with fog light) Refer to LIGHTING SYSTEM>FRONT FOG LIGHT ASSEMBLY>ADJUSTMENT>FOG LIGHT AIMING .
