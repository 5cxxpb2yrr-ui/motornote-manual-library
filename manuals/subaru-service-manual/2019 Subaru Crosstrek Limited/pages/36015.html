Outer Mirror Assembly: Installation

CAUTION: Be careful not to catch the harness in between the parts.
  1. Install the outer mirror assembly.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  2. Install the front sealing cover.
  3. Install the trim panel - front door.
  4. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY>GROUND TERMINAL REMOVAL OR INSTALLATION .
