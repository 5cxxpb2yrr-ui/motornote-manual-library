Return Hose

WARNING: This page is about a different variant/trim than selected.
CAUTION: Replace the O-rings with new parts, and then apply compressor oil to install completely.
  1. Install the hose - pressure suction COMPL.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  2. Install the A/C accumulator assembly and bracket - A/C accumulator. Refer to AIR CONDITIONER (HEV)>ACCUMULATOR>INSTALLATION .
  3. Install the inverter tank. Refer to COOLING (H4DO (HEV))>INVERTER TANK>INSTALLATION .
  4. Install the bracket - hood stay.

    Tightening torque: 

    18 N.m (1.8 kgf-m, 13.3 ft-lb)

  5. Install the cover UPR - front.
  6. Install the air intake duct. Refer to INTAKE (INDUCTION) (H4DO (EXCEPT FOR HEV))>AIR INTAKE DUCT>INSTALLATION .
  7. Install the collector cover. Refer to INTAKE (INDUCTION) (H4DO (EXCEPT FOR HEV))>COLLECTOR COVER>INSTALLATION .
  8. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
  9. Charge refrigerant. Refer to AIR CONDITIONER (HEV)>REFRIGERANT CHARGING PROCEDURE>PROCEDURE .
  10. Fill engine coolant. (Inverter assembly side) Refer to COOLING (H4DO (HEV))>ENGINE COOLANT>REPLACEMENT>FILLING OF ENGINE COOLANT .
  11. Install the under cover - front. Refer to EXTERIOR/INTERIOR TRIM>FRONT UNDER COVER>INSTALLATION .
