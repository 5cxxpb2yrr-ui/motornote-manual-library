Section 11 (CVT Transaxle (Th2A)): Flywheel: Installation

WARNING: This page is about a different variant/trim than selected.
  1. Temporarily install the crankshaft position sensor plate and flywheel, and install the ST.
    NOTE:
    • Install the crankshaft position sensor plate so that the identifier mark faces the flywheel side.
    • Align the knock pin hole of the crankshaft position sensor plate to the knock pin of the crankshaft to secure the knock pin.
    Courtesy of SUBARU OF AMERICA, INC.

    Preparation tool: 

    ST: CRANKSHAFT STOPPER (498497100)

    Courtesy of SUBARU OF AMERICA, INC.
  2. Install the flywheel.
    1. Tighten the bolts which fasten the flywheel in the numerical order shown in the figure.

      Tightening torque: 

      30 N.m (3.1 kgf-m, 22.1 ft-lb)

    2. Using angle gauge, further tighten the bolts in numerical order as shown in the figure.

      Tightening angle: 

      30°- 35°

      Fig 1: Flywheel Bolts Tightening Sequence
      Courtesy of SUBARU OF AMERICA, INC.
  3. Install the damper (with torque limiter).
    NOTE:
    • Make sure to install in the right direction.
    • Install so that the damper knock pin hole is aligned with the flywheel knock pin.
    Courtesy of SUBARU OF AMERICA, INC.

    Tightening torque: 

    24 N.m (2.4 kgf-m, 17.7 ft-lb)

    Courtesy of SUBARU OF AMERICA, INC.
  4. Install the transmission body.

    Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TH2A)>TRANSMISSION ASSEMBLY>INSTALLATION .
