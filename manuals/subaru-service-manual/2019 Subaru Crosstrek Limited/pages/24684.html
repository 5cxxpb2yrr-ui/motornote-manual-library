Diagnostic Method

Do you like it dark? Easier on the eyes.

WARNING: This page is about a different variant/trim than selected.

Measure the pressure values when the enable conditions are established, and perform diagnosis by calculating those results.

  1. Label the intake manifold pressure value as PMOF1, which is observed when the enable conditions are established, and set the EGR target step to 68step(s) (nearly full open).
  2. Label the intake manifold pressure value as PMON, which is observed after 1000 ms has passed since EGR target step was set to 68step(s) (when the enable conditions were established), and set the EGR target step to 0.
  3. Label the intake manifold pressure as PMOF2, which is observed after 1000 ms has passed since EGR target step was set to 0 (after (1000 ms + 1000 ms) have passed since the enable conditions were established).

Judge as NG when the following conditions are established.

JUDGMENT VALUE SPECIFICATION

Malfunction Criteria Threshold Value
PMON - (PMOF1 + PMOF2)/2 Less than 2.48 kPa (18.6 mmHg, 0.7 inHg)
Courtesy of SUBARU OF AMERICA, INC.

Time needed for diagnosis:  1000 ms x 2

Malfunction indicator light illumination:  Illuminates when malfunction occurs in 2 continuous driving cycles.
