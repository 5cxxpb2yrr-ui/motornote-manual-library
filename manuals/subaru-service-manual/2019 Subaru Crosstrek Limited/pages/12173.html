Inspection Mode 2

Code Description & trouble part Note
B14A1 SUNLOAD SENSOR CIRCUIT LOW/OPEN -
B14A2 SUNLOAD SENSOR CIRCUIT SHORT-CIRCUIT -

Diagnostic procedure:

  1. Using the Subaru Select Monitor, perform the clear memory of [Air Conditioner]. Refer to COMMON (DIAG)>CLEAR MEMORY .
  2. Using the Subaru Select Monitor, read the DTC of [Air Conditioner] to check that there is no DTC displayed. Refer to AIR CONDITIONER (DIAGNOSTICS) (EXCEPT FOR HEV)>DIAGNOSTIC TROUBLE CODE (DTC) .
    NOTE: If the DTC is displayed on the screen, the trouble is still present. Perform the diagnosis for the displayed DTCs. After solving the DTC, repeat from step  1.
  3. Park the vehicle in the place subjected to direct sunlight.
  4. Turn the ignition switch to ON and then leave it for 1 second or more.
  5. Using the Subaru Select Monitor, read the DTC of [Air Conditioner] to check that there is no DTC displayed. Refer to AIR CONDITIONER (DIAGNOSTICS) (EXCEPT FOR HEV)>DIAGNOSTIC TROUBLE CODE (DTC) .
    NOTE: If the DTC is displayed on the screen, the trouble is still present. Perform the diagnosis for the displayed DTCs.
