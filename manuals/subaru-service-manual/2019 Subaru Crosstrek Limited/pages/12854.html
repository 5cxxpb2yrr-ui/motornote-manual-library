DTC C2544: Auto Start Stop System

Do you like it dark? Easier on the eyes.

DTC detecting condition: 

  • When a failure of CAN communication is detected after the ignition switch is ON.
  • When the power steering control module has a detection error after the ignition switch is ON.

Trouble symptom: 

DTC C2544 is stored in the power steering control module.

CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to POWER STEERING (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK LAN SYSTEM. 

    Perform the diagnosis for LAN system using the Subaru Select Monitor. Refer to LAN SYSTEM (DIAGNOSTICS) (EXCEPT FOR HEV)>BASIC DIAGNOSTIC PROCEDURE .

    Is DTC of CAN communication displayed?

    Yes:  Perform the diagnosis according to DTC. Refer to LAN SYSTEM (DIAGNOSTICS) (EXCEPT FOR HEV)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Go to  2.

  2. CHECK POWER STEERING CONTROL MODULE. 
    1. Execute the inspection mode. Refer to POWER STEERING (DIAGNOSTICS)>INSPECTION MODE .
    2. Read the DTC of [Power Steering System] using the Subaru Select Monitor. Refer to POWER STEERING (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC C2544 displayed in current malfunction?

    Yes:  Replace the steering gearbox. Refer to POWER ASSISTED SYSTEM (POWER STEERING)>ELECTRIC POWER STEERING GEARBOX .

    No:  It results from a temporary noise interference. Clear the memory to complete the diagnosis. Refer to COMMON (DIAG)>CLEAR MEMORY .
