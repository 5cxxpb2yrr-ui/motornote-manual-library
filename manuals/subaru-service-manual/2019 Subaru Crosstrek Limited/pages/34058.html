Inspection Mode S

DTC Item Condition Number of driving cycles on the detecting condition
P0851 PARK/NEUTRAL SWITCH INPUT CIRCUIT LOW MT model 2
P0852 PARK/NEUTRAL SWITCH INPUT CIRCUIT HIGH MT model 2
WARNING: When performing inspection mode S on a public road, pay sufficient attention to the traffic condition and give the highest priority to safe driving.

Diagnostic procedure: 

  1. Using the Subaru Select Monitor, clear the memory of [Engine Control System]. Refer to COMMON (DIAG)>CLEAR MEMORY .
  2. Drive 3 times according to the drive pattern described below.
