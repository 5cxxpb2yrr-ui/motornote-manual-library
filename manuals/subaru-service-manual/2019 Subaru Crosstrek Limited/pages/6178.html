Diagnostic Method

Communication Status with ECM is invalid or Communication Status with ECM Valid to Invalid edge is detected.

JUDGMENT VALUE SPECIFICATION

Malfunction Criteria Threshold Value
Case 1 
Communication Status with ECM		 Invalid
Case 2 
(Communication Status with ECM Valid to Invalid edge for time)		 Detected
5.00 sec or more

Time needed for diagnosis: 

  • Case 1:  2 s
  • Case 2:  60 s

Malfunction indicator light illumination:  Illuminates as soon as a malfunction occurs.
