DTC C2124: RL Transmitter No Data

DTC detecting condition  :

Detected when no data is received from each transmitter for 8 minutes or more at a vehicle speed of 40 km/h (25 MPH) or more. (Timer is not cleared when the vehicle speed becomes lower than 40 km/h halfway.)

Trouble symptom: 

Tire pressure warning light blinks 25 times and then illuminates.

CAUTION:
  • When driving vehicle to perform driving test, there should be always 2 persons (driver and checker) to check.
  • Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to TIRE PRESSURE MONITOR (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. REPRODUCTION OF FAILURE. 
    1. Perform the drive test.

      Drive the vehicle at 40 km/h (25 MPH) or faster for at least 10 minutes.

    2. Read the DTC of [Tire Pressure Monitor] using the Subaru Select Monitor. Refer to TIRE PRESSURE MONITOR (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC displayed as current malfunction?

    Yes:  Go to  2.

    No:  When DTC is displayed as "Past faults", the system has returned to a normal condition at this time. Reproduce the failure, and then perform the diagnosis again.

    NOTE: In this case, there may be temporary poor communication due to radio wave environment inside/outside the vehicle.
  2. START FRONT LEFT TRANSMITTER. 
    1. Connect the Subaru Select Monitor and then turn the ignition switch to ON.
    2. Using the Subaru Select Monitor, check the following items in the [Data monitor] of [Tire Pressure Monitor]. Refer to TIRE PRESSURE MONITOR (DIAGNOSTICS)>DATA MONITOR .
    3. Use the transmitter registration tool and transmit the ID from the front left transmitter to check [Latest reception ID].

    Is [Latest reception ID] updated?

    Yes:  Go to  3.

    No:  Replace the front left transmitter. Refer to WHEEL AND TIRE SYSTEM>TIRE PRESSURE MONITORING SYSTEM .

  3. CHECK FRONT LEFT TRANSMITTER ID. 

    Compare the ID on the latest ID display with [FL Registered ID].

    Are the two IDs same?

    Yes:  Go to  4.

    No:  Record [Latest reception ID] as the front left. Go to  4.

  4. START FRONT RIGHT TRANSMITTER. 

    Use the transmitter registration tool and transmit the ID from the front right transmitter to check

    [Latest reception ID].

    Is [Latest reception ID] updated?

    Yes:  Go to  5.

    No:  Replace the front right transmitter. Refer to WHEEL AND TIRE SYSTEM>TIRE PRESSURE MONITORING SYSTEM .

  5. CHECK FRONT RIGHT TRANSMITTER ID. 

    Compare the ID on the latest ID display with [FR Registered ID].

    Are the two IDs same?

    Yes:  Go to  6.

    No:  Record [Latest reception ID] as the front right. Go to  6.

  6. START REAR RIGHT TRANSMITTER. 

    Use the transmitter registration tool and transmit the ID from the rear right transmitter to check

    [Latest reception ID].

    Is [Latest reception ID] updated?

    Yes:  Go to  7.

    No:  Replace the rear right transmitter. Refer to WHEEL AND TIRE SYSTEM>TIRE PRESSURE MONITORING SYSTEM .

  7. CHECK REAR RIGHT TRANSMITTER ID. 

    Compare the ID on the latest ID display with [RR Registered ID].

    Are the two IDs same?

    Yes:  Go to  8.

    No:  Record [Latest reception ID] as the rear right. Go to  8.

  8. START REAR LEFT TRANSMITTER. 

    Use the transmitter registration tool and transmit the ID from the rear left transmitter to check

    [Latest reception ID].

    Is [Latest reception ID] updated?

    Yes:  Go to  9.

    No:  Replace the rear left transmitter. Refer to WHEEL AND TIRE SYSTEM>TIRE PRESSURE MONITORING SYSTEM .

  9. CHECK REAR LEFT TRANSMITTER ID. 

    Compare the ID on the latest ID display with [RL Registered ID].

    Are the two IDs same?

    Yes:  Go to  10.

    No:  Record [Latest reception ID] as the rear left. Go to  10.

  10. CHECK MALFUNCTION TRANSMITTER. 

    Is ID recorded by this procedure?

    Yes:  Go to  11.

    No:  Go to  2.

  11. CHECK MALFUNCTION TRANSMITTER. 

    Check the registered ID of the transmitter indicated by DTC.

    Is there checked ID in the record?

    Yes:  Replace the transmitter of the recorded position. Refer to WHEEL AND TIRE SYSTEM>TIRE PRESSURE MONITORING SYSTEM .

    No:  Replace the transmitter showing the latest ID that is not included in the registered IDs. Refer to WHEEL AND TIRE SYSTEM>TIRE PRESSURE MONITORING SYSTEM .
