Primary Speed Sensor: Installation

CAUTION: Be sure to prevent water or oil from contacting the connector terminal of primary speed sensor. If adhesion occurs, replace with a new part.
  1. Connect the harness connector.
  2. Install the primary speed sensor.
    NOTE:
    • Use new O-rings.
    • Apply CVTF to the O-rings.

    Tightening torque: 

    7 N.m (0.7 kgf-m, 5.2 ft-lb)

  3. Install the transmission assembly. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>AUTOMATIC TRANSMISSION ASSEMBLY>INSTALLATION .
