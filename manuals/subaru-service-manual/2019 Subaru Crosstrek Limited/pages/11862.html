Pre-Delivery Inspection (PDI) Procedure: Notes

Perform the procedures indicated in the table below.

Static checks just after vehicle receipt 

Item Check point
1. Appearance
  1. If the vehicle is covered with protective coating, visually check the vehicle body for damage and dents. If the protective coating has been removed, visually check the painted body surfaces in detail for damage or rust.
  2. Visually check the glass and light lenses for any damage, cracks or excessive gaps between body sheet metal.
  3. Visually check the plated parts for any damage.
  4. Check the instrument panel, console and trim for stains or dirt.
2. Tire
  1. Check the tires for damage, defective, and dents on wheels.
  2. Check the tire air pressure.
3. Fuse installation If the vehicle is about to be delivered to customer, attach a back-up fuse.
4. Door lock/unlock and open/close operations
  1. Using the key, check the door can be locked or unlocked normally.
  2. Open and close all doors to check that there are no problems.
  3. Operate the power door lock switch to check that all doors and the rear gate lock and unlock normally.
5. Child safety lock Check the child safety lock system operates normally.
6. Trunk lid open/close operations
  1. Operate the trunk lock release lever to check that the trunk lid opens normally.
  2. Open and close the trunk lid to check that there are no problems.
7. Rear gate lock/unlock and open/close operation
  1. Check if the rear gate can be unlocked normally through the emergency hole.
  2. Open and close the rear gate to check that there are no problems.
  3. Operate the power door lock switch to check that all doors and the rear gate lock and unlock normally.
8. Operation check of trunk lid release lever Operate the trunk lid release lever to check that the trunk lock is unlocked normally.
9. Fuel lid opener lever (except for hybrid model) Operate the fuel lid opener to check that the fuel lid is unlocked normally.
10. Fuel lid lock/unlock and open/close operation (hybrid model)
  1. Press the fuel lid opener switch to check that the fuel lid is unlocked normally.
  2. Check the fuel lid can be unlocked normally by using an emergency release cable.
11. Charging inlet door and charging connector (hybrid model)
  1. Check the charging inlet door unlocks normally.
  2. With unlock condition, check the charging inlet door opens normally.
  3. Insert the charge cable into the device side, and check the charging indicator illuminates.
  4. Check the charging connector locks and unlocks normally.
  5. Check the charging inlet door and charging connector unlock normally using the emergency unlock function.
12. Towing hook (eyebolt) (Crosstrek model) At factory shipment, the towing hook (eyebolt) is installed to the rear bumper. Remove the towing hook (eyebolt), store it in the holder. Install the supplied rear hook cover to the vehicle.
13. Accessory Check that the following accessories are equipped.
  • Owner's manual
  • Warranty booklet
  • Maintenance note
  • Spare key
  • Key No. plate
  • Jack
  • Jack handle
  • Tool set
  • Charge cable
  • Spare tire or puncture repair kit
  • Towing hook (eyebolt)
14. Front hood lock release Operate the front hood lock release lever to check that the front hood opens normally.
15. Battery Check the battery for any abnormal conditions such as rust or traces of battery fluid leaks. (Including battery (12 V))
16. HV battery cooling air intake Check that no dirt or fluid is adhered or mixed in.
17. EV charger assembly cooling exhaust Check that no dirt or fluid is adhered or mixed in.
18. HV battery smoke emission duct vehicle outside discharge port Check that no dirt or fluid is adhered or mixed in.
19. Brake fluid Check the brake fluid amount.
20. Engine oil Check the engine oil amount.
21. Transmission gear oil Check that the transmission gear oil level is normal.
22. CVTF Check for leakage of CVTF.
23. ATF Check for leakage of the ATF.
24. CVT (TR580 and TH2A) front differential gear oil Check for leakage of CVT (TR580 and TH2A) front differential gear oil.
25. Rear differential gear oil Check for leakage of gear oil from the rear differential.
26. Engine coolant (engine side) Check the engine coolant (engine side) level.
27. Engine coolant (inverter assembly side) Check the engine coolant (inverter assembly side) level.
28. Clutch fluid Check the clutch fluid amount.
29. Window washer fluid Check the window washer fluid amount.
30. Front hood latch Check that the front hood is closed normally and locked securely.
31. Keyless entry system Check that the keyless entry system operates normally.
32. Keyless access system Check that the keyless access system operates normally.
33. Alarm system Check that the alarm system operates normally.
34. Seat
  1. Check the seat surfaces for stains or dirt.
  2. Check the seat installation conditions and functionality.
35. Seat belt
  1. Check the seat belt installation conditions and functionality.
  2. Check the seat belt warning system operates normally.
36. TPMS (U.S. model) If the display of TPMS warning light does not operate normally, perform the diagnosis by referring to TPMS (Diagnosis).
37. Grommet installation Use the following procedures to install the grommet.
  • Install the grommet stored in the glove box to the tie-down hole. (Impreza model)
  • Install the grommet provided on the rear seat to the tie-down hole. (Crosstrek model)

Checks with the engine running 

Item Check point
38. Delivery mode Turn the ignition switch to ON and check that the malfunction indicator light starts blinking.
39. Immobilizer system
  1. Check that the engine starts with all keys that are equipped on vehicle.
  2. Check that the security indicator light operates normally.
40. Push button start Using the access key that is equipped on vehicle, operate the push button start function to check engine start and stop operations.
41. Starting condition Start the engine and check that the engine starts smoothly.
42. Exhaust system Check that the exhaust noise is normal and no leaks are found.
43. Indicator and warning lights Check that all indicator lights and warning lights are operating correctly.
44. Heater & ventilation Check that the heater & ventilation system operates normally.
45. Air conditioner Check that the air conditioner operates normally.
46. Multi-function display (MFD) Check that the Multi-Function Display (MFD) function operates normally.
47. Audio Check the radio and AUX operate normally.
48. Navigation Check the navigation and AUX operate normally.
49. Telematics system
  1. Check that the indicator light on the overhead console or on the stereo camera cover assembly goes off.
  2. Perform the Bluetooth connection procedure between head unit (without navigation) and smartphone.
50. Accessory power supply socket Check that the accessory power supply socket operates normally.
51. Lighting system Check that the lighting system operates normally.
52. Illumination control Check that the illumination control operates normally.
53. Window washer system Check that the window washer system operates normally.
54. Wiper system Check that the wiper system operates normally.
55. Wiper deicer Check that the wiper deicer operates normally.
56. Power window Check that the power window operates normally.
57. Sunroof Check that the sunroof operates normally.
58. Rear defogger system Check that the rear defogger system operates normally.
59. Door mirror Check that the remote control mirror and heated mirror operate normally.
60. Room mirror Check that the automatic anti-glare function operates normally.
61. Steering heater Check that the steering heater operates normally.
62. Blind Spot Detection/Rear Cross Traffic Alert (BSD/RCTA)
  1. Press the BSD/RCTA OFF switch several times to check that the system is activated and deactivated correctly.
  2. Check the rear bumper around the sensor for dirt, scratch, affixed stickers and poor paint coating.
63. Reverse Automatic Braking (RAB)
  1. Check that the RAB system is activated and deactivated correctly.
  2. Check the sonar sensor installed on the rear bumper for parts missing, dirt, scratch, foreign objects, etc.
64. Diagnostic trouble code (DTC) check Check that the diagnostic trouble code (DTC) is not detected.
65. Driver assist indicator Check the driver assist indicator operates normally.

Dynamic test with the vehicle running 

Item Check point
66. Brake test Check the foot brake for normal operations.
67. Parking brake Check that the parking brake operates normally.
68. Shift control Check that the shift patterns are correct.
69. Cruise control Check that the cruise control system operates normally.
70. Subaru EyeSight Check that the Subaru EyeSight operates normally.
71. Hybrid system Check that the hybrid system operates normally.
72. EV (Electric Vehicle) mode light Check the EV (Electric Vehicle) mode light operates normally.

Checks after dynamic test 

Item Check point
73. Power steering system (electric power steering model) Check the steering warning light operation.
74. Fluid leakage Check for fluid/oil leaks.
75. Water leak test Spray the vehicle with water and check for water leaks.
76. Appearance 2
  1. Remove the protective coating (if equipped).
  2. Check the body paints for damage and stain.
  3. Check the plated parts for damage and rust.
