DTC C1423: Different Ecu Specifications

DTC detecting condition: 

A fault is detected if the vehicle type information obtained from ECM via communication is different from the parameter setting information.

Trouble symptom: 

  • ABS does not operate.
  • VDC does not operate.
  • Hill start assist does not operate.
  • EyeSight does not operate. (Models with EyeSight)
CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to BRAKE CONTROL (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
NOTE: When parameter selection for VDC Contol Module is improper, this DTC may be memorized.
  1. CHECK VDC CONTOL MODULE & H/U IDENTIFICATION SYMBOL. 

    Check the identification symbol attached on the H/U. Refer to VEHICLE DYNAMICS CONTROL (VDC)>GENERAL DESCRIPTION>SPECIFICATION .

    Is the identification symbol correct?

    Yes:  Go to  2.

    No:  Replace the VDC Contol Module & H/U. Refer to VEHICLE DYNAMICS CONTROL (VDC)>VDC CONTROL MODULE AND HYDRAULIC CONTROL UNIT (VDCCM & H/U) .

  2. CHECK PARAMETER SELECTED IN VDC CONTOL MODULE. 

    Refer to VEHICLE DYNAMICS CONTROL (VDC)>VDC CONTROL MODULE AND HYDRAULIC CONTROL UNIT (VDCCM & H/U)>MAINTENANCE MODE>VDCCM PARAMETER CHECK .

    Does the parameter registered in the VDC Contol Module match the relevant vehicle?

    Yes:  CVT model: Go to  3.

    MT model: Go to  5.

    No:  Select and register the correct parameter. Refer to VEHICLE DYNAMICS CONTROL (VDC)>VDC CONTROL MODULE AND HYDRAULIC CONTROL UNIT (VDCCM & H/U)>MAINTENANCE MODE>VDCCM PARAMETER SELECTION.

  3. CHECK TCM SPECIFICATION. 

    Check the TCM specification.

    Is the specification of TCM same as vehicle specification?

    Yes:  Go to  4.

    No:  Replace the TCM. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSMISSION CONTROL MODULE (TCM) .

  4. CHECK CVT SYSTEM. 
    1. Start the engine.
    2. Using the Subaru Select Monitor, read DTC of CVT system. Refer to TRANSMISSION (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC of CVT system displayed?

    Yes:  Perform the diagnosis according to DTC. Refer to TRANSMISSION (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Go to  5.

  5. CHECK ECM SPECIFICATION. 

    Check the ECM specification.

    Is the specification of ECM same as vehicle specification?

    Yes:  Go to  6.

    No:  Replace the ECM. Refer to FUEL INJECTION (FUEL SYSTEMS) (H4DO (EXCEPT FOR HEV))>ENGINE CONTROL MODULE (ECM) .

  6. CHECK ENGINE SYSTEM. 
    1. Start the engine.
    2. Read the DTC of engine system using the Subaru Select Monitor. Refer to ENGINE (DIAGNOSTICS) (H4DO (EXCEPT FOR HEV))>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is engine system DTC displayed?

    Yes:  Perform the diagnosis according to DTC. Refer to ENGINE (DIAGNOSTICS) (H4DO (EXCEPT FOR HEV))>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Go to  7.

  7. CHECK VDC CONTOL MODULE & H/U. 
    1. Using the Subaru Select Monitor, perform the clear memory. Refer to COMMON (DIAG)>CLEAR MEMORY .
    2. Execute the inspection mode. Refer to BRAKE CONTROL (DIAGNOSTICS)>INSPECTION MODE .
    3. Read the DTC using Subaru Select Monitor. Refer to BRAKE CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is the same DTC displayed?

    YES:  REPLACE THE VDC Contol Module & H/U. REFER TO VEHICLE DYNAMICS CONTROL (VDC)>VDC CONTROL MODULE AND HYDRAULIC CONTROL UNIT (VDCCM & H/U) .

    No:  Go to  8.

  8. CHECK DETECTION OF OTHER DTCS FOR VDC. 

    Read the DTC using Subaru Select Monitor. Refer to BRAKE CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is any other DTC displayed?

    Yes:  Perform the diagnosis according to DTC. Refer to BRAKE CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Currently, it is normal. There may have been a temporary poor contact in the harness and connector or a temporary noise interference.
