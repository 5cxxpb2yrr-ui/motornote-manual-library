DTC C2541: Vehicle Dynamics Control Module Vehicle Speed Sensor

Do you like it dark? Easier on the eyes.

DTC detecting condition: 

When VDCCM reception failure (related to vehicle speed sensor) is detected after the ignition switch is ON.

Trouble symptom: 

The steering wheel operation feels heavy.

CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to POWER STEERING (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK DTC. 

    Read the DTC of [Brake Control] using the Subaru Select Monitor. Refer to BRAKE CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) . Refer to BRAKE CONTROL (DIAGNOSTICS) (HEV)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is a DTC related to VDC system or vehicle speed signal system displayed?

    Yes:  Perform the diagnosis according to the DTC. Refer to BRAKE CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST . Refer to BRAKE CONTROL (DIAGNOSTICS) (HEV)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Go to  2.

  2. CHECK LAN SYSTEM. 

    Perform the diagnosis for LAN system using the Subaru Select Monitor. Refer to LAN SYSTEM (DIAGNOSTICS) (EXCEPT FOR HEV)>BASIC DIAGNOSTIC PROCEDURE . Refer to LAN SYSTEM (DIAGNOSTICS) (HEV)>BASIC DIAGNOSTIC PROCEDURE .

    Is DTC of CAN communication displayed?

    Yes:  Perform the diagnosis according to the DTC. Refer to LAN SYSTEM (DIAGNOSTICS) (EXCEPT FOR HEV)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST . Refer to LAN SYSTEM (DIAGNOSTICS) (HEV)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Go to  3.

  3. CHECK VEHICLE SPEED SIGNAL. 
    1. Using the Subaru Select Monitor, display the data monitor [Vehicle Speed] of [Power Steering]. Refer to POWER STEERING (DIAGNOSTICS)>DATA MONITOR .
    2. Lift up the vehicle (so that the wheels turn freely), start the engine, and raise engine speed in gear.
      CAUTION: Be careful that no one is near the spinning tires and nothing gets caught in them.
    3. Check for whether the data changes according to vehicle speed.

    Is the data in sync with the vehicle speed?

    Yes:  It is possible that temporary poor communication occurs. Clear the memory. Refer to COMMON (DIAG)>CLEAR MEMORY .

    No:  Replace the steering gearbox. Refer to POWER ASSISTED SYSTEM (POWER STEERING)>ELECTRIC POWER STEERING GEARBOX .
