Diagnostic Method

When there is no camshaft position sensor signal input in TDC for 10time(s), judge as NG.

JUDGMENT VALUE SPECIFICATION

Malfunction Criteria Threshold Value
Number of exhaust camshaft position sensor pulse during 0.5 crankshaft rev. Equal to 0

Time needed for diagnosis:  Engine speed: 4 engine revs.

Malfunction indicator light illumination:  Illuminates as soon as a malfunction occurs.
