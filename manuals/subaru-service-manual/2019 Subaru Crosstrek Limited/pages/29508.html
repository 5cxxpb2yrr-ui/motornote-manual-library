X MODE Switch: Installation

WARNING: This page is about a different variant/trim than selected.
  1. Install the X mode switch.
  2. Install the cover assembly - front.

    Refer to EXTERIOR/INTERIOR TRIM>INSTRUMENT PANEL ASSEMBLY>INSTALLATION .

  3. Shift the select lever to "P range".
  4. Connect the battery ground terminal.

    Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
