Section 3 (HVAC System (Heater, Ventilator And A/C) (HEV)): Compressor: Installation

Do you like it dark? Easier on the eyes.

WARNING: This page is about a different variant/trim than selected.
WARNING: The hybrid system includes a high voltage circuit. Mishandling could cause accidents such as electric shock or leak. Always check "WARNING (HYBRID SYSTEM)" and perform the proper operation. Refer to PRECAUTION/WARNING>WARNING (HYBRID SYSTEM) .
CAUTION:
  • After replacing the electric compressor assembly, adjust the amount of compressor oil. Refer to AIR CONDITIONER (HEV)>COMPRESSOR OIL>ADJUSTMENT .
  • Replace the O-rings with new parts, and then apply compressor oil to install completely.
  1. Install the compressor bracket.

    Tightening torque: 

    26.5N.m (2.7 kgf-m, 19.5 ft-lb)

  2. Install the electric compressor assembly.
    WARNING: Be sure to wear insulated gloves.
    CAUTION: Make sure the electrical connector is connected securely.

    Tightening torque: 

    36 N.m (3.7 kgf-m, 26.6 ft-lb)

    NOTE: Tighten the electric compressor assembly bolts in the numerical order as shown in the figure. Refer to AIR CONDITIONER (HEV)>GENERAL DESCRIPTION>COMPONENT>COMPRESSOR .
  3. Install the hose - pressure suction and the hose - pressure discharge.

    Tightening torque: 

    10 N.m (1 kgf-m, 704 ft-lb)

  4. Install the inverter tank. Refer to COOLING (H4DO (HEV))>INVERTER TANK>INSTALLATION .
  5. Install the inverter radiator outlet hose and inverter tank outlet hose onto the clamps.
  6. Install the under cover - front. Refer to EXTERIOR/INTERIOR TRIM>FRONT UNDER COVER>INSTALLATION .
  7. Install the bracket - hood stay.

    Tightening torque: 

    18 N.m (1.8 kgf-m, 13.3 ft-lb)

  8. Install the cover UPR - front.
  9. Install the air intake duct.
  10. Install the service disconnect plug. Refer to HYBRID ELECTRIC VEHICLE>SERVICE PLUG>INSTALLATION .
  11. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
  12. Install the collector cover. Refer to INTAKE (INDUCTION) (H4DO (EXCEPT FOR HEV))>COLLECTOR COVER>INSTALLATION .
  13. Charge refrigerant. Refer to AIR CONDITIONER (HEV)>REFRIGERANT CHARGING PROCEDURE>PROCEDURE .
  14. After replacing the electric compressor assembly with a new part, follow the procedure below to perform break-in operation.
  1. Make sure that the outdoor air temperature is equal to or higher than 0°C (32°F).
  2. Check that all connectors are locked securely.
  3. Reset the heater control assembly. (Disconnect and then connect the connector)
  4. Attach a delivery (test) mode fuse to the main fuse box.
  5. Using the Subaru Select Monitor, perform the break-in operation.
    NOTE: For detailed operation procedures, refer to "Help" of application.
    1. Connect the Subaru Select Monitor.
    2. On [Start] screen, select [Diagnosis].
    3. On [Select Vehicle] screen, enter vehicle information and select [OK].
    4. On [Main Menu] screen, select [Each System].
    5. On [Select System] screen, select [Air Conditioner], and then select [Next].
    6. On [Select Function] screen, select [Work Support].
    7. From the list of work support items, select [Electric compressor break-in operation] mode and then follow the procedure to perform and check preparation work, then select [Execution].
    8. When preparation work is completed, select [Execution].
    9. When [Electric compressor break-in operation completed status] is [incomplete] → [ON], turn READY OFF.
  6. Remove the delivery (test) mode fuse from the main fuse box.
  7. The break-in operation finishes.
