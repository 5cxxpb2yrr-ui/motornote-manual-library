EGR Pipe: Installation

  1. Use a new gasket and install the EGR pipe to the intake manifold assembly and EGR control valve.

    Tightening torque: 

    6.4 N.m (0.7 kgf-m, 4.7 ft-lb)

  2. Install the throttle body. Refer to FUEL INJECTION (FUEL SYSTEMS) (H4DO (EXCEPT FOR HEV))>THROTTLE BODY>INSTALLATION .
  3. Install the air intake boot. Refer to INTAKE (INDUCTION) (H4DO (EXCEPT FOR HEV))>Air Intake Boot>INSTALLATION .
