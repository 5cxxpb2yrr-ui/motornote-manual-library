RAB Operation Record Data Save When ignition switch ON counts of "Latest", "1 block before", "2 blocks before"... "4 blocks before" all shows "0", it can be judged that there is no data. The display shows the latest data and the data in the previous 4 times in the order of their occurrence. Blue letter means that the data exists, and black letter means that there is no data. Select the blue letters and read out the details.
