Basic Diagnostic Procedure: Procedure

Do you like it dark? Easier on the eyes.

CAUTION:
  • Subaru Select Monitor is required for reading DTC, performing diagnosis and reading data monitor.
  • Remove foreign matter (dust, water, oil, etc.) from the body integrated unit connector during removal and installation.
  • Registration of immobilizer may be needed after the replacement of control modules, etc. For detailed procedure, refer to the "REGISTRATION INSTRUCTIONS FOR IMMOBILIZER" provided as a separate volume.
NOTE: To check harness for open or short circuits, shake the suspected trouble spot or connector.
  1. PERFORM CUSTOMER INTERVIEW. 

    Ask the customer when and how the trouble occurred using the interview check list. Refer to BODY CONTROL (DIAGNOSTICS)>CHECK LIST FOR INTERVIEW .

    Did you interview the customer?

    Yes:  Go to  2.

    No:  Perform the interview, and Go to  2.

  2. BASIC INSPECTION. 

    Perform basic inspection. Refer to BODY CONTROL (DIAGNOSTICS)>GENERAL DESCRIPTION>INSPECTION .

    Is the check result OK?

    Yes:  Go to  3.

    No:  Repair the faulty part found in basic inspection, and Go to  3.

  3. CHECK SUBARU SELECT MONITOR COMMUNICATION. 
    1. Turn the ignition switch to OFF.
    2. Connect the Subaru Select Monitor to data link connector. Refer to COMMON (DIAG)>DATA LINK CONNECTOR .
    3. Turn the ignition switch to ON and run the Subaru Select Monitor.
    4. Select [Body Control].
      NOTE: For detailed operation procedures, refer to "Help" of application.

    Is communication possible?

    Yes:  Go to  4.

    No:  Check the communication circuit. Refer to BODY CONTROL (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE FOR SUBARU SELECT MONITOR COMMUNICATION .

  4. CHECK DTC. 

    Read the DTC of [Body Control] using the Subaru Select Monitor. Refer to BODY CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed? (Current malfunction)

    Yes:  Record the DTC, time stamp and freeze frame data, and Go to  5.

    No:  Go to  6.

  5. PERFORM DIAGNOSIS. 
    1. Perform the diagnosis for the displayed DTCs. Refer to BODY CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .
    2. Repair or replace the cause of trouble.
    3. Using the Subaru Select Monitor, perform the clear memory of [Body Control]. Refer to COMMON (DIAG)>CLEAR MEMORY .
    4. Execute the inspection mode. Refer to BODY CONTROL (DIAGNOSTICS)>INSPECTION MODE .
    5. Read the DTC of [Body Control] using the Subaru Select Monitor. Refer to BODY CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed? (Current malfunction)

    Yes:  Repeat step  5 until DTC is not shown.

    No:  Finish the diagnosis.

  6. PERFORM DIAGNOSTICS WITH PHENOMENON. 

    Check the "Phenomenon List". Refer to BODY CONTROL (DIAGNOSTICS)>DIAGNOSTICS WITH PHENOMENON>LIST>HIGH BEAM ASSIST SYSTEM .

    Is there a symptom that corresponds in the phenomenon list?

    Yes:  Perform diagnosis according to the procedures in the phenomenon list.

    No:  Go to  7.

  7. PERFORM GENERAL DIAGNOSTICS. 

    Check "General Diagnostic Table". Refer to BODY CONTROL (DIAGNOSTICS)>GENERAL DIAGNOSTIC TABLE .

    Is the check result OK?

    Yes:  The body control system is normal.

    No:  Perform inspection using "General Diagnostic Table".
