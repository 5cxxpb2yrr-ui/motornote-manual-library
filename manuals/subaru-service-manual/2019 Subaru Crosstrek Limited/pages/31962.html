6MT Model

  1. Install the gear shift lever assembly.

    Tightening torque:

    18 N.m (1.8 kgf-m, 13.3 ft-lb)

    Courtesy of SUBARU OF AMERICA, INC.
  2. Install the harness clamp.
  3. Lift up the vehicle.
  4. Install the cable cover assembly.

    Tightening torque:

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  5. Connect the MT gear shift cable and MT gear select cable.
    CAUTION:
    • Be careful not to deform the cable inner.
    • Do not twist the cable inner excessively.
    • Do not apply excessive load while holding the part (a).
    Courtesy of SUBARU OF AMERICA, INC.
    Courtesy of SUBARU OF AMERICA, INC.
  6. Attach the cable cover plate.

    Tightening torque:

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  7. Install the center exhaust cover.

    Tightening torque:

    18 N.m (1.8 kgf-m, 13.3 ft-lb)

  8. Install the front exhaust pipe. Refer to EXHAUST (H4DO (EXCEPT FOR HEV))>FRONT EXHAUST PIPE>INSTALLATION .
  9. Lower the vehicle.
  10. Install the panel center LWR LH and RH. Refer to EXTERIOR/INTERIOR TRIM>CONSOLE BOX>INSTALLATION .
  11. Install the front console panel and install the gear shift knob. Refer to EXTERIOR/INTERIOR TRIM>CONSOLE BOX>INSTALLATION .
  12. Make sure the gears can be shifted accurately into each gear. Adjust the MT gear select lever, if the gears cannot be shifted correctly. Refer to CONTROL SYSTEMS>MT GEAR SELECT CABLE>ADJUSTMENT .
  13. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
