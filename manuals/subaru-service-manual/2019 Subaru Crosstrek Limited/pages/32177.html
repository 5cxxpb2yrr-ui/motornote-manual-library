Seat Belt - CTR LH (4 Door Model)

  1. Install the seat belt - CTR LH.

    Tightening torque:

    30 N.m (3.1 kgf-m, 22.1 ft-lb)

  2. Install the rear seat cushion assembly.
  3. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
  4. After installation, check the following points.
    • The seat belt is not twisted.
    • The seat belt engagement can be performed smoothly.
