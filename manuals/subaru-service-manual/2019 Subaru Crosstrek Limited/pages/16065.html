Service Mode

WARNING: This page is about a different variant/trim than selected.
NOTE: If it is necessary to run the engine for 10 minutes or more, fasten the driver's seat belt.
  1. On [Start] screen, select [Diagnosis].
  2. On [Vehicle selection] screen, enter vehicle information and select [OK].
  3. On [Main Menu] screen, select [Each System].
  4. On [Select System] screen, select [P-HEV Hybrid Powertrain Control].
  5. On [Select Function] screen, select [Work Support].
  6. On [Work Support] screen, select [Inspection Mode for cutting TCS] or [Inspection Mode for measuring Exhaust Gas].
Item name Explanation for items Control items
Inspection Mode for measuring Exhaust Gas Used when the following inspections are performed:
  • Engine adjustment such as ignition timing inspection, idling inspection at vehicle inspection, CO/HC inspection, and so on
  • Testing using a speedmeter tester, two-wheels chassis dynamometer, and so on
  • Engine forced idling (shift position in P)
  • Operation deactivation of TRC device
NOTE:
  • With the shift position in P, idling speed in the service mode (2WD (for exhaust gas measurement)) is approximately 1000 r/min.
  • Only with the shift position in P, racing is performed at approximately 1500 r/min with the accelerator pedal depressed up to the medium opening angle, and at approximately 2000 r/min with the accelerator pedal depressed from the medium to full open angle.
  • When DTC is stored during the service mode (2WD (for exhaust gas measurement)), Hybrid Fail Lamp illuminates.
  • When Hybrid Fail Lamp remains illuminated during operations in the service mode (2WD (for exhaust gas measurement)), stop the service mode (2WD (for exhaust gas measurement)) and check DTC.
Inspection Mode for cutting TCS Used when the following inspections are performed:
  • Testing using a speedmeter tester, two-wheels chassis dynamometer, and so on
 Operation deactivation of TRC device
NOTE:
  • When DTC is stored during the authentication mode (2WD (for TRC prohibition)), Hybrid Fail Lamp illuminates.
  • When Hybrid Fail Lamp remains illuminated during operations in the authentication mode (2WD (for TRC prohibition)), stop the authentication mode (2WD (for TRC prohibition)) and check DTC.
NOTE: For the service mode, mode transition is also possible by performing the following operation.
  • Inspection Mode for measuring Exhaust Gas
    1. Fix the wheels with stoppers.
    2. Release the parking brake. From here on, be sure to depress the brake pedal to prevent the vehicle from moving.
    3. Turn to IG ON, and perform the following operation within 60 seconds. (An accelerator pedal operation from fully released to fully depressed is considered as one operation.)
      1. While depressing the brake pedal, fully depress the accelerator pedal twice with the shift position in P.
      2. While depressing the brake pedal, fully depress the accelerator pedal twice with the shift position in N.
      3. While depressing the brake pedal, fully depress the accelerator pedal twice with the shift position in P.
    4. The mode is switched to the service mode, the service mode shift screen is displayed in the combination meter, and the VDC OFF indicator light illuminates.
    5. Depress the brake pedal and turn to READY ON.
    6. READY indicator light illuminates and the engine starts continuous running operation.
    7. With the ignition turned to IG OFF, the service mode ends.
  • Inspection Mode for cutting TCS
    1. Fix the wheels with stoppers.
    2. Release the parking brake. From here on, be sure to depress the brake pedal to prevent the vehicle from moving.
    3. Turn to IG ON, and perform the following operation within 60 seconds. (An accelerator pedal operation from fully released to fully depressed is considered as one operation.)
      1. While depressing the brake pedal, fully depress the accelerator pedal three times with the shift position in P.
      2. While depressing the brake pedal, move the shift lever to N position, and fully depress the accelerator pedal three times.
      3. While depressing the brake pedal, move the shift lever to P position, and fully depress the accelerator pedal three times.
    4. The mode is switched to the service mode, the service mode shift screen is displayed in the combination meter, and the VDC OFF indicator light illuminates.
    5. Depress the brake pedal and turn to READY ON.
    6. Check that the READY indicator light illuminates.
    7. With the ignition turned to IG OFF, the service mode ends.
