WARNING: When performing inspection mode B on a public road, pay sufficient attention to the traffic condition and give the highest priority to safe driving.
NOTE: Perform the inspection mode after warming up the engine except that the engine coolant temperature at engine start is specified.
  1. Check that the battery voltage is 12 V or more and fuel remains approx. half [20 - 40 L (5.3 - 10.6 US gal, 4.4 - 8.8 Imp gal)].
  2. Using the Subaru Select Monitor, clear the memory of [Engine Control System]. Refer to COMMON (DIAG)>CLEAR MEMORY .
  3. Drive at 10 km/h (6 MPH) or more.
  4. Stop the vehicle and idle for ten minutes.
  5. Read the readiness code of [Engine Control System] using Subaru Select Monitor and check that the concerned self-diagnosis is completed. Refer to ENGINE (DIAGNOSTICS (H4DO (HEV))>ALL READINESS DIAGNOSTIC CODE(S) .
  6. Read the DTC of [Engine Control System] using the Subaru Select Monitor. Refer to ENGINE (DIAGNOSTICS) (H4DO (HEV))>DIAGNOSTIC TROUBLE CODE (DTC) .
  7. Read the temporary code using the Subaru Select Monitor or general scan tool. Refer to COMMON (DIAG)>DIAGNOSTIC TROUBLE CODE (DTC) .
