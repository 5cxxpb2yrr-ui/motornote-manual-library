Brake Stroke Sensor

  1. Install the brake stroke sensor.

    Tightening torque: 

    8 N.m (0.8 kgf-m, 5.9 ft-lb)

  2. Install the hybrid powertrain control module. Refer to HYBRID ELECTRIC VEHICLE>HYBRID POWERTRAIN CONTROL MODULE>INSTALLATION .
  3. Install the duct - foot driver. Refer to AIR CONDITIONER (HEV)>HEATER DUCT>INSTALLATION .
  4. Install the knee airbag module.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  5. Install the cover assembly - instrument panel LWR driver.
  6. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY>GROUND TERMINAL REMOVAL OR INSTALLATION .
  7. Erase the backup memory. Refer to BRAKE>BRAKE SYSTEM>OPERATION>BACK-UP MEMORY CLEARING .
  8. Perform linear valve offset learning. Refer to BRAKE>BRAKE SYSTEM>OPERATION>LINEAR VALVE OFFSET LEARNING .
