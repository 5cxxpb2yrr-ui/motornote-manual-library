DTC C1A0C: Brake Fluid Pressure Sensor 1 Zero Position: Notes

1. - 

DTC detecting condition: 

When the brake pedal is not operated, the output value of the reaction pressure sensor is -0.63 MPa or less or 1.53 MPa or more and this condition continues for 3 seconds or more.

Trouble symptom: 

  • Brake cannot be controlled.
  • Regenerative brake cannot be controlled.
  • Brake assist does not operate.
  • EyeSight functions (ACC/PCS) do not operate.
  1. CHECK DTC. 
    1. Using the Subaru Select Monitor, perform the clear memory. Ref. to COMMON (DIAG)>CLEAR MEMORY .
    2. Read the DTC using Subaru Select Monitor. Ref. to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is the DTC C1A0C only displayed?

    Yes:  Go to  2.

    No:  Perform the diagnosis according to DTC. Ref. to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

  2. CHECK BRAKE PEDAL. 

    Check the brake pedal and brake stroke sensor. Ref. to BRAKE>BRAKE PEDAL .

    Is the check result OK?

    Yes:  Go to  3.

    No:  Adjust the brake pedal and brake stroke sensor, and properly install the sensor. Go to  3.

  3. CHECK DATA MONITOR. 
    1. Using Subaru Select Monitor, display [Reaction Pressure] in [Data monitor]. Ref. to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>DATA MONITOR .
    2. Check [Reaction Pressure] without operating the brake pedal.

    Does [Reaction Pressure] value fall within 0.00 - 1.53 MPa range?

    Yes:  Go to  4.

    No:  Replace the brake booster assembly (with the master cylinder). Ref. to BRAKE>BRAKE BOOSTER .

  4. RECHECK DTC. 
    1. Using the Subaru Select Monitor, perform the clear memory. Ref. to COMMON (DIAG)>CLEAR MEMORY .
    2. Read the DTC using Subaru Select Monitor. Ref. to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC C1A0C displayed?

    Yes:  Replace the brake booster assembly (with the master cylinder). Ref. to BRAKE>BRAKE BOOSTER .

    No:  Currently, it is normal. Temporary interference from noise is a possible cause.
