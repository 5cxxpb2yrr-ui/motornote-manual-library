Check Cruise Indicator Light And Cruise Set Indicator Light

Trouble Symptom: 

Cruise control can be set, but the CRUISE indicator and SET indicator do not illuminate.

CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to CRUISE CONTROL (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK CRUISE INDICATOR LIGHT AND CRUISE SET INDICATOR LIGHT. 

    Using the Subaru Select Monitor, perform [Active Test] of [Combination Meter]. Refer to COMBINATION METER (DIAGNOSTICS)>ACTIVE TEST .

    • CRUISE indicator
    • SET indicator

    Do the CRUISE & SET indicators illuminate?

    Yes:  Go to  2.

    No:  Replace the combination meter. Refer to INSTRUMENTATION/DRIVER INFO>COMBINATION METER .

  2. CHECK LAN SYSTEM. 

    Perform the diagnosis for LAN system. Refer to LAN SYSTEM (DIAGNOSTICS) (EXCEPT FOR HEV)>BASIC DIAGNOSTIC PROCEDURE .

    Is LAN system OK?

    Yes:  Perform the inspection according to the diagnosis for LAN system.

    No:  Replace the ECM. Refer to FUEL INJECTION (FUEL SYSTEMS) (H4DO (EXCEPT FOR HEV))>ENGINE CONTROL MODULE (ECM) .
