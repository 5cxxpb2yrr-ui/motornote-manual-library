HFC-134A A/C System

Do you like it dark? Easier on the eyes.

WARNING: This page is about a different variant/trim than selected.
  • Because the A/C system of this vehicle is a special HFC-134a system, do not use any refrigerant other than HFC-134a.
  • Before maintenance, check the A/C system identification using label (a) which is attached to the vehicle.
