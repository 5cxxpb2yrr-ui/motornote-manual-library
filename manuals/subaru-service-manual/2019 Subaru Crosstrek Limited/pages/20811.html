Except For Hybrid Model

Wiring diagram: 

Reverse Automatic Braking Refer to WIRING SYSTEM (IMPREZA MODEL)>REVERSE AUTOMATIC BRAKING>WIRING DIAGRAM . Refer to WIRING SYSTEM (CROSSTREK MODEL (EXCEPT FOR HEV))>REVERSE AUTOMATIC BRAKING>WIRING DIAGRAM .

Courtesy of SUBARU OF AMERICA, INC.
  1. CHECK OTHER INDICATOR. 

    Turn the ignition switch to ON.

    Do other indicators illuminate?

    Yes:  Go to  2.

    No:  Check the combination meter. Refer to COMBINATION METER (DIAGNOSTICS)>BASIC DIAGNOSTIC PROCEDURE .

  2. ACTIVE TEST FOR THE COMBINATION METER. 

    Using the Subaru Select Monitor, perform [Active Test] of [Combination Meter]. Refer to COMBINATION METER (DIAGNOSTICS)>ACTIVE TEST .

    • All lamps lighted

    Does the indicator illuminate?

    Yes:  Go to  3.

    No:  Replace the combination meter. Refer to INSTRUMENTATION/DRIVER INFO>COMBINATION METER .

  3. CHECK DTC. 

    Read the DTC of [Reverse Automatic Braking] using the Subaru Select Monitor. Refer to REVERSE AUTOMATIC BRAKING (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed? (Current malfunction)

    Yes:  Perform the diagnosis for the displayed DTCs.

    No:  Go to  4.

  4. CHECK LAN SYSTEM. 

    Perform the diagnosis for LAN system. Refer to LAN SYSTEM (DIAGNOSTICS) (EXCEPT FOR HEV)>BASIC DIAGNOSTIC PROCEDURE>PROCEDURE .

    Is the check result OK?

    Yes:  Replace the RAB control module. Refer to REVERSE AUTOMATIC BRAKING>REVERSE AUTOMATIC BRAKING control module .

    No:  Perform the inspection according to the diagnosis for LAN system.
