Inspection Mode F

DTC Item Condition
P0705 TRANSMISSION RANGE SENSOR "A" CIRCUIT (PRNDL INPUT) -

Diagnostic procedure: 

  1. Start the engine.
  2. Check the readiness code using Subaru Select Monitor and confirm that the diagnosis is not completed. Refer to TRANSMISSION (DIAGNOSTICS)>ALL READINESS DIAGNOSTIC CODE(S) .
  3. Depress the brake pedal and move the select lever to each range at an interval of five seconds.
    NOTE: Move the select lever in the following order: "P" → "R" → "N" → "D".
  4. Maintain the engine speed to 2, 000 rpm for five seconds or more.
  5. Check the readiness code using Subaru Select Monitor, confirm that the diagnosis is completed, and end the procedure.
