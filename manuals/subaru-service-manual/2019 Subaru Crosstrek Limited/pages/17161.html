Engine Coolant Temperature Sensor: Installation

Do you like it dark? Easier on the eyes.

  1. Set a new gasket, install the engine coolant temperature sensor using the ST.
    NOTE: STRUT MOUNT SOCKET (20099 Pa000) can also be used.

    Preparation tool: 

    ST: STRUT MOUNT SOCKET (20399AG000)

    Tightening torque: 

    16 N.m (1.6 kgf-m, 11.8 ft-lb)

  2. Connect the connector to engine coolant temperature sensor.
  3. Install the air intake boot. Refer to INTAKE (INDUCTION) (H4DO (EXCEPT FOR HEV))>Air Intake Boot>INSTALLATION .
  4. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
  5. Fill engine coolant. Refer to COOLING (H4DO (EXCEPT FOR HEV))>ENGINE COOLANT>REPLACEMENT>FILLING OF ENGINE COOLANT .
