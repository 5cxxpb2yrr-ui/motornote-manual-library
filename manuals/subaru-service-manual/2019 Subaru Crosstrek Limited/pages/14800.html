Passenger's Airbag ON/OFF Indicator

Detecting condition: 

  • Passenger's airbag ON/OFF indicator malfunction
  • Airbag control module to combination meter circuit is shorted or open.
  • Grounding circuit is faulty.
  • Connector connection is improper.
  • Airbag control module is faulty.
  • Occupant detection control module is faulty.
CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to OCCUPANT DETECTION (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK DTC. 

    Read the DTC of [Airbag] using the Subaru Select Monitor. Refer to AIRBAG (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC B1661 displayed? (Current malfunction)

    Yes:  Perform the diagnosis of DTC B1661. Refer to AIRBAG (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC B1661 PASSENGER'S AIRBAG ON/OFF INDICATOR FAILURE .

    No:  Go to  2.

  2. CHECK WARNING BOX. 

    Check for poor contact of the warning box connector.

    Is there poor contact of connector?

    Yes:  Repair or replace the poor contact.

    No:  Go to  3.

  3. CHECK DTC. 

    Read the DTC of [Airbag] using the Subaru Select Monitor. Refer to AIRBAG (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is any DTC other than DTC B1661 displayed?

    Yes:  Perform the diagnosis for the displayed DTCs. Refer to AIRBAG (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Go to  4.

  4. REZERO. 

    Perform [Rezero]. Refer to OCCUPANT DETECTION (DIAGNOSTICS)>REZERO .

    Does the passenger's airbag indicator illuminate?

    Yes:  Finish the diagnosis.

    No:  Replace the cushion frame assembly. Refer to SEATS>FRONT SEAT>DISASSEMBLY .
