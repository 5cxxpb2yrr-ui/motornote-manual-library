Malfunction Indicator Light Does Not Go Off

Diagnosis: 

The malfunction indicator light circuit is shorted.

Trouble symptom: 

Although malfunction indicator light comes on when the engine runs, DTC is not shown on the Subaru Select Monitor or general scan tool display.

  1. CHECK DTC  .

    Read the DTC of engine or LAN system using the Subaru Select Monitor or a general scan tool. Refer to COMMON (DIAG)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC of engine or LAN system displayed?

    Yes:  Check the appropriate DTC using the "Diagnostic Trouble Code (DTC)". Refer to ENGINE (DIAGNOSTICS) (H4DO (EXCEPT FOR HEV))>DIAGNOSTIC TROUBLE CODE (DTC)>LIST . Refer to LAN SYSTEM (DIAGNOSTICS) (EXCEPT FOR HEV)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Check the combination meter system. Refer to COMBINATION METER (DIAGNOSTICS)>BASIC DIAGNOSTIC PROCEDURE .
