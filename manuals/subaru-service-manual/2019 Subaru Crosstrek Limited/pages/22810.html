Inspection Mode 3

DTC Item Note
B1571 REFERENCE CODE INCOMPATIBILITY (IMMOBILIZER control module TO ECM) -
B1572 IMM CIRCUIT EXCEPT ANTENNA CIRCUIT -
B1576 ECM EEPROM -
B1577 IMMOBILIZER control module EEPROM -
B1578 METER -

Diagnostic procedure:

  1. Using the Subaru Select Monitor, perform the clear memory of [Engine Control System]. Refer to COMMON (DIAG)>CLEAR MEMORY .
  2. Using the Subaru Select Monitor, read the DTC of [Engine Control System] to check that there is no DTC displayed. Refer to IMMOBILIZER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
    NOTE: If the DTC is displayed on the screen, the trouble is still present. Perform the diagnosis for the displayed DTCs. After solving the DTC, repeat from step  1.
  3. Start the engine, and then run the engine at idle for 10 seconds or more. Or, disconnect and reconnect the battery, then turn the ignition switch OFF → ON, and wait for 10 seconds or more.
  4. Using the Subaru Select Monitor, read the DTC of [Engine Control System] to check that there is no DTC displayed. Refer to IMMOBILIZER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
    NOTE: If the DTC is displayed on the screen, the trouble is still present. Perform the diagnosis for the displayed DTCs.
