Back-Up Memory Clearing

Do you like it dark? Easier on the eyes.

  1. Using the Subaru Select Monitor, select [Erase Backup Memory] on the [Work Support] display. Refer to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>WORK SUPPORT .
  2. Follow the instructions on the Subaru Select Monitor screen and erase the backup memory.
