DTC U049C: Invalid Data Received From Battery Charger Control Module

DTC detecting condition: 

CAN data from the electric vehicle charger assembly is abnormal.

Trouble symptom: 

  • The charging end time is not displayed on the energy flow screen.
  • The SOC status is not displayed on the energy flow screen.
  • Setting screen Timer charging setting is not displayed.
  • Setting screen Cable lock mode setting is not displayed.
  • Setting screen Cannot set maximum AC charging current.
  • Switch that recalls the timer charging setting cannot be operated.
  • The next timer charging schedule display is not displayed properly.
NOTE: For the diagnostic procedure, refer to DTC U0074. Refer to MULTI-FUNCTION DISPLAY (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC U0074 CONTROL MODULE COMMUNICATION BUS "BODY-CAN" OFF .
