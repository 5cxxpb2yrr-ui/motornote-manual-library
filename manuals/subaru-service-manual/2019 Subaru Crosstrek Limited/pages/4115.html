DTC B1576-44: Hybrid/EV Powertrain Control Module Data Memory Failure (Immobilizer)

Do you like it dark? Easier on the eyes.

DTC detecting condition: 

  • Defective hybrid vehicle control computer.
  • When the ROM in the hybrid vehicle control computer was inaccessible during registration.

Trouble symptom: 

  • READY ON is not possible.
  • Immobilizer registration is not completed normally.
CAUTION:
  • For replacement procedure of the hybrid vehicle control computer, refer to "REGISTRATION INSTRUCTIONS FOR IMMOBILIZER" provided as a separate volume.
  • Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. PERFORM HYBRID VEHICLE CONTROL COMPUTER REGISTRATION. 

    Perform hybrid vehicle control computer registration. Refer to the "REGISTRATION INSTRUCTIONS FOR IMMOBILIZER" provided as a separate volume.

    Is hybrid vehicle control computer registration complete?

    Yes:  Check that the hybrid system can be started, and end the procedure.

    No:  Go to  2.

  2. PERFORM HYBRID VEHICLE CONTROL COMPUTER REGISTRATION. 

    Perform hybrid vehicle control computer registration. Refer to the "REGISTRATION INSTRUCTIONS FOR IMMOBILIZER" provided as a separate volume.

    Is hybrid vehicle control computer registration complete?

    Yes:  Check that the hybrid system can be started, and end the procedure.

    No:  Go to  3.

  3. PERFORM HYBRID VEHICLE CONTROL COMPUTER REGISTRATION. 

    Perform hybrid vehicle control computer registration. Refer to the "REGISTRATION INSTRUCTIONS FOR IMMOBILIZER" provided as a separate volume.

    Is hybrid vehicle control computer registration complete?

    Yes:  Check that the hybrid system can be started, and end the procedure.

    No:  Replace the hybrid vehicle control computer. Refer to HYBRID ELECTRIC VEHICLE>HYBRID POWERTRAIN CONTROL MODULE . Install the hybrid vehicle control computer from other vehicle to the original vehicle.
