Lever Assembly

Do you like it dark? Easier on the eyes.

  1. Before installation, check the following items.
    • Is the cable deformed?
    • Grease is applied sufficiently to cable joints.

      If grease is insufficient, add it as necessary before assembling the cable.

  2. Install the lever assembly - safety.

    Tightening torque: 

    18 N.m (1.8 kgf-m, 13.3 ft-lb)

  3. Install the cable - safety.
  4. Install the cover UPR - front.
  5. Install the air intake duct.
