Inspection Mode 5

Do you like it dark? Easier on the eyes.

DTC Item Note
B1015 KEY INTERLOCK CIRCUIT CVT Model without the keyless access with push button start system

Diagnostic procedure:

  1. Using the Subaru Select Monitor, perform the clear memory of [Body Control]. Refer to COMMON (DIAG)>CLEAR MEMORY .
  2. Using the Subaru Select Monitor, read the DTC of [Body Control] to check that there is no DTC displayed. Refer to BODY CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
    NOTE: If the DTC is displayed on the screen, the trouble is still present. Perform the diagnosis for the displayed DTCs. After solving the DTC, repeat from step  1. Refer to BODY CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .
  3. Turn the ignition switch to ON, shift the shift lever in other than P range, and wait for 10 seconds or more.
  4. Using the Subaru Select Monitor, read the DTC of [Body Control] to check that there is no DTC displayed. Refer to BODY CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
    NOTE: If the DTC is displayed on the screen, the trouble is still present. Perform the diagnosis for the displayed DTCs. Refer to BODY CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .
