Diagnostic Method

  • Monitor#1 <Timer diagnosis> 

    Start the count up operation of counters in ECM and in soaking timer IC when the engine is started. Judge as timer malfunction if the difference between the counter in ECM and counter in soaking timer IC exceeds the allowable limit when the ignition switch is OFF.

    Courtesy of SUBARU OF AMERICA, INC.

    Judge as NG when the following conditions are established.

    JUDGMENT VALUE SPECIFICATION

    Malfunction Criteria Threshold Value
    |osoaktimcpu - osoaktimic|/osoaktimcpu Exceeds 0.24
    osoaktimcpu = Counter in ECM  
    osoaktimic = Counter in soaking timer IC  
  • Monitor#2<Full count diagnosis> 

    Reset the counter in soaking timer IC and start the count up operation.

    Judge as full count diagnosis malfunction if counter in soaking timer IC is not the specified value after 4 seconds.

    Courtesy of SUBARU OF AMERICA, INC.

    Judge as NG when the following conditions are established.

    JUDGMENT VALUE SPECIFICATION

    Malfunction Criteria Threshold Value
    osoakfcntic osoakfcntic = Counter in soaking timer IC Not equal to 65535 counts
  • Monitor#3<Soak timer IC setting diagnosis> 

    When setting the activation setting time to soaking timer IC, compare the writing value to soaking timer IC with read out value. Judge as malfunction if the values do not match 3 times in a row.

    Courtesy of SUBARU OF AMERICA, INC.

    Judge as NG when the following conditions are established.

    JUDGMENT VALUE SPECIFICATION

    Malfunction Criteria Threshold Value
    Writing value and read out value when setting the soaking timer Unmatch
  • Monitor#4<Timer diagnosis (during soaking)> 

    Wake-up at the predetermined interval until 5, 7 or 9.5 hours have passed after the ignition switch is OFF, and compare the counter in soaking timer IC with the counter in ECM.

    Judge as malfunction if the counter in soaking timer IC is counted up to maximum value when the counter in ECM is 1636 ms, or if the counter in soaking timer IC is not counted up to maximum value when the counter in ECM is 2456 ms.

    Courtesy of SUBARU OF AMERICA, INC.

    Judge as NG when the following conditions are established.

    JUDGMENT VALUE SPECIFICATION

    Malfunction Criteria Threshold Value
    When any one of the followings is established:
    • All of the following conditions are established.

    Counter in ECM    		 1636 ms or less
    Counter in soaking timer IC Equal to 65535 counts
    • All of the following conditions are established.
    		  
    Counter in ECM 2456 ms or more
    Counter in soaking timer IC Not equal to 65535 counts
  • Monitor#5 <Wake-up diagnosis> 

    Store the number of wake-up activation when the ECM wakes up by the soaking timer IC. Next time when the ignition switch is ON, if the number of wake-up activation does not reach the predetermined value even though the counter in soaking timer IC operates 1 hour or more, judge as wake-up malfunction.

    Courtesy of SUBARU OF AMERICA, INC.

    Judge as NG when the following conditions are established.

    JUDGMENT VALUE SPECIFICATION

    Malfunction Criteria Threshold Value
    Number of wake-up Not equal to wake-up indication count

    Time needed for diagnosis: 

    Monitor#1: 0.128 s

    Monitor#2: 0.128 s

    Monitor#3: 0.128 s

    Monitor#4: Less than 1 s

    Monitor#5: Less than 1 s

    Malfunction indicator light illumination:  Illuminates when malfunction occurs in 2 continuous driving cycles.
