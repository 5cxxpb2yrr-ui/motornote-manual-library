Basic Diagnostic Procedure: Procedure

WARNING: This page is about a different variant/trim than selected.
NOTE: When the sunload sensor check is performed indoors or in the shade, it could be diagnosed as sensor having an open circuit. Always perform the inspection in direct sunlight.
  1. PERFORM CUSTOMER INTERVIEW. 

    Ask the customer when and how the trouble occurred using the interview check list. Refer to AIR CONDITIONER (DIAGNOSTICS) (HEV)>CHECK LIST FOR INTERVIEW .

    Did you interview the customer?

    Yes:  Go to  2.

    No:  Perform the interview, and Go to  2.

  2. PERFORM BASIC INSPECTION. 

    Perform basic inspection. Refer to AIR CONDITIONER (DIAGNOSTICS) (HEV)>GENERAL DESCRIPTION>INSPECTION .

    Is the check result OK?

    Yes:  Go to  3.

    No:  Repair the faulty part found in basic inspection, and Go to  3.

  3. CHECK SUBARU SELECT MONITOR COMMUNICATION. 
    1. Turn the ignition switch to OFF.
    2. Connect the Subaru Select Monitor to data link connector. Refer to COMMON (DIAG)>DATA LINK CONNECTOR .
    3. Turn the ignition switch to ON and run the Subaru Select Monitor.
    4. Select [Air Conditioner].
      NOTE: For detailed operation procedures, refer to "Help" of application.

    Is communication possible?

    Yes:  Go to  4.

    No:  Check the communication circuit. Refer to AIR CONDITIONER (DIAGNOSTICS) (HEV)>DIAGNOSTIC PROCEDURE FOR SUBARU SELECT MONITOR COMMUNICATION .

  4. CHECK DTC. 

    Read the DTC of [Air Conditioner] using the Subaru Select Monitor. Refer to AIR CONDITIONER (DIAGNOSTICS) (HEV)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed? (Current malfunction)

    Yes:  Record the DTC, time stamp and freeze frame data, and Go to  5.

    No:  Perform diagnosis according to the procedures in the diagnostics with phenomenon. Refer to AIR CONDITIONER (DIAGNOSTICS) (HEV)>DIAGNOSTICS WITH PHENOMENON .

  5. PERFORM DIAGNOSIS. 
    1. Perform the diagnosis for the displayed DTCs. Refer to AIR CONDITIONER (DIAGNOSTICS) (HEV)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .
    2. Repair or replace the cause of trouble.
    3. Using the Subaru Select Monitor, perform the clear memory of [Air Conditioner]. Refer to COMMON (DIAG)>CLEAR MEMORY .
    4. Execute the inspection mode. Refer to AIR CONDITIONER (DIAGNOSTICS) (HEV)>INSPECTION MODE .
    5. Read the DTC of [Air Conditioner] using the Subaru Select Monitor. Refer to AIR CONDITIONER (DIAGNOSTICS) (HEV)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed? (Current malfunction)

    Yes:  Repeat step  5 until DTC is not shown. Go to  5.

    No:  Finish the diagnosis.
