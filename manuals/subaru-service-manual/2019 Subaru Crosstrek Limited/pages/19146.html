Cooling Pipe

Do you like it dark? Easier on the eyes.

WARNING: This page is about a different variant/trim than selected.
CAUTION: Replace the O-rings with new parts, and then apply compressor oil to install completely.
  1. Install the pipe - evaporator cooling.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  2. Install the inverter front water pipe.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  3. Install the radiator assembly. Refer to COOLING (H4DO (HEV))>RADIATOR>INSTALLATION .
  4. Install the bumper face - front. Refer to EXTERIOR/INTERIOR TRIM>FRONT BUMPER>INSTALLATION .
  5. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
  6. Charge refrigerant. Refer to AIR CONDITIONER (HEV)>REFRIGERANT CHARGING PROCEDURE>PROCEDURE .
