Diagnostic procedure:

  1. Using the Subaru Select Monitor, perform the clear memory of [P-HEV High Voltage Battery]. Refer to COMMON (DIAG)>CLEAR MEMORY .
  2. Turn to IG OFF, and wait for two minutes or more.
  3. Drive the vehicle for 10 minutes at an outside temperature of -10°C (14°F) or more while referring to [Vehicle Speed Sensor], [Accel. Opening Angle], [Hybrid Battery Temperature 1] - [Hybrid Battery Temperature 15], [Hybrid Battery Current] in the freeze frame data. (This DTC will not be detected in vehicle stop state and constant speed driving.)

    (Check that the output of HV battery temperature sensor changes. Check that there is not much difference in output of each HV battery temperature sensor.)

  4. Read the [Readiness code] of [P-HEV High Voltage Battery] using Subaru Select Monitor and check that the concerned self-diagnosis is completed. Refer to P-HEV HIGH VOLTAGE BATTERY (DIAGNOSTICS)>ALL READINESS DIAGNOSTIC CODE(S) .
    NOTE: If the concerned DTC is displayed, the self-diagnosis of the DTC is not complete. Repeat from step  3.
  5. Using the Subaru Select Monitor, read the DTC of [P-HEV High Voltage Battery] to check that there is no DTC displayed. Refer to P-HEV HIGH VOLTAGE BATTERY (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
    NOTE: If the DTC is displayed on the screen, the trouble is still present. Perform the diagnosis for the displayed DTCs.
