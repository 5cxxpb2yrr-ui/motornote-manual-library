DTC U0100-87: Lost Communication With ECM/PCM "A" Missing Message: Notes

WARNING: This page is about a different variant/trim than selected.
  1. - 

    Detecting condition: 

    Malfunction of CAN communication with ECM (CAN system malfunction)

    (1 trip detection logic)

    Trouble symptom: 

    Normal driving

    CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to P-HEV DRIVE MOTOR (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK DTC. 

    Read the DTC of [P-HEV Drive Motor] using the Subaru Select Monitor. Refer to P-HEV DRIVE MOTOR (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    NOTE:
    Related DTC
    P312487 LOST COMMUNICATION BETWEEN DRIVE MOTOR "A" AND HV ECU MISSING MESSAGE

    Are any DTCs listed in reference above displayed?

    Yes:  Perform the diagnosis of DTC P312487. Refer to P-HEV DRIVE MOTOR (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC P312487 LOST COMMUNICATION BETWEEN DRIVE MOTOR "A" AND HV ECU MISSING MESSAGE .

    NOTE: DTC U010087, U029387 or U117087 may be output due to a malfunction that outputs DTC P312487. Check DTC P312487 first, and then perform the reproducing test to check that the DTC is not output.

    No:  Check the CAN communication system. Refer to LAN SYSTEM (DIAGNOSTICS) (HEV)>BASIC DIAGNOSTIC PROCEDURE>PROCEDURE .
