DTC B281C: Incompatible With Eyesight (EPS)

Do you like it dark? Easier on the eyes.

WARNING: This page is about a different variant/trim than selected.

Detected when the EPS Control Module does not recognize EyeSight.

DTC detecting condition: 

The EPS Control Module does not recognize EyeSight.

Trouble symptom: 

All functions of EyeSight system do not operate.

CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to EYESIGHT (DIAGNOSTICS) (HEV)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK DTC. 

    Read the DTC of [EyeSight] using the Subaru Select Monitor. Refer to EYESIGHT (DIAGNOSTICS) (HEV)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC U**** displayed? (Current malfunction)

    Yes:  Perform the diagnosis for LAN system. Refer to LAN SYSTEM (DIAGNOSTICS) (HEV)>BASIC DIAGNOSTIC PROCEDURE>PROCEDURE . Go to  2.

    No:  Go to  3.

  2. CHECK DTC. 

    Read the DTC of [EyeSight] using the Subaru Select Monitor. Refer to EYESIGHT (DIAGNOSTICS) (HEV)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC B281C still a current malfunction?

    Yes:  Go to  3.

    No:  Using the Subaru Select Monitor, perform the clear memory of [EyeSight]. Refer to COMMON (DIAG)>CLEAR MEMORY .

  3. CHECK DATA MONITOR. 

    Using the Subaru Select Monitor, check the following items in the [Data Monitor] of [EyeSight]. Refer to EYESIGHT (DIAGNOSTICS) (HEV)>DATA MONITOR .

    • EyeSight Specification

    Is the data [Yes]?

    Yes:  Go to  4.

    No:  Go to  5.

  4. CHECK DATA MONITOR. 

    Using the Subaru Select Monitor, check the following items in the [Data Monitor] of [EyeSight]. Refer to EYESIGHT (DIAGNOSTICS) (HEV)>DATA MONITOR .

    • EyeSight Recognition Status (EPS)

    Is the data [Detect]?

    Yes:  Replace the stereo camera. Refer to EYESIGHT>STEREO CAMERA>REMOVAL .

    No:  Replace the EPS Control Module. Refer to POWER ASSISTED SYSTEM (POWER STEERING)>POWER STEERING CONTROL MODULE>REMOVAL .

  5. CHECK DATA MONITOR. 

    Using the Subaru Select Monitor, check the following items in the [Data Monitor] of [EyeSight]. Refer to EYESIGHT (DIAGNOSTICS) (HEV)>DATA MONITOR .

    • EyeSight Recognition Status (EPS)

    Is the data [Detect]?

    Yes:  Replace the EPS Control Module and combination meter. Refer to POWER ASSISTED SYSTEM (POWER STEERING)>POWER STEERING CONTROL MODULE>REMOVAL . Refer to INSTRUMENTATION/DRIVER INFO>COMBINATION METER>REMOVAL .

    No:  Replace the combination meter. Refer to INSTRUMENTATION/DRIVER INFO>COMBINATION METER>REMOVAL .
