VDC Off Indicator Light Does Not Go Off

Detecting condition: 

  • Defective combination meter
  • Defective CAN communication
  • VDC OFF switch is shorted.

Trouble symptom: 

VDC OFF indicator light does not go off when starting the engine.

Wiring diagram: 

Vehicle dynamics control system Refer to WIRING SYSTEM (IMPREZA MODEL)>VEHICLE DYNAMICS CONTROL SYSTEM . Refer to WIRING SYSTEM (CROSSTREK MODEL (EXCEPT FOR HEV))>VEHICLE DYNAMICS CONTROL SYSTEM .

Courtesy of SUBARU OF AMERICA, INC.
CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to BRAKE CONTROL (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. READ DTC. 

    Read the DTC using Subaru Select Monitor. Refer to BRAKE CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC displayed?

    Yes:  Perform the diagnosis according to DTC. Refer to BRAKE CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Go to  2.

  2. CHECK VDC OFF SWITCH. 

    Using the Subaru Select Monitor and while the engine is running, display the [OFF SW Signal] of [Data monitor]. Refer to BRAKE CONTROL (DIAGNOSTICS)>DATA MONITOR .

    Does [OFF SW Signal] change according to operation of VDC OFF switch?

    Yes:  Go to  5.

    No:  Go to  3.

  3. CHECK VDC OFF SWITCH. 

    Remove and check VDC OFF switch. Refer to VEHICLE DYNAMICS CONTROL (VDC)>VDC OFF SWITCH .

    Is the check result OK?

    Yes:  Go to  4.

    No:  Replace the VDC OFF switch.

  4. CHECK VDC OFF SWITCH CIRCUIT. 
    1. Disconnect the connector from the VDC Contol Module & H/U.
    2. Measure the resistance between VDC Contol Module & H/U connector and chassis ground.

      Connector & terminal 

      (B310) No. 32 - Chassis ground:

    Is the resistance less than 10 Ω?

    Yes:  Check the VDC OFF switch circuit.

    No:  Go to  5.

  5. CHECK LAN SYSTEM. 

    Perform the diagnosis for LAN system using the Subaru Select Monitor. Refer to LAN SYSTEM (DIAGNOSTICS) (EXCEPT FOR HEV)>BASIC DIAGNOSTIC PROCEDURE .

    Is DTC of CAN communication displayed?

    Yes:  Perform the diagnosis according to DTC. Refer to LAN SYSTEM (DIAGNOSTICS) (EXCEPT FOR HEV)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Go to  6.

  6. CHECK COMBINATION METER. 

    Check the combination meter. Refer to INSTRUMENTATION/DRIVER INFO>COMBINATION METER SYSTEM>OPERATION>SELF-DIAGNOSIS DISPLAY MODE .

    Is the check result OK?

    Yes:  Replace the VDC Contol Module & H/U. Refer to VEHICLE DYNAMICS CONTROL (VDC)>VDC CONTROL MODULE AND HYDRAULIC CONTROL UNIT (VDCCM & H/U) .

    No:  Replace the combination meter. Refer to INSTRUMENTATION/DRIVER INFO>COMBINATION METER .
