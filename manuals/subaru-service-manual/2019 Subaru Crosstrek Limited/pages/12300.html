HVAC System (Heater, Ventilator And A/C) (Except For HEV): Condenser: Installation

CAUTION:
  • Since the auto A/C model uses the variable displacement compressor, be careful of the following items.
    • Do not start the engine before charging refrigerant.
    • If the engine is started with no refrigerant charge, replace the compressor assembly.
  • Replace the O-rings with new parts, and then apply compressor oil to install completely.
  • If the condenser assembly - air conditioner has been replaced, add an appropriate amount of compressor oil. Refer to AIR CONDITIONER (EXCEPT FOR HEV)>COMPRESSOR OIL>ADJUSTMENT .
  1. Install the condenser assembly - air conditioner.
  2. Install the hose - pressure discharge and the pipe - evaporator cooling.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  3. Install the bracket - bumper UPR and radiator upper frame. Refer to COOLING (H4DO (EXCEPT FOR HEV))>RADIATOR>INSTALLATION .
  4. Install the bumper face - front. Refer to EXTERIOR/INTERIOR TRIM>FRONT BUMPER>INSTALLATION .
  5. Install the lock assembly - front hood. Refer to SECURITY AND LOCKS>FRONT HOOD LOCK ASSEMBLY>INSTALLATION .
  6. Install the air intake duct. Refer to INTAKE (INDUCTION) (H4DO (EXCEPT FOR HEV))>AIR INTAKE DUCT>INSTALLATION .
  7. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
  8. Charge refrigerant. Refer to AIR CONDITIONER (EXCEPT FOR HEV)>REFRIGERANT CHARGING PROCEDURE>PROCEDURE .
