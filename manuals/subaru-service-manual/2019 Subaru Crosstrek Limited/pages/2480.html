Basic Diagnostic Procedure: Procedure

CAUTION: For the steering responsive fog light system, perform the diagnosis for the "BODY CONTROL SYSTEM (DIAGNOSTICS)". Refer to BODY CONTROL (DIAGNOSTICS)>BASIC DIAGNOSTIC PROCEDURE>PROCEDURE .
  1. PERFORM CUSTOMER INTERVIEW. 

    Ask the customer when and how the trouble occurred using the interview check list. Refer to HEADLIGHT/FOGLIGHT (DIAGNOSTICS)>CHECK LIST FOR INTERVIEW .

    Did you interview the customer?

    Yes:  Go to  2.

    No:  Perform the interview, and Go to  2.

  2. BASIC INSPECTION. 

    Perform basic inspection. Refer to HEADLIGHT/FOGLIGHT (DIAGNOSTICS)>GENERAL DESCRIPTION>INSPECTION .

    Is the check result OK?

    Yes:  Go to  3.

    No:  Repair the faulty part found in basic inspection, and Go to  3.

  3. CHECK SUBARU SELECT MONITOR COMMUNICATION. 
    1. Turn the ignition switch to OFF.
    2. Connect the Subaru Select Monitor to data link connector. Refer to COMMON (DIAG)>DATA LINK CONNECTOR .
    3. Turn the ignition switch to ON and run the Subaru Select Monitor.
    4. Select [Headlight/Foglight].
      NOTE: For detailed operation procedures, refer to "Help" of application.

      Is communication possible?

      Yes:  Go to  4.

      No:  Check the communication circuit. Refer to HEADLIGHT/FOGLIGHT (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE FOR SUBARU SELECT MONITOR COMMUNICATION .

  4. CHECK DTC. 
    1. Read the DTC of [Headlight/Foglight] using the Subaru Select Monitor. Refer to HEADLIGHT/FOGLIGHT (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
    2. Record all DTCs, time stamp and freeze frame data.
      NOTE: For time stamp, refer to "LAN SYSTEM". Refer to LAN SYSTEM (DIAGNOSTICS) (EXCEPT FOR HEV)>GENERAL DESCRIPTION>CAUTION>TIME STAMP . Refer to LAN SYSTEM (DIAGNOSTICS) (HEV)>GENERAL DESCRIPTION>CAUTION>TIME STAMP .

      Are any DTCs displayed? (Current malfunction)

      Yes:  Record the DTC, time stamp and freeze frame data, and Go to  5.

      No:  Perform diagnosis according to the procedures in the diagnostics with phenomenon. Refer to HEADLIGHT/FOGLIGHT (DIAGNOSTICS)>DIAGNOSTICS WITH PHENOMENON .

  5. PERFORM DIAGNOSIS. 
    1. Perform the diagnosis according to the displayed DTC.
    2. Repair or replace the cause of trouble.
    3. Using the Subaru Select Monitor, perform the clear memory of [Headlight/Foglight]. Refer to COMMON (DIAG)>CLEAR MEMORY .
    4. Execute the inspection mode. Refer to HEADLIGHT/FOGLIGHT (DIAGNOSTICS)>INSPECTION MODE .
    5. Read the DTC of [Headlight/Foglight] using the Subaru Select Monitor. Refer to HEADLIGHT/FOGLIGHT (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

      Are any DTCs displayed? (Current malfunction)

      Yes:  Repeat step  5 until DTC is not shown.

      No:  Finish the diagnosis.
