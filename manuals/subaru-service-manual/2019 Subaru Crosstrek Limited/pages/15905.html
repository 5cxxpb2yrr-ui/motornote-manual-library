Active Test: List

WARNING: This page is about a different variant/trim than selected.
Active test items Contents Execution condition
Fuel Pump Relay ON/OFF of the fuel pump can be set. Ignition switch ON (engine OFF)
CPC Solenoid Valve ON/OFF of the purge control solenoid valve can be set.
Radiator Fan Relay ON/OFF of the radiator fan relay can be set.
ELCM switching valve ON/OFF of the leak check valve assembly switching valve can be set.
ELCM pump ON/OFF of the leak check valve assembly vacuum pump can be set.
Fuel Pump Control (OFF Drive) Fuel pump can be set to OFF. Non-load idling(1)
Fixed Idle Ignition Timing Ignition timing is set to 6° - 18° according to engine speed.
Idle Speed Control Idle speed can be set to 1000 - 2000 rpm.
CAUTION: Idle speed can be set up to 500 rpm at the Subaru Select Monitor. However, do not set to 1000 rpm or less.
Injection Stop Mode (Injector 1) Injection Stop Mode (Injector 2) Injection Stop Mode (Injector 3) Injection Stop Mode (Injector 4) Injector of each cylinder can be set to stop the fuel injection.
Injection Quantity Control The amount of fuel injection can be set to -13 - 20%.
EGR Valve Control (Step) EGR control valve can be set to 0 - 68 STEP.
Active Grille Shutter Control(2) Open ←→ close of the active grille shutter can be set.
  • Ignition switch ON (engine OFF)
  • Experienced 20 seconds or more of the elapsed time after starting engine (when replacing ECM)
Electric Vent Solenoid Value Open/close status of the valve that seals the fuel tank is displayed.
Open: Not sealed
Close: Sealed
  • Ignition switch ON (engine OFF)
  • "P" range
  • Vehicle speed 0 km/h (0 MPH)
Fuel Filler Lid Lock Solenoid Relay Output Operating status of the relay that drives the lock assembly fuel is displayed.
ON: Opens the fuel lid
OFF: Does not open the lock assembly fuel
  • Ignition switch ON (engine OFF)
  • "P" range
  • Vehicle speed 0 km/h (0 MPH)
(1) A condition where Inspection Mode for measuring Exhaust Gas is initiated before starting engine and the following data monitor items are ON after starting engine corresponds to non-load idling. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>Work Support>OPERATION>SERVICE MODE . Refer to ENGINE (DIAGNOSTICS) (H4DO (HEV))>DATA MONITOR .
