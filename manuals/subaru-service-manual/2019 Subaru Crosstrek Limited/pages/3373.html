Rear Shelf Trim: Installation

  1. Install the trim panel assembly - rear shelf.
  2. Install the lower anchor of seat belt - rear shoulder CTR.

    Tightening torque: 

    30 N.m (3.1 kgf-m, 22.1 ft-lb)

  3. Install the trim panel - rear pillar UPR and the trim panel - rear pillar LWR.
  4. Install the side sill cover - rear INN.
  5. Install the rear seat cushion assembly.
  6. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
