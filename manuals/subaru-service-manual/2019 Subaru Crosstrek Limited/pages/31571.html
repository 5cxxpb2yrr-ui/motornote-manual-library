Fog Light Covers-Design Change (12-276-19)

FOG LIGHT COVERS-DESIGN CHANGE

FOG LIGHT COVERS-DESIGN CHANGE

TECHNICAL SERVICE BULLETIN

Reference Number(s): 12-276-19, Date of Issue:  December 12, 2019
SUBARU: 2018-19 Crosstrek

APPLICABILITY

2018-19MY Crosstrek

INTRODUCTION

This bulletin announces a design change made to the fog light cover claws to improve their retention. The height of all 5 retaining claws has been increased by.5 mm as shown in the illustration below.

PRODUCTION CHANGE INFORMATION

The new covers were incorporated into production starting with VIN KH390125  .

PART INFORMATION

Description Part Number Note
COVER-FOG LIGHT RH 57731FL062 WITHOUT Fog Light
COVER-FOG LIGHT LH 57731FL072
COVER-FOG LIGHT RH 57731FL082 WITH Fog Light
COVER-FOG LIGHT LH 57731FL092

REMINDER  : Always order the most up-to-date replacement parts based on the specific VIN being repaired.

SERVICE PROCEDURE/INFORMATION

REMINDER  : Customer satisfaction and retention starts with performing quality repairs.

The service procedures for Fog Light Cover replacement remain unchanged. Always refer to the applicable Service Manual and review the full requirements of the repair being performed. The Service Manual procedures contain information critical to performing effective repairs first time, every time.

WARRANTY/CLAIM INFORMATION

For vehicles within the Basic New Car Limited Warranty period, this repair may be submitted using the following claim information:

Labor Description Labor Operation # Labor Time Fail Code
One or Both Fog Light Covers R&R A916-711 0.2 XEQ-23
