DTC U1120: Lost Communication With Autostart Stop Control Module

NOTE: The electric power steering control module identifies whether the Auto Start Stop function is provided or not using information from the combination meter. Therefore, this DTC may be detected if lost communication with the combination meter occurs. For the diagnostic procedure, refer to DTC U0155 LOST COMMUNICATION WITH INSTRUMENT PANEL CLUSTER (IPC) CONTROL MODULE.
