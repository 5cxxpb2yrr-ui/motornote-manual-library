Cannot Register Or Change The Timer Charging Schedule

WARNING: This page is about a different variant/trim than selected.
CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to PLUG-IN BATTERY CHARGER (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK DTC. 

    Using the Subaru Select Monitor, read all DTCs. Refer to COMMON (diag)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed?

    Yes:  Perform the diagnosis for the displayed DTCs.

    No:  Go to  2.

  2. CHECK THE INTERVIEW RESULTS. 

    Check the method which the customer used to set the timer (MFD, smartphone).

    If MFD was used, go to  A.

    If a smartphone was used, go to  B.

    Yes: 

    1. Go to  3.
    2. Go to  4.

    No:  -

  3. REPRODUCTION TEST (MFD). 
    1. Turn to IG ON.
    2. Use the same method as the customer and display the timer charging schedule change (register) screen. (Timer charging setting switch, steering wheel switch)
    3. Press the timer charging switch and display the timer charging schedule change screen on the MFD.
    4. Select MFD "Settings screen" → "Charge settings" → "Charge timer settings" to display the change screen.
    5. From the change screen, register or change the timer charging schedule.

    If it is possible to change (register) the timer charging schedule from the MFD, go to  A.

    If operation using the timer charging switch is not possible, go to  B.

    If operation using the steering wheel switch is not possible, go to  C.

    If it is not possible to change (register) the timer charging schedule from settings screen displayed on the MFD, go to  D.

    Yes: 

    1. Analyze the cause (user cause when using MFD).

      Analyze the cause as shown below.

      • Timer setting method
        • Ask questions to customer and explain method of use.
        • Explain that when setting the timer from the MFD, the power must be set to IG ON or READY ON.
      • Maximum number of timer charging schedules that can be set
        • Ask questions to customer and explain method of use.
        • A maximum of 3 timer charging schedules can be set. When 3 are already set, the screen is grayed out and cannot be selected.
    2. Go to Timer charging setting switch system. Refer to PLUG-IN BATTERY CHARGER (DIAGNOSTICS)>DIAGNOSTICS WITH PHENOMENON>INSPECTION>TIMER CHARGING SETTING SWITCH .
    3. Go to check of the steering wheel switch. Refer to INSTRUMENTATION/DRIVER INFO>SWITCHES AND HARNESS .
    4. Go to MFD diagnosis. Refer to MULTI-FUNCTION DISPLAY (DIAGNOSTICS)>BASIC DIAGNOSTIC PROCEDURE .

    No:  -

  4. REPRODUCTION TEST (SMARTPHONE). 
    1. Launch the app on the customer smartphone and change the timer charging schedule.
    2. Turn to IG ON.
    3. Check that the settings change was applied to the charging schedule screen in the combination meter.
      NOTE: Depending on the communication environment, several minute may be required before the timer charging information is applied on the vehicle side.

    Is is possible to change (register) the timer charging schedule?

    Yes:  Analyze the cause (user cause when using smartphone).

    Analyze the cause as shown below.

    • The user attempted to change the timer charging schedule from a smartphone while setting the timer from the MFD.
      • Explain that it is not possible to change the timer charging schedule from a smartphone while the timer setting screen is displayed and operated on the MFD.

    No:  Contact the Telematics Support Center.
