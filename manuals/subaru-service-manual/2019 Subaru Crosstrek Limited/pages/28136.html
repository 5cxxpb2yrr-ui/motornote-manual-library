Diagnostic Method

WARNING: This page is about a different variant/trim than selected.

Judge as NG when the following conditions are established.

  1. Judgment 1: Diagnosis for open circuit 
    JUDGMENT VALUE SPECIFICATION

    Malfunction Criteria Threshold Value
    High-pressure fuel pump wrong operation signal (0.2 A or less) ON
  2. Judgment 2: Diagnosis for overcurrent 
    JUDGMENT VALUE SPECIFICATION

    Malfunction Criteria Threshold Value
    High-pressure fuel pump wrong operation signal (14.2 A or more) ON
  3. Judgment 3: Diagnosis for ground short 
    JUDGMENT VALUE SPECIFICATION

    Malfunction Criteria Threshold Value
    High-pressure fuel pump wrong operation signal (1 V or less) ON
  4. Judgment 4: Diagnosis for power supply short 
    JUDGMENT VALUE SPECIFICATION

    Malfunction Criteria Threshold Value
    High-pressure fuel pump wrong operation signal (5 V or more) ON
  5. Judgment 5: Diagnosis for ground short (between ECM and high-pressure fuel pump driver) 
    JUDGMENT VALUE SPECIFICATION

    Malfunction Criteria Threshold Value
    High-pressure fuel pump control voltage Less than 3.92 V
  6. Judgment 6: Diagnosis for power supply short (between ECM and high-pressure fuel pump driver) 
JUDGMENT VALUE SPECIFICATION

Malfunction Criteria Threshold Value
High-pressure fuel pump control voltage 3.92 V or more

Time needed for diagnosis: 

Judgment 1, 2, 5: Map1

Judgment 3, 4, 6: Map2

Map1 

Engine speed (rpm) 500 2000 4000
Time when calculation was performed 10 times (sec) 0.6 0.15 0.08

Map2 

Engine speed (rpm) 0 500 2000 4000
Time when calculation was performed 10 times (sec) 0.04 0.6 0.15 0.08

Malfunction indicator light illumination:  Illuminates as soon as a malfunction occurs.
