DTC B2821: Reverse Automatic Braking Control Prohibition

DTC detecting condition: 

Defective RAB Control Module.

Trouble symptom: 

  • The Reverse Automatic Braking function does not operate.
  • RAB warning light illuminates.
NOTE: Check the Reverse Automatic Braking when this DTC is displayed. Refer to REVERSE AUTOMATIC BRAKING (DIAGNOSTICS)>BASIC DIAGNOSTIC PROCEDURE .
