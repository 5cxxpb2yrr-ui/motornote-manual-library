Brake Stroke Sensor

  1. Using the Subaru Select Monitor, read the brake stroke sensor output value.
    CAUTION: Read the output pedal when the brake pedal is not depressed.

    Specification: 

    1±0.2 V

  2. If the inspection result is not the standard value, adjust the brake stroke sensor. Refer to BRAKE>BRAKE PEDAL>ADJUSTMENT>BRAKE STROKE SENSOR .
