Ignition Key Lock: Assembly

  1. Install the ignition switch assembly.
    NOTE: When installing the ignition switch, make sure to turn the key to the ACC position.
  2. Install the key lock assembly.
  3. Install the key warning switch.
  4. Install the immobilizer antenna assembly.
