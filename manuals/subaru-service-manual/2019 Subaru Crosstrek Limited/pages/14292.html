Charging Inlet Door

WARNING: This page is about a different variant/trim than selected.
CAUTION: Airbag system satellite safing sensor is located under the front center of the rear seat cushion. Be careful not to apply strong impact to the sensor when working with the rear seat cushion removed.
  1. Install the saucer SUB-assembly.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  2. Install the flap - outer.
  3. Install the charge lid lock assembly with motor.
  4. Install the duct assembly - cooling out LH. Refer to HYBRID ELECTRIC VEHICLE>HIGH VOLTAGE BATTERY COOLING SYSTEM>INSTALLATION>REAR DUCT>LH SIDE .
  5. Install the battery cooling blower assembly LH. Refer to HYBRID ELECTRIC VEHICLE>HIGH VOLTAGE BATTERY COOLING SYSTEM>INSTALLATION>COOLING BLOWER .
  6. Install the duct - battery cooling blower LH. Refer to HYBRID ELECTRIC VEHICLE>HIGH VOLTAGE BATTERY COOLING SYSTEM>INSTALLATION>FRONT DUCT .
  7. Install the trim panel - rear apron LH. Refer to EXTERIOR/INTERIOR TRIM>REAR QUARTER TRIM>INSTALLATION .
  8. Install the rear seat cushion assembly. Refer to SEATS>REAR SEAT>INSTALLATION .
  9. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
