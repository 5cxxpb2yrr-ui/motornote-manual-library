Active Test: Operation

Do you like it dark? Easier on the eyes.

WARNING: This page is about a different variant/trim than selected.
  1. On [Start] screen, select [Diagnosis].
  2. On [Vehicle selection] screen, enter vehicle information and select [OK].
  3. On [Main Menu] screen, select [Each System].
  4. On [Select System] screen, select [P-HEV Hybrid Powertrain Control].
  5. On [Select Function] screen, select [Active Test].
  6. On [Active Test] screen, select an item to be checked.
NOTE:
  • For detailed operation procedures, refer to "Help" of application.
  • When connector disconnection or communication error with the Subaru Select Monitor occurred during the active test, driving may become impossible (READY OFF), so use special care.
  • After the active test is finished, resume the work after turning to IG OFF.
