Center Console: Installation

CAUTION: The clips "C62" and "C63" shown in the figure may have different engaging forces. Always use the specified parts when installing.
  1. Install the tray - center UPR.
  2. Install the panel center LWR.
  3. Install the console box assembly, the cover assembly - front and the boot - hand brake.

    (Except for hybrid model)

    Tightening torque: 

    Console box: 6.5 N.m (0.7 kgf-m, 4.8 ft-lb)

  4. Install the console box assembly and the cover assembly - front. (Hybrid model)

    Tightening torque: 

    Console box: 6.5 N.m (0.7 kgf-m, 4.8 ft-lb)

  5. Install the heater control assembly.
  6. Install the audio assembly or navigation assembly.
  7. Install the panel - center UPR.
  8. Install the center grille assembly.
  9. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
    NOTE: For CVT models, after connecting the battery ground terminal, place the select lever in the P position.
