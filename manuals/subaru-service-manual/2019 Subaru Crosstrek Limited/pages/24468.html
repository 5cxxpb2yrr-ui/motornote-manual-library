Diagnostic Method

WARNING: This page is about a different variant/trim than selected.
Courtesy of SUBARU OF AMERICA, INC.

Calculate the difference between the Evaporative Leak Check Module pressure sensor output value of 5 seconds ago and the value at the present moment, and if the value is greater than the judgment value, detect as filter clogging trouble and judge as malfunction.

Judge as NG when the following conditions are established.

JUDGMENT VALUE SPECIFICATION

Malfunction Criteria Threshold Value
|Pressure sensor output value as of 5 seconds ago - Current pressure sensor output value| More than 1 kPa (7.499 mmHg, 0.3 inHg)

Time needed for diagnosis:  2time(s) x 0.512 ms

Malfunction indicator light illumination:  Illuminates when malfunction occurs in 2 continuous driving cycles.
