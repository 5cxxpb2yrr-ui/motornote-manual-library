High Voltage Battery: Installation

WARNING: This page is about a different variant/trim than selected.
WARNING: The hybrid system includes a high voltage circuit. Mishandling could cause accidents such as electric shock or leak. Always check "WARNING (HYBRID SYSTEM)" and perform the proper operation. Refer to PRECAUTION/WARNING>WARNING (HYBRID SYSTEM) .
CAUTION: Airbag system satellite safing sensor is located under the front center of the rear seat cushion. Be careful not to apply strong impact to the sensor when working with the rear seat cushion removed.
  1. Install the HV battery.
    WARNING: Be sure to wear insulated gloves.
    CAUTION:
    • Since the HV battery is heavy, installation work must be performed by 2 or more persons using a mini crane. Use caution to prevent damage to surrounding parts.
    • If the HV battery was dropped or subjected to a strong impact, replace it with a new battery.
    • Securely press in the connector until a click sound is heard, and check visually and by pulling on the connector that the connector is connected securely.
    • If the HV battery will be reused, install the new part seal onto the duct assembly - gas out.
    1. Following the same procedure as for removal, install the cable onto the HV battery and install the mini crane.
      WARNING: Because the HV battery is heavy, pay careful attention to the work procedure and balance when hoisting the HV battery in order to prevent injury or accident.
    2. Install the cover - battery LWR.
    3. Install the HV battery into the cargo room.
      CAUTION:
      • Be careful that the mini crane, cable, and HV battery do not contact the body, glass, or other objects.
      • If the HV battery was dropped or subjected to a strong impact, replace it with a new battery.
      • In order to prevent scratches, protect the vehicle with cardboard or other material while working.
    4. Install new bolts and nuts.
      CAUTION: Do not touch bolts and nuts if they have grease or other oil component on them.

      Tightening torque: 

      18 N.m (1.8 kgf-m, 13.3 ft-lb)

    5. Install the center antenna assembly - interior harness clips.
  2. Install the bar - floor rear COMPL.

    Tightening torque: 

    Bar - floor rear COMPL: 18 N.m (1.8 kgf-m, 13.3 ft-lb)

    Ground terminal: 7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  3. Install the wire harness and HV battery charger wire No. 1.
    WARNING: Be sure to wear insulated gloves.
    CAUTION: Check that the HV battery charger wire No. 1 connector is connected securely.
  4. Install the bracket - battery front.

    Tightening torque: 

    18 N.m (1.8 kgf-m, 13.3 ft-lb)

  5. Install the bar - floor front COMPL.

    Tightening torque: 

    28 N.m (2.9 kgf-m, 20.7 ft-lb)

  6. Connect the main battery - sensor cord.
    WARNING: Be sure to wear insulated gloves.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  7. Connect the main battery cable assembly.
    WARNING: Be sure to wear insulated gloves.
    CAUTION: Make sure the main battery cable assembly connector is connected securely.
  8. Install the duct assembly - gas out. Refer to HYBRID ELECTRIC VEHICLE>HOSE AND PIPE>INSTALLATION .
  9. Install the charger duct. Refer to HYBRID ELECTRIC VEHICLE>ELECTRIC VEHICLE CHARGER>INSTALLATION>CHARGER DUCT .
  10. Install the duct assembly - cooling out. Refer to HYBRID ELECTRIC VEHICLE>HIGH VOLTAGE BATTERY COOLING SYSTEM>INSTALLATION>REAR DUCT .
  11. Install the battery cooling blower assembly. Refer to HYBRID ELECTRIC VEHICLE>HIGH VOLTAGE BATTERY COOLING SYSTEM>INSTALLATION>COOLING BLOWER .
  12. Install the duct - battery cooling blower. Refer to HYBRID ELECTRIC VEHICLE>HIGH VOLTAGE BATTERY COOLING SYSTEM>INSTALLATION>FRONT DUCT .
  13. Install the Reverse Automatic Braking control module. Refer to REVERSE AUTOMATIC BRAKING>REVERSE AUTOMATIC BRAKING CONTROL MODULE >INSTALLATION .
  14. Install the rear antenna assembly - interior. Refer to SECURITY AND LOCKS>KEYLESS ACCESS INDOOR ANTENNA>INSTALLATION>REAR ANTENNA .
  15. Install the trim panel - rear apron. Refer to EXTERIOR/INTERIOR TRIM>REAR QUARTER TRIM>INSTALLATION .
  16. Install the rear seat cushion assembly, backrest assembly, hinge assembly - backrest CTR, and plate - anchor LWR LH. Refer to SEATS>REAR SEAT>INSTALLATION .
  17. Install the service disconnect plug. Refer to HYBRID ELECTRIC VEHICLE>SERVICE PLUG>INSTALLATION .
  18. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
  19. After the HV battery was replaced with a new part, perform the following work.
    1. Perform battery diagnosis. Refer to P-HEV HIGH VOLTAGE BATTERY (DIAGNOSTICS)>ACTIVE TEST>LIST>BATTERY DIAGNOSIS .
    2. Perform update of battery status information. Refer to P-HEV HIGH VOLTAGE BATTERY (DIAGNOSTICS)>WORK SUPPORT>OPERATION>BATTERY STATUS INFORMATION UPDATE .
    3. Perform current sensor offset learning. Refer to HYBRID ELECTRIC VEHICLE>HYBRID ELECTRIC VEHICLE SYSTEM>PROCEDURE .
  20. Using Subaru Select Monitor, check [Hybrid Battery SOC] from the list of Data Monitor items. Refer to P-HEV HIGH VOLTAGE BATTERY (DIAGNOSTICS)>DATA MONITOR . If the [Hybrid Battery SOC] is low, perform charging work.
