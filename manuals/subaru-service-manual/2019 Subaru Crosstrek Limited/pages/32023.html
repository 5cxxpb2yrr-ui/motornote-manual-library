CROSSTREK Model

CAUTION:
  • When raising the transmission jack, make sure that the tie-rod end and the drive shaft boot do not interfere. The drive shaft boot may be damaged.
  • The crossmember COMPL is heavy. Make sure that it is firmly supported so that it is level.
  • For parts which are not reusable, always use new parts.
  • Always tighten the bushing in the state where the vehicle is at curb weight and the wheels are in full contact with the ground.
  • Install the clamp - stabilizer bushing with the peak of triangle facing the front of the vehicle.

  1. Install the crossmember COMPL.
    NOTE: Check the crossmember COMPL for damage or cracks, and correct or replace if defective.
    1. Install the bolts which secure the crossmember COMPL to the body.

      Tightening torque: 

      Refer to "COMPONENT" of "General Description" for the tightening torque.

      Refer to FRONT SUSPENSION>GENERAL DESCRIPTION>COMPONENT>FRONT SUSPENSION .

  2. Lower the engine and remove the lifting device and wire ropes.
  3. Remove the ST1 and ST2 from the engine unit.
  4. Install the engine mounting and the crossmember COMPL with new nuts.

    Tightening torque: 

    Engine mounting - crossmember COMPL: 90 N.m (9.2 kgf-m, 66.4 ft-lb)

  5. Install the steering gearbox assembly and stiffener to the crossmember COMPL.

    Tightening torque: 

    Refer to "COMPONENT" of "General Description" for the tightening torque.

    Refer to FRONT SUSPENSION>GENERAL DESCRIPTION>COMPONENT>FRONT SUSPENSION .

  6. Install the power steering harness connector and harness clamp.
  7. Install the universal joint assembly - steering.

    Refer to POWER ASSISTED SYSTEM (POWER STEERING)>UNIVERSAL JOINT>INSTALLATION .

  8. Install the front arm assembly.

    Refer to FRONT SUSPENSION>FRONT ARM>INSTALLATION .

  9. Install the tie-rod end.
    NOTE: When tightening the castle nut, tighten the castle nut to the specified torque first, then tighten it further but within 60° until the hole in the ball stud is aligned with a slot in castle nut.

    Tightening torque: 

    27 N.m (2.7 kgf-m, 19.9 ft-lb)

  10. Insert a new cotter pin and secure the castle nut.
  11. Install the stabilizer.

    Refer to FRONT SUSPENSION>STABILIZER>INSTALLATION>STABILIZER .

  12. Install the front exhaust pipe.

    Refer to EXHAUST (H4DO (EXCEPT FOR HEV))>FRONT EXHAUST PIPE>INSTALLATION .

  13. Install the crossmember support - front and the crossmember support - rear.

    Refer to FRONT SUSPENSION>CROSSMEMBER SUPPORT>INSTALLATION .

  14. Install the under cover - front.

    Tightening torque: 

    18 N.m (1.8kgf-m, 13.3 ft-lb)

  15. Install the front wheels and lower the vehicle.

    Tightening torque: 

    120 N.m (12.2 kgf-m, 88.5 ft-lb)

  16. Install the pitching stopper.

    Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSMISSION MOUNTING SYSTEM>INSTALLATION>PITCHING STOPPER .

  17. Install the air cleaner case.

    Refer to INTAKE (INDUCTION) (H4DO (EXCEPT FOR HEV))>AIR CLEANER CASE>INSTALLATION .

  18. Install the V-belt cover. (Gasoline engine model)

    Tightening torque: 

    7 N.m (0.7 kgf-m, 5.2 ft-lb)

  19. Install the collector cover. (Hybrid model)

    Refer to INTAKE (INDUCTION) (H4DO (EXCEPT FOR HEV))>COLLECTOR COVER>INSTALLATION .

  20. Install the striker - front hood.

    Refer to EXTERIOR BODY PANELS>FRONT HOOD>ASSEMBLY .

  21. Connect the battery ground terminal.

    Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY>GROUND TERMINAL REMOVAL OR INSTALLATION .

  22. Inspect the wheel alignment and adjust if necessary.
    • Inspection:

      Refer to FRONT SUSPENSION>WHEEL ALIGNMENT>INSPECTION .

    • Adjustment:

      Refer to FRONT SUSPENSION>WHEEL ALIGNMENT>ADJUSTMENT .

      CAUTION: When the wheel alignment has been adjusted, perform the following adjustment.
      • Lane keep assist learning value clear (except for hybrid model) (model with EyeSight):

        Refer to EYESIGHT (DIAGNOSTICS) (EXCEPT FOR HEV)>CLEAR ACTIVE LANE KEEP SYSTEM LEARNING VALUE>OPERATION .

      • Lane keep assist learning value clear (hybrid model):

        Refer to EYESIGHT (DIAGNOSTICS) (HEV)>CLEAR ACTIVE LANE KEEP SYSTEM LEARNING VALUE>OPERATION .

      • VDC sensor midpoint setting mode:

        Refer to VEHICLE DYNAMICS CONTROL (VDC)>VDC CONTROL MODULE AND HYDRAULIC CONTROL UNIT (VDCCM & H/U)>ADJUSTMENT .

  23. Perform reinitialization of the auto headlight beam leveler system. (Model with auto headlight beam leveler)

    Refer to LIGHTING SYSTEM>AUTO HEADLIGHT BEAM LEVELER SYSTEM>PROCEDURE .
