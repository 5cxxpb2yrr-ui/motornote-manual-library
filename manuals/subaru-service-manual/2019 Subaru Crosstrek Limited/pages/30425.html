Camshaft Position Sensor: Installation: Intake

WARNING: This page is about a different variant/trim than selected.

• RH SIDE 

  1. Install the camshaft position sensor with new O-ring.
    NOTE: Apply engine oil to O-ring.

    Tightening torque: 

    6.4 N.m (0.7 kgf-m, 4.7 ft-lb)

  2. Connect the connector.
  3. Install the air intake duct. Refer to INTAKE (INDUCTION) (H4DO (EXCEPT FOR HEV))>AIR INTAKE DUCT>INSTALLATION .
  4. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .

• LH SIDE 

  1. Install the camshaft position sensor with new O-ring.
    NOTE: Apply engine oil to O-ring.

    Tightening torque: 

    6.4 N.m (0.7 kgf-m, 4.7 ft-lb)

  2. Connect the connector.
  3. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
