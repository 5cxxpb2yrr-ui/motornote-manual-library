[S], [I] OR [S#] Indicator Is Blinking

Do you like it dark? Easier on the eyes.

Trouble causes: 

  • CAN communication failure
  • ECM failure
  • Combination meter malfunction
CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description".
  1. CHECK DTC. 

    Using the Subaru Select Monitor, read the DTCs of [Engine] and [Combination Meter]. Refer to COMBINATION METER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed? (Current malfunction)

    Yes:  Perform the diagnosis for the displayed DTCs.

    No:  Go to  2.

  2. CHECK DTC. 
    1. Start the engine.
    2. Using the Subaru Select Monitor, read all DTCs. Refer to LAN SYSTEM (DIAGNOSTICS) (EXCEPT FOR HEV)>DIAGNOSTIC TROUBLE CODE (DTC)>OPERATION .

      Is DTC U**** displayed? (Current malfunction)

    Yes:  Perform the diagnosis according to the basic diagnostic procedure in LAN SYSTEM (DIAGNOSTICS). Refer to LAN SYSTEM (DIAGNOSTICS) (EXCEPT FOR HEV)>BASIC DIAGNOSTIC PROCEDURE .

    No:  Go to  3.

  3. CHECK THE ENGINE COOLANT TEMPERATURE LIGHT. 

    Using the Subaru Select Monitor, check the following items in the [Active Test] of [Combination Meter]. Refer to COMBINATION METER (DIAGNOSTICS)>ACTIVE TEST .

    • [S] indicator
    • [I] indicator
    • [S#] indicator

    Do the indicated amount on Subaru Select Monitor and the SI-DRIVE indication match?

    Yes:  Check the engine. Refer to ENGINE (DIAGNOSTICS) (H4DO (EXCEPT FOR HEV))>BASIC DIAGNOSTIC PROCEDURE .

    No:  Replace the combination meter. Refer to INSTRUMENTATION/DRIVER INFO>COMBINATION METER .
