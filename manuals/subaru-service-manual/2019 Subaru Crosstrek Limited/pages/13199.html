DTC C2721: Threshold Read Malfunction

DTC detecting condition  :

When threshold read abnormal (TPMS & keyless entry control module or TPMS control module abnormal) is detected.

Trouble symptom: 

Tire pressure warning light blinks 25 times and then illuminates.

CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to TIRE PRESSURE MONITOR (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. REPRODUCTION OF FAILURE. 

    Read the DTC of [Tire Pressure Monitor] using the Subaru Select Monitor. Refer to TIRE PRESSURE MONITOR (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC displayed as current malfunction?

    Yes:  Go to  2.

    No:  When DTC is displayed as "Past faults", the system has returned to a normal condition at this time. Reproduce the failure, and then perform the diagnosis again.

    NOTE: In this case, there may be temporary poor communication due to radio wave environment inside/outside the vehicle.
  2. REPRODUCTION OF FAILURE. 
    1. Disconnect the battery negative terminal, and connect it again.
    2. Turn the ignition switch to ON.
    3. Read the DTC of [Tire Pressure Monitor] using the Subaru Select Monitor. Refer to TIRE PRESSURE MONITOR (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC displayed as current malfunction?

    Yes:  Replace the TPMS & keyless entry control module or TPMS control module. Refer to WHEEL AND TIRE SYSTEM>TIRE PRESSURE MONITORING SYSTEM .

    No:  When DTC is displayed as "Past faults", the system has returned to a normal condition at this time. Reproduce the failure, and then perform the diagnosis again.

    NOTE: In this case, there may be temporary poor communication due to radio wave environment inside/outside the vehicle.
