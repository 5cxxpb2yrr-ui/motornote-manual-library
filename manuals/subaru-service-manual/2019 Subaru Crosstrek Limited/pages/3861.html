Rear Washer: Installation

  1. Install the nozzle - rear washer.
  2. Install the roof spoiler assembly.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  3. Install the trim panel - rear gate UPR.
  4. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
  5. Check the nozzle - rear washer position. Refer to WIPER AND WASHER SYSTEMS>REAR WASHER>INSPECTION>VISUAL INSPECTION .
