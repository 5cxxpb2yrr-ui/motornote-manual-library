5 Door Model (Hybrid)

  1. Install the trim panel - rear pillar UPR.
  2. Install the trim panel - rear apron.
    CAUTION: Remove the tape on the duct - outlet charger section to prevent the clip from falling off. (When removing the RH side)
  3. Install the cap - rear suspension.
  4. Install the lower anchor bolts of seat belts.

    Tightening torque: 

    33 N.m (3.4 kgf-m, 24.3 ft-lb)

  5. Install the spacer - rear floor CTR.
  6. Install the clips of the backrest backside mat.
  7. Install the box - sub-trunk.
  8. Install the mat - rear floor.
  9. Install the cover side sill - rear INN.
  10. Install the rear seat cushion assembly.
  11. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
