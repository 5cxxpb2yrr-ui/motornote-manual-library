Remote Climate Control (RCC) Does Not Operate Normally

Do you like it dark? Easier on the eyes.

WARNING: This page is about a different variant/trim than selected.

Trouble symptom: 

RCC does not operate.

Trouble causes: 

  • A/C control panel failure
  • Hybrid vehicle control ECU assembly failure.
  • Keyless access control module malfunction
  • Body integrated unit malfunction.
  • DCM malfunction.
CAUTION:
  • Before performing diagnosis, refer to "General description" in "General Description" to check the operating conditions are met. Refer to AIR CONDITIONER (DIAGNOSTICS) (HEV)>GENERAL DESCRIPTION>GENERAL DESCRIPTION .
  • Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to AIR CONDITIONER (DIAGNOSTICS) (HEV)>GENERAL DESCRIPTION>CAUTION .
  • If timer charging in conjunction with the air conditioner does not operate normally, first perform Plug-in Battery Charger diagnosis. Refer to PLUG-IN BATTERY CHARGER (DIAGNOSTICS)>BASIC DIAGNOSTIC PROCEDURE .
  1. CHECK DTC. 

    Read the following DTCs using Subaru Select Monitor. Refer to AIR CONDITIONER (DIAGNOSTICS) (HEV)>DIAGNOSTIC TROUBLE CODE (DTC) . Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) . Refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) . Refer to BODY CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) . Refer to TELEMATICS SYSTEM (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    • Air Conditioner
    • P-HEV Hybrid Powertrain Control
    • Keyless Access with Push Button Start
    • Body Control
    • Telematics

    Are any DTCs displayed? (Current malfunction)

    Yes:  Perform the diagnosis for the displayed DTCs. Refer to AIR CONDITIONER (DIAGNOSTICS) (HEV)>DIAGNOSTIC TROUBLE CODE (DTC) . Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) . Refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) . Refer to BODY CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) . Refer to TELEMATICS SYSTEM (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    No:  Go to  2.

  2. PERFORM DIAGNOSTICS WITH PHENOMENON (AIR CONDITIONER). 

    Check the "Symptom Table" in "Diagnostics with Phenomenon" for the air conditioner. Refer to AIR CONDITIONER (DIAGNOSTICS) (HEV)>DIAGNOSTICS WITH PHENOMENON>LIST .

    Is there a symptom that is not listed in the symptom table?

    Yes:  Perform diagnosis according to the procedures in the diagnostics with the corresponding phenomenon. Refer to AIR CONDITIONER (DIAGNOSTICS) (HEV)>DIAGNOSTICS WITH PHENOMENON>LIST .

    No:  Go to  3.

  3. PERFORM DIAGNOSTICS WITH PHENOMENON (P-HEV HYBRID POWERTRAIN CONTROL). 

    Check the "Symptom Table" in "Diagnostics with Phenomenon" for the P-HEV hybrid powertrain control. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DIAGNOSTICS WITH PHENOMENON>LIST .

    Is there a symptom that corresponds in the symptom table?

    Yes:  Perform diagnosis according to the procedures in the diagnostics with the corresponding phenomenon. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DIAGNOSTICS WITH PHENOMENON>LIST .

    No:  If it does not operate normally on the smartphone, Go to  4.

    If it does not operate normally on devices other than the smartphone, Go to  5.

  4. CHECK RCC OPERATION FROM THE ACCESS KEY. 

    Operate RCC using the access key.

    Does it operate properly?

    Yes:  Perform appropriate inspection using Diagnostics with Phenomenon of telematics. Refer to TELEMATICS SYSTEM (DIAGNOSTICS)>DIAGNOSTICS WITH PHENOMENON>INSPECTION>RCC DOES NOT OPERATE .

    No:  Go to  5.

  5. CHECK OPERATION OF KEYLESS DOOR LOCK. 

    Using the access key, check the operation of the door lock.

    Does it lock/unlock normally?

    Yes:  Go to  6.

    No:  Refer to "Diagnostics with Phenomenon" of the keyless access with push button start to perform appropriate inspection. Refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS)>DIAGNOSTICS WITH PHENOMENON .

  6. CHECK DATA MONITOR. 
    1. Check that all doors are closed.
    2. Using the Subaru Select Monitor, check the following items in the [Data monitor] of [Body Control]. Refer to BODY CONTROL (DIAGNOSTICS)>DATA MONITOR .
      • Driver's door SW input
      • P-door SW input
      • Rear right door SW input
      • Rear left door SW input
      • R Gate SW input

    Are all indications OFF (closed)?

    Yes:  Go to  7.

    No:  Check the door switch. Refer to SECURITY AND LOCKS>DOOR LOCK CONTROL SYSTEM .

  7. CHECK DATA MONITOR. 

    Using the Subaru Select Monitor, check the following items in the [Data monitor] of [Body Control]. Refer to BODY CONTROL (DIAGNOSTICS)>DATA MONITOR .

    • Hood Switch Close-side
    • Hood Switch Open-side

    Does the display indicate ON (closed) for [Hood Switch Close-side], and OFF (closed) for [Hood Switch Open-side]?

    Yes:  Go to  8.

    No:  Check the hood switch. Refer to SECURITY AND LOCKS>FRONT HOOD LOCK ASSEMBLY .

  8. CHECK DATA MONITOR. 
    1. Check that all doors are locked.
    2. Using the Subaru Select Monitor, check the following items in the [Data monitor] of [Body Control]. Refer to BODY CONTROL (DIAGNOSTICS)>DATA MONITOR .
      • Driver's seat lock status SW input
      • Passenger's seat lock status SW input
      • R gate lock status SW input

    Does the display indicate OFF (locked) for [Driver's seat lock status SW input] and [Passenger's seat lock status SW input], and ON (locked) for [R gate lock status SW input]?

    Yes:  Go to  9.

    No:  Check the door lock switch. Refer to SECURITY AND LOCKS>DOOR LOCK CONTROL SYSTEM .

  9. CHECK DATA MONITOR. 
    1. Turn the ignition switch to OFF.
    2. Using the Subaru Select Monitor, check the following items in the [Data monitor] of [Keyless Access with Push Button Start]. Refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS)>DATA MONITOR .
      • Push start SW 1
      • Push start SW 2
    3. Turn the ignition switch to ON.

    Does the display change from OFF to ON?

    Yes:  Go to  10.

    No:  Check the push button ignition switch. Refer to SECURITY AND LOCKS>KEYLESS ACCESS WITH PUSH BUTTON START SYSTEM .

  10. CHECK DATA MONITOR. 
    1. Turn the ignition switch to OFF.
    2. Using the Subaru Select Monitor, check the following items in the [Data monitor] of [Keyless Access with Push Button Start]. Refer to BODY CONTROL (DIAGNOSTICS)>DATA MONITOR .
      • IGB Output Status
    3. Operate RCC.
      NOTE: If RCC does not operate, turn the ignition switch to ON.

    Does the display change from OFF to ON?

    Yes:  Stop RCC or turn the ignition switch to OFF, Go to  11.

    No:  Check the push button ignition switch. Refer to SECURITY AND LOCKS>KEYLESS ACCESS WITH PUSH BUTTON START SYSTEM .

  11. PERFORM DIAGNOSTICS WITH PHENOMENON (KEYLESS ACCESS WITH PUSH BUTTON START). 

    Check the "Symptom Table" in "Diagnostics with Phenomenon" for the keyless access with push button start. Refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS)>DIAGNOSTICS WITH PHENOMENON>LIST .

    Is there a symptom that corresponds in the symptom table?

    Yes:  Perform diagnosis according to the procedures in the diagnostics with the corresponding phenomenon. Refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS)>DIAGNOSTICS WITH PHENOMENON>LIST .

    No:  Go to  12.

  12. PERFORM GENERAL DIAGNOSTICS (BODY CONTROL). 

    Check "General Diagnostic Table" for the body control. Refer to BODY CONTROL (DIAGNOSTICS)>GENERAL DIAGNOSTIC TABLE .

    Is there a symptom that corresponds in the symptom table?

    Yes:  Perform diagnosis according to the procedures in the corresponding general diagnostic table. Refer to BODY CONTROL (DIAGNOSTICS)>GENERAL DIAGNOSTIC TABLE .

    No:  The circuit has returned to a normal condition at this time. Reproduce the failure, and then perform the diagnosis again.

    NOTE: In this case, temporary poor contact of connector, temporary open or short circuit of harness may be the cause.
