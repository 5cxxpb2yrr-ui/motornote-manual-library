Front Washer Nozzle And Hose: Installation

CAUTION: Before installing the windshield glass and cowl panel, make sure there are no gravel in the installing area.
  1. Install the nozzle - windshield washer.
    1. Install the nozzle - windshield washer.
    2. Install the hose - windshield washer.
  2. Install the cowl panel - side and the cowl panel assembly. Refer to EXTERIOR/INTERIOR TRIM>COWL PANEL>INSTALLATION .
  3. Install the arm assembly - windshield wiper. Refer to WIPER AND WASHER SYSTEMS>FRONT WIPER ARM>INSTALLATION .
  4. Install the hose to the joint - washer hose. (Models with EyeSight)
    Courtesy of SUBARU OF AMERICA, INC.
  5. Install the cover - joint to the cowl panel assembly. (Models with EyeSight)
  6. Adjust the position of the nozzle - windshield washer. Refer to WIPER AND WASHER SYSTEMS>FRONT WASHER NOZZLE AND HOSE>ADJUSTMENT .
  7. Operate the windshield wiper to check that the stop position is aligned with the point mark. If it is not aligned with the point mark, perform the removal and installation of the windshield wiper over again. Refer to WIPER AND WASHER SYSTEMS>FRONT WIPER ARM>REMOVAL .
  8. Make sure that the hose and the cover - joint do not interfere during windshield wiper operation. (Models with EyeSight)
