DTC B2801: TCM Abnormal

Detected when error occurs in the transmission.

Detected when EyeSight operation is prohibited, because sufficient performance cannot be achieved due to the increased ATF (CVTF) temperature.

DTC detecting condition: 

  • Defective transmission
  • ATF temperature is high. (In this case, DTCs related to transmission are not detected.)

Trouble symptom: 

All functions of EyeSight system do not operate.

CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to EYESIGHT (DIAGNOSTICS) (EXCEPT FOR HEV)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK DTC. 

    Read the DTC of [EyeSight] using the Subaru Select Monitor. Refer to EYESIGHT (DIAGNOSTICS) (EXCEPT FOR HEV)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC U0101 displayed? (Current malfunction)

    Yes:  Perform the diagnosis for U0101. Refer to EYESIGHT (DIAGNOSTICS) (EXCEPT FOR HEV)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC U0101 LOST COMMUNICATION WITH TCM .

    No:  Go to  2.

  2. CHECK DTC. 

    Read the DTC of [Transmission] using the Subaru Select Monitor. Refer to TRANSMISSION (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC for transmission displayed? (Current malfunction)

    Yes:  Check the transmission. Refer to TRANSMISSION (DIAGNOSTICS)>BASIC DIAGNOSTIC PROCEDURE>PROCEDURE .

    No:  Check the AT OIL TEMP light display. Refer to TRANSMISSION (DIAGNOSTICS)>AT OIL TEMP WARNING LIGHT DISPLAY .
