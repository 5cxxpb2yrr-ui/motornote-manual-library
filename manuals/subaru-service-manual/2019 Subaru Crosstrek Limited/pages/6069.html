DTC C1BFF: Solenoid Valve Calibration Not Initialized: Notes

Do you like it dark? Easier on the eyes.

1. - 

DTC detecting condition: 

If linear valve offset learning value is not stored

  • If linear valve offset learning value is not stored (detail code 1133)
  • If linear valve offset learning value could not be obtained (detail code 1134)

Trouble symptom: 

  • Brake cannot be controlled. (Detail code 1133 only)
  • Regenerative brake cannot be controlled.
  • Brake assist does not operate.
  • EyeSight functions (ACC/PCS) do not operate.
  1. CHECK DTC. 
    1. Using the Subaru Select Monitor, perform the clear memory. Ref. to COMMON (DIAG)>CLEAR MEMORY .
    2. Read the DTC using Subaru Select Monitor. Ref. to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are DTCs other than C1BFF and C1A7F displayed?

    Yes:  Perform the diagnosis according to DTC. Ref. to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Go to  2.

  2. AIR BLEEDING FROM BRAKE SYSTEM. 
    1. Using the Subaru Select Monitor, perform the clear memory. Ref. to COMMON (DIAG)>CLEAR MEMORY .
    2. Using the Subaru Select Monitor, perform [Air Bleeding from Brake System] under [Brake System Bleeding] in [Work Support]. Ref. to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>WORK SUPPORT .

    Yes:  Go to  3.

    No:  -

  3. PERFORM LINEAR VALVE OFFSET LEARNING. 
    1. Check the following conditions.
      • Battery condition Ref. to STARTING/CHARGING SYSTEMS (H4DO (HEV))>BATTERY>INSPECTION .
      • The temperature of the brake actuator inside the brake booster assembly (with master cylinder) does not rise.
      • There is no abnormality in the hybrid system.
      • Shift position indicator shows P when the shifter is in P.
      • The READY sign inside the combination meter assembly illuminates.
      • Do not depress the brake pedal during linear valve offset learning.
      • Release the parking brake.
      • DTC C1C60 is not detected. (If this DTC is detected, bleed air from the high pressure tube brake system.)
    2. Using the Subaru Select Monitor, perform [Liner Valve Offset Learning] in [Work Support]. Ref. to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>WORK SUPPORT .

    Yes:  Go to  4.

    No:  -

  4. RECHECK DTC. 
    1. Using the Subaru Select Monitor, perform the clear memory. Ref. to COMMON (DIAG)>CLEAR MEMORY .
    2. Read the DTC using Subaru Select Monitor. Ref. to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC C1BFF displayed?

    Yes:  Replace the brake booster assembly (with the master cylinder). Ref. to BRAKE>BRAKE BOOSTER .

    No:  Finish the diagnosis.
