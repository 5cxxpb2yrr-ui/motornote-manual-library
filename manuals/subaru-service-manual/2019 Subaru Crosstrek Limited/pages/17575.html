Diagnostic procedure: 

  1. Check the readiness code using Subaru Select Monitor and confirm that the diagnosis is not completed. Refer to TRANSMISSION (DIAGNOSTICS)>ALL READINESS DIAGNOSTIC CODE(S) .
  2. Start the engine.
  3. Check the readiness code using Subaru Select Monitor, confirm that the diagnosis is completed, and end the procedure.
