Fuel Lid Opener (Except For Hybrid Model)

Do you like it dark? Easier on the eyes.

  1. Before installation, check the following items.
    • Cable is free from deformation such as fray.
  2. Install the cable assembly - trunk lid and the cable assembly - fuel.
  3. Install the trim panel - rear apron RH. (5 door model) Refer to EXTERIOR/INTERIOR TRIM>REAR QUARTER TRIM>INSTALLATION .
  4. Install the trim panel - trunk side RH. (4 door model) Refer to EXTERIOR/INTERIOR TRIM>TRUNK ROOM TRIM>INSTALLATION .
  5. Install the spacer - rear floor front.
  6. Install the mat - floor rear, spacer - side LH, and spacer - side RH. (5 door model)
  7. Install the trim panel - trunk mat and the spacer - CTR. (4 door model)
  8. Install the lower inner trim.
  9. Install the pull handle - opener.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  10. Install the cover - handle.
