DTC P0420: Catalyst System Efficiency Below Threshold Bank 1: Notes

Do you like it dark? Easier on the eyes.

1. - 

DTC detecting condition:

Detected when two consecutive driving cycles with fault occur.

Trouble symptom:

  • Engine stall
  • Idle mixture is out of specifications.
NOTE: After the faulty parts are repaired or replaced, perform the final check in Basic Diagnostic Procedure. Refer to ENGINE (DIAGNOSTICS) (H4DO (EXCEPT FOR HEV))>BASIC DIAGNOSTIC PROCEDURE>PROCEDURE .
  1. CHECK DTC AND FREEZE FRAME DATA  .
    1. Using the Subaru Select Monitor or a general scan tool, read the DTC of [Engine]. Refer to ENGINE (DIAGNOSTICS) (H4DO (EXCEPT FOR HEV))>DIAGNOSTIC TROUBLE CODE (DTC) .
    2. Read the freeze frame data. Refer to ENGINE (DIAGNOSTICS) (H4DO (EXCEPT FOR HEV))>FREEZE FRAME DATA . Refer to ENGINE (DIAGNOSTICS) (H4DO (EXCEPT FOR HEV))>GENERAL SCAN TOOL .
    3. Save the displayed DTC and freeze frame data.

      Is DTC other than P0420 displayed? (Current malfunction)

      Yes: 

      Check the appropriate DTC using the "Diagnostic Trouble Code (DTC)". Refer to ENGINE (DIAGNOSTICS) (H4DO (EXCEPT FOR HEV))>DIAGNOSTIC TROUBLE CODE (DTC) .

      No: 

      Go to  2.

  2. CHECK ENGINE OIL CONSUMPTION  .

    Check the engine oil amount. Refer to LUBRICATION (H4DO (EXCEPT FOR HEV))>ENGINE OIL .

    Is white smoke emitted from the muffler?

    Yes: 

    Check the engine, and repair the defective part. Refer to MECHANICAL (H4DO (EXCEPT FOR HEV))>SYMPTOMS AND CAUSES>INSPECTION .

    After repairing the engine, replace all catalytic converters. Refer to EMISSION CONTROL (AUX. EMISSION CONTROL DEVICES) (H4DO (EXCEPT FOR HEV))>FRONT CATALYTIC CONVERTER . Refer to EMISSION CONTROL (AUX. EMISSION CONTROL DEVICES) (H4DO (EXCEPT FOR HEV))>REAR CATALYTIC CONVERTER .

    No: 

    Go to  3.

  3. CHECK EXHAUST SYSTEM  .

    Check the following items regarding exhaust system.

    • Loose or detached nut and bolt
    • Exhaust gas leakage
    • Air suction
    • Hole on exhaust pipe

    Is there any trouble?

    Yes: 

    Repair or replace the exhaust system. Refer to EXHAUST (H4DO (EXCEPT FOR HEV))>GENERAL DESCRIPTION .

    No: 

    Go to  4.

  4. CHECK CATALYTIC CONVERTER  .
    1. Start the engine and warm up completely.
    2. Read the waveform data of rear oxygen sensor during idling using Subaru Select Monitor.
    3. Check the waveform by waggling the connector between ECM and rear oxygen sensor.
      • At normal condition

      Is an abnormal waveform displayed?

      Connect the connector after checking the following items, and check the waveform again while waggling.

      • Check the contact point of the connector that caused disturbed waveform. If faulty, repair or replace it.
      • If any problem is not found, It is possible that a temporary poor contact occurs in the connector.

      Replace all the catalytic converter. Refer to EMISSION CONTROL (AUX. EMISSION CONTROL DEVICES) (H4DO (EXCEPT FOR HEV))>FRONT CATALYTIC CONVERTER . Refer to EMISSION CONTROL (AUX. EMISSION CONTROL DEVICES) (H4DO (EXCEPT FOR HEV))>REAR CATALYTIC CONVERTER .
