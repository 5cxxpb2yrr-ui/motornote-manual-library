Air Cleaner Element: Installation

  1. Set the air cleaner element and install the air cleaner case (rear).
    CAUTION:
    • Be sure to use SUBARU genuine air cleaner element suitable to the engine type. Otherwise the engine performance may decrease.
    • Install the air cleaner element so that the printed surface is on the upper side.
    NOTE:
    • If any foreign matter is found in the air cleaner case, clean it.
    • Install by aligning the claws located on the bottom of the air cleaner case.
