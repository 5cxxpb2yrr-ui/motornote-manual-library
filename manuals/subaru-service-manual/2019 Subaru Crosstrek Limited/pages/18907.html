Brake Override

WARNING: This page is about a different variant/trim than selected.
NOTE:
  • Example:

    While driving the vehicle at approximately 10 km/h (6.2 MPH), depress the accelerator pedal to half to three-quarters of the way.

    With the accelerator pedal being depressed, if the driving torque is restrained when the brake pedal is depressed with the left leg, it can be judged that the brake override system is operating.

  • When the customer complains of deceleration feeling when he/she intentionally depresses both the accelerator pedal and the brake pedal, advise the customer not to depress both pedals. (Example: Operating the brake pedal with the left foot while operating the accelerator pedal)
CAUTION:
  • Perform this test in a location where the driving can be checked safely, while paying sufficient attention to the vicinity.
  • Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. CHECK DTC  .

    Using the Subaru Select Monitor, read all DTCs. Refer to COMMON (DIAG)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed?

    Yes:  Perform the diagnosis for the displayed DTCs.

    No:  Go to  2.

  2. CHECK DATA MONITOR (Master Cylinder Control Torque)  .

    Using the Subaru Select Monitor, display the following items in the [Data monitor] of [P-HEV Hybrid Powertrain Control]. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DATA MONITOR .

    • Master Cylinder Control Torque

    Does the display change according to the brake pedal force?

    Yes:  Go to  3.

    No:  Perform the diagnosis for the brake control. Refer to BRAKE CONTROL (DIAGNOSTICS)>BASIC DIAGNOSTIC PROCEDURE .

  3. CHECK DATA MONITOR (Accelerator Position Sensor No. 1 Voltage %, Accelerator Position Sensor No. 2 Voltage %)  .

    Using the Subaru Select Monitor, display the following items in the [Data monitor] of [P-HEV Hybrid Powertrain Control]. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DATA MONITOR .

    • Accelerator Position Sensor No. 1 Voltage %
    • Accelerator Position Sensor No. 2 Voltage %

    Does the display change according to accelerator pedal operation?

    Yes:  Go to  4.

    No:  Replace Accelerator pedal sensor. Refer to SPEED CONTROL SYSTEMS (H4DO (HEV))>GENERAL DESCRIPTION. Refer to ACCELERATOR PEDAL .

  4. CHECK DATA MONITOR (Vehicle Speed Sensor)  .

    Using the Subaru Select Monitor, display the following items in the [Data monitor] of [P-HEV Hybrid Powertrain Control]. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DATA MONITOR .

    • Vehicle Speed Sensor

    Is the data as follows?

    At stall: 0 km/h (0 MPH)

    During driving at a constant speed (16 - 64 km/h (10 - 40 MPH)): Displayed speed does not fluctuate widely

    Yes:  Go to  5.

    No:  Perform the diagnosis for combination meter. Refer to COMBINATION METER (DIAGNOSTICS)>BASIC DIAGNOSTIC PROCEDURE .

  5. CHECK DATA MONITOR (FR Wheel Speed, FL Wheel Speed, RR Wheel Speed, RL Wheel Speed)  .

    Using the Subaru Select Monitor, display the following items in the [Data monitor] of [Brake Control]. Refer to BRAKE CONTROL (DIAGNOSTICS)>DATA MONITOR .

    • FR Wheel Speed
    • FL Wheel Speed
    • RR Wheel Speed
    • RL Wheel Speed

    Is the data as follows?

    At stall: 0 km/h (0 MPH)

    During driving at a constant speed (16 - 64 km/h (10 - 40 MPH)): Displayed speed does not fluctuate widely

    Yes:  System is normal.

    No:  Perform the diagnosis for the brake control. Refer to BRAKE CONTROL (DIAGNOSTICS)>BASIC DIAGNOSTIC PROCEDURE .

GENERAL DESCRIPTION 

Explanation of circuits 

The brake override system performs control to restrain the driving torque, when the accelerator pedal and brake pedal are depressed during driving. Control operating conditions and control items are shown below.

Courtesy of SUBARU OF AMERICA, INC.

Control operating condition

  • When the accelerator pedal and brake pedal are depressed
    NOTE: Control may not be operated depending on the relationship between the accelerator pedal opening angle and speed.

Control items

  • Restraining of driving torque
    NOTE:
    • During the control operation, the torque requested by the accelerator pedal operation is restrained based on the amount of the brake pedal stroke.
    • When the driving torque is maximally restrained with the brake pedal strongly depressed together with accelerator pedal, the operation indicator is displayed on the meter. (The displayed operation indicator allows to visually confirm that the system is operating.)

Recovery conditions

  • When the accelerator pedal or the brake pedal is returned
