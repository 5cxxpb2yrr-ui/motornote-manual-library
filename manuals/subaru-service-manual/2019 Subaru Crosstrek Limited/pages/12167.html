System Block Diagram

Do you like it dark? Easier on the eyes.

  • A/C control & status display

    Using the CAN communication, perform A/C control from vehicle information and each sensor value to actuate the A/C system device. Also display A/C status on MFD by CAN output of A/C status.

  • Hazard is ON

    Output hazard switch signals to body integrated unit. The control of hazard illumination is carried out via body integrated unit.

  • Illumination

    Adjust the A/C control panel lighting according to input (body integrated unit & combination meter).

  • Engine control

    Transmit the A/C status via CAN for engine control.

  • Rear defogger operation

    Output switch signals to body integrated unit. The control of rear defogger operation is carried out via body integrated unit.

  • Mirror heater operation

    Output switch signals to body integrated unit. The control of mirror heater operation is carried out via body integrated unit.

  • Voice recognition

    Change the A/C setting according to voice input in combination with AVN.
