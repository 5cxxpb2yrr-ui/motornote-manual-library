Diagnostic Method

WARNING: This page is about a different variant/trim than selected.

Compare the diagnostic value with the threshold value, and if a condition meeting the criteria continues for 10s x 3time(s) or more, judge that there is a fault in the fuel system.

JUDGMENT VALUE SPECIFICATION

Malfunction Criteria Threshold Value
Offset amount of main feedback compensation 1.3 or more

Time needed for diagnosis:  10s x 3time(s)

Malfunction indicator light illumination:  Illuminates when malfunction occurs in 2 continuous driving cycles.
