Front Regulator and Motor Assembly: Installation

Do you like it dark? Easier on the eyes.

  1. Install the regulator and motor assembly - front.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  2. Install the glass assembly - front door. Refer to GLASS/WINDOWS/MIRRORS>FRONT DOOR GLASS>INSTALLATION>FRONT DOOR GLASS .
  3. Install the front sealing cover.
  4. Install the trim panel - front door.
  5. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY>GROUND TERMINAL REMOVAL OR INSTALLATION .
