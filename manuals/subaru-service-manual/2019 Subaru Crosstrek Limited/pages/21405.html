DTC P0A78-9E: Drive Motor "A" Inverter Stuck On: Notes

WARNING: This page is about a different variant/trim than selected.

1. - 

Detecting condition: 

Motor inverter fail signal detection (circuit malfunction)

(1 trip detection logic)

Trouble symptom: 

  • Greatly reduced output power
  • Driving in reverse not possible
  • A driving range is limited
  • Engine used while driving and engine speed becomes high
CAUTION:
  • Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to P-HEV DRIVE MOTOR (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  • After the check is finished, always replace the Inverter with converter assembly. (Because it may be damaged by inverter overheat) Refer to HYBRID ELECTRIC VEHICLE>INVERTER AND CONVERTER ASSEMBLY .
  1. CHECK DTC. 

    Read the DTC of [P-HEV Drive Motor] using the Subaru Select Monitor. Refer to P-HEV DRIVE MOTOR (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC P0A7873 displayed?

    Yes:  Perform the diagnosis of DTC P0A7873 Refer to P-HEV DRIVE MOTOR (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC P0A7873 DRIVE MOTOR "A" INVERTER ACTUATOR STUCK CLOSED . Go to  3.

    No:  Go to  2.

  2. CHECK DTC. 

    Read the following DTCs using Subaru Select Monitor. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) . Refer to P-HEV DRIVE MOTOR (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) . Refer to P-HEV HIGH VOLTAGE BATTERY (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .
