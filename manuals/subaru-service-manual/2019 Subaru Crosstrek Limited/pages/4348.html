Glove Box: Installation

CAUTION: The clips "C62" and "C63" shown in the figure may have different engaging forces. Always use the specified parts when installing.
  1. Install the back panel - pocket.
  2. Connect the connector, and install the glove box light LED.
  3. Install the ornament - panel assembly passenger.
    CAUTION: Make sure that the directions of the clip and claw, and insert until a clicking sound is heard.
  4. Install the under cover assembly - passenger.
  5. Install the pocket assembly.
  6. Install the cover - instrument panel side RH.
  7. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
