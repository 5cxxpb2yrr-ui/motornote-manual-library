DTC P3000-00: Hybrid/EV Battery Discharge Control Malfunction: Notes

WARNING: This page is about a different variant/trim than selected.

1. - 

Outline of diagnosis: 

When discharge of HV battery continues after discharge was prohibited because of HV battery capacity SOC lower limit due to HV battery system malfunction, etc., (1 trip detection logic)

Trouble symptom: 

Hybrid system stopped

CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to P-HEV HIGH VOLTAGE BATTERY (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
NOTE:
  • SOC, with HV battery still left uncharged, will be lowered below the limit if the vehicle still is left in N position (parked/stopped) for an extended period of time, which may result in DTC P300000 output.
  • Inability of engine start may disable charge to HV battery and cause DTC P300000 output. (This is not a system malfunction.)
  • DTC P300000 may be output due to decreased SOC caused by repeated engine start check. In this case, charge HV battery via plug-in charge.
  • SOC decreases by approx. 0.5% at one cranking.
  • Ten minutes' plug-in charge makes SOC recover by approx. 4.2% with AC120 V, and 8.4% with AC240 V.
  • If engine does not restart after repair, perform memory clear of DTCs and charge HV battery via plug-in charge.
  1. CHECK DTC. 

    Read the following DTCs using Subaru Select Monitor. Refer to P-HEV HIGH VOLTAGE BATTERY (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) . Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    • P-HEV High Voltage Battery
    • P-HEV Hybrid Powertrain Control

    When DTC P300000 or P300016 is displayed, go to  A.

    When DTCs related to [P-HEV High Voltage Battery] other than P300000 or P300016 is simultaneously displayed, go to  B.

    When DTCs related to [P-HEV Hybrid Powertrain Control] other than P300000 or P300016 is simultaneously displayed, go to  C.

    Yes: 

    1. Go to  2.
    2. Perform the diagnosis for the simultaneously displayed DTCs.
    3. Perform the diagnosis for the simultaneously displayed DTCs.

    No:  -

  2. CHECK DTC. 

    Read the DTC of [Engine Control System] using the Subaru Select Monitor. Refer to ENGINE (DIAGNOSTICS) (H4DO (HEV))>DIAGNOSTIC TROUBLE CODE (DTC) .

    Are any DTCs displayed?

    Yes:  Perform the diagnosis for the displayed DTCs. Refer to ENGINE (DIAGNOSTICS) (H4DO (HEV))>DIAGNOSTIC TROUBLE CODE (DTC) .

    No:  Go to  3.

  3. CHECK GASOLINE LEVEL. 
    1. Turn to IG ON.
    2. Check the gasoline level on the fuel gauge in the combination meter.

    Does gasoline remain?

    Yes:  Go to  4.

    No:  Refill gasoline.

    NOTE: Refill until the warning light on the fuel gauge goes off.
  4. CHECK ENGINE START. 
    1. Using the Subaru Select Monitor, read the value in [Shift Position] of [Freeze frame data] for DTC P300000. Refer to P-HEV HIGH VOLTAGE BATTERY (DIAGNOSTICS)>FREEZE FRAME DATA .
      CAUTION:
      • If the shift position indicates "N" in the freeze frame data, charge to HV battery is disabled, which may cause DTC P300000 to be detected.
      • When only "DTC P300000" is displayed, replacement of HV battery is unnecessary. Charge the HV battery.
    2. Check if the engine starts.
      NOTE:
      • Set the shift lever to "P" and depress the accelerator pedal and the engine starts.
      • If READY ON/OFF is repeated with SOC lowered, the SOC further decreases and the DTC P300016 may be displayed. Therefore, if necessary, perform charging via plug-in charge.
      • SOC decreases by approx. 0.5% at one cranking.
      • Ten minutes' plug-in charge makes SOC recover by approx. 4.2% with AC120 V, and 8.4% with AC240 V.

    Does the engine start?

    Yes:  Leave the shift lever placed in P and perform charging in the idling state until Auto Start Stop occurs.

    No:  Clear the memory of DTCs. Refer to COMMON (DIAG)>CLEAR MEMORY .

    Then perform charging via plug-in charge and check that the engine starts.
