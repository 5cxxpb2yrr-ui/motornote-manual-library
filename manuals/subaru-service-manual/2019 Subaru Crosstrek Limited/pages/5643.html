Initial Learning

  • When replacing the following parts, clear the stored values, then perform initial learning procedures.
  • Once the stored values from the initial learning (linear valve offset learning) are stored, they will not be recaptured unless the data is cleared.
Replacement parts Necessary operation
Brake booster assembly (with master cylinder)
  • Brake System Air Bleeding
  • Brake Line Air Bleeding
  • Erase Backup Memory
  • Learning Offset of Liner Solenoid Valve
Brake stroke sensor or brake pedal
  • Erase Backup Memory
  • Learning Offset of Liner Solenoid Valve
