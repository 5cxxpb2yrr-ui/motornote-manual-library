Current Sensor Offset Learning

WARNING: This page is about a different variant/trim than selected.
NOTE: Perform this work if the HV battery, battery ECU, or HV battery junction block assembly was replaced.
  1. Using the Subaru Select Monitor, select [HV battery current] from the list of Data Monitor items. Refer to P-HEV HIGH VOLTAGE BATTERY (DIAGNOSTICS)>DATA MONITOR .
  2. Turn to READY ON.
  3. Perform a driving test.
    CAUTION: Avoid sudden acceleration and deceleration, and accelerate and decelerate gradually while driving.
    1. Drive so that the HV battery current is within the range of -50 - 50 A.
    NOTE: The driving distance and driving duration are not specified.
  4. Turn IG OFF and leave for 30 seconds or more.
  5. Turn to IG ON.
  6. Using the Subaru Select Monitor, select [HV battery current] from the list of Data Monitor items. Refer to P-HEV HIGH VOLTAGE BATTERY (DIAGNOSTICS)>DATA MONITOR .
  7. Check that the HV battery current is within the range of -0.5 - 0.5 A.
CAUTION: If the HV battery current is not within the range of -0.5 - 0.5 A, perform the driving test again.
NOTE:
  • If the HV battery current is within the range of -0.5 - 0.5 A when IG is ON, then current sensor offset learning is completed.
  • Even if current sensor offset learning is not completed, the current sensor value will be corrected by performing the driving test up to maximum 7 times.
