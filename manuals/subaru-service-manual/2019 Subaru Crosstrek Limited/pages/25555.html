Registration Of Keyless Transmitter With SUBARU Select Monitor

Do you like it dark? Easier on the eyes.

NOTE:
  • A maximum of four keyless transmitters can be registered for each individual vehicle.
  • When replacing or adding the keyless transmitter, new registration of transmitter is necessary.
  1. Register the transmitter.
    1. Connect the Subaru Select Monitor.
      NOTE: For detailed operation procedures, refer to "Help" of application.
    2. Turn the ignition switch to ON.
    3. On [Start] screen, select [Diagnosis].
    4. On [Select Vehicle] screen, input the target vehicle information and select [OK].
    5. On [Main Menu] screen, select [Each System].
    6. On [Select System] screen, select [Keyless Entry], and then select [Next].
    7. On [Select Function] screen, select [Work Support].
    8. On [Work Support] screen, select [Keyless ID registration].
    9. According to the directions on the screen, press the button of the transmitter to be registered in order of Lock → Unlock. (When registration completed: Outside buzzer sounds once.)
      NOTE:
      • Repeat the procedure as many times as the number of transmitters to be registered.
      • When attempting to register a key that has already been registered, the external buzzer sounds twice.
    10. Press the Exit button to finish the operations.
