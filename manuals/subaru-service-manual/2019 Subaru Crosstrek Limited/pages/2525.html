The Steering Responsive Headlight Operates In A Direction Different From The Target

Detecting condition: 

Malfunction of VDC control module, LAN communication circuit, actuator power supply circuit, reverse signal circuit, switch circuit, actuator, auto headlight beam leveler control module power supply circuit, auto headlight beam leveler control module, alignment

Wiring diagram: 

Headlight beam leveler system. Refer to WIRING SYSTEM (IMPREZA MODEL)>HEADLIGHT BEAM LEVELER SYSTEM>WIRING DIAGRAM . Refer to WIRING SYSTEM (CROSSTREK MODEL (EXCEPT FOR HEV))>HEADLIGHT BEAM LEVELER SYSTEM>WIRING DIAGRAM . Refer to WIRING SYSTEM (CROSSTREK MODEL (HEV))>HEADLIGHT BEAM LEVELER SYSTEM>WIRING DIAGRAM .

Courtesy of SUBARU OF AMERICA, INC.
CAUTION:
  • Before performing diagnosis, check the fuse in this circuit. Refer to LIGHTING SYSTEM>RELAY AND FUSE .
  • Initialization is required after replacing the auto headlight beam leveler control module. Refer to LIGHTING SYSTEM>AUTO HEADLIGHT BEAM LEVELER SYSTEM>PROCEDURE .
  1. CHECK DTC. 
    1. Turn the ignition switch to OFF.
    2. Start the engine.
    3. Using the Subaru Select Monitor, perform the clear memory of [Headlight/Foglight]. Refer to COMMON (DIAG)>CLEAR MEMORY .
    4. Read the DTC of [Headlight/Foglight] using the Subaru Select Monitor. Refer to HEADLIGHT/FOGLIGHT (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

      Are any DTCs displayed? (Current malfunction)

      Yes:  Perform the diagnosis for the displayed DTCs. Refer to HEADLIGHT/FOGLIGHT (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

      No:  Go to  2.

  2. CHECK DTC. 
    1. Using the Subaru Select Monitor, read all DTCs. Refer to LAN SYSTEM (DIAGNOSTICS) (EXCEPT FOR HEV)>DIAGNOSTIC TROUBLE CODE (DTC) . Refer to LAN SYSTEM (DIAGNOSTICS) (HEV)>DIAGNOSTIC TROUBLE CODE (DTC) .

      Is DTC of U-code displayed? (Current malfunction)

      Yes:  Perform the diagnosis for LAN system. Refer to LAN SYSTEM (DIAGNOSTICS) (EXCEPT FOR HEV)>BASIC DIAGNOSTIC PROCEDURE>PROCEDURE . Refer to LAN SYSTEM (DIAGNOSTICS) (HEV)>BASIC DIAGNOSTIC PROCEDURE>PROCEDURE .

      No:  Go to  3.

  3. CHECK DTC. 

    Read the DTC of [Brake Control] using the Subaru Select Monitor. Refer to BRAKE CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is any DTC related to the vehicle speed and steering angle sensor displayed?

    Yes:  Perform the diagnosis for the displayed DTCs. Refer to BRAKE CONTROL (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .

    No:  Go to  4.

  4. CHECK INITIALIZE FUNCTION. 

    Perform the function check (the initialize function) for the steering responsive headlight. Refer to HEADLIGHT/FOGLIGHT (DIAGNOSTICS)>GENERAL DESCRIPTION>INSPECTION>BASIC INSPECTION .

    Do the left and right headlights operate?

    Yes:  Go to  5.

    No: 

    • Only one side does not operate: Go to  13.
    • Both sides do not operate: Go to  12.
  5. CHECK INPUT SIGNAL. 

    Using the Subaru Select Monitor, check the following items in the [Data monitor] of [Headlight/Foglight]. Refer to HEADLIGHT/FOGLIGHT (DIAGNOSTICS)>DATA MONITOR .

    • Vehicle speed signal
    • Steering Angle Signal

    Is [Vehicle speed signal] 8 km/h (5 MPH) or less, and [Steering Angle Signal] 8.5 deg or less?

    Yes:  Go to  6.

    No:  Perform the diagnosis for VDC. Refer to BRAKE CONTROL (DIAGNOSTICS)>BASIC DIAGNOSTIC PROCEDURE .

  6. CHECK SWIVEL ACTUATOR POWER SUPPLY. 

    Using the Subaru Select Monitor, check the following items in the [Data monitor] of [Headlight/Foglight]. Refer to HEADLIGHT/FOGLIGHT (DIAGNOSTICS)>DATA MONITOR .

    • Left Steering Responsive Headlight Power Supply Failure
    • Right Steering Responsive Headlight Power Supply Failure

    Is the target angle 0 degree?

    Yes:  Go to  9.

    No:  Go to  7.

  7. CHECK AUTO HEADLIGHT BEAM LEVELER control module POWER SUPPLY. 
    1. Turn the ignition switch to ON.
    2. Using the Subaru Select Monitor, check the following items in the [Data monitor] of [Headlight/Foglight]. Refer to HEADLIGHT/FOGLIGHT (DIAGNOSTICS)>DATA MONITOR .
      • Control module voltage

      Is the voltage 8 - 16 V?

      Yes:  Go to  8.

      No:  Check the battery and fuse. If no fault is found, check the auto headlight beam leveler control module power supply circuit.

  8. CHECK SWIVEL ACTUATOR POWER SUPPLY CIRCUIT. 
    1. Turn the ignition switch to OFF.
    2. Disconnect the headlight assembly connector.
    3. Turn the ignition switch to ON.
    4. Using a tester, measure the voltage between headlight assembly connector and chassis ground.

      Connector & terminal 

      (B487) No. 13 (+) - Chassis ground (-):

      (B477) No. 13 (+) - Chassis ground (-):

      Is the voltage 8 - 16 V?

      Yes:  Replace the auto headlight beam leveler control module. Refer to LIGHTING SYSTEM>AUTO HEADLIGHT BEAM LEVELER CONTROL MODULE .

      No:  Check the battery and fuse. If no fault is found, check the swivel actuator power supply circuit.

  9. CHECK SRH SWIVEL ACTUATOR CURRENT ANGLE. 

    Using the Subaru Select Monitor, check the following items in the [Data monitor] of [Headlight/Foglight]. Refer to HEADLIGHT/FOGLIGHT (DIAGNOSTICS)>DATA MONITOR .

    • Left Steering Responsive Headlight Current Angle
    • Right Steering Responsive Headlight Current Angle

    Is the current angle 0 degree?

    Yes:  Go to  12.

    No:  Go to  10.

  10. CHECK SWIVEL ACTUATOR POWER SUPPLY. 

    Using the Subaru Select Monitor, check the following items in the [Data monitor] of [Headlight/Foglight]. Refer to HEADLIGHT/FOGLIGHT (DIAGNOSTICS)>DATA MONITOR .

    • Left Steering Responsive Headlight Power Supply Failure
    • Right Steering Responsive Headlight Power Supply Failure

    Is [FAIL] displayed?

    Yes:  Check the battery and fuse. If no fault is found, check the swivel actuator power supply circuit.

    No:  Go to  11.

  11. CHECK SWIVEL ACTUATOR POWER SUPPLY CIRCUIT. 
    1. Turn the ignition switch to OFF.
    2. Disconnect the headlight assembly connector.
    3. Turn the ignition switch to ON.
    4. Using a tester, measure the voltage between headlight assembly connector and chassis ground.

      Connector & terminal 

      (B487) No. 13 (+) - Chassis ground (-):

      (B477) No. 13 (+) - Chassis ground (-):

      Is the voltage 8 - 16 V?

      Yes:  Replace the headlight assembly. Refer to LIGHTING SYSTEM>HEADLIGHT ASSEMBLY .

      No:  Check the battery and fuse. If no fault is found, check the swivel actuator power supply circuit.

  12. CHECK AUTO HEADLIGHT BEAM LEVELER control module POWER SUPPLY. 
    1. Turn the ignition switch to OFF.
    2. Using the Subaru Select Monitor, check the following items in the [Data monitor] of [Headlight/Foglight]. Refer to HEADLIGHT/FOGLIGHT (DIAGNOSTICS)>DATA MONITOR .
      • Control module voltage

      Is the voltage 8 - 16 V?

      Yes:  Go to  13.

      No:  Check the battery and fuse. If no fault is found, check the auto headlight beam leveler control module power supply circuit.

  13. CHECK SWIVEL ACTUATOR POWER SUPPLY. 

    Using the Subaru Select Monitor, check the following items in the [Data monitor] of [Headlight/Foglight]. Refer to HEADLIGHT/FOGLIGHT (DIAGNOSTICS)>DATA MONITOR .

    • Left Steering Responsive Headlight Power Supply Failure
    • Right Steering Responsive Headlight Power Supply Failure

    Is [FAIL] displayed?

    Yes:  Check the battery and fuse. If no fault is found, check the swivel actuator power supply circuit.

    No:  Go to  14.

  14. CHECK SWIVEL ACTUATOR POWER SUPPLY CIRCUIT. 
    1. Turn the ignition switch to OFF.
    2. Disconnect the headlight assembly connector.
    3. Turn the ignition switch to ON.
    4. Using a tester, measure the voltage between headlight assembly connector and chassis ground.

      Connector & terminal 

      (B487) No. 13 (+) - Chassis ground (-):

      (B477) No. 13 (+) - Chassis ground (-):

      Is the voltage 8 - 16 V?

      Yes:  Go to  15.

      No:  Check the battery and fuse. If no fault is found, check the swivel actuator power supply circuit.

  15. CHECK ACTIVE TEST OF SWIVEL ACTUATOR. 

    Using the Subaru Select Monitor, check the following items in the [Active Test] of [Headlight/Foglight]. Refer to HEADLIGHT/FOGLIGHT (DIAGNOSTICS)>ACTIVE TEST .

    • Right Steering Responsive Headlight
    • Left Steering Responsive Headlight

    Is the actuator current position value approximately the same as the input value of the actuator control position? (Within 1.2 seconds)

    Yes:  Go to  16.

    No:  When the value is not the same on one side only, replace the headlight assembly of the side where the same value is not achieved. Refer to LIGHTING SYSTEM>HEADLIGHT ASSEMBLY .

    When the value is not the same on both sides, replace the auto headlight beam leveler control module. Refer to LIGHTING SYSTEM>AUTO HEADLIGHT BEAM LEVELER CONTROL MODULE .

  16. DRIVING CHECK. 

    Perform the road test to make sure there is no yawing.

    Is it yawing?

    Yes:  Check the vehicle alignment. Refer to FRONT SUSPENSION>WHEEL ALIGNMENT .

    No:  The circuit has returned to a normal condition at this time. Reproduce the failure, and then perform the diagnosis again.

    NOTE: In this case, temporary poor contact of connector, temporary open or short circuit of harness may be the cause.
