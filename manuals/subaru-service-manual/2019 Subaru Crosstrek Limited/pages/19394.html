Security And Locks - Keyless Access (W/Push Button Start) (Diagnostics): Customize: Operation

Do you like it dark? Easier on the eyes.

NOTE: 4 door model only.
  1. On [Start] display, select [Diagnosis].
  2. On [Select Vehicle] display, input the target vehicle information and select [OK].
  3. On [Main Menu] display, select [Each System].
  4. On [Select System] display, select [Keyless Access with Push Button Start], and then select [Next].
  5. On [Select Function] display, select [Customize].
    NOTE:
    • For detailed operation procedures, refer to "Help" of application.
    • For details on customization, refer to the list. Refer to KEYLESS ACCESS WITH PUSH BUTTON START (DIAGNOSTICS)>CUSTOMIZE>LIST .
