Fuel Lid

Do you like it dark? Easier on the eyes.

EXCEPT FOR HYBRID MODEL 

  1. Install the saucer - COMPL.
    NOTE: Securely install the rubber portion of the saucer - COMPL to the fuel filler pipe assembly.
  2. Attach the ring clips.
    CAUTION: Do not reuse the ring clip and replace with a new part, because engagement of the claw weakens.
  3. Install the fuel filler pipe protector.
  4. Install the fuel filler cap.
  5. Install the flap - COMPL fuel.
  6. Install the drain filter assembly. Refer to EMISSION CONTROL (AUX. EMISSION CONTROL DEVICES) (H4DO (EXCEPT FOR HEV))>DRAIN FILTER>INSTALLATION .
  7. Install the mud guard - rear RH. Refer to EXTERIOR/INTERIOR TRIM>MUD GUARD>INSTALLATION .
  8. Install the cable assembly - fuel.
  9. Install the trim panel - rear apron RH. (5 door model) Refer to EXTERIOR/INTERIOR TRIM>REAR QUARTER TRIM>INSTALLATION>5 DOOR MODEL (EXCEPT FOR HYBRID) .
  10. Install the trim panel - trunk side RH. (4 door model) Refer to EXTERIOR/INTERIOR TRIM>TRUNK ROOM TRIM>INSTALLATION .

HYBRID MODEL 

  1. Install the saucer - COMPL.
    NOTE: Securely install the rubber portion of the saucer - COMPL to the fuel filler pipe assembly.
  2. Attach the ring clips.
    CAUTION: Do not reuse the ring clip and replace with a new part, because engagement of the claw weakens.
  3. Install the fuel filler pipe protector.
  4. Install the fuel filler cap.
  5. Install the flap - COMPL fuel.
  6. Install the drain filter assembly. Refer to EMISSION CONTROL (AUX. EMISSION CONTROL DEVICES) (H4DO (EXCEPT FOR HEV))>DRAIN FILTER>INSTALLATION .

  8. Install the lock assembly - fuel.
  9. Connect the fuel flap status switch connector.
  10. Install the battery cooling blower assembly. Refer to HYBRID ELECTRIC VEHICLE>HIGH VOLTAGE BATTERY COOLING SYSTEM>INSTALLATION>COOLING BLOWER .
  11. Install the trim panel - rear apron RH. Refer to EXTERIOR/INTERIOR TRIM>REAR QUARTER TRIM>INSTALLATION>5 DOOR MODEL (HYBRID) .
