Heater and Cooling Unit: Installation

CAUTION:
  • Since the auto A/C model uses the variable displacement compressor, be careful of the following items.
    • Do not start the engine before charging refrigerant.
    • If the engine is started with no refrigerant charge, replace the compressor assembly.
  • Replace the O-rings with new parts, and then apply compressor oil to install completely.
  • Before handling the airbag system components, refer to "CAUTION" of "General Description" in "AIRBAG SYSTEM". Refer to AIRBAG SYSTEM>GENERAL DESCRIPTION>CAUTION .
  1. Install the blower motor unit assembly.
  2. Install the heater and cooling unit assembly.

    Tightening torque: 

    7.5 N.m (0.8 kgf-m, 5.5 ft-lb)

  3. Install the hose - drain.
  4. Install the duct - foot. Refer to AIR CONDITIONER (EXCEPT FOR HEV)>HEATER DUCT>INSTALLATION>FOOT .
  5. Install the duct - rear heater front. Refer to AIR CONDITIONER (EXCEPT FOR HEV)>HEATER DUCT>INSTALLATION>FRONT .
  6. Install the instrument panel assembly and the beam COMPL - steering. Refer to EXTERIOR/INTERIOR TRIM>INSTRUMENT PANEL ASSEMBLY>INSTALLATION .
  7. Install the hose - heater outlet and the hose - heater inlet.
  8. Install the expansion valve - cooling. Refer to AIR CONDITIONER (EXCEPT FOR HEV)>EXPANSION VALVE>INSTALLATION .
  9. Install the air intake boot. Refer to INTAKE (INDUCTION) (H4DO (EXCEPT FOR HEV))>Air Intake Boot>INSTALLATION .
  10. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
  11. Charge refrigerant. Refer to AIR CONDITIONER (EXCEPT FOR HEV)>REFRIGERANT CHARGING PROCEDURE>PROCEDURE .
  12. Fill engine coolant. Refer to COOLING (H4DO (EXCEPT FOR HEV))>ENGINE COOLANT>REPLACEMENT .
