Crossmember Support: Installation

  1. Install the crossmember support - front and the crossmember support - rear.

    Tightening torque: 

    Crossmember support - front: 60 N.m (6.1 kgf-m, 44.3 ft-lb)

    Crossmember support - rear: 70 N.m (7.1 kgf-m, 51.6 ft-lb)

  2. Install the under cover - front.

    Tightening torque: 

    18 N.m (1.8 kgf-m, 13.3 ft-lb)
