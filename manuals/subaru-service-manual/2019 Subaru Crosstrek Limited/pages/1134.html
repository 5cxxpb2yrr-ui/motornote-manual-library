Basic Diagnostic Procedure: Procedure

  1. PERFORM CUSTOMER INTERVIEW. 

    Ask the customer when and how the trouble occurred using the interview check list. Refer to BLIND SPOT DETECTION/REAR CROSS TRAFFIC ALERT (DIAGNOSTICS)>CHECK LIST FOR INTERVIEW .

    Did you interview the customer?

    Yes:  Go to  2.

    No:  Perform the interview, and Refer to BLIND SPOT DETECTION/REAR CROSS TRAFFIC ALERT (DIAGNOSTICS)>CHECK LIST FOR INTERVIEW .

  2. PERFORM BASIC INSPECTION. 

    Perform basic inspection.

    Is the check result OK?

    Yes:  Go to  3.

    No:  Repair the faulty part found in basic inspection, and Go to  3.

  3. CHECK SUBARU SELECT MONITOR COMMUNICATION. 
    1. Turn the ignition switch to OFF.
    2. Connect the Subaru Select Monitor to data link connector. Refer to COMMON (DIAG)>DATA LINK CONNECTOR .
    3. Turn the ignition switch to ON and run the Subaru Select Monitor.
    4. Select [Blind Spot Detection/Rear Cross Traffic Alert (RH)] or [Blind Spot Detection/Rear Cross Traffic Alert (LH)].
      NOTE: For detailed operation procedures, refer to "Help" of application.

    Is communication possible?

    Yes:  Go to  4.

    No:  Check the communication circuit. Refer to BLIND SPOT DETECTION/REAR CROSS TRAFFIC ALERT (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE FOR SUBARU SELECT MONITOR COMMUNICATION .

  4. CHECK DTC AND CANCEL CODE. 

    Using the Subaru Select Monitor, read the DTCs and cancel codes of [Blind Spot Detection/Rear Cross Traffic Alert (RH)] or [Blind Spot Detection/Rear Cross Traffic Alert (LH)]. Refer to BLIND SPOT DETECTION/REAR CROSS TRAFFIC ALERT (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) . Refer to BLIND SPOT DETECTION/REAR CROSS TRAFFIC ALERT (DIAGNOSTICS)>CANCEL CODE .

    • Blind Spot Detection/Rear Cross Traffic Alert (RH)
    • Blind Spot Detection/Rear Cross Traffic Alert (LH)

    Is any DTC or cancel code displayed? (Current malfunction)

    Yes:  Record the DTC, time stamp and freeze frame data, and Go to  5.

    No:  Perform diagnosis according to the procedures in the diagnostics with phenomenon. Refer to BLIND SPOT DETECTION/REAR CROSS TRAFFIC ALERT (DIAGNOSTICS)>DIAGNOSTICS WITH PHENOMENON .

  5. PERFORM DIAGNOSIS. 
    1. Perform the diagnosis for the displayed DTCs or cancel codes. (Perform the diagnosis for the side that displayed DTCs or cancel codes.) Refer to BLIND SPOT DETECTION/REAR CROSS TRAFFIC ALERT (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST . Refer to BLIND SPOT DETECTION/REAR CROSS TRAFFIC ALERT (DIAGNOSTICS)>CANCEL CODE>LIST .
    2. Repair or replace the cause of trouble.
    3. Using the Subaru Select Monitor, perform the clear memory of [Blind Spot Detection/Rear Cross Traffic Alert (RH)] or [Blind Spot Detection/Rear Cross Traffic Alert (LH)]. Refer to COMMON (DIAG)>CLEAR MEMORY .
      • Blind Spot Detection/Rear Cross Traffic Alert (RH)
      • Blind Spot Detection/Rear Cross Traffic Alert (LH)
    4. Execute the inspection mode. Refer to BLIND SPOT DETECTION/REAR CROSS TRAFFIC ALERT (DIAGNOSTICS)>INSPECTION MODE .
    5. Using the Subaru Select Monitor, read the DTCs or cancel codes of [Blind Spot Detection/Rear Cross Traffic Alert (RH)] or [Blind Spot Detection/Rear Cross Traffic Alert (LH)]. Refer to BLIND SPOT DETECTION/REAR CROSS TRAFFIC ALERT (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) . Refer to BLIND SPOT DETECTION/REAR CROSS TRAFFIC ALERT (DIAGNOSTICS)>CANCEL CODE .
      • Blind Spot Detection/Rear Cross Traffic Alert (RH)
      • Blind Spot Detection/Rear Cross Traffic Alert (LH)

    Is any DTC or cancel code displayed? (Current malfunction)

    Yes:  Repeat step  5 until DTC is not shown. Go to  5.

    No:  Finish the diagnosis.
