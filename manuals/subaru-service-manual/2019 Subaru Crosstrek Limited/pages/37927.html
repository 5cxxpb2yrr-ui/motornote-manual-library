Other Than For C5

Do you like it dark? Easier on the eyes.

Diagnosis start condition: 

  • Battery voltage is 10 V or more.
  • The remote engine starter was not used to start the engine.

DTC detecting condition: 

Communication failure between ignition key and body integrated unit

Trouble symptom: 

  • Engine will not start.
  • The security indicator illuminates.
CAUTION: When the body integrated unit is replaced, registration of the immobilizer system is required. For details, refer to the "REGISTRATION INSTRUCTIONS FOR IMMOBILIZER" provided as a separate volume.
  1. CHECK IGNITION KEY. 
    1. Remove the ignition key from the ignition switch.
    2. Insert the ignition key into the ignition switch, and then turn the ignition switch to ON.
    3. Using the Subaru Select Monitor, perform the clear memory of [Body Control]. Refer to COMMON (DIAG)>CLEAR MEMORY .
    4. Read the DTC of [Body Control] using the Subaru Select Monitor. Refer to IMMOBILIZER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

      Is DTC B1410 displayed? (Current malfunction)

      Yes:  Go to  2.

      No:  Even if DTC is displayed, the circuit has returned to a normal condition at this time. Reproduce the failure, and then perform the diagnosis again.

      NOTE: It is possible that the surrounding radio wave environment was poor.
  2. CHECK IGNITION KEY. 
    1. Prepare a spare ignition key that is already registered.
    2. Insert the ignition key into the ignition switch, and then turn the ignition switch to ON.
    3. Read the DTC of [Body Control] using the Subaru Select Monitor. Refer to IMMOBILIZER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

      Is DTC B1410 displayed? (Current malfunction)

      Yes:  Go to  3.

      No:  Malfunction occurred in ignition key. Or the key has not been registered.

  3. CHECK DTC. 

    Read the DTC of [Body Control] using the Subaru Select Monitor. Refer to IMMOBILIZER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC B1411 displayed? (Current malfunction)

    Yes:  Perform the diagnosis of DTC B1411. Refer to IMMOBILIZER (DIAGNOSTICS)>DIAGNOSTIC PROCEDURE WITH DIAGNOSTIC TROUBLE CODE (DTC)>DTC B1411 IMMOBILIZER ANTENNA .

    No:  Go to  4.

  4. CHECK IMMOBILIZER ANTENNA. 
    1. Insert the ignition key into the ignition switch, and then turn the ignition switch to ON.
    2. Using the Subaru Select Monitor, perform the clear memory of [Body Control]. Refer to COMMON (DIAG)>CLEAR MEMORY .
    3. Read the DTC of [Body Control] using the Subaru Select Monitor. Refer to IMMOBILIZER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC) .

      Is DTC B1410 displayed? (Current malfunction)

      Yes:  Replace the body integrated unit. Refer to SECURITY AND LOCKS>BODY INTEGRATED UNIT .

      No:  Malfunction occurred in the immobilizer antenna, ignition key or body integrated unit.
