Rear Duct

WARNING: This page is about a different variant/trim than selected.
  • LH SIDE 
    CAUTION: Airbag system satellite safing sensor is located under the front center of the rear seat cushion. Be careful not to apply strong impact to the sensor when working with the rear seat cushion removed.
    1. Install the duct assembly - cooling out.
    2. Install the trim panel - rear apron LH. Refer to EXTERIOR/INTERIOR TRIM>REAR QUARTER TRIM>INSTALLATION .
    3. Install the rear seat cushion assembly. Refer to SEATS>REAR SEAT>INSTALLATION .
    4. Install the mat - rear floor.
    5. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
  • RH SIDE 
CAUTION: Airbag system satellite safing sensor is located under the front center of the rear seat cushion. Be careful not to apply strong impact to the sensor when working with the rear seat cushion removed.
  1. Install the duct assembly - cooling out No. 1.
  2. Install the duct assembly - cooling out No. 2.
  3. Install the trim panel - rear apron RH. Refer to EXTERIOR/INTERIOR TRIM>REAR QUARTER TRIM>INSTALLATION .
  4. Install the rear seat cushion assembly. Refer to SEATS>REAR SEAT>INSTALLATION .
  5. Install the mat - rear floor.
  6. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
