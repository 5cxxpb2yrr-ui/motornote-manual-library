Diagnostic Method

WARNING: This page is about a different variant/trim than selected.

Judge as NG if a status where the judgment value is satisfied lasts for the predetermined time or more.

JUDGMENT VALUE SPECIFICATION

Malfunction Criteria Threshold Value
Status of engine start command from HV system With start command

Time needed for diagnosis: 

  • Diagnosis period: 10 s (water temperature 10°C (50°F))
  • Diagnosis period: 5 s (water temperature 20°C (68°F))

Malfunction indicator light illumination:  Does not illuminate.
