Front Differential Assembly: Installation

  1. Install the front differential assembly to the converter case.
    NOTE: Be careful not to damage the inside of the case (especially the mounting surface of the differential side retainers).
    Courtesy of SUBARU OF AMERICA, INC.
  2. Install the bearing outer race.
  3. Temporarily install the differential side retainers using the ST.

    Preparation tool: 

    ST: WRENCH COMPL RETAINER (18658AA020)

    Courtesy of SUBARU OF AMERICA, INC.
  4. Adjust the backlash of the front differential. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>FRONT DIFFERENTIAL ASSEMBLY>ADJUSTMENT .
  5. Inspect and adjust the tooth contact. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>DRIVE PINION SHAFT ASSEMBLY>ADJUSTMENT .
  6. Using the ST, loosen the differential side retainer until the mounting groove of the O-ring appears, and then install the O-ring.
    NOTE:
    • When loosening the differential side retainer, record the number of the turns made.
    • Perform this for both left and right differential side retainers.
    • Use new O-rings.
    • Apply the differential gear oil to O-ring.

    Preparation tool: 

    ST: WRENCH COMPL RETAINER (18658AA020)

  7. Using the ST, tighten the retainer to the position before it is loosened.

    Preparation tool: 

    ST: WRENCH COMPL RETAINER (18658AA020)

  8. Install the oil seal to the differential side retainer. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>DIFFERENTIAL SIDE RETAINER OIL SEAL .
  9. Install the lock plate.

    Tightening torque: 

    25 N.m (2.5 kgf-m, 18.4 ft-lb)

    Courtesy of SUBARU OF AMERICA, INC.
  10. Install the oil baffle.
    Courtesy of SUBARU OF AMERICA, INC.
  11. Install the drive pinion shaft assembly. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>DRIVE PINION SHAFT ASSEMBLY>INSTALLATION .
  12. Install the forward clutch assembly. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>FORWARD CLUTCH ASSEMBLY>INSTALLATION .
  13. Install the reverse brake assembly. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>REVERSE BRAKE ASSEMBLY>INSTALLATION .
  14. Install the primary pulley, secondary pulley and variator chain. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>PRIMARY PULLEY AND SECONDARY PULLEY>INSTALLATION .
  15. Install the reduction drive gear. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>REDUCTION DRIVE GEAR>INSTALLATION .
  16. Install the transmission case. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSMISSION CASE>INSTALLATION .
  17. Install the oil strainer and oil pan. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>OIL PAN AND STRAINER>INSTALLATION .
  18. Install the transmission control device. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSMISSION CONTROL DEVICE>INSTALLATION .
  19. Install the reduction driven gear assembly. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>REDUCTION DRIVEN GEAR>INSTALLATION .
  20. Install the parking pawl. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>PARKING PAWL>INSTALLATION .
  21. Install the transfer driven gear assembly. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSFER DRIVEN GEAR>INSTALLATION .
  22. Install the transfer clutch assembly. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSFER CLUTCH>INSTALLATION .
  23. Install the extension case. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>EXTENSION CASE>INSTALLATION .
  24. Install the inhibitor switch. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>INHIBITOR SWITCH>INSTALLATION .
  25. Install the secondary speed sensor. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>SECONDARY SPEED SENSOR>INSTALLATION .
  26. Install the primary speed sensor. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>PRIMARY SPEED SENSOR>INSTALLATION .
  27. Install the turbine speed sensor. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TURBINE SPEED SENSOR>INSTALLATION .
  28. Install the transmission harness. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>TRANSMISSION HARNESS>INSTALLATION .
  29. Install the control valve body. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>CONTROL VALVE BODY>INSTALLATION .
  30. Install the air breather hose. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>AIR BREATHER HOSE>INSTALLATION .
  31. Install the transmission assembly to the vehicle. Refer to CONTINUOUSLY VARIABLE TRANSMISSION (TR580)>AUTOMATIC TRANSMISSION ASSEMBLY>INSTALLATION .
