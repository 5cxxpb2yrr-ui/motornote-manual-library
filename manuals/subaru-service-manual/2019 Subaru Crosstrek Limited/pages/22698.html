Diagnostic Trouble Code (DTC): Operation

  1. On [Start] display, select [Diagnosis].
  2. On [Vehicle selection] display, input the target vehicle information and select [OK].
  3. On [Main Menu] display, select [All diagnosis code].
    NOTE:
    • For detailed operation procedures, refer to "Help" of application.
    • For details on DTCs, refer to the list. Refer to LAN SYSTEM (DIAGNOSTICS) (EXCEPT FOR HEV)>CAN COMMUNICATION CIRCUIT CHECK>LIST .
