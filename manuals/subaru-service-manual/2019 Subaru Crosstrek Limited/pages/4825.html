Diagnostic Method

Do you like it dark? Easier on the eyes.

Difference between the current power supply voltage ratio and the previous power supply voltage ratio of brake stroke sensor input 2 and brake stroke sensor power supply 2 is higher than 8.48%.

JUDGMENT VALUE SPECIFICATION

Malfunction Criteria Threshold Value
ABS (Current brake stroke sensor input 2/Brake stroke sensor power supply 2 - Last brake stroke sensor input 2/Brake stroke sensor power supply 2) More than 0.0848

Time needed for diagnosis:  200 ms

Malfunction indicator light illumination:  Illuminates as soon as a malfunction occurs.
