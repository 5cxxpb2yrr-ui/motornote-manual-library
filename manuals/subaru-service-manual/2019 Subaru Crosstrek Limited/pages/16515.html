DTC B224A: Backup Camera

DTC detecting condition: 

Detected when the synchronization error occurs in the condition of the picture input.

Trouble symptom: 

Camera image does not appear.

Wiring diagram: 

Rearview camera system Refer to WIRING SYSTEM (IMPREZA MODEL)>REARVIEW CAMERA SYSTEM>WIRING DIAGRAM . Refer to WIRING SYSTEM (CROSSTREK MODEL (EXCEPT FOR HEV))>REARVIEW CAMERA SYSTEM>WIRING DIAGRAM . Refer to WIRING SYSTEM (CROSSTREK MODEL (HEV))>REARVIEW CAMERA SYSTEM>WIRING DIAGRAM .

Navigation system Refer to WIRING SYSTEM (IMPREZA MODEL)>NAVIGATION SYSTEM>WIRING DIAGRAM . Refer to WIRING SYSTEM (CROSSTREK MODEL (EXCEPT FOR HEV))>NAVIGATION SYSTEM>WIRING DIAGRAM . Refer to WIRING SYSTEM (CROSSTREK MODEL (HEV))>NAVIGATION SYSTEM>WIRING DIAGRAM .

Audio system Refer to WIRING SYSTEM (IMPREZA MODEL)>AUDIO SYSTEM>WIRING DIAGRAM . Refer to WIRING SYSTEM (CROSSTREK MODEL (EXCEPT FOR HEV))>AUDIO SYSTEM>WIRING DIAGRAM . Refer to WIRING SYSTEM (CROSSTREK MODEL (HEV))>AUDIO SYSTEM>WIRING DIAGRAM .

Back-up light system Refer to WIRING SYSTEM (IMPREZA MODEL)>BACK-UP LIGHT SYSTEM>WIRING DIAGRAM . Refer to WIRING SYSTEM (CROSSTREK MODEL (EXCEPT FOR HEV))>BACK-UP LIGHT SYSTEM>WIRING DIAGRAM . Refer to WIRING SYSTEM (CROSSTREK MODEL (HEV))>BACK-UP LIGHT SYSTEM>WIRING DIAGRAM .
