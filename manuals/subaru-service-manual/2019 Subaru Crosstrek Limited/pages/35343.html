Diagnostic Trouble Code (DTC): Operation: Notes

Do you like it dark? Easier on the eyes.

NOTE:
  • Refer to "COMMON (diag)". Ref. to COMMON (diag)>DIAGNOSTIC TROUBLE CODE (DTC) .
  • For details on DTCs, refer to the list. Ref. to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>LIST .
CAUTION:
  • To perform memory clear of failure information related to the following DTCs, first perform "Preparation for Memory Clear". Ref. to ELECTRIC BRAKE BOOSTER (DIAGNOSTICS)>DIAGNOSTIC TROUBLE CODE (DTC)>OPERATION>PREPARATION FOR MEMORY CLEAR .
  • Do not perform this memory clear unless the defective area is identified and repair is completed. Otherwise, the vehicle condition may become hazardous.
