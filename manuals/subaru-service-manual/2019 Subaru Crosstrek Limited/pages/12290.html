Manual A/C Model

Do you like it dark? Easier on the eyes.

  1. Install the cable - mode and the cable - temperature.
  2. Install the panel assembly - heater.
  3. Install the heater control assembly.
    CAUTION: Install the heater control assembly so that each cable position and heater control assembly dial position are the same.
  4. Install the pocket assembly and the back panel - pocket. Refer to EXTERIOR/INTERIOR TRIM>GLOVE BOX>INSTALLATION .
  5. Install the audio assembly or navigation assembly. Refer to ENTERTAINMENT & MONITORING>AUDIO>INSTALLATION .
  6. Install the grille assembly - CTR ventilation.
  7. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY .
