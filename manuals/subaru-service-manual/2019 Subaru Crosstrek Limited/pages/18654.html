Parking Brake Lever: Installation

Do you like it dark? Easier on the eyes.

  1. Install the inner cable end to equalizer.
  2. Install the lever assembly - hand brake.

    Tightening torque: 

    18 N.m (1.8 kgf-m, 13.3 ft-lb)

    CAUTION: Do not reuse the adjusting nut (self locking nut). Always replace with a new part.
  3. Be sure to adjust the lever stroke. Refer to PARKING BRAKE>PARKING BRAKE LEVER>ADJUSTMENT .
  4. Install the console box assembly.

    Tightening torque: 

    6.5 N.m (0.7 kgf-m, 4.8 ft-lb)

  5. Install the driver's seat. Refer to SEATS>FRONT SEAT>INSTALLATION .
  6. Connect the battery ground terminal. Refer to REPAIR CONTENTS>REPAIR CONTENTS>NOTE>BATTERY>GROUND TERMINAL REMOVAL OR INSTALLATION .
NOTE: For CVT models, after connecting the battery ground terminal, place the select lever in the P position.
