VDCCM Parameter Reading

  1. Perform reading of parameter.
    1. Connect the Subaru Select Monitor.
      NOTE: For detailed operation procedures, refer to "Help" of application.
    2. Turn the ignition switch to ON.
    3. On [Start] display, select [Diagnosis].
    4. On [Select Vehicle] display, input the target vehicle information and select [Set].
    5. On [Main Menu] display, select [Each System].
    6. On [Select System] display, select [Brake Control], and then select [Enter].
    7. On [Select Function] display, select [Work Support].
    8. On [Work Support] display, select [Reading of parameter: ECM to SSM].
  2. Save and close the file.
