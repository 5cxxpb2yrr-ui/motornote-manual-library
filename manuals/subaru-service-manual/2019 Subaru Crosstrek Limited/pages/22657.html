Basic Diagnostic Procedure: Procedure

Do you like it dark? Easier on the eyes.

CAUTION: Before performing diagnosis, refer to "CAUTION" in "General Description". Refer to CRUISE CONTROL (DIAGNOSTICS)>GENERAL DESCRIPTION>CAUTION .
  1. PERFORM CUSTOMER INTERVIEW. 

    Ask the customer when and how the trouble occurred using the interview check list. Refer to CRUISE CONTROL (DIAGNOSTICS)>CHECK LIST FOR INTERVIEW .

    Did you interview the customer?

    Yes:  Go to  2.

    No:  Perform the interview, and Go to  2.

  2. CHECK MALFUNCTION INDICATOR LIGHT. 

    Make sure the malfunction indicator light illuminates.

    Does the malfunction indicator light illuminate?

    Yes:  Go to  6.

    No:  Go to  3.

  3. CHECK CRUISE INDICATOR LIGHT. 

    Make sure the cruise indicator light blinks.

    Does the cruise indicator light blink?

    Yes:  Go to  8.

    No:  Go to  4.

  4. CHECK CRUISE SWITCH OPERATION. 

    Check the CRUISE switch operation. (Check the illumination of the CRUISE indicator.)

    Is the CRUISE switch turned to ON? (Does the CRUISE indicator illuminate?)

    Yes:  Go to  5.

    No:  Go to phenomenon 1. Refer to CRUISE CONTROL (DIAGNOSTICS)>DIAGNOSTICS WITH PHENOMENON>DIAGNOSTIC PROCEDURE WITH PHENOMENON .

  5. CHECK CRUISE CONTROL SET OPERATION. 

    Check the cruise control setting operation.

    Can the cruise control be set while driving at 40 km/h (25 MPH) or more?

    Yes:  Go to  9.

    No:  Go to  8.

  6. CHECK DTC. 

    Using the Subaru Select Monitor, read all DTCs. Refer to COMMON (diag)>DIAGNOSTIC TROUBLE CODE (DTC) .

    Is DTC related to engine or ABS/VDC displayed? (Current malfunction)

    Yes:  Record the DTC. Go to  7.

    No:  Go to phenomenon 2. Refer to CRUISE CONTROL (DIAGNOSTICS)>DIAGNOSTICS WITH PHENOMENON>DIAGNOSTIC PROCEDURE WITH PHENOMENON .

  7. CHECK FREEZE FRAME DATA. 

    Using the Subaru Select Monitor, check the Freeze Frame Data or Information in Trouble State.

    Was the Freeze Frame Data or Information in Trouble State recorded?

    Yes:  Record the data. Perform the inspection according to the engine or ABS/VDC related DTC.

    No:  Perform the inspection according to the engine or ABS/VDC related DTC.

  8. CHECK CANCEL CODE. 

    Read the cancel codes using the Subaru Select Monitor. Refer to CRUISE CONTROL (DIAGNOSTICS)>CANCEL CODE .

    NOTE:
    • Do not turn the ignition switch to OFF after the cruise control is deactivated.
    • Do not operate the cruise control command switch after the cruise control is deactivated.

    If the above is performed, the cancel code will be cleared.

    Is a cancel code displayed?

    Yes:  Perform the diagnosis according to the cancel code. Refer to CRUISE CONTROL (DIAGNOSTICS)>CANCEL CODE>LIST .

    No:  Go to  9.

  9. INSPECTION OF SET INDICATOR. 

    Check the illumination of the SET indicator.

    Does the SET indicator illuminate?

    Yes:  Go to  10.

    No:  Go to phenomenon 3. Refer to CRUISE CONTROL (DIAGNOSTICS)>DIAGNOSTICS WITH PHENOMENON>DIAGNOSTIC PROCEDURE WITH PHENOMENON .

  10. CHECK VEHICLE SPEED IS HELD WITHIN SET SPEED. 

    Make sure the vehicle speed is held within set speed.

    Is the vehicle speed kept within the setting speed ±3 km/h (±2 MPH)? (Confirm that on a level road.)

    Yes:  Go to  11.

    No:  Go to phenomenon 4. Refer to CRUISE CONTROL (DIAGNOSTICS)>DIAGNOSTICS WITH PHENOMENON>DIAGNOSTIC PROCEDURE WITH PHENOMENON .

  11. CHECK RES/+ OPERATION. 

    Check the RES/+ switch operation.

    Does the vehicle speed increase or return to set speed after RES/+ switch has been pressed?

    Yes:  Go to  12.

    No:  Go to phenomenon 5. Refer to CRUISE CONTROL (DIAGNOSTICS)>DIAGNOSTICS WITH PHENOMENON>DIAGNOSTIC PROCEDURE WITH PHENOMENON .

  12. CHECK SET/- OPERATION. 

    Check the SET/- switch operation.

    Does the vehicle speed decrease after SET/- switch has been pressed?

    Yes:  Go to  13.

    No:  Go to phenomenon 6. Refer to CRUISE CONTROL (DIAGNOSTICS)>DIAGNOSTICS WITH PHENOMENON>DIAGNOSTIC PROCEDURE WITH PHENOMENON .

  13. CANCEL OPERATION CHECK. 

    Check the CANCEL switch operation.

    Is the cruise control released after CANCEL switch has been pressed?

    Yes:  Go to  14.

    No:  Go to phenomenon 7. Refer to CRUISE CONTROL (DIAGNOSTICS)>DIAGNOSTICS WITH PHENOMENON>DIAGNOSTIC PROCEDURE WITH PHENOMENON .

  14. CHECK CRUISE CONTROL RELEASE OPERATION. 

    Check the cruise control release operation.

    Is the cruise control released after brake pedal has been depressed?

    Yes:  Go to  15.

    No:  Go to phenomenon 8. Refer to CRUISE CONTROL (DIAGNOSTICS)>DIAGNOSTICS WITH PHENOMENON>DIAGNOSTIC PROCEDURE WITH PHENOMENON .

  15. CHECK CRUISE CONTROL RELEASE OPERATION. 

    Check the cruise control release operation.

    Is the cruise control released after shifting to the neutral position?

    Yes:  Go to  16.

    No:  Go to phenomenon 9. Refer to CRUISE CONTROL (DIAGNOSTICS)>DIAGNOSTICS WITH PHENOMENON>DIAGNOSTIC PROCEDURE WITH PHENOMENON .

  16. CHECK CRUISE CONTROL RELEASE OPERATION. 

    Check the cruise control release operation.

    Is the cruise control released after depressing the clutch pedal?

    Yes:  Finish the diagnosis.

    No:  Go to phenomenon 10. Refer to CRUISE CONTROL (DIAGNOSTICS)>DIAGNOSTICS WITH PHENOMENON>DIAGNOSTIC PROCEDURE WITH PHENOMENON .
