  1. Check that the battery voltage is 12 V or more and fuel remains approx. half [20 - 40 L (5.3 - 10.6 US gal, 4.4 - 8.8 Imp gal)].
  2. Using the Subaru Select Monitor, clear the memory of [Engine Control System]. Refer to COMMON (DIAG)>CLEAR MEMORY .
  3. Turn the ignition switch to ON.
  4. Navigate to Inspection Mode for measuring Exhaust Gas. Refer to P-HEV HYBRID POWERTRAIN CONTROL (DIAGNOSTICS)>Work Support>OPERATION>SERVICE MODE .
    NOTE: If it is necessary to run the engine for 10 minutes or more, fasten the driver's seat belt.
  5. Start the engine.
  6. Idle the engine for 10 seconds or more.
  7. Read the readiness code of [Engine Control System] using Subaru Select Monitor and check that the concerned self-diagnosis is completed. Refer to ENGINE (DIAGNOSTICS) (H4DO (HEV))>ALL READINESS DIAGNOSTIC CODE(S) .
  8. Read the temporary code using the Subaru Select Monitor or general scan tool. Refer to COMMON (DIAG)>DIAGNOSTIC TROUBLE CODE (DTC) .
