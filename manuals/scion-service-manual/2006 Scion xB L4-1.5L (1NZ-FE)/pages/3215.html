POWER DOOR LOCK CONTROL SYSTEM

SYSTEM DESCRIPTION

1. POWER DOOR LOCK CONTROL SYSTEM DESCRIPTION

a. Step 1: The power door lock control system locks/ unlocks all the doors simultaneously.

The master switch and the door control switch on the front passenger side door send "lock/unlock" request signals to the door control relay. Then, the door control relay sends these requests to the lock motors in each door to lock/unlock all the doors simultaneously.

Inserting the key into the driver side or passenger side door key cylinder and performing a lock/unlock operation also sends lock/unlock request signals to the door lock control rely. The driver side door key-linked lock function has an unlock method called the "2-step unlock function". Please refer to the chart in step 2 for details of this function.
