Shifter M/T: Service and Repair

FLOOR SHIFT LEVER ASSEMBLY

COMPONENTS:




COMPONENTS:





REMOVAL





1. REMOVE SHIFT LEVER KNOB SUB-ASSEMBLY
a) Remove the shift lever knob.
2. REMOVE REAR CONSOLE BOX ASSEMBLY
a) Remove the rear console box.
3. REMOVE FLOOR SHIFT LEVER ASSEMBLY
a) Disconnect the wire harness.





b) Remove the 4 bolts and disconnect the shift lever.





c) Remove the clip, and disconnect the cable end of the transmission control select cable from the floor shift lever.





d) Using a screwdriver, detach the claw.
e) Disconnect the transmission control select cable from the shift lever retainer.





f) Remove the clip, and disconnect the cable end of the transmission control shift cable from the floor shift lever.





g) Using a screwdriver, detach the claw.
h) Disconnect the transmission control shift cable from the shift lever retainer.

INSTALLATION





1. INSTALL FLOOR SHIFT LEVER ASSEMBLY
a) Connect the transmission control shift cable to the shift lever retainer with the clip.
b) Connect the end of the transmission control shift cable to the floor shift lever.





c) Connect the transmission control select cable to the shift lever retainer.
d) Connect the end of the transmission control select cable to the floor shift lever with the clip.

NOTICE:
^ The serrated part of the select cable point should face upward when the select cable point is connected.
^ The clip should be inserted in the direction shown in the illustration.





e) Install the shift lever with the 4 bolts.
Torque: 12 Nm (120 kgf-cm, 9 ft. lbs.)





f) Connect the wire harness.
2. INSTALL REAR CONSOLE BOX ASSEMBLY
a) Install the rear console box.
3. INSTALL SHIFT LEVER KNOB SUB-ASSEMBLY
a) Install the shift lever knob.
