Throttle Position Sensor: Service and Repair

REMOVAL

1. DISCONNECT CABLE FROM NEGATIVE BATTERY TERMINAL

CAUTION: Wait at least 90 seconds after disconnecting the cable from the negative (-) battery terminal to prevent airbag and seat belt pretensioner activation.

2. REMOVE THROTTLE BODY ASSEMBLY
a. Remove the throttle body.

3. REMOVE THROTTLE POSITION SENSOR




a. Remove the 2 screws and sensor.

INSTALLATION

1. INSTALL THROTTLE POSITION SENSOR




a. Install the sensor with the 2 screws.

Torque: 2.0 N.m (20 kgf.cm, 18 in.lbf)

2. INSTALL THROTTLE BODY ASSEMBLY
a. Install the throttle body.

3. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
