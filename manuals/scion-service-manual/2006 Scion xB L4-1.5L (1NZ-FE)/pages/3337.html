Disassembly and Reassembly

COMBINATION METER

DISASSEMBLY




1. REMOVE COMBINATION METER GLASS
a. Using a screwdriver, detach the 3 claws and remove the combination meter glass.

HINT: Tape the screwdriver tip before use.

2. REMOVE NO. 1 COMBINATION METER COVER
a. Using a screwdriver, detach the 6 claws and remove the combination meter cover.

HINT: Tape the screwdriver tip before use.

REASSEMBLY

1. INSTALL NO. 1 COMBINATION METER COVER
a. Attach the 6 claws to install the combination meter cover.




2. INSTALL COMBINATION METER GLASS
a. Attach the 3 claws to install the combination meter glass.
