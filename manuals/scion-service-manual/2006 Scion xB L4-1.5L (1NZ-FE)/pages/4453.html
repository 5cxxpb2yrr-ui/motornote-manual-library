Disassembly and Reassembly

Do you like it dark? Easier on the eyes.

REAR COMBINATION LIGHT ASSEMBLY

DISASSEMBLY

HINT:
- Use the same procedures for the RH side and LH side.
- The procedures listed below are for the LH side.

1. REMOVE REAR COMBINATION LIGHT BODY GASKET LH




2. REMOVE REAR COMBINATION LIGHT BULB
a. Remove the 3 light sockets as shown in the illustration.
b. Remove the 3 light bulbs from the light sockets.




3. REMOVE REAR COMBINATION LIGHT LENS LH
a. Using a screwdriver, detach the 11 claws and remove the rear combination light lens.

4. REMOVE REAR COMBINATION LIGHT LENS GASKET LH

REASSEMBLY

HINT:
- Use the same procedures for the RH side and LH side.
- The procedures listed below are for the LH side.

1. INSTALL REAR COMBINATION LIGHT LENS GASKET LH
a. Install a new rear combination light lens gasket on the rear combination light lens.

NOTE: Be sure to replace the rear combination lens gasket with a new one because it cannot be reused.




2. INSTALL REAR COMBINATION LIGHT LENS LH
a. Attach the 11 claws to install the rear combination light lens.

NOTE: Make sure that water cannot go inside the rear combination light by applying water with automatic car wash or a hose.

3. INSTALL REAR COMBINATION LIGHT BULB
a. Install the 3 light bulbs to the light sockets.
b. Install the 3 light sockets.

4. INSTALL REAR COMBINATION LIGHT BODY GASKET LH
