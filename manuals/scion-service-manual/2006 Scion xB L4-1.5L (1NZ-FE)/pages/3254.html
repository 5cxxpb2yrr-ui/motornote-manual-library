Inner Rear View Mirror

REMOVAL




1. REMOVE INNER REAR VIEW MIRROR ASSEMBLY
a. Using a screwdriver, detach the claws and mirror cover.

HINT: Tape the screwdriver tip before use.

b. Remove the 2 screws and mirror.

INSTALLATION




1. INSTALL INNER REAR VIEW MIRROR ASSEMBLY
a. Install the mirror with the 2 screws.
b. Install the mirror cover.
