Disassembly and Reassembly

Do you like it dark? Easier on the eyes.

HEADLIGHT ASSEMBLY

DISASSEMBLY

HINT:
- Use the same procedures for the RH side and LH side.
- The procedures listed below are for the LH side.




1. REMOVE HEADLIGHT SOCKET COVER
a. Remove the headlight socket cover.




2. REMOVE NO. 1 HEADLIGHT BULB
a. Remove the No. 1 headlight bulb as shown in the illustration.




3. REMOVE CLEARANCE LIGHT BULB
a. Remove the clearance light bulb, clearance light socket as shown in the illustration.
b. Remove the clearance light bulb from the clearance light socket.

REASSEMBLY

HINT:
- Use the same procedures for the RH side and LH side.
- The procedures listed below are for the LH side.

1. INSTALL CLEARANCE LIGHT BULB
a. Install the bulb to the socket.
b. Install the clearance light socket.

2. INSTALL NO. 1 HEADLIGHT BULB
a. Release the lock of the set spring and install the headlight No. 1 bulb.

3. INSTALL HEADLIGHT SOCKET COVER
a. Install the headlight socket cover.
