Shift Cable: Service and Repair

Do you like it dark? Easier on the eyes.

TRANSMISSION CONTROL CABLE

COMPONENTS:




COMPONENTS:





REMOVAL





1. REMOVE FRONT NO. 1 FLOOR HEAT INSULATOR
2. REMOVE SHIFT LEVER KNOB SUB-ASSEMBLY
a) Remove the shift lever knob.
3. REMOVE REAR CONSOLE BOX ASSEMBLY
a) Remove the rear console box.
4. DISCONNECT FLOOR SHIFT LEVER ASSEMBLY
a) Disconnect the wire harness.





b) Remove the 4 bolts and disconnect the floor shift lever.





5. REMOVE TRANSMISSION CONTROL CABLE ASSEMBLY
a) Remove the clip, and disconnect the cable end of the transmission control select cable from the floor shift lever.





b) Using a screwdriver, detach the claw.
c) Disconnect the transmission control select cable from the shift lever retainer.





d) Remove the clip, and disconnect the cable end of the transmission control shift cable from the floor shift lever.





e) Using a screwdriver, detach the claw.
f) Disconnect the transmission control shift cable from the shift lever retainer.





g) Remove the 2 clips and 2 washers, and disconnect the 2 cables from the manual transaxle.
h) Remove the 2 clips, and disconnect the 2 cables from the control cable bracket.





i) Remove the 2 bolts and retainer from the floor.





j) Remove the retainer from the grommet.
k) Remove the transmission control select cable from the grommet.





l) Remove the bolt and clamp.
m) Pull out the transmission control select cable and transmission control shift cable through the floor hole.

INSTALLATION





1. INSTALL TRANSMISSION CONTROL CABLE ASSEMBLY
a) Install the clamp with the bolt.
Torque: 5.0 Nm (51 kgf-cm, 44 inch lbs.)
b) Insert the transmission control select cable and transmission control shift cable through the floor hole and retainer.
c) Install the transmission control select cable to the grommet.





d) Install the retainer on the grommet.

NOTICE: Fit the projections of the grommet into the holes of the retainer.





e) Install the retainer to the floor with the 2 bolts.
Torque: 5.0 Nm (51 kgf-cm, 44 inch lbs.)
f) Connect the transmission control cable to the shift lever retainer.





g) Connect the end of the transmission control shift cable to the floor shift lever with the clip.
h) Connect the transmission select cable to the shift lever retainer.





i) Connect the end of the transmission control select cable to the floor shift lever with the clip.

NOTICE:
^ The serrated part of the select cable point should face upward when the select cable point is connected.
^ The clip should be inserted in the direction shown in the illustration.





j) Connect the 2 cable ends to the transaxle with the 2 washers and 2 clips.
k) Install 2 new clips to the control cable bracket.





2. INSTALL FLOOR SHIFT LEVER ASSEMBLY
a) Install the floor shift lever with the 4 bolts.
Torque: 12 Nm (120 kgf-cm, 9 ft. lbs.)





b) Connect the wire harness.
3. INSTALL REAR CONSOLE BOX ASSEMBLY
a) Install the rear console box.
4. INSTALL SHIFT LEVER KNOB SUB-ASSEMBLY
a) Install the shift lever knob.
5. INSTALL FRONT NO. 1 FLOOR HEAT INSULATOR
Torque: 5.5 Nm (56 kgf-cm, 49 inch lbs.)
