Check Mode Procedure

CHECK MODE PROCEDURE




1. CHECK MODE (SIGNAL CHECK)
a. Connect the intelligent tester (with CAN VIM) to the DLC3.
b. Turn the ignition switch ON.
c. Select the Signal Check, and check using the intelligent tester.

HINT:
- Check mode is more sensitive to malfunctions than normal mode.
- If the normal system code is output in normal mode even when a sensor signal malfunction is suspected, perform the inspection in check mode.
