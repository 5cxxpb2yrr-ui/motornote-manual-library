Rear Door Window Glass: Service and Repair

REMOVAL

Rear Door Glass Weatherstrip:






HINT:
- Use the same procedures for the RH side and LH side.
- The procedures listed below are for the LH side.

1. REMOVE CABLE FROM NEGATIVE BATTERY TERMINAL

CAUTION: Wait at least 90 seconds after disconnecting the cable from the negative (-) battery terminal to prevent airbag and seat belt pretensioner activation.

2. REMOVE DOOR PULL HANDLE
3. REMOVE POWER WINDOW REGULATOR SWITCH ASSEMBLY REAR
4. REMOVE REAR DOOR TRIM BOARD SUB-ASSEMBLY LH
5. REMOVE REAR DOOR GLASS WEATHERSTRIP ASSEMBLY OUTER LH




a. Put protective tape under the weatherstrip.
b. Using a moulding remover, detach the claws to remove the weatherstrip as shown in the illustration.

HINT: Tape the remover tip before use.

INSTALLATION

1. INSTALL REAR DOOR GLASS WEATHERSTRIP ASSEMBLY OUTER LH




a. Attach the claws to install the weatherstrip.

2. INSTALL REAR DOOR TRIM BOARD SUB-ASSEMBLY LH
3. INSTALL POWER WINDOW REGULATOR SWITCH ASSEMBLY REAR
4. INSTALL DOOR PULL HANDLE
5. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
