Rear Axle Hub Bolt

REAR AXLE HUB BOLT

COMPONENTS:





REPLACEMENT





HINT:
^ Use the same procedures for the RH side and LH side.
^ The procedures listed are for the LH side.

1. REMOVE REAR WHEEL
2. REMOVE REAR BRAKE DRUM SUB-ASSEMBLY
3. REMOVE REAR AXLE HUB BOLT
a) Using SST and a screwdriver or an equivalent, remove the hub bolt.
SST 09628-10011





4. INSTALL REAR AXLE HUB BOLT
a) Install the washer and nut to a new hub bolt as shown in the illustration.
b) Using a screwdriver or an equivalent to hold the hub and bearing assembly, install the hub bolt by tightening the nut.
5. INSTALL REAR BRAKE DRUM SUB-ASSEMBLY
6. INSTALL REAR WHEEL
Torque: 103 Nm (1,050 kgf-cm, 76 ft. lbs.)
