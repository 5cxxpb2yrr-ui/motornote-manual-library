System Description

SYSTEM DESCRIPTION
1. SYSTEM DESCRIPTION
a) The Electronic Controlled Automatic Transmission (ECT) is an automatic transaxle that electronically controls shift timing using the Engine Control Module (ECM). The ECM detects electrical signals that indicate engine and driving conditions, and controls the shift point based on driver habits and road conditions. As a result, fuel efficiency and power transaxle performance are improved. Shift shock is reduced by controlling the engine and transaxle simultaneously.
In addition, the ECT has these features:
^ Diagnostic function.
^ Fail-safe function when a malfunction occurs.
