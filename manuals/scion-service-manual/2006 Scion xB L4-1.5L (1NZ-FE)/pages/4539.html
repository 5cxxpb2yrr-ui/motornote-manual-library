Removal and Installation

Do you like it dark? Easier on the eyes.

LICENSE PLATE LIGHT ASSEMBLY

REMOVAL
1. DISCONNECT CABLE FROM NEGATIVE BATTERY TERMINAL

CAUTION: Wait at least 90 seconds after disconnecting the cable from the negative (-) battery terminal to prevent airbag and seat belt pretensioner activation.

2. REMOVE BACK DOOR TRIM BOARD
3. REMOVE BACK DOOR GARNISH OUTSIDE




4. REMOVE LICENSE PLATE LIGHT ASSEMBLY
a. Remove the 4 screws and light as shown in the illustration.

INSTALLATION




1. INSTALL LICENSE PLATE LIGHT ASSEMBLY
a. Install the rear light with the 4 screws.

2. INSTALL BACK DOOR GARNISH OUTSIDE
3. INSTALL BACK DOOR TRIM BOARD
4. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
