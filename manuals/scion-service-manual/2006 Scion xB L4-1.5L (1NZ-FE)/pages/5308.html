Front Shock Absorber with Coil Spring

FRONT SHOCK ABSORBER WITH COIL SPRING

COMPONENTS:




COMPONENTS:





REMOVAL
1. REMOVE WINDSHIELD WIPER ARM COVER
2. REMOVE FRONT WIPER ARM LH
3. REMOVE FRONT WIPER ARM RH
4. REMOVE HOOD TO COWL TOP SEAL
5. REMOVE COWL TOP VENTILATOR LOUVER LH
6. REMOVE COWL TOP VENTILATOR LOUVER RH
7. REMOVE WINDSHIELD WIPER LINK ASSEMBLY
8. REMOVE COWL TOP PANEL OUTER
a) Disconnect the hose and wire harness form the wiper.
b) Remove the cowl top panel outer with the 8 bolts.
9. REMOVE FRONT WHEEL





10. DISCONNECT FLEXIBLE HOSE
a) Remove the bolt and disconnect the flexible hose and speed sensor wire clamp from the shock absorber bracket.





11. REMOVE FRONT SHOCK ABSORBER WITH COIL SPRING
a) Remove the 2 nuts and 2 bolts, and disconnect the shock absorber from the steering knuckle.





b) Remove the 3 nuts and shock absorber.
c) Remove the No. 2 suspension support.

DISASSEMBLY





1. FIX FRONT SHOCK ABSORBER WITH COIL SPRING
a) Install the 2 nuts and bolt on the bracket at the lower side of the shock absorber and secure it in a vise.
b) Using SST, compress the coil spring.
SST 09727-30021 (09727-00010, 09727-00021, 09727-00031)

NOTICE: Do not use an impact wrench. It will damage the SST.

2. REMOVE FRONT SUSPENSION SUPPORT DUST COVER LH
a) Remove the dust cover from the suspension support.





3. REMOVE FRONT SUPPORT TO FRONT SHOCK ABSORBER LH NUT
a) Using the 2 nuts and a screwdriver or an equivalent to secure the front shock absorber, remove the center nut.

NOTICE: Be careful not to damage the suspension support stud bolts.

4. REMOVE FRONT SUSPENSION SUPPORT SUB-ASSEMBLY LH
5. REMOVE FRONT SUSPENSION SUPPORT LH DUST SEAL
6. REMOVE FRONT COIL SPRING SEAT UPPER LH
7. REMOVE FRONT COIL SPRING INSULATOR UPPER LH
8. REMOVE FRONT COIL SPRING LH
9. REMOVE FRONT SPRING BUMPER LH
10. REMOVE FRONT SHOCK ABSORBER ASSEMBLY LH

INSPECTION





1. INSPECT FRONT SHOCK ABSORBER ASSEMBLY LH
a) Compress and extend the shock absorber rod and check that there is no abnormal resistance or unusual sound during operation.
If there is any abnormality, replace the shock absorber with a new one.

NOTICE: When disposing of the shock absorber, refer to DISPOSAL.

REASSEMBLY





1. INSTALL FRONT SHOCK ABSORBER ASSEMBLY LH
2. INSTALL FRONT SPRING BUMPER LH
3. INSTALL FRONT COIL SPRING LH
a) Using SST, compress the coil spring.
SST 09727-30021 (09727-00010, 09727-00021, 09727-00031)

NOTICE: Do not use an impact wrench. It will damage the SST.





b) Install the coil spring on the shock absorber.

HINT: Fit the lower end of the coil spring into the gap of the spring lower seat.

4. INSTALL FRONT COIL SPRING INSULATOR UPPER LH
a) Install the upper insulator with the mark facing the outside of the vehicle.
5. INSTALL FRONT COIL SPRING SEAT UPPER LH
a) Install the spring seat upper with the "OUT" mark facing the outside of the vehicle.
6. INSTALL FRONT SUSPENSION SUPPORT LH DUST SEAL
7. INSTALL FRONT SUSPENSION SUPPORT SUB-ASSEMBLY LH
8. INSTALL FRONT SUPPORT TO FRONT SHOCK ABSORBER LH NUT
a) Using the 2 nuts and a screwdriver or an equivalent to secure the front shock absorber, install a new center nut.
Torque: 33 Nm (340 kgf-cm, 25 ft. lbs.)

NOTICE: Be careful not to damage the suspension support stud bolts.





b) Remove the SST.
c) Apply MP grease to the suspension support.
9. INSTALL FRONT SUSPENSION SUPPORT DUST COVER LH

INSTALLATION
1. INSTALL FRONT SHOCK ABSORBER WITH COIL SPRING
a) Install the No. 2 suspension support.
b) Install the shock absorber with the 3 nuts.
Torque: 39 Nm (400 kgf-cm, 29 ft. lbs.)
c) Connect the shock absorber to the steering knuckle.
d) Install the 2 bolts and nut.

NOTICE: When installing the bolt, keep it from rotating and torque the nut.

Torque: 132 Nm (1,350 kgf-cm, 97 ft. lbs.)
2. INSTALL FLEXIBLE HOSE
a) Install the flexible hose.
Torque: 29 Nm (300 kgf-cm, 22 ft. lbs.)
3. INSTALL FRONT WHEEL
Torque: 103 Nm (1,050 kgf-cm, 76 ft. lbs.)
4. INSTALL COWL TOP PANEL OUTER
a) Install the cowl top panel outer with the 8 bolts.
Torque: 5.0 Nm (51 kgf-cm, 44 inch lbs.)
b) Connect the hose and wire harness to the wiper.
5. INSTALL WINDSHIELD WIPER LINK ASSEMBLY
6. INSTALL COWL TOP VENTILATOR LOUVER RH
7. INSTALL COWL TOP VENTILATOR LOUVER LH
8. INSTALL HOOD TO COWL TOP SEAL
9. INSTALL FRONT WIPER ARM LH
10. INSTALL FRONT WIPER ARM RH
11. INSPECT AND ADJUST FRONT WHEEL ALIGNMENT
a) Inspect and adjust the front wheel alignment.

DISPOSAL





1. DISPOSE OF FRONT SHOCK ABSORBER ASSEMBLY LH
a) Fully extend the shock absorber rod.
b) Using a drill, make a hole in the cylinder somewhere between A and B as shown in the illustration to discharge the gas inside.

CAUTION: Be careful when drilling as shards of metal may fly out, and always use the proper safety equipment.

NOTICE: The gas is colorless, odorless and harmless.
