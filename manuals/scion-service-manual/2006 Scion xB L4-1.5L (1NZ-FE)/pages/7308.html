SUPPLEMENTAL RESTRAINT SYSTEM: AIRBAG SYSTEM: B1653/35: Seat Position Airbag Sensor Circuit Malfunction

B1653/35 Seat Position Airbag Sensor Circuit Malfunction

DESCRIPTION
The seat position airbag sensor circuit consists of the center airbag sensor and the seat position sensor.

DTC B1653/35 is recorded when a malfunction is detected in the seat position airbag sensor circuit.
