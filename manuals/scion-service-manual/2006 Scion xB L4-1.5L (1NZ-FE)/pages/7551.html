DTC B1100/31 Center Airbag Sensor Assembly Malfunction

DESCRIPTION

DTC Detection Condition:




The center airbag sensor assembly consists of the airbag sensor, the safing sensor, the driver circuit, the diagnosis circuit and the ignition control circuit.

If the center airbag sensor assembly receives signals from the other airbag sensors, it judges whether or not the SRS should be activated.

DTC B1100/31 is recorded when a malfunction in the center airbag sensor assembly is detected.

HINT: When a malfunction code other than code B1100/31 is displayed at the same time, first repair the malfunction indicated by the malfunction code other than code B1100/31.
