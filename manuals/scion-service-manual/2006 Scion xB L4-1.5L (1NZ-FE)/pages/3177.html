Only Wireless Door Lock Control Function does not Operate

DESCRIPTION
The door control receiver receives a signal from the transmitter and sends this signal to the door control relay. Then, the door control relay controls the door operation by sending a door LOCK/UNLOCK signal to each door lock motor.
