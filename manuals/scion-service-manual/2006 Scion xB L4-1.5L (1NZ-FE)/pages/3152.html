Trunk / Liftgate: Service and Repair

BACK DOOR

COMPONENTS

Back Door:




Back Door:





DISASSEMBLY
1. DISCONNECT CABLE FROM NEGATIVE BATTERY TERMINAL

CAUTION: Wait at least 90 seconds after disconnecting the cable from the negative (-) battery terminal to prevent airbag and seat belt pretensioner activation.

2. REMOVE BACK DOOR TRIM BOARD
(a) Using a clip remover, remove the 11 clips and trim board.
3. REMOVE BACK DOOR GARNISH OUTSIDE
4. REMOVE CENTER STOP LIGHT ASSEMBLY
5. REMOVE REAR WIPER MOTOR ASSEMBLY
6. REMOVE BACK DOOR LOCK ASSEMBLY





(a) Disconnect the door lock connector.
(b) Remove the 3 bolts and door lock.

HINT: Remove the door lock through the service hole.

7. REMOVE BACK WINDOW GLASS CHANNEL LH
(a) Using a clip remover, remove the 2 clips.
(b) Using a heat light, heat the channel.
Standard heating temperature: 20 to 30°C (68 to 86°F)

NOTICE: Do not heat the body and channel excessively.

(c) Using a screwdriver, remove the channel.

HINT: Tape the screwdriver tip before use.

8. REMOVE BACK WINDOW GLASS CHANNEL RH
(a) Use the same procedures described for the LH side.

9. REMOVE DOOR PULL HANDLE





(a) Using a screwdriver, detach the 4 claws and remove the pull handle.

HINT: Tape the screwdriver tip before use.

10. REMOVE BACK DOOR STAY SUB-ASSEMBLY LH
11 REMOVE BACK DOOR STAY SUB-ASSEMBLY RH
(a) Use the same procedures described for the LH side.

12. REMOVE BACK DOOR STOPPER LOWER
(a) Remove the bolt and stopper LH and RH.

REASSEMBLY

HINT: A bolt without a torque specification is shown in the standard bolt chart.

1. INSTALL BACK DOOR STOPPER LOWER
(a) Install the stopper LH and RH with the bolt.
Torque: 12.5 Nm (112 kgf-cm, 9 ft.-lbf)

2. INSTALL BACK DOOR STAY SUB-ASSEMBLY LH
3. INSTALL BACK DOOR STAY SUB-ASSEMBLY RH
(a) Use the same procedures described for the LH side.

4. INSTALL DOOR PULL HANDLE





(a) Attach the 4 claws and install the pull handle.
5. INSTALL BACK WINDOW GLASS CHANNEL LH
(a) Clean the contact surface of the door with a sponge saturated with white gasoline.
(b) Using a heat light, heat the door and new channel.





NOTICE: Do not heat the door and channel excessively.

(c) Remove peeling paper from the channel face.
(d) Install the channel and 2 clips.

6. INSTALL BACK WINDOW GLASS CHANNEL RH
(a) Use the same procedures described for the LH side.

7. INSTALL BACK DOOR LOCK ASSEMBLY





(a) Install the door lock with the 3 bolts.
Torque: 12.5 Nm (112 kgf-cm, 9 ft.-lbf)
(b) Connect the door lock connector.

8. INSTALL REAR WIPER MOTOR ASSEMBLY
9. INSTALL CENTER STOP LIGHT ASSEMBLY
10. INSTALL BACK DOOR GARNISH OUTSIDE
11 INSTALL BACK DOOR TRIM BOARD
(a) Install the trim board with the 11 clips.
12. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
