Cigarette Lighter: Service and Repair

CIGARETTE LIGHTER ASSEMBLY

REMOVAL

1. DISCONNECT CABLE FROM NEGATIVE BATTERY TERMINAL

CAUTION: Wait at least 90 seconds after disconnecting the cable from the negative (-) battery terminal to prevent airbag and seat belt pretensioner activation.

2. REMOVE INSTRUMENT CLUSTER FINISH PANEL CENTER
3. REMOVE HEATER CONTROL KNOB
4. REMOVE INSTRUMENT CLUSTER FINISH PANEL SUB-ASSEMBLY LOWER CENTER




5. REMOVE CIGARETTE LIGHTER COVER
a. Detach the 2 claws and remove the cigarette lighter cover.
6. REMOVE CIGARETTE LIGHTER ASSEMBLY




a. Remove the cigarette lighter knob and element.




b. Turn the socket in the direction as shown in the illustration, disengage the claw between the socket and the cigarette lighter bezel stay, and pull out the socket.
c. Align the socket with the notch on the cigarette lighter bezel stay, and remove the cigarette lighter.

INSTALLATION




1. INSTALL CIGARETTE LIGHTER ASSEMBLY
a. Align the socket with the notch on the cigarette lighter bezel stay and push the cigarette lighter in as hard as possible.
b. Install the cigarette lighter knob and element.




2. INSTALL CIGARETTE LIGHTER COVER
a. Attach the 2 claws to install the cigarette lighter cover.

3. INSTALL INSTRUMENT CLUSTER FINISH PANEL SUB-ASSEMBLY LOWER CENTER
4. INSTALL INSTRUMENT CLUSTER FINISH PANEL CENTER
5. INSTALL HEATER CONTROL KNOB
6. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
