Parking Brake Lever: Service and Repair

PARKING BRAKE LEVER

COMPONENTS:





REMOVAL
1. REMOVE SHIFT LEVER KNOB SUB-ASSEMBLY (for Manual Transaxle)
2. REMOVE STEREO JACK ADAPTER ASSEMBLY
3. REMOVE REAR CONSOLE BOX COVER
4. REMOVE CONSOLE BOX CARPET
5. REMOVE REAR CONSOLE BOX ASSEMBLY
6. REMOVE NO. 1 WIRE ADJUSTING NUT
a) Remove the lock nut and wire adjusting nut.





7. REMOVE PARKING BRAKE LEVER SUB-ASSEMBLY
a) Disconnect the parking brake switch connector.
b) Disconnect the parking brake pull rod.
c) Remove the 2 bolts and parking brake lever.
8. REMOVE PARKING BRAKE SWITCH ASSEMBLY
a) Remove the screw and parking brake switch.

INSTALLATION
1. INSTALL PARKING BRAKE SWITCH ASSEMBLY
a) Install the parking brake switch with the screw.





2. INSTALL PARKING BRAKE LEVER SUB-ASSEMBLY
a) Connect the parking brake pull rod to the lever.
b) Install the parking brake lever with the 2 bolts.
Torque: 13 Nm (127 kgf-cm, 9 ft. lbs.)
c) Connect the parking brake switch connector.
3. INSTALL NO. 1 WIRE ADJUSTING NUT
a) Install the wire adjusting nut and lock nut.
Torque: 5.4 Nm (55 kgf-cm, 48 inch lbs.)

4. INSTALL REAR CONSOLE BOX ASSEMBLY
5. INSTALL CONSOLE BOX CARPET
6. INSTALL REAR CONSOLE BOX COVER
7. INSTALL STEREO JACK ADAPTER ASSEMBLY
8. INSTALL SHIFT LEVER KNOB SUB-ASSEMBLY (for Manual Transaxle)
9. CHECK PARKING BRAKE LEVER TRAVEL
10. ADJUST PARKING BRAKE LEVER TRAVEL
