High Pitched Horn

REMOVAL

1. REMOVE RADIATOR GRILLE
2. REMOVE FRONT FENDER LINER LH
3. REMOVE FRONT FENDER LINER RH
4. REMOVE RADIATOR GRILLE LOWER
5. REMOVE FRONT BUMPER EXTENSION MOUNTING BRACKET LH
6. REMOVE FRONT BUMPER EXTENSION MOUNTING BRACKET RH
7. REMOVE FRONT BUMPER COVER




8. REMOVE HIGH PITCHED HORN
a. Disconnect the horn connector.
b. Remove the bolt and horn.

INSTALLATION




1. INSTALL HIGH PITCHED HORN
a. Attach the horn stay to the body panel and then install the horn with the bolt.

Torque: 19.5 N.m (199 kgf.cm, 14 ft.lbf)

b. Connect the horn connector.

2. INSTALL FRONT BUMPER COVER
3. INSTALL FRONT BUMPER EXTENSION MOUNTING BRACKET RH
4. INSTALL FRONT BUMPER EXTENSION MOUNTING BRACKET LH
5. INSTALL RADIATOR GRILLE LOWER
6. INSTALL FRONT FENDER LINER RH
7. INSTALL FRONT FENDER LINER LH
8. INSTALL RADIATOR GRILLE
