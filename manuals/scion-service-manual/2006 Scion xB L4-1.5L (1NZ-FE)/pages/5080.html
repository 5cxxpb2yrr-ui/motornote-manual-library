Front Airbag Sensor

Do you like it dark? Easier on the eyes.

REMOVAL

CAUTION: Be sure to read the precautionary notices concerning the SRS airbag system before servicing it.

1. DISCONNECT CABLE FROM NEGATIVE BATTERY TERMINAL

CAUTION: Wait at least 90 seconds after disconnecting the cable from the negative (-) battery terminal to prevent airbag and seat belt pretensioner activation.




2. REMOVE NO. 1 AIR CLEANER INLET
a. Remove the bolt and air cleaner inlet.




3. REMOVE FRONT AIRBAG SENSOR LH
a. Disconnect the sensor connector.
b. Remove the 2 bolts and sensor.




4. REMOVE FRONT AIRBAG SENSOR RH
a. Disconnect the sensor connector.
b. Remove the 2 bolts and sensor.

INSTALLATION

CAUTION: Be sure to read the precautionary notices concerning the SRS airbag system before servicing it.




1. INSTALL FRONT AIRBAG SENSOR LH
a. Install the sensor with the 2 bolts.

Torque: 17.5 N.m (178 kgf.cm, 13 ft.lbf)

CAUTION:
- If the airbag sensor has been dropped, or there are any cracks, dents or other defects in the case or connector, replace it with a new one.
- When installing the airbag sensor, make sure that the SRS wiring does not interfere with other parts and is not pinched between other parts.

b. Check that there is no free play in the installation parts of the sensor.
c. Connect the sensor connector.




2. INSTALL FRONT AIRBAG SENSOR RH
a. Install the sensor with the 2 bolts.

Torque: 17.5 N.m (178 kgf.cm, 13 ft.lbf)

NOTE:
- If the airbag sensor has been dropped, or there are any cracks, dents or other defects in the case or connector, replace it with a new one.
- When installing the airbag sensor, make sure that the SRS wiring does not interfere with other parts and is not pinched between other parts.

b. Check that there is no free play in the installation parts of the sensor.
c. Connect the sensor connector.




3. INSTALL NO. 1 AIR CLEANER INLET
a. Install the air cleaner inlet with the bolt.

4. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
5. CHECK SRS WARNING LIGHT
a. Check the SRS warning light.
