DIAGNOSIS SYSTEM

1. DESCRIPTION
Meter/gauge system data and the Diagnostic Trouble Codes (DTCs) can be read through the Data Link Connector 3 (DLC3) of the vehicle. When the system seems to be malfunctioning, use the intelligent tester to check for malfunctions and perform repairs.
