Water Pump: Service and Repair

Do you like it dark? Easier on the eyes.

WATER PUMP

COMPONENTS:





REMOVAL
1. DRAIN ENGINE COOLANT
2. REMOVE ENGINE UNDER COVER RH
3. REMOVE GENERATOR V BELT
4. REMOVE ENGINE MOUNTING INSULATOR SUBASSEMBLY RH





5. REMOVE WATER PUMP PULLEY
a) Using SST, hold the pump pulley.
SST 09960-10010 (09962-01000, 09963-00600)
b) Remove the 3 bolts and pump pulley.





6. REMOVE WATER PUMP ASSEMBLY
a) Remove the 3 bolts and 2 nuts.
b) Remove the water pump and gasket.

INSTALLATION
1. INSTALL WATER PUMP ASSEMBLY
a) Install a new gasket and the water pump with the 3 bolts and 2 nuts.
Torque: 11 Nm (112 kgf-cm, 8 ft. lbs.)

2. INSTALL WATER PUMP PULLEY
a) Using SST, install the pump pulley with the 3 bolts.
SST 09960-10010 (09962-01000, 09963-00600)
Torque: 15 Nm (153 kgf-cm, 11 ft. lbs.)

3. INSTALL ENGINE MOUNTING INSULATOR SUBASSEMBLY RH
4. INSTALL GENERATOR V BELT
5. ADJUST GENERATOR V BELT
6. INSTALL ENGINE UNDER COVER RH
7. ADD ENGINE COOLANT
8. CHECK FOR ENGINE COOLANT LEAKS
