Removal and Installation

Do you like it dark? Easier on the eyes.

REMOVAL




1. TABLE OF BOLT, SCREW AND NUT

HINT: All bolts, screws and nuts relevant to installing and removing the instrument panel are shown along with their alphabet code in the table.

2. DISCONNECT CABLE FROM NEGATIVE BATTERY TERMINAL

CAUTION: Wait at least 90 seconds after disconnecting the cable from the negative (-) battery terminal to prevent airbag and seat belt pretensioner activation.




3. REMOVE INSTRUMENT CLUSTER FINISH PANEL
a. Remove the clip.
b. Using a screwdriver, detach the 7 claws and 2 clips, and remove the instrument cluster finish panel.

HINT: Tape the screwdriver tip before use.




4. REMOVE COMBINATION METER ASSEMBLY
a. Remove the 3 screws.
b. Disconnect the connector and remove the combination meter.




5. REMOVE NO. 2 INSTRUMENT PANEL SPEAKER PANEL SUB-ASSEMBLY
a. Using a moulding remover, detach the 5 claws and remove the speaker panel.

HINT: Tape the moulding remover tip before use.

6. REMOVE NO. 1 INSTRUMENT PANEL SPEAKER PANEL SUB-ASSEMBLY




7. REMOVE FRONT NO. 2 SPEAKER ASSEMBLY
8. REMOVE HEATER CONTROL KNOB
a. Remove the 3 heater control knobs.

9. REMOVE INSTRUMENT CLUSTER FINISH PANEL CENTER




a. Remove the 2 screws.




b. Disengage the 8 clips and 6 claws, and remove the instrument cluster finish panel center.




10. REMOVE NO. 1 RADIO BRACKET
a. Remove the 2 screws and radio bracket.

11. REMOVE NO. 2 RADIO BRACKET
a. Remove the 2 screws and radio bracket.




12. REMOVE FRONT PILLAR GARNISH LH
a. Using a screwdriver, detach the 2 clips and remove the front pillar garnish.

HINT: Tape the screwdriver tip before use.

13. REMOVE FRONT PILLAR GARNISH RH

HINT: Use the same procedures for the RH side and LH side.




14. REMOVE NO. 3 INSTRUMENT PANEL HOLE COVER
a. Using a screwdriver, detach the 4 claws and remove the instrument panel hole cover.

HINT: Tape the screwdriver tip before use.

15. DISCONNECT PASSENGER AIRBAG CONNECTOR

16. REMOVE INSTRUMENT PANEL SUB-ASSEMBLY




a. Remove the bolt.
b. Remove the 6 screws.
c. Disengage the 7 clips and 3 claws.
d. Disconnect the connectors.




e. Remove the instrument panel.

INSTALLATION

1. INSTALL INSTRUMENT PANEL SUB-ASSEMBLY




a. Install the instrument panel.
b. Connect the connectors.
c. Attach the 7 clips and 3 claws.
d. Install the 6 screws.




e. Install the bolt.

2. CONNECT PASSENGER AIRBAG CONNECTOR




3. INSTALL NO. 3 INSTRUMENT PANEL HOLE COVER
a. Attach the 4 claws to install the instrument panel hole cover.




4. INSTALL FRONT PILLAR GARNISH LH
a. Attach the 2 clips to install the front pillar garnish.

5. INSTALL FRONT PILLAR GARNISH RH

HINT: Use the same procedures for the RH side and LH side.




6. INSTALL NO. 1 RADIO BRACKET
a. Install the radio bracket with the 2 screws.

7. INSTALL NO. 2 RADIO BRACKET
a. Install the radio bracket with the 2 screws.

8. INSTALL INSTRUMENT CLUSTER FINISH PANEL CENTER




a. Attach the 8 clips and 6 claws to install the instrument cluster finish panel.




b. Install the 2 screws.




9. INSTALL HEATER CONTROL KNOB
a. Install the 3 heater control knobs.

10. INSTALL FRONT NO. 2 SPEAKER ASSEMBLY
11. INSTALL NO. 2 INSTRUMENT PANEL SPEAKER PANEL SUB-ASSEMBLY
a. Attach the 5 claws to install the speaker panel.

12. INSTALL NO.1 INSTRUMENT PANEL SPEAKER PANEL SUB-ASSEMBLY

HINT: Use the same procedures described for the No. 1 instrument panel speaker panel.




13. INSTALL COMBINATION METER ASSEMBLY
a. Connect the connector.
b. Install the combination meter with the 3 screws.




14. INSTALL INSTRUMENT CLUSTER FINISH PANEL
a. Attach the 7 claws and 2 clips to install the instrument cluster finish panel.
b. Install the clip.

15. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
16. CHECK SRS WARNING LIGHT
a. Check the SRS warning light.
