Parking Brake Cable: Service and Repair

Do you like it dark? Easier on the eyes.

PARKING BRAKE CABLE

COMPONENTS:





REMOVAL

HINT:
^ Use the same procedures for the No. 2 parking brake cable and No. 3 parking brake cable.
^ The procedures listed are for the No. 3 parking brake cable.

1. REMOVE SHIFT LEVER KNOB SUB-ASSEMBLY (for Manual Transaxle)
2. REMOVE REAR CONSOLE BOX COVER
3. REMOVE CONSOLE BOX CARPET
4. REMOVE REAR CONSOLE BOX ASSEMBLY
5. REMOVE NO. 1 WIRE ADJUSTING NUT
a) Remove the No. 1 wire adjusting nut.
6. REMOVE FRONT FLOOR PANEL BRACE
a) Remove the 2 bolts and floor panel brace.
7. REMOVE FRONT EXHAUST PIPE ASSEMBLY
8. REMOVE FRONT NO. 2 FLOOR HEAT INSULATOR
a) Remove the 3 bolts and heat insulator.
9. DISCONNECT NO. 3 PARKING BRAKE CABLE ASSEMBLY
a) Remove the nut and 3 bolts, and then disconnect the parking brake cable from the body.
b) Disconnect the parking brake cable from the parking brake equalizer.
10. REMOVE REAR WHEEL
11. REMOVE REAR BRAKE DRUM SUB-ASSEMBLY
12. DISCONNECT PARKING BRAKE SHOE STRUT LH
13. REMOVE FRONT BRAKE SHOE
14. REMOVE PARKING BRAKE SHOE STRUT LH
15. REMOVE REAR BRAKE AUTOMATIC ADJUST LEVER LH
16. REMOVE REAR BRAKE SHOE





17. REMOVE NO. 3 PARKING BRAKE CABLE ASSEMBLY
a) Remove the bolt and then disconnect the parking brake cable from the backing plate.

INSTALLATION





HINT:
^ Use the same procedures for the No. 2 parking brake cable and No. 3 parking brake cable.
^ The procedures listed are for the No. 3 parking brake cable.

1. INSTALL NO. 3 PARKING BRAKE CABLE ASSEMBLY
a) Connect the parking brake cable to the parking brake equalizer.
b) Install the parking brake cable to the body with the nut and 3 bolts.
Torque: 5.4 Nm (55 kgf-cm, 48 inch lbs.)

2. CONNECT NO. 3 PARKING BRAKE CABLE ASSEMBLY
a) Connect the parking brake cable to the backing plate with the bolt.
Torque: 7.8 Nm (80 kgf-cm, 69 inch lbs.)

3. APPLY HIGH TEMPERATURE GREASE
4. INSTALL REAR BRAKE SHOE
5. INSTALL REAR BRAKE AUTOMATIC ADJUST LEVER LH
6. INSTALL PARKING BRAKE SHOE STRUT LH
7. INSTALL FRONT BRAKE SHOE
8. CONNECT REAR BRAKE SHOE RETURN SPRING
9. CHECK REAR BRAKE DRUM INSTALLATION
10. INSTALL REAR BRAKE DRUM SUB-ASSEMBLY
11. ADJUST REAR BRAKE DRUM SHOE CLEARANCE
12. INSTALL REAR WHEEL
Torque: 103 Nm (1,050 kgf-cm, 76 ft. lbs.)

13. INSTALL FRONT NO. 2 FLOOR HEAT INSULATOR
a) Install the heat insulator with the 3 bolts.
Torque: 5.5 Nm (55 kgf-cm, 48 inch lbs.)

14. INSTALL FRONT EXHAUST PIPE ASSEMBLY
15. INSTALL FRONT FLOOR PANEL BRACE
a) Install the floor panel brace with the 2 bolts.
16. TEMPORARILY TIGHTEN NO. 1 WIRE ADJUSTING NUT
a) Temporarily tighten the wire adjusting nut.
17. CHECK PARKING BRAKE LEVER TRAVEL
18. ADJUST PARKING BRAKE LEVER TRAVEL
19. INSTALL REAR CONSOLE BOX ASSEMBLY
20. INSTALL CONSOLE BOX CARPET
21. INSTALL REAR CONSOLE BOX COVER
22. INSTALL SHIFT LEVER KNOB SUB-ASSEMBLY (for Manual Transaxle)
23. CHECK EXHAUST GAS LEAKAGE
