Removal and Installation

Do you like it dark? Easier on the eyes.

HEADLIGHT ASSEMBLY

REMOVAL

HINT:
- Use the same procedures for the RH side and LH side.
- The procedures listed below are for the LH side.

1. DISCONNECT CABLE FROM NEGATIVE BATTERY TERMINAL

CAUTION: Wait at least 90 seconds after disconnecting the cable from the negative (-) battery terminal to prevent airbag and seat belt pretensioner activation

2. REMOVE RADIATOR GRILLE
3. REMOVE FRONT FENDER LINER LH
4. REMOVE FRONT FENDER LINER RH
5. REMOVE FRONT BUMPER COVER




6. REMOVE HEADLIGHT ASSEMBLY LH
a. Remove the 4 screws.
b. Disconnect the connectors and remove the headlight.

INSTALLATION

HINT:
- Use the same procedures for the RH side and LH side.
- The procedures listed below are for the LH side.




1. INSTALL HEADLIGHT ASSEMBLY LH
a. Install the headlight with the 4 screws.
b. Connect the connectors.

2. INSTALL FRONT BUMPER COVER
3. INSTALL FRONT FENDER LINER LH
4. INSTALL FRONT FENDER LINER RH
5. INSTALL RADIATOR GRILLE
6. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
7. INSPECT HEADLIGHT AIMING
8. ADJUST HEADLIGHT AIMING
