PROBLEM SYMPTOMS TABLE




When a "Normal" code is output during a DTC check but the problem is still occurring, use the Problem Symptoms Table. The suspected areas (circuits or parts) for each problem symptom are in the table. The suspected areas are listed in order of probability. A description of each of the chart's columns is as given.

HINT: In some cases, the problem is not detected by the diagnostic system even though a problem symptom is present. It is possible that the problem is occurring outside the detection range of the diagnostic system, or that the problem is occurring in a completely different system.
