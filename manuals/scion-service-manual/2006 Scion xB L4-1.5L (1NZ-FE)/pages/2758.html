Steering Column: Service and Repair

STEERING COLUMN ASSEMBLY

COMPONENTS:




COMPONENTS:




COMPONENTS:





REMOVAL
1. PRECAUTION
(a) Refer to Air Bag System Precaution.
2. DISCONNECT CABLE FROM NEGATIVE BATTERY TERMINAL

CAUTION: Wait at least 90 seconds after disconnecting the cable from the negative (-) battery terminal to prevent airbag and seat belt pretensioner activation.

3. PLACE FRONT WHEELS FACING STRAIGHT AHEAD
4. REMOVE STEERING PAD ASSEMBLY





5. REMOVE STEERING WHEEL ASSEMBLY
a) Disconnect the connector.
b) Remove the steering wheel set nut.
c) Put matchmarks on the steering wheel and main shaft.
d) Using SST, remove the steering wheel.
SST 09950-50013 (09951-05010, 09952-05010, 09953-05020, 09954-05021)





6. REMOVE STEERING COLUMN COVER
a) Remove the 3 screws and column cover lower.





b) Remove the 2 bolts and column cover upper.





7. DISCONNECT FLOOR SHIFT PARKING LOCK CABLE ASSEMBLY (for Automatic Transaxle)
a) With the key in the ACC position, detach the claw and pull out the floor shift parking lock cable.
8. REMOVE SPIRAL CABLE SUB-ASSEMBLY
9. REMOVE HEADLIGHT DIMMER SWITCH ASSEMBLY
10. REMOVE WINDSHIELD WIPER SWITCH ASSEMBLY
11. REMOVE STEERING COLUMN HOLE COVER PLATE
a) Remove the clip and column hole cover plate.





12. DISCONNECT STEERING INTERMEDIATE SHAFT ASSEMBLY
a) Put matchmarks on the sliding yoke and intermediate shaft.
b) Remove the bolt and intermediate shaft.





13. REMOVE STEERING INTERMEDIATE SHAFT ASSEMBLY
a) Put matchmarks on the main shaft and intermediate shaft.
b) Remove the bolt and intermediate shaft.





14. REMOVE STEERING COLUMN ASSEMBLY
a) Disconnect the connectors and wire harness clamps from the steering column.
b) Remove the bolt and steering column.

DISASSEMBLY





1. REMOVE STEERING COLUMN UPPER WITH SWITCH BRACKET ASSEMBLY
a) Using a centering punch, mark the center of the 2 tapered-head bolts.
b) Using a 3 to 4 mm (0.12 to 0.16 inch) drill, drill a hole in the 2 bolt heads.
c) Using a screw extractor, remove the 2 bolts, steering column clamp and steering column upper with switch bracket.





2. REMOVE STEERING MAIN SHAFT BUSH
Using a screwdriver and hammer, tap out the steering main shaft bush.





3. REMOVE STEERING MAIN SHAFT ASSEMBLY
a) Using a snap ring expander, remove the snap ring on the upper side.





b) Using an extension bar and hammer, tap out the steering main shaft.





c) Using a snap ring expander, remove the snap ring on the lower side.





4. REMOVE IGNITION SWITCH LOCK CYLINDER ASSEMBLY
a) Place the ignition switch lock cylinder in the ACC position.
b) Push down the stop pin with a screwdriver, and pull out the cylinder.





5. REMOVE UNLOCK WARNING SWITCH ASSEMBLY
a) Disconnect the unlock warning switch connector from the ignition switch.
b) Remove the unlock warning switch.
6. REMOVE IGNITION SWITCH ASSEMBLY
a) Remove the 2 screws and ignition or starter switch from the steering column bracket.

REASSEMBLY





1. INSTALL IGNITION SWITCH ASSEMBLY
a) Install the ignition switch to the steering column bracket with the 2 screws.
2. INSTALL UNLOCK WARNING SWITCH ASSEMBLY
a) Install the unlock warning switch.
b) Connect the unlock warning switch connector to the ignition switch.





c) Using a new clamp, fix the wire harness of the unlock warning switch to the steering column bracket upper as shown in the illustration.

NOTICE: When fixing the wire harness, do not tighten the clamp too hard. It could damage the wire harness inside.

3. INSTALL IGNITION SWITCH LOCK CYLINDER ASSEMBLY
a) Make sure that the ignition switch lock cylinder is in the ACC position.
b) Install the ignition switch lock cylinder.
4. INSPECT STEERING LOCK OPERATION
a) Check that the steering lock mechanism is activated when the key is removed.
b) Check that the steering lock mechanism is deactivated when the key is inserted and turned to the ACC position.





5. INSTALL STEERING MAIN SHAFT ASSEMBLY
a) Using a snap ring expander, install a new snap ring to the lower side.
b) Install the steering main shaft.





c) Using a snap ring expander, install a new snap ring to the upper side.





6. INSTALL STEERING MAIN SHAFT BUSH
a) Coat a new steering main shaft bush with molybdenum disulfide lithium base grease.
b) Using SST and a hammer, tap in the steering main shaft bush.
SST 09612-22011





7. INSTALL STEERING COLUMN UPPER WITH SWITCH BRACKET ASSEMBLY
a) Temporarily install the steering column upper with switch bracket and steering column clamp upper with 2 new steering lock set bolts.
b) Tighten the 2 steering lock set bolts until the bolt heads break off.

INSTALLATION





1. INSTALL STEERING COLUMN ASSEMBLY
a) Install the steering column from the front side, and install the steering column clamp to the instrumental reinforcement.
b) Install the steering column with the bolt.
Torque: 21 Nm (210 kgf-cm, 15 ft. lbs.)
c) Connect the connectors and wire harness clamps.





2. INSTALL STEERING INTERMEDIATE SHAFT ASSEMBLY
a) Align the matchmarks on the main shaft and steering intermediate shaft.
b) Install the steering intermediate shaft with the bolt.

NOTICE: Install the intermediate shaft with the distinction paint facing the steering column side.





3. CONNECT STEERING INTERMEDIATE SHAFT ASSEMBLY
a) Align the matchmarks on the sliding yoke and intermediate shaft.
b) Connect the intermediate shaft with the bolt.
Torque: 28 Nm (286 kgf-cm, 21 ft. lbs.)
4. INSTALL STEERING COLUMN HOLE COVER PLATE
a) Install the column hole cover plate with the clip.
5. INSTALL WINDSHIELD WIPER SWITCH ASSEMBLY
6. INSTALL HEADLIGHT DIMMER SWITCH ASSEMBLY
7. PLACE FRONT WHEELS FACING STRAIGHT AHEAD
8. INSTALL SPIRAL CABLE SUB-ASSEMBLY





9. CONNECT FLOOR SHIFT PARKING LOCK CABLE ASSEMBLY (for Automatic Transaxle)
a) With the key in the ACC position, connect the floor shift parking lock cable.
10. CHECK KEY INTERLOCK OPERATION





11. INSTALL STEERING COLUMN COVER
a) Install the column cover upper.
b) Install the 2 bolts.
Torque: 21 Nm (210 kgf-cm, 15 ft. lbs.)





c) Install the column cover lower with the 3 screws.
12. INSTALL SPIRAL CABLE SUB-ASSEMBLY
13. INSTALL STEERING WHEEL ASSEMBLY
a) Align the matchmarks on the steering wheel and steering main shaft.
b) Install the steering wheel with the set nut.
Torque: 50 Nm (510 kgf-cm, 37 ft. lbs.)
c) Connect the connector.
14. INSTALL STEERING PAD ASSEMBLY
15. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
16. INSPECT STEERING PAD ASSEMBLY
a) Inspect the steering pad.
17. PERFORM VSC SYSTEM CALIBRATION
a) Perform VSC system calibration.
18. INSPECT SRS WARNING LIGHT
a) Inspect the SRS warning light.
