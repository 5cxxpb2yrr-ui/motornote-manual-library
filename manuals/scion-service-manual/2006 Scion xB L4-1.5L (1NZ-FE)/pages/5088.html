Removal and Installation

Do you like it dark? Easier on the eyes.

FRONT PASSENGER AIRBAG ASSEMBLY

REMOVAL

CAUTION: Be sure to read the precautionary notices concerning the SRS airbag system before servicing it.

1. REMOVE NO. 1 INSTRUMENT PANEL SPEAKER PANEL SUB-ASSEMBLY
2. REMOVE NO. 2 INSTRUMENT PANEL SPEAKER PANEL SUB-ASSEMBLY
3. REMOVE INSTRUMENT PANEL SUB-ASSEMBLY
a. Remove the instrument panel.

NOTE: When handling the airbag connector, do not damage the airbag wire harness.

4. REMOVE FRONT PASSENGER AIRBAG ASSEMBLY




a. Remove the 2 nuts.




b. Detach the 12 claws and remove the front passenger airbag.

INSTALLATION

CAUTION: Be sure to read the precautionary notices concerning the SRS airbag system before servicing it.




1. INSTALL FRONT PASSENGER AIRBAG ASSEMBLY
a. Attach the 12 claws to install the front passenger airbag.
b. Install the 2 nuts.




2. INSTALL INSTRUMENT PANEL SUB-ASSEMBLY
a. Install the instrument panel.

NOTE: When handling the airbag connector, do not damage the airbag wire harness.

3. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
4. CHECK SRS WARNING LIGHT
a. Check the SRS warning light.
