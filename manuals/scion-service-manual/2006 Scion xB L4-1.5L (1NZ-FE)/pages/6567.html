Removal and Installation

RADIATOR

COMPONENTS:




COMPONENTS:





REMOVAL
1. DISCONNECT CABLE FROM NEGATIVE BATTERY TERMINAL

CAUTION: Wait at least 90 seconds after disconnecting the cable from the negative (-) battery terminal to prevent airbag and seat belt pretensioner activation.

2. DRAIN ENGINE COOLANT
3. DISCONNECT RADIATOR HOSE INLET
4. DISCONNECT RADIATOR HOSE OUTLET
5. DISCONNECT OIL COOLER INLET HOSE (for Automatic Transaxle)
6. DISCONNECT OIL COOLER OUTLET HOSE (for Automatic Transaxle)
7. REMOVE RADIATOR GRILLE
8. REMOVE FRONT FENDER LINER LH
9. REMOVE FRONT FENDER LINER RH
10. REMOVE FRONT BUMPER COVER





11. REMOVE HOOD LOCK ASSEMBLY
a) Remove the 3 bolts, clip and hood lock.





12. REMOVE HOOD LOCK SUPPORT BRACE
a) Remove the 5 bolts and support brace.





13. REMOVE RADIATOR SUPPORT OPENING COVER
a) Remove the 2 clips and support opening cover.





14. REMOVE RADIATOR SUPPORT SUB-ASSEMBLY UPPER
a) Disconnect the connector from the horn.
b) Remove the 2 bolts and disconnect the condenser from the radiator support upper.
c) Remove the 4 bolts and radiator support upper.





15. REMOVE RADIATOR ASSEMBLY
a) Disconnect the connector from the cooling fan motor and remove the radiator from the engine compartment.
b) Remove the 3 bolts and detach the fan shroud with fan.





c) Remove the 2 bolts and water filler.
d) Remove the 2 radiator support cushions and radiator support lower.

INSTALLATION





1. INSTALL RADIATOR ASSEMBLY
a) Install the 2 radiator support cushions and radiator support lower onto the radiator.
b) Install the water filler with the 2 bolts.
Torque: 7.5 Nm (76 kgf-cm, 66 inch lbs.)





c) Install the fan shroud with fan with the 3 bolts.
Torque: 7.5 Nm (76 kgf-cm, 66 inch lbs.)
d) Install the radiator, and connect the connector to the cooling fan motor.





2. INSTALL RADIATOR SUPPORT SUB-ASSEMBLY UPPER
a) Install the radiator support upper with the 4 bolts.
Torque: 5.0 Nm (51 kgf-cm, 44 inch lbs.) for bolt A
b) Install the condenser to the radiator support upper with the 2 bolts.
Torque: 9.8 Nm (100 kgf-cm, 7.2 ft. lbs.) for bolt B
c) Connect the connector to the horn.
3. INSTALL RADIATOR SUPPORT OPENING COVER





4. INSTALL HOOD LOCK SUPPORT BRACE
a) Install the support brace with the 5 bolts.
Torque: 5.0 Nm (51 kgf-cm, 44 inch lbs.)





5. INSTALL HOOD LOCK ASSEMBLY
a) Temporarily install the hood lock with the 3 bolts and clip.
6. ADJUST HOOD LOCK ASSEMBLY
7. INSTALL FRONT BUMPER COVER
8. INSTALL FRONT FENDER LINER LH
9. INSTALL FRONT FENDER LINER RH
10. INSTALL RADIATOR GRILLE
11. CONNECT OIL COOLER OUTLET HOSE (for Automatic Transaxle)
12. CONNECT OIL COOLER INLET HOSE (for Automatic Transaxle)
13. CONNECT RADIATOR HOSE OUTLET
14. CONNECT RADIATOR HOSE INLET
15. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
16. ADD ENGINE COOLANT
17. CHECK FOR ENGINE COOLANT LEAKS
