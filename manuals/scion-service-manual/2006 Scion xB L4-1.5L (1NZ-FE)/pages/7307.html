SUPPLEMENTAL RESTRAINT SYSTEM: AIRBAG SYSTEM: B1650/32: Occupant Classification System Malfunction

B1650/32 Occupant Classification System Malfunction

DESCRIPTION
The occupant classification system circuit consists of the center airbag sensor and the occupant classification system. When the center airbag sensor receives signals from the occupant classification ECU, it determines whether or not the front passenger airbag, front seat side airbag RH and seat belt pretensioner RH should be operated.

DTC B1650/32 is set when a malfunction is detected in the occupant classification system circuit.
