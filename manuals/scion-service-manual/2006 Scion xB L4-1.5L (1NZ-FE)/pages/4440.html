Heated Glass Element Switch: Service and Repair

WINDOW DEFOGGER SWITCH

REMOVAL

1. DISCONNECT CABLE FROM NEGATIVE BATTERY TERMINAL

CAUTION: Wait at least 90 seconds after disconnecting the cable from the negative (-) battery terminal to prevent airbag and seat belt pretensioner activation.

2. REMOVE HEATER CONTROL KNOB
3. REMOVE INSTRUMENT CLUSTER FINISH PANEL SUB-ASSEMBLY CENTER
4. REMOVE CENTER CLUSTER MODULE SWITCH

INSTALLATION

1. INSTALL CENTER CLUSTER MODULE SWITCH
2. INSTALL INSTRUMENT CLUSTER FINISH PANEL SUB-ASSEMBLY CENTER
3. INSTALL HEATER CONTROL KNOB
4. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
