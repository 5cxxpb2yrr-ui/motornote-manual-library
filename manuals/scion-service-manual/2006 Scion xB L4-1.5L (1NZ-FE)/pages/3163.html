Removal and Installation

REMOVAL




1. TABLE OF BOLT, SCREW AND NUT

HINT: All bolts, screws and nuts relevant to installing and removing the lower instrument panel are shown along with their alphabet code in the table.

2. DISCONNECT CABLE FROM NEGATIVE BATTERY TERMINAL

CAUTION: Wait at least 90 seconds after disconnecting the cable from the negative (-) battery terminal to prevent airbag and seat belt pretensioner activation.

3. REMOVE INSTRUMENT PANEL SUB-ASSEMBLY
a. Remove the instrument panel.

4. REMOVE STEERING PAD ASSEMBLY
5. REMOVE STEERING WHEEL ASSEMBLY
6. REMOVE STEERING COLUMN COVER
7. REMOVE HEADLIGHT DIMMER SWITCH ASSEMBLY
8. REMOVE WINDSHIELD WIPER SWITCH ASSEMBLY
9. REMOVE FRONT DOOR SCUFF PLATE LH
10. REMOVE FRONT DOOR SCUFF PLATE RH
11. REMOVE COWL SIDE TRIM BOARD LH
12. REMOVE COWL SIDE TRIM BOARD RH
13. REMOVE HEATER CONTROL AND ACCESSORY ASSEMBLY




14. REMOVE INSTRUMENT CLUSTER FINISH PANEL SUB-ASSEMBLY LOWER CENTER
a. Using a screwdriver, detach the 2 claws and 2 clips.

HINT: Tape the screwdriver tip before use.

b. Disconnect the connectors, and remove the instrument cluster finish panel.




15. REMOVE INSTRUMENT PANEL FINISH PANEL LOWER CENTER
a. Using a clip remover, remove the clip.
b. Using a screwdriver, detach the 3 claws, and remove the instrument panel finish panel.

HINT: Tape the screwdriver tip before use.




16. REMOVE GLOVE COMPARTMENT DOOR ASSEMBLY
a. Push the right side wall, and then push the left wall to release the stoppers.
b. Pull the glove compartment door rearward to remove it.




17. DISCONNECT FLOOR SHIFT PARKING LOCK CABLE ASSEMBLY (for Automatic Transaxle)
18. REMOVE STEERING COLUMN HOLE COVER PLATE
19. DISCONNECT STEERING INTERMEDIATE SHAFT ASSEMBLY
20. REMOVE STEERING INTERMEDIATE SHAFT ASSEMBLY
21. REMOVE STEERING COLUMN ASSEMBLY
22. REMOVE ANTENNA CORD SUB-ASSEMBLY

23. REMOVE LOWER INSTRUMENT PANEL ASSEMBLY




a. Remove the 3 bolts.




b. Remove the 3 bolts.




c. Using a clip remover, remove the clip.




d. Remove the 3 bolts.




e. Remove the bolt and No. 1 instrument panel mounting bracket.




f. Remove the screw.
g. Disconnect the connector, and remove the door control receiver.




h. Remove the bolt.
i. Disconnect the hood lock control cable.
j. Remove the 2 bolts, 2 nuts and 2 screws.
k. Remove the 2 screws and 3 nuts, and disconnect the instrument panel junction block.




l. Disconnect the connectors, and then remove the instrument panel.

INSTALLATION

1. INSTALL LOWER INSTRUMENT PANEL ASSEMBLY
a. Connect the connectors.
b. Install the instrument panel.
c. Install the instrument panel junction block assembly with the 2 screws and 3 nuts.
d. Install the 2 bolts, 2 nuts and 2 screws.




e. Connect the hood lock control cable.




f. Install the bolt.




g. Connect the connector.
h. Install the door control receiver.
i. Install the screw.




j. Install the No. 1 instrument panel mounting bracket with the bolt.




k. Install the 3 bolts




l. Install the clip.




m. Install the 3 bolts.
n. Install the 3 bolts.




2. INSTALL ANTENNA CORD SUB-ASSEMBLY
3. INSTALL STEERING COLUMN ASSEMBLY
4. INSTALL STEERING INTERMEDIATE SHAFT ASSEMBLY
5. CONNECT STEERING INTERMEDIATE SHAFT ASSEMBLY
6. INSTALL STEERING COLUMN HOLE COVER PLATE
7. CONNECT FLOOR SHIFT PARKING LOCK CABLE ASSEMBLY (for Automatic Transaxle)




8. INSTALL GLOVE COMPARTMENT DOOR ASSEMBLY
a. Push in the sides of the glove compartment door, as indicated by the arrows in the illustration. Then close the door to engage it to the 2 stoppers.




9. INSTALL INSTRUMENT PANEL FINISH PANEL LOWER CENTER
a. Attach the 3 claws to install the instrument panel finish panel.
b. Install the clip.




10. INSTALL INSTRUMENT CLUSTER FINISH PANEL SUB-ASSEMBLY LOWER CENTER
a. Connect the connectors.
b. Attach the 2 claws and 2 clips to install the instrument cluster finish panel.

11. INSTALL HEATER CONTROL AND ACCESSORY ASSEMBLY
12. INSTALL COWL SIDE TRIM BOARD LH
13. INSTALL COWL SIDE TRIM BOARD RH
14. INSTALL FRONT DOOR SCUFF PLATE LH
15. INSTALL FRONT DOOR SCUFF PLATE RH
16. INSTALL WINDSHIELD WIPER SWITCH ASSEMBLY
17. INSTALL HEADLIGHT DIMMER SWITCH ASSEMBLY
18. INSTALL STEERING COLUMN COVER
19. INSTALL STEERING WHEEL ASSEMBLY
20. INSTALL STEERING PAD ASSEMBLY
21. INSTALL INSTRUMENT PANEL SUB-ASSEMBLY
a. Install the instrument panel.

22. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
23. CHECK SRS WARNING LIGHT
a. Check the SRS warning light.
