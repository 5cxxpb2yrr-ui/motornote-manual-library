Outer Rear View Mirror

REMOVAL

HINT:
- Use the same procedures for the RH side and LH side.
- The procedures listed below are for the LH side.

1. REMOVE FRONT DOOR LOWER FRAME BRACKET GARNISH LH
2. REMOVE DOOR PULL HANDLE
3. REMOVE POWER WINDOW REGULATOR MASTER SWITCH ASSEMBLY
4. REMOVE FRONT DOOR TRIM BOARD SUB-ASSEMBLY LH
5. REMOVE FRONT DOOR SERVICE HOLE COVER LH




6. REMOVE OUTER REAR VIEW MIRROR ASSEMBLY LH
a. Disconnect the connector.
b. Remove the 3 nuts and mirror.

INSTALLATION

HINT:
- Use the same procedures for the RH side and LH side.
- The procedures listed below are for the LH side.




1. INSTALL OUTER REAR VIEW MIRROR ASSEMBLY LH
a. Install the mirror with the 3 nuts.

Torque: 8.0 N.m (82 kgf.cm, 71 in.lbf)

b. Connect the connector.

2. INSTALL FRONT DOOR SERVICE HOLE COVER LH
3. INSTALL FRONT DOOR TRIM BOARD SUB-ASSEMBLY LH
4. INSTALL POWER WINDOW REGULATOR MASTER SWITCH ASSEMBLY
5. INSTALL DOOR PULL HANDLE
6. INSTALL FRONT DOOR LOWER FRAME BRACKET GARNISH LH
