Disassembly and Reassembly

DISASSEMBLY







1. REMOVE NO. 1 HEATER TO REGISTER DUCT
a. Using nippers, cut off the ultrasonic welding portion as shown in the illustration to remove the No. 1 heater to register duct from the instrument panel.







2. REMOVE NO. 3 HEATER TO REGISTER DUCT
a. Using nippers, cut off the ultrasonic welding portion as shown in the illustration to remove the No. 3 heater to register duct from the instrument panel.







3. REMOVE NO. 1 INSTRUMENT PANEL REGISTER ASSEMBLY
a. Using nippers, cut off the ultrasonic welding portion as shown in the illustration to remove the No. 1 instrument panel register from the instrument panel.




4. REMOVE INSTRUMENT CLUSTER FINISH PANEL END
a. Remove the screw.
b. Disengage the 2 claws and remove the instrument cluster finish panel end.

5. REMOVE FRONT PASSENGER AIRBAG ASSEMBLY
6. REMOVE NO. 1 INSTRUMENT PANEL CUSHION
a. Remove the No. 1 instrument panel cushion from the instrument panel sub-assembly.

REASSEMBLY

1. INSTALL NO. 1 INSTRUMENT PANEL CUSHION
a. Install the No. 1 instrument panel cushion to the instrument panel.

2. INSTALL FRONT PASSENGER AIRBAG ASSEMBLY
3. INSTALL INSTRUMENT CLUSTER FINISH PANEL END
a. Attach the 2 claws to install the instrument cluster finish panel end.
b. Install the screw.

4. INSTALL NO. 1 INSTRUMENT PANEL REGISTER ASSEMBLY




a. Only when replacing the instrument panel with a new one: Using nippers, cut the boss off, as shown in the illustration.




b. Using a screw, install the No. 1 instrument panel register to the instrument panel.

5. INSTALL NO. 3 HEATER TO REGISTER DUCT




a. Only when replacing the instrument panel with a new one: Using nippers, cut the boss off, as shown in the illustration.




b. Using a screw, install the No. 3 heater to register duct to the instrument panel.

6. INSTALL NO. 1 HEATER TO REGISTER DUCT




a. Only when replacing the instrument panel with a new one: Using nippers, cut the boss off, as shown in the illustration.




b. Using a screw, install the No. 1 heater to register duct to the instrument panel.
