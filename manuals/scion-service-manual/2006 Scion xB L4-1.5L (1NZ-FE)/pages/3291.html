Disassembly and Reassembly

DISASSEMBLY

HINT:
- Use the same procedures for the RH side and LH side.
- The procedures listed below are for the LH side.

CAUTION: Wear protective gloves. Sharp surfaces on the seatback spring and seat adjuster may injure your hands.

1. REMOVE FRONT SEAT HEADREST ASSEMBLY
2. REMOVE FRONT SEAT INNER BELT ASSEMBLY LH
a. Remove the bolt and inner belt.




3. REMOVE RECLINING ADJUSTER RELEASE HANDLE LH
a. Raise the reclining adjuster release handle to reveal the claw.
b. Using a screwdriver, detach the claw and remove the release handle.

HINT: Tape the screwdriver tip before use.




4. REMOVE FRONT SEAT CUSHION SHIELD LH
a. Remove the 2 screws.
b. Using a screwdriver, detach the 2 claws and remove the seat cushion shield.

HINT: Tape the screwdriver tip before use.




5. REMOVE FRONT SEAT CUSHION SHIELD INNER LH
a. Remove the clip and screw.
b. Using a screwdriver, detach the claw and remove the cushion shield.

HINT: Tape the screwdriver tip before use.

6. REMOVE FRONT SEATBACK ASSEMBLY




a. Remove the hog rings.




b. Lift up the seatback cover and remove the hog rings.
c. Disconnect the clamp.




d. Remove the 4 bolts and seatback.

7. REMOVE FRONT SEATBACK COVER




a. w/ Seat hook:Remove the screw and seatback hook.




b. Lift up the seatback cover to the top of the seat, and then detach the 4 claws and remove the 2 headrest supports.
c. Remove the hog rings and the seatback cover (with pad) from the seatback spring.
d. Remove the hog ring and remove the seatback cover.




8. REMOVE FRONT SEAT CUSHION COVER
a. Remove the hog rings.
b. Detach the claw of the front part of the seat adjuster.
c. Detach the hook and remove the seat cushion cover (with pad) from seat adjuster.
d. Remove the hog rings and seat cushion cover.




9. REMOVE RECLINING ADJUSTER INSIDE COVER LH
a. Remove the screw and inside cover.

10. REMOVE RECLINING ADJUSTER INSIDE COVER RH
a. Remove the screw and inside cover.

11. REMOVE SEAT POSITION AIRBAG SENSOR

REASSEMBLY

HINT:
- Use the same procedures for the RH side and LH side.
- The procedures listed below are for the LH side.
- A bolt without a torque specification is shown in the standard bolt chart.

CAUTION: Wear protective gloves. Sharp surfaces on the seatback spring and seat adjuster may injure your hands.

1. INSTALL SEAT POSITION AIRBAG SENSOR




2. INSTALL RECLINING ADJUSTER INSIDE COVER LH
a. Install the inside cover with the screw.

3. INSTALL RECLINING ADJUSTER INSIDE COVER RH
a. Install the inside cover with the screw.

4. INSTALL FRONT SEAT CUSHION COVER

NOTE:
- Be careful not to damage the cover.
- When installing the hog rings, avoid wrinkling the cover.




a. Using hog ring pliers, install the seat cushion cover to the seat cushion pad with new hog rings.




b. Attach the hook and claw of the front part of the seat adjuster to install the seat cushion cover (with pad).
c. Using a hog ring pliers, install new hog rings.

5. INSTALL FRONT SEATBACK COVER

NOTE:
- Be careful not to damage the cover.
- When installing the hog rings, avoid wrinkling the cover.




a. Using hog ring pliers, install the seatback cover to the seatback pad with new hog rings.
b. Using hog ring pliers, install the seatback cover (with pad) to the seatback frame with new hog rings
c. Install the 2 headrest supports.




d. w/ Seat hook:Install the seatback hook with the screw.

6. INSTALL FRONT SEATBACK ASSEMBLY




a. Install the seatback with the 4 bolts.
b. Connect the clamps.




c. Lift up the seatback cover. Then using hog ring pliers, install the seat cushion cover to the seat cushion pad with new hog rings.

NOTE:
- Be careful not to damage the cover.
- When installing the hog rings, avoid wrinkling the cover.




d. Using hog ring pliers, install new hog rings.

NOTE:
- Be careful not to damage the cover.
- When installing the hog rings, avoid wrinkling the cover.




7. INSTALL FRONT SEAT CUSHION SHIELD LH
a. Attach the 2 claws to install the seat cushion shield.
b. Install the 2 screws.




8. INSTALL RECLINING ADJUSTER RELEASE HANDLE LH
a. Attach the claw to install the release handle.




9. REMOVE FRONT SEAT CUSHION SHIELD INNER LH
a. Attach the claw to install the seat cushion shield.
b. Install the clip and screw.

10. INSTALL FRONT SEAT INNER BELT ASSEMBLY LH
a. Install the inner belt with the bolt.

Torque: 42 N.m (428 kgf.cm, 31 ft.lbf)
