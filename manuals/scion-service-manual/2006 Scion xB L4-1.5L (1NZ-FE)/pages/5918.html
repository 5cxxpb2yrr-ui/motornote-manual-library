Shift Cable: Service and Repair

Do you like it dark? Easier on the eyes.

TRANSMISSION CONTROL CABLE ASSEMBLY

REPLACEMENT
1. REMOVE CONSOLE BOX REAR COVER
a) Remove the console box rear cover.
2. REMOVE CONSOLE BOX CARPET
3. REMOVE REAR CONSOLE BOX ASSEMBLY
a) Remove the rear console box.
4. REMOVE FRONT EXHAUST PIPE ASSEMBLY
a) Remove the front exhaust pipe.
5. REMOVE FRONT NO. 1 FLOOR HEAT INSULATOR
6. REMOVE AIR CLEANER ASSEMBLY
a) Remove the air cleaner assembly.





7. DISCONNECT TRANSMISSION CONTROL CABLE ASSEMBLY
a) Remove the nut, and disconnect the transmission control cable from the floor shift assembly.
b) Using a screwdriver, disconnect the transmission control cable assembly from the shift lever plate.





c) Remove the 3 bolts.
d) Pull out the transmission control cable from the body.





e) Remove the nut and disconnect the transmission control cable from the control shaft lever.
f) Remove the clip and disconnect the transmission control cable from the control cable bracket.





g) Disconnect the transmission control cable from the transmission control cable support.





8. CONNECT TRANSMISSION CONTROL CABLE ASSEMBLY
a) Temporarily install the transmission control cable on the control shaft lever with the nut.
b) Connect the transmission control cable on the bracket with a new clip.





c) Connect the transmission control cable to the transmission control cable support.





d) Install the transmission control cable on the body with the 3 bolts.
Torque: 5.0 Nm (51 kgf-cm, 44 inch lbs.)





e) Connect the transmission control cable on the shift lever plate.
f) Temporarily install the transmission control cable on the floor shift.
Torque: 2 Nm (122 kgf-cm, 9 ft. lbs.)
9. INSTALL AIR CLEANER ASSEMBLY
a) Install the air cleaner.
10. INSTALL FRONT NO. 1 FLOOR HEAT INSULATOR
11. INSTALL FRONT EXHAUST PIPE ASSEMBLY
a) Install the front exhaust pipe.
12. ADJUST SHIFT LEVER POSITION
a) Adjust the shift lever position.
13. INSPECT SHIFT LEVER POSITION
a) Inspect the shift lever position.
14. INSTALL REAR CONSOLE BOX ASSEMBLY
a) Install the rear console box.
15. INSTALL CONSOLE BOX CARPET
16. INSTALL CONSOLE BOX REAR COVER
a) Install the console box rear cover.
