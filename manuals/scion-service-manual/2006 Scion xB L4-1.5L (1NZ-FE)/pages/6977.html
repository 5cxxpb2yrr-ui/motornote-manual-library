Seat Position Sensor: Service and Repair

Do you like it dark? Easier on the eyes.

REMOVAL

CAUTION: Be sure to read the precautionary notices concerning the SRS airbag system before servicing it.

1. DISCONNECT CABLE FROM NEGATIVE BATTERY TERMINAL

CAUTION: Wait at least 90 seconds after disconnecting the cable from the negative (-) battery terminal to prevent airbag and seat belt pretensioner activation.

2. REMOVE FRONT SEAT ASSEMBLY
a. Remove the front seat assembly.




3. REMOVE SEAT POSITION AIRBAG SENSOR
a. Disconnect the connector.
b. Using a T30 "torx" socket, remove the screw and seat position sensor.

INSTALLATION

CAUTION: Be sure to read the precautionary notices concerning the SRS airbag system before servicing it.




1. INSTALL SEAT POSITION AIRBAG SENSOR
a. Connect the connector.
b. Install the sensor.
c. Using a T30 "torx" socket, install the screw.

Torque: 8.0 N.m (82 kgf.cm, 71 in.lbf)

CAUTION:
- If the sensor has been dropped, or there are any cracks, dents or other defects in the case or connector, replace the sensor with a new one.
- When installing the sensor, be careful that the SRS wiring does not interfere with other parts and that it is not pinched between other parts.

2. INSTALL FRONT SEAT ASSEMBLY
a. Install the front seat assembly.

3. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
4. CHECK SRS WARNING LIGHT
a. Check the SRS warning light.
