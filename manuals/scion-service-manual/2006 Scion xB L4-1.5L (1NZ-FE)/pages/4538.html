Marker Lamp: Service and Repair

REAR SIDE MARKER LIGHT ASSEMBLY

REMOVAL

HINT:
- Use the same procedures for the RH side and LH side.
- The procedures listed below are for the LH side.

1. DISCONNECT CABLE FROM NEGATIVE BATTERY TERMINAL
2. REMOVE REAR BUMPER SIDE SEAL LH
3. REMOVE REAR BUMPER SIDE SEAL RH
4. REMOVE REAR BUMPER COVER




5. REMOVE REAR SIDE MARKER LIGHT ASSEMBLY LH
a. Disconnect the connector.
b. Remove the nut and rear side marker light.

INSTALLATION

HINT:
- Use the same procedures for the RH side and LH side.
- The procedures listed below are for the LH side.




1. INSTALL REAR SIDE MARKER LIGHT ASSEMBLY LH
a. Install the rear side marker light with the nut.
b. Connect the connector.

2. INSTALL REAR BUMPER COVER
3. INSTALL REAR BUMPER SIDE SEAL LH
4. INSTALL REAR BUMPER SIDE SEAL RH
5. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
