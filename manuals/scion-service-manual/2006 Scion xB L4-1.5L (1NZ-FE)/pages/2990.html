Seat Belt Systems: Service and Repair

REMOVAL

HINT:
- Use the same procedures for the RH side and LH side.
- The procedures listed below are for the RH side.

1. DISCONNECT CABLE FROM NEGATIVE BATTERY TERMINAL

CAUTION: Wait at least 90 seconds after disconnecting the cable from the negative (-) battery terminal to prevent airbag and seat belt pretensioner activation.

2. REMOVE SEAT TRACK OUTER COVER RH
3. REMOVE SEAT TRACK BRACKET COVER INNER RH
4. REMOVE FRONT SEAT ASSEMBLY RH
5. REMOVE FRONT SEAT INNER BELT ASSEMBLY RH
a. Remove the bolt and inner belt.

INSTALLATION

HINT:
- Use the same procedures for the RH side and LH side.
- The procedures listed below are for the RH side.
- A bolt without a torque specification is shown in the standard bolt chart.

1. INSTALL FRONT SEAT INNER BELT ASSEMBLY RH
a. Install the inner belt with the bolt.

Torque: 42 N.m (428 kgf.cm, 31 ft.lbf)

2. INSTALL FRONT SEAT ASSEMBLY RH
3. INSTALL SEAT TRACK BRACKET COVER INNER RH
4. INSTALL SEAT TRACK OUTER COVER RH
5. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
