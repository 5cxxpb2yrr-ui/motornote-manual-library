Rear Speaker

REMOVAL

HINT:
- Use the same procedures for the RH side and LH side.
- The procedures listed below are for the LH side.

1. DISCONNECT CABLE FROM NEGATIVE BATTERY TERMINAL

CAUTION: Wait at least 90 seconds after disconnecting the cable from the negative (-) battery terminal to prevent airbag and seat belt pretensioner activation.

2. REMOVE REAR DOOR SCUFF PLATE RH
3. REMOVE REAR DOOR SCUFF PLATE LH
4. REMOVE REAR DOOR OPENING TRIM RH
5. REMOVE REAR DOOR OPENING TRIM LH
6. REMOVE REAR SEAT ASSEMBLY
a. Rear seat assembly.

7. REMOVE BACK DOOR WEATHERSTRIP
8. REMOVE SPARE WHEEL COVER ASSEMBLY
9. REMOVE DECK TRIM COVER REAR




10. REMOVE REAR SPEAKER ASSEMBLY LH
a. Disconnect the connector.
b. Remove the 3 bolts and speaker.

INSTALLATION

HINT:
- Use the same procedures for the RH side and LH side.
- The procedures listed below are for the LH side.




1. INSTALL REAR SPEAKER ASSEMBLY
a. Connect the connector.
b. Install the speaker with the 3 bolts.

2. INSTALL DECK TRIM COVER REAR
3. INSTALL SPARE WHEEL COVER ASSEMBLY
4. INSTALL BACK DOOR WEATHERSTRIP
5. INSTALL REAR SEAT ASSEMBLY
a. Rear seat assembly.

6. INSTALL REAR DOOR OPENING TRIM RH
7. INSTALL REAR DOOR OPENING TRIM LH
8. INSTALL REAR DOOR SCUFF PLATE RH
9. INSTALL REAR DOOR SCUFF PLATE LH
10. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
