ON-VEHICLE INSPECTION
1. CHECK CLUTCH START SYSTEM
a) Check that the engine does not start when the clutch pedal is released.
b) Check that the engine starts when the clutch pedal is fully depressed.
If necessary, replace the clutch start switch assembly.

REMOVAL





1. REMOVE CLUTCH START SWITCH ASSEMBLY
a) Disconnect the clutch start switch connector.
b) Remove the 2 nuts and clutch start switch with the bracket.
c) Remove the nut and clutch start switch from the bracket.

1. INSPECT CLUTCH START SWITCH ASSEMBLY
