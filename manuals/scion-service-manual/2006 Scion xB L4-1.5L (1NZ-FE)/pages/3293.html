Disassembly and Reassembly

DISASSEMBLY

CAUTION: Wear protective gloves. Sharp areas on the seatback frame may injure your hands.

1. REMOVE REAR SEAT HEADREST ASSEMBLY
a. Remove the 3 headrests.

2. REMOVE REAR SEATBACK HINGE SUB-ASSEMBLY LH
a. Remove the bolt and seatback hinge.

3. REMOVE REAR SEATBACK HINGE SUB-ASSEMBLY RH
a. Remove the bolt and seatback hinge.

4. REMOVE REAR SEATBACK LOCK RELEASE BUTTON
a. Remove the 2 buttons.




5. REMOVE REAR SEAT SHOULDER BELT COVER (for RH Side)
a. Using a screwdriver, pry out the shoulder belt cover.

HINT: Tape the screwdriver tip before use.




6. REMOVE TETHER ANCHOR COVER
a. Using a screwdriver, pry out the 3 tether anchor covers.

HINT: Tape the screwdriver tip before use.

7. REMOVE REAR SEAT HEADREST SUPPORT




a. Using a clip remover, remove the 17 clips.

NOTE: If clips are damaged during removal, replace them.

b. Remove the hog rings.




c. Detach the claws and remove the 6 headrest supports.

HINT: In order to detach the claw of the headrest support, insert your hand between the seatback frame and the seatback cover (with pad).




8. REMOVE REAR SEATBACK STOP BUTTON GROMMET
a. Detach the claws and remove the 2 grommets.

HINT: In order to detach the claw of the headrest support, insert your hand between the seatback frame and the seatback cover (with pad).

9. REMOVE REAR SEATBACK COVER WITH PAD LH
a. Remove the seatback cover (with pad) from the seatback frame.

10. REMOVE REAR SEATBACK COVER WITH PAD RH
a. Remove the seatback cover (with pad) from the seatback frame.




11. REMOVE REAR SEATBACK LOCK ASSEMBLY LH
a. Remove the 2 bolts and lock.

12. REMOVE REAR SEATBACK LOCK ASSEMBLY RH
a. Remove the 2 bolts and lock.

13. REMOVE REAR SEAT BELT ASSEMBLY OUTER CENTER
a. Remove the nut and belt.

REASSEMBLY

CAUTION: Wear protective gloves. Sharp areas on the seatback frame may injure your hands.

1. INSTALL REAR SEAT BELT ASSEMBLY OUTER CENTER
a. Install the belt with the nut.

Torque: 42 N.m (428 kgf.cm, 31 ft.lbf)




2. INSTALL REAR SEATBACK LOCK ASSEMBLY LH
a. Install the lock with the 2 bolts.

3. INSTALL REAR SEATBACK LOCK ASSEMBLY RH
a. Install the lock with the 2 bolts.

4. INSTALL REAR SEATBACK COVER WITH PAD LH
a. Install the seatback cover (with pad) to the seatback frame.

NOTE: Be careful not to damage the cover.

5. INSTALL REAR SEATBACK COVER WITH PAD RH

HINT: Use the same procedures described for the LH side.




6. INSTALL REAR SEATBACK STOP BUTTON GROMMET
a. Attach the claws to install the 2 grommets.

7. INSTALL REAR SEAT HEADREST SUPPORT




a. Attach the claws to install the 6 headrest supports.




b. Using hog ring pliers, install the seatback cover (with pad) to the seatback frame with new hog rings.

NOTE:
- Be careful not to damage the cover.
- When installing the hog rings, avoid wrinkling the cover.




c. Install the 17 clips.




8. INSTALL TETHER ANCHOR COVER
a. Install the 3 tether anchor covers.




9. INSTALL REAR SEAT SHOULDER BELT COVER (for RH Side)
a. Attach the claws to install the shoulder belt cover.

10. INSTALL REAR SEATBACK LOCK RELEASE BUTTON
a. Install the 2 buttons.

11. INSTALL REAR SEATBACK HINGE SUB-ASSEMBLY LH
a. Install the seatback hinge with the bolt.

Torque: 42 N.m (428 kgf.cm, 31 ft.lbf)

12. INSTALL REAR SEATBACK HINGE SUB-ASSEMBLY RH
a. Install the seatback hinge with the bolt.

Torque: 42 N.m (428 kgf.cm, 31 ft.lbf)

13. INSTALL REAR SEAT HEADREST ASSEMBLY
a. Install the 3 headrests.
