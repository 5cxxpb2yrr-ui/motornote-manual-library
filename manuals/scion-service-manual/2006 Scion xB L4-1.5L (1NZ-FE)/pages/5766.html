Installation

BRAKE MASTER CYLINDER

COMPONENTS:





INSTALLATION





1. INSTALL BRAKE MASTER CYLINDER RESERVOIR SUB-ASSEMBLY
a) Apply lithium soap base glycol grease to 2 new grommets and install them to the brake master cylinder.
b) Install the cap and strainer to the brake master cylinder reservoir.





c) Install the brake master cylinder reservoir with the reservoir stopper.

NOTICE: Install the stopper securely to the groove of the reservoir and master cylinder.





2. INSTALL BRAKE MASTER CYLINDER SUBASSEMBLY
a) Install the brake master cylinder to the booster with the 2 nuts.
Torque: 13 Nm (127 kgf-cm, 9 ft. lbs.)





b) Using SST, connect the 2 brake lines to the brake master cylinder.
SST 09023-00101
Torque: 15 Nm (155 kgf-cm, 11 ft. lbs.) without SST
14 Nm (143 kgf-cm, 10 ft. lbs.) with SST

HINT: Use a torque wrench with a fulcrum length of 30 cm (11.81 inch).

c) Connect the level warning light switch connector.
3. CONNECT CLUTCH RESERVOIR TUBE (for Manual Transaxle)
a) Slide the clip and connect the clutch reservoir tube.
4. INSTALL AIR CLEANER CAP SUB-ASSEMBLY
5. FILL RESERVOIR WITH BRAKE FLUID
6. BLEED AIR FROM BRAKE MASTER CYLINDER
7. BLEED AIR FROM BRAKE LINE
8. BLEED AIR FROM CLUTCH LINE (for Manual Transaxle)
9. CHECK BRAKE FLUID LEVEL IN RESERVOIR
10. CHECK FOR BRAKE FLUID LEAKAGE
