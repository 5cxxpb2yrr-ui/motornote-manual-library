Antenna, Radio: Service and Repair

RADIO ANTENNA HOLDER

REMOVAL

1. DISCONNECT CABLE FROM NEGATIVE BATTERY TERMINAL

CAUTION: Wait at least 90 seconds after disconnecting the cable from the negative (-) battery terminal to prevent airbag and seat belt pretensioner activation.

2. REMOVE ROOF HEADLINING ASSEMBLY
a. Remove the headlining.

3. REMOVE INSTRUMENT PANEL SUB-ASSEMBLY
a. Remove the instrument panel.




4. REMOVE ANTENNA HOLDER ASSEMBLY
a. Disconnect the connectors.
b. Remove the 19 clamps and 3 bolts.
c. Remove the antenna holder.

INSTALLATION




1. INSTALL ANTENNA HOLDER ASSEMBLY
a. Install the antenna holder with 19 clamps and 3 bolts.
b. Connect the connectors.

2. INSTALL INSTRUMENT PANEL SUB-ASSEMBLY
a. Install the instrument panel.

3. INSTALL ROOF HEADLINING ASSEMBLY
a. Install the roof headlining.

4. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
