Exhaust Pipe: Installation

  1. INSTALL HEATED OXYGEN SENSOR (for Bank 1 Sensor 2) 
    1. Using SST, install the sensor to the front exhaust pipe.
      Fig 1: Installing Heated Oxygen Sensor (For Bank 1 Sensor 2)
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002

      SST 09224-00010 

      Torque: 40 N*m (408 kgf*cm, 30 ft.*lbf) for use with SST 

      44 N*m (449 kgf*cm, 32 ft.*lbf) for use without SST 

      HINT:

      Use a torque wrench with a fulcrum length of 30 cm (11.81 in.).

  2. REMOVE HEATED OXYGEN SENSOR (for Bank 1 Sensor 1) 
    1. Using SST, install the sensor to the front exhaust pipe.
      Fig 2: Installing Heated Oxygen Sensor (For Bank 1 Sensor 1)
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002

      SST 09224-00010 

      Torque: 40 N*m (408 kgf*cm, 30 ft.*lbf) for use with SST 

      44 N*m (449 kgf*cm, 32 ft.*lbf) for use without SST 

      HINT:

      Use a torque wrench with a fulcrum length of 30 cm (11.81 in.).

  3. INSTALL FRONT EXHAUST PIPE 
    1. Using a vernier caliper, measure the free length of the compression spring.
      Fig 3: Checking Free Length Of Compression Spring
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002

      Minimum length: 40.5 mm (1.594 in.) 

      If the length is less than the minimum, replace the compression spring.

    2. Using a plastic-faced hammer and wooden block, tap in a new gasket until its surface is flush with the exhaust manifold.
      Fig 4: Installing Gasket
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
      NOTE:
      • Tap in the gasket in the correct direction.
      • Do not reuse the removed gasket.
      • Do not to push in the gasket while installing the exhaust pipe.
    3. Connect the 2 exhaust pipe supports, and install the exhaust pipe.
    4. Install the 2 compression springs and 2 bolts.

      Torque: 43 N*m (438 kgf*cm, 32 ft.*lbf) 

    5. Connect the 2 heated oxygen sensor connectors.
    6. Install the grommet.
      Fig 5: Installing Front Exhaust Pipe
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  4. INSTALL TAILPIPE 
    1. Install a new gasket onto the front exhaust pipe.
    2. Connect the 2 exhaust pipe supports, and install the tailpipe.
    3. Install the clamp with the bolt as shown in the illustration.

      Torque: 32 N*m (326 kgf*cm, 24 ft.*lbf) 

    Fig 6: Installing Tailpipe
    Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  5. CHECK FOR EXHAUST GAS LEAKS 
  6. INSTALL FRONT PANEL BRACE 
    1. Install the floor panel brace with the 2 bolts.
      Fig 7: Installing Front Panel Brace
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002

      Torque: 20 N*m (204 kgf*cm, 14 ft.*lbf) 

  7. INSTALL REAR CONSOLE BOX (See  INSTALLATION  ) 
  8. INSTALL SHIFT LEVER KNOB (for Manual Transaxle) 
  9. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
