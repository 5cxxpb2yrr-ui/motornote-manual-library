Parking Brake Lever: Installation

  1. INSTALL PARKING BRAKE SWITCH ASSEMBLY 
    1. Install the parking brake switch with the screw.
  2. INSTALL PARKING BRAKE LEVER SUB-ASSEMBLY 
    1. Connect the parking brake pull rod to the lever.
    2. Install the parking brake lever with the 2 bolts.

      Torque: 13 N*m (127 kgf*cm, 9 ft.*lbf) 

    3. Connect the parking brake switch connector.
  3. INSTALL NO. 1 WIRE ADJUSTING NUT 
    1. Install the wire adjusting nut and lock nut.

      Torque: 5.4 N*m (55 kgf*cm, 48 in.*lbf)
