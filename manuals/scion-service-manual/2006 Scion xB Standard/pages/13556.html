Inspection Procedure

  1. INSPECT FUSE (ECU-IG) 
    1. Remove the ECU-IG fuse from the instrument panel junction block.
    2. Measure the resistance of the fuse.

      Standard resistance: Below 1 Ω 

      Result 

      RESULT REFERENCE

      Result Proceed to
      OK (when using intelligent tester) A
      OK (when not using intelligent tester) B
      NG C

    B: Go to step   3 

    C: REPLACE FUSE 

    A: Go to next step 

  2. READ DATA LIST (IG1 VOLTAGE) 
    1. Check the DATA LIST for proper functioning of the IG voltage.

      Skid control ECU with actuator 

      MEASUREMENT ITEM DIAGNOSTIC CHART

      Item Measurement Item / Range (Display) Normal Condition Diagnostic Note
      IG VOLTAGE ECU power supply voltage / NORMAL / TOO LOW NORMAL: 9.5 to 14 V
      TOO LOW: Below 9.5 V      		 -

      Result 

      RESULT REFERENCE

      Result Proceed to
      Display is not NORMAL A
      Display is NORMAL B

      HINT:

      When replacing the skid control ECU with actuator, perform the zero point calibration (see CALIBRATION  ).

    B: REPLACE BRAKE ACTUATOR ASSEMBLY 

    A: Go to next step 

  3. CHECK WIRE HARNESS (SKID CONTROL ECU - BATTERY AND BODY GROUND) 
    1. Disconnect the S3 ECU connector.
    2. Measure the voltage of the wire harness side connector.

      Standard voltage 

      TESTER CONNECTION SPECIFIED CONDITION

      Tester Connection Condition Specified Condition
      S3-46 (IG1) - Body ground Ignition switch ON 10 to 14 V
    3. Measure the resistance of the wire harness side connector.

      Standard resistance 

      TESTER CONNECTION SPECIFIED CONDITION

      Tester Connection Specified Condition
      S3-32 (GND1) - Body ground Below 1 Ω
      S3-1 (GND2) - Body ground

    NG: REPAIR OR REPLACE HARNESS AND CONNECTOR 

    OK: Go to Next Step 

  4. CHECK IF DTC OUTPUT RECURS 
    1. Clear the DTCs (see DTC CHECK / CLEAR  ).
    2. Drive the vehicle at approximately 30 km/h (19 mph) or more for 60 seconds or more.
    3. Check for DTCs (see DTC CHECK / CLEAR  ).

      Result 

      RESULT REFERENCE

      Result Proceed to
      DTC is output A
      DTC is not output B

      HINT:

      When replacing the skid control ECU with actuator, perform the zero point calibration (see CALIBRATION  ).

    B: END 

    A: REPLACE BRAKE ACTUATOR ASSEMBLY
