Clutch Release Cylinder: Reassembly

  1. INSTALL RELEASE CYLINDER BLEEDER PLUG Torque: 8.4 N*m (85 kgf*cm, 74 in.*lbf) 
  2. INSTALL CLUTCH RELEASE CYLINDER KIT 
    1. Install the bleeder plug cap on the bleeder plug.
    2. Install a new spring on the cylinder body.
    3. Coat the parts with lithium soap base glycol grease to the areas shown in the illustration.
    4. Install the piston on the cylinder body.
      NOTE: Be careful not to damage the inside of the cylinder body.
    5. Install the push rod on the cylinder body.
    6. Install the boot on the cylinder body.
      Fig 1: Installing Clutch Release Cylinder Kit

  3. INSTALL CLUTCH RELEASE UNION 
    1. Install the clutch release union with the union bolt and 2 new gaskets.

      Torque: 25 N*m (250 kgf*cm, 18 ft.*lbf) 

      NOTE: Installation angle of the clutch release union should be 0°+-3° against the body.
