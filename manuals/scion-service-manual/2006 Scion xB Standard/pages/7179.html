DTC C1201/51 Engine Control System Malfunction: Description

If trouble occurs in the engine control system, the skid control ECU prohibits TRAC and VSC control.

TROUBLE AREA INDEX REFERENCE

DTC No. DTC Detection Condition Trouble Area
C1201/51 At engine speed of 500 rpm or more, a trouble signal in engine control system continues for 5 seconds or more Engine control system
