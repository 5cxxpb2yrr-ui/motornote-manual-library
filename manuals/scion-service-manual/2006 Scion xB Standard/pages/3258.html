Inspection Procedure

  1. READ CURRENT DTC 
    1. Connect the intelligent tester to the CAN VIM. Then connect the CAN VIM to the DLC3.
    2. Turn the ignition switch ON and turn the tester ON.
    3. Enter the following menus: DIAGNOSIS / ENHANCED OBD II / DAC INFO / CURRENT CODES.
    4. Read DTCs.

    Result 

    RESULT

    Display (DTC Output) Proceed to
    P0630 A
    P0630 and other DTCs B

    If any DTCs other than P0630 are output, troubleshoot those DTCs first.

    NOTE: If P0630 is set, the VIN must be input to the ECM using the intelligent tester. However, all DTCs are cleared automatically by the tester when inputting the VIN. If DTCs other than P0630 are set, check them first.

    B: GO TO  DTC CHART  

    A: Go to next step 

  2. INPUT VIN WITH INTELLIGENT TESTER 
    1. Input the VIN with the intelligent tester (see REGISTRATION  ).
