Installation (2005/07-2005/12)

HINT:

  • Use the same procedures for the RH side and LH side.
  • The procedures listed below are for the LH side.
  1. INSTALL FRONT SEAT ASSEMBLY 
    1. Place the seat in the cabin.
      NOTE: Be careful not to damage the vehicle body.
    2. Connect the connectors under the seat.
    3. Install the 4 bolts.

      Torque: 37 N*m (375 kgf*cm, 27 ft.*lbf) 

  2. INSTALL SEAT TRACK OUTER COVER LH 
    1. Attach the 4 claws to install the seat track outer cover.
      Fig 1: Attaching Claws To Install Seat Track Outer Cover
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  3. INSTALL SEAT TRACK BRACKET COVER INNER LH 
    1. Attach the 2 claws to install the seat track bracket cover.
  4. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
