Cooling (1NZ-FE): Thermostat: Installation

  1. INSTALL THERMOSTAT 
    1. Install a new gasket onto the thermostat.
    2. Install the thermostat with the jiggle valve facing upward.
      Fig 1: Installing Thermostat
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002

      HINT:

      The jiggle valve may be set within 10° of either side as shown in the illustration.

  2. INSTALL WATER INLET 
    1. Install the water inlet to the cylinder block with the 2 nuts.
      Fig 2: Installing Water Inlet
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002

      Torque: 9.0 N*m (92 kgf*cm, 80 in.*lbf) 

      NOTE: Ensure that the gasket is not stuck between the water inlet and cylinder block.
  3. ADD ENGINE  COOLANT  
  4. CHECK FOR ENGINE COOLANT LEAKS (See  WATER PUMP   )
