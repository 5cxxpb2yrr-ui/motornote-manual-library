Ignition Coil: Installation

  1. INSTALL IGNITION COIL ASSEMBLY 
    1. Install the 4 ignition coils with the 4 bolts.
      Fig 1: Installing Ignition Coils
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002

      Torque: 9.0 N*m (90 kgf*cm, 80 in.*lbf) 

    2. Connect the 4 ignition coil connectors.
  2. INSTALL NO. 2 CYLINDER HEAD COVER 
    1. Install the head cover with the 4 cap nuts.

      Torque: 7.0 N*m (71 kgf*cm, 62 in.*lbf) 

  3. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
