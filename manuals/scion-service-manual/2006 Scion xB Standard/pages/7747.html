Upper Instrument Panel: Reassembly

  1. INSTALL NO. 1 INSTRUMENT PANEL CUSHION 
    1. Install the No. 1 instrument panel cushion to the instrument panel.
  2. INSTALL FRONT PASSENGER AIRBAG ASSEMBLY (See  INSTALLATION  ) 
  3. INSTALL INSTRUMENT CLUSTER FINISH PANEL END 
    1. Attach the 2 claws to install the instrument cluster finish panel end.
    2. Install the screw.
  4. INSTALL NO. 1 INSTRUMENT PANEL REGISTER ASSEMBLY 
    1. Only when replacing the instrument panel with a new one:

      Using nippers, cut the boss off, as shown in the illustration.

      Fig 1: Cutting Boss Off Using Nippers
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    2. Using a screw, install the No. 1 instrument panel register to the instrument panel.
      Fig 2: Installing No. 1 Instrument Panel Register To Instrument Panel Using Screw
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  5. INSTALL NO. 3 HEATER TO REGISTER DUCT 
    1. Only when replacing the instrument panel with a new one:

      Using nippers, cut the boss off, as shown in the illustration.

      Fig 3: Cutting Boss Off Using Nippers
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    2. Using a screw, install the No. 3 heater to register duct to the instrument panel.
      Fig 4: Installing No. 3 Heater To Register Duct To Instrument Panel Using Screw
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  6. INSTALL NO. 1 HEATER TO REGISTER DUCT 
    1. Only when replacing the instrument panel with a new one:

      Using nippers, cut the boss off, as shown in the illustration.

      Fig 5: Cutting Boss Off Using Nippers
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    2. Using a screw, install the No. 1 heater to register duct to the instrument panel.
      Fig 6: Installing No. 1 Heater To Register Duct To Instrument Panel Using Screw
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
