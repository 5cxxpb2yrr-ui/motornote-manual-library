Air Fuel Ratio Sensor Drive Cycle

P2195, P2196 

Fig 1: Drive Cycle Pattern 19 (P2195, P2196)
Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  1. Connect the Techstream to the DLC3.
  2. Turn the ignition switch to ON and turn the Techstream on.
  3. Clear DTCs (even if no DTCs are stored, perform the clear DTC operation).
  4. Turn the ignition switch off and wait for at least 30 seconds.
  5. Turn the ignition switch to ON and turn the Techstream on.
  6. Start the engine and warm it up until the engine coolant temperature reaches 75°C (167°F) or higher.
    NOTE: Check the engine coolant temperature is 20°C (68°F) or less at engine started.
    7. CAUTION: When performing the confirmation driving pattern, obey all speed limits and traffic laws.
  7. Perform the following the confirmation driving pattern.
    1. Drive the vehicle at 80 km/h (50 mph) or more for 20 minutes or more [A].
    2. Stop the vehicle.
    3. Idle the engine for 1 minute or more [B].
  8. Enter the following menus: Powertrain / Engine / Trouble Codes.
  9. Read pending DTCs.
    NOTE:
    • If a pending DTC is output, the system is malfunctioning.
    • If a pending DTC is not output, perform the following procedure.
  10. Enter the following menus: Powertrain / Engine / Utility / All Readiness.
  11. Input the DTC: P2195 or P2196.
  12. Check the DTC judgment result.
    JUDGMENT RESULT

    TECHSTREAM DISPLY DESCRIPTION
    NORMAL
    • DTC judgment completed
    • System normal
    ABNORMAL
    • DTC judgment completed
    • System abnormal
    INCOMPLETE
    • DTC judgment not completed
    • Perform driving pattern after confirming DTC enabling conditions
    UNKNOWN
    • Unable to perform DTC judgment
    • Number of DTCs which do not fulfill DTC preconditions has reached ECU's memory limit
    NOTE:
    • If the judgment result shows NORMAL, the system is normal.
    • If the judgment result shows ABNORMAL, the system has a malfunction.
  13. If the test result is INCOMPLETE or N/A and no DTC is output, perform a universal trip and check for permanent DTCs.
    NOTE:
    • If a permanent DTC is output, the system is malfunctioning.
    • If no permanent DTC is output, the system is normal.
