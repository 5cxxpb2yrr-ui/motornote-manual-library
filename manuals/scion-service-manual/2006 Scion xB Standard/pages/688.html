Yaw Rate Sensor Communication Stop Mode: Description

SYMPTOM DESCRIPTION

Detection Item Symptom Trouble Area
YAW RATE SENSOR COMMUNICATION STOP MODE
  • YAW / DECELERAT is not displayed on the "BUS CHECK" screen of the intelligent tester
  • Applies to "YAW RATE SENSOR COMMUNICATION STOP MODE" in the "DTC, BUS CHECK COMBINATION TABLE"
  • Power source or inside the yaw rate sensor
  • Yaw rate sensor sub line and connector
