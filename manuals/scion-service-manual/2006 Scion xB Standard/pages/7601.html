Back Door: Reassembly

HINT:

A bolt without a torque specification is shown in the standard bolt chart (see SPECIFIED TORQUE FOR STANDARD BOLTS ).

  1. INSTALL BACK DOOR STOPPER LOWER 
    1. Install the stopper LH and RH with the bolt.

      Torque: 12.5 N*m (112 kgf*cm, 9 ft.*lbf) 

  2. INSTALL BACK DOOR STAY SUB-ASSEMBLY LH (See  BACK DOOR SUPPORT   ) 
  3. INSTALL BACK DOOR STAY SUB-ASSEMBLY RH 
    1. Use the same procedures described for the LH side.
  4. INSTALL DOOR PULL HANDLE 
    1. Attach the 4 claws and install the pull handle.
  5. INSTALL BACK WINDOW GLASS CHANNEL LH 
    1. Clean the contact surface of the door with a sponge saturated with white gasoline.
    2. Using a heat light, heat the door and new channel.

      Standard heating temperature 

      STANDARD HEATING TEMPERATURE

      Item Specified Condition
      Door 40 to 60°C (104 to 140°F)
      Channel 20 to 30°C (68 to 86°F)
      NOTE: Do not heat the door and channel excessively.
      Fig 1: Installing Pull Handle

    3. Remove peeling paper from the channel face.
    4. Install the channel and 2 clips.
  6. INSTALL BACK WINDOW GLASS CHANNEL RH 
    1. Use the same procedures described for the LH side.
  7. INSTALL BACK DOOR LOCK ASSEMBLY 
    1. Install the door lock with the 3 bolts.

      Torque: 12.5 N*m (112 kgf*cm, 9 ft.*lbf) 

    2. Connect the door lock connector.
  8. INSTALL REAR WIPER MOTOR ASSEMBLY (See  INSTALLATION  ) 
  9. INSTALL CENTER STOP LIGHT ASSEMBLY (See  INSTALLATION  ) 
  10. INSTALL BACK DOOR GARNISH OUTSIDE (See  INSTALLATION  )

  11. INSTALL BACK DOOR TRIM BOARD 
    1. Install the trim board with the 11 clips.
  12. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
