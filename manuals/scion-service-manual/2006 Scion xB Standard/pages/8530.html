Rear Axle Hub Bolt: Replacement

HINT:

  • Use the same procedures for the RH side and LH side.
  • The procedures listed below are for the LH side.
  1. REMOVE REAR WHEEL 
  2. REMOVE REAR BRAKE DRUM SUB-ASSEMBLY 
  3. REMOVE REAR AXLE HUB BOLT 
    1. Using SST and a screwdriver or an equivalent, remove the hub bolt.

      SST 09628-10011 

      Fig 1: Removing Rear Axle Hub Bolt
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  4. INSTALL REAR AXLE HUB BOLT 
    1. Install the washer and nut to a new hub bolt as shown in the illustration.
    2. Using a screwdriver or an equivalent to hold the hub and bearing assembly, install the hub bolt by tightening the nut.
      Fig 2: Installing Rear Axle Hub Bolt
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  5. INSTALL REAR BRAKE DRUM SUB-ASSEMBLY 
  6. INSTALL REAR WHEEL 

    Torque: 103 N*m (1,050 kgf*cm, 76 ft.*lbf)
