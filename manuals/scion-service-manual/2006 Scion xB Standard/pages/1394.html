Front Axle Hub Bolt: Replacement

  1. REMOVE FRONT WHEEL 
  2. DISCONNECT FRONT DISC BRAKE CYLINDER ASSEMBLY 
    1. Disconnect the front disc brake cylinder assembly (see REMOVAL ).
  3. REMOVE FRONT DISC 
  4. REMOVE FRONT AXLE HUB BOLT 
    1. Using SST and a screwdriver or an equivalent to hold the axle hub, remove the hub bolt.

      SST 09628-10011 

      Fig 1: Removing Front Axle Hub Bolt
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  5. INSTALL FRONT AXLE HUB BOLT 
    1. Install the washer and nut to a new hub bolt as shown in the illustration.
    2. Using a screwdriver or an equivalent to hold the axle hub, install the hub bolt by tightening the nut.
  6. INSTALL FRONT DISC 
  7. CONNECT FRONT DISC BRAKE CYLINDER ASSEMBLY 
    1. Connect the front disc brake cylinder assembly (see INSPECTION ).
  8. INSTALL FRONT WHEEL 

    Torque: 103 N*m (1,050 kgf*cm, 76 ft.*lbf)
