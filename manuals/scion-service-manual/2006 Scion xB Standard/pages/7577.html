Front Bumper: Reassembly

  1. INSTALL FOG LIGHT COVER LH 
    1. Attach the 4 claws to install the cover.
  2. INSTALL FOG LIGHT COVER RH 
    1. Attach the 4 claws to install the cover.
  3. INSTALL RADIATOR GRILLE UPPER 
    1. Attach the 13 claws to install the grille upper.
  4. INSTALL FRONT SPOILER 
    1. Attach the 4 claws to install the spoiler.
    2. Install the 4 screws.
  5. INSTALL FRONT BUMPER EXTENSION MOUNTING BRACKET LH 
    1. Attach the 4 claws to install the mounting bracket.
  6. INSTALL FRONT BUMPER EXTENSION MOUNTING BRACKET RH 

    HINT:

    Use the same procedures for the RH side and LH side.

  7. INSTALL RADIATOR GRILLE LOWER 
    1. Attach the 9 claws to install the grille lower.
