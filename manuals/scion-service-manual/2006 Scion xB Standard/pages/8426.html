Clutch Unit: Installation

  1. INSTALL CLUTCH DISC ASSEMBLY 
    1. Insert SST in the disc, then insert them in the flywheel.

      SST 09301-00210 

      NOTE: Take care not to insert the clutch disc in the wrong direction.
      Fig 1: Inserting SST In Disc
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  2. INSTALL CLUTCH COVER ASSEMBLY 
    1. Align the matchmark on the cover with that on the flywheel.
    2. Following the procedures shown in the illustration, tighten the 6 bolts in order, and start with the bolt located near the knock pin on the top.

      Torque: 19 N*m (195 kgf*cm, 14 ft.*lbf) 

      HINT:

      • Following the order in the illustration, tighten the bolts one at a time evenly.
      • Move SST up and down, right and left lightly after checking that the disc is in the center to tighten the bolts.

      SST 09301-00210 

      Fig 2: Aligning Matchmark On Cover
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  3. INSPECT AND ADJUST CLUTCH COVER ASSEMBLY 
    Fig 3: Checking Disc Position
    Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    1. Using a dial indicator with the roller instrument, measure the diaphragm spring tip alignment.

      Maximum misalignment: 0.5 mm (0.020 in.) 

      If the alignment is greater than the maximum, use SST to adjust the diaphragm spring tip alignment.

      SST 09333-00013 

  4. INSTALL RELEASE FORK SUPPORT 
    1. Install the release fork support on the transaxle.

      Torque: 37 N*m (375 kgf*cm, 27 ft.*lbf) 

      Fig 4: Measuring Diaphragm Spring Tip Alignment
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  5. INSTALL CLUTCH RELEASE FORK BOOT 
  6. INSTALL RELEASE BEARING HUB CLIP 
  7. INSTALL CLUTCH RELEASE FORK SUB-ASSEMBLY 
    1. Apply release hub grease to the contact surfaces of the release fork and release bearing, fork and push rod, and fork and fork support.

      Release hub grease: Part No. 08887-01806, RELEASE HUB GREASE or equivalent 

    2. Install the fork to the release bearing.
      Fig 5: Applying Release Hub Grease To Contact Surfaces Of Release Fork And Release Bearing
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  8. INSTALL CLUTCH RELEASE BEARING ASSEMBLY 
    1. Apply clutch spline grease to the input shaft spline.

      Clutch spline grease: Part No. 08887-01706, CLUTCH SPLINE GREASE or equivalent 

    2. Install the bearing with release fork to the transaxle.
      NOTE: After the installation, move the fork forward and backward to check that the release bearing slides smoothly.
