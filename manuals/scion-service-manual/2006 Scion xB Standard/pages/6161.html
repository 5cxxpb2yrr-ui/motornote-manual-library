Heater Radiator Assembly: Reassembly

  1. INSTALL HEATER RADIATOR UNIT SUB-ASSEMBLY 
    1. Install the heater radiator unit sub-assembly.
    2. Attach the clamp to connect the connector.
    3. Install the bracket with the screw.
      Fig 1: Installing Bracket With Screw

    4. Install the No. 2 cooler wiring with the 4 screws.
      Fig 2: Installing No. 2 Cooler Wiring With 4 Screws
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  2. INSTALL THERMISTOR ASSEMBLY 
    1. Install the thermistor.
    2. Install the clamp and attach the claw.
      Fig 3: Installing Clamp And Attach Claw
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  3. INSTALL HEATER COVER 
    1. Attach the 2 claws to install the heater cover.
    2. Install the screw.

  4. INSTALL AIR DUCT ASSEMBLY
