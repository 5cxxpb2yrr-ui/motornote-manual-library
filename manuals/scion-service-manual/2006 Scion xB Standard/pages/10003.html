Introduction

In the event that either or both of the rear coil springs are removed for any reason, use the following procedure to ensure the proper installation of the rear coil springs.

Applicable Vehicles

  • 2004 - 2006  model year Scion xA  and xB  vehicles.

Installation Procedure

NOTE: The installation procedure is the same for both the LH and RH side.
  1. Install the lower coil spring insulator onto the axle beam.
  2. Install the upper coil spring insulator so that its gap fits onto the end of the coil spring.
    Fig 1: Installing Lower Coil Spring Insulator
    Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  3. Install the coil spring onto the lower coil spring insulator already installed on the axle beam.
    Fig 2: Identifying Paint Mark On Coil Spring
    Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    NOTE: The paint mark of the coil spring should be toward the axle beam and rear side of the vehicle.
