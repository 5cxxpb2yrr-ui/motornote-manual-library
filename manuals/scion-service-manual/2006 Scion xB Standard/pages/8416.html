Clutch Master Cylinder: Reassembly

  1. INSTALL CLUTCH MASTER CYLINDER KIT 
    1. Coat the parts shown in the illustration with lithium soap base glycol grease.
    2. Install the piston with spring into the cylinder body.
      NOTE: Be careful not to damage the inside of the cylinder body.
      Fig 1: Coating Parts With Lithium Soap Base Glycol Grease
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    3. Install the stop plate to the push rod.
    4. Install the push rod to the cylinder body.
    5. While pushing the push rod, install the snap ring with snap ring pliers.
    6. Install the boot on the cylinder body.
    7. Install the lock nut on the push rod.
    8. Temporarily install the push rod clevis with the lock nut on the push rod.
    9. Install the inlet union and a new grommet.
      Fig 2: Installing Snap Ring With Snap Ring Pliers
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    10. Using a pin punch and hammer, tap in the slotted spring pin.

      Standard protrusion: 1.5 to 3.5 mm (0.059 to 0.138 in.)
