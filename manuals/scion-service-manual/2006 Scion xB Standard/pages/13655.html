Rear Seat Assembly: Reassembly

CAUTION: Wear protective gloves. Sharp areas on the seatback frame may injure your hands.
  1. INSTALL REAR SEAT BELT ASSEMBLY OUTER CENTER 
    1. Install the belt with the nut.

      Torque: 42 N*m (428 kgf*cm, 31 ft.*lbf) 

  2. INSTALL REAR SEATBACK LOCK ASSEMBLY LH 
    1. Install the lock with the 2 bolts.
  3. INSTALL REAR SEATBACK LOCK ASSEMBLY RH 
    1. Install the lock with the 2 bolts.
  4. INSTALL REAR SEATBACK COVER WITH PAD LH 
    Fig 1: Installing Lock With Bolts
    Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    1. Install the seatback cover (with pad) to the seatback frame.
      NOTE: Be careful not to damage the cover.
  5. INSTALL REAR SEATBACK COVER WITH PAD RH 

    HINT:

    Use the same procedures described for the LH side.

  6. INSTALL REAR SEATBACK STOP BUTTON GROMMET 
    1. Attach the claws to install the 2 grommets.
      Fig 2: Installing Grommets
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  7. INSTALL REAR SEAT HEADREST SUPPORT 
    1. Attach the claws to install the 6 headrest supports.
      Fig 3: Attaching Claws To Install Headrest Supports
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    2. Using hog ring pliers, install the seatback cover (with pad) to the seatback frame with new hog rings.
      NOTE:
      • Be careful not to damage the cover.
      • When installing the hog rings, avoid wrinkling the cover.
        Fig 4: Installing Hog Rings Using Hog Ring Pliers
        Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    3. Install the 17 clips.
      Fig 5: Installing Clips
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  8. INSTALL TETHER ANCHOR COVER 
    1. Install the 3 tether anchor covers.
      Fig 6: Installing Tether Anchor Covers
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  9. INSTALL REAR SEAT SHOULDER BELT COVER (for RH Side) 
    1. Attach the claws to install the shoulder belt cover.
  10. INSTALL REAR SEATBACK LOCK RELEASE BUTTON 
    1. Install the 2 buttons.
  11. INSTALL REAR SEATBACK HINGE SUB-ASSEMBLY LH 
    1. Install the seatback hinge with the bolt.
      Fig 7: Installing Buttons
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002

      Torque: 42 N*m (428 kgf*cm, 31 ft.*lbf) 

  12. INSTALL REAR SEATBACK HINGE SUB-ASSEMBLY RH 
    1. Install the seatback hinge with the bolt.

      Torque: 42 N*m (428 kgf*cm, 31 ft.*lbf) 

  13. INSTALL REAR SEAT HEADREST ASSEMBLY 
    1. Install the 3 headrests.
