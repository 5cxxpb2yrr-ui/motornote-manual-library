Front Wiper Rubber: Installation

HINT:

  • Use the same procedures for the RH side and LH side.
  • The procedures listed below are for the LH side.
  1. INSTALL WIPER RUBBER LH 
    1. Install the 2 wiper rubber backing plates on the wiper rubber.
      NOTE: Be sure to install the wiper rubber backing plates in the correct direction.
      Fig 1: Identifying Wiper Rubber
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    2. Install the wiper rubber so that the head part (longer side) of the wiper rubber faces the arm axle side.
      NOTE:
      • Push in the front wiper blade into the grooves of the wiper rubber to engage them completely.
      • Put back the wiper arm of the passenger side before putting back the driver side wiper arm.
