Front Shock Absorber With Coil Spring: Installation

  1. INSTALL FRONT SHOCK ABSORBER WITH COIL SPRING 
    1. Install the No. 2 suspension support.
    2. Install the shock absorber with the 3 nuts.

      Torque: 39 N*m (400 kgf*cm, 29 ft.*lbf) 

    3. Connect the shock absorber to the steering knuckle.
    4. Install the 2 bolts and nut.
      NOTE: When installing the bolt, keep it from rotating and torque the nut.

      Torque: 132 N*m (1,350 kgf*cm, 97 ft.*lbf) 

  2. INSTALL FLEXIBLE HOSE 
    1. Install the flexible hose.

      Torque: 29 N*m (300 kgf*cm, 22 ft.*lbf) 

  3. INSTALL FRONT WHEEL 

    Torque: 103 N*m (1,050 kgf*cm, 76 ft.*lbf) 

  4. INSTALL COWL TOP PANEL OUTER 
    1. Install the cowl top panel outer with the 8 bolts.

      Torque: 5.0 N*m (51 kgf*cm, 44 in.*lbf) 

    2. Connect the hose and wire harness to the wiper.

  6. INSTALL COWL TOP VENTILATOR LOUVER RH 
  7. INSTALL COWL TOP VENTILATOR LOUVER LH 
  8. INSTALL HOOD TO COWL TOP SEAL 
  9. INSTALL FRONT WIPER ARM LH 
  10. INSTALL FRONT WIPER ARM RH
