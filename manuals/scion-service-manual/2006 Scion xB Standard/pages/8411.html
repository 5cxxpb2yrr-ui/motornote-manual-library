Clutch Pedal: Reassembly

  1. INSTALL CLUTCH MASTER CYLINDER PUSH ROD CLEVIS BUSH 
    1. Apply MP grease to the inside of a new bush.
    2. Install the bush on the clutch pedal.

      HINT:

      Install the bush from the left side of the vehicle.

      Fig 1: Applying MP Grease To Inside Of Bush
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  2. INSTALL CLUTCH PEDAL BUSH 
    1. Apply MP grease to both sides of 2 new bushes.
    2. Install the 2 bushes to the clutch pedal.
  3. INSTALL CLUTCH PEDAL PAD 
    Fig 2: Applying MP Grease To Bushes
    Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  4. INSTALL CLUTCH PEDAL SUB-ASSEMBLY 
    1. Install the pedal on the clutch pedal support with the bolt and nut.

      Torque: 37 N*m (375 kgf*cm, 27 ft.*lbf) 

      HINT:

      Install the bolt from the left side of the vehicle.

      Fig 3: Installing Pedal On Clutch Pedal Support With Bolt And Nut
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  5. INSTALL CLUTCH PEDAL STOPPER BOLT 
    1. Install the lock nut on the bolt but do not torque it.
    2. Install the bolt so that its end touches the clutch pedal cushion.

      HINT:

      Temporarily tighten the lock nut.
