Front No. 1 Speaker: Installation

HINT:

  • Use the same procedures for the RH side and LH side.
  • The procedures listed below are for the LH side.
  1. INSTALL FRONT NO. 1 SPEAKER ASSEMBLY LH 
    1. Using an air riveter or a hand riveter, install 3 new strike rivets to the speaker on the front door panel.

      HINT:

      Install the new strike rivets in the order shown in the illustration.

      Fig 1: Installing New Strike Rivets In Order Shown
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
      NOTE:
      • Do not pry the rivet with the riveter, as this will cause damage to the riveter and mandrel.
        Fig 2: Precaution Do Not Pry Rivet With Riveter
        Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
      • Confirm that the rivets are seated properly against the speaker. Do not tilt the riveter when installing the rivet to the speaker. Do not leave any space between the rivet head and the speaker.
        Fig 3: Installing Rivet
        Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
      • Do not leave any space between the speaker and door panel. Firmly hold together the 2 items while installing the rivet.
    2. Connect the connectors.
  2. INSTALL FRONT DOOR TRIM BOARD SUBASSEMBLY LH (See  REASSEMBLY  ) 
  3. INSTALL POWER WINDOW REGULATOR MASTER SWITCH ASSEMBLY (See  REASSEMBLY  ) 
  4. INSTALL DOOR PULL HANDLE (See  REASSEMBLY  ) 
  5. INSTALL FRONT DOOR LOWER FRAME BRACKET GARNISH LH (See  REASSEMBLY  ) 
  6. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
