Power Steering Link: Installation

NOTE: When installing, apply power steering fluid or molybdenum disulfide lithium base grease to the parts indicated by arrows (see REASSEMBLY  ).
  1. INSTALL POWER STEERING LINK ASSEMBLY 
    1. Install the No. 2 grommet to the steering link.
    2. Align the matchmarks and install the No. 2 bracket to the steering link.
      NOTE: Install the bracket with the inscribed mark facing to the front of the vehicle.
      Fig 1: Aligning Matchmarks And Install No. 2 Bracket To Steering Link
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    3. Install the steering link with the 4 bolts and nuts.

      Torque: 74 N *  m (749 kgf *  cm, 54 ft. *  lbf) 

      NOTE:
      • Torque the bolt with the nut fixed in place as the nut has its own stopper.
      • Do not turn the nut.
      Fig 2: Installing Steering Link With Bolts And Nuts
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  2. INSTALL STEERING INTERMEDIATE SHAFT 
    1. Align the matchmarks on the intermediate shaft with the pinion shaft.
    2. Install the bolt.

      Torque: 28 N *  m (290 kgf *  cm, 21 ft. *  lbf) 

  3. INSTALL NO. 1 STEERING COLUMN HOLE COVER SUB-ASSEMBLY 
    Fig 3: Aligning Matchmarks On Intermediate Shaft With Pinion Shaft
    Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  4. INSTALL POWER STEERING RACK HOUSING HEAT INSULATOR 
    1. Install the heat insulator with the bolt as shown in the illustration.

      Torque: 18 N *  m (178 kgf *  cm, 13 ft. *  lbf) 

    2. Install the bolt to the heat insulator.

      Torque: 35 N *  m (360 kgf *  cm, 26 ft. *  lbf) 

      Fig 4: Installing Heat Insulator With Bolt
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  5. INSTALL FRONT SUSPENSION CROSSMEMBER SUB-ASSEMBLY 
    1. Using a transmission jack, support the crossmember.
    2. Using SST, align the holes of the crossmember.

      SST 09670-00010 

      HINT:

      Use the same procedures described for the other side.

      Fig 5: Aligning Holes Of Crossmember
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    3. Install the crossmember with the 4 bolts.

      Torque: 116 N *  m (1,183 kgf *  cm, 86 ft. *  lbf) for bolt A 

      Torque: 70 N *  m (714 kgf *  cm, 52 ft. *  lbf) for bolt B 

      Fig 6: Installing Crossmember With Bolts
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    4. Install the crossmember with the bolt and 2 nuts.

      Torque: 72 N *  m (734 kgf *  cm, 53 ft. *  lbf) 

      Fig 7: Installing Crossmember With Bolt And Nuts
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    5. Install the 2 reinforcements with the 4 bolts.

      Torque: 47 N *  m (479 kgf *  cm, 35 ft. *  lbf) 

  6. CONNECT NO. 1 FRONT SUSPENSION ARM SUBASSEMBLY LOWER LH (See  INSTALLATION  ) 
    Fig 8: Installing Reinforcements With Bolts
    Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  7. REMOVE NO. 1 FRONT SUSPENSION ARM SUBASSEMBLY LOWER RH 

    HINT:

    Use the same procedures described for the LH side.

  8. CONNECT PRESSURE FEED TUBE ASSEMBLY 
    1. Using SST, connect the pressure feed tube.

      SST 09023-12701 

      Torque: 27 N *  m (273 kgf *  cm, 20 ft. *  lbf) 

      HINT:

      • Use a torque wrench with a fulcrum length of 345 mm (13.58 in.).
      • This torque value is effective when SST is parallel to a torque wrench.
    2. Connect the return hose with the clip.
      Fig 9: Connecting Pressure Feed Tube
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    3. Install the tube clamp to the crossmember with the bolts.

      Torque: 7.8 N *  m (80 kgf *  cm, 69 in. *  lbf) 

  9. INSTALL TIE ROD END SUB-ASSEMBLY LH (See  INSTALLATION   ) 
  10. INSTALL TIE ROD END SUB-ASSEMBLY RH 

    HINT:

    Use the same procedures described for the LH side.

  11. INSTALL FRONT WHEEL 

    Torque: 103 N *  m (1,050 kgf *  cm, 76 ft. *  lbf) 

  12. INSTALL STEERING SLIDING YOKE SUBASSEMBLY 
    1. Align the matchmarks on the sliding yoke and intermediate shaft.
    2. Tighten the bolt.

      Torque: 28 N *  m (290 kgf *  cm, 21 ft. *  lbf) 

      Fig 10: Aligning Matchmarks On Sliding Yoke And Intermediate Shaft
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  13. INSPECT FRONT WHEELS FACING STRAIGHT AHEAD 
  14. REMOVE NO. 1 STEERING COLUMN HOLE COVER SUB-ASSEMBLY 
  15. ADD POWER STEERING FLUID 
  16. BLEED AIR FROM POWER STEERING SYSTEM (See  ON-VEHICLE INSPECTION   ) 
  17. CHECK POWER STEERING FLUID LEVEL IN RESERVOIR (See  ON-VEHICLE INSPECTION   ) 
  18. CHECK FOR POWER STEERING FLUID LEAKS 
  19. INSTALL HOOD SUB-ASSEMBLY 
    1. Install the hood with the 4 bolts.

      Torque: 13 N *  m (133 kgf *  cm, 10 ft. *  .lbf) 

  20. INSPECT AND ADJUST FRONT WHEEL ALIGNMENT 
    1. Inspect and adjust the front wheel alignment (see FRONT WHEEL ALIGNMENT ).
  21. INSTALL ENGINE UNDER COVER LH 
  22. INSTALL ENGINE UNDER COVER RH 
  23. INSTALL COWL PANEL SUB-ASSEMBLY 
  24. INSTALL WINDSHIELD WIPER MOTOR AND LINK ASSEMBLY (See  INSTALLATION  ) 
  25. INSTALL COWL TOP VENTILATOR LOUVER LH (See  INSTALLATION  ) 
  26. INSTALL COWL TOP VENTILATOR LOUVER RH (See  INSTALLATION  ) 
  27. INSTALL HOOD TO COWL TOP SEAL (See  INSTALLATION  ) 
  28. INSTALL FRONT WIPER ARM AND BLADE ASSEMBLY LH (See  INSTALLATION  ) 
  29. INSTALL FRONT WIPER ARM AND BLADE ASSEMBLY RH (See  INSTALLATION  )
