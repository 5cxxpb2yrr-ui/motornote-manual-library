Transmission Control Cable: Installation

  1. INSTALL TRANSMISSION CONTROL CABLE ASSEMBLY 
    1. Install the clamp with the bolt.

      Torque: 5.0 N*m (51 kgf*cm, 44 in.*lbf) 

    2. Insert the transmission control select cable and transmission control shift cable through the floor hole and retainer.
      Fig 1: Installing Clamp With Bolt
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    3. Install the transmission control select cable to the grommet.
    4. Install the retainer on the grommet.
      Fig 2: Installing Retainer On Grommet
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
      NOTE: Fit the projections of the grommet into the holes of the retainer.
    5. Install the retainer to the floor with the 2 bolts.

      Torque: 5.0 N*m (51 kgf*cm, 44 in.*lbf) 

      Fig 3: Installing Retainer To Floor With Bolts
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    6. Connect the transmission control cable to the shift lever retainer.
    7. Connect the end of the transmission control shift cable to the floor shift lever with the clip.
      Fig 4: Connecting End Of Transmission Control Shift Cable To Floor Shift Lever With Clip
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    8. Connect the transmission select cable to the shift lever retainer.
    9. Connect the end of the transmission control select cable to the floor shift lever with the clip.
      NOTE:
      • The serrated part of the select cable point should face upward when the select cable point is connected.
      • The clip should be inserted in the direction shown in the illustration.
      Fig 5: Identifying Serrated Part Of Select Cable Point
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    10. Connect the 2 cable ends to the transaxle with the 2 washers and 2 clips.
    11. Install 2 new clips to the control cable bracket.
      Fig 6: Connecting Cable Ends To Transaxle With Washers And Clips
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  2. INSTALL FLOOR SHIFT LEVER ASSEMBLY 
    1. Install the floor shift lever with the 4 bolts.

      Torque: 12 N*m (120 kgf*cm, 9 ft.*lbf) 

      Fig 7: Installing Floor Shift Lever With Bolts
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    2. Connect the wire harness.
  3. INSTALL REAR CONSOLE BOX ASSEMBLY 
    1. Install the rear console box (See INSTALLATION ).
  4. INSTALL SHIFT LEVER KNOB SUB-ASSEMBLY 
    1. Install the shift lever knob (See INSTALLATION ).
  5. INSTALL FRONT NO.1 FLOOR HEAT INSULATOR 

    Torque: 5.5 N*m (56 kgf*cm, 49 in.*lbf)
