Rear Seat Assembly: Installation

  1. INSTALL CHILD RESTRAINT SEAT ANCHOR BRACKET SUB-ASSEMBLY 
    1. Install the anchor bracket with the 4 bolts.

      Torque: 42 N*m (428 kgf*cm, 31 ft.*lbf) 

  2. INSTALL REAR SEATBACK LOCK STRIKER SUBASSEMBLY LH 
    1. Install the seatback lock striker with the 2 bolts.

      Torque: 21 N*m (214 kgf*cm, 15 ft.*lbf) 

  3. INSTALL REAR SEATBACK LOCK STRIKER SUBASSEMBLY RH 
    1. Install the seatback lock striker with the 2 bolts.

      Torque: 21 N*m (214 kgf*cm, 15 ft.*lbf) 

  4. INSTALL REAR SEATBACK ASSEMBLY LH 
    1. Turn up the seatback cover as shown in the illustration.
    2. Install the seatback with the 2 bolts.

      Torque: 37 N*m (377 kgf*cm, 27 ft.*lbf) 

    3. Return the seatback to the upright position.
      Fig 1: Installing Seatback With Bolts

  5. INSTALL REAR SEATBACK ASSEMBLY RH 

    HINT:

    Use the same procedures described for the LH side.

    Torque: 37 N*m (377 kgf*cm, 27 ft.*lbf) 

    Fig 2: Turning Up Seatback Cover
    Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  6. INSTALL REAR SEAT CUSHION WITH COVER PAD SUB-ASSEMBLY 
    1. Attach the seat cushion's rear hook.
    2. Attach the seat cushion's 2 front hooks to the vehicle body.
    3. Confirm that the seat cushion is firmly installed.
      NOTE: When installing the seat cushion, make sure the seat belt buckle is not under the seat cushion.
