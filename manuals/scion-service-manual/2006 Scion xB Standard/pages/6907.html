Transmission Control Cable Assembly: Replacement

WARNING: This page is about a different variant/trim than selected.
  1. REMOVE CONSOLE BOX REAR COVER 
    1. Remove the console box rear cover (See REMOVAL ).
  2. REMOVE CONSOLE BOX CARPET 
  3. REMOVE REAR CONSOLE BOX ASSEMBLY 
    1. Remove the rear console box (See REMOVAL ).
  4. REMOVE FRONT EXHAUST PIPE ASSEMBLY 
    1. Remove the front exhaust pipe (see REMOVAL ).
  5. REMOVE FRONT NO. 1 FLOOR HEAT INSULATOR 
  6. REMOVE AIR CLEANER ASSEMBLY 
    1. Remove the air cleaner assembly (see REMOVAL ).
  7. DISCONNECT TRANSMISSION CONTROL CABLE ASSEMBLY 
    1. Remove the nut, and disconnect the transmission control cable from the floor shift assembly.
    2. Using a screwdriver, disconnect the transmission control cable assembly from the shift lever plate.
      Fig 1: Disconnecting Transmission Control Cable Assembly
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    3. Remove the 3 bolts.
    4. Pull out the transmission control cable from the body.
      Fig 2: Removing Bolts Pulling Out Transmission Control Cable From Body
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    5. Remove the nut and disconnect the transmission control cable from the control shaft lever.
    6. Remove the clip and disconnect the transmission control cable from the control cable bracket.
      Fig 3: Removing Nut And Disconnecting Transmission Control Cable From Control Shaft Lever
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    7. Disconnect the transmission control cable from the transmission control cable support.
      Fig 4: Disconnecting Transmission Control Cable
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  8. CONNECT TRANSMISSION CONTROL CABLE ASSEMBLY 
    1. Temporarily install the transmission control cable on the control shaft lever with the nut.
    2. Connect the transmission control cable on the bracket with a new clip.
      Fig 5: Connecting Transmission Control Cable Assembly
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    3. Connect the transmission control cable to the transmission control cable support.
      Fig 6: Connecting Transmission Control Cable
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    4. Install the transmission control cable on the body with the 3 bolts.

      Torque: 5.0 N*m (51 kgf*cm, 44 in.*lbf) 

      Fig 7: Installing Transmission Control Cable On Body With Bolts
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    5. Connect the transmission control cable on the shift lever plate.
    6. Temporarily install the transmission control cable on the floor shift.

      Torque: 2 N*m (122 kgf*cm, 9 ft.*lbf) 

  9. INSTALL AIR CLEANER ASSEMBLY 
    1. Install the air cleaner (see INSTALLATION ).
  10. INSTALL FRONT NO. 1 FLOOR HEAT INSULATOR 
  11. INSTALL FRONT EXHAUST PIPE ASSEMBLY 
    1. Install the front exhaust pipe (see INSTALLATION ).
  12. ADJUST SHIFT LEVER POSITION 
    1. Adjust the shift lever position (see ADJUSTMENT  ).
  13. INSPECT SHIFT LEVER POSITION 
    1. Inspect the shift lever position (see ADJUSTMENT  ).
  14. INSTALL REAR CONSOLE BOX ASSEMBLY 
    1. Install the rear console box (See INSTALLATION ).
  15. INSTALL CONSOLE BOX CARPET 
  16. INSTALL CONSOLE BOX REAR COVER 
    1. Install the console box rear cover (See INSTALLATION ).
