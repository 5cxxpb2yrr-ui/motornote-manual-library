HOW TO REPLACE TERMINAL (with terminal retainer or secondary locking device)

  1. PREPARE THE SPECIAL TOOL

    HINT: To remove the terminal from the connector, please construct and use the special tool or like object shown on the left.

  2. DISCONNECT CONNECTOR
    Fig 1: Identifying Special Tool Dimensions
    Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  3. DISENGAGE THE SECONDARY LOCKING DEVICE OR TERMINAL RETAINER.
    1. Locking device must be disengaged before the terminal locking clip can be released and the terminal removed from the connector.
    2. Use a special tool or the terminal pick to unlock the secondary locking device or terminal retainer.
      NOTE: Do not remove the terminal retainer from connector body.
      Fig 2: Disengaging Secondary Locking Device Or Terminal Retainer
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
      1. For Non-Waterproof Type Connector

        HINT: The needle insertion position varies according to the connector's shape (number of terminals etc.), so check the position before inserting it.

        "Case 1"

        Raise the terminal retainer up to the temporary lock position.

        Fig 3: Raising Terminal Retainer Up To Temporary Lock Position
        Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002

        "Case 2"

        Open the secondary locking device.

        Fig 4: Opening Secondary Locking Device
        Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
        Fig 5: Removing Non Waterproof Type Connector Locking Tab Using Tool
        Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
      2. For Waterproof Type Connector

        HINT: Terminal retainer color is different according to connector body.

        Example:

        Terminal Retainer  : Connector Body 

        Black or White: Gray

        Black or White: Dark Gray

        Gray or White: Black

        Fig 6: Removing Waterproof Type Connector Locking Tab Using Tool
        Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002

        "Case 1"

        Type where terminal retainer is pulled up to the temporary lock position (Pull Type).

        Insert the special tool into the terminal retainer access hole ( Mark) and pull the terminal retainer up to the temporary lock position.

        HINT: The needle insertion position varies according to the connector's shape (Number of terminals etc.), so check the position before inserting it.

        Fig 7: Pulling Terminal Retainer Up To Temporary Lock Position Using Special Tool (Case 1)
        Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002

        "Case 2"

        Type which cannot be pulled as far as Power Lock insert the tool straight into the access hole of terminal retainer as shown.

        Fig 8: Inserting Tool Straight Into Access Hole Of Terminal Retainer (Case 2)
        Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002

        Push the terminal retainer down to the temporary lock position.

        Fig 9: Pushing Terminal Retainer Down To Temporary Lock Position
        Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    3. Release the locking lug from terminal and pull the terminal out from rear.
      Fig 10: Releasing Terminal Locking Lug
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  4. INSTALL TERMINAL TO CONNECTOR
    1. Insert the terminal.

      HINT:

      1. Make sure the terminal is positioned correctly.
      2. Insert the terminal until the locking lug locks firmly.
      3. Insert the terminal with terminal retainer in the temporary lock position.
        Fig 11: Installing Terminal To Connector
        Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    2. Push the secondary locking device or terminal retainer in to the full lock position.
  5. CONNECT CONNECTOR
    Fig 12: Pushing Secondary Locking Device Or Terminal Retainer In To Full Lock Position
    Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
