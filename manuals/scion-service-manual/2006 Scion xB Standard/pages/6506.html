Rear Seat Inner Belt Assembly: Installation

HINT:

A bolt without a torque specification is shown in the standard bolt chart (see SPECIFIED TORQUE FOR STANDARD BOLTS ).

  1. INSTALL CHILD RESTRAINT SEAT TETHER ANCHOR BRACKET SUB-ASSEMBLY 
    1. Install the anchor bracket with the 4 bolts.

      Torque: 42 N*m (428 kgf*cm, 31 ft.*lbf) 

  2. INSTALL REAR SEATBACK ASSEMBLY LH (See  INSTALLATION  ) 
  3. INSTALL REAR SEATBACK ASSEMBLY RH (See  INSTALLATION  ) 
  4. INSTALL REAR SEAT INNER WITH CENTER BELT ASSEMBLY LH 
    1. Install the floor anchor and belt with the bolt, as shown in the illustration.

      Torque: 42 N*m (428 kgf*cm, 31 ft.*lbf) 

      NOTE: Make sure that the anchor part does not run onto the protruding part of the floor panel.
      Fig 1: Installing Rear Seat Inner With Center Belt Assembly LH

  5. INSTALL REAR SEAT INNER WITH CENTER BELT ASSEMBLY RH 
    1. Install the floor anchor and belt with the bolt, as shown in the illustration.

      Torque: 42 N*m (428 kgf*cm, 31 ft.*lbf) 

      NOTE: Make sure that the anchor part does not run onto the protruding part of the floor panel.
  6. INSTALL REAR SEAT CUSHION WITH COVER PAD SUB-ASSEMBLY (See  INSTALLATION  )
