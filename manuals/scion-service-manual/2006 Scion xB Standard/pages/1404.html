Rear Axle Hub: Installation

  1. INSTALL REAR AXLE HUB AND BEARING ASSEMBLY 
    1. Install the hub and bearing assembly with the 4 bolts.

      Torque: 61 N*m (622 kgf*cm, 45 ft.*lbf) 

    2. Connect the skid control sensor connector.
      NOTE: Do not twist the sensor wire when connecting it.

  2. INSPECT REAR AXLE DEVIATION AND BACKLASH 
    1. Inspect the rear axle deviation and backlash (see INSTALLATION  ).
  3. INSTALL REAR BRAKE DRUM SUB-ASSEMBLY 
  4. INSTALL REAR WHEEL 

    Torque: 103 N*m (1,050 kgf*cm, 76 ft.*lbf) 

  5. CHECK ABS SPEED SENSOR SIGNAL 
    1. Check the ABS speed sensor signal (see OPERATION CHECK ).
