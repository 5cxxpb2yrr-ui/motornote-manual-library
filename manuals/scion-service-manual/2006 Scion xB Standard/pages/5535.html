TPMS Reminder Reset - Procedure 02: Notes

NOTE: Initialization is NOT required if re-inflating tires to the currently specified tire pressure.
NOTE: Registration of the tire pressure sensor IDs is accomplished using either an Intelligent Tester , or Techstream  scan tool. Initialization of the TPM system does not REQUIRE the use of a scan tool, but a scan tool can be used to verify that the correct tire pressures have been input into the system ECU.
