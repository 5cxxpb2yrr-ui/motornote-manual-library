Front No. 2 Speaker: Installation

HINT:

  • Use the same procedures for the RH side and LH side.
  • The procedures listed below are for the LH side.
  1. INSTALL NO. 2 FRONT SPEAKER ASSEMBLY LH 
    1. Connect the connector.
    2. Install the speaker with the 2 bolts.
  2. INSTALL NO. 2 INSTRUMENT PANEL SPEAKER PANEL SUB-ASSEMBLY (See  INSTALLATION  ) 
  3. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
