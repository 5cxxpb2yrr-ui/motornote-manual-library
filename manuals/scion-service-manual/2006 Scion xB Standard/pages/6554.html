Power Steering Link: Reassembly

  1. INSTALL POWER STEERING RACK HOUSING OIL SEAL 
    1. Coat the lip of a new oil seal with power steering fluid.
    2. Using SST and a press, press in the housing oil seal.

      SST 09950-60010 (09951-00210, 09951-00370, 

      09952-06010), 09950-70010 (09951-07360) 

      NOTE: Make sure that the oil seal is installed correctly.
      Fig 1: Pressing In Housing Oil Seal
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  2. INSTALL RACK STEERING PISTON RING 
    1. Apply power steering fluid to a new O-ring and install it to the steering rack.
    2. Expand a new piston ring with your fingers.
      NOTE: Be careful not to overly expand the piston ring.
    3. Apply power steering fluid to the piston ring.
    4. Install the piston ring to the steering rack, and adjust it with your fingers.
      Fig 2: Expanding Piston Ring With Your Fingers
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  3. INSTALL POWER STEERING RACK 
    1. Install SST to the steering rack.

      SST 09631-10041 

      HINT:

      If necessary, scrape the burrs off the steering rack teeth end and burnish.

    2. Apply power steering fluid to the SST.
    3. Install the steering rack to the rack housing.
    4. Remove SST.
      Fig 3: Installing SST To Steering Rack
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  4. INSTALL POWER STEERING RACK BUSH 
    1. Using SST and a press, press in the rack bush oil seal to the rack bush.

      SST 09950-60010 (09951-00210, 09951-00340, 

      09952-06010), 09950-70010 (09951-07100) 

      NOTE: Make sure that the oil seal is installed correctly.
    2. Apply power steering fluid to a new O-ring and install it to the rack bush.
      Fig 4: Pressing In Rack Bush Oil Seal To Rack Bush
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    3. Wrap vinyl tape around the steering rack end to prevent damaging the lip of the rack bush oil seal, and apply power steering fluid to the rack bush oil seal.
    4. Install the rack bush into the rack housing.
      NOTE:
      • Make sure that the rack bush is installed correctly.
      • Be careful not to damage the lip of the oil seal.
      Fig 5: Wrapping Vinyl Tape Around Steering Rack End
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  5. INSTALL CYLINDER END STOPPER 
    1. Push in the cylinder end stopper.
    2. Using needle nose pliers, install the hole snap ring.
  6. CHECK AIR TIGHTNESS 
    1. Install SST onto the rack housing.

      SST 09631-12071 (09633-00010) 

    2. Apply a vacuum of 53 kPa (400 mmHg, 15.75 in.Hg) for approximately 30 seconds.
    3. Check that there is no change in the vacuum.

      If there is a change in the vacuum pressure, check the installation of the oil seals.

      Fig 6: Installing SST Onto Rack Housing
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  7. INSTALL POWER STEERING CONTROL VALVE 
    1. Apply grease to the needle roller bearing.
    2. Install a new gasket to the control valve.
      Fig 7: Applying Grease To Needle Roller Bearing
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    3. Align the matchmarks and install the control valve to the rack housing with the 2 bolts.

      Torque: 21 N *  m (214 kgf *  cm, 15 ft. *  lbf) 

      Fig 8: Aligning Matchmarks And Install Control Valve To Rack Housing With Bolts
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  8. INSTALL RACK GUIDE 
    1. Install the rack guide, rack guide spring spacer and rack guide spring.
      NOTE: Make sure that the rack guide spring spacer is installed correctly
    2. Apply sealant to 2 or 3 threads of the rack guide spring cap.

      Sealant: Part No. 08833-00080, THREE BOND 1344, 

      LOCTITE 242 or equivalent. 

    3. Temporarily install the rack guide spring cap.
      Fig 9: Installing Rack Guide, Rack Guide Spring Spacer And Rack Guide Spring
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  9. ADJUST TOTAL PRELOAD 
    1. To prevent the steering rack teeth from damaging the lip of the oil seal, temporarily install the RH and LH rack ends.
    2. Using a 19 mm hexagon wrench, torque the rack guide spring cap.

      Torque: 25 N *  m (250 kgf *  cm, 18 ft. *  lbf) 

    3. Using a 19 mm hexagon wrench, return the rack guide spring cap approximately 12°.
      Fig 10: Returning Rack Guide Spring Cap Approximately 12°
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    4. Using SST, turn the control valve to the right and left once or twice.

      SST 09616-00011 

    5. Using a 19 mm hexagon wrench, loosen the rack guide spring cap until the rack guide spring stops functioning.
      Fig 11: Turning Control Valve To Right And Left Once Or Twice
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    6. Using SST, a torque wrench and 19 mm hexagon wrench, tighten the rack guide spring cap until the preload is within the specification.

      SST 09616-00011 

      Standard preload (turning): 1.2 to 1.5 N *  m (12 to 15 kgf *  cm, 10.6 to 13.3 in. *  lbf) 

    7. Apply sealant to 2 or 3 threads of the spring cap lock nut.

      Sealant: Part No. 08833-00080, THREE BOND 1344, 

      LOCTITE 242 or equivalent 

      Fig 12: Tightening Rack Guide Spring Cap
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    8. Temporarily install the spring cap lock nut.
    9. Hold the rack guide spring cap with a 19 mm hexagon wrench, and using SST, torque the spring cap lock nut.

      Torque: 28 N *  m (286 kgf *  cm, 21 ft. *  lbf) 

      NOTE: Use SST 09922-10010 in the direction shown in the illustration.

      HINT:

      Use a torque wrench with a fulcrum length of 345 mm (13.58 in.).

    10. Recheck the total preload.

      Standard total preload (turning): 1.2 to 1.5 N *  m (12 to 15 kgf *  cm, 10.6 to 13.3 in. *  lbf) 

    11. Remove the RH and LH rack ends.
      Fig 13: Checking Total Preload
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  10. INSTALL STEERING RACK END SUB-ASSEMBLY 
    1. Temporarily install the 2 rack ends.
    2. Using SST, torque the 2 rack ends.

      SST 09922-10010 

      Torque: 60 N *  m (614 kgf *  cm, 44 ft. *  lbf) 

      NOTE: Use SST 09922-10010 in the direction shown in the illustration.

      HINT:

      • Use a torque wrench with a fulcrum length of 345 mm (13.58 in.).
      • Using SST, hold the rack and install the rack end.
        Fig 14: Installing Steering Rack End Sub-Assembly
        Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  11. INSPECT STEERING RACK END HOLE 
    1. Ensure that the hole of the rack end is not clogged with grease.

      HINT:

      If the hole is clogged, the pressure inside the boot will change after it is assembled and the steering wheel is turned.

      Fig 15: Inspecting Steering Rack End Hole
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  12. INSTALL NO. 2 STEERING RACK BOOT 
    1. Apply silicon grease to the inside small caliber of the No. 2 rack boot.
    2. Install the No. 2 rack boot onto the groove on the rack housing.
      NOTE: Be careful not to damage or twist the boot.
  13. INSTALL NO. 1 STEERING RACK BOOT 

    HINT:

    Use the same procedures described for the No. 2 side.

    Fig 16: Applying Silicon Grease To Inside Small Caliber Of No. 2 Rack Boot
    Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  14. INSTALL NO. 2 STEERING RACK BOOT CLAMP 
    1. Using SST, tighten the No. 2 rack boot clamp, as shown in the illustration.

      SST 09240-00020, 09521-24010 

      Standard clearance: 3.0 mm (0.118 in.) or less 

      NOTE: Be careful not to damage the boot.
      Fig 17: Tightening No. 2 Rack Boot Clamp
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  15. INSTALL NO. 1 STEERING RACK BOOT CLAMP 

    HINT:

    Use the same procedures described for the No. 2 side.

  16. INSTALL STEERING RACK BOOT CLIP 
    1. Using pliers, install the 2 rack boot clips.
  17. INSTALL TIE ROD END SUB-ASSEMBLY LH 
    1. Screw the lock nut and tie rod end on the rack end until the matchmarks are aligned.

      Torque: 74 N *  m (750 kgf *  cm, 54 ft. *  lbf) 

      HINT:

      After adjusting toe-in, torque the lock nut (see REASSEMBLY  ).

  18. INSTALL TIE ROD END SUB-ASSEMBLY RH 

    HINT:

    Use the same procedures described for the LH side.

    Fig 18: Aligning Matchmarks Of Lock Nut And Tie Rod End On Rack End
    Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  19. INSTALL STEERING TURN PRESSURE TUBE RH 
    1. Apply power steering fluid to 2 new O-rings and install them to the turn pressure tube.
    2. Using SST, install the turn pressure tube to the steering link.

      SST 09023-38201 

      Torque: 12 N *  m (118 kgf *  cm, 9 ft. *  lbf) 

      HINT:

      • Use a torque wrench with a fulcrum length of 250 mm (9.84 in.).
      • This torque value is effective when SST is parallel to a torque wrench.
  20. INSTALL STEERING TURN PRESSURE TUBE LH 

    HINT:

    Use the same procedures described for the RH side.

    Fig 19: Installing Turn Pressure Tube To Steering Link
    Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
