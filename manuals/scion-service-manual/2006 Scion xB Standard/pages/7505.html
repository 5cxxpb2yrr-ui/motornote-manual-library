Front Airbag Sensor: Installation

CAUTION: Be sure to read the precautionary notices concerning the SRS airbag system before servicing it (see AIRBAG SYSTEM  ).
  1. INSTALL FRONT AIRBAG SENSOR LH 
    1. Install the sensor with the 2 bolts.

      Torque: 17.5 N*m (178 kgf*cm, 13 ft.*lbf) 

      CAUTION:
      • If the airbag sensor has been dropped, or there are any cracks, dents or other defects in the case or connector, replace it with a new one.
      • When installing the airbag sensor, make sure that the SRS wiring does not interfere with other parts and is not pinched between other parts.
    2. Check that there is no free play in the installation parts of the sensor.
    3. Connect the sensor connector.

    1. Install the sensor with the 2 bolts.

      Torque: 17.5 N*m (178 kgf*cm, 13 ft.*lbf) 

      NOTE:
      • If the airbag sensor has been dropped, or there are any cracks, dents or other defects in the case or connector, replace it with a new one.
      • When installing the airbag sensor, make sure that the SRS wiring does not interfere with other parts and is not pinched between other parts.
    2. Check that there is no free play in the installation parts of the sensor.
    3. Connect the sensor connector.

  3. INSTALL NO. 1 AIR CLEANER INLET 
    1. Install the air cleaner inlet with the bolt.
  4. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL 
  5. CHECK SRS WARNING LIGHT 
    1. Check the SRS warning light (see PROBLEM SYMPTOMS TABLE  ).
