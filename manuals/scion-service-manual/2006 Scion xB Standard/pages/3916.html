VVT Drive Cycle 3

Fig 1: Drive Cycle Pattern 3
Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  1. 1.Connect the Techstream to the DLC3.
  2. 2.Turn the engine switch on (IG) and turn the Techstream on.
  3. 3.Clear the DTCs (even if no DTCs are stored, perform the clear DTC procedure).
  4. 4.Turn the engine switch off and wait for at least 30 seconds.
  5. 5.Turn the engine switch on (IG) and turn the Techstream on [A].
  6. 6.Start the engine and warm it up until the engine coolant temperature reaches 75°C (167°F) or higher [B].
  7. 7.Drive the vehicle at approximately 60 km/h (37 mph) for 10 minutes or more [C].
    CAUTION: When performing the confirmation driving pattern, obey all speed limits and traffic laws.
  8. 8.Idle the engine for 3 minutes or more [D].
  9. 9.Enter the following menus: Powertrain / Engine / Trouble Codes [E].
  10. 10.Read the pending DTCs.
    • If a pending DTC is output, the system is malfunctioning.
    • If a pending DTC is not output, perform the following procedure.
  11. 11.Enter the following menus: Powertrain / Engine / Utility / All Readiness.
  12. 12.Input the DTC: P0011, P0012, P0021 or P0022.
  13. 13.Check the DTC judgment result.
    JUDGMENT RESULT

    TECHSTREAM DISPLY DESCRIPTION
    NORMAL
    • DTC judgment completed
    • System normal
    ABNORMAL
    • DTC judgment completed
    • System abnormal
    INCOMPLETE
    • DTC judgment not completed
    • Perform driving pattern after confirming DTC enabling conditions
    UNKNOWN
    • Unable to perform DTC judgment
    • Number of DTCs which do not fulfill DTC preconditions has reached ECU's memory limit
    NOTE:
    • If the judgment result shows NORMAL, the system is normal.
    • If the judgment result shows ABNORMAL, the system has a malfunction.
    • If the judgment result shows INCOMPLETE or UNKNOWN, perform steps [F] through [H].
  14. 14.Repeat the pattern of accelerating the vehicle from rest to approximately 60 km/h (37 mph) and then decelerating the vehicle 10 to 15 times [F].
    CAUTION: When performing the confirmation driving pattern, obey all speed limits and traffic laws.
    NOTE: Depress the accelerator pedal by a large amount.
  15. 15.Idle the engine for 3 minutes or more [G].
  16. 16.Enter the following menus: Powertrain / Engine / Trouble Codes [H].
  17. 17.Read the pending DTCs.
    NOTE:
    • If a pending DTC is output, the system is malfunctioning.
    • If a pending DTC is not output, perform the following procedure.
  18. 18.Check the DTC judgment result again.
    NOTE:
    • If the judgment result shows NORMAL, the system is normal.
    • If the judgment result shows ABNORMAL, the system has a malfunction.
    • If the judgment result shows INCOMPLETE or N/A, perform the following procedure.
  19. 19.Perform a universal trip and check for permanent DTCs.
    NOTE:
    • If a permanent DTC is output, the system is malfunctioning.
    • If no permanent DTC is output, the system is normal.
