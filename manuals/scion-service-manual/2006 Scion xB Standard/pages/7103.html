Floor Shift Assembly: Adjustment

WARNING: This page is about a different variant/trim than selected.
  1. INSPECT SHIFT LEVER POSITION 
    Fig 1: Identifying Shift Lever Position
    Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    1. When adjusting the shift lever to each position, make sure that it moves smoothly, can be properly operated and the position indicator displays correctly.

      Positions which can be operated without pressing the shift lever knob button: R --> N --> D --> 2, L --> 2 --> D --> N 

      Positions which can be operated only while pressing the shift lever knob button: 2 --> L, N --> R --> P 

      Positions which can be operated only while pressing the shift lever knob button, the ignition switch is in the ON position and the brake pedal is depressed: P --> R 

    2. When starting the engine, make sure that the vehicle moves forward when shifting from the N to D position, and moves rearward when shifting to the R position.
  2. ADJUST SHIFT LEVER POSITION 
    1. Remove the nut and disconnect the control cable from the control shaft lever.
      Fig 2: Removing Nut And Disconnecting Control Cable From Control Shaft Lever
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    2. Turn the control shaft lever counterclockwise until it stops.
    3. Turn it clockwise 2 notches to set it to the N position.
    4. Move the shift lever to the N position and install the control cable to the control shaft lever with the nut while pushing the end of the control cable up.

      Torque: 12.7 N*m (130 kgf*cm, 9 ft.*lbf) 

      NOTE:
      • The shift lever cannot be moved if the end of the control cable is excessively pushed up.
      • Tighten the nut while the control cable is properly stretched.
        Fig 3: Moving Shift Lever To N Position
        Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    5. After adjustment, check that the shift lever moves smoothly, and that the shift lever and gear operate correctly.
