Front Passenger Airbag Assembly: Installation

CAUTION: Be sure to read the precautionary notices concerning the SRS airbag system before servicing it (see AIRBAG SYSTEM  ).
  1. INSTALL FRONT PASSENGER AIRBAG ASSEMBLY 
    1. Attach the 12 claws to install the front passenger airbag.
      Fig 1: Attaching Claws To Installing Front Passenger Airbag

    2. Install the 2 nuts.
  2. INSTALL INSTRUMENT PANEL SUB-ASSEMBLY 
    1. Install the instrument panel (see INSTALLATION ).
      NOTE: When handling the airbag connector, do not damage the airbag wire harness.
  3. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL 
  4. CHECK SRS WARNING LIGHT 
    1. Check the SRS warning light (see PROBLEM SYMPTOMS TABLE  ).
