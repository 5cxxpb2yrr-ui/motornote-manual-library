Front Seat Outer Belt Assembly With PRETENSIONER: Installation

HINT:

  • Use the same procedures for the RH side and LH side.
  • The procedures listed below are for the RH side.
  • A bolt without a torque specification is shown in the standard bolt chart (see SPECIFIED TORQUE FOR STANDARD BOLTS ).
  1. INSTALL FRONT SHOULDER BELT ANCHOR ADJUSTER ASSEMBLY 
    1. Install the anchor adjuster with the 2 bolts.

      Torque: 42 N*m (428 kgf*cm, 31 ft.*lbf) 

  2. INSTALL CENTER PILLAR GARNISH UPPER RH (See  INSTALLATION  ) 
  3. INSTALL FRONT SEAT OUTER BELT ASSEMBLY RH 
    1. Install the outer belt with the 2 bolts on the retractor side.

      Torque: 5.0 N*m (51 kgf*cm, 44 in.*lbf) for upper bolt 

      42 N*m (428 kgf*cm, 31 ft.*lbf) for lower bolt 

    2. Connect the pretensioner connector as shown in the illustration.
    3. Install the outer belt with the bolt on the shoulder anchor side.

      Torque: 42 N*m (428 kgf*cm, 31 ft.*lbf) 

    4. Install the shoulder anchor cover.
    5. Install the outer belt with the bolt on the floor anchor side.

      Torque: 42 N*m (428 kgf*cm, 31 ft.*lbf) 

    6. Install the floor anchor cover.
    7. With the belt installed, check that the belt locks when it is pulled out quickly.
      Fig 1: Connecting Pretensioner Connector
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
      NOTE: The check should be performed with the outer belt assembly installed.

      If the operation is not as specified, replace the belt.

    8. Check the fastening function of the child restraint system.
      NOTE: The check should be performed with the outer belt installed.
      1. When the belt is pulled out fully, the belt should automatically try to retract.
      2. After the belt has fully retracted, the belt should be able to be pulled out and retracted again.

        If the operation is not as specified, replace the belt.

  4. INSTALL CENTER PILLAR GARNISH LOWER RH (See  INSTALLATION  ) 
  5. INSTALL REAR DOOR OPENING TRIM WEATHERSTRIP RH 
  6. INSTALL REAR DOOR SCUFF PLATE RH (See  INSTALLATION  ) 
  7. INSTALL FRONT DOOR OPENING TRIM WEATHERSTRIP RH 
  8. INSTALL COWL SIDE TRIM BOARD RH (See  INSTALLATION  ) 
  9. INSTALL FRONT DOOR SCUFF PLATE RH (See  INSTALLATION  ) 
  10. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
