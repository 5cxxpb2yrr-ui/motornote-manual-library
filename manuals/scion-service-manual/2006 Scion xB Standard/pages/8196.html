DTC P0630 VIN not Programmed or Mismatch - ECM / PCM: Description

DTC P0630 is set if the Vehicle Identification Number (VIN) is not stored in the ECM or the input VIN is not accurate. Input the VIN with the intelligent tester (see REGISTRATION  ).

DTC DETECTION CONDITION AND TROUBLE AREA

DTC No. DTC Detection Condition Trouble Area
P0630
  • VIN not stored in ECM
  • Input VIN in ECM not accurate
