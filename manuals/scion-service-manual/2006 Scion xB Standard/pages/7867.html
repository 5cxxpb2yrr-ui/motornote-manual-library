High Pitched Horn: Removal

  1. REMOVE RADIATOR GRILLE (See  REMOVAL  ) 
  2. REMOVE FRONT FENDER LINER LH (See  REMOVAL  ) 
  3. REMOVE FRONT FENDER LINER RH (See  REMOVAL  ) 
  4. REMOVE RADIATOR GRILLE LOWER (See  REMOVAL  ) 
  5. REMOVE FRONT BUMPER EXTENSION MOUNTING BRACKET LH (See  REMOVAL  ) 
  6. REMOVE FRONT BUMPER EXTENSION MOUNTING BRACKET RH (See  REMOVAL  ) 
  7. REMOVE FRONT BUMPER COVER (See  REMOVAL  ) 
  8. REMOVE HIGH PITCHED HORN 
    1. Disconnect the horn connector.
    2. Remove the bolt and horn.
