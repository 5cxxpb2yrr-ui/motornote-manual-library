Front Wiper Motor And Link: Installation

  1. INSTALL WINDSHIELD WIPER MOTOR ASSEMBLY 
    1. Install the wiper motor to the wiper link with the 3 bolts.

      Torque: 5.4 N*m (55 kgf*cm, 47 in.*lbf) 

    2. Apply grease to the crank arm pivot of the wiper motor.
    3. Install the 2 rods to the wiper motor.
      Fig 1: Installing Windshield Wiper Motor Assembly
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  2. INSTALL WINDSHIELD WIPER MOTOR AND LINK ASSEMBLY 
    1. Install the wiper motor and link with the 3 bolts.

      Torque: 5.4 N*m (55 kgf*cm, 47 in.*lbf) 

    2. Connect the connector.
      Fig 2: Installing Wiper Motor And Link
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  3. INSTALL COWL TOP VENTILATOR LOUVER LH 
    1. Attach the 5 claws to install the ventilator louver.
    2. Install the 4 clips.
      Fig 3: Installing Cowl Top Ventilator Louver LH
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  4. INSTALL COWL TOP VENTILATOR LOUVER RH 
    1. Attach the 5 claws to install the ventilator louver.
    2. Install the 4 clips.
      Fig 4: Installing Cowl Top Ventilator Louver RH
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  5. INSTALL HOOD TO COWL TOP SEAL 
    1. Attach the 5 clips to install the seal.
      Fig 5: Installing Hood To Cowl Top Seal
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  6. INSTALL FRONT WIPER ARM AND BLADE ASSEMBLY LH 
    1. Operate the wiper, and stop the windshield wiper motor at the automatic stop position.
    2. Scrape off the serration part of the wiper arm with a round file or equivalent.
    3. Clean the wiper pivot serration with a wire brush.
      Fig 6: Cleaning Wiper Pivot Serration With Wire Brush
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    4. Install the wiper arm and blade with the nut in the position shown in the illustration.

      Torque: 20 N*m (205 kgf*cm, 15 ft.*lbf) 

      Installation position mark: 

      25 to 40 mm (0.98 to 1.57 in.) 

      HINT:

      Hold down the arm hinge by hand in order to fasten the nut.

    5. Operate the wiper while running water or washer fluid over the window, and check the wiping condition and that the rear wiper does not hit against the vehicle's body.
      Fig 7: Identifying Wiper Arm And Blade Installation Position
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  7. INSTALL FRONT WIPER ARM AND BLADE ASSEMBLY RH 
    1. Operate the wiper, and stop the wiper motor at the automatic stop position.
    2. Scrape off the serration part of the wiper arm with a round file or equivalent.
    3. Clean the wiper pivot serration with a wire brush.
      Fig 8: Cleaning Wiper Pivot Serration With Wire Brush
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    4. Install the wiper arm and blade with a nut in the position shown in the illustration.

      Torque: 20 N*m (205 kgf*cm, 15 ft.*lbf) 

      Installation position mark: 

      29 to 44 mm (1.14 to 1.73 in.) 

      HINT:

      Hold down the arm hinge by hand in order to fasten the nut.

  8. INSTALL WINDSHIELD WIPER ARM HEAD CAP 
  9. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
