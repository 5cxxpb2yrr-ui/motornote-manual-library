Installation (2005/12- )

  1. INSTALL AIR CONDITIONING BLOWER ASSEMBLY 
    1. Install the wire harness and connect the 2 clamps.
      Fig 1: Installing Wire Harness And Connecting 2 Clamps
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    2. Install the A/C blower with the 4 bolts and 3 nuts.
      Fig 2: Installing A/C Blower With 4 Bolts And 3 Nuts
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    3. Attach the 2 clamps to connect the wire harness.
    4. Connect the connectors.
      Fig 3: Attaching 2 Clamps To Connecting Wire Harness
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    5. Install the clamp.
  2. INSTALL ECM 
    1. Attach the 2 claws to install the ECM.
      Fig 4: Attaching 2 Claws To Installing ECM
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    2. Install the 2 screws.
    3. Connect the connectors.
      Fig 5: Installing 2 Screws
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  3. INSTALL ECM COVER 
    1. Attach the 2 claws to install the cover.
  4. INSTALL AIR CONDITIONING AMPLIFIER ASSEMBLY 
  5. INSTALL LOWER INSTRUMENT PANEL ASSEMBLY 
    1. Install the instrument panel (see INSTALLATION ).
  6. INSTALL INSTRUMENT PANEL SUB-ASSEMBLY 
    1. Install the instrument panel (see INSTALLATION ).
      Fig 6: Installing Instrument Panel
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  7. CONNECT LIQUID TUBE SUB-ASSEMBLY 
    1. Remove the vinyl tape attached to the liquid tube and condenser.
      1. Lubricate 2 new O-rings with compressor oil and install them to the liquid tube.

        Compressor oil: 

        ND-OIL 8 or equivalent 

      2. Connect the liquid tube and piping clamp.
        Fig 7: Connecting Liquid Tube And Piping Clamp
        Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  8. CONNECT SUCTION HOSE SUB-ASSEMBLY 
    1. Remove the vinyl tape attached to the hose and condenser.
      1. Lubricate 2 new O-rings with compressor oil and install them to the hose.

        Compressor oil: 

        ND-OIL 8 or equivalent 

    2. Connect the suction hose and piping clamp.
      1. Connect the bracket with the bolt.

        Torque: 9.8 N*m (100 kgf*cm, 7 ft.*lbf) 

        Fig 8: Connecting Bracket With Bolt
        Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  9. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL 
  10. CHECK SRS WARNING LIGHT 
    1. Check the SRS warning light (see TERMINALS OF ECU ).
  11. CHARGE REFRIGERANT (See  REPLACEMENT   ) 
  12. WARM UP ENGINE (See  REPLACEMENT   ) 
  13. CHECK FOR LEAKAGE OF REFRIGERANT (See  REPLACEMENT   )
