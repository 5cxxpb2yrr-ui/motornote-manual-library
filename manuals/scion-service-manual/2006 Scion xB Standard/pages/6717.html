Clutch Release Cylinder: Installation

  1. INSTALL CLUTCH RELEASE CYLINDER ASSEMBLY 
    1. Install the clutch release cylinder with the 2 bolts.

      Torque: 12 N*m (120 kgf*cm, 9 ft.*lbf) 

      Fig 1: Installing Clutch Release Cylinder With Bolts
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  2. CONNECT CLUTCH RELEASE CYLINDER TO FLEXIBLE HOSE TUBE 
    1. Using SST, connect the flexible hose tube.

      SST 09023-00101 

      Torque: 15 N*m (155 kgf*cm, 11 ft.*lbf) 

  3. BLEED CLUTCH PIPE LINE 
    1. Fill the brake reservoir with brake fluid and bleed the clutch system.

      Torque: 8.4 N*m (86 kgf*cm, 74 in.*lbf) 

  4. CHECK FOR BRAKE FLUID LEAKAGE
