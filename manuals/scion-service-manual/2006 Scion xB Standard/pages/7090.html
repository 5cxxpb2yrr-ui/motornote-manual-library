Transmission Wire: Installation

WARNING: This page is about a different variant/trim than selected.
  1. INSTALL TRANSMISSION WIRE 
    1. Coat an O-ring with ATF.
    2. Install the transmission wire.
      Fig 1: Installing Transmission Wire
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    3. Install the bolt.

      Torque: 5.4 N*m (55 kgf*cm, 48 in.*lbf) 

      Fig 2: Installing Transmission Connector Bolts
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  2. INSTALL TRANSMISSION VALVE BODY ASSEMBLY 
    1. Align the groove of the manual valve with the pin of the manual valve lever.
    2. Temporarily install the valve body with the 13 bolts.

      HINT:

      Bolt length:

      32 mm (1.26 in.) for bolt A

      22 mm (0.87 in.) for bolt B

      55 mm (2.17 in.) for bolt C

      45 mm (1.77 in.) for bolt D

      Fig 3: Installing Valve Body With Bolts
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    3. Temporarily install the detent spring and cover with the 2 bolts.

      HINT:

      Bolt length:

      14 mm (0.55 in.) for bolt A

      45 mm (1.77 in.) for bolt B

      Fig 4: Installing Detent Spring And Cover With Bolts
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    4. Check that the manual valve lever contacts the center of the roller at the tip of the detent spring.
    5. Tighten the 15 bolts.

      Torque: 10.8 N*m (110 kgf*cm, 8 ft.*lbf) 

    6. Install the ATF temperature sensor with the lock plate and bolt.

      Torque: 10.8 N*m (110 kgf*cm, 8 ft.*lbf) 

    7. Connect the 5 shift solenoid valve connectors.
      Fig 5: Installing ATF Temperature Sensor With Lock Plate And Bolt
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  3. INSTALL VALVE BODY OIL STRAINER ASSEMBLY 
    1. Coat a new O-ring with ATF.
    2. Install the O-ring on the oil strainer.
      Fig 6: Installing O-Ring On Oil Strainer
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    3. Install the oil strainer with the 3 bolts.

      Torque: 10.8 N*m (110 kgf*cm, 8 ft.*lbf) 

      Fig 7: Installing Oil Strainer With Bolts
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  4. INSTALL AUTOMATIC TRANSAXLE OIL PAN SUBASSEMBLY 
    1. Install the 2 magnets in the oil pan, as shown in the illustration.
      Fig 8: Installing Magnets In Oil Pan
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    2. Install a new gasket and the oil pan with the 19 bolts.

      Torque: 7.8 N*m (8 kgf*cm, 69 in.*lbf) 

      Fig 9: Tightening Oil Pan Bolts
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  5. INSTALL ENGINE UNDER COVER LH 
  6. ADD AUTOMATIC TRANSAXLE FLUID 

    Fluid type: Toyota Genuine ATF TYPE T-IV 

    Standard capacity: 2.9 liters (3.1 US qts, 2.6 Imp. qts) 

  7. INSPECT AUTOMATIC TRANSAXLE FLUID 
    1. Inspect the automatic transaxle fluid (see AUTOMATIC TRANSAXLE FLUID  ).
