Rear Wiper Motor: Installation

  1. INSTALL REAR WIPER MOTOR ASSEMBLY 
    1. Install the wiper motor with the 3 bolts.

      Torque: 5.4 N*m (55 kgf*cm, 47 in.*lbf) 

    2. Connect the connector.
      Fig 1: Installing Rear Wiper Motor
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  2. INSTALL REAR WIPER MOTOR GROMMET 
    1. Install the rear wiper motor grommet as shown in the illustration.
  3. INSTALL REAR WIPER ARM AND BLADE ASSEMBLY 
    1. Operate the wiper, and stop the wiper motor at the automatic stop position.
      Fig 2: Installing Rear Wiper Motor Grommet
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    2. Scrape off the serration part of the wiper arm with a round file or equivalent.
    3. Clean the wiper pivot serration with a wiper brush.
      Fig 3: Cleaning Wiper Pivot Serration With Wiper Brush
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    4. Install the wiper arm with the nut in the position as shown in the illustration.

      Torque: 5.4 N*m (55 kgf*cm, 47 in.*lbf) 

      HINT:

      Hold down the arm hinge by hand in order fasten the nut.

    5. Operate the wiper while running water or washer fluid over the window, and check the wiping condition and that the rear wiper does not hit against the vehicle's body.
      Fig 4: Identifying Mark For Blade Position
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  4. INSTALL BACK DOOR TRIM BOARD (See  REASSEMBLY  ) 
  5. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
