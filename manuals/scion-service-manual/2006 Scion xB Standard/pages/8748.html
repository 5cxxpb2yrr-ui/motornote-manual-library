TPMS Reminder Reset - Procedure 03

NOTE: Reset is NOT required if re-inflating tires to the currently specified tire pressure.
NOTE: When a tire, wheel, tire pressure sensor, or TPMS ECU are replaced, sensor IDs needs to be registered in the ECU.

Tire Pressure Sensor Registration: 

NOTE: Set the pressure of all tires to the pressure specified on the tire and loading information label.
NOTE: The transmitter ID is written on the tire pressure sensor. It is not possible to determine a sensor's ID after installing the tire onto the wheel. Therefore, make a note of the ID before installing the tire. If replacing an ECU, read the registered sensor IDs that are stored in the old ECU, using the Techstream, and note them down
  1. Turn the ignition switch off.
  2. Connect the Techstream to DLC3.
  3. Turn the ignition switch on and Techstream on.
  4. Enter the menu items in this order: Chassis / Tire Pressure Monitor / Utility / ID Registration.
  5. Perform the procedures displayed on the screen.
NOTE: If the ID registration step is not completed within 300 seconds, ID registration will be canceled.

Confirmation Of ID Registration 

  1. On the Techstream, enter the menu items in this order: Chassis / Tire Pressure Monitor / Data List.
  2. Read the "ID Tire Inflation Pressure" values.
  3. Confirm accurately registered tire pressures for all tires (except spare tire). If all values are correctly displayed, registration was completed successfully.
NOTE: It may take up to a few minutes to update the tire pressure data. If the values are not displayed after a few minutes, perform troubleshooting according to the inspection procedure for DTCs C2121 to C2124. If the IDs have not been registered, DTC C2171 is stored in the door control receiver after 3 minutes or more. If the tire pressure values are not displayed after a few minutes, the IDs may be incorrect or the system may have a malfunction. After all IDs are registered, DTC C2126 is stored in the door control receiver and the tire pressure warning light blinks for 1 minute and then illuminates. When the door control receiver successfully receives signals from all the transmitters whose IDs are stored in the ECU, DTC C2126 is cleared and the tire pressure warning light goes off.
