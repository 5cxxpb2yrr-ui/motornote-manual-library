Outer Rear View Mirror: Removal

HINT:

  • Use the same procedures for the RH side and LH side.
  • The procedures listed below are for the LH side.
  1. REMOVE FRONT DOOR LOWER FRAME BRACKET GARNISH LH (See  DISASSEMBLY  ) 
  2. REMOVE DOOR PULL HANDLE (See  DISASSEMBLY  ) 
  3. REMOVE POWER WINDOW REGULATOR MASTER SWITCH ASSEMBLY (See  DISASSEMBLY  ) 
  4. REMOVE FRONT DOOR TRIM BOARD SUBASSEMBLY LH (See  DISASSEMBLY  ) 
  5. REMOVE FRONT DOOR SERVICE HOLE COVER LH (See  DISASSEMBLY  ) 
  6. REMOVE OUTER REAR VIEW MIRROR ASSEMBLY LH 
    1. Disconnect the connector.
    2. Remove the 3 nuts and mirror.
