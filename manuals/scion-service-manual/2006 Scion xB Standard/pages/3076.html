DTC P0125 Insufficient Coolant Temperature for Closed Loop Fuel Control: Description

Refer to DTC P0115  (see ).

DTC DETECTION CONDITION AND TROUBLE AREA

DTC No. DTC Detection Condition Trouble Area
P0125
  • Case 1:

    ECT above 10°C (50°F) at engine start and following conditions met (2 trip detection logic):

    1. 1 minute elapsed since engine start
    2. ECT sensor value remains below closed loop fuel control enabling temperature
  • Case 2:

    ECT between -6.6 and 10°C (20 and 50°F) at engine start and following conditions met (2 trip detection logic):

    1. 1.7 minutes elapsed since engine start
    2. ECT sensor value remains below closed loop fuel control enabling temperature
  • Case 3:

    Engine Coolant Temperature (ECT) less than -6.6°C (20°F) at engine start and following conditions met (2 trip detection logic):

    1. 19 minutes elapsed since engine start
    2. ECT sensor value remains below closed loop fuel control enabling temperature
