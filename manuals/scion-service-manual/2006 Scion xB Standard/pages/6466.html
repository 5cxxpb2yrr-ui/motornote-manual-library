Spiral Cable: Installation

CAUTION: Be sure to read the precautionary notices concerning the SRS airbag system before servicing it (see AIRBAG SYSTEM  ).
  1. INSTALL SPIRAL CABLE SUB-ASSEMBLY 
    1. Check that the front wheels are facing straight ahead.
    2. Set the turn signal switch to the neutral position.
      NOTE: Make sure that the turn signal switch is in the neutral position, as the pin of the turn signal switch may be snapped.
    3. Install the spiral cable.
      NOTE: When replacing the spiral cable with a new one, remove the lock pin before installing the steering wheel.
    4. Connect the connector to the spiral cable.
      NOTE: When handling the airbag connector, do not damage the airbag wire harness.
  2. INSTALL STEERING COLUMN COVER 
    1. Install the steering column covers with the 3 screws.
      Fig 1: Installing Steering Column Covers With Screws
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  3. POSITION SPIRAL CABLE 
    1. Slowly rotate the spiral cable counterclockwise by hand until it feels firm.
      NOTE: Do not use the airbag wire harness to turn the spiral cable.
      Fig 2: Rotating Spiral Cable Counterclockwise
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    2. Rotate the spiral cable clockwise approximately 2.5 turns to align the marks.
      NOTE: Do not use the airbag wire harness to turn the spiral cable.

      HINT:

      The spiral cable will rotate approximately 2.5 turns to the left and right from the center.

  4. INSTALL STEERING WHEEL ASSEMBLY (See  INSTALLATION  )

    Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  5. INSTALL STEERING PAD ASSEMBLY (See  INSTALLATION   ) 
  6. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL 
  7. INSPECT STEERING PAD ASSEMBLY (See  INSTALLATION   ) 
  8. CHECK SRS WARNING LIGHT 
    1. Check the SRS warning light (see PROBLEM SYMPTOMS TABLE  ).
  9. INSPECT STEERING WHEEL POSITION
