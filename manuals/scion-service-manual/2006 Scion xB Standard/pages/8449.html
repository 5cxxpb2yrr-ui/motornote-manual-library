Floor Shift Lever Assembly: Installation

  1. INSTALL FLOOR SHIFT LEVER ASSEMBLY 
    1. Connect the transmission control shift cable to the shift lever retainer with the clip.
    2. Connect the end of the transmission control shift cable to the floor shift lever.
      Fig 1: Connecting Transmission Control Shift Cable To Shift Lever Retainer With Clip
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    3. Connect the transmission control select cable to the shift lever retainer.
    4. Connect the end of the transmission control select cable to the floor shift lever with the clip.
      Fig 2: Identifying Serrated Part Of Select Cable Point
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
      NOTE:
      • The serrated part of the select cable point should face upward when the select cable point is connected.
      • The clip should be inserted in the direction shown in the illustration.
    5. Install the shift lever with the 4 bolts.

      Torque: 12 N*m (120 kgf*cm, 9 ft.*lbf) 

      Fig 3: Installing Shift Lever With Bolts
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    6. Connect the wire harness.
  2. INSTALL REAR CONSOLE BOX ASSEMBLY 
    1. Install the rear console box (See INSTALLATION ).
  3. INSTALL SHIFT LEVER KNOB SUB-ASSEMBLY 
    1. Install the shift lever knob (see INSTALLATION ).
