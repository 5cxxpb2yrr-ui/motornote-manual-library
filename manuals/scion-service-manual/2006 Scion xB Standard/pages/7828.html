Air Conditioning: Condenser: Reassembly

  1. INSTALL COOLER DRYER 
    1. Using pliers, install the cooler dryer.
      Fig 1: Installing Cooler Dryer
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    2. Apply a sufficient amount of compressor oil to the contact surfaces of a new O-ring and the cap.
    3. Install the O-ring to the cap.

      Compressor oil: 

      ND-OIL 8 or equivalent 

      Fig 2: Installing O-Ring To Cap
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    4. Using a 14 mm socket hexagon wrench, install the cap to the modulator.

      Torque: 2.9 N*m (29 kgf*cm, 25 in.*lbf) 

      Fig 3: Installing Cap To Modulator
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  2. INSTALL NO.1 CONDENSER BRACKET COLLAR 
    1. Install the 2 condenser bracket collars with the 2 bolts.

      Torque: 3.9 N*m (40 kgf*cm, 35 in.*lbf) 

      Fig 4: Installing 2 Condenser Bracket Collars With 2 Bolts
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
