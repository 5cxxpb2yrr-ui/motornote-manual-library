Rear Brake Shoe, Wheel Cylinder & Brake Drum: Reassembly

HINT:

  • Use the same procedures for the LH side and RH side.
  • The procedures listed below are for the LH side.
  1. INSTALL REAR WHEEL CYLINDER CUP KIT 
    1. Apply lithium soap base glycol grease to 2 new wheel cylinder cups and the 2 pistons.
    2. Install the 2 wheel cylinder cups on each piston.
    3. Install the compression spring and 2 pistons to the wheel brake cylinder.
    4. Install 2 new cylinder dust boots to the wheel brake cylinder.
  2. TEMPORARILY TIGHTEN REAR BRAKE DRUM BLEEDER PLUG 
    1. Install the bleeder plug to the cylinder.
      Fig 1: Applying Lithium Soap Base Glycol Grease To Wheel Cylinder Cups And Pistons
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002

      HINT:

      The bleeder plug will be tightened to a torque specification in the "bleed air from brake line" procedures.

    2. Install the bleeder plug cap.
  3. INSTALL REAR WHEEL BRAKE CYLINDER ASSEMBLY LH 
    1. Install the wheel brake cylinder with the bolt.

      Torque: 9.8 N*m (100 kgf*cm, 87 in.*lbf) 

    2. Using SST, connect the brake line.

      SST 09023-00101 

      Torque: 15 N*m (155 kgf*cm, 11 ft.*lbf) without SST 

      14 N*m (143 kgf*cm, 10 ft.*lbf) with SST 

      HINT:

      Use a torque wrench with a fulcrum length of 30 cm (11.81 in.).

      Fig 2: Installing Wheel Brake Cylinder With Bolt
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  4. APPLY HIGH TEMPERATURE GREASE 
    1. Apply high temperature grease to the surface of the backing plate to which the shoe is attached.
      Fig 3: Applying High Temperature Grease To Surface Of Backing Plate To Which Shoe Is Attached
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  5. INSTALL REAR BRAKE PARKING BRAKE SHOE LEVER SUB-ASSEMBLY 
    1. Using needle-nose pliers, install the parking brake lever with a new C-washer.
      Fig 4: Installing Parking Brake Lever With C-Washer
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  6. INSTALL REAR BRAKE SHOE 
    1. Using needle-nose pliers, connect the No. 3 parking brake cable to the parking brake shoe lever.
      Fig 5: Connecting No. 3 Parking Brake Cable To Parking Brake Shoe Lever
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    2. Using SST, install the rear brake shoe, pin, shoe hold down spring and shoe hold down spring cup.

      SST 09718-00010 

      Fig 6: Installing Rear Brake Shoe
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  7. INSTALL REAR BRAKE AUTOMATIC ADJUST LEVER LH 
    1. Install the automatic adjust lever and automatic adjust lever tension spring to the front brake shoe.
      Fig 7: Identifying Automatic Adjust Lever And Automatic Adjust Lever Tension Spring
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  8. INSTALL PARKING BRAKE SHOE STRUT LH 
    1. Disassemble the strut. Apply high temperature grease to the areas indicated by the arrows in the illustration. Then assemble the shoe strut.
    2. Install the shoe return spring to the shoe strut.
      Fig 8: Identifying Areas For Applying High Temperature Grease To Shoe Strut
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    3. Install the shoe strut as shown in the illustration.
      Fig 9: Installing Shoe Strut
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  9. INSTALL FRONT BRAKE SHOE 
    1. Connect the tension spring to the front brake shoe and rear brake shoe.
    2. Using SST, install the front brake shoe, pin, shoe hold down spring and shoe hold down spring cup.

      SST 09718-00010 

      Fig 10: Installing Front Brake Shoe, Pin, Shoe Hold Down Spring And Shoe Hold Down Spring Cup
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    3. Using needle-nose pliers, connect the tension spring to the front brake shoe and rear brake shoe.
      Fig 11: Connecting Tension Spring To Front Brake Shoe And Rear Brake Shoe
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  10. CONNECT PARKING BRAKE SHOE STRUT LH 
    1. Using SST, connect the shoe return spring to the front brake shoe and rear brake shoe.

      SST 09703-30011 

      NOTE: Be careful not to damage the wheel cylinder boot.
      Fig 12: Connecting Shoe Return Spring To Front Brake Shoe And Rear Brake Shoe
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  11. CHECK REAR BRAKE DRUM INSTALLATION 
    1. Check that each part is installed properly.
      Fig 13: Checking Rear Brake Drum Part Installation
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    2. Measure the inside diameter of the brake drum and diameter of the brake shoe. Check that the difference between the diameters is the correct shoe clearance.

      Standard shoe clearance: 0.6 mm (0.024 in.) 

      NOTE: There should be no oil or grease on the contact surfaces of the brake shoe and brake drum.
  12. INSTALL REAR BRAKE DRUM SUB-ASSEMBLY 
    Fig 14: Measuring Inside Diameter Of Brake Drum And Diameter Of Brake Shoe
    Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  13. ADJUST REAR BRAKE DRUM SHOE CLEARANCE 
    1. Temporarily install the 2 hub nuts.
    2. Remove the pin plug, and turn the adjuster to expand the shoe until the drum locks.
    3. Rotate the adjuster backwards by 8 notches.
    4. Install the hole plug.
    5. Remove the 2 hub nuts.
  14. FILL RESERVOIR WITH BRAKE FLUID (See  BRAKE FLUID   ) 
  15. BLEED AIR FROM BRAKE MASTER CYLINDER (See  BRAKE FLUID   ) 
    Fig 15: Adjusting Rear Brake Drum Shoe Clearance
    Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  16. BLEED AIR FROM BRAKE LINE (See  BLEEDING   ) 
  17. CHECK BRAKE FLUID LEVEL IN RESERVOIR (See  BLEEDING   ) 
  18. CHECK FOR BRAKE FLUID LEAKAGE 
  19. INSTALL REAR WHEEL 

    Torque: 103 N*m (1,050 kgf*cm, 76 ft.*lbf) 

  20. CHECK PARKING BRAKE LEVER TRAVEL (See  ADJUSTMENT  ) 
  21. ADJUST PARKING BRAKE LEVER TRAVEL (See  ADJUSTMENT  )
