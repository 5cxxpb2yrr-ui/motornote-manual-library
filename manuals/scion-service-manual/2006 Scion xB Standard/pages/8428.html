On-Vehicle Inspection

  1. CHECK CLUTCH START SYSTEM 
    1. Check that the engine does not start when the clutch pedal is released.
    2. Check that the engine starts when the clutch pedal is fully depressed.

      If necessary, replace the clutch start switch assembly.
