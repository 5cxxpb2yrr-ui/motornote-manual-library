Vane Pump: Installation

NOTE: When installing, coat the parts indicated by arrows with power steering fluid (see REMOVAL  ).
  1. INSTALL VANE PUMP ASSEMBLY 
    1. Temporarily install the vane pump with bolt A.

      HINT:

      After adjusting the V belt tension, torque the bolt.

    2. Install the adjusting strut with bolt B.

      Torque: 44 N *  m (449 kgf *  cm, 32 ft. *  lbf) 

    3. Temporarily install bolt C.

      HINT:

      After adjusting the V belt tension, torque the bolt.

      Fig 1: Installing Vane Pump With Bolt A
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  2. INSTALL REAR VANE PUMP STAY 
    1. Install the rear stay to the rear housing, as shown in the illustration.
      Fig 2: Installing Rear Stay To Rear Housing
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    2. Install the heat insulator and rear stay with the bolt.

      Torque: 44 N *  m (449 kgf *  cm, 32 ft. *  lbf) 

      NOTE: Install the heat insulator by pressing its projection into a hole in the rear bracket, as shown in the illustration.
      Fig 3: Installing Heat Insulator And Rear Stay With Bolt
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  3. CONNECT PRESSURE FEED TUBE ASSEMBLY 
    1. Using SST, connect the pressure feed tube.

      Torque: 41 N *  m (414 kgf *  cm, 30 ft. *  lbf) 

      SST 09023-12701 

      HINT:

      Fig 4: Connecting Pressure Feed Tube
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
      • Use a torque wrench with a fulcrum length of 345 mm (13.58 in.).
      • This torque value is effective when SST is parallel to a torque wrench.
    2. Check that the pressure feed tube is properly installed to the rear stay.
    3. Connect the return hose with the clip.
      NOTE: Take care not to spill fluid on the V belt.
    4. Connect the oil pressure sensor connector.
      Fig 5: Installing Pressure Feed Tube To Rear Stay
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  4. ADJUST VANE PUMP V BELT (see  INSTALLATION  ) 
  5. INSPECT DRIVE BELT DEFLECTION AND TENSION (See  ON-VEHICLE INSPECTION  ) 
  6. ADD POWER STEERING FLUID 
    1. Add power steering fluid (see ON-VEHICLE INSPECTION  ).
  7. BLEED AIR FROM POWER STEERING SYSTEM 
    1. Bleed air from the power steering system (see ON-VEHICLE INSPECTION  ).
  8. CHECK FOR POWER STEERING FLUID LEAKS 
  9. INSTALL ENGINE UNDER COVER RH 
  10. INSTALL FRONT WHEEL RH 

    Torque: 103 N *  m (1,050 kgf *  cm, 76 ft. *  lbf) 

  11. CHECK POWER STEERING FLUID LEVEL IN RESERVOIR (See  ON-VEHICLE INSPECTION   ) 
  12. INSTALL VANE PUMP OIL RESERVOIR COVER 
  13. INSTALL COWL PANEL SUB-ASSEMBLY 
  14. INSTALL WINDSHIELD WIPER LINK ASSEMBLY (See  INSTALLATION  ) 
  15. INSTALL COWL TOP VENTILATOR LOUVER LH (See  INSTALLATION  ) 
  16. INSTALL COWL TOP VENTILATOR LOUVER RH (See  INSTALLATION  ) 
  17. INSTALL HOOD TO COWL TOP SEAL (See  INSTALLATION  ) 
  18. INSTALL FRONT WIPER ARM AND BLADE ASSEMBLY LH (See  INSTALLATION  ) 
  19. INSTALL FRONT WIPER ARM AND BLADE ASSEMBLY RH (See  INSTALLATION  )
