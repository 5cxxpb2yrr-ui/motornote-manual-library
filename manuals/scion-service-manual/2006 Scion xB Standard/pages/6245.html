Data List / Active Test

  1. READ DATA LIST 

    HINT:

    Using the intelligent tester DATA LIST allows switch, sensor, actuator and other item values to be read without removing any parts. Reading the DATA LIST early in troubleshooting is one way to save time.

    1. Connect the intelligent tester (with CAN VIM) to the DLC3.
    2. Turn the ignition switch ON.
    3. Read the DATA LIST according to the display on the tester.
