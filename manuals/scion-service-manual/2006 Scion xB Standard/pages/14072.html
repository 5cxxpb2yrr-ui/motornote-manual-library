Introduction

This TSB contains information regarding Special Service Tools (SSTs) distributed or added to the SST program that apply to 2004-2009 model year Scion vehicles. Essential SSTs are listed by tool number, tool name, and tool description.

NOTE: Special Service Tools can be ordered through the Toyota/Scion SST Program by calling SPX/OTC at 1-800-933-8335

Required Materials

REQUIRED MATERIALS

  • Used to remove oil seals and bearing races.
