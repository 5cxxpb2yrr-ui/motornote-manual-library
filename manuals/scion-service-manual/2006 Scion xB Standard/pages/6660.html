Rear Axle Beam: Installation

  1. TEMPORARILY INSTALL REAR AXLE BEAM ASSEMBLY 
    1. Support the axle beam with a jack.
    2. Install the axle beam, and temporarily install the 2 bolts.
      Fig 1: Installing Axle Beam Bolts
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  2. INSTALL REAR COIL SPRING LH (See  REAR SHOCK ABSORBER   ) 
  3. INSTALL REAR COIL SPRING RH 

    HINT:

    Use the same procedures described for the LH side.

  4. TEMPORARILY INSTALL REAR SHOCK ABSORBER ASSEMBLY LH (See  REAR SHOCK ABSORBER   ) 
  5. TEMPORARILY INSTALL REAR SHOCK ABSORBER ASSEMBLY RH 

    HINT:

    Use the same procedures described for the LH side.

  6. INSTALL REAR AXLE HUB AND BEARING ASSEMBLY LH 
    1. Install the brake and the axle hub and bearing with the 4 bolts.

      Torque: 61 N*m (622 kgf*cm, 45 ft.*lbf) 

  7. INSTALL REAR AXLE HUB AND BEARING ASSEMBLY RH 

    HINT:

    Use the same procedures described for the LH side.

  8. INSTALL REAR BRAKE DRUM SUB-ASSEMBLY 
    1. Install the rear brake drum (see REASSEMBLY ).
      Fig 2: Installing Brake And Axle Hub And Bearing With Bolts
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  9. ADJUST REAR DRUM BRAKE SHOE CLEARANCE 
    1. Adjust the rear drum brake shoe clearance (see REASSEMBLY ).
  10. CONNECT NO. 3 PARKING BRAKE CABLE ASSEMBLY (See  REAR SHOCK ABSORBER   ) 
  11. CONNECT NO. 2 PARKING BRAKE CABLE ASSEMBLY (See  REAR SHOCK ABSORBER   ) 
  12. CONNECT REAR NO. 4 BRAKE TUBE (See  REAR SHOCK ABSORBER   ) 
  13. CONNECT REAR NO. 3 BRAKE TUBE (See  REAR SHOCK ABSORBER   ) 
  14. CONNECT SKID CONTROL SENSOR WIRE (See  REAR SHOCK ABSORBER   ) 
  15. FULLY TIGHTEN REAR AXLE BEAM ASSEMBLY 

    Torque: 82 N*m (836 kgf*cm, 60 ft.*lbf) 

  16. FULLY TIGHTEN REAR SHOCK ABSORBER ASSEMBLY LH (See  REAR SHOCK ABSORBER   ) 
  17. FULLY TIGHTEN REAR SHOCK ABSORBER ASSEMBLY RH 

    HINT:

    Use the same procedures described for the LH side.

  18. BLEED BRAKE LINE 
    1. Bleed the brake line (see BLEEDING ).
  19. INSTALL REAR WHEEL 

    Torque: 103 N*m (1,050 kgf*cm, 76 ft.*lbf) 

  20. INSPECT REAR WHEEL ALIGNMENT 
    1. Inspect the rear wheel alignment (see REAR WHEEL ALIGNMENT  ).
  21. CHECK ABS SPEED SENSOR SIGNAL 
    1. Check the ABS speed sensor signal (see DIAGNOSIS SYSTEM ).
