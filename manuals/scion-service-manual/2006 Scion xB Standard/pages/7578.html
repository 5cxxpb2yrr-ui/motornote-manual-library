Front Bumper: Installation

HINT:

A bolt without a torque specification is shown in the standard bolt chart (see SPECIFIED TORQUE FOR STANDARD BOLTS ).

  1. INSTALL FRONT BUMPER REINFORCEMENT 
    1. Install the reinforcement with the 4 nuts.
  2. INSTALL FRONT BUMPER COVER 
    1. Put protective tape under the front fender.
    2. Attach the 2 claws to install the bumper cover.
    3. Install the 4 bolts, 6 screws and clip.
  3. INSTALL FRONT FENDER LINER LH 
    1. Install the fender liner with the 2 screws.
  4. INSTALL FRONT FENDER LINER RH 
    1. Install the fender liner with the 2 screws.
