Reassembly (2005/12- )

HINT:

  • Use the same procedures for the RH side and LH side.
  • The procedures listed below are for the LH side.
  • A bolt without a torque specification is shown in the standard bolt chart (see SPECIFIED TORQUE FOR STANDARD BOLTS ).
CAUTION: Wear protective gloves. Sharp surfaces on the seatback spring and seat adjuster may injure your hands.
  1. INSTALL RECLINING ADJUSTER INSIDE COVER LH 
    1. Install the inside cover with the screw.
      Fig 1: Installing Inside Cover With Screw
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  2. INSTALL RECLINING ADJUSTER INSIDE COVER RH 
    1. Install the inside cover with the screw.
      Fig 2: Installing Screw
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  3. INSTALL FRONT SEAT CUSHION COVER 
    NOTE:
    • Be careful not to damage the cover.
    • When installing the hog rings, avoid wrinkling the cover.
      Fig 3: Identifying Hog Ring Installation Procedure Using Hog Ring Pliers
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    1. Using hog ring pliers, install the seat cushion cover to the seat cushion pad with new hog rings.
    2. Attach the hook and claw of the front part of the seat adjuster to install the seat cushion cover (with pad).
    3. Using hog ring pliers, install new hog rings.
      Fig 4: Identifying Hook And Claw Installation Directions
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  4. INSTALL FRONT SEATBACK COVER 
    NOTE:
    • Be careful not to damage the cover.
    • When installing the hog rings, avoid wrinkling the cover.
    1. Install the seatback pad.
    2. Using hog ring pliers, install the seatback cover to the seatback pad with new hog rings.
      Fig 5: Installing Seatback Cover To Seatback Pad With Hog Rings Using Hog Ring Pliers
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    3. Using hog ring pliers, install the seatback cover to the seatback frame with 2 new hog rings.
    4. Attach the 4 claws and install the 2 headrest supports.
      Fig 6: Installing Seatback Cover To Front Side Seatback Frame
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    5. Using hog ring pliers, install the seatback cover to the seatback frame with 2 new hog rings.
      Fig 7: Identifying Seatback Cover Installation Procedure
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    6. Using hog ring pliers, install the seatback cover to the seatback frame with 4 new hog rings.
      Fig 8: Installing Hog Rings
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    7. Using hog ring pliers, install the seatback cover to the seatback frame with 2 new hog rings.
      Fig 9: Locating Front Side Seatback Cover
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    8. Using hog ring pliers, install the seatback cover to the seatback frame with 2 new hog rings.
      Fig 10: Locating Back Side Hog Rings
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    9. w/Seat hook: Install the seatback hook with the screw.
      Fig 11: Installing Seatback Hook With Screw
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    10. Fold back the seatback cover. Then using hog ring pliers, install the seat cushion cover to the seat cushion pad with 3 new hog rings.
      Fig 12: Locating Hog Rings
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    11. Using hog ring pliers, install 3 new hog rings.
      Fig 13: Installing Hog Rings
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  5. INSTALL FRONT SEAT CUSHION SHIELD LH 
    1. Attach the 2 claws and clip to install the seat cushion shield.
    2. Install the screw.
      Fig 14: Attaching Claws And Clip To Install Seat Cushion Shield
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  6. INSTALL RECLINING ADJUSTER RELEASE HANDLE LH 
    1. Attach the claw to install the release handle.
      Fig 15: Attaching Claw To Install Release Handle
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  7. REMOVE FRONT SEAT CUSHION SHIELD INNER LH 
    1. Attach the claw and clip to install the seat cushion shield.
    2. Install the screw.
  8. INSTALL FRONT SEAT INNER BELT ASSEMBLY LH (See  INSTALLATION  ) 
  9. INSTALL FRONT SEAT HEADREST ASSEMBLY
