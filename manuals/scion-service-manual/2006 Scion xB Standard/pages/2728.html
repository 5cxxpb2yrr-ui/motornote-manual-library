Timing Chain: Installation

  1. INSTALL CHAIN 
    1. Set the position of the No. 1 cylinder to 20° ATDC.
      NOTE: To prevent the pistons from hitting against valves, the following procedures must be performed in the order below.
      1. Set the crankshaft between 40 to 140° ATDC.
      2. Set the cams of the intake and exhaust timing sprockets to 20° ATDC.
      3. Reset the crankshaft to 20° ATDC.
    2. Install the chain vibration damper with the 2 bolts.

      Torque: 9.0 N*m (92 kgf*cm, 80 in.*lbf) 

    3. Align the timing mark of the camshaft timing sprocket, camshaft timing gear and crankshaft timing sprocket with each mark plate (colored in yellow) of the timing chain.

      HINT:

      To prevent the exhaust camshaft from springing back, turn it using a wrench and set it at the mark on the chain.

    4. Install the chain tensioner slipper with the bolt.
      Fig 1: Aligning Timing Mark Of Camshaft And Crankshaft Timing Sprocket With Each Mark Plate Of Timing Chain
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002

      Torque: 9.0 N*m (92 kgf*cm, 80 in.*lbf) 

    5. Install the chain tensioner with the 2 bolts.
      1. While rotating the stopper plate of the chain tensioner upward as shown in the illustration, push in the plunger of the tensioner.
      2. While rotating the stopper plate of the tensioner downward, insert a 2.5 mm (0.098 in.) diameter bar into the holes of the stopper plate and the tensioner to hold the stopper plate.
      3. Install the chain tensioner with the 2 bolts.

        Torque: 9.0 N*m (92 kgf*cm, 80 in.*lbf) 

      4. Remove the bar from the chain tensioner.
    6. Check the tension between the intake and exhaust camshaft timing sprockets.
      Fig 2: Installing Chain Tensioner
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002

    1. Install the mounting bracket RH with the 4 bolts.

  6. INSTALL ENGINE MOUNTING INSULATOR RH 
    1. Install the mounting insulator with the 5 bolts and nut.

      Torque: 45 N*m (459 kgf*cm, 33 ft.*lbf) for bolt A 

      52 N*m (530 kgf*cm, 38 ft.*lbf) for bolt B and nut 

    2. Install the liquid tube with the bolt.
      Fig 4: Installing Engine Mounting Insulator RH
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002

      Torque: 9.8 N*m (100 kgf*cm, 7 ft.*lbf) for bolt C 

  7. INSTALL CAMSHAFT TIMING OIL CONTROL VALVE ASSEMBLY 
    1. Apply a light coat of engine oil to a new O-ring, and install it onto the camshaft timing oil control valve.
    2. Install the camshaft timing oil control valve with the bolt.
      Fig 5: Installing Camshaft Timing Oil Control Valve Assembly
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002

      Torque: 7.5 N*m (76 kgf*cm, 66 in.*lbf) 

      NOTE: Be careful not to twist an O-ring.

  10. INSTALL CRANKSHAFT PULLEY 
    1. Align the pin hole of the crankshaft pulley with the pin position and install the crankshaft pulley.
    2. Using SST, install the pulley bolt.
      Fig 6: Installing Crankshaft Pulley Bolt
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002

      SST 09330-00021, 09213-58012 (91111-50845) 

      Torque: 128 N*m (1,305 kgf*cm, 95 ft.*lbf) 

  11. INSTALL CYLINDER HEAD COVER 
    1. Apply seal packing to the 2 locations shown in the illustration.
      Fig 7: Identifying Seal Packing Application Area
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002

      Seal packing: Part No. 08826-00080 or equivalent 

      NOTE:
      • Remove any oil from the contact surface.
      • Install the cylinder head cover within 3 minutes of applying seal packing.
      • Do not start the engine for at least 2 hours after installation.
    2. Install the head cover with the 9 bolts, 2 seal washers and 2 nuts.
    3. Using several steps, uniformly tighten the bolts and nuts in the sequence shown in the illustration.
      Fig 8: Installing Head Cover
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002

      Torque: 10 N*m (102 kgf*cm, 7 ft.*lbf)
