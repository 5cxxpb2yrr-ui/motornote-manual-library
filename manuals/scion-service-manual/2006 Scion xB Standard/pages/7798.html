Air Conditioning And Blower Unit: Reassembly

  1. INSTALL COOLER EVAPORATOR SUB-ASSEMBLY 
    1. Sufficiently apply compressor oil to the contact surfaces of 2 new O-rings and install them in the cooler evaporator.

      Compressor oil: 

      ND-OIL 8 or equivalent 

    2. Install the cooler evaporator on the blower unit.
      Fig 1: Installing Cooler Evaporator On Blower Unit
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    3. Install the evaporator cover with the 3 screws.
      Fig 2: Installing Evaporator Cover With 3 Screws
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    4. Attach the 2 claws to install the air duct.
    5. Install the screw.
      Fig 3: Attaching 2 Claws To Installing Air Duct
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  2. INSTALL COOLER EXPANSION VALVE 
    1. Using a 4 mm hexagon wrench, install the cooler expansion valve with the 2 bolts.

      Torque: 5.4 N*m (55 kgf*cm, 48 in.*lbf) 

      Fig 4: Installing Cooler Expansion Valve With 2 Bolts
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  3. INSTALL AIR CONDITIONING TUBE ASSEMBLY 
    1. Sufficiently apply compressor oil to the contact surfaces of 2 new O-rings and install them in the A/C tube.

      Compressor oil: 

      ND-OIL 8 or equivalent 

    2. Using a 5 mm hexagon wrench, install the A/C tube with the bolt.

      Torque: 5.4 N*m (55 kgf*cm, 48 in.*lbf) 

      Fig 5: Installing A/C Tube With Bolt
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    3. Install the packing.
      Fig 6: Installing Packing
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  4. INSTALL COOLER THERMISTOR 
    1. Install the cooler thermistor and attach the clamp.
      NOTE:
      • When installing the thermistor, move it one fin toward the front of the vehicle from its former position. Do not install it to its former position, as that fin may be bent and the thermistor may not function properly.
      • Do not install the thermistor to a position that is horizontally toward the rear of the vehicle.
        Fig 7: Installing Cooler Thermistor And Attach Clamp
        Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  5. INSTALL BLOWER WITH FAN MOTOR SUBASSEMBLY 
    1. Install the blower motor with the 3 screws.
    2. Connect the connector.
      Fig 8: Installing Blower Motor With 3 Screws
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  6. INSTALL BLOWER MOTOR COVER 
    1. Install the blower motor cover with the holding spring and 4 screws.
      Fig 9: Installing Blower Motor Cover With Holding Spring And 4 Screws
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    2. Connect the rod in the order shown in the illustration.
      Fig 10: Connecting Rod In Order Shown
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  7. INSTALL BLOWER RESISTOR 
    1. Install the blower resistor with the 2 screws.
    2. Connect the connector.
      Fig 11: Installing Blower Resistor With 2 Screws
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  8. INSTALL DAMPER SERVO SUB-ASSEMBLY 
    1. Install the damper servo with the 3 screws.
      Fig 12: Installing Damper Servo With 3 Screws
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  9. INSTALL AIR FILTER CASE 
    1. Attach the 2 claws to install the air filter case.
      Fig 13: Attaching 2 Claws To Install Air Filter Case
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
