Park / Neutral Position Switch: Installation

WARNING: This page is about a different variant/trim than selected.
  1. INSTALL PARK/NEUTRAL POSITION SWITCH ASSEMBLY 
    1. Install the park/neutral position switch to the manual valve shaft.
    2. Temporarily install the 2 bolts.
      Fig 1: Installing Park/Neutral Position Switch
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    3. Install a new lock washer and tighten the manual valve shaft nut.

      Torque: 6.9 N*m (70 kgf*cm, 61 in.*lbf) 

    4. Temporarily install the control shaft lever.
      Fig 2: Installing Lock Washer And Tightening Manual Valve Shaft Nut
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    5. Turn the lever counterclockwise until it stops, and then turn it clockwise 2 notches.
    6. Remove the control shaft lever.
      Fig 3: Turning Shaft Lever
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    7. Align the groove with neutral basic line.
    8. Hold the switch in this position and tighten the 2 bolts.

      Torque: 5.4 N*m (55 kgf*cm, 48 in.*lbf) 

      Fig 4: Aligning Groove And Holding Switch In This Position And Tightening Bolts
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    9. Using a screwdriver, stake the nut with the lock washer.
      Fig 5: Staking Nut With Lock Washer Using Screwdriver
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    10. Install the control shaft lever with the washer and nut.

      Torque: 12.7 N*m (130 kgf*cm, 9 ft.*lbf) 

    11. Connect the connector to the park/neutral position switch.
      Fig 6: Installing Control Shaft Lever With Washer And Nut
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  2. INSTALL TRANSMISSION CONTROL CABLE ASSEMBLY 
    1. Temporarily install the control cable to the control shaft lever with the nut.
    2. Install the control cable to the bracket with a new clip.
      Fig 7: Installing Control Cable To Bracket With Clip
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002

  4. ADJUST SHIFT LEVER POSITION

  5. INSPECT SHIFT LEVER POSITION 
    1. Inspect the shift lever position (see ADJUSTMENT  ).
