Problem Symptoms Table

If a normal code is displayed during the DTC check but the problem still occurs, check the circuits for each problem symptom in the order given in the table below and proceed to the relevant troubleshooting page.

NOTE:
  • When replacing the skid control ECU, sensors, etc., turn the ignition switch OFF.
  • When replacing the yaw rate sensor and/or the brake actuator assembly, make sure to perform the yaw rate sensor zero point calibration (see CALIBRATION  ).
