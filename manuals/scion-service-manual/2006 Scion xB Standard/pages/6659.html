Rear Axle Beam: Reassembly

  1. INSTALL REAR AXLE CARRIER BUSH LH 
    1. Position the axle carrier bush with the axle beam as shown in the illustration.
      Fig 1: Positioning Axle Carrier Bush With Axle Beam
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    2. Using SST, install the bushes on the axle beam.

      SST 09710-14013 (09710-00021), 09950-40011 (09951-04010, 09952-04010, 09953-04030, 09954-04020, 09955-04031, 09957-04010, 09958-04011), 09950-60010 (09951-00560) 

      NOTE:
      • Hang the claw of SST to the bush deeply and firmly.
      • Do not scratch the rubber portion of the bush.
      • Do not deform the bush's rib.
  2. INSTALL REAR AXLE CARRIER BUSH RH 

    HINT:

    Use the same procedures described for the LH side.
