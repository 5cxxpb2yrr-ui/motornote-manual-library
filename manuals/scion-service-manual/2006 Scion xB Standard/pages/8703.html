Rear Shock Absorber: Installation

  1. INSTALL REAR SHOCK ABSORBER ASSEMBLY LH 
    1. Install the suspension support to the shock absorber.
    2. Install the shock absorber, suspension support and cushion retainer to the body.
    3. While holding the piston rod, install the lower nut so that the piston rod protrudes 15 to 18 mm (0.59 to 0.71 in.) from the lower nut.
    4. Install the upper nut and torque it against the lower one.

      Torque: 25 N*m (250 kgf*cm, 18 ft.*lbf) 

    5. While raising the jack, install the shock absorber to the axle beam with the spacer and nut.

      Torque: 49 N*m (500 kgf*cm, 36 ft.*lbf) 

  2. INSTALL REAR WHEEL 

    Torque: 103 N*m (1,050 kgf*cm, 76 ft.*lbf)
