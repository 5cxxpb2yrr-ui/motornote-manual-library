HEATED OXYGEN SENSOR (for Bank 1 Sensor 2): Removal

  1. DISCONNECT CABLE FROM NEGATIVE BATTERY TERMINAL 
    CAUTION: Wait at least 90 seconds after disconnecting the cable from the negative (-) battery terminal to prevent airbag and seat belt pretensioner activation.
  2. REMOVE SHIFT LEVER KNOB (for Manual Transaxle) 
  3. REMOVE REAR CONSOLE BOX (See  REMOVAL  ) 
  4. REMOVE HEATED OXYGEN SENSOR 
    1. Disconnect the sensor connector.
      Fig 1: Disconnecting Heated Oxygen Sensor Connector

    2. Using SST, remove the sensor.
