Headlight Assembly: Reassembly

HINT:

  • Use the same procedures for the RH side and LH side.
  • The procedures listed below are for the LH side.
  1. INSTALL CLEARANCE LIGHT BULB 
    1. Install the bulb to the socket.
    2. Install the clearance light socket.
  2. INSTALL NO. 1 HEADLIGHT BULB 
    1. Release the lock of the set spring and install the headlight No. 1 bulb.
  3. INSTALL HEADLIGHT SOCKET COVER 
    1. Install the headlight socket cover.
