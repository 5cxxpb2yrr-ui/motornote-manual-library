Parking Brake Cable: Installation

HINT:

  • Use the same procedures for the No. 2 parking brake cable and No. 3 parking brake cable.
  • The procedures listed below are for the No. 3 parking brake cable.
  1. INSTALL NO. 3 PARKING BRAKE CABLE ASSEMBLY 
    1. Connect the parking brake cable to the parking brake equalizer.
    2. Install the parking brake cable to the body with the nut and 3 bolts.

      Torque: 5.4 N*m (55 kgf*cm, 48 in.*lbf) 

      Fig 1: Installing Parking Brake Cable To Body With Nut And Bolts
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  2. CONNECT NO. 3 PARKING BRAKE CABLE ASSEMBLY 
    1. Connect the parking brake cable to the backing plate with the bolt.

      Torque: 7.8 N*m (80 kgf*cm, 69 in.*lbf) 

  3. APPLY HIGH TEMPERATURE GREASE (See  REASSEMBLY  ) 
  4. INSTALL REAR BRAKE SHOE (See  REASSEMBLY  ) 
  5. INSTALL REAR BRAKE AUTOMATIC ADJUST LEVER LH (See  REASSEMBLY  ) 
  6. INSTALL PARKING BRAKE SHOE STRUT LH (See  REASSEMBLY  ) 
  7. INSTALL FRONT BRAKE SHOE (See  REASSEMBLY  ) 
  8. CONNECT REAR BRAKE SHOE RETURN SPRING (See  REASSEMBLY  ) 
  9. CHECK REAR BRAKE DRUM INSTALLATION (See  REASSEMBLY  ) 
  10. INSTALL REAR BRAKE DRUM SUB-ASSEMBLY 
  11. ADJUST REAR BRAKE DRUM SHOE CLEARANCE (See  REASSEMBLY  ) 
  12. INSTALL REAR WHEEL 

    Torque: 103 N*m (1,050 kgf*cm, 76 ft.*lbf) 

  13. INSTALL FRONT NO. 2 FLOOR HEAT INSULATOR 
    1. Install the heat insulator with the 3 bolts.

      Torque: 5.5 N*m (55 kgf*cm, 48 in.*lbf) 

  14. INSTALL FRONT EXHAUST PIPE ASSEMBLY (See  INSTALLATION  ) 
  15. INSTALL FRONT FLOOR PANEL BRACE 
    1. Install the floor panel brace with the 2 bolts.
  16. TEMPORARILY TIGHTEN NO. 1 WIRE ADJUSTING NUT 
    1. Temporarily tighten the wire adjusting nut.
  17. CHECK PARKING BRAKE LEVER TRAVEL (See  PARKING BRAKE SYSTEM   ) 
  18. ADJUST PARKING BRAKE LEVER TRAVEL (See  PARKING BRAKE SYSTEM   ) 
  19. INSTALL REAR CONSOLE BOX ASSEMBLY (See  INSTALLATION  ) 
  20. INSTALL CONSOLE BOX CARPET 
  21. INSTALL REAR CONSOLE BOX COVER 
  22. INSTALL SHIFT LEVER KNOB SUB-ASSEMBLY (for Manual Transaxle) 
  23. CHECK EXHAUST GAS LEAKAGE
