Clutch Start Switch: Installation

  1. INSTALL CLUTCH START SWITCH ASSEMBLY 
    1. Install the clutch start switch to the bracket with the nut.

      Torque: 6.2 N*m (63 kgf*cm, 55 in.*lbf) 

    2. Install the clutch start switch with the 2 nuts.

      Torque: 6.2 N*m (63 kgf*cm, 55 in.*lbf) 

    3. Connect the clutch start switch connector.
  2. INSPECT CLUTCH START SWITCH ASSEMBLY (See  CLUTCH START SWITCH   )
