Camshaft Timing Oil Control Valve Assembly: Installation

  1. INSTALL CAMSHAFT TIMING OIL CONTROL VALVE ASSEMBLY 
    1. Apply a light coat of engine oil to a new O-ring.
    2. Install the O-ring to the oil control valve.
    3. Install the oil control valve with the bolt.

      Torque: 7.5 N*m (76 kgf*cm, 66 in.*lbf) 

    4. Connect the oil control valve connector.
      Fig 1: Connecting Oil Control Valve Connector

  2. INSTALL FAN BELT ADJUSTING BAR 
    1. Temporarily install the adjusting bar with the bolt and nut.
    2. Adjust the drive belt tension (see INSTALLATION ).

  3. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
