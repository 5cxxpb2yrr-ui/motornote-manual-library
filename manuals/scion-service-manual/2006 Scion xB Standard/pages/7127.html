Second Brake Piston: Reassembly

WARNING: This page is about a different variant/trim than selected.
  1. INSTALL 2ND BRAKE CYLINDER O-RING 
    1. Install 2 new O-rings to the 2nd brake cylinder.
      NOTE: Be careful not to damage the O-rings.
      Fig 1: Installing O-Rings To 2Nd Brake Cylinder
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  2. INSTALL 2ND BRAKE PISTON 
    1. Coat 2 new O-rings with ATF and install them in the 2nd brake cylinder.
    2. Be careful not to damage the O-rings and press in the 2nd brake piston into the 2nd brake cylinder with your hands.
      Fig 2: Installing 2Nd Brake Piston
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  3. INSTALL 2ND BRAKE PISTON RETURN SPRING SUB-ASSEMBLY 
    1. Install the piston return spring.
      Fig 3: Installing Piston Return Spring
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    2. Place SST on the piston return spring, and compress the piston return spring with a press.

      SST 09387-00060 

    3. Using a screwdriver, install the snap ring.
      NOTE: Be sure the end gap of the snap ring is not aligned with the piston return spring claw.
      Fig 4: Installing Snap Ring
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
