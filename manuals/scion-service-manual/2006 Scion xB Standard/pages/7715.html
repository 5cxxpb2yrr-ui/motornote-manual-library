Brake Pedal: Installation

  1. INSTALL BRAKE PEDAL PAD 
    1. Install the brake pedal pad to the brake pedal.
  2. INSTALL STOP LIGHT SWITCH ASSEMBLY 
    1. Install the stop light switch to the support with the nut.

      Torque: 26 N*m (265 kgf*cm, 19 ft.*lbf) 

  3. INSTALL BRAKE PEDAL SUB-ASSEMBLY 
    1. Apply lithium soap base glycol grease to the ends and sides of 2 new brake pedal bushes and brake pedal shaft.
    2. Install the switch cushion.
    3. Install the brake pedal and 2 brake pedal bushes to the brake pedal support with the brake pedal shaft and nut.

      Torque: 37 N*m (375 kgf*cm, 27 ft.*lbf) 

      Fig 1: Applying Lithium Soap Base Glycol Grease To Ends And Sides Of Brake Pedal Bushes And Brake Pedal Shaft
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  4. INSTALL BRAKE PEDAL SUPPORT SUB-ASSEMBLY 
    1. Install the brake pedal support with the 4 nuts.

      Torque: 13 N*m (127 kgf*cm, 9 ft.*lbf) 

      Fig 2: Installing Brake Pedal Support With Nuts
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    2. Install the bolt on the brake pedal support.

      Torque: 21 N*m (214 kgf*cm, 15 ft.*lbf) 

      Fig 3: Installing Bolt On Brake Pedal Support
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  5. CONNECT MASTER CYLINDER PUSH ROD CLEVIS 
    1. Apply lithium soap base glycol grease to the clevis pin.
    2. Install the clevis pin and clip.
      NOTE: The direction for the clip installation is as shown in the illustration.
    3. Install the brake pedal return spring.
    4. Connect the stop light switch connector to the stop light switch.
      Fig 4: Installing Master Cylinder Push Rod Clevis Pin And Clip
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  6. INSTALL LOWER INSTRUMENT PANEL ASSEMBLY 
    1. Install the instrument panel (see INSTALLATION ).
  7. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL 
  8. CHECK AND ADJUST BRAKE PEDAL HEIGHT (See  ADJUSTMENT   ) 
  9. CHECK BRAKE PEDAL FREE PLAY (See  ADJUSTMENT   ) 
  10. CHECK BRAKE PEDAL RESERVE DISTANCE (See  ADJUSTMENT   ) 
  11. CHECK SRS WARNING LIGHT (w/SRS Airbag) 
    1. Check the SRS warning light (see PROBLEM SYMPTOMS TABLE ).
