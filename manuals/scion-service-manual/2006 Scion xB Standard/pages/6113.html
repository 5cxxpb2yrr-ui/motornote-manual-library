How To Proceed With Troubleshooting

HINT:

  • Use these procedures to troubleshoot the air conditioning system.
  • *: Use the intelligent tester.
  1. VEHICLE BROUGHT TO WORKSHOP 

    NEXT 

  2. INSPECT BATTERY VOLTAGE 

    Standard voltage: 

    11 to 14 V 

    If the voltage is below 11 V, recharge or replace the battery before proceeding.

    NEXT 

  3. CHECK CAN COMMUNICATION SYSTEM* 
    1. Use the intelligent tester to check if the CAN Communication system is functioning.

      Result 

      RESULT

      Result Proceed to
      CAN DTC is not output A
      CAN DTC is output B

      HINT:

      The amplifier of this system is connected to the CAN communication system. Therefore, before starting troubleshooting, make sure to check that there is no trouble in the CAN communication system.

    B: Go to  CAN COMMUNICATION 

    A: Go to next step 

  4. CHECK DTC 
    1. Check for DTCs and note any codes that are output.
    2. Delete the DTC.
    3. Recheck for DTCs. Based on the DTCs output above, try to force output of the A/C system DTC by simulating the operation indicated by the DTC.

      Result 

      RESULT

      Result Proceed to
      DTC is output A
      DTC is not output B

    B: Go to step   6 

    A: Go to next step
