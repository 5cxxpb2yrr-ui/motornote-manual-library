Installation (2005/07-2005/12)

  1. INSTALL STEERING COLUMN ASSEMBLY 
    1. Install the steering column from the front side, and install the steering column clamp to the instrumental reinforcement.
    2. Install the steering column with the bolt.

      Torque: 21 N*m (210 kgf*cm, 15 ft.*lbf) 

    3. Connect the connectors and wire harness clamps.
      Fig 1: Installing Steering Column With Bolt
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  2. INSTALL STEERING INTERMEDIATE SHAFT ASSEMBLY 
    1. Align the matchmarks on the main shaft and steering intermediate shaft.
    2. Install the steering intermediate shaft with the bolt.
      NOTE: Install the intermediate shaft with the distinction paint facing the steering column side.
      Fig 2: Aligning Matchmarks On Main Shaft And Steering Intermediate Shaft
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  3. CONNECT STEERING INTERMEDIATE SHAFT ASSEMBLY 
    1. Align the matchmarks on the sliding yoke and intermediate shaft.
    2. Connect the intermediate shaft with the bolt.

      Torque: 28 N*m (286 kgf*cm, 21 ft.*lbf) 

  4. INSTALL STEERING COLUMN HOLE COVER PLATE 
    1. Install the column hole cover plate with the clip.
  5. INSTALL WINDSHIELD WIPER SWITCH ASSEMBLY (See  INSTALLATION  ) 
    Fig 3: Aligning Matchmarks On Sliding Yoke And Intermediate Shaft
    Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  6. INSTALL HEADLIGHT DIMMER SWITCH ASSEMBLY (See  INSTALLATION  ) 
  7. PLACE FRONT WHEELS FACING STRAIGHT AHEAD 
  8. INSTALL SPIRAL CABLE SUB-ASSEMBLY (See  INSTALLATION  ) 
  9. CONNECT FLOOR SHIFT PARKING LOCK CABLE ASSEMBLY (for Automatic Transaxle) 
    1. With the key in the ACC position, connect the floor shift parking lock cable.
  10. CHECK KEY INTERLOCK OPERATION 
    Fig 4: Connecting Floor Shift Parking Lock Cable
    Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  11. INSTALL STEERING COLUMN COVER 
    1. Install the column cover upper.
    2. Install the 2 bolts.

      Torque: 21 N*m (210 kgf*cm, 15 ft.*lbf) 

      Fig 5: Installing Column Cover Upper Bolts
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    3. Install the column cover lower with the 3 screws.
  12. INSTALL SPIRAL CABLE SUB-ASSEMBLY (See  INSTALLATION  ) 
  13. INSTALL STEERING WHEEL ASSEMBLY 
    1. Align the matchmarks on the steering wheel and steering main shaft.
    2. Install the steering wheel with the set nut.

      Torque: 50 N*m (510 kgf*cm, 37 ft.*lbf) 

    3. Connect the connector.
  14. INSTALL STEERING PAD ASSEMBLY (See  INSTALLATION  ) 
    Fig 6: Installing Column Cover Lower With Screws
    Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  15. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL 
  16. INSPECT STEERING PAD ASSEMBLY 
    1. Inspect the steering pad (see INSTALLATION ).
  17. PERFORM VSC SYSTEM CALIBRATION 
    1. Perform VSC system calibration (see PROBLEM SYMPTOMS TABLE ).
  18. INSPECT SRS WARNING LIGHT 
    1. Inspect the SRS warning light (see PROBLEM SYMPTOMS TABLE ).
