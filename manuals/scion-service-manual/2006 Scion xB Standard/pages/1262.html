Brake Booster: Installation

  1. INSTALL BRAKE BOOSTER ASSEMBLY 
    1. Install the brake booster and a new gasket.
    2. Install the booster and a new gasket with the 4 nuts.

      Torque: 13 N*m (127 kgf*cm, 9 ft.*lbf) 

    3. Install the push rod clevis to the booster.
      Fig 1: Installing Booster And Gasket With Nuts
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    4. Apply lithium soap base glycol grease to the clevis pin.
    5. Install the clip and clevis pin.
      NOTE: The clip must be installed as shown in the illustration.
    6. Install the brake pedal return spring.
      Fig 2: Installing Brake Pedal Return Spring
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    7. Connect the vacuum hose to the brake booster and slide the clip.
  2. CHECK AND ADJUST BRAKE BOOSTER PUSH ROD (See  INSPECTION   ) 
  3. INSTALL BRAKE ACTUATOR ASSEMBLY WITH BRACKET (See  INSTALLATION  ) 
  4. INSTALL BRAKE MASTER CYLINDER SUBASSEMBLY (See  INSTALLATION   ) 
  5. CONNECT CLUTCH RESERVOIR TUBE (for Manual Transaxle) 
    1. Slide the clip and connect the clutch reservoir tube.
      Fig 3: Connecting Vacuum Hose To Brake Booster And Slide Clip
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  6. INSTALL AIR CLEANER CAP SUB-ASSEMBLY 
  7. INSTALL BATTERY 
  8. FILL RESERVOIR WITH BRAKE FLUID (See  BRAKE FLUID   ) 
  9. BLEED AIR FROM BRAKE MASTER CYLINDER (See  BRAKE FLUID   ) 
  10. BLEED AIR FROM BRAKE LINE (See  BLEEDING   ) 
  11. BLEED AIR FROM CLUTCH LINE (for Manual Transaxle) (See  INSTALLATION  ) 
  12. CHECK AND ADJUST BRAKE PEDAL HEIGHT (See  ADJUSTMENT   ) 
  13. CHECK BRAKE PEDAL FREE PLAY (See  ADJUSTMENT   ) 
  14. CHECK BRAKE PEDAL RESERVE DISTANCE (See  ADJUSTMENT   ) 
  15. CHECK BRAKE FLUID LEVEL IN RESERVOIR (See  BLEEDING   )
