Rear Seat Outer Belt Assembly: Installation

HINT:

  • Use the same procedures for the RH side and LH side.
  • The procedures listed below are for the LH side.
  1. INSTALL REAR SEAT OUTER BELT ASSEMBLY CENTER 
    1. Install the belt with the nut.

      Torque: 42 N*m (428 kgf*cm, 31 ft.*lbf) 

    2. Install the rear seatback cover (with pad) RH (see REASSEMBLY ).
    3. Install the rear seatback stop button grommet (see REASSEMBLY ).
    4. Install the 4 rear seat headrest supports (see REASSEMBLY ).
    5. Install the 2 tether anchor covers (see REASSEMBLY ).
    6. Install the rear seatback lock release button (see REASSEMBLY ).
    7. Install the rear seat headrest assembly (see REASSEMBLY ).
    8. With the belt installed, check that the belt locks when it is pulled out quickly.
      NOTE: The check should be performed with the outer belt installed.

      HINT:

      The seat belt does not lock when it is pulled out to a length of 955 mm (37.60 in.) or less.

      If the operation is not as specified, replace the belt.

    9. Check the fastening function of the child restraint system.
      NOTE: The check should be performed with the outer belt installed.
      1. When the belt is pulled out fully, the belt should automatically try to retract.
      2. After the belt has fully retracted, the belt should be able to be pulled out and retracted again.

        If the operation is not as specified, replace the belt.

  2. INSTALL REAR SEAT 3 POINT TYPE BELT ASSEMBLY RH 
    1. Install the belt with the bolt on the retractor side.

      Torque: 42 N*m (428 kgf*cm, 31 ft.*lbf) 

      NOTE: Make sure that the anchor part does not run onto the protruding part of the side panel.
    2. Install the belt with the bolt on the shoulder anchor side.

      Torque: 42 N*m (428 kgf*cm, 31 ft.*lbf) 

    3. With the belt installed, check that the belt locks when it is pulled out quickly.
      NOTE: The check should be performed with the outer belt assembly installed.

      If the operation is not as specified, replace the belt.

    4. Check the fastening function of the child restraint system.
      NOTE: The check should be performed with the outer belt assembly installed.
      1. When the belt is pulled out fully, the belt should automatically try to retract.
      2. After the belt has fully retracted, the belt should be able to be pulled out and retracted again.

        If the operation is not as specified, replace the belt.

  3. INSTALL ROOF SIDE GARNISH INNER RH (See  INSTALLATION  ) 
  4. INSTALL DECK TRIM SIDE PANEL ASSEMBLY RH 
    1. Install the deck trim side panel assembly RH (see INSTALLATION ).
    2. Install the rear seat 3 point type belt assembly RH with the bolt on the floor anchor side.

      Torque: 42 N*m (428 kgf*cm, 31 ft.*lbf) 

  5. INSTALL REAR DECK TRIM COVER (See  INSTALLATION  ) 
  6. INSTALL REAR SEATBACK ASSEMBLY RH (See  INSTALLATION  ) 
  7. INSTALL REAR SEATBACK ASSEMBLY LH (See  INSTALLATION  ) 
  8. INSTALL REAR SEAT CUSHION WITH COVER PAD SUB-ASSEMBLY (See  INSTALLATION  ) 
  9. INSTALL DECK FLOOR BOX RH 
  10. REMOVE DECK FLOOR BOX LH 
  11. INSTALL NO. 1 DECK BOARD 
  12. INSTALL NO. 2 DECK BOARD 
  13. INSTALL REAR DOOR OPENING TRIM WEATHERSTRIP RH 
  14. INSTALL REAR DOOR SCUFF PLATE RH (See  INSTALLATION  ) 
  15. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
