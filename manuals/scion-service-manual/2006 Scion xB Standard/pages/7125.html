Second Brake Piston: Disassembly

WARNING: This page is about a different variant/trim than selected.
  1. REMOVE 2ND BRAKE PISTON RETURN SPRING SUB-ASSEMBLY 
    1. Place SST on the piston return spring and compress the piston return spring with a press.

      SST 09387-00060 

    2. Using a screwdriver, remove the snap ring.
      Fig 1: Removing Snap Ring Using Screwdriver
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    3. Remove the piston return spring from the 2nd brake cylinder.
  2. INSPECT 2ND BRAKE PISTON RETURN SPRING SUB-ASSEMBLY (See  DISASSEMBLY   ) 
    Fig 2: Removing Piston Return Spring From 2Nd Brake Cylinder
    Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  3. REMOVE 2ND BRAKE PISTON 
    1. Hold the 2nd brake piston and apply compressed air (392 kPa,4.0 kgf/cm2 , 57 psi) to the 2nd brake cylinder to remove the 2nd brake piston.
      Fig 3: Applying Compressed Air To Brake Pistion
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  4. REMOVE 2ND BRAKE CYLINDER O-RING 
    1. Using a screwdriver, remove the 2 O-rings from the 2nd brake cylinder.
      Fig 4: Removing O-Rings From 2Nd Brake Cylinder
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
