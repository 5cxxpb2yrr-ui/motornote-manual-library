Rear Bumper: Reassembly

  1. INSTALL REAR SIDE MARKER LIGHT ASSEMBLY LH 
    1. Install the marker light with the nut.
  2. INSTALL REAR SIDE MARKER LIGHT ASSEMBLY RH 
    1. Install the marker light with the nut.
  3. INSTALL REAR BUMPER EXTENSION RH 
    1. Attach the 2 claws to install the extension.
  4. INSTALL REAR BUMPER PIECE RH 
    1. Attach the claw and install the bumper piece LH to the bumper piece RH with the clip.
  5. INSTALL REAR BUMPER PIECE LH 
    1. Attach the 8 claws and install the bumper piece LH (with bumper piece RH) with the 5 clips.
  6. INSTALL REAR BUMPER PROTECTOR LH 
    1. Install the bumper protector with the 3 clips.
  7. INSTALL REAR BUMPER PROTECTOR RH 
    1. Install the bumper protector with the 3 clips.
