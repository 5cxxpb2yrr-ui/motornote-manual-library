Rear Door: Reassembly

HINT:

  • Use the same procedure for the RH side and LH side.
  • The procedures listed below are for the LH side.
  • A bolt without a torque specification is shown in the standard bolt chart (see SPECIFIED TORQUE FOR STANDARD BOLTS ).
  1. INSTALL REAR DOOR WEATHERSTRIP LH 
    1. Attach the clip and install the weatherstrip.
  2. INSTALL REAR DOOR CHECK ASSEMBLY LH 
    1. Apply MP grease to the sliding areas of the check.
    2. Install the check to the door panel with the 2 bolts.

      Torque: 5.5 N*m (56 kgf*cm, 49 in.*lbf) 

      HINT:

      Install the door check so that the rivet head is facing upward.

    3. Apply adhesive to the threads of the bolt.

      Adhesive: 

      Part No. 08833-00070, THREE BOND 1324 or equivalent 

    4. Install the check to the body panel with the bolt.

      Torque: 30 N*m (306 kgf*cm, 22 ft.*lbf) 

      Fig 1: Installing Check To Door Panel With Bolts
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  3. INSTALL REAR DOOR OUTSIDE HANDLE ASSEMBLY LH 
    1. Install the handle with the bolt.

      Torque: 5.0 N*m (51 kgf*cm, 44 in.*lbf) 

      Fig 2: Installing Handle With Bolt
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    2. Install the outside panel hole seal with the bolt and nut.

      Torque: 5.0 N*m (51 kgf*cm, 44 in.*lbf) 

      Fig 3: Installing Outside Panel Hole Seal With Bolt And Nut
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  4. INSTALL REAR DOOR LOCK ASSEMBLY LH 
    1. Install the actuator with the 2 screws.
      Fig 4: Installing Actuator With Screws
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    2. Apply MP grease to the sliding and rotating areas of the door lock.
      Fig 5: Identifying Grease Application Area
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    3. Apply adhesive to the threads of the 3 screws.

      Adhesive: 

      Part No. 08833-00070, THREE BOND 1324 or equivalent 

    4. Using a T30 "Torx" socket, install the door lock with the 3 screws.

      Torque: 5.0 N*m (51 kgf*cm, 44 in.*lbf) 

    5. Connect the door lock connector.
      Fig 6: Connecting Door Lock Connector
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    6. Install the bellcrank, remote control rod and No. 2 remote control rod.
      Fig 7: Installing Bellcrank, Remote Control Rod And No 2 Remote Control Rod
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    7. Install the guide.
    8. Attach the knob as indicated by the white arrow mark in the illustration.

      HINT:

      After attaching the knob, rotate it 90° in the direction indicated by the arrow marks in the illustration.

      Fig 8: Installing Guide
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    9. Connect the No. 2 remote control rod in the direction indicated by the arrow marks in the illustration.
      Fig 9: Connecting No 2 Remote Control Rod
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  5. INSTALL REAR POWER WINDOW REGULATOR MOTOR ASSEMBLY LH 
    1. Using a T25 "Torx" driver, install the motor with the 3 screws.

      Torque: 5.5 N*m (56 kgf*cm, 49 in.*lbf) 

      Fig 10: Installing Motor With Screws
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  6. INSTALL REAR DOOR WINDOW REGULATOR SUBASSEMBLY LH 
    1. Apply MP grease to the sliding and rotating areas of the window regulator.
      NOTE: Do not apply grease to the spring of the window regulator.
      Fig 11: Installing Rear Door Window Regulator Subassembly LH
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    2. Install the window regulator with the 4 bolts.

      Torque: 8.0 N*m (82 kgf*cm, 71 in.*lbf) 

    3. Connect the window regulator connector.
      NOTE: Be careful not to drop the window regulator as it may become damaged.
  7. INSTALL REAR DOOR GLASS SUB-ASSEMBLY LH 
    NOTE: Be careful not to damage the glass.
    1. Install the door glass into the door panel.

      HINT:

      Insert a cushion inside the door panel to prevent the door glass from being scratched.

      Fig 12: Installing Window Regulator With Bolts
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  8. INSTALL REAR DOOR QUARTER WINDOW GLASS LH 
    1. Install the quarter window weatherstrip on the glass.
      NOTE: Be careful not to damage the glass.
    2. Install the quarter window glass as indicated by the arrow mark in the illustration.
    3. Mount the door glass to the window regulator along the glass run.
      Fig 13: Installing Quarter Window Weatherstrip On Glass
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  9. INSTALL REAR DOOR WINDOW DIVISION BAR SUBASSEMBLY LH 
    1. Insert the division bar into the door panel and then rotate it by 90°, as indicated by the arrow marks in the illustration.
      Fig 14: Inserting Division Bar
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    2. Install the division bar with the 2 bolts and screw.

      Torque: 5.0 N*m (51 kgf*cm, 44 in.*lbf) 

    3. Install the glass run.
    4. Check operation of the power window.
      1. Connect the power window switch to the wire harness and turn the ignition switch ON.
      2. Check that the power window control operates normally by performing the power window control switch UP / DOWN operation several times.

        If the result is not as specified, check the power window control switch (see SYSTEM DESCRIPTION ).

        Fig 15: Installing Division Bar With Bolts And Screw
        Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  10. INSTALL REAR DOOR GLASS WEATHERSTRIP ASSEMBLY OUTER LH (See  INSTALLATION  ) 
  11. INSTALL REAR DOOR SERVICE HOLE COVER LH 
    1. Apply butyl tape to the door, as shown in the illustration.
    2. Install a new service hole cover.

      HINT:

      • When installing the service hole cover, pull out the links and connectors through the service hole cover.
      • There should be no wrinkles or folds after attaching the service hole cover.
      • After attaching the service hole cover, check the sealing quality.
        Fig 16: Applying Butyl Tape To Door
        Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    3. Install the bracket with the 2 screws.
      Fig 17: Installing Bracket With Screws
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  12. INSTALL REAR DOOR INSIDE HANDLE SUBASSEMBLY LH 
    1. Move the inside handle in the direction indicated by the arrow in the illustration to install the inside handle.
    2. Connect the rod to the inside handle.
      Fig 18: Installing Rear Door Inside Handle Subassembly LH
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  13. INSTALL REAR DOOR TRIM BOARD SUBASSEMBLY LH 
    1. Attach the 7 clips and install the trim board.
    2. Install the screw as shown in the illustration.
      Fig 19: Installing Rear Door Trim Board Subassembly LH
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  14. INSTALL POWER WINDOW REGULATOR SWITCH ASSEMBLY REAR 
    1. Attach the 2 claws to install the switch to the armrest base panel upper labeled A in the illustration.
    2. Connect the connector.
    3. Attach the 2 claws to install the armrest base panel upper to the rear door trim board labeled B in the illustration.
      Fig 20: Installing Power Window Regulator Switch Assembly Rear
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  15. INSTALL DOOR PULL HANDLE 
    1. Install the handle with the screw.
  16. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
