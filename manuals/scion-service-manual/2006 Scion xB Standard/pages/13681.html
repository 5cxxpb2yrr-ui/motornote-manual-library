Rear Bumper: Installation

HINT:

A bolt without a torque specification is shown in the standard bolt chart (see SPECIFIED TORQUE FOR STANDARD BOLTS ).

  1. INSTALL REAR BUMPER SIDE RETAINER LH 
    1. Install the 2 side retainers with the 2 screws.
  2. INSTALL REAR BUMPER SIDE RETAINER RH 
    1. Install the 2 side retainers with the 2 screws.
  3. INSTALL REAR BUMPER REINFORCEMENT SUBASSEMBLY 
    1. Install the reinforcement with the 6 nuts.
  4. INSTALL REAR BUMPER SHIELD BRACKET CENTER 
    1. Attach the 8 claws to install the 3 shield brackets.
  5. INSTALL REAR BUMPER COVER 
    1. Put protective tape under the quarter panel.
    2. Attach the clamps and connect the rear side marker light wire harness's connectors.
    3. Connect the wire harness's connector to the vehicle body.
    4. Attach the 2 claws and install the bumper cover with the 6 bolts.

  6. INSTALL REAR BUMPER SIDE SEAL LH 
    1. Attach the claw and install the side seal with the screw and 2 clips.
  7. INSTALL REAR BUMPER SIDE SEAL RH 

    HINT:

    Use the same procedures described for the LH side.
