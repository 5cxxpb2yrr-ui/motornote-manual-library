Installation (2005/12- )

HINT:

  • Use the same procedures for the RH side and LH side.
  • The procedures listed below are for the RH side.
  • A bolt without a torque specification is shown in the standard bolt chart (see SPECIFIED TORQUE FOR STANDARD BOLTS ).
  1. INSTALL FRONT SEAT INNER BELT ASSEMBLY LH 
    1. Install the inner belt with the bolt.

      Torque: 42 N*m (428 kgf*cm, 31 ft.*lbf) 

  2. INSTALL FRONT SEAT ASSEMBLY RH 
    1. Install the front seat (see INSTALLATION ).
  3. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL 
  4. CHECK SRS WARNING LIGHT 
    1. Check SRS warning light (see TERMINALS OF ECU ).
