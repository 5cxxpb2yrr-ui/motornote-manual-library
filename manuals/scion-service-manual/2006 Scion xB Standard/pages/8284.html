Engine Control System (1NZ-FE): ECM: Installation

  1. INSTALL ECM 
    1. Install the No. 3 ECM bracket with the 2 screws.
    2. Install the No. 2 ECM bracket with the 2 screws.
    3. Install the ECM bracket with the 2 screws.
    4. Install the ECM with the 2 bolts.

      Torque: 3.0 N*m (31 kgf*cm, 27 in.*lbf) 

    5. Connect the 4 ECM connectors.
  2. INSTALL GLOVE COMPARTMENT DOOR ASSEMBLY (See  INSTALLATION  ) 
  3. CONNECT CABLE TO NEGATIVE BATTERY TERMINAL
