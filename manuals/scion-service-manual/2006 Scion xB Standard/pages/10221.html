Front Shock Absorber With Coil Spring: Reassembly

  1. INSTALL FRONT SHOCK ABSORBER ASSEMBLY LH 
  2. INSTALL FRONT SPRING BUMPER LH 
  3. INSTALL FRONT COIL SPRING LH 
    1. Using SST, compress the coil spring.

      SST 09727-30021 (09727-00010, 09727-00021, 09727-00031) 

      NOTE: Do not use an impact wrench. It will damage the SST.
      Fig 1: Compressing Coil Spring
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    2. Install the coil spring on the shock absorber.

      HINT:

      Fit the lower end of the coil spring into the gap of the spring lower seat.

  4. INSTALL FRONT COIL SPRING INSULATOR UPPER LH 
    1. Install the upper insulator with the mark facing the outside of the vehicle.
      Fig 2: Installing Spring Seat Upper With OUT Mark Facing Outside Of Vehicle
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  5. INSTALL FRONT COIL SPRING SEAT UPPER LH 
    1. Install the spring seat upper with the "OUT" mark facing the outside of the vehicle.
  6. INSTALL FRONT SUSPENSION SUPPORT LH DUST SEAL 
  7. INSTALL FRONT SUSPENSION SUPPORT SUBASSEMBLY LH 
  8. INSTALL FRONT SUPPORT TO FRONT SHOCK ABSORBER LH NUT 
    1. Using the 2 nuts and a screwdriver or an equivalent to secure the front shock absorber, install a new center nut.

      Torque: 33 N*m (340 kgf*cm, 25 ft.*lbf) 

      NOTE: Be careful not to damage the suspension support stud bolts.
    2. Remove the SST.
    3. Apply MP grease to the suspension support.
  9. INSTALL FRONT SUSPENSION SUPPORT DUST COVER LH
