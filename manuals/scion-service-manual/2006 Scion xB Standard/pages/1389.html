Front Drive Shaft Assembly: Reassembly

HINT:

  • Use the same procedures for the RH side and LH side.
  • The procedures listed below are for the LH side.
  1. INSTALL FRONT DRIVE SHAFT DUST COVER LH 
    1. Using SST and a press, press in the dust cover.

      SST 09527-10011 

      NOTE:
      • Be careful not to damage the dust cover.
      • Dust cover should be installed completely.
  2. INSTALL FRONT DRIVE INBOARD JOINT HOLE SNAP RING 
    1. Install a new hole snap ring.
      Fig 1: Installing Front Drive Shaft Dust Cover LH
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  3. INSTALL FRONT DRIVE SHAFT OUTBOARD BOOT 
    1. Wrap the spline of the outboard joint shaft with vinyl tape to prevent the boot from being damaged.
    2. Install the new parts on the inboard joint shaft in the following order.
      1. No. 2 outboard joint boot clamp.
      2. Outboard joint boot
      3. Outboard joint boot clamp.
    3. Pack the outboard joint with grease.

      Standard grease capacity: 155 to 170 g (5.5 to 6.1 oz.) 

    4. Install the outboard joint boot on the outboard joint shaft.
  4. INSTALL FRONT NO. 2 AXLE OUTBOARD JOINT BOOT CLAMP 
    1. Secure the No. 2 outboard joint boot clamp onto the outboard joint boot.
    2. Place SST onto the No. 2 outboard joint boot clamp.

      SST 09521-24010 

    3. Tighten the SST so that the No. 2 outboard joint boot clamp is pinched.
      NOTE: Do not overtighten the SST.
      Fig 2: Installing Front No. 2 Axle Outboard Joint Boot Clamp
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    4. Using SST, measure the clearance of the No. 2 outboard joint boot clamp.

      SST 09240-00020 (09242-00080) 

      Standard clearance: 0.8 mm (0.031 in.) or less 

      NOTE: When the measured value exceeds the specified value, retighten the clamp.
  5. INSTALL FRONT AXLE OUTBOARD JOINT BOOT CLAMP 
    1. Mount drive shaft in a soft vise.
    2. Secure the outboard joint boot clamp onto the outboard joint boot.
    3. Place SST onto the outboard joint boot clamp.

      SST 09521-24010 

    4. Tighten the SST so that the outboard joint boot clamp is pinched.
      NOTE: Do not overtighten the SST.
      Fig 3: [Tightening Special Tool While Outboard Joint Boot Clamp Is Pinched]
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    5. Using SST, measure the clearance of the outboard joint boot clamp.

      SST 09240-00020 (09242-00080) 

      NOTE: When the measured value exceeds the specified value, retighten the clamp.
      Fig 4: Measuring Clearance Of Outboard Joint Boot Clamp
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  6. INSTALL FRONT DRIVE SHAFT DAMPER RH (RH DRIVE SHAFT) 
    1. Install the drive shaft damper RH on the outboard joint shaft.
  7. INSTALL DRIVE SHAFT DAMPER SETTING CLAMP (RH DRIVE SHAFT) 
    1. Install the damper setting clamp to the shaft.
      NOTE: Be sure to install the clamp in the correct position.
    2. One touch clamp type:

      Using a screwdriver, install the damper setting clamp as shown in the illustration.

    3. Claw engagement type:

      Using needle nose pliers, install the damper setting clamp as shown in the illustration.

      Fig 5: Installing Drive Shaft Damper Setting Clamp
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  8. INSTALL FRONT DRIVE INBOARD JOINT ASSEMBLY 

    HINT:

    Before installing the boot, wrap the spline of the drive shaft with vinyl tape to prevent the boot from being damaged.

    1. Install the new parts on the outboard joint shaft in the following order.
      1. Inboard joint boot clamp
      2. Inboard joint boot
      3. No. 2 inboard joint boot clamp
    2. Align the matchmarks and tap in the tripod joint to the outboard joint.
    3. Using a brass bar and hammer, install the tripod joint.
      NOTE:
      • Do not tap the roller.
      • Be sure to install the tripod joint in the correct direction.
        Fig 6: Aligning Tripod Joint And Outboard Joint Matching Marks
        Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    4. Using a snap ring expander, install a new inner shaft snap ring.
    5. Apply grease to the inboard joint.

      Standard grease capacity: 125 to 135 g (4.5 to 4.8 oz.) 

      Fig 7: Installing Inner Shaft Snap Ring
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    6. Align the matchmarks and install the inboard joint on the outboard joint shaft.
  9. INSTALL FRONT DRIVE SHAFT INBOARD JOINT BOOT 
    1. Install the inboard joint boot on the inboard joint and outboard joint shaft.
      Fig 8: Identifying Matching Marks On Inboard Joint And Outboard Joint Shaft
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  10. INSTALL FRONT NO. 2 AXLE INBOARD JOINT BOOT CLAMP 
    1. One touch clamp type:

      Using a screwdriver, install the inboard joint boot clamp as shown in the illustration.

    2. Claw engagement type:

      Using needle nose pliers, install the inboard joint boot clamp as shown in the illustration.

      Fig 9: Installing Front No. 2 Axle Inboard Joint Boot Clamp
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  11. INSTALL FRONT AXLE INBOARD JOINT BOOT CLAMP 
    1. One touch clamp type:

      Using a screwdriver, install the inboard joint boot clamp as shown in the illustration.

    2. Claw engagement type:

      Using needle nose pliers, install the inboard joint boot clamp as shown in the illustration.

      Fig 10: Installing Front Axle Inboard Joint Boot Clamp
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  12. INSPECT FRONT DRIVE SHAFT 
    1. Check that there is no remarkable play in the outboard joint.
    2. Check that the inboard joint slides smoothly in the thrust direction.
    3. Check that there is no remarkable play in the radial direction of the inboard joint.
    4. Check the boots for damage.
      Fig 11: Inspecting Front Drive Shaft
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
