Inspection Procedure

  1. CHECK SRS WARNING LIGHT 
    1. Turn the ignition switch ON, and check the SRS warning light condition.

      HINT:

      If this trouble occurs, the SRS warning light is off. If it is on, a DTC is output. Troubleshoot for the output DTC.

      OK: 

      The SRS warning light does not come on. 

    NG : Go to step   9 

    OK : Go to Next Step 

  2. CHECK PASSENGER AIRBAG ON / OFF INDICATOR CONDITION 
    1. Turn the ignition switch ON.
    2. Check if the passenger airbag ON / OFF indicator correctly indicates the front passenger seat condition.

      OK 

      FRONT PASSENGER SEAT CONDITION

      Front Passenger Seat Condition ON Indicator OFF Indicator
      Vacant OFF OFF
      Adult is seated. ON OFF
      Child is seated. OFF ON
      Child restraint system is set. OFF ON
      Front passenger occupant classification system failure OFF ON

    OK : END 

    NG : Go to Next Step 

  3. PERFORM ZERO POINT CALIBRATION 
    1. Turn the ignition switch OFF.
    2. Connect the intelligent tester to the DLC3.
    3. Turn the ignition switch ON.
    4. Using the intelligent tester, perform "Zero point calibration" (see INITIALIZATION  ).

      OK: 

      "COMPLETED" is displayed. 

    NG : Go to step   5 

    OK : Go to Next Step 

  4. PERFORM SENSITIVITY CHECK 
    1. Using the intelligent tester, perform the "Sensitivity check" (see INITIALIZATION  ).

      Standard value: 

      27 to 33 kg (59.52 to 72.75 lb) 

    OK : END 

    NG : Go to Next Step 

  5. RETIGHTEN FRONT SEAT ASSEMBLY RH BOLT 
    1. Turn the ignition switch OFF.
    2. Loosen the 4 installation bolts of the front seat RH.
    3. Tighten the 4 installation bolts of the front seat RH to the specified torque.

      Torque: 37 N*m (380 kgf*cm, 27 ft.*lbf) 

    NG : Go to step   8 

    OK : Go to Next Step 

  6. PERFORM ZERO POINT CALIBRATION 
    1. Connect the intelligent tester to the DLC3.
    2. Turn the ignition switch ON.
    3. Using the intelligent tester, perform "Zero point calibration" (see INITIALIZATION  ).

      OK: 

      "COMPLETED" is displayed. 

    NG : Go to step   8 

    OK : Go to Next Step 

  7. PERFORM SENSITIVITY CHECK 
    1. Using the intelligent tester, perform the "Sensitivity check" (see INITIALIZATION  ).

      Standard value: 

      27 to 33 kg (59.52 to 72.75 lb) 

    OK : END 

    NG : Go to Next Step 

  8. CHECK CONNECTOR 
    1. Turn the ignition switch OFF.
    2. Disconnect the cable from the negative (-) battery terminal.
    3. Check that the connectors are properly connected to the occupant classification ECU and the 4 occupant classification sensors.

      OK: 

      The connectors are properly connected. 

    4. Disconnect the connectors from the occupant classification ECU and the 4 occupant classification sensors.
    5. Check that the connectors are not damaged or deformed.

      OK: 

      The connectors are normal. 

    NG : REPAIR OR REPLACE CONNECTOR 

    OK : Go to Next Step 

  9. CHECK FOR DTC 
    1. Connect the connectors to the occupant classification ECU and the 4 occupant classification sensors.
    2. Connect the cable to the negative (-) battery terminal.
    3. Turn the ignition switch ON, and wait for at least 60 seconds.
    4. Turn the ignition switch OFF.
    5. Clear the DTCs stored in the memory (see DTC CHECK / CLEAR  ).
    6. Turn the ignition switch ON, and wait for at least 60 seconds.
    7. Check the DTCs (see DTC CHECK / CLEAR  ).

      OK: 

      DTC is not output. 

    NG : REPLACE CENTER AIRBAG SENSOR ASSEMBLY 

    OK : Go to Next Step 

  10. REPLACE OCCUPANT CLASSIFICATION ECU 
    1. Turn the ignition switch OFF.
    2. Disconnect the negative (-) terminal cable from the battery.
    3. Replace the occupant classification ECU (see REMOVAL ).

      HINT:

      Perform the inspection using parts from a normal vehicle if possible.

    NEXT 

  11. PERFORM ZERO POINT CALIBRATION 
    1. Connect the cable to the negative (-) battery terminal.
    2. Connect the intelligent tester to the DLC3.
    3. Turn the ignition switch ON.
    4. Using the intelligent tester, perform "Zero point calibration" (see INITIALIZATION  ).

      HINT:

      "COMPLETED" is displayed on the tester when the calibration is completed.

    NEXT 

  12. PERFORM SENSITIVITY CHECK 
    1. Using the intelligent tester, perform the "Sensitivity check" (see INITIALIZATION  ).

      Standard value: 

      27 to 33 kg (59.52 to 72.75 lb) 

    NEXT 

    END
