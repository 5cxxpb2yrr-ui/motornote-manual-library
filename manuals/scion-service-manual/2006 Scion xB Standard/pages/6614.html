Rear Coil Spring: Installation

  1. INSTALL REAR COIL SPRING LH 
    1. Install the coil spring insulator upper so that its gap fits to the end of the coil spring.
      Fig 1: Installing Coil Spring Insulator Upper
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    2. Install the coil spring insulator lower and coil spring to the axle beam.
      NOTE: Be sure to install the coil spring so that the paint mark comes to a position below the vehicle body.
      Fig 2: Identifying Coil Spring Paint Mark
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  2. TEMPORARILY INSTALL REAR SHOCK ABSORBER ASSEMBLY LH 
    1. While lifting up the axle beam with jacks, install the shock absorber to the axle beam.
    2. Temporarily install the washer and nut.
  3. TEMPORARILY INSTALL REAR SHOCK ABSORBER ASSEMBLY RH 

    HINT:

    Use the same procedures described for the LH side.

    Fig 3: Installing Shock Absorber Washer And Nut
    Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  4. CONNECT NO. 3 PARKING BRAKE CABLE ASSEMBLY 
    1. Install the parking brake cable with the nut.

      Torque: 5.4 N*m (55 kgf*cm, 48 in.*lbf) 

  5. CONNECT NO. 2 PARKING BRAKE CABLE ASSEMBLY 

    HINT:

    Use the same procedures described for the No. 3 cable.

    Fig 4: Installing Parking Brake Cable With Nut
    Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  6. CONNECT REAR NO. 4 BRAKE TUBE 
    1. Using SST, connect the brake tube to the flexible hose.

      SST 09023-00101 

      Torque: 15 N*m (155 kgf*cm, 11 ft.*lbf) 

    2. Install the clip.
  7. CONNECT REAR NO. 3 BRAKE TUBE 

    HINT:

    Use the same procedures described for the No. 4 tube.

  8. CONNECT SKID CONTROL SENSOR WIRE 
    1. Install the sensor wire with the bolt.

      Torque: 8.0 N*m (82 kgf*cm, 71 in.*lbf) 

    2. Connect the sensor wire.

      HINT:

      Use the same procedures described for the other side.

      Fig 5: Connecting Brake Tube To Flexible Hose
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  9. FULLY TIGHTEN REAR AXLE BEAM ASSEMBLY 
    1. Stabilize the shock absorber.

      HINT:

      If the bolt cannot be tightened at this position, support the axle beam with the jack and load the rear compartment with a mass of approximately 90 kg (198 lb.).

      Standard length of shock absorber: 250 mm (9.8 in.) 

    2. Fully tighten the bolt.

      Torque: 82 N*m (836 kgf*cm, 60 ft.*lbf) 

  10. FULLY TIGHTEN REAR SHOCK ABSORBER ASSEMBLY LH 
    1. Fully tighten the nut.

      Torque: 49 N*m (500 kgf*cm, 36 ft.*lbf) 

  11. FULLY TIGHTEN REAR SHOCK ABSORBER ASSEMBLY RH 

    HINT:

    Use the same procedures described for the LH side.

  12. BLEED BRAKE LINE 
    1. Bleed the brake line (see BLEEDING ).
  13. INSTALL REAR WHEEL 

    Torque: 103 N*m (1,050 kgf*cm, 76 ft.*lbf) 

    Fig 6: Tightening Rear Axle Beam Bolts
    Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  14. INSPECT REAR WHEEL ALIGNMENT 
    1. Inspect the rear wheel alignment (see REAR WHEEL ALIGNMENT  ).
  15. CHECK ABS SPEED SENSOR SIGNAL 
    1. Check the ABS speed sensor signal (see DIAGNOSIS SYSTEM ).
