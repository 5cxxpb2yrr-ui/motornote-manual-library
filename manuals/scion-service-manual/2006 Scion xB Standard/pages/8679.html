Back Door Support: Installation

HINT:

  • Use the same procedure for the RH side and LH side.
  • The procedures listed below are for the LH side.
  • A bolt without a torque specification is shown in the standard bolt chart (see SPECIFIED TORQUE FOR STANDARD BOLTS ).
  1. INSTALL BACK DOOR STAY SUB-ASSEMBLY LH 
    1. Install the stay with the 3 bolts.

      Torque: 22.0 N*m (224 kgf*cm, 16 ft.*lbf) for bolt A 

      8.0 N*m (82 kgf*cm, 71 ft.*lbf) for bolt B
