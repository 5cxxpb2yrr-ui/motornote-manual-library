How To Proceed With Troubleshooting

HINT:

  • Use these procedures to troubleshoot the occupant classification system.
  • *: Use the intelligent tester.
  1. VEHICLE BROUGHT TO WORKSHOP 

    NEXT 

  2. INSPECT BATTERY VOLTAGE 

    Standard voltage: 

    11 to 14 V 

    If the voltage is below 11 V, recharge or replace the battery before proceeding.

    NEXT 

  3. PASSENGER AIRBAG ON / OFF INDICATOR CHECK 

    NEXT 

  4. CHECK FOR DTC* 
    1. Check for DTCs and note any codes that are output (see DTC CHECK / CLEAR  ).
    2. Delete the DTC.
    3. Recheck for DTCs. Based on the DTC output above, try to force output of the same airbag system DTC or occupant classification system DTC by simulating the operation indicated by the DTC.

      Result: 

      RESULT

      Result Proceed to
      Occupant classification system DTC output reoccurs A
      DTC output does not reoccur B
      Airbag system DTC output reoccurs C

    B : GO TO  PROBLEM SYMPTOMS TABLE  

    C : GO TO  AIRBAG SYSTEM  

    A : Go to next step 

  5. DTC CHART 

    NEXT 

  6. CIRCUIT INSPECTION 

    NEXT 

  7. REPAIR OR REPLACE 

    NEXT 

  8. CLEAR DTC (Present and Past DTCs) 
    1. Clear DTCs.

    NEXT 

  9. CHECK FOR DTC (Present and Past DTCs) 
    1. Check for DTCs.

      Result: 

      RESULT

      Result Proceed to
      DTC is not output. A
      DTC is output. B

    B : Go to step   5 

    A : Go to next step 

  10. SYMPTOM SIMULATION 
    1. Check the passenger airbag ON / OFF indicator condition.

      Result: 

      RESULT

      Result Proceed to
      Passenger airbag ON / OFF indicator is operating normally. A
      Passenger airbag ON / OFF indicator ("OFF") and SRS warning light come on. B

    B : Go to step   4 

    A : Go to next step 

  11. CONFIRMATION TEST 

    NEXT : END
