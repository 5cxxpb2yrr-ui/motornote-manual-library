Front Brake Pad, Brake Caliper & Brake Rotor: Reassembly

HINT:

  • Use the same procedures for the LH side and RH side.
  • The procedures listed below are for the LH side.
  1. TEMPORARILY TIGHTEN FRONT DISC BRAKE BLEEDER PLUG 
    1. Install the bleeder plug to the brake cylinder.

      HINT:

      The bleeder plug will be tightened to a torque specification in the "bleed air from brake line" procedures.

    2. Install the bleeder plug cap.
  2. INSTALL PISTON SEAL 
    1. Apply lithium soap base glycol grease to a new piston seal.
    2. Install the piston seal to the brake cylinder.
  3. INSTALL FRONT DISC BRAKE PISTON 
    1. Apply lithium soap base glycol grease to the brake piston and a new cylinder boot.
    2. Install the cylinder boot to the brake piston.
    3. Install the piston (with boot) to the brake cylinder.
      NOTE: Do not forcibly install the piston to the cylinder.
      Fig 1: Applying Lithium Soap Base Glycol Grease To Brake Piston

  4. INSTALL CYLINDER BOOT 
    1. Install the cylinder boot to the brake cylinder.
      NOTE: Install the boot securely to the grooves of the cylinder and piston.
    2. Using a screwdriver, install the set ring.
      NOTE: Be careful not to damage the boot.
