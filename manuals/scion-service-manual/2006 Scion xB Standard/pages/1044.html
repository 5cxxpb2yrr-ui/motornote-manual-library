Front Door: Reassembly

HINT:

  • Use the same procedures for the RH side and LH side.
  • The procedures listed below are for the LH side.
  • A bolt without a torque specification is shown in the standard bolt chart (see SPECIFIED TORQUE FOR STANDARD BOLTS ).
  1. INSTALL FRONT DOOR WEATHERSTRIP LH 
    1. Install the weatherstrip and attach the clips.
  2. INSTALL FRONT DOOR CHECK ASSEMBLY LH 
    1. Apply MP grease to the sliding areas of the check.
    2. Install the check to the door panel with the 2 bolts.

      Torque: 5.5 N*m (56 kgf*cm, 49 in.*lbf) 

      HINT:

      Install the door check so that the rivet head is facing upward.

    3. Apply adhesive to the threads of the bolt.

      Adhesive: 

      Part No. 08833-00070, THREE BOND 1324 or equivalent 

    4. Install the check to the body panel with the bolt.

      Torque: 30 N*m (306 kgf*cm, 22 ft.*lbf) 

      Fig 1: Installing Check To Door Panel With Bolts
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  3. INSTALL FRONT DOOR OUTSIDE HANDLE ASSEMBLY LH 
    1. Install the cylinder to the handle.
    2. Lock the cylinder by turning it as indicated by the arrow mark in the illustration.
      Fig 2: Installing Cylinder To Handle
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    3. Install the handle together with the cylinder with the 2 bolts.

      Torque: 5.5 N*m (56 kgf*cm, 49 in.*lbf) 

      Fig 3: Installing Handle With Cylinder With Bolts
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  4. INSTALL FRONT DOOR LOCK ASSEMBLY LH 
    1. Install the actuator with the 2 screws.
      Fig 4: Installing Actuator With Screws
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    2. Apply MP grease to the sliding and rotating areas of the door lock.
      Fig 5: Identifying Grease Application Area
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    3. Install the bolt.

      Torque: 5.0 N*m (51 kgf*cm, 44 in.*lbf) 

    4. Apply adhesive to the threads of the 3 screws.

      Adhesive: 

      Part No. 08833-00070, THREE BOND 1324 or equivalent 

    5. Using a T30 "Torx" socket, install the door lock with the 3 screws.

      Torque: 5.0 N*m (51 kgf*cm, 44 in.*lbf) 

    6. Connect the door lock connector.
      Fig 6: Installing Screws
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    7. Install the lock open rod and outside locking link in the direction indicated by the arrow marks in the illustration.
      Fig 7: Installing Lock Open Rod And Outside Locking Link
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    8. Install the guide.
    9. Attach the knob as indicated by the white arrow mark in the illustration.

      HINT:

      After attaching the knob, rotate it 90° in the direction indicated by the arrow marks in the illustration.

      Fig 8: Attaching Knob
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  5. INSTALL FRONT DOOR FRAME SUB-ASSEMBLY REAR LOWER LH 
    1. Install the frame with the bolt.

      Torque: 5.5 N*m (56 kgf*cm, 49 in.*lbf) 

      Fig 9: Installing Frame With Bolt
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  6. INSTALL FRONT POWER WINDOW REGULATOR MOTOR ASSEMBLY LH 
    1. Using a T25 "Torx" driver, install the motor with the 3 screws.

      Torque: 5.5 N*m (56 kgf*cm, 49 in.*lbf) 

      Fig 10: Installing Motor With Screws
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  7. INSTALL POWER WINDOW REGULATOR SUBASSEMBLY LH 
    1. Apply MP grease to the sliding and rotating areas of the window regulator.
      NOTE: Do not apply grease to the spring of the window regulator.
      Fig 11: Installing Power Window Regulator Subassembly LH
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    2. Install the window regulator with the 6 bolts.

      Torque: 8.0 N*m (82 kgf*cm, 71 in.*lbf) 

      NOTE: Be careful not to drop the window regulator as it may become damaged.
    3. Connect the window regulator connector.
      Fig 12: Installing Window Regulator With Bolts
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  8. INSTALL FRONT DOOR GLASS SUB-ASSEMBLY LH 
    1. Install the glass clip as indicated by the arrow mark in the illustration.

      Standard measurement 

      STANDARD MEASUREMENT

      Area Specified Condition
      Lower frame upper end x glass clip 170 +- 30 mm (6.70 +- 1.18 in.)
    2. Install the glass run.
      NOTE: Be careful not to damage the glass.
      Fig 13: Installing Glass Clip
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    3. Insert the door glass into the door panel along the glass run as indicated in the illustration.
      Fig 14: Inserting Door Glass Into Door Panel
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    4. Install the door glass to the window regulator with the 2 bolts.

      Torque: 5.0 N*m (51 kgf*cm, 44 in.*lbf) 

    5. Check operation of the power window.
      1. Connect the power window switch to the wire harness and turn the ignition switch ON.
      2. Check that the power window control operates normally by performing the power window control switch UP / DOWN operation several times.

        If the result is not as specified, check the power window control switch (see SYSTEM DESCRIPTION ).

        Fig 15: Installing Door Glass To Window Regulator With Bolts
        Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  9. INSTALL FRONT NO. 1 SPEAKER ASSEMBLY (See  INSPECTION  ) 
  10. INSTALL FRONT DOOR GLASS WEATHERSTRIP ASSEMBLY OUTER LH (See  INSTALLATION  ) 
  11. INSTALL OUTER REAR VIEW MIRROR ASSEMBLY LH (See  INSTALLATION  ) 
  12. INSTALL FRONT DOOR SERVICE HOLE COVER LH 
    1. Apply butyl tape to the door as shown in the illustration.
    2. Install a new service hole cover.

      HINT:

      • When installing the service hole cover, pull out the links and connectors through the service hole cover.
      • There should be no wrinkles or folds after attaching the service hole cover.
      • After attaching the service hole cover, check the sealing quality.
        Fig 16: Applying Butyl Tape To Door
        Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    3. Install the bracket with the 2 screws.
      Fig 17: Installing Bracket With Screws
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  13. INSTALL FRONT DOOR INSIDE HANDLE SUBASSEMBLY LH 
    1. Move the inside handle in the direction indicated by the arrow in the illustration to install the inside handle.
    2. Connect the cable to the inside handle.
      Fig 18: Installing Front Door Inside Handle Subassembly LH
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  14. INSTALL FRONT DOOR TRIM BOARD SUBASSEMBLY LH 
    1. Attach the claws to install the weatherstrip inner.
    2. Attach the 7 clips to install the trim board.
    3. Install the screw and clip A as shown in the illustration.
      Fig 19: Installing Front Door Trim Board Subassembly LH
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  15. INSTALL POWER WINDOW REGULATOR MASTER SWITCH ASSEMBLY 
    1. Driver's side:
      1. Install the window regulator master switch to the armrest base panel upper LH with the 3 screws.
    2. Passenger's side:
      1. Attach the 2 claws to install the power window regulator switch.
    3. Connect the switch connector.
      Fig 20: Installing Window Regulator Master Switch To Armrest Base Panel Upper LH With Screws
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  16. INSTALL DOOR PULL HANDLE 
    1. Install the pull handle to the trim board with the screw.
      Fig 21: Installing Pull Handle To Trim Board With Screw
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  17. INSTALL FRONT DOOR LOWER FRAME BRACKET GARNISH LH 
    1. Attach the clip and claw to install the garnish.
