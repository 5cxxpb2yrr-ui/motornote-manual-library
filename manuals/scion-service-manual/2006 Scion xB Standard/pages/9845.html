Alarm Triggers

While the system is ARMED, an ALARM will be TRIGGERED when any of the following occurs:

  • Forcibly opening any door. 
    Fig 1: Opening Door
    Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  • Manually unlocking a door 

    Manually operating an inside lock button will Trigger an ALARM.

    NOTE: Because this action will Trigger an ALARM, it is important that you do not ARM the system while someone is in the vehicle.
    Fig 2: Unlocking Door
    Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  • "Hot wiring" the vehicle 

    The xB-Security can detect the absence of the ignition key if the ignition circuit is shorted in attempt to start the vehicle.

    Fig 3: Caution For Starting Vehicle
    Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  • Intrusion Detection 

    When the radar sensor detects intrusion, it TRIGGERS an ALARM first, then a regular ALARM. See the description of how the RADAR SENSOR TRIGGERS ALARMS  .

    Fig 4: Detecting Radar Sensor
    Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  • Power restoration 

    If power to the system is interrupted while it is ARMED, an ALARM will be TRIGGERED immediately when power is restored.

    Fig 5: Restoration Of Power
    Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
