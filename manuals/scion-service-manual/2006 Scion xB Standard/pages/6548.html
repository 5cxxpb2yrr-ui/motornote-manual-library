Vane Pump: Reassembly

  1. INSTALL VANE PUMP HOUSING OIL SEAL 
    1. Coat the lip of a new housing oil seal with power steering fluid.
    2. Using SST and a press, press in the new housing oil seal.

      SST 09950-60010 (09951-00280), 09950-70010 (09951-07100) 

      NOTE: Make sure that the oil seal is installed correctly.
      Fig 1: Pressing In Housing Oil Seal
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  2. INSTALL SHAFT SUB-ASSEMBLY WITH PULLEY 
    1. Coat the inside bushing surface of the front housing with power steering fluid.
    2. Gradually insert the shaft with pulley.
      NOTE: Be careful not to damage the lip of the oil seal.

      HINT:

      Wrap the shaft with vinyl tape before inserting.

      Fig 2: Wrapping Shaft With Vinyl Tape Before Inserting
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  3. INSTALL FRONT VANE PUMP SIDE PLATE 
    1. Coat a new O-ring with power steering fluid and install it to the front housing.
      Fig 3: Installing O-Ring To Front Housing
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    2. Coat a new O-ring with power steering fluid and install it to the front side plate.
      Fig 4: Installing O-Ring To Front Side Plate
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    3. Align the dent of the front side plate with that of the front housing and install them.
      NOTE: Make sure that the front side plate is installed correctly.
      Fig 5: Aligning Dent Of Front Side Plate With Front Housing
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  4. INSTALL VANE PUMP CAM RING 
    1. Align the dent of the cam ring with that of the front side plate, and install the cam ring with the inscribed mark facing upward.
      Fig 6: Installing Cam Ring With Inscribed Mark Facing Upward
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  5. INSTALL VANE PUMP ROTOR 
    1. Install the vane pump rotor.
      Fig 7: Installing Vane Pump Rotor
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
    2. Apply power steering fluid to the 10 vane pump plates.
    3. Install the vane pump plates with the round end facing outward.
      Fig 8: Installing Vane Pump Plates With Round End Facing Outward
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  6. INSTALL VANE PUMP SHAFT SNAP RING 
    1. Using a screwdriver and snap ring expander, install a new snap ring to the shaft.
      Fig 9: Installing Snap Ring To Shaft
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  7. INSTALL REAR VANE PUMP HOUSING 
    1. Apply power steering fluid to a new O-ring and install it to the rear housing.
    2. Align the straight pin of the rear housing with the dents of the cam ring, the front side plate and the front housing, and install the rear housing with the 4 bolts.

      Torque: 22 N *  m (224 kgf *  cm, 16 ft. *  lbf) 

      Fig 10: Aligning Straight Pin Of Rear Housing With Dents Of Cam Ring
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  8. INSPECT PRELOAD 
    1. Check that the pump rotates smoothly without abnormal noise.
    2. Temporarily install the service bolt.

      Recommended service bolt: Thread diameter: 10 mm (0.39 in.) 

      Thread pitch: 1.25 mm (0.0492 in.) 

      Bolt length: 50 mm (1.97 in.) 

    3. Using a torque wrench, check the pump rotating torque.

      Standard rotating torque: 0.27 N *  m (2.8 kgf *  cm, 2.4 in. *  lbf) or less 

      If the rotating torque is not as specified, check the installation of the housing oil seal.

      Fig 11: Checking Pump Rotating Torque
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  9. INSTALL POWER STEERING OIL PRESSURE SENSOR 
    1. Apply power steering fluid to a new O-ring and install it to the oil pressure sensor.
    2. Install the oil pressure sensor to the front housing.

      Torque: 21 N *  m (214 kgf *  cm, 15 ft. *  lbf) 

  10. INSTALL FLOW CONTROL VALVE 
    1. Apply power steering fluid to the compression spring and flow control valve.
    2. Install the compression spring and the flow control valve.
    3. Apply power steering fluid to a new O-ring and install it to the pressure port union.
    4. Install the pressure port union.

      Torque: 69 N *  m (704 kgf *  cm, 51 ft. *  lbf) 

      Fig 12: Installing Compression Spring And Flow Control Valve
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  11. INSTALL FRONT PUMP BRACKET 
    1. Install the front bracket and rear bracket with the 2 bolts.
  12. INSTALL VANE PUMP OIL RESERVOIR ASSEMBLY 
    1. Apply power steering fluid to a new O-ring and install it to the oil reservoir.
    2. Install the oil reservoir to the front housing with the 3 bolts.

      Torque: 9.0 N *  m (92 kgf *  cm, 80 in. *  lbf) 

  13. INSTALL VANE PUMP OIL RESERVOIR CAP SUBASSEMBLY
