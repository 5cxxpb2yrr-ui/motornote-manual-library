How To Proceed With Troubleshooting (2005/12- )

HINT:

  • Use these procedures to troubleshoot the supplemental restraint system.
  • *: Use the intelligent tester.
  1. VEHICLE BROUGHT TO WORKSHOP 

    NEXT 

  2. INSPECT BATTERY VOLTAGE 

    Standard voltage: 

    11 to 14 V 

    If the voltage is below 11 V, recharge or replace the battery before proceeding.

    NEXT 

  3. CHECK FOR DTC* 
    1. Check for DTCs and note any codes that are output (see DTC CHECK / CLEAR  ).
    2. Delete the DTC.
    3. Recheck for DTC. Based on the DTC output above, try to force output of the same airbag system DTC or occupant classification system DTC by simulating the operation indicated by the DTC.

    Result: 

    RESULT

    Result Proceed to
    DTC output does not reoccur A
    Occupant classification system DTC output reoccurs B
    Airbag system DTC output reoccurs C

    B : Go to  OCCUPANT CLASSIFICATION SYSTEM  

    C : Go to step   6 

    A : Go to next step 

  4. PROBLEM SYMPTOMS TABLE 

    Result: 

    PROBLEM SYMPTOMS TEST RESULT

    Result Proceed to
    Fault is not listed in problem symptoms table A
    Fault is listed in problem symptoms table B

    B : Go to step   6 

    A : Go to next step
