Ignition Switch: Installation

  1. INSTALL IGNITION SWITCH ASSEMBLY 
    1. Install the switch to the steering column bracket with the 2 screws.
      Fig 1: Installing Steering Column Bracket Screws
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  2. REMOVE STEERING COLUMN UPPER WITH SWITCH BRACKET ASSEMBLY 
    1. Temporarily install the steering column upper with switch bracket and steering column clamp upper with 2 new steering lock set bolts.
    2. Tighten the 2 steering lock set bolts until the bolt heads break off.
      Fig 2: Identifying Steering Lock Set Bolts Installation Position
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  3. CONNECT CONNECTOR 
    1. Connect the 2 connectors as shown in the illustration.
    2. Secure the wire harness with the clamps.
      Fig 3: Identifying Connectors Connecting Position
      Courtesy of © TOYOTA, LICENSE AGREEMENT TMS1002
  4. INSTALL STEERING COLUMN COVER 
    1. Install the cover lower and upper with the 3 screws.

      HINT:

      Turn the steering wheel to the right and left as necessary to install the 3 screws and cover lower.
