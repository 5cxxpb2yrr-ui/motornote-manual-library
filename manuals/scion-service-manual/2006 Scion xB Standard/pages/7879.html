Water Pump: Installation

  1. INSTALL WATER PUMP ASSEMBLY 
    1. Install a new gasket and the water pump with the 3 bolts and 2 nuts.

      Torque: 11 N*m (112 kgf*cm, 8 ft.*lbf) 

  2. INSTALL WATER PUMP PULLEY 
    1. Using SST, install the pump pulley with the 3 bolts.

      SST 09960-10010 (09962-01000, 09963-00600) 

      Torque: 15 N*m (153 kgf*cm, 11 ft.*lbf) 

  3. INSTALL ENGINE MOUNTING INSULATOR SUBASSEMBLY RH (See  INSTALLATION  ) 
  4. INSTALL GENERATOR V BELT (see  INSTALLATION  ) 
  5. ADJUST GENERATOR V BELT (see  INSTALLATION  ) 
  6. INSTALL ENGINE UNDER COVER RH 
  7. ADD ENGINE COOLANT (See  COOLANT   ) 
  8. CHECK FOR ENGINE COOLANT LEAKS (See  WATER PUMP   )
